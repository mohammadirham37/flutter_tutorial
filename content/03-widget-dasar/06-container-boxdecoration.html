Container adalah "kotak serbaguna". Satu widget ini bisa mengatur ukuran (width, height), jarak dalam (padding), jarak luar (margin), posisi anak (alignment), dan dekorasi (decoration: warna, sudut membulat, border, bayangan, gradasi).

Contoh kecil: kotak berwarna

Container(
  width: 200,
  height: 100,
  color: Colors.amber,
  alignment: Alignment.center,
  child: const Text('Saya di dalam Container'),
)
Container kuning 200 x 100 dengan teks di tengah

Padding vs margin

┌──────────────── margin (jarak ke luar) ───────────────┐
│  ┌───────────── batas Container (warna) ───────────┐  │
│  │   padding (jarak ke dalam)                      │  │
│  │      ┌──────── child ────────┐                  │  │
│  │      │  Text('Halo')         │                  │  │
│  │      └───────────────────────┘                  │  │
│  └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘

EdgeInsets dipakai untuk keduanya: EdgeInsets.all(16) (semua sisi), EdgeInsets.symmetric(horizontal: 16, vertical: 8), dan EdgeInsets.only(left: 8, top: 4).

BoxDecoration: menghias kotak

Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),          // sudut membulat
    border: Border.all(color: Colors.indigo, width: 2), // garis tepi
    boxShadow: [
      BoxShadow(
        color: Colors.black.withValues(alpha: 0.15),  // bayangan transparan
        blurRadius: 8,
        offset: const Offset(0, 4),                   // geser ke bawah 4px
      ),
    ],
  ),
  child: const Text('Kotak dengan dekorasi'),
)
BoxDecoration: border, sudut membulat, bayangan

Contoh lengkap: galeri dekorasi Container

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const GaleriContainer(),
    );
  }
}

class GaleriContainer extends StatelessWidget {
  const GaleriContainer({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Galeri Container')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // 1. Warna polos + ukuran tetap
          Container(
            height: 80,
            color: Colors.indigo.shade100,
            alignment: Alignment.center,
            child: const Text('1. Warna polos'),
          ),
          const SizedBox(height: 16),

          // 2. Sudut membulat + border
          Container(
            height: 80,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              color: Colors.white,
              borderRadius: BorderRadius.circular(16),
              border: Border.all(color: Colors.indigo, width: 2),
            ),
            child: const Text('2. Border + sudut membulat'),
          ),
          const SizedBox(height: 16),

          // 3. Bayangan
          Container(
            height: 80,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              color: Colors.white,
              borderRadius: BorderRadius.circular(16),
              boxShadow: [
                BoxShadow(
                  color: Colors.black.withValues(alpha: 0.2),
                  blurRadius: 12,
                  offset: const Offset(0, 6),
                ),
              ],
            ),
            child: const Text('3. Bayangan (boxShadow)'),
          ),
          const SizedBox(height: 16),

          // 4. Gradasi warna
          Container(
            height: 80,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              gradient: const LinearGradient(
                colors: [Colors.orange, Colors.pink],
                begin: Alignment.centerLeft,
                end: Alignment.centerRight,
              ),
              borderRadius: BorderRadius.circular(16),
            ),
            child: const Text('4. LinearGradient', style: TextStyle(color: Colors.white)),
          ),
          const SizedBox(height: 16),

          // 5. Lingkaran
          Center(
            child: Container(
              width: 100,
              height: 100,
              alignment: Alignment.center,
              decoration: const BoxDecoration(
                color: Colors.teal,
                shape: BoxShape.circle, // jangan dipakai bersama borderRadius
              ),
              child: const Text('5. Bulat', style: TextStyle(color: Colors.white)),
            ),
          ),
          const SizedBox(height: 16),

          // 6. Border hanya di sisi kiri (gaya kartu pengumuman)
          Container(
            padding: const EdgeInsets.all(12),
            margin: const EdgeInsets.symmetric(horizontal: 8),
            decoration: BoxDecoration(
              color: Colors.amber.shade50,
              border: const Border(
                left: BorderSide(color: Colors.amber, width: 6),
              ),
            ),
            child: const Text('6. Pengumuman: UTS dimulai 3 November.'),
          ),
        ],
      ),
    );
  }
}
Galeri dekorasi Container

Penjelasan kode

  • alignment: Alignment.center menaruh child di tengah kotak.
  • Colors.indigo.shade100 adalah tingkat terang warna (50, 100, ... 900).
  • withValues(alpha: 0.2) membuat warna 20% tidak transparan. Ini pengganti withOpacity yang sudah usang.
  • BoxShape.circle membuat kotak menjadi lingkaran; ukurannya sebaiknya persegi (lebar = tinggi).
  • Border(left: BorderSide(...)) membuat garis hanya di satu sisi.

Studi kasus: Kartu Tanda Mahasiswa

Berikut implementasi kode kartu mahasiswa yang memadukan Container, BoxDecoration, Text, Icon, dan SizedBox:

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Kartu Mahasiswa',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: Scaffold(
        appBar: AppBar(title: const Text("Kartu Tanda Mahasiswa")),
        body: const Column(
          children: [
            SizedBox(height: 16),
            KartuMahasiswaWidget(
              nama: "Nadia Putri",
              nim: "21102001",
              jurusan: "S1 Informatika",
            ),
            KartuMahasiswaWidget(
              nama: "Fikri Ramadhan",
              nim: "21102045",
              jurusan: "S1 Sistem Informasi",
              isAktif: false,
            ),
          ],
        ),
      ),
    );
  }
}

class KartuMahasiswaWidget extends StatelessWidget {
  final String nama;
  final String nim;
  final String jurusan;
  final bool isAktif;

  const KartuMahasiswaWidget({
    super.key,
    required this.nama,
    required this.nim,
    required this.jurusan,
    this.isAktif = true,
  });

  @override
  Widget build(BuildContext context) {
    return Container(
      width: double.infinity,
      padding: const EdgeInsets.all(20),
      margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
      decoration: BoxDecoration(
        gradient: const LinearGradient(
          colors: [Color(0xFF1E3A8A), Color(0xFF3B82F6)], // Gradasi Biru Kampus
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
        ),
        borderRadius: BorderRadius.circular(16),
        boxShadow: [
          BoxShadow(
            // withValues menggantikan withOpacity yang sudah deprecated
            color: Colors.blue.withValues(alpha: 0.3),
            blurRadius: 12,
            offset: const Offset(0, 6),
          ),
        ],
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              // Flexible mencegah overflow jika layar HP sempit
              const Flexible(
                child: Text(
                  "KARTU TANDA MAHASISWA",
                  overflow: TextOverflow.ellipsis,
                  style: TextStyle(
                    color: Colors.white70,
                    fontSize: 12,
                    letterSpacing: 1.5,
                    fontWeight: FontWeight.bold,
                  ),
                ),
              ),
              Icon(
                isAktif ? Icons.verified : Icons.cancel,
                color: isAktif ? Colors.greenAccent : Colors.redAccent,
              ),
            ],
          ),
          const SizedBox(height: 16),
          Text(
            nama,
            style: const TextStyle(
              color: Colors.white,
              fontSize: 20,
              fontWeight: FontWeight.bold,
            ),
          ),
          const SizedBox(height: 4),
          Text(
            "NIM: $nim",
            style: const TextStyle(
              color: Colors.white,
              fontFamily: 'monospace',
              fontSize: 14,
            ),
          ),
          const SizedBox(height: 2),
          Text(
            jurusan,
            style: const TextStyle(
              color: Colors.white70,
              fontSize: 14,
            ),
          ),
        ],
      ),
    );
  }
}
Studi kasus Kartu Tanda Mahasiswa (aktif dan tidak aktif)

Penjelasan studi kasus

  • KartuMahasiswaWidget menerima data lewat konstruktor (nama, nim, jurusan, isAktif), sehingga satu class bisa dipakai untuk banyak mahasiswa.
  • width: double.infinity membuat kartu selebar mungkin sesuai ruang dari induknya.
  • Ikon berubah berdasarkan isAktif memakai operator ternary kondisi ? a : b.

⚠️ Kesalahan umum

  • Memakai color dan decoration bersamaan. Ini menimbulkan error "Cannot provide both a color and a decoration". Jika memakai decoration, pindahkan warna ke BoxDecoration(color: ...).
  • shape: BoxShape.circle + borderRadius sekaligus akan error. Pilih salah satu.
  • Memakai Container hanya untuk jarak. Jika hanya butuh jarak, SizedBox atau Padding lebih ringan dan lebih jelas maksudnya (dibahas di section berikutnya).
