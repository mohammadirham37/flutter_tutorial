Widget Image menampilkan gambar. Ada dua sumber yang paling sering dipakai: asset (file gambar yang ikut dibundel di dalam aplikasi) dan network (gambar dari internet lewat URL).

KonstruktorSumberKapan dipakai
Image.asset('assets/...')File di folder proyekLogo, ilustrasi, ikon kustom yang selalu sama.
Image.network('https://...')InternetFoto profil, gambar berita, data dari server.

Langkah 1: siapkan folder asset

Buat folder assets/images/ di akar proyek (sejajar dengan lib/ dan pubspec.yaml), lalu salin gambar ke sana, misalnya logo_unsoed.png.

nama_proyek/
├── assets/
│   └── images/
│       └── logo_unsoed.png
├── lib/
│   └── main.dart
└── pubspec.yaml

Langkah 2: daftarkan di pubspec.yaml

Buka pubspec.yaml, cari bagian flutter:, lalu tambahkan assets:. Perhatikan indentasi: assets: menjorok 2 spasi di bawah flutter:, dan daftar di bawahnya menjorok 4 spasi.

📄 pubspec.yaml (potongan)

flutter:
  uses-material-design: true

  # Daftarkan seluruh isi folder (akhiri dengan garis miring)
  assets:
    - assets/images/

Setelah menyimpan pubspec.yaml, jalankan perintah berikut lalu hentikan dan jalankan ulang aplikasi (hot reload tidak cukup untuk asset baru):

flutter pub get
flutter run

Langkah 3: tampilkan gambar

Image.asset(
  'assets/images/logo_unsoed.png',
  width: 120,
  height: 120,
  fit: BoxFit.contain, // gambar utuh, tidak terpotong
)

Gambar dari internet

Image.network(
  'https://picsum.photos/id/1/400/250',
  height: 180,
  width: double.infinity,
  fit: BoxFit.cover, // penuhi kotak, boleh terpotong
)
Image.network dengan BoxFit.cover

ℹ️ Izin internet di Android

Saat debug, izin internet sudah aktif. Untuk build rilis Android, pastikan android/app/src/main/AndroidManifest.xml berisi <uses-permission android:name="android.permission.INTERNET"/>. Detailnya dibahas di Modul 09 dan 16.

Nilai BoxFit yang perlu diketahui

NilaiHasil
BoxFit.coverMemenuhi kotak, sisi yang berlebih dipotong. Cocok untuk banner dan foto.
BoxFit.containGambar utuh di dalam kotak, mungkin ada ruang kosong. Cocok untuk logo.
BoxFit.fillDitarik memenuhi kotak, gambar bisa gepeng.
BoxFit.fitWidth / fitHeightMenyesuaikan lebar atau tinggi saja.

Contoh lengkap: gambar network dengan loading dan error

Contoh ini hanya memakai gambar network supaya langsung bisa dijalankan tanpa menyiapkan asset. Gambar dari internet butuh waktu dimuat dan bisa gagal (misalnya saat offline), jadi kita tampilkan indikator loading dan ikon cadangan.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: const DemoGambar(),
    );
  }
}

class DemoGambar extends StatelessWidget {
  const DemoGambar({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Demo Image')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          const Text('1. BoxFit.cover dengan sudut membulat'),
          const SizedBox(height: 8),
          // ClipRRect memotong anak menjadi sudut membulat
          ClipRRect(
            borderRadius: BorderRadius.circular(16),
            child: Image.network(
              'https://picsum.photos/id/1011/600/300',
              height: 180,
              width: double.infinity,
              fit: BoxFit.cover,
              // Dipanggil berulang selama gambar diunduh
              loadingBuilder: (context, child, progress) {
                if (progress == null) return child; // selesai dimuat
                return const SizedBox(
                  height: 180,
                  child: Center(child: CircularProgressIndicator()),
                );
              },
              // Dipanggil jika gambar gagal dimuat
              errorBuilder: (context, error, stackTrace) {
                return Container(
                  height: 180,
                  color: Colors.grey.shade300,
                  alignment: Alignment.center,
                  child: const Icon(Icons.broken_image, size: 48),
                );
              },
            ),
          ),
          const SizedBox(height: 24),
          const Text('2. Foto profil bulat dengan CircleAvatar'),
          const SizedBox(height: 8),
          Row(
            children: [
              CircleAvatar(
                radius: 32,
                foregroundImage: const NetworkImage('https://i.pravatar.cc/150?img=12'),
                // child tampil jika foregroundImage belum/gagal dimuat
                child: const Icon(Icons.person),
              ),
              const SizedBox(width: 12),
              const Text('Nadia Putri', style: TextStyle(fontSize: 18)),
            ],
          ),
          const SizedBox(height: 24),
          const Text('3. URL salah: errorBuilder bekerja'),
          const SizedBox(height: 8),
          Image.network(
            'https://contoh.invalid/gambar-tidak-ada.png',
            height: 100,
            errorBuilder: (context, error, stackTrace) => const Row(
              children: [
                Icon(Icons.error_outline, color: Colors.red),
                SizedBox(width: 8),
                Text('Gambar gagal dimuat'),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
Gambar network dengan sudut membulat, CircleAvatar, dan errorBuilder

Penjelasan kode

  • loadingBuilder menerima progress. Jika null, artinya gambar sudah selesai diunduh sehingga kita kembalikan child (gambar aslinya).
  • errorBuilder mencegah layar merah dan menggantinya dengan tampilan cadangan.
  • ClipRRect memotong gambar agar sudutnya membulat. Image sendiri tidak punya properti borderRadius.
  • CircleAvatar dengan foregroundImage tetap menampilkan ikon child jika foto gagal dimuat.

Versi asset dari contoh di atas

Setelah langkah 1 dan 2 selesai, kamu bisa mengganti Image.network(...) dengan asset, dan NetworkImage dengan AssetImage:

Column(
  children: [
    Image.asset('assets/images/logo_unsoed.png', height: 100),
    const SizedBox(height: 12),
    const CircleAvatar(
      radius: 32,
      backgroundImage: AssetImage('assets/images/logo_unsoed.png'),
    ),
  ],
)

⚠️ Kesalahan umum

  • "Unable to load asset": path di kode berbeda dengan nama file (huruf besar/kecil berpengaruh), atau folder belum didaftarkan di pubspec.yaml.
  • Indentasi YAML salah: assets: harus berada di dalam flutter: (2 spasi), bukan di tingkat paling kiri.
  • Hanya hot reload setelah menambah asset. Lakukan flutter pub get dan jalankan ulang aplikasi.
  • Gambar network tanpa errorBuilder: saat internet mati, pengguna melihat area kosong atau pesan error.
