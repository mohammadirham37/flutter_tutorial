Dua hal kecil yang sering muncul di kode Flutter: kata kunci const (supaya widget tidak dibuat ulang tanpa perlu) dan parameter key (supaya Flutter bisa mengenali widget yang sama ketika urutannya berubah).

Bagian 1: const

Widget yang ditandai const dibuat sekali saat kompilasi dan dipakai ulang. Saat induknya build ulang, Flutter tahu widget const pasti sama sehingga bisa melewatinya. Hasilnya aplikasi lebih hemat kerja.

// Boleh const: semua nilainya sudah pasti saat kompilasi
const judul = Text('Jadwal Kuliah');
const jarak = SizedBox(height: 16);
const ikon = Icon(Icons.home, color: Colors.indigo);
const kotak = Padding(padding: EdgeInsets.all(8), child: Text('Halo'));

// TIDAK boleh const: ada nilai yang baru diketahui saat aplikasi berjalan
Widget contoh(String nama, int skor) {
  return Column(
    children: [
      Text('Halo, $nama'),                   // nama berasal dari variabel
      Text('Skor: $skor'),
      Container(color: Colors.indigo.shade100), // .shade100 bukan konstanta
      // Tetapi anak yang nilainya tetap tetap boleh const:
      const Divider(),
    ],
  );
}

💡 Biarkan linter membantu

Proyek baru Flutter sudah memakai flutter_lints. Jika muncul garis biru "Use 'const' with the constructor to improve performance", tekan Ctrl+. lalu pilih Add 'const' modifier. Perintah dart fix --apply bisa menambahkan const di seluruh proyek sekaligus.

Bagian 2: Key

Flutter mencocokkan widget lama dan baru berdasarkan tipe dan posisinya. Biasanya ini cukup. Masalah muncul jika ada beberapa StatefulWidget bertipe sama dalam satu daftar lalu urutannya berubah (dihapus, diurutkan, ditukar). Tanpa key, State bisa "tertinggal" di posisi lama dan menempel ke data yang salah.

Contoh berikut memperlihatkan masalah itu. Setiap kotak menyimpan angka hitungan di State-nya sendiri. Tekan beberapa kotak, lalu tekan tombol Tukar urutan.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: DemoKey()));
}

class DemoKey extends StatefulWidget {
  const DemoKey({super.key});

  @override
  State<DemoKey> createState() => _DemoKeyState();
}

class _DemoKeyState extends State<DemoKey> {
  List<String> _nama = ['Andi', 'Budi', 'Citra'];
  bool _pakaiKey = false;

  void _tukar() {
    setState(() => _nama = _nama.reversed.toList());
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Demo Key')),
      body: Column(
        children: [
          SwitchListTile(
            title: const Text('Pakai ValueKey'),
            value: _pakaiKey,
            onChanged: (v) => setState(() => _pakaiKey = v),
          ),
          for (final n in _nama)
            KotakHitung(
              // Tanpa key: State dicocokkan berdasarkan posisi
              // Dengan key: State dicocokkan berdasarkan nama
              key: _pakaiKey ? ValueKey(n) : null,
              nama: n,
            ),
          const SizedBox(height: 16),
          FilledButton.icon(
            onPressed: _tukar,
            icon: const Icon(Icons.swap_vert),
            label: const Text('Tukar urutan'),
          ),
        ],
      ),
    );
  }
}

class KotakHitung extends StatefulWidget {
  final String nama;

  const KotakHitung({super.key, required this.nama});

  @override
  State<KotakHitung> createState() => _KotakHitungState();
}

class _KotakHitungState extends State<KotakHitung> {
  int _hitung = 0; // state milik masing-masing kotak

  @override
  Widget build(BuildContext context) {
    return Card(
      child: ListTile(
        title: Text(widget.nama),
        subtitle: const Text('Ketuk untuk menambah'),
        trailing: Text('$_hitung', style: const TextStyle(fontSize: 24)),
        onTap: () => setState(() => _hitung++),
      ),
    );
  }
}
Tampilan awal demo Key
Tanpa key: Andi diketuk 3x lalu ditukar, angka 3 tertinggal di baris pertama
Dengan ValueKey: angka 3 ikut pindah bersama Andi

Apa yang terjadi?

  • Tanpa key: ketuk Andi 3 kali (Andi = 3), lalu tukar urutan. Sekarang baris pertama berisi "Citra" tetapi angkanya tetap 3. State tetap di posisi pertama, sementara namanya pindah. Ini salah.
  • Dengan ValueKey(n): ulangi langkah yang sama. Angka 3 ikut pindah bersama "Andi" ke baris paling bawah. Flutter mencocokkan State berdasarkan key, bukan posisi.

Jenis key yang umum

KeyKapan dipakai
ValueKey(id)Item daftar yang punya nilai unik (id, NIM, email). Paling sering dipakai.
ObjectKey(objek)Keunikan ditentukan oleh objeknya sendiri.
UniqueKey()Memaksa widget selalu dianggap baru (State di-reset).
GlobalKeyMengakses State dari luar, misalnya GlobalKey<FormState> di Modul 05.

⚠️ Kesalahan umum

  • Memakai index sebagai key (ValueKey(index)). Index ikut berubah saat urutan berubah, jadi tidak membantu. Pakai id unik dari data.
  • Membuat UniqueKey() atau GlobalKey() di dalam build(). Key baru di setiap build membuat State terus di-reset.
  • Menambahkan const pada widget yang argumennya berasal dari variabel. Compiler akan error "Invalid constant value".
