Container memang serbaguna, tetapi untuk tugas tunggal Flutter menyediakan widget yang lebih kecil dan jelas maksudnya: Padding (jarak dalam), SizedBox (ukuran tetap atau jarak kosong), Center (menengahkan), dan Align (menaruh anak di posisi tertentu).

WidgetFungsiContoh
PaddingMemberi ruang di sekeliling anakPadding(padding: EdgeInsets.all(16), child: ...)
SizedBoxKotak berukuran pasti, atau jarak kosongSizedBox(height: 12)
CenterMenaruh anak tepat di tengahCenter(child: ...)
AlignMenaruh anak di titik mana punAlign(alignment: Alignment.topRight, child: ...)

Padding

const Padding(
  padding: EdgeInsets.symmetric(horizontal: 24, vertical: 8),
  child: Text('Teks dengan jarak kiri-kanan 24 dan atas-bawah 8'),
)
Padding horizontal 24 dan vertikal 8

SizedBox: tiga kegunaan

Column(
  children: [
    // 1. Jarak vertikal antar widget
    const Text('Baris pertama'),
    const SizedBox(height: 16),
    const Text('Baris kedua'),

    // 2. Memaksa ukuran anak
    SizedBox(
      width: 200,
      height: 48,
      child: ElevatedButton(onPressed: () {}, child: const Text('Login')),
    ),

    // 3. Selebar mungkin
    SizedBox(
      width: double.infinity,
      child: FilledButton(onPressed: () {}, child: const Text('Daftar')),
    ),
  ],
)
SizedBox sebagai jarak, ukuran tetap, dan selebar layar

Align dan nilai Alignment

Alignment(x, y) memakai koordinat dari -1 sampai 1. Titik (0, 0) adalah tengah, (-1, -1) pojok kiri atas, dan (1, 1) pojok kanan bawah.

(-1,-1) topLeft      (0,-1) topCenter      (1,-1) topRight
(-1, 0) centerLeft   (0, 0) center         (1, 0) centerRight
(-1, 1) bottomLeft   (0, 1) bottomCenter   (1, 1) bottomRight

Contoh lengkap: membandingkan keempat widget

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepPurple),
      home: const DemoTataLetakDasar(),
    );
  }
}

class DemoTataLetakDasar extends StatelessWidget {
  const DemoTataLetakDasar({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Padding, SizedBox, Center, Align')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          const Text('Padding:'),
          Container(
            color: Colors.deepPurple.shade50,
            child: const Padding(
              padding: EdgeInsets.all(24),
              child: Text('Ada ruang 24 px di sekeliling teks ini'),
            ),
          ),
          const SizedBox(height: 24),

          const Text('SizedBox ukuran tetap 120 x 60:'),
          const SizedBox(
            width: 120,
            height: 60,
            child: ColoredBox(color: Colors.orange),
          ),
          const SizedBox(height: 24),

          const Text('Center di dalam kotak 200 px:'),
          Container(
            height: 200,
            color: Colors.grey.shade200,
            child: const Center(child: Icon(Icons.star, size: 48)),
          ),
          const SizedBox(height: 24),

          const Text('Align ke pojok-pojok:'),
          Container(
            height: 200,
            color: Colors.grey.shade200,
            child: const Stack(
              children: [
                Align(alignment: Alignment.topLeft, child: Text('topLeft')),
                Align(alignment: Alignment.topRight, child: Text('topRight')),
                Align(alignment: Alignment.center, child: Text('center')),
                Align(alignment: Alignment.bottomLeft, child: Text('bottomLeft')),
                Align(alignment: Alignment(0.5, 0.5), child: Text('(0.5, 0.5)')),
              ],
            ),
          ),
          const SizedBox(height: 24),

          const Text('Tombol selebar layar dengan SizedBox:'),
          const SizedBox(height: 8),
          SizedBox(
            width: double.infinity,
            height: 48,
            child: FilledButton(
              onPressed: () {},
              child: const Text('Simpan KRS'),
            ),
          ),
        ],
      ),
    );
  }
}
Perbandingan Padding, SizedBox, Center, dan Align

Penjelasan kode

  • Container berwarna di sekitar Padding membuat jarak dalam terlihat jelas.
  • ColoredBox adalah widget ringan untuk memberi warna latar saja.
  • Stack dipakai agar beberapa Align bisa menempati kotak yang sama (Stack dibahas lengkap di Modul 04).
  • Alignment(0.5, 0.5) menunjukkan bahwa posisi tidak harus di sudut; nilai pecahan juga boleh.

💡 Pilih widget yang paling sederhana

Butuh jarak? SizedBox. Butuh ruang di sekitar? Padding. Butuh warna + sudut + bayangan sekaligus? Baru Container. Kode jadi lebih mudah dibaca dan bisa const.

⚠️ Kesalahan umum

  • Menulis SizedBox(height: 16) di dalam Row untuk memberi jarak horizontal. Di Row yang dipakai adalah width.
  • Menaruh Center di dalam Column lalu heran anaknya tidak di tengah layar secara vertikal. Center hanya menengahkan di dalam ruang yang diberikan induknya. Gunakan mainAxisAlignment pada Column (Modul 04).
  • Lupa const pada SizedBox dan Padding yang isinya tetap. Linter akan memberi saran prefer_const_constructors.
