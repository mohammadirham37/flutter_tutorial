Method build() yang panjangnya ratusan baris sulit dibaca dan sulit diperbaiki. Solusinya: pecah menjadi widget-widget kecil. Data dikirim ke widget kecil lewat parameter konstruktor, dan widget kecil mengabari induknya lewat callback (fungsi yang dikirim sebagai parameter).

Langkah 2: jadikan class dengan parameter

// SESUDAH: satu class, dipakai tiga kali
class KotakStatistik extends StatelessWidget {
  final IconData ikon;
  final String label;
  final String nilai;

  const KotakStatistik({
    super.key,
    required this.ikon,
    required this.label,
    required this.nilai,
  });

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: const EdgeInsets.all(12),
      color: Colors.blue.shade50,
      child: Column(children: [Icon(ikon), Text(label), Text(nilai)]),
    );
  }
}

Langkah 3: callback, agar anak bisa "melapor" ke induk

Widget kecil sebaiknya tidak menyimpan state yang juga dibutuhkan induk. Biarkan induk yang menyimpan state, lalu kirim fungsi ke anak. Tipe yang paling sering dipakai:

TipeArtinyaContoh pemakaian
VoidCallbackFungsi tanpa parameter, tanpa nilai kembaliTombol "Hapus" ditekan
ValueChanged<T>Fungsi yang menerima satu nilai bertipe TCheckbox berubah menjadi true/false
void Function(String, int)Fungsi dengan parameter bebasMengirim nama dan jumlah sekaligus
 
class TombolSuka extends StatelessWidget {
  final bool disukai;
  final VoidCallback onTekan; // induk yang menentukan apa yang terjadi

  const TombolSuka({super.key, required this.disukai, required this.onTekan});

  @override
  Widget build(BuildContext context) {
    return IconButton(
      onPressed: onTekan, // teruskan ke induk
      icon: Icon(
        disukai ? Icons.favorite : Icons.favorite_border,
        color: disukai ? Colors.red : null,
      ),
    );
  }
}

Contoh lengkap: daftar tugas kuliah yang dipecah menjadi widget kecil

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const HalamanTugas(),
    );
  }
}

/// Model data sederhana untuk satu tugas.
class Tugas {
  final String judul;
  final String matkul;
  bool selesai;

  Tugas({required this.judul, required this.matkul, this.selesai = false});
}

/// INDUK: satu-satunya tempat state disimpan.
class HalamanTugas extends StatefulWidget {
  const HalamanTugas({super.key});

  @override
  State<HalamanTugas> createState() => _HalamanTugasState();
}

class _HalamanTugasState extends State<HalamanTugas> {
  final List<Tugas> _daftar = [
    Tugas(judul: 'Laporan Praktikum 3', matkul: 'Pemrograman Mobile'),
    Tugas(judul: 'ERD Sistem Akademik', matkul: 'Basis Data'),
    Tugas(judul: 'Resume Bab 4', matkul: 'Jaringan Komputer', selesai: true),
  ];

  void _ubahStatus(int index, bool nilai) {
    setState(() => _daftar[index].selesai = nilai);
  }

  void _hapus(int index) {
    setState(() => _daftar.removeAt(index));
  }

  @override
  Widget build(BuildContext context) {
    final jumlahSelesai = _daftar.where((t) => t.selesai).length;

    return Scaffold(
      appBar: AppBar(title: const Text('Tugas Kuliah')),
      body: Column(
        children: [
          // Widget kecil 1: hanya menerima data
          RingkasanTugas(selesai: jumlahSelesai, total: _daftar.length),
          Expanded(
            child: ListView.builder(
              itemCount: _daftar.length,
              itemBuilder: (context, index) {
                // Widget kecil 2: menerima data + 2 callback
                return ItemTugas(
                  tugas: _daftar[index],
                  onCentang: (nilai) => _ubahStatus(index, nilai),
                  onHapus: () => _hapus(index),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

/// ANAK 1: StatelessWidget yang hanya menampilkan ringkasan.
class RingkasanTugas extends StatelessWidget {
  final int selesai;
  final int total;

  const RingkasanTugas({super.key, required this.selesai, required this.total});

  @override
  Widget build(BuildContext context) {
    final progres = total == 0 ? 0.0 : selesai / total;
    return Card(
      margin: const EdgeInsets.all(16),
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('$selesai dari $total tugas selesai',
                style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 8),
            LinearProgressIndicator(value: progres),
          ],
        ),
      ),
    );
  }
}

/// ANAK 2: menampilkan satu tugas dan melapor ke induk lewat callback.
class ItemTugas extends StatelessWidget {
  final Tugas tugas;
  final ValueChanged<bool> onCentang;
  final VoidCallback onHapus;

  const ItemTugas({
    super.key,
    required this.tugas,
    required this.onCentang,
    required this.onHapus,
  });

  @override
  Widget build(BuildContext context) {
    return ListTile(
      leading: Checkbox(
        value: tugas.selesai,
        // Checkbox memberi bool? (bisa null), kita ubah jadi bool
        onChanged: (nilai) => onCentang(nilai ?? false),
      ),
      title: Text(
        tugas.judul,
        style: TextStyle(
          decoration: tugas.selesai ? TextDecoration.lineThrough : null,
        ),
      ),
      subtitle: Text(tugas.matkul),
      trailing: IconButton(
        icon: const Icon(Icons.delete_outline),
        tooltip: 'Hapus',
        onPressed: onHapus,
      ),
    );
  }
}

Penjelasan alur data

_HalamanTugasState (punya state _daftar)
   │  data turun lewat parameter (selesai, total, tugas)
   ▼
RingkasanTugas     ItemTugas
                      │  kejadian naik lewat callback (onCentang, onHapus)
                      ▼
               _ubahStatus / _hapus  →  setState  →  build ulang
  • Data turun, kejadian naik. Ini pola paling penting dalam Flutter. Anak tidak mengubah data sendiri, ia memanggil callback dan induk yang memutuskan.
  • RingkasanTugas dan ItemTugas adalah StatelessWidget walaupun tampilannya berubah, karena state disimpan di induk.
  • (nilai) => _ubahStatus(index, nilai) adalah fungsi anonim yang "mengingat" index item tersebut.

Widget class vs method helper

Kamu mungkin melihat kode yang memecah UI dengan method seperti Widget _buildHeader() { ... }. Cara ini boleh untuk potongan kecil, tetapi class widget lebih disarankan karena bisa const, punya context sendiri, dan Flutter bisa melewati build-nya jika datanya tidak berubah.

⚠️ Kesalahan umum

  • Menyimpan salinan state di anak (misalnya anak punya bool _selesai sendiri). Data induk dan anak jadi tidak sinkron.
  • Memanggil callback saat build: onPressed: onHapus() (dengan kurung) langsung menjalankan fungsi saat build. Yang benar onPressed: onHapus tanpa kurung.
  • Memecah terlalu kecil sampai setiap Text jadi class. Pecah berdasarkan bagian yang bermakna: header, kartu, item daftar.
