Setiap widget buatan sendiri adalah turunan dari salah satu dari dua class: StatelessWidget (tampilan tidak berubah sendiri) atau StatefulWidget (punya data yang bisa berubah dan membuat tampilan digambar ulang).

Aspek StatelessWidget StatefulWidget
Karakteristik Statis, tidak berubah sepanjang waktu Dinamis, dapat berubah berdasarkan interaksi atau data
State Tidak memiliki objek State internal Memiliki objek State<T> yang persisten
Jumlah class 1 class 2 class: widget + State-nya
Kapan Digunakan? Label teks statis, icon, layout struktur, kartu profil statis Formulir input, checkbox toggle, animasi, data hasil request API

Pertanyaan penentu

Tanyakan: "Apakah widget ini perlu mengingat sesuatu yang bisa berubah saat aplikasi berjalan?" Jika tidak, pakai StatelessWidget. Jika ya (angka penghitung, status centang, teks yang diketik), pakai StatefulWidget.

Kerangka StatelessWidget

class SapaanMahasiswa extends StatelessWidget {
  // Data masuk lewat konstruktor dan bersifat final (tidak bisa diubah)
  final String nama;

  const SapaanMahasiswa({super.key, required this.nama});

  @override
  Widget build(BuildContext context) {
    return Text('Halo, $nama!');
  }
}
Widget SapaanMahasiswa dengan nama Nadia

Tiga bagian wajib: field final untuk data, konstruktor const dengan super.key, dan method build yang mengembalikan widget.

Contoh lengkap StatelessWidget: kartu profil dosen

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: Scaffold(
        appBar: AppBar(title: const Text('Dosen Pengampu')),
        body: ListView(
          padding: const EdgeInsets.all(16),
          children: const [
            // Satu class dipakai berulang dengan data berbeda
            KartuDosen(
              nama: 'Dr. Ratna Dewi, S.Kom., M.Kom.',
              bidang: 'Rekayasa Perangkat Lunak',
              ruang: 'Gedung E, Lt. 2',
            ),
            KartuDosen(
              nama: 'Andi Wijaya, S.T., M.Eng.',
              bidang: 'Jaringan Komputer',
              ruang: 'Gedung E, Lt. 3',
            ),
            KartuDosen(
              nama: 'Siti Rahma, S.Kom., M.Cs.',
              bidang: 'Kecerdasan Buatan',
              ruang: 'Gedung F, Lt. 1',
            ),
          ],
        ),
      ),
    );
  }
}

class KartuDosen extends StatelessWidget {
  final String nama;
  final String bidang;
  final String ruang;

  const KartuDosen({
    super.key,
    required this.nama,
    required this.bidang,
    required this.ruang,
  });

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Row(
          children: [
            CircleAvatar(
              radius: 28,
              // Ambil huruf pertama nama sebagai inisial
              child: Text(nama.substring(0, 1), style: const TextStyle(fontSize: 22)),
            ),
            const SizedBox(width: 16),
            Expanded(
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(nama, style: const TextStyle(fontWeight: FontWeight.bold)),
                  const SizedBox(height: 4),
                  Text(bidang),
                  Row(
                    children: [
                      const Icon(Icons.room, size: 16),
                      const SizedBox(width: 4),
                      Text(ruang, style: const TextStyle(color: Colors.grey)),
                    ],
                  ),
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}
Satu class KartuDosen dipakai untuk tiga dosen

Penjelasan kode

  • KartuDosen tidak menyimpan data yang berubah. Semua datanya datang dari luar (parameter konstruktor), jadi cocok sebagai StatelessWidget.
  • Karena konstruktornya const dan datanya berupa string literal, daftar children di ListView bisa diberi const.
  • Expanded mencegah teks nama yang panjang menabrak tepi layar (dibahas di Modul 04).

ℹ️ "Stateless" bukan berarti tidak pernah digambar ulang

StatelessWidget tetap bisa tampil berbeda jika induknya membangunnya ulang dengan data baru. Yang tidak bisa adalah mengubah tampilannya sendiri. Untuk itu kita perlu StatefulWidget di section berikutnya.

⚠️ Kesalahan umum

  • Mencoba mengubah field di StatelessWidget (nama = 'baru'). Field-nya final, jadi akan error.
  • Langsung memakai StatefulWidget untuk semua hal "berjaga-jaga". Mulailah dari StatelessWidget, ubah ke Stateful hanya jika memang butuh state.
