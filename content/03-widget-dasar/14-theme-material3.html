Daripada mengatur warna dan ukuran huruf di setiap widget, Flutter menyediakan ThemeData: satu tempat untuk mengatur tampilan seluruh aplikasi. Sejak Flutter 3.16, tema bawaan sudah memakai Material 3.

ColorScheme.fromSeed: satu warna, satu palet lengkap

Cukup berikan satu warna benih (seed). Flutter menghitung palet lengkap yang serasi: primary, secondary, tertiary, surface, error, beserta pasangan warna teks di atasnya (onPrimary, onSurface, dan seterusnya).

MaterialApp(
  theme: ThemeData(
    colorScheme: ColorScheme.fromSeed(seedColor: const Color(0xFF0D47A1)),
  ),
  home: const Scaffold(body: Center(child: Text('Tema biru'))),
)
Tema dari ColorScheme.fromSeed

Bentuk singkatnya adalah ThemeData(colorSchemeSeed: Colors.indigo), yang sudah kita pakai di contoh-contoh sebelumnya.

Peran warna di ColorScheme

WarnaDipakai untuk
primary / onPrimaryTombol utama, elemen penting / teks di atasnya.
primaryContainer / onPrimaryContainerLatar lembut untuk kartu atau chip yang ditonjolkan.
secondary, tertiaryAksen pendukung.
surface / onSurfaceLatar halaman dan kartu / teks umum.
errorPesan kesalahan.

Membaca tema dari widget

Widget kotakTema(BuildContext context) {
  final warna = Theme.of(context).colorScheme;
  final teks = Theme.of(context).textTheme;

  return Container(
    padding: const EdgeInsets.all(16),
    color: warna.primaryContainer,
    child: Text(
      'Halo',
      style: teks.headlineMedium?.copyWith(color: warna.onPrimaryContainer),
    ),
  );
}

Contoh lengkap: tema terang, tema gelap, dan tombol ganti tema

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const AplikasiBertema());
}

class AplikasiBertema extends StatefulWidget {
  const AplikasiBertema({super.key});

  @override
  State<AplikasiBertema> createState() => _AplikasiBertemaState();
}

class _AplikasiBertemaState extends State<AplikasiBertema> {
  // system = ikut pengaturan HP, light = terang, dark = gelap
  ThemeMode _mode = ThemeMode.system;

  static const Color _warnaKampus = Color(0xFFF2A900); // kuning keemasan

  ThemeData _buatTema(Brightness brightness) {
    final skema = ColorScheme.fromSeed(
      seedColor: _warnaKampus,
      brightness: brightness,
    );
    return ThemeData(
      colorScheme: skema,
      // Atur gaya teks tertentu, sisanya ikut bawaan Material 3
      textTheme: const TextTheme(
        headlineSmall: TextStyle(fontWeight: FontWeight.bold),
      ),
      appBarTheme: AppBarTheme(
        backgroundColor: skema.primaryContainer,
        foregroundColor: skema.onPrimaryContainer,
        centerTitle: true,
      ),
      cardTheme: const CardThemeData(
        margin: EdgeInsets.symmetric(vertical: 6),
      ),
      filledButtonTheme: FilledButtonThemeData(
        style: FilledButton.styleFrom(minimumSize: const Size.fromHeight(48)),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: _buatTema(Brightness.light),      // dipakai saat mode terang
      darkTheme: _buatTema(Brightness.dark),   // dipakai saat mode gelap
      themeMode: _mode,                        // menentukan mana yang aktif
      home: HalamanTema(
        mode: _mode,
        onGantiMode: (modeBaru) => setState(() => _mode = modeBaru),
      ),
    );
  }
}

class HalamanTema extends StatelessWidget {
  final ThemeMode mode;
  final ValueChanged<ThemeMode> onGantiMode;

  const HalamanTema({super.key, required this.mode, required this.onGantiMode});

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    final teks = Theme.of(context).textTheme;

    return Scaffold(
      appBar: AppBar(title: const Text('Tema Material 3')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Text('Pilih mode tema', style: teks.headlineSmall),
          const SizedBox(height: 12),
          SegmentedButton<ThemeMode>(
            segments: const [
              ButtonSegment(value: ThemeMode.light, icon: Icon(Icons.light_mode), label: Text('Terang')),
              ButtonSegment(value: ThemeMode.system, icon: Icon(Icons.phone_android), label: Text('Sistem')),
              ButtonSegment(value: ThemeMode.dark, icon: Icon(Icons.dark_mode), label: Text('Gelap')),
            ],
            selected: {mode},
            onSelectionChanged: (pilihan) => onGantiMode(pilihan.first),
          ),
          const SizedBox(height: 24),
          Text('Palet dari ColorScheme.fromSeed', style: teks.titleMedium),
          const SizedBox(height: 8),
          Wrap(
            spacing: 8,
            runSpacing: 8,
            children: [
              KotakWarna(nama: 'primary', latar: warna.primary, teks: warna.onPrimary),
              KotakWarna(nama: 'secondary', latar: warna.secondary, teks: warna.onSecondary),
              KotakWarna(nama: 'tertiary', latar: warna.tertiary, teks: warna.onTertiary),
              KotakWarna(nama: 'primaryContainer', latar: warna.primaryContainer, teks: warna.onPrimaryContainer),
              KotakWarna(nama: 'surface', latar: warna.surfaceContainerHighest, teks: warna.onSurface),
              KotakWarna(nama: 'error', latar: warna.error, teks: warna.onError),
            ],
          ),
          const SizedBox(height: 24),
          const Card(
            child: ListTile(
              leading: Icon(Icons.campaign),
              title: Text('Card ikut tema'),
              subtitle: Text('Warna dan margin diatur di cardTheme'),
            ),
          ),
          const SizedBox(height: 16),
          FilledButton(onPressed: () {}, child: const Text('Tombol utama (lebar penuh dari tema)')),
        ],
      ),
    );
  }
}

class KotakWarna extends StatelessWidget {
  final String nama;
  final Color latar;
  final Color teks;

  const KotakWarna({super.key, required this.nama, required this.latar, required this.teks});

  @override
  Widget build(BuildContext context) {
    return Container(
      width: 150,
      height: 56,
      alignment: Alignment.center,
      decoration: BoxDecoration(color: latar, borderRadius: BorderRadius.circular(12)),
      child: Text(nama, style: TextStyle(color: teks, fontSize: 12)),
    );
  }
}

Setelah memilih mode Gelap

Penjelasan kode

  • theme dan darkTheme dibuat dari fungsi yang sama, hanya berbeda brightness. Palet gelap otomatis dihitung dari seed yang sama.
  • themeMode menentukan tema mana yang dipakai. ThemeMode.system mengikuti pengaturan mode gelap di HP.
  • appBarTheme, cardTheme, dan filledButtonTheme mengatur gaya default semua AppBar, Card, dan FilledButton sekaligus. Itulah sebabnya Card dan tombol di halaman tidak perlu diatur satu per satu.
  • Pilihan mode disimpan di _AplikasiBertemaState (induk paling atas) dan diubah lewat callback onGantiMode, sesuai pola "data turun, kejadian naik".
  • SegmentedButton adalah tombol pilihan bersegmen dari Material 3.

ℹ️ Menyimpan pilihan tema

Saat aplikasi ditutup, pilihan tema di contoh ini kembali ke "Sistem". Menyimpannya secara permanen akan dipelajari di Modul 10 (SharedPreferences) dan mengelolanya lintas halaman di Modul 08 (Provider).

⚠️ Kesalahan umum

  • Memberi brightness berbeda antara ThemeData dan ColorScheme. Atur brightness di ColorScheme.fromSeed seperti contoh di atas.
  • Menulis warna langsung (Colors.white, Colors.black) di banyak tempat. Di mode gelap teks hitam di latar gelap jadi tidak terbaca. Gunakan colorScheme.onSurface dan kawan-kawannya.
  • Mengisi darkTheme tetapi lupa themeMode. Default-nya ThemeMode.system, jadi tema gelap hanya muncul jika HP sedang mode gelap.
  • Memakai CardTheme di ThemeData.cardTheme. Versi Flutter terbaru memakai CardThemeData.
