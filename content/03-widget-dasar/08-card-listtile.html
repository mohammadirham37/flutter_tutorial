Card adalah panel bersudut membulat dengan bayangan/warna permukaan khas Material. ListTile adalah satu baris berisi ikon/gambar di kiri, judul, subjudul, dan widget di kanan. Keduanya sering dipakai bersama untuk daftar data seperti mata kuliah, pengumuman, atau kontak.

Anatomi ListTile

┌─────────────────────────────────────────────────────┐
│ [leading]  title (judul)                 [trailing] │
│            subtitle (keterangan)                    │
└─────────────────────────────────────────────────────┘

Contoh kecil

Card(
  child: ListTile(
    leading: const Icon(Icons.book),
    title: const Text('Pemrograman Mobile'),
    subtitle: const Text('3 SKS • Senin 07.30'),
    trailing: const Icon(Icons.chevron_right),
    onTap: () {
      debugPrint('Mata kuliah dipilih');
    },
  ),
)
Card berisi ListTile lengkap

Varian Card di Material 3

Material 3 menyediakan tiga gaya: Card() (elevated, sedikit bayangan), Card.filled() (warna permukaan, tanpa bayangan), dan Card.outlined() (garis tepi).

Contoh lengkap: daftar mata kuliah

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.blue),
      home: const DaftarMatkul(),
    );
  }
}

class DaftarMatkul extends StatelessWidget {
  const DaftarMatkul({super.key});

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;

    return Scaffold(
      appBar: AppBar(title: const Text('Mata Kuliah Semester 5')),
      body: ListView(
        padding: const EdgeInsets.all(12),
        children: [
          // 1. Card biasa + ListTile lengkap
          Card(
            child: ListTile(
              leading: CircleAvatar(
                backgroundColor: warna.primaryContainer,
                child: const Text('PM'),
              ),
              title: const Text('Pemrograman Mobile'),
              subtitle: const Text('3 SKS • Senin, 07.30 • Lab Komputer 2'),
              trailing: const Icon(Icons.chevron_right),
              onTap: () {
                ScaffoldMessenger.of(context).showSnackBar(
                  const SnackBar(content: Text('Membuka Pemrograman Mobile')),
                );
              },
            ),
          ),

          // 2. Card.filled + subtitle dua baris
          const Card.filled(
            child: ListTile(
              leading: Icon(Icons.storage),
              title: Text('Basis Data Lanjut'),
              subtitle: Text('3 SKS • Selasa, 10.00\nDosen: Dr. Budi Santoso'),
              isThreeLine: true,
            ),
          ),

          // 3. Card.outlined + trailing berupa teks
          const Card.outlined(
            child: ListTile(
              leading: Icon(Icons.hub),
              title: Text('Jaringan Komputer'),
              subtitle: Text('2 SKS • Rabu, 13.00'),
              trailing: Text('A', style: TextStyle(fontSize: 20, fontWeight: FontWeight.bold)),
            ),
          ),

          // 4. Card berisi konten bebas (bukan ListTile)
          Card(
            clipBehavior: Clip.antiAlias, // agar isi ikut terpotong sudutnya
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Container(
                  height: 100,
                  color: warna.tertiaryContainer,
                  alignment: Alignment.center,
                  child: const Icon(Icons.campaign, size: 48),
                ),
                const Padding(
                  padding: EdgeInsets.all(16),
                  child: Text(
                    'Pengumuman: Kuliah pengganti Pemrograman Mobile '
                    'dilaksanakan Sabtu pukul 08.00.',
                  ),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
Varian Card Material 3 dan Card berisi konten bebas

Penjelasan kode

  • Theme.of(context).colorScheme memberi akses ke warna tema (misal primaryContainer), jadi warna otomatis serasi.
  • onTap membuat seluruh baris bisa ditekan dan memunculkan efek riak (ripple).
  • isThreeLine: true memberi tinggi ekstra saat subtitle berisi dua baris.
  • clipBehavior: Clip.antiAlias diperlukan agar Container berwarna di dalam Card tidak keluar dari sudut membulat.

⚠️ Kesalahan umum

  • Menaruh Row panjang di title sehingga overflow. Gunakan Text dengan maxLines dan overflow.
  • Menaruh widget lebar tanpa batas (misal TextField atau Row tanpa Expanded) di trailing. Slot trailing ukurannya terbatas.
  • Lupa clipBehavior sehingga gambar/warna di dalam Card menutupi sudut membulat.
