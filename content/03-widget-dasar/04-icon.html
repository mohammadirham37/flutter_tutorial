Widget Icon menampilkan simbol dari font ikon. Flutter sudah membawa ribuan ikon Material lewat class Icons, jadi kamu tidak perlu mengunduh gambar apa pun.

Contoh kecil

const Icon(
  Icons.favorite,      // jenis ikon
  size: 32,            // ukuran (default 24)
  color: Colors.red,   // warna
  semanticLabel: 'Favorit', // dibacakan oleh pembaca layar (aksesibilitas)
)
Icon favorit merah ukuran 32

Nama ikon bisa dicari di fonts.google.com/icons. Hampir setiap ikon punya beberapa varian: Icons.home (terisi), Icons.home_outlined (garis), Icons.home_rounded, dan Icons.home_sharp.

Icon vs IconButton

Icon hanya gambar dan tidak bisa diklik. Jika ikon harus bisa ditekan, pakai IconButton yang memiliki onPressed dan efek sentuhan.

IconButton(
  icon: const Icon(Icons.share),
  tooltip: 'Bagikan',
  onPressed: () {
    debugPrint('Tombol bagikan ditekan');
  },
)
IconButton berbentuk ikon bagikan

Contoh lengkap: menu ikon portal kampus

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DemoIkon(),
    );
  }
}

class DemoIkon extends StatelessWidget {
  const DemoIkon({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Demo Icon'),
        actions: [
          IconButton(
            icon: const Icon(Icons.settings_outlined),
            tooltip: 'Pengaturan',
            onPressed: () {
              ScaffoldMessenger.of(context).showSnackBar(
                const SnackBar(content: Text('Pengaturan ditekan')),
              );
            },
          ),
        ],
      ),
      body: const Padding(
        padding: EdgeInsets.all(24),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('Ukuran berbeda:'),
            SizedBox(height: 8),
            Row(
              children: [
                Icon(Icons.star, size: 16),
                Icon(Icons.star, size: 24),
                Icon(Icons.star, size: 36),
                Icon(Icons.star, size: 48),
              ],
            ),
            SizedBox(height: 24),
            Text('Warna berbeda:'),
            SizedBox(height: 8),
            Row(
              children: [
                Icon(Icons.circle, color: Colors.red),
                Icon(Icons.circle, color: Colors.orange),
                Icon(Icons.circle, color: Colors.green),
                Icon(Icons.circle, color: Colors.blue),
              ],
            ),
            SizedBox(height: 24),
            Text('Varian ikon yang sama:'),
            SizedBox(height: 8),
            Row(
              children: [
                Icon(Icons.home, size: 32),
                Icon(Icons.home_outlined, size: 32),
                Icon(Icons.home_rounded, size: 32),
                Icon(Icons.home_sharp, size: 32),
              ],
            ),
            SizedBox(height: 24),
            Text('Ikon + teks (pola yang paling sering dipakai):'),
            SizedBox(height: 8),
            Row(
              children: [
                Icon(Icons.location_on, color: Colors.redAccent),
                SizedBox(width: 8),
                Text('Kampus Karangwangkal, Purwokerto'),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
Ukuran, warna, dan varian ikon

Penjelasan kode

  • Seluruh isi body bisa const karena tidak ada nilai yang berubah. Satu const di depan Padding sudah berlaku untuk semua anak di dalamnya.
  • IconButton di AppBar memakai ScaffoldMessenger.of(context).showSnackBar(...) untuk menampilkan pesan singkat di bawah layar.
  • Pola ikon + SizedBox + teks di dalam Row akan sangat sering kamu pakai.

⚠️ Kesalahan umum

  • Membungkus Icon dengan GestureDetector agar bisa diklik. Bisa, tetapi tidak ada efek sentuhan dan area sentuhnya kecil. Gunakan IconButton.
  • Salah nama ikon (misalnya Icons.homes) akan langsung error saat kompilasi. Cek ejaan di situs Google Fonts Icons.
  • Lupa tooltip pada IconButton. Tooltip membantu pengguna dan pembaca layar memahami fungsi tombol.
