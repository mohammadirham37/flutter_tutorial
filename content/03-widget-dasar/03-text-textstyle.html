Widget Text menampilkan tulisan. Tampilan tulisan (ukuran, warna, ketebalan, jarak huruf) diatur lewat objek TextStyle yang diberikan ke parameter style.

Contoh kecil

const Text(
  'Informatika UNSOED',
  style: TextStyle(
    fontSize: 24,                 // ukuran huruf (logical pixel)
    fontWeight: FontWeight.bold,  // ketebalan: w100 s.d. w900
    color: Colors.indigo,         // warna teks
    letterSpacing: 1.2,           // jarak antar huruf
  ),
)
Text dengan TextStyle: besar, tebal, berwarna

Properti penting

MilikPropertiFungsi
TexttextAlignPerataan: TextAlign.left, center, right, justify.
TextmaxLinesBatas jumlah baris.
TextoverflowPerilaku jika teks kepanjangan, misalnya TextOverflow.ellipsis (menambah "...").
TextStylefontStyleFontStyle.italic untuk huruf miring.
TextStyledecorationGaris bawah, coret: TextDecoration.underline, lineThrough.
TextStyleheightTinggi baris sebagai kelipatan ukuran font (misal 1.5).

Contoh lengkap: berbagai gaya teks

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const DemoTeks(),
    );
  }
}

class DemoTeks extends StatelessWidget {
  const DemoTeks({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Demo Text & TextStyle')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // 1. Teks polos tanpa gaya
          const Text('1. Teks polos tanpa style'),
          const SizedBox(height: 12),

          // 2. Ukuran, tebal, warna
          const Text(
            '2. Judul Besar',
            style: TextStyle(
              fontSize: 28,
              fontWeight: FontWeight.w800,
              color: Colors.teal,
            ),
          ),
          const SizedBox(height: 12),

          // 3. Miring, garis bawah, coret
          const Text(
            '3. Miring dan bergaris bawah',
            style: TextStyle(
              fontStyle: FontStyle.italic,
              decoration: TextDecoration.underline,
            ),
          ),
          const Text(
            'Harga lama: Rp150.000',
            style: TextStyle(decoration: TextDecoration.lineThrough, color: Colors.grey),
          ),
          const SizedBox(height: 12),

          // 4. Teks panjang dipotong dengan ellipsis
          const Text(
            '4. Ini adalah judul pengumuman yang sangat panjang sekali sehingga '
            'tidak muat dalam satu baris layar ponsel mahasiswa',
            maxLines: 1,
            overflow: TextOverflow.ellipsis,
          ),
          const SizedBox(height: 12),

          // 5. Rata tengah dan jarak baris
          const Text(
            '5. Paragraf rata tengah dengan jarak baris 1.6 agar '
            'lebih nyaman dibaca saat teksnya panjang.',
            textAlign: TextAlign.center,
            style: TextStyle(height: 1.6),
          ),
          const SizedBox(height: 12),

          // 6. Memakai gaya dari tema (disarankan)
          Text(
            '6. headlineSmall dari tema',
            style: Theme.of(context).textTheme.headlineSmall,
          ),
          const SizedBox(height: 12),

          // 7. Text.rich: satu kalimat, beberapa gaya
          const Text.rich(
            TextSpan(
              text: '7. IPK kamu: ',
              children: [
                TextSpan(
                  text: '3.85',
                  style: TextStyle(fontWeight: FontWeight.bold, color: Colors.green),
                ),
                TextSpan(text: ' (Cumlaude)'),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
Berbagai gaya teks, ellipsis, dan Text.rich

Penjelasan kode

  • Teks panjang di Dart bisa ditulis sebagai beberapa string yang ditempel berurutan (adjacent strings), seperti pada nomor 4 dan 5. Dart menggabungkannya otomatis.
  • maxLines: 1 + overflow: TextOverflow.ellipsis adalah pasangan yang paling sering dipakai untuk judul di daftar.
  • Theme.of(context).textTheme.headlineSmall mengambil gaya teks bawaan tema Material 3. Cara ini membuat ukuran huruf konsisten di seluruh aplikasi.
  • Text.rich dengan TextSpan dipakai jika satu kalimat butuh beberapa gaya berbeda.

Menggabungkan gaya tema dengan copyWith

Sering kita ingin gaya dari tema, tetapi warnanya diganti. Gunakan copyWith agar tidak menulis ulang semua properti:

Text(
  'Jadwal Hari Ini',
  style: Theme.of(context).textTheme.titleLarge?.copyWith(
        color: Theme.of(context).colorScheme.primary,
        fontWeight: FontWeight.bold,
      ),
)
Gaya titleLarge dari tema yang diubah dengan copyWith

Tanda ?. dipakai karena titleLarge bertipe TextStyle? (boleh null).

⚠️ Kesalahan umum

  • Memberi angka bertipe int ke tempat yang butuh double sebenarnya aman (fontSize: 24 boleh), tetapi menulis fontWeight: 700 salah. Gunakan FontWeight.w700.
  • Memakai overflow: TextOverflow.ellipsis tanpa maxLines atau tanpa batas lebar. Ellipsis hanya muncul jika teks memang dibatasi.
  • Menulis ukuran font berbeda-beda secara manual di setiap halaman. Lebih baik pakai textTheme agar konsisten.
