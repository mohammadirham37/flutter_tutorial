StatefulWidget terdiri dari dua class: class widget (konfigurasi, tetap immutable) dan class State (tempat menyimpan data yang berubah). Untuk mengubah data dan memperbarui layar, kita memanggil setState().

Kerangka StatefulWidget

// Class 1: widget-nya. Hanya bertugas membuat objek State.
class Penghitung extends StatefulWidget {
  const Penghitung({super.key});

  @override
  State<Penghitung> createState() => _PenghitungState();
}

// Class 2: State-nya. Di sinilah data yang berubah disimpan.
class _PenghitungState extends State<Penghitung> {
  int _jumlah = 0; // data (state)

  @override
  Widget build(BuildContext context) {
    return Text('Jumlah: $_jumlah');
  }
}
Kerangka Penghitung menampilkan nilai awal 0

Tanda garis bawah (_) di depan nama berarti private: hanya bisa diakses dari file yang sama. Ini konvensi untuk class State.

Contoh lengkap: counter dengan tambah, kurang, dan reset

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      home: const HalamanCounter(),
    );
  }
}

class HalamanCounter extends StatefulWidget {
  const HalamanCounter({super.key});

  @override
  State<HalamanCounter> createState() => _HalamanCounterState();
}

class _HalamanCounterState extends State<HalamanCounter> {
  int _hadir = 0; // jumlah mahasiswa yang hadir

  void _tambah() {
    setState(() {
      _hadir++;
    });
  }

  void _kurang() {
    // Jangan sampai negatif
    if (_hadir == 0) return;
    setState(() {
      _hadir--;
    });
  }

  void _reset() {
    setState(() => _hadir = 0);
  }

  @override
  Widget build(BuildContext context) {
    // build dipanggil ulang setiap setState; print ini membuktikannya
    debugPrint('build() dipanggil, _hadir = $_hadir');

    return Scaffold(
      appBar: AppBar(title: const Text('Presensi Kelas')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            const Text('Mahasiswa hadir:', style: TextStyle(fontSize: 18)),
            Text(
              '$_hadir',
              style: TextStyle(
                fontSize: 72,
                fontWeight: FontWeight.bold,
                // Warna berubah sesuai state
                color: _hadir >= 10 ? Colors.green : Colors.orange,
              ),
            ),
            Text(_hadir >= 10 ? 'Kuorum tercapai' : 'Belum kuorum (min. 10)'),
            const SizedBox(height: 24),
            Row(
              mainAxisSize: MainAxisSize.min,
              children: [
                IconButton.filledTonal(
                  onPressed: _hadir == 0 ? null : _kurang, // null = tombol nonaktif
                  icon: const Icon(Icons.remove),
                ),
                const SizedBox(width: 16),
                IconButton.filled(
                  onPressed: _tambah,
                  icon: const Icon(Icons.add),
                ),
              ],
            ),
            const SizedBox(height: 16),
            TextButton.icon(
              onPressed: _reset,
              icon: const Icon(Icons.refresh),
              label: const Text('Reset'),
            ),
          ],
        ),
      ),
    );
  }
}
Counter presensi: tampilan awal, tombol kurang nonaktif
Setelah tombol tambah ditekan beberapa kali

Apa yang terjadi saat tombol + ditekan?

  1. Flutter memanggil _tambah().
  2. Di dalam setState, nilai _hadir bertambah 1.
  3. setState menandai widget ini sebagai "kotor" (dirty), artinya perlu digambar ulang.
  4. Pada frame berikutnya, Flutter memanggil ulang build(). Karena _hadir sudah berubah, Text menampilkan angka baru dan warnanya ikut menyesuaikan.

Buka tab Debug Console di VS Code: setiap kali tombol ditekan, baris build() dipanggil muncul.

Penjelasan kode

  • onPressed: null membuat tombol nonaktif (abu-abu). Kita memakainya saat nilai sudah 0.
  • setState(() => _hadir = 0) adalah bentuk singkat (arrow function) dari setState(() { _hadir = 0; }).
  • Logika yang tidak mengubah tampilan (seperti if (_hadir == 0) return;) boleh di luar setState.

Contoh kedua: toggle dan input teks

State tidak harus angka. Berikut contoh state bertipe bool dan String:

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(home: HalamanPengaturan()));
}

class HalamanPengaturan extends StatefulWidget {
  const HalamanPengaturan({super.key});

  @override
  State<HalamanPengaturan> createState() => _HalamanPengaturanState();
}

class _HalamanPengaturanState extends State<HalamanPengaturan> {
  bool _notifikasiAktif = true;
  String _nama = '';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pengaturan')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          SwitchListTile(
            title: const Text('Notifikasi jadwal kuliah'),
            subtitle: Text(_notifikasiAktif ? 'Aktif' : 'Nonaktif'),
            value: _notifikasiAktif,
            onChanged: (nilaiBaru) {
              setState(() => _notifikasiAktif = nilaiBaru);
            },
          ),
          const SizedBox(height: 16),
          TextField(
            decoration: const InputDecoration(
              labelText: 'Nama panggilan',
              border: OutlineInputBorder(),
            ),
            onChanged: (teks) {
              setState(() => _nama = teks);
            },
          ),
          const SizedBox(height: 16),
          Text(
            _nama.isEmpty ? 'Ketik nama di atas' : 'Halo, $_nama!',
            style: const TextStyle(fontSize: 22),
          ),
        ],
      ),
    );
  }
}
SwitchListTile dan TextField dengan state
Setelah nama diketik: teks sapaan langsung berubah

Setiap kali switch digeser atau huruf diketik, setState memperbarui variabel dan layar langsung menyesuaikan. Form dibahas lebih dalam di Modul 05.

⚠️ Kesalahan umum

  • Mengubah variabel tanpa setState. Nilainya berubah di memori, tetapi layar tidak diperbarui.
  • Menaruh variabel state di dalam build(). Contoh: int _hadir = 0; ditulis di dalam build. Nilainya kembali ke 0 setiap build. Variabel state harus menjadi field class State.
  • Memanggil setState di dalam build(). Ini memicu build tanpa henti dan error.
  • Menaruh state di class widget (yang extends StatefulWidget). Class widget harus immutable; state disimpan di class State.
