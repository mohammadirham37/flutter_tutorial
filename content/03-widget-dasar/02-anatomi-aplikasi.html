Hampir semua aplikasi Flutter yang kamu buat akan memakai tiga widget kerangka: MaterialApp (aplikasi), Scaffold (halaman), dan AppBar (bilah judul). Memahami peran ketiganya membuat kode lain jauh lebih mudah dibaca.

WidgetAnalogiTugas utama
MaterialAppGedung kampusMenyediakan tema, judul aplikasi, navigasi, bahasa, dan arah teks untuk seluruh halaman.
ScaffoldSatu ruang kelasKerangka satu halaman: tempat untuk appBar, body, floatingActionButton, drawer, dan bottomNavigationBar.
AppBarPapan nama di pintu kelasBilah di bagian atas berisi judul, tombol kembali, dan tombol aksi.

Contoh kecil: kerangka paling minimal

MaterialApp(
  home: Scaffold(
    appBar: AppBar(title: const Text('Beranda')),
    body: const Center(child: Text('Isi halaman')),
  ),
)
Kerangka minimal: MaterialApp + Scaffold + AppBar

Dari luar ke dalam: MaterialApp membungkus Scaffold lewat parameter home. Scaffold punya slot appBar dan body. Slot body adalah area utama di bawah AppBar.

Contoh lengkap: semua slot Scaffold

Kode berikut memperlihatkan slot-slot penting Scaffold sekaligus. Jalankan, lalu coba tekan ikon menu (garis tiga) dan tombol bulat di kanan bawah.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const AplikasiKampus());
}

class AplikasiKampus extends StatelessWidget {
  const AplikasiKampus({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Portal UNSOED', // nama aplikasi di task manager / tab browser
      debugShowCheckedModeBanner: false, // sembunyikan pita "DEBUG"
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const HalamanBeranda(),
    );
  }
}

class HalamanBeranda extends StatelessWidget {
  const HalamanBeranda({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // 1. AppBar: bilah judul di atas
      appBar: AppBar(
        title: const Text('Portal Mahasiswa'),
        centerTitle: true,
        actions: [
          IconButton(
            icon: const Icon(Icons.notifications_outlined),
            tooltip: 'Notifikasi',
            onPressed: () {},
          ),
          IconButton(
            icon: const Icon(Icons.search),
            tooltip: 'Cari',
            onPressed: () {},
          ),
        ],
      ),
      // 2. Drawer: menu samping. Ikon menu muncul otomatis di AppBar.
      drawer: Drawer(
        child: ListView(
          children: const [
            DrawerHeader(child: Text('Menu Utama', style: TextStyle(fontSize: 22))),
            ListTile(leading: Icon(Icons.home), title: Text('Beranda')),
            ListTile(leading: Icon(Icons.calendar_month), title: Text('Jadwal Kuliah')),
            ListTile(leading: Icon(Icons.logout), title: Text('Keluar')),
          ],
        ),
      ),
      // 3. Body: area utama halaman
      body: const Center(
        child: Text(
          'Selamat datang di Portal Mahasiswa',
          style: TextStyle(fontSize: 18),
        ),
      ),
      // 4. Tombol aksi melayang di kanan bawah
      floatingActionButton: FloatingActionButton(
        onPressed: () {},
        tooltip: 'Tambah',
        child: const Icon(Icons.add),
      ),
      // 5. Navigasi bawah (Material 3)
      bottomNavigationBar: NavigationBar(
        selectedIndex: 0,
        destinations: const [
          NavigationDestination(icon: Icon(Icons.home), label: 'Beranda'),
          NavigationDestination(icon: Icon(Icons.book), label: 'KRS'),
          NavigationDestination(icon: Icon(Icons.person), label: 'Profil'),
        ],
      ),
    );
  }
}
Semua slot Scaffold: AppBar, body, FAB, NavigationBar
Setelah ikon menu ditekan: Drawer terbuka

Penjelasan kode

  • runApp(const AplikasiKampus()) menjadikan AplikasiKampus sebagai akar aplikasi.
  • MaterialApp mengatur title, theme, dan halaman pertama lewat home. Kita memisahkan halaman ke class HalamanBeranda supaya rapi.
  • AppBar.actions menerima daftar widget (biasanya IconButton) yang tampil di sisi kanan.
  • Begitu drawer diisi, Scaffold otomatis menambahkan ikon menu di kiri AppBar.
  • NavigationBar adalah navigasi bawah gaya Material 3. Di sini indeksnya masih tetap 0; cara mengubahnya dengan setState dibahas di section StatefulWidget dan Modul 07.

Properti AppBar yang sering dipakai

PropertiFungsi
titleWidget judul, biasanya Text.
centerTitletrue agar judul di tengah (default Android: kiri, iOS: tengah).
leadingWidget di kiri judul (misalnya tombol kembali kustom).
actionsDaftar tombol di kanan.
backgroundColor / foregroundColorWarna latar dan warna teks/ikon AppBar.
bottomWidget di bawah AppBar, misalnya TabBar.

⚠️ Kesalahan umum

  • Membuat MaterialApp di setiap halaman. Cukup satu MaterialApp di akar aplikasi. Setiap halaman cukup memakai Scaffold.
  • Lupa Scaffold. Jika Text langsung ditaruh di home tanpa Scaffold, teks tampil dengan garis bawah kuning dan latar hitam karena tidak ada Material di atasnya.
  • Menaruh widget besar langsung di appBar. Slot appBar mengharapkan PreferredSizeWidget seperti AppBar, bukan Container biasa.
