Menguji manual seperti section 11 memakan waktu dan mudah terlewat. Dua file test berikut menjalankan pengecekan yang sama secara otomatis dalam beberapa detik: satu unit test untuk HiveService dan satu widget test untuk alur CRUD lewat UI.

1. Unit test HiveService

Buat file test/hive_service_test.dart:

📄 test/hive_service_test.dart

import 'dart:io';

import 'package:crud_mahasiswa/models/mahasiswa_adapter.dart';
import 'package:crud_mahasiswa/models/mahasiswa_model.dart';
import 'package:crud_mahasiswa/services/hive_service.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:hive_ce/hive_ce.dart';

void main() {
  late Directory dir;
  final service = HiveService();

  setUpAll(() async {
    dir = await Directory.systemTemp.createTemp('hive_test');
    Hive.init(dir.path);
    Hive.registerAdapter(MahasiswaAdapter());
    await Hive.openBox<Mahasiswa>(HiveService.boxName);
  });

  tearDownAll(() async {
    await Hive.deleteFromDisk();
    await dir.delete(recursive: true);
  });

  final budi = Mahasiswa(
      id: '1', nim: '220101001', nama: 'Budi', prodi: 'Informatika', semester: 5);

  test('CREATE & READ', () async {
    await service.create(budi);
    final all = service.getAll();
    expect(all.length, 1);
    expect(all.first.nama, 'Budi');
    expect(all.first.semester, 5);
  });

  test('UPDATE', () async {
    await service.update(budi.copyWith(nama: 'Budi Santoso', semester: 6));
    final all = service.getAll();
    expect(all.length, 1);
    expect(all.first.nama, 'Budi Santoso');
    expect(all.first.semester, 6);
  });

  test('Data tetap ada setelah box ditutup & dibuka lagi', () async {
    await Hive.box<Mahasiswa>(HiveService.boxName).close();
    await Hive.openBox<Mahasiswa>(HiveService.boxName);
    expect(service.getAll().first.nama, 'Budi Santoso');
  });

  test('DELETE', () async {
    await service.delete('1');
    expect(service.getAll(), isEmpty);
  });
}
  • Hive.init(dir.path), bukan Hive.initFlutter(). Saat test, tidak ada HP/emulator sehingga folder penyimpanan dibuat sendiri di folder sementara (Directory.systemTemp.createTemp). Data test tidak tercampur dengan data aplikasi.
  • setUpAll berjalan sekali sebelum semua test: menyiapkan Hive, mendaftarkan adapter, dan membuka box.
  • tearDownAll berjalan sekali setelah semua test: menghapus file box dan folder sementara.
  • Keempat test berjalan berurutan dan saling melanjutkan: CREATE menambah Budi, UPDATE mengubahnya, test ketiga menutup lalu membuka ulang box untuk membuktikan data benar-benar tertulis di file (mirip aplikasi ditutup lalu dibuka), dan DELETE menghapusnya.

2. Widget test alur CRUD

Buat file test/crud_flow_test.dart:

📄 test/crud_flow_test.dart

import 'dart:io';

import 'package:crud_mahasiswa/main.dart';
import 'package:crud_mahasiswa/models/mahasiswa_adapter.dart';
import 'package:crud_mahasiswa/models/mahasiswa_model.dart';
import 'package:crud_mahasiswa/services/hive_service.dart';
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';
import 'package:hive_ce/hive_ce.dart';

/// Tap tombol lalu beri waktu nyata agar operasi IO Hive selesai.
Future<void> tapDanTunggu(WidgetTester tester, Finder f) async {
  await tester.tap(f);
  for (var i = 0; i < 5; i++) {
    await tester.pump(const Duration(milliseconds: 300));
    await tester.runAsync(
        () => Future.delayed(const Duration(milliseconds: 100)));
  }
}

void main() {
  testWidgets('Alur CRUD lewat UI', (tester) async {
    await tester.runAsync(() async {
      final dir = await Directory.systemTemp.createTemp('hive_ui');
      Hive.init(dir.path);
      Hive.registerAdapter(MahasiswaAdapter());
      await Hive.openBox<Mahasiswa>(HiveService.boxName);
    });

    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();
    expect(find.text('Belum ada data mahasiswa'), findsOneWidget);

    // CREATE
    await tester.tap(find.text('Tambah'));
    await tester.pumpAndSettle();
    await tester.enterText(find.widgetWithText(TextFormField, 'NIM'), '22010100');
    await tester.enterText(find.widgetWithText(TextFormField, 'Nama Lengkap'), 'Siti');
    await tester.enterText(find.widgetWithText(TextFormField, 'Semester'), '3');
    await tapDanTunggu(tester, find.text('Simpan'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Siti'), findsOneWidget);

    // UPDATE
    await tester.tap(find.byIcon(Icons.edit));
    await tester.pumpAndSettle();
    await tester.enterText(find.widgetWithText(TextFormField, 'Nama Lengkap'), 'Siti Aminah');
    await tapDanTunggu(tester, find.text('Perbarui'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Siti Aminah'), findsOneWidget);

    // DELETE
    await tester.tap(find.byIcon(Icons.delete));
    await tester.pumpAndSettle();
    await tapDanTunggu(tester, find.text('Hapus'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Belum ada data mahasiswa'), findsOneWidget);
    Get.reset();
  });
}
  • Test ini menjalankan MyApp sungguhan, lalu "menekan tombol" dan "mengetik" seperti pengguna: tambah Siti, ubah menjadi Siti Aminah, lalu hapus.
  • tester.runAsync: widget test berjalan dengan jam palsu (fake async), sedangkan Hive membaca/menulis file sungguhan. Operasi file harus dibungkus runAsync agar benar-benar dijalankan. Helper tapDanTunggu memberi sedikit waktu nyata setelah tombol yang memicu penulisan ke Hive ditekan.
  • pumpAndSettle(const Duration(seconds: 4)) menunggu animasi pindah halaman dan snackbar selesai.
  • find.widgetWithText(TextFormField, 'NIM') mencari field berdasarkan label-nya.
  • Get.reset() di akhir membersihkan semua controller GetX agar tidak terbawa ke test lain.
