Di modul ini kita membangun satu aplikasi utuh dari proyek kosong: CRUD Data Mahasiswa. Data disimpan di Hive (database lokal, jalan tanpa internet), state dan navigasi diatur oleh GetX, dan kodenya disusun dengan pola MVC (Model, View, Controller). Setiap file ditulis lengkap, jadi Anda bisa menyalinnya satu per satu lalu langsung menjalankannya.

Apa itu MVC di proyek ini?

MVC membagi kode menjadi tiga peran supaya setiap file punya satu tugas yang jelas:

  • Model (M): bentuk data dan cara menyimpannya. Di sini: class Mahasiswa, MahasiswaAdapter (cara Hive mengubah objek menjadi byte), dan HiveService (satu-satunya kelas yang menyentuh database).
  • View (V): tampilan. Di sini: MahasiswaListView dan MahasiswaFormView. View hanya menampilkan data dan meneruskan klik ke controller. View tidak pernah memanggil Hive.
  • Controller (C): otak aplikasi. MahasiswaController menyimpan state reaktif (.obs), memvalidasi input, dan memanggil HiveService untuk tambah, ubah, dan hapus.

Dua bagian pendukung dari GetX: Routes (daftar nama halaman) dan Binding (tempat mendaftarkan controller sebelum halaman dibuka).

Alur data (arah panah satu jalur)

┌──────────────────────────────┐
│ VIEW                         │  MahasiswaListView, MahasiswaFormView
│ Obx(() => ...) membaca state │  tombol memanggil controller.save(), dst.
└──────────────┬───────────────┘
               │ memanggil method
               ▼
┌──────────────────────────────┐
│ CONTROLLER                   │  MahasiswaController (GetxController)
│ mahasiswaList.obs, keyword   │  validasi, navigasi, snackbar, dialog
└──────────────┬───────────────┘
               │ create / getAll / update / delete
               ▼
┌──────────────────────────────┐
│ MODEL                        │  HiveService  ──►  Box<Mahasiswa> 'mahasiswa_box'
│                              │  Mahasiswa + MahasiswaAdapter (typeId 0)
└──────────────────────────────┘

Contoh saat pengguna menekan Simpan:

  1. View memanggil controller.save().
  2. Controller memvalidasi form, membuat objek Mahasiswa, lalu memanggil _service.create(mhs).
  3. HiveService menulis objek ke box. MahasiswaAdapter mengubahnya menjadi byte di file.
  4. Controller memanggil loadData() yang mengisi ulang mahasiswaList (sebuah RxList).
  5. Karena mahasiswaList berubah, Obx di halaman daftar otomatis membangun ulang tampilannya. Tidak ada setState sama sekali.

💡 Cara mengikuti modul ini

Kerjakan section 2 sampai 10 berurutan, dari lapisan paling bawah (model) ke paling atas (view dan main.dart). Dengan urutan ini setiap file yang Anda tulis hanya bergantung pada file yang sudah ada. Garis merah di editor yang muncul karena file belum dibuat akan hilang sendiri setelah file tersebut ditulis. Jika ingin langsung jadi, buka section 13 (Listing Lengkap) dan salin semua file sekaligus.
