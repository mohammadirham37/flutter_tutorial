Langkah pertama: membuat proyek Flutter baru, memasang tiga package, lalu menyiapkan folder MVC.

1. Buat proyek

Buka terminal di folder tempat Anda menyimpan proyek, lalu jalankan:

flutter create crud_mahasiswa
cd crud_mahasiswa

⚠️ Nama proyek harus crud_mahasiswa

File test di section 12 mengimpor package:crud_mahasiswa/.... Nama package diambil dari nama proyek, jadi jika Anda memakai nama lain, ganti juga bagian import di file test.

2. Pasang package

flutter pub add get hive_ce hive_ce_flutter
PackageKegunaan di proyek ini
getState reaktif (.obs, Obx), dependency injection (Bindings, GetView), named route, snackbar, dan dialog
hive_ceDatabase NoSQL lokal: Box, TypeAdapter, put, delete
hive_ce_flutterHive.initFlutter() yang otomatis memilih folder penyimpanan di HP

Setelah perintah di atas, bagian dependencies di pubspec.yaml kira-kira menjadi seperti ini (nomor versi di laptop Anda boleh lebih baru):

📄 pubspec.yaml (bagian dependencies)

dependencies:
  flutter:
    sdk: flutter

  cupertino_icons: ^1.0.8
  get: ^4.7.3
  hive_ce: ^2.23.3
  hive_ce_flutter: ^2.5.0

ℹ️ Kenapa hive_ce, bukan hive?

Package hive versi 2.x sudah tidak dirawat lagi oleh pembuatnya. hive_ce (Community Edition) adalah lanjutannya dengan API yang sama persis, seperti dibahas di Modul 11. Jika di laboratorium Anda terpaksa memakai hive + hive_flutter lama, kode di modul ini tetap berjalan. Cukup ganti baris import di main.dart, mahasiswa_adapter.dart, hive_service.dart, dan kedua file test:

// Versi modul ini (hive_ce)
import 'package:hive_ce/hive_ce.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

// Versi package lama (hive)
import 'package:hive/hive.dart';
import 'package:hive_flutter/hive_flutter.dart';

3. Siapkan folder MVC dan hapus test bawaan

# macOS / Linux / Git Bash
mkdir -p lib/models lib/services lib/controllers lib/bindings lib/routes lib/views
rm test/widget_test.dart

# Windows PowerShell
mkdir lib/models, lib/services, lib/controllers, lib/bindings, lib/routes, lib/views
Remove-Item test/widget_test.dart

File test/widget_test.dart bawaan menguji aplikasi counter. Karena aplikasi counter akan kita ganti, test itu pasti gagal, jadi kita hapus. Test baru ditulis di section 12.

Isi lib/main.dart biarkan dulu. Kita menggantinya di section 10 setelah semua file lain siap.

💡 Cek cepat

Jalankan flutter pub get lalu pastikan tidak ada pesan error. Jika muncul version solving failed, jalankan flutter upgrade agar SDK Flutter Anda versi stabil terbaru, lalu ulangi flutter pub add.
