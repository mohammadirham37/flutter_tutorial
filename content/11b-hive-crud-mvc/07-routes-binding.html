Sebelum membuat View, kita siapkan dua hal dari GetX: Routes (alamat setiap halaman) dan Binding (siapa yang membuat controller). Dengan keduanya, View tidak perlu membuat controller sendiri dan navigasi cukup memakai nama, misalnya Get.toNamed('/form').

1. Nama route

Buat file lib/routes/app_routes.dart:

📄 lib/routes/app_routes.dart

/// Daftar nama route aplikasi.
abstract class AppRoutes {
  static const home = '/';
  static const form = '/form';
}

Nama route ditulis sebagai konstanta agar tidak salah ketik. Menulis Get.toNamed(AppRoutes.form) akan dicek oleh compiler, sedangkan Get.toNamed('/from') (salah ketik) baru ketahuan saat aplikasi berjalan. abstract class dipakai agar class ini tidak bisa dibuat objeknya; ia hanya wadah konstanta.

2. Binding

Buat file lib/bindings/mahasiswa_binding.dart:

📄 lib/bindings/mahasiswa_binding.dart

import 'package:get/get.dart';

import '../controllers/mahasiswa_controller.dart';

/// Binding: mendaftarkan dependency (controller) ke GetX
/// sebelum halaman dibuka.
class MahasiswaBinding extends Bindings {
  @override
  void dependencies() {
    Get.lazyPut<MahasiswaController>(() => MahasiswaController());
  }
}
  • dependencies() dipanggil GetX tepat sebelum halaman yang memakai binding ini dibuka.
  • Get.lazyPut mendaftarkan "resep" pembuat controller. Controller baru benar-benar dibuat saat pertama kali dicari dengan Get.find (atau lewat properti controller milik GetView). Sesudah itu, objek yang sama dipakai di mana pun.

3. Pemetaan route ke halaman

Buat file lib/routes/app_pages.dart:

📄 lib/routes/app_pages.dart

import 'package:get/get.dart';

import '../bindings/mahasiswa_binding.dart';
import '../views/mahasiswa_form_view.dart';
import '../views/mahasiswa_list_view.dart';
import 'app_routes.dart';

/// Pemetaan route -> halaman (+ binding).
class AppPages {
  static final pages = [
    GetPage(
      name: AppRoutes.home,
      page: () => const MahasiswaListView(),
      binding: MahasiswaBinding(),
    ),
    GetPage(
      name: AppRoutes.form,
      page: () => const MahasiswaFormView(),
    ),
  ];
}

Setiap GetPage menghubungkan nama route dengan widget halaman. Hal penting yang perlu diperhatikan:

  • Binding hanya dipasang di route home. Halaman form tidak memerlukan binding sendiri karena selalu dibuka dari halaman daftar, sehingga MahasiswaController sudah ada di memori. Halaman form memakai controller yang sama dengan halaman daftar, dan inilah yang membuat data form (yang diisi di openEditForm) langsung terbaca di halaman form.
  • Controller milik route home tetap hidup selama halaman daftar masih ada di tumpukan navigasi. Karena halaman daftar adalah halaman pertama, controller hidup sepanjang aplikasi berjalan.

⚠️ Garis merah di app_pages.dart

File ini mengimpor mahasiswa_list_view.dart dan mahasiswa_form_view.dart yang belum dibuat, sehingga editor menampilkan error. Ini normal. Error akan hilang setelah kedua View dibuat di section 8 dan 9.
