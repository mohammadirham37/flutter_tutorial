Halaman kedua adalah form yang dipakai untuk Create sekaligus Update. Mode form ditentukan oleh controller.isEdit yang sudah diatur sebelum halaman dibuka.

Buat file lib/views/mahasiswa_form_view.dart:

📄 lib/views/mahasiswa_form_view.dart

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:get/get.dart';

import '../controllers/mahasiswa_controller.dart';

/// VIEW: halaman form untuk CREATE dan UPDATE.
class MahasiswaFormView extends GetView<MahasiswaController> {
  const MahasiswaFormView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(controller.isEdit ? 'Edit Mahasiswa' : 'Tambah Mahasiswa'),
      ),
      body: Form(
        key: controller.formKey,
        // pesan error diperbarui otomatis saat user mengetik
        autovalidateMode: AutovalidateMode.onUserInteraction,
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            TextFormField(
              controller: controller.nimC,
              keyboardType: TextInputType.number,
              inputFormatters: [FilteringTextInputFormatter.digitsOnly],
              validator: controller.validateNim,
              decoration: const InputDecoration(
                labelText: 'NIM',
                prefixIcon: Icon(Icons.badge),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            TextFormField(
              controller: controller.namaC,
              textCapitalization: TextCapitalization.words,
              validator: controller.validateNama,
              decoration: const InputDecoration(
                labelText: 'Nama Lengkap',
                prefixIcon: Icon(Icons.person),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            DropdownButtonFormField<String>(
              initialValue: controller.selectedProdi.value,
              items: controller.daftarProdi
                  .map((p) => DropdownMenuItem(value: p, child: Text(p)))
                  .toList(),
              onChanged: (v) {
                if (v != null) controller.selectedProdi.value = v;
              },
              decoration: const InputDecoration(
                labelText: 'Program Studi',
                prefixIcon: Icon(Icons.school),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            TextFormField(
              controller: controller.semesterC,
              keyboardType: TextInputType.number,
              inputFormatters: [FilteringTextInputFormatter.digitsOnly],
              validator: controller.validateSemester,
              decoration: const InputDecoration(
                labelText: 'Semester',
                prefixIcon: Icon(Icons.calendar_month),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 24),
            FilledButton.icon(
              onPressed: controller.save,
              icon: const Icon(Icons.save),
              label: Text(controller.isEdit ? 'Perbarui' : 'Simpan'),
              style: FilledButton.styleFrom(
                padding: const EdgeInsets.symmetric(vertical: 16),
              ),
            ),
          ],
        ),
      ),
    );
  }
}

Penjelasan kode

  • Judul dan label tombol dinamis: controller.isEdit ? 'Edit Mahasiswa' : 'Tambah Mahasiswa'. Tidak perlu Obx karena nilainya sudah pasti saat halaman dibangun dan tidak berubah selama form terbuka.
  • Form(key: controller.formKey) mengelompokkan semua field sehingga validate() di controller bisa memeriksa semuanya sekaligus.
  • autovalidateMode: AutovalidateMode.onUserInteraction: setelah pengguna menyentuh sebuah field, pesan error diperbarui setiap kali ia mengetik. Pesan merah langsung hilang begitu input sudah benar.
  • controller: controller.nimC: isi field disimpan di TextEditingController milik controller. Inilah yang membuat form mode edit langsung terisi.
  • keyboardType: TextInputType.number menampilkan keyboard angka, dan FilteringTextInputFormatter.digitsOnly (dari package:flutter/services.dart) menolak karakter selain angka, misalnya jika pengguna menempel teks.
  • textCapitalization: TextCapitalization.words membuat huruf pertama setiap kata otomatis kapital di keyboard.
  • validator: controller.validateNim: fungsi validasi diambil dari controller (tear-off), sehingga aturan validasi ada di satu tempat.
  • DropdownButtonFormField: initialValue diambil dari selectedProdi (saat edit berisi prodi lama). Saat pengguna memilih, onChanged menulis ke controller.selectedProdi.value, yang nanti dibaca save().
  • FilledButton.icon(onPressed: controller.save) menjalankan validasi lalu simpan.

ℹ️ initialValue pada dropdown

Di Flutter versi terbaru, parameter value pada DropdownButtonFormField sudah ditandai deprecated dan diganti initialValue. Jika Flutter di laptop Anda versi lama dan muncul error No named parameter with the name 'initialValue', jalankan flutter upgrade, atau untuk sementara ganti initialValue: menjadi value:.
