Semua bagian sudah siap. File terakhir, main.dart, menyalakan Hive lalu menjalankan aplikasi dengan GetMaterialApp.

Hapus seluruh isi lib/main.dart bawaan, lalu ganti dengan:

📄 lib/main.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import 'models/mahasiswa_adapter.dart';
import 'models/mahasiswa_model.dart';
import 'routes/app_pages.dart';
import 'routes/app_routes.dart';
import 'services/hive_service.dart';

Future<void> main() async {
  // 1. Pastikan binding Flutter siap sebelum memanggil kode async
  WidgetsFlutterBinding.ensureInitialized();

  // 2. Inisialisasi Hive (menentukan folder penyimpanan otomatis)
  await Hive.initFlutter();

  // 3. Daftarkan adapter untuk class Mahasiswa
  Hive.registerAdapter(MahasiswaAdapter());

  // 4. Buka box (seperti membuka "tabel")
  await Hive.openBox<Mahasiswa>(HiveService.boxName);

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'CRUD Mahasiswa',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorSchemeSeed: Colors.indigo,
        useMaterial3: true,
      ),
      initialRoute: AppRoutes.home,
      getPages: AppPages.pages,
    );
  }
}

Empat langkah wajib sebelum runApp

  1. WidgetsFlutterBinding.ensureInitialized(): main() kita bersifat async dan memanggil plugin (Hive butuh lokasi folder dari sistem operasi). Baris ini memastikan "jembatan" Flutter ke sistem operasi sudah siap sebelum plugin dipakai.
  2. await Hive.initFlutter(): menentukan folder penyimpanan file box di HP secara otomatis.
  3. Hive.registerAdapter(MahasiswaAdapter()): memperkenalkan adapter ke Hive. Harus dilakukan sebelum membuka box yang berisi Mahasiswa, karena saat dibuka Hive langsung membaca isi file dan butuh adapter untuk menerjemahkannya.
  4. await Hive.openBox<Mahasiswa>(HiveService.boxName): membuka box (mirip membuka tabel). Setelah ini, Hive.box() di HiveService bisa dipakai secara sinkron di mana saja.

Jika urutan ini salah, Anda akan melihat error seperti di section 14.

GetMaterialApp

  • GetMaterialApp menggantikan MaterialApp agar fitur GetX (named route, Get.snackbar, Get.dialog, Get.key) bisa dipakai tanpa BuildContext.
  • initialRoute: AppRoutes.home membuka halaman daftar pertama kali, dan saat itu MahasiswaBinding dijalankan sehingga MahasiswaController dibuat dan onInit() memuat data dari box.
  • getPages: AppPages.pages adalah daftar semua route dari section 7.
  • colorSchemeSeed: Colors.indigo membuat seluruh warna tema Material 3 dari satu warna dasar.
