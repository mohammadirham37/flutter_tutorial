Sekarang lapisan paling atas: View. Halaman pertama adalah daftar mahasiswa. Halaman ini menangani Read (menampilkan data), pencarian, serta tombol menuju Create, Update, dan Delete.

Buat file lib/views/mahasiswa_list_view.dart:

📄 lib/views/mahasiswa_list_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/mahasiswa_controller.dart';

/// VIEW: halaman daftar mahasiswa (READ + tombol Edit/Hapus).
/// `GetView<T>` otomatis menyediakan properti `controller`.
class MahasiswaListView extends GetView<MahasiswaController> {
  const MahasiswaListView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Data Mahasiswa'),
        centerTitle: true,
      ),
      body: Column(
        children: [
          // ---------- Kolom pencarian ----------
          Padding(
            padding: const EdgeInsets.all(12),
            child: TextField(
              onChanged: (v) => controller.keyword.value = v,
              decoration: const InputDecoration(
                hintText: 'Cari nama atau NIM...',
                prefixIcon: Icon(Icons.search),
                border: OutlineInputBorder(),
              ),
            ),
          ),

          // ---------- Daftar data (reaktif) ----------
          Expanded(
            child: Obx(() {
              final data = controller.filteredList;

              if (data.isEmpty) {
                return const Center(
                  child: Text('Belum ada data mahasiswa'),
                );
              }

              return ListView.builder(
                padding: const EdgeInsets.only(bottom: 80),
                itemCount: data.length,
                itemBuilder: (context, index) {
                  final mhs = data[index];
                  return Card(
                    margin: const EdgeInsets.symmetric(
                        horizontal: 12, vertical: 6),
                    child: ListTile(
                      leading: CircleAvatar(
                        child: Text(mhs.nama[0].toUpperCase()),
                      ),
                      title: Text(mhs.nama),
                      subtitle: Text(
                          'NIM ${mhs.nim}\n${mhs.prodi} • Smt ${mhs.semester}'),
                      isThreeLine: true,
                      trailing: Row(
                        mainAxisSize: MainAxisSize.min,
                        children: [
                          IconButton(
                            visualDensity: VisualDensity.compact,
                            icon: const Icon(Icons.edit, color: Colors.orange),
                            onPressed: () => controller.openEditForm(mhs),
                          ),
                          IconButton(
                            visualDensity: VisualDensity.compact,
                            icon: const Icon(Icons.delete, color: Colors.red),
                            onPressed: () => controller.confirmDelete(mhs),
                          ),
                        ],
                      ),
                    ),
                  );
                },
              );
            }),
          ),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: controller.openAddForm,
        icon: const Icon(Icons.add),
        label: const Text('Tambah'),
      ),
    );
  }
}

Penjelasan kode

  • GetView<MahasiswaController> adalah StatelessWidget yang sudah punya properti controller. Di belakang layar properti ini memanggil Get.find<MahasiswaController>(), yaitu controller yang didaftarkan MahasiswaBinding. Kita tidak memerlukan StatefulWidget sama sekali.
  • Kolom pencarian: setiap huruf yang diketik dikirim ke controller.keyword.value. Kolom ini tidak perlu dibungkus Obx karena ia tidak menampilkan state apa pun.
  • Obx(() { ... }) hanya membungkus bagian yang berubah, yaitu daftar data. Di dalamnya controller.filteredList dibaca, sehingga Obx otomatis "berlangganan" ke keyword dan mahasiswaList. AppBar, kolom cari, dan tombol Tambah tidak ikut dibangun ulang.
  • Empty state: jika daftar kosong (belum ada data atau pencarian tidak menemukan hasil), tampil teks Belum ada data mahasiswa di tengah layar.
  • ListView.builder membuat kartu hanya untuk item yang terlihat di layar (Modul 06). padding bottom: 80 memberi ruang agar kartu terakhir tidak tertutup tombol Tambah.
  • Isi kartu: CircleAvatar berisi huruf pertama nama, subtitle dua baris (NIM, lalu prodi dan semester) dengan isThreeLine: true agar tinggi kartu cukup.
  • Tombol aksi: ikon pensil memanggil controller.openEditForm(mhs), ikon tempat sampah memanggil controller.confirmDelete(mhs), dan tombol Tambah memanggil controller.openAddForm. View hanya meneruskan klik; semua keputusan ada di controller.

💡 onPressed: controller.openAddForm vs onPressed: () => controller.openEditForm(mhs)

Jika method tidak butuh argumen, kita bisa langsung memberikan method-nya (tear-off) tanpa tanda kurung. Jika butuh argumen seperti mhs, bungkus dengan fungsi anonim () => .... Kesalahan umum adalah menulis onPressed: controller.openAddForm() (dengan kurung), yang membuat method langsung dijalankan saat build, bukan saat tombol ditekan.
