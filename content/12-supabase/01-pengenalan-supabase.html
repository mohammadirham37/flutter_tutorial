Sampai Modul 11, semua data aplikasi kita tersimpan di HP (SharedPreferences, SQLite, Hive). Data itu hilang kalau aplikasi di-uninstall dan tidak bisa dibuka dari HP lain. Untuk aplikasi sungguhan kita butuh backend: server yang menyimpan data di cloud dan mengatur siapa boleh mengakses apa.

Apa itu Backend as a Service (BaaS)?

Membuat backend sendiri berarti menyewa server, memasang database, menulis REST API (seperti yang kita konsumsi di Modul 09), membuat sistem login, mengurus keamanan, dan seterusnya. BaaS menyediakan semua itu dalam bentuk siap pakai. Kita cukup membuat tabel lewat dashboard, lalu memanggilnya dari Flutter dengan library resmi.

Supabase adalah BaaS open source yang dibangun di atas database PostgreSQL. Karena memakai PostgreSQL, semua yang Anda pelajari di mata kuliah Basis Data (tabel, relasi, primary key, foreign key, SQL) langsung terpakai.

Fitur utama Supabase

FiturFungsiDipakai di modul

Kita tidak menulis URL endpoint satu per satu seperti di Modul 09. Cukup panggil supabase.from('tabel').select(). Library-lah yang mengubahnya menjadi request HTTP, menyertakan token login, lalu mengembalikan JSON yang sudah di-decode.

Supabase vs Firebase

Firebase (Google) adalah BaaS paling populer di dunia Flutter. Keduanya bagus. Perbedaan utamanya:

AspekSupabaseFirebase
Jenis databaseRelasional (PostgreSQL), memakai SQLNoSQL dokumen (Cloud Firestore)
Relasi antar dataForeign key dan JOIN bawaanDenormalisasi manual
Aturan keamananRow Level Security (policy SQL)Security Rules (bahasa khusus)
Open source / self-hostYa, bisa dipasang di server sendiriTidak
Setup di FlutterCukup URL + key, tanpa file konfigurasi nativePerlu FlutterFire CLI dan file konfigurasi per platform
Paket gratisAda (project bisa di-pause otomatis bila lama tidak aktif)Ada (Spark plan)
Cocok untukData terstruktur, mahasiswa yang sudah belajar SQLData fleksibel, ekosistem Google

ℹ️ Kenapa kita memilih Supabase?

Kurikulum Informatika sudah membekali Anda dengan SQL dan desain basis data relasional. Dengan Supabase, ilmu itu langsung terpakai, dan konsep keamanan per baris (RLS) adalah praktik yang juga dipakai di dunia industri.
