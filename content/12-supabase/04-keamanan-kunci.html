Menulis URL dan key langsung di kode (hard-code) memang praktis, tetapi berisiko: begitu kode di-push ke GitHub publik, siapa pun bisa melihat dan memakai project Anda. Di section ini kita belajar memisahkan konfigurasi dari kode.

Aturan emas

  1. Jangan pernah memasukkan secret key (sb_secret_...) atau service_role ke aplikasi Flutter. Semua isi APK bisa dibongkar (decompile), dan kunci itu melewati seluruh RLS, sehingga pemegangnya bisa membaca dan menghapus data semua user.
  2. Publishable key memang boleh ada di aplikasi. Yang melindungi data adalah RLS, bukan kerahasiaan publishable key.
  3. Meskipun publishable key tidak rahasia, tetap simpan di file konfigurasi terpisah yang tidak di-commit. Dengan begitu setiap anggota tim bisa memakai project masing-masing tanpa mengubah kode, dan repo tidak menjadi sasaran penyalahgunaan kuota.

Cara 1: --dart-define

Flutter bisa "menyuntikkan" nilai konstanta saat build. Nilai itu dibaca dengan String.fromEnvironment:

📄 lib/config/env.dart

// lib/config/env.dart
class Env {
  // Nilai diisi saat build oleh --dart-define / --dart-define-from-file.
  static const String supabaseUrl = String.fromEnvironment('SUPABASE_URL');
  static const String supabasePublishableKey = String.fromEnvironment(
    'SUPABASE_PUBLISHABLE_KEY',
  );

  static bool get isConfigured =>
      supabaseUrl.isNotEmpty && supabasePublishableKey.isNotEmpty;
}

Jalankan dengan:

flutter run \
  --dart-define=SUPABASE_URL=https://abcdefghijklm.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxxxxxxxxx
  • String.fromEnvironment harus dipakai sebagai const. Nilainya ditentukan saat kompilasi, bukan saat aplikasi berjalan.
  • Jika lupa memberi --dart-define, nilainya string kosong ''. Karena itu kita sediakan isConfigured untuk menampilkan pesan yang jelas.

Cara 2 (disarankan): --dart-define-from-file

Mengetik dua define setiap kali menjalankan aplikasi cukup merepotkan. Simpan saja di file JSON di root proyek (sejajar pubspec.yaml):

📄 env.json

{
  "SUPABASE_URL": "https://abcdefghijklm.supabase.co",
  "SUPABASE_PUBLISHABLE_KEY": "sb_publishable_xxxxxxxxxxxxxxxxxxxx"
}

flutter run --dart-define-from-file=env.json

Lalu cegah file itu ikut ter-commit dengan menambahkan baris berikut ke .gitignore, dan sediakan contoh tanpa isi untuk teman satu tim:

📄 .gitignore

# Konfigurasi rahasia/pribadi
env.json

📄 env.example.json

{
  "SUPABASE_URL": "https://YOUR-PROJECT-REF.supabase.co",
  "SUPABASE_PUBLISHABLE_KEY": "sb_publishable_YOUR_KEY"
}

Agar tombol Run di VS Code ikut membaca env.json

Buat file .vscode/launch.json:

📄 .vscode/launch.json

{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "catatan_kuliah",
      "request": "launch",
      "type": "dart",
      "args": ["--dart-define-from-file=env.json"]
    }
  ]
}

Di Android Studio: Run → Edit Configurations → isi Additional run args dengan --dart-define-from-file=env.json.

Inisialisasi memakai Env

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabasePublishableKey,
  );

  runApp(const MyApp());
}

⚠️ Sudah terlanjur push key ke GitHub?

Hapus dari repo saja tidak cukup karena riwayat commit masih menyimpannya. Buka Project Settings → API Keys, buat kunci baru, lalu hapus (revoke) kunci lama. Hal ini wajib dilakukan segera jika yang bocor adalah secret key.
