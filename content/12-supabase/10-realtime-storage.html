Dua fitur tambahan ini tidak wajib untuk proyek Modul 13–14, tetapi sering diminta di tugas besar: data yang berubah live (Realtime) dan unggah file (Storage).

Realtime: data yang otomatis ter-update

Langkah 1: aktifkan Realtime untuk tabel. Caranya bisa lewat Table Editor → pilih tabel → aktifkan Enable Realtime, atau lewat SQL:

alter publication supabase_realtime add table public.mata_kuliah;

Langkah 2: ganti select() dengan stream(primaryKey: [...]), dan FutureBuilder dengan StreamBuilder:

📄 lib/main.dart

// lib/main.dart — contoh Realtime: daftar mata kuliah yang otomatis
// berubah ketika tabel diubah dari dashboard atau perangkat lain.
// Jalankan: flutter run --dart-define-from-file=env.json
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

const supabaseUrl = String.fromEnvironment('SUPABASE_URL');
const supabaseKey = String.fromEnvironment('SUPABASE_PUBLISHABLE_KEY');

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Supabase.initialize(url: supabaseUrl, publishableKey: supabaseKey);
  runApp(
    const MaterialApp(debugShowCheckedModeBanner: false, home: RealtimePage()),
  );
}

class RealtimePage extends StatefulWidget {
  const RealtimePage({super.key});

  @override
  State<RealtimePage> createState() => _RealtimePageState();
}

class _RealtimePageState extends State<RealtimePage> {
  // Stream disimpan di State: JANGAN dibuat di dalam build().
  final Stream<List<Map<String, dynamic>>> _stream = Supabase.instance.client
      .from('mata_kuliah')
      .stream(primaryKey: ['id'])
      .order('kode');

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Mata Kuliah (Realtime)')),
      body: StreamBuilder<List<Map<String, dynamic>>>(
        stream: _stream,
        builder: (context, snapshot) {
          if (snapshot.hasError) {
            return Center(child: Text('Error: ${snapshot.error}'));
          }
          if (!snapshot.hasData) {
            return const Center(child: CircularProgressIndicator());
          }
          final rows = snapshot.data!;
          return ListView.builder(
            itemCount: rows.length,
            itemBuilder: (context, index) {
              final row = rows[index];
              return ListTile(
                leading: const Icon(Icons.bolt),
                title: Text(row['nama'] as String),
                subtitle: Text('${row['kode']} • semester ${row['semester']}'),
              );
            },
          );
        },
      ),
    );
  }
}
StreamBuilder + stream(): data awal dari Supabase, lalu ikut berubah saat tabel diubah
  • stream(primaryKey: ['id']) mula-mula memancarkan seluruh data, lalu memancarkan list baru setiap kali ada INSERT/UPDATE/DELETE. primaryKey dipakai untuk mencocokkan baris yang berubah.
  • Stream disimpan sebagai field State. Membuatnya di dalam build() akan membuka koneksi baru di setiap rebuild.
  • RLS tetap berlaku: user hanya menerima perubahan baris yang boleh ia lihat.
  • Coba buka Table Editor, ubah nama satu mata kuliah, lalu lihat aplikasi berubah sendiri tanpa refresh.

ℹ️ Kapan memakai realtime?

Chat, papan skor, status pesanan, kolaborasi. Untuk daftar yang jarang berubah (seperti catatan pribadi), select() biasa plus pull-to-refresh sudah cukup dan lebih hemat kuota koneksi.

Storage: menyimpan file

  1. Buka Storage → New bucket, beri nama avatars. Centang Public bucket agar file bisa dibuka lewat URL.
  2. Storage juga dilindungi RLS. Buat policy agar user hanya boleh mengunggah ke foldernya sendiri:
create policy "User mengunggah ke foldernya sendiri"
on storage.objects for insert to authenticated
with check (
  bucket_id = 'avatars'
  and (storage.foldername(name))[1] = (select auth.uid())::text
);

create policy "User menimpa file di foldernya sendiri"
on storage.objects for update to authenticated
using (
  bucket_id = 'avatars'
  and (storage.foldername(name))[1] = (select auth.uid())::text
);

Kode unggah (byte gambar bisa didapat dari package seperti image_picker dengan await file.readAsBytes()):

Future<String> unggahFoto(Uint8List bytes) async {
  final userId = supabase.auth.currentUser!.id;
  // Simpan di folder milik user: avatars/<userId>/foto.jpg
  final path = '$userId/foto.jpg';

  await supabase.storage
      .from('avatars')
      .uploadBinary(
        path,
        bytes,
        fileOptions: const FileOptions(
          contentType: 'image/jpeg',
          upsert: true, // timpa jika sudah ada
        ),
      );

  // URL publik (bucket harus bertipe Public)
  return supabase.storage.from('avatars').getPublicUrl(path);
}
  • uploadBinary menerima Uint8List sehingga bisa dipakai di Android, iOS, maupun Web.
  • storage.foldername(name)[1] di policy adalah nama folder pertama dari path file, yang harus sama dengan id user.
  • upsert: true membutuhkan policy UPDATE juga, karena file lama ditimpa.
  • Untuk bucket privat, gunakan createSignedUrl(path, detik) sebagai pengganti getPublicUrl.

Ringkasan Modul 12

  • Supabase = PostgreSQL + Auth + RLS + Realtime + Storage, diakses lewat supabase_flutter.
  • Supabase.initialize(url:, publishableKey:) sekali di main(). Simpan nilai di env.json + --dart-define-from-file.
  • Secret/service_role key tidak pernah masuk ke aplikasi. Data dilindungi oleh RLS.
  • Query: from().select()/insert()/update()/delete()/upsert() plus filter, order, range, single/maybeSingle.
  • Error database = PostgrestException, error login = AuthException, sisanya biasanya jaringan.
