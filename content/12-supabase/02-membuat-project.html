Sebelum menulis kode Flutter, kita siapkan dulu "server"-nya, yaitu sebuah project di Supabase. Semua langkah di bawah gratis dan tidak memerlukan kartu kredit.

Langkah 1: Membuat akun

  1. Buka supabase.com, klik Start your project.
  2. Pilih Continue with GitHub (paling cepat) atau daftar dengan email.
  3. Saat pertama kali masuk, Anda diminta membuat Organization. Isi nama (misalnya praktikum-mobile), pilih tipe Personal dan plan Free.

Langkah 2: Membuat project baru

  1. Di dashboard klik New project.
  2. Project name: catatan-kuliah.
  3. Database Password: klik Generate a password, lalu simpan di tempat aman. Password ini adalah password database Postgres (dipakai untuk koneksi langsung ke database), bukan password login aplikasi.
  4. Region: pilih yang paling dekat dengan pengguna, yaitu Southeast Asia (Singapore), agar latensi kecil.
  5. Klik Create new project dan tunggu 1–2 menit sampai status project siap.

Langkah 3: Menemukan Project URL dan API key

Aplikasi Flutter hanya butuh dua nilai untuk terhubung:

  1. Klik tombol Connect di bagian atas dashboard project, atau buka Project Settings (ikon roda gigi) → API Keys.
  2. Project URL berbentuk https://<project-ref>.supabase.co. project-ref adalah 20 huruf acak, sama dengan yang terlihat di address bar dashboard.
  3. Publishable key berbentuk sb_publishable_.... Inilah kunci yang dipasang di aplikasi.

ℹ️ Publishable key vs anon key

Supabase memperkenalkan format kunci baru sb_publishable_... dan sb_secret_.... Package supabase_flutter versi terbaru memakai parameter publishableKey di Supabase.initialize(). Parameter lama anonKey masih ada tetapi sudah deprecated. Jika Anda menemukan tutorial lama yang menulis anonKey: 'eyJ...', cara itu masih berjalan, tetapi untuk project baru gunakan publishableKey.

💡 Tampilan dashboard berubah?

Supabase cukup sering memperbarui tampilan dashboard. Jika menu di atas tidak persis sama, cari kata kunci API Keys atau tombol Connect. Nilai yang dicari tetap sama, yaitu Project URL dan publishable key.

Langkah 4: Mengenal menu dashboard yang akan sering dipakai

MenuKegunaan
Table EditorMelihat dan mengedit isi tabel seperti spreadsheet.
SQL EditorMenjalankan perintah SQL: membuat tabel, policy, trigger. Kita akan banyak memakai menu ini.
AuthenticationDaftar user yang sudah register, pengaturan provider login (Email), dan template email.

⚠️ Project gratis bisa di-pause

Project pada plan Free akan di-pause otomatis bila tidak ada aktivitas selama beberapa waktu. Jika aplikasi tiba-tiba tidak bisa terhubung menjelang praktikum, buka dashboard lalu klik Restore project.
