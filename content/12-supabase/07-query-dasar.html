Setelah tabel dan policy siap, saatnya mengakses data dari Flutter. Semua query dimulai dengan supabase.from('nama_tabel'), lalu disambung method lain seperti rantai (method chaining), mirip menyusun kalimat SQL.

Semua contoh di section ini mengasumsikan bagian atas file berisi:

1. SELECT: membaca data

Pertama, siapkan model seperti di Modul 09 agar data aman dari salah tipe:

class MataKuliah {
  const MataKuliah({
    required this.id,
    required this.kode,
    required this.nama,
    required this.sks,
    required this.semester,
  });

  final int id;
  final String kode;
  final String nama;
  final int sks;
  final int semester;

  // Satu baris hasil query Supabase = Map<String, dynamic>
  factory MataKuliah.fromJson(Map<String, dynamic> json) {
    return MataKuliah(
      id: json['id'] as int,
      kode: json['kode'] as String,
      nama: json['nama'] as String,
      sks: json['sks'] as int,
      semester: json['semester'] as int,
    );
  }
}

Future<List<MataKuliah>> ambilSemua() async {
  // SELECT * FROM mata_kuliah
  final List<Map<String, dynamic>> rows = await supabase
      .from('mata_kuliah')
      .select();
  return rows.map(MataKuliah.fromJson).toList();
}
  • Hasil select() berupa List<Map<String, dynamic>>. Satu Map adalah satu baris, dengan key berupa nama kolom.
  • rows.map(MataKuliah.fromJson).toList() mengubah setiap Map menjadi objek. Polanya sama persis dengan Modul 09.

Mengambil sebagian kolom saja (lebih hemat kuota dan lebih cepat):

Future<void> ambilKolomTertentu() async {
  // SELECT kode, nama FROM mata_kuliah
  final rows = await supabase.from('mata_kuliah').select('kode, nama');
  for (final row in rows) {
    debugPrint('${row['kode']} - ${row['nama']}');
  }
}

2. Filter

Future<List<Map<String, dynamic>>> contohFilter() async {
  // WHERE semester = 5
  final semester5 = await supabase
      .from('mata_kuliah')
      .select()
      .eq('semester', 5);

  // WHERE sks >= 4
  final sksBesar = await supabase.from('mata_kuliah').select().gte('sks', 4);

  // WHERE nama ILIKE '%data%'  (cari teks, tidak peka huruf besar/kecil)
  final cari = await supabase
      .from('mata_kuliah')
      .select()
      .ilike('nama', '%data%');

  // WHERE semester IN (1, 2)
  final awal = await supabase.from('mata_kuliah').select().inFilter(
    'semester',
    [1, 2],
  );

  return [...semester5, ...sksBesar, ...cari, ...awal];
}

3. Urutan dan batas jumlah

Future<List<Map<String, dynamic>>> urutDanBatasi() async {
  // SELECT * FROM mata_kuliah WHERE semester <= 4
  // ORDER BY semester ASC, nama ASC LIMIT 5
  return supabase
      .from('mata_kuliah')
      .select()
      .lte('semester', 4) // filter dulu
      .order('semester', ascending: true) // lalu urutkan
      .order('nama', ascending: true)
      .limit(5); // terakhir batasi jumlah
}

ℹ️ Urutan method

Tulis filter (eq, gte, ...) lebih dulu, baru order, limit/range, dan single. Setelah .order(), method filter sudah tidak tersedia, dan analyzer akan langsung memberi tahu jika urutannya salah.

4. Pagination dengan range

/// Pagination: halaman dimulai dari 0, setiap halaman berisi [perHalaman] baris.
Future<List<Map<String, dynamic>>> ambilHalaman(
  int halaman, {
  int perHalaman = 3,
}) {
  final dari = halaman * perHalaman; // halaman 0 -> 0, halaman 1 -> 3
  final sampai = dari + perHalaman - 1; // halaman 0 -> 2, halaman 1 -> 5
  return supabase
      .from('mata_kuliah')
      .select()
      .order('id')
      .range(dari, sampai); // indeks inklusif di kedua sisi
}

range(dari, sampai) memakai indeks mulai 0 dan inklusif di kedua ujung. range(0, 2) berarti 3 baris pertama. Panggil ambilHalaman(0), ambilHalaman(1), dan seterusnya saat user menggulir ke bawah (infinite scroll, Modul 06).

5. Mengambil satu baris: single() dan maybeSingle()

Future<void> ambilSatu() async {
  // single(): WAJIB tepat 1 baris. 0 atau >1 baris -> PostgrestException.
  final Map<String, dynamic> row = await supabase
      .from('mata_kuliah')
      .select()
      .eq('kode', 'INF301')
      .single();
  debugPrint(row['nama']);

  // maybeSingle(): 0 baris -> null (tidak error).
  final Map<String, dynamic>? mungkin = await supabase
      .from('mata_kuliah')
      .select()
      .eq('kode', 'TIDAK-ADA')
      .maybeSingle();
  if (mungkin == null) debugPrint('Mata kuliah tidak ditemukan');
}

6. INSERT: menambah data

Future<void> tambah() async {
  // Insert tanpa meminta data balik
  await supabase.from('mata_kuliah').insert({
    'kode': 'INF401',
    'nama': 'Komputasi Awan',
    'sks': 3,
    'semester': 7,
  });

  // Insert banyak baris sekaligus: kirim List<Map>
  await supabase.from('mata_kuliah').insert([
    {'kode': 'INF402', 'nama': 'Data Mining', 'semester': 7},
    {'kode': 'INF403', 'nama': 'Etika Profesi', 'sks': 2, 'semester': 8},
  ]);
}

Future<MataKuliah> tambahDanAmbil() async {
  // .select().single() -> baris yang baru dibuat dikembalikan,
  // lengkap dengan id dan created_at yang diisi database.
  final row = await supabase
      .from('mata_kuliah')
      .insert({'kode': 'INF404', 'nama': 'Keamanan Siber', 'semester': 7})
      .select()
      .single();
  return MataKuliah.fromJson(row);
}
  • Kolom yang punya default (id, sks, created_at) boleh tidak dikirim.
  • Secara default insert tidak mengembalikan data. Tambahkan .select() (dan .single() untuk satu baris) jika butuh id yang dibuat database. Pola ini akan kita pakai di Modul 14.

7. UPDATE: mengubah data

Future<void> ubah() async {
  // UPDATE mata_kuliah SET sks = 4 WHERE kode = 'INF401'
  await supabase
      .from('mata_kuliah')
      .update({'sks': 4})
      .eq('kode', 'INF401'); // JANGAN lupa filter!
}

⚠️ Selalu pakai filter

update() dan delete() wajib diikuti filter seperti .eq('id', ...). Di project Supabase, update/delete tanpa filter biasanya ditolak dengan pesan UPDATE/DELETE requires a WHERE clause. Filter yang salah lebih berbahaya lagi karena bisa mengubah baris yang tidak Anda maksud.

8. DELETE: menghapus data

Future<void> hapus() async {
  // DELETE FROM mata_kuliah WHERE kode = 'INF401'
  await supabase.from('mata_kuliah').delete().eq('kode', 'INF401');
}

Catatan: dengan policy dari section sebelumnya, tabel mata_kuliah tidak punya policy UPDATE/DELETE, sehingga dua contoh di atas tidak mengubah apa pun jika dijalankan dari aplikasi (0 baris). Ini contoh nyata RLS bekerja.

9. UPSERT: insert atau update

Future<void> simpanAtauPerbarui() async {
  // Jika kode 'INF301' sudah ada -> UPDATE, jika belum -> INSERT.
  // onConflict menunjuk kolom UNIQUE yang dipakai untuk mencocokkan.
  await supabase.from('mata_kuliah').upsert({
    'kode': 'INF301',
    'nama': 'Pemrograman Mobile',
    'sks': 4,
    'semester': 5,
  }, onConflict: 'kode');
}

Upsert berguna untuk sinkronisasi, misalnya "simpan profil": jika belum ada dibuat, jika sudah ada diperbarui. Ingat, upsert butuh policy INSERT dan UPDATE sekaligus.

10. Menghitung jumlah baris

Future<int> hitung() async {
  // Hanya menghitung jumlah baris tanpa mengambil datanya.
  return supabase.from('mata_kuliah').count();
}

Contoh lengkap: daftar mata kuliah dari Supabase

Gabungkan semuanya menjadi aplikasi kecil yang bisa dijalankan. Pastikan SQL di section 5 dan 6 sudah dijalankan, dan env.json sudah dibuat (section 4).

📄 lib/main.dart

// lib/main.dart — contoh lengkap: membaca tabel mata_kuliah dari Supabase.
// Jalankan: flutter run --dart-define-from-file=env.json
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

const supabaseUrl = String.fromEnvironment('SUPABASE_URL');
const supabaseKey = String.fromEnvironment('SUPABASE_PUBLISHABLE_KEY');

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Supabase.initialize(url: supabaseUrl, publishableKey: supabaseKey);
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.teal),
      ),
      home: const MataKuliahPage(),
    );
  }
}

class MataKuliah {
  const MataKuliah({
    required this.kode,
    required this.nama,
    required this.sks,
    required this.semester,
  });

  final String kode;
  final String nama;
  final int sks;
  final int semester;

  factory MataKuliah.fromJson(Map<String, dynamic> json) {
    return MataKuliah(
      kode: json['kode'] as String,
      nama: json['nama'] as String,
      sks: json['sks'] as int,
      semester: json['semester'] as int,
    );
  }
}

class MataKuliahPage extends StatefulWidget {
  const MataKuliahPage({super.key});

  @override
  State<MataKuliahPage> createState() => _MataKuliahPageState();
}

class _MataKuliahPageState extends State<MataKuliahPage> {
  final _supabase = Supabase.instance.client;
  late Future<List<MataKuliah>> _future;

  @override
  void initState() {
    super.initState();
    _future = _ambilData();
  }

  Future<List<MataKuliah>> _ambilData() async {
    final rows = await _supabase
        .from('mata_kuliah')
        .select()
        .order('semester')
        .order('nama');
    return rows.map(MataKuliah.fromJson).toList();
  }

  Future<void> _refresh() async {
    final future = _ambilData();
    setState(() => _future = future);
    await future;
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Mata Kuliah Informatika')),
      body: FutureBuilder<List<MataKuliah>>(
        future: _future,
        builder: (context, snapshot) {
          if (snapshot.connectionState == ConnectionState.waiting) {
            return const Center(child: CircularProgressIndicator());
          }
          if (snapshot.hasError) {
            return Center(
              child: Padding(
                padding: const EdgeInsets.all(24),
                child: Column(
                  mainAxisSize: MainAxisSize.min,
                  children: [
                    Text(
                      'Gagal memuat data:\n${snapshot.error}',
                      textAlign: TextAlign.center,
                    ),
                    const SizedBox(height: 12),
                    FilledButton(
                      onPressed: _refresh,
                      child: const Text('Coba lagi'),
                    ),
                  ],
                ),
              ),
            );
          }
          final data = snapshot.data!;
          if (data.isEmpty) {
            return const Center(child: Text('Tabel masih kosong.'));
          }
          return RefreshIndicator(
            onRefresh: _refresh,
            child: ListView.separated(
              itemCount: data.length,
              separatorBuilder: (_, _) => const Divider(height: 1),
              itemBuilder: (context, index) {
                final mk = data[index];
                return ListTile(
                  leading: CircleAvatar(child: Text('${mk.semester}')),
                  title: Text(mk.nama),
                  subtitle: Text(mk.kode),
                  trailing: Text('${mk.sks} SKS'),
                );
              },
            ),
          );
        },
      ),
    );
  }
}
Data tabel mata_kuliah diambil dari project Supabase sungguhan
  • _future disimpan di State dan dibuat di initState, bukan di build(). Jika dibuat di build, setiap rebuild akan memicu query baru (pelajaran yang sama dengan FutureBuilder di Modul 09).
  • _refresh() membuat Future baru dan memasangnya lewat setState, lalu menunggu sampai selesai agar animasi RefreshIndicator berhenti tepat waktu.
  • .order('semester').order('nama') mengurutkan per semester, lalu per nama.
