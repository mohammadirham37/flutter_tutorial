Supabase menyediakan package resmi supabase_flutter. Di dalamnya sudah ada semua yang dibutuhkan: client database (PostgREST), Auth, Realtime, dan Storage, termasuk penyimpanan sesi login otomatis di perangkat.

Langkah 1: Tambahkan package

flutter pub add supabase_flutter

Perintah ini menambahkan baris supabase_flutter: ^x.y.z di pubspec.yaml dengan versi terbaru yang kompatibel, lalu menjalankan flutter pub get.

Langkah 2: Inisialisasi di main()

Supabase harus di-initialize satu kali, sebelum runApp(). Contoh paling sederhana (nilai URL dan key masih ditulis langsung; di section berikutnya kita pindahkan ke file konfigurasi):

import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

Future<void> main() async {
  // 1. Wajib: memastikan binding Flutter siap sebelum kode async + plugin.
  WidgetsFlutterBinding.ensureInitialized();

  // 2. Hubungkan aplikasi ke project Supabase (cukup SEKALI).
  await Supabase.initialize(
    url: 'https://abcdefghijklm.supabase.co',
    publishableKey: 'sb_publishable_xxxxxxxxxxxxxxxxxxxx',
  );

  runApp(const MaterialApp(home: Scaffold()));
}

// 3. Ambil client di mana saja setelah initialize.
final supabase = Supabase.instance.client;

Penjelasan baris penting:

  • main() diubah menjadi async dan mengembalikan Future<void> karena kita perlu await sebelum runApp().
  • WidgetsFlutterBinding.ensureInitialized() wajib dipanggil sebelum memakai plugin (di sini untuk penyimpanan sesi) di dalam main(). Lupa baris ini akan memunculkan error Binding has not yet been initialized.
  • Supabase.initialize(url:, publishableKey:) membuat client sekaligus memulihkan sesi login yang tersimpan dari pembukaan aplikasi sebelumnya.
  • Supabase.instance.client adalah objek SupabaseClient yang kita pakai untuk semua operasi. Memanggilnya sebelum initialize selesai akan error.

Langkah 3: Izin internet di Android

Proyek Flutter baru hanya memberi izin internet untuk mode debug. Agar APK release juga bisa mengakses Supabase, tambahkan izin di manifest utama:

📄 android/app/src/main/AndroidManifest.xml

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <!-- Tambahkan baris ini, di atas tag <application> -->
    <uses-permission android:name="android.permission.INTERNET"/>

    <application
        android:label="catatan_kuliah"
        ...

💡 Platform lain

iOS tidak membutuhkan izin tambahan. Untuk macOS, aktifkan com.apple.security.network.client di file macos/Runner/DebugProfile.entitlements dan Release.entitlements. Flutter Web langsung bisa dipakai.

Langkah 4: Uji koneksi

Jalankan aplikasi. Jika tidak ada error merah di konsol, inisialisasi berhasil. Perlu diingat, initialize tidak mengirim query ke database, jadi URL atau key yang salah baru ketahuan saat query pertama dijalankan (akan kita coba di section Query).

⚠️ Kesalahan umum

  • "You must initialize the supabase instance before calling Supabase.instance": Supabase.instance.client dipanggil sebelum await Supabase.initialize(...), misalnya di variabel global yang dibaca terlalu awal atau karena lupa await.
  • Memanggil initialize di dalam build(): initialize cukup sekali di main().
  • URL diakhiri /rest/v1: cukup tulis URL dasarnya, https://xxxx.supabase.co.
