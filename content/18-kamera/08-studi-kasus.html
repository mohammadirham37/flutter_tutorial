Kita gabungkan semua materi bab ini menjadi aplikasi Kartu Mahasiswa: foto profil bisa diambil dari kamera sistem, kamera di dalam aplikasi dengan bingkai wajah, atau galeri; foto disimpan permanen, bisa diganti dan dihapus; izin kamera ditangani lengkap; dan foto yang "hilang" di Android dipulihkan.

Fitur dan alur

  1. Saat dibuka, controller memeriksa retrieveLostData() (Android), lalu memuat foto profil tersimpan dari folder dokumen.
  2. Menekan foto atau tombol Ganti Foto membuka bottom sheet: Kamera sistem, Kamera di aplikasi, Galeri, dan Hapus (jika sudah ada foto).
  3. Sebelum kamera dibuka, izin diminta dengan permission_handler: diberikan → lanjut; ditolak → SnackBar; ditolak permanen → dialog Buka Pengaturan.
  4. Foto baru disalin ke <dokumen>/profil/foto_profil_<waktu>.jpg, foto lama dihapus.

Service

📄 lib/services/foto_profil_service.dart

// lib/services/foto_profil_service.dart
// SERVICE: membungkus image_picker, permission_handler, dan file sistem.
import 'dart:io';

import 'package:flutter/services.dart';
import 'package:image_picker/image_picker.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';
import 'package:permission_handler/permission_handler.dart';

enum SumberFoto { kamera, galeri }

enum StatusIzin { diberikan, ditolak, ditolakPermanen }

class FotoException implements Exception {
  const FotoException(this.pesan);
  final String pesan;

  @override
  String toString() => pesan;
}

class FotoProfilService {
  final ImagePicker _picker = ImagePicker();
  static const String _awalan = 'foto_profil_';

  Future<Directory> _folder() async {
    final dokumen = await getApplicationDocumentsDirectory();
    return Directory(p.join(dokumen.path, 'profil')).create(recursive: true);
  }

  Future<List<File>> _semuaFotoProfil() async {
    final folder = await _folder();
    final isi = await folder.list().toList();
    return isi
        .whereType<File>()
        .where((f) => p.basename(f.path).startsWith(_awalan))
        .toList()
      ..sort((a, b) => b.path.compareTo(a.path)); // terbaru lebih dulu
  }

  /// Foto profil yang tersimpan, atau null jika belum ada.
  Future<File?> fotoTersimpan() async {
    final daftar = await _semuaFotoProfil();
    return daftar.isEmpty ? null : daftar.first;
  }

  // ---------- Izin kamera (alur dari Modul 17) ----------
  Future<StatusIzin> mintaIzinKamera() async {
    final status = await Permission.camera.request();
    if (status.isGranted) return StatusIzin.diberikan;
    if (status.isPermanentlyDenied || status.isRestricted) {
      return StatusIzin.ditolakPermanen;
    }
    return StatusIzin.ditolak;
  }

  Future<bool> bukaPengaturan() => openAppSettings();

  // ---------- Mengambil foto ----------
  Future<XFile?> pilih(SumberFoto sumber) async {
    try {
      return await _picker.pickImage(
        source: sumber == SumberFoto.kamera
            ? ImageSource.camera
            : ImageSource.gallery,
        preferredCameraDevice: CameraDevice.front, // foto profil = selfie
        maxWidth: 800,
        imageQuality: 80,
      );
    } on PlatformException catch (e) {
      throw FotoException('Gagal mengambil foto (${e.code}).');
    }
  }

  /// Android: foto yang "hilang" karena aplikasi dimatikan sistem
  /// saat aplikasi kamera terbuka.
  Future<XFile?> pulihkanFotoHilang() async {
    if (!Platform.isAndroid) return null;
    final respons = await _picker.retrieveLostData();
    if (respons.isEmpty) return null;
    final files = respons.files;
    return (files != null && files.isNotEmpty) ? files.first : null;
  }

  // ---------- Menyimpan & menghapus ----------
  /// Menyalin foto (dari cache) ke folder dokumen dengan nama unik,
  /// lalu menghapus foto profil lama.
  Future<File> simpan(String pathSumber) async {
    final folder = await _folder();
    final sumber = File(pathSumber);
    final ukuran = await sumber.length();
    if (ukuran > 5 * 1024 * 1024) {
      throw const FotoException('Ukuran foto lebih dari 5 MB.');
    }

    final nama =
        '$_awalan${DateTime.now().millisecondsSinceEpoch}${p.extension(pathSumber)}';
    final baru = await sumber.copy(p.join(folder.path, nama));

    for (final lama in await _semuaFotoProfil()) {
      if (lama.path != baru.path) await lama.delete();
    }
    return baru;
  }

  Future<void> hapusSemua() async {
    for (final f in await _semuaFotoProfil()) {
      await f.delete();
    }
  }
}
  • mintaIzinKamera() menerjemahkan PermissionStatus menjadi enum StatusIzin sederhana. isRestricted (iOS, misalnya karena kontrol orang tua) diperlakukan seperti ditolak permanen.
  • preferredCameraDevice: CameraDevice.front hanya saran untuk kamera sistem. Jika aplikasi kamera HP mengabaikannya, pengguna bisa membalik kamera sendiri.
  • simpan() memeriksa ukuran (maksimal 5 MB) sebelum menyalin, memakai nama unik agar imageCache tidak menampilkan foto lama, lalu menghapus foto profil sebelumnya.
  • pulihkanFotoHilang() hanya berjalan di Android, sesuai dokumentasi image_picker.

Controller

📄 lib/controllers/kartu_controller.dart

// lib/controllers/kartu_controller.dart
// CONTROLLER: state kartu + keputusan alur. Tanpa material.dart.
import 'dart:io';

import 'package:get/get.dart';

import '../models/mahasiswa.dart';
import '../services/foto_profil_service.dart';

/// Hasil sebuah aksi foto, dibaca oleh view untuk menampilkan pesan.
enum HasilFoto { berhasil, batal, izinDitolak, izinDitolakPermanen, gagal }

class KartuController extends GetxController {
  KartuController(this._service);
  final FotoProfilService _service;

  final Mahasiswa mahasiswa = const Mahasiswa(
    nama: 'Siti Rahmawati',
    nim: '2201010123',
    prodi: 'Teknik Komputer',
    angkatan: 2022,
  );

  final _foto = Rxn<File>();
  final _sibuk = false.obs;
  String pesanError = '';

  File? get foto => _foto.value;
  bool get sibuk => _sibuk.value;

  @override
  void onInit() {
    super.onInit();
    _muatAwal();
  }

  Future<void> _muatAwal() async {
    _sibuk.value = true;
    try {
      // 1. Ada foto yang hilang karena aplikasi sempat dimatikan? (Android)
      final hilang = await _service.pulihkanFotoHilang();
      if (hilang != null) {
        _foto.value = await _service.simpan(hilang.path);
      } else {
        // 2. Jika tidak, tampilkan foto yang sudah tersimpan
        _foto.value = await _service.fotoTersimpan();
      }
    } on Exception catch (e) {
      pesanError = e.toString();
    } finally {
      _sibuk.value = false;
    }
  }

  /// Dipanggil sebelum membuka kamera (sistem maupun di dalam aplikasi).
  Future<HasilFoto> pastikanIzinKamera() async {
    return switch (await _service.mintaIzinKamera()) {
      StatusIzin.diberikan => HasilFoto.berhasil,
      StatusIzin.ditolak => HasilFoto.izinDitolak,
      StatusIzin.ditolakPermanen => HasilFoto.izinDitolakPermanen,
    };
  }

  /// Kamera sistem atau galeri lewat image_picker.
  Future<HasilFoto> ambilFoto(SumberFoto sumber) async {
    if (_sibuk.value) return HasilFoto.batal;
    if (sumber == SumberFoto.kamera) {
      final izin = await pastikanIzinKamera();
      if (izin != HasilFoto.berhasil) return izin;
    }
    try {
      final xfile = await _service.pilih(sumber);
      if (xfile == null) return HasilFoto.batal;
      return await _simpan(xfile.path);
    } on FotoException catch (e) {
      pesanError = e.pesan;
      return HasilFoto.gagal;
    }
  }

  /// Hasil dari KameraView (kamera di dalam aplikasi).
  Future<HasilFoto> simpanDariKamera(String? path) async {
    if (path == null) return HasilFoto.batal;
    return _simpan(path);
  }

  Future<HasilFoto> _simpan(String path) async {
    _sibuk.value = true;
    try {
      _foto.value = await _service.simpan(path);
      return HasilFoto.berhasil;
    } on FotoException catch (e) {
      pesanError = e.pesan;
      return HasilFoto.gagal;
    } on FileSystemException catch (e) {
      pesanError = 'Gagal menyimpan: ${e.message}';
      return HasilFoto.gagal;
    } finally {
      _sibuk.value = false;
    }
  }

  Future<void> hapusFoto() async {
    await _service.hapusSemua();
    _foto.value = null;
  }

  Future<bool> bukaPengaturan() => _service.bukaPengaturan();
}
  • Rxn<File> adalah Rx yang boleh null: null berarti belum ada foto.
  • Setiap aksi mengembalikan HasilFoto. Controller memutuskan apa yang terjadi, view memutuskan bagaimana menampilkannya (SnackBar atau dialog).
  • simpanDariKamera() menerima path dari KameraView. Jika pengguna kembali tanpa memotret, path-nya null dan hasilnya batal.
  • return await _simpan(...) di dalam try: tanpa await, exception dari _simpan tidak tertangkap oleh blok on FotoException (linter memperingatkannya dengan unawaited_return_in_try_block).

View: kamera di dalam aplikasi

📄 lib/views/kamera_view.dart

// lib/views/kamera_view.dart
// Kamera di dalam aplikasi (package camera). Mengembalikan path foto
// lewat Navigator.pop, atau null jika pengguna kembali tanpa memotret.
import 'package:camera/camera.dart';
import 'package:flutter/material.dart';

class KameraView extends StatefulWidget {
  const KameraView({super.key});

  @override
  State<KameraView> createState() => _KameraViewState();
}

class _KameraViewState extends State<KameraView> with WidgetsBindingObserver {
  List<CameraDescription> _daftar = [];
  int _indeks = 0;
  CameraController? _controller;
  String? _pesan;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
    _siapkan();
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _controller?.dispose();
    super.dispose();
  }

  Future<void> _siapkan() async {
    try {
      _daftar = await availableCameras();
    } on CameraException catch (e) {
      _setPesan('Kamera tidak tersedia (${e.code}).');
      return;
    }
    if (_daftar.isEmpty) {
      _setPesan('Perangkat ini tidak punya kamera.');
      return;
    }
    // Foto profil: utamakan kamera depan jika ada
    final depan = _daftar.indexWhere(
      (k) => k.lensDirection == CameraLensDirection.front,
    );
    _indeks = depan == -1 ? 0 : depan;
    await _buka();
  }

  Future<void> _buka() async {
    final controller = CameraController(
      _daftar[_indeks],
      ResolutionPreset.high,
      enableAudio: false,
      imageFormatGroup: ImageFormatGroup.jpeg,
    );
    setState(() {
      _controller = controller;
      _pesan = null;
    });
    try {
      await controller.initialize();
    } on CameraException catch (e) {
      _setPesan('Gagal membuka kamera: ${e.code}');
      return;
    }
    if (mounted) setState(() {});
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    final controller = _controller;
    if (state == AppLifecycleState.inactive) {
      if (controller == null || !controller.value.isInitialized) return;
      setState(() => _controller = null);
      controller.dispose();
    } else if (state == AppLifecycleState.resumed) {
      if (controller == null && _daftar.isNotEmpty) _buka();
    }
  }

  Future<void> _ganti() async {
    final controller = _controller;
    if (controller == null || _daftar.length < 2) return;
    final arah = _daftar[_indeks].lensDirection;
    final baru = _daftar.indexWhere((k) => k.lensDirection != arah);
    if (baru == -1) return;
    _indeks = baru;
    try {
      await controller.setDescription(_daftar[baru]);
    } on CameraException catch (e) {
      _setPesan('Gagal mengganti kamera: ${e.code}');
    }
    if (mounted) setState(() {});
  }

  Future<void> _potret() async {
    final controller = _controller;
    if (controller == null ||
        !controller.value.isInitialized ||
        controller.value.isTakingPicture) {
      return;
    }
    try {
      final foto = await controller.takePicture();
      if (!mounted) return;
      Navigator.pop(context, foto.path); // kirim hasil ke halaman sebelumnya
    } on CameraException catch (e) {
      _setPesan('Gagal memotret: ${e.code}');
    }
  }

  void _setPesan(String pesan) {
    if (mounted) setState(() => _pesan = pesan);
  }

  @override
  Widget build(BuildContext context) {
    final controller = _controller;
    final siap = controller != null && controller.value.isInitialized;
    return Scaffold(
      backgroundColor: Colors.black,
      appBar: AppBar(
        title: const Text('Foto Profil'),
        backgroundColor: Colors.black,
        foregroundColor: Colors.white,
      ),
      body: Column(
        children: [
          Expanded(
            child: Center(
              child: _pesan != null
                  ? Text(_pesan!, style: const TextStyle(color: Colors.white))
                  : siap
                  ? CameraPreview(
                      controller,
                      // Bingkai bantu agar wajah berada di tengah
                      child: Center(
                        child: Container(
                          width: 220,
                          height: 280,
                          decoration: BoxDecoration(
                            border: Border.all(
                              color: Colors.white.withValues(alpha: 0.7),
                              width: 2,
                            ),
                            borderRadius: BorderRadius.circular(16),
                          ),
                        ),
                      ),
                    )
                  : const CircularProgressIndicator(),
            ),
          ),
          Padding(
            padding: const EdgeInsets.symmetric(vertical: 24),
            child: Row(
              mainAxisAlignment: MainAxisAlignment.spaceEvenly,
              children: [
                const SizedBox(width: 48),
                FloatingActionButton.large(
                  onPressed: siap ? _potret : null,
                  child: const Icon(Icons.camera_alt),
                ),
                IconButton(
                  color: Colors.white,
                  onPressed: siap && _daftar.length > 1 ? _ganti : null,
                  icon: const Icon(Icons.cameraswitch),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
  • Ini versi ringkas dari contoh bagian 4: lifecycle tetap ditangani, kamera depan diutamakan, dan flash dihilangkan karena kamera depan jarang punya flash.
  • Parameter child pada CameraPreview menampilkan bingkai wajah tepat di atas gambar kamera.
  • Navigator.pop(context, foto.path) mengirim path ke halaman pemanggil, setelah memastikan mounted.

// lib/views/kartu_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/kartu_controller.dart';
import '../services/foto_profil_service.dart';
import 'kamera_view.dart';

enum _Pilihan { kameraSistem, kameraAplikasi, galeri, hapus }

class KartuView extends GetView<KartuController> {
  const KartuView({super.key});

  Future<void> _gantiFoto(BuildContext context) async {
    final pilihan = await showModalBottomSheet<_Pilihan>(
      context: context,
      showDragHandle: true,
      builder: (context) => SafeArea(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            ListTile(
              leading: const Icon(Icons.photo_camera),
              title: const Text('Kamera sistem'),
              subtitle: const Text('image_picker'),
              onTap: () => Navigator.pop(context, _Pilihan.kameraSistem),
            ),
            ListTile(
              leading: const Icon(Icons.camera_front),
              title: const Text('Kamera di aplikasi'),
              subtitle: const Text('package camera, dengan bingkai wajah'),
              onTap: () => Navigator.pop(context, _Pilihan.kameraAplikasi),
            ),
            ListTile(
              leading: const Icon(Icons.photo_library),
              title: const Text('Pilih dari galeri'),
              onTap: () => Navigator.pop(context, _Pilihan.galeri),
            ),
            if (controller.foto != null)
              ListTile(
                leading: const Icon(Icons.delete_outline),
                title: const Text('Hapus foto'),
                onTap: () => Navigator.pop(context, _Pilihan.hapus),
              ),
          ],
        ),
      ),
    );
    if (pilihan == null || !context.mounted) return;

    final HasilFoto hasil;
    switch (pilihan) {
      case _Pilihan.kameraSistem:
        hasil = await controller.ambilFoto(SumberFoto.kamera);
      case _Pilihan.galeri:
        hasil = await controller.ambilFoto(SumberFoto.galeri);
      case _Pilihan.kameraAplikasi:
        final izin = await controller.pastikanIzinKamera();
        if (izin != HasilFoto.berhasil) {
          hasil = izin;
          break;
        }
        if (!context.mounted) return;
        final path = await Navigator.push<String>(
          context,
          MaterialPageRoute(builder: (_) => const KameraView()),
        );
        hasil = await controller.simpanDariKamera(path);
      case _Pilihan.hapus:
        if (!await _konfirmasiHapus(context)) return;
        await controller.hapusFoto();
        hasil = HasilFoto.berhasil;
    }
    if (!context.mounted) return;
    _tampilkanHasil(context, hasil);
  }

  Future<bool> _konfirmasiHapus(BuildContext context) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Hapus foto profil?'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    return yakin == true;
  }

  void _tampilkanHasil(BuildContext context, HasilFoto hasil) {
    final messenger = ScaffoldMessenger.of(context);
    switch (hasil) {
      case HasilFoto.berhasil:
        messenger.showSnackBar(
          const SnackBar(content: Text('Foto profil diperbarui')),
        );
      case HasilFoto.batal:
        break; // pengguna membatalkan: tidak perlu pesan
      case HasilFoto.izinDitolak:
        messenger.showSnackBar(
          const SnackBar(
            content: Text('Izin kamera diperlukan untuk memotret'),
          ),
        );
      case HasilFoto.izinDitolakPermanen:
        showDialog<void>(
          context: context,
          builder: (context) => AlertDialog(
            title: const Text('Izin kamera ditolak'),
            content: const Text(
              'Aktifkan izin Kamera di Pengaturan aplikasi agar bisa '
              'memotret foto profil.',
            ),
            actions: [
              TextButton(
                onPressed: () => Navigator.pop(context),
                child: const Text('Nanti'),
              ),
              FilledButton(
                onPressed: () {
                  Navigator.pop(context);
                  controller.bukaPengaturan();
                },
                child: const Text('Buka Pengaturan'),
              ),
            ],
          ),
        );
      case HasilFoto.gagal:
        messenger.showSnackBar(SnackBar(content: Text(controller.pesanError)));
    }
  }

  @override
  Widget build(BuildContext context) {
    final mhs = controller.mahasiswa;
    final skema = Theme.of(context).colorScheme;
    return Scaffold(
      appBar: AppBar(title: const Text('Kartu Mahasiswa')),
      body: Center(
        child: Padding(
          padding: const EdgeInsets.all(16),
          child: Card(
            clipBehavior: Clip.antiAlias,
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                Container(
                  width: double.infinity,
                  color: skema.primary,
                  padding: const EdgeInsets.all(12),
                  child: Text(
                    'KARTU TANDA MAHASISWA',
                    textAlign: TextAlign.center,
                    style: TextStyle(
                      color: skema.onPrimary,
                      fontWeight: FontWeight.bold,
                      letterSpacing: 1.2,
                    ),
                  ),
                ),
                Padding(
                  padding: const EdgeInsets.all(16),
                  child: Row(
                    crossAxisAlignment: CrossAxisAlignment.start,
                    children: [
                      _FotoProfil(onTap: () => _gantiFoto(context)),
                      const SizedBox(width: 16),
                      Expanded(
                        child: Column(
                          crossAxisAlignment: CrossAxisAlignment.start,
                          children: [
                            Text(
                              mhs.nama,
                              style: Theme.of(context).textTheme.titleMedium,
                            ),
                            const SizedBox(height: 8),
                            Text('NIM: ${mhs.nim}'),
                            Text('Prodi: ${mhs.prodi}'),
                            Text('Angkatan: ${mhs.angkatan}'),
                            const SizedBox(height: 12),
                            OutlinedButton.icon(
                              onPressed: () => _gantiFoto(context),
                              icon: const Icon(Icons.edit),
                              label: const Text('Ganti Foto'),
                            ),
                          ],
                        ),
                      ),
                    ],
                  ),
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}

class _FotoProfil extends GetView<KartuController> {
  const _FotoProfil({required this.onTap});
  final VoidCallback onTap;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: onTap,
      child: ClipRRect(
        borderRadius: BorderRadius.circular(8),
        child: Container(
          width: 105,
          height: 140, // rasio 3:4 seperti pas foto
          color: Theme.of(context).colorScheme.surfaceContainerHighest,
          child: Obx(() {
            if (controller.sibuk) {
              return const Center(child: CircularProgressIndicator());
            }
            final foto = controller.foto;
            if (foto == null) {
              return const Icon(Icons.person, size: 64);
            }
            return Image.file(
              foto,
              key: ValueKey(foto.path), // path baru = gambar baru
              fit: BoxFit.cover,
              cacheWidth: 315, // 3x lebar tampilan, cukup untuk layar tajam
            );
          }),
        ),
      ),
    );
  }
}
  • showModalBottomSheet<_Pilihan> mengembalikan pilihan pengguna, lalu context.mounted dicek sebelum melanjutkan.
  • Untuk kamera di aplikasi, izin diminta dulu lewat controller, baru KameraView dibuka dengan Navigator.push<String>, dan path hasilnya diteruskan ke controller.simpanDariKamera().
  • _tampilkanHasil menangani semua cabang HasilFoto, termasuk dialog Buka Pengaturan untuk izin yang ditolak permanen.
  • _FotoProfil adalah satu-satunya bagian yang dibungkus Obx. ValueKey(foto.path) memastikan widget gambar dibuat ulang saat path berubah, dan cacheWidth menjaga pemakaian memori tetap kecil.
