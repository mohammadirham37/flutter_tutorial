Sebelum menulis kode, pasang package dan siapkan konfigurasi Android serta iOS. Bagian ini juga menjelaskan siapa yang meminta izin kamera pada setiap package, karena di situlah mahasiswa paling sering bingung.

Memasang package

# Kamera sistem + galeri
flutter pub add image_picker

# Kamera di dalam aplikasi
flutter pub add camera

# Menyimpan file permanen (sudah dipakai di Modul 10)
flutter pub add path_provider path

# Alur izin lengkap (Modul 17) dan GetX (Modul 08)
flutter pub add permission_handler get

Setelah menambah package yang berisi kode native, hentikan aplikasi lalu jalankan ulang dengan flutter run. Hot reload maupun hot restart tidak memasang kode native baru, sehingga muncul error MissingPluginException.

Android

Kedua package mendukung Android API 24 ke atas. Proyek Flutter terbaru sudah memakai minSdk = flutter.minSdkVersion yang bernilai 24, jadi biasanya tidak ada yang perlu diubah. Jika proyekmu lama dan memakai angka di bawah 24, naikkan di android/app/build.gradle.kts:

📄 android/app/build.gradle.kts

android {
    defaultConfig {
        // minimal 24 untuk image_picker dan camera
        minSdk = flutter.minSdkVersion
    }
}

image_picker tidak butuh konfigurasi tambahan di Android. Package camera (lewat camera_android_camerax) sudah mendaftarkan sendiri izin CAMERA, RECORD_AUDIO, dan WRITE_EXTERNAL_STORAGE (khusus Android 9 ke bawah) ke manifest hasil gabungan. Meski begitu, karena kita juga memakai permission_handler, tulis izin kamera secara eksplisit di manifest agar mudah dibaca dan tidak bergantung pada package lain:

📄 android/app/src/main/AndroidManifest.xml

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.CAMERA" />
    <!-- Kamera tidak wajib: aplikasi tetap bisa dipasang di perangkat tanpa kamera -->
    <uses-feature android:name="android.hardware.camera" android:required="false" />

    <application ...>
        ...
    </application>
</manifest>

ℹ️ Galeri tidak butuh izin penyimpanan

Di Android 13 ke atas, image_picker memakai Android Photo Picker: pengguna memilih foto lewat jendela sistem, dan aplikasi hanya menerima foto yang dipilih. Karena itu kita tidak perlu menambah READ_EXTERNAL_STORAGE atau READ_MEDIA_IMAGES hanya untuk memilih foto. Menambahkannya tanpa alasan justru bisa ditolak saat review Play Store.

iOS

iOS mewajibkan kalimat penjelasan untuk setiap izin. Tanpa kunci ini aplikasi akan langsung crash saat kamera atau galeri dibuka.

📄 ios/Runner/Info.plist

<key>NSCameraUsageDescription</key>
<string>Kamera dipakai untuk memotret foto profil kartu mahasiswa.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Galeri dipakai untuk memilih foto profil.</string>
<key>NSMicrophoneUsageDescription</key>
<string>Mikrofon dipakai saat merekam video.</string>

Dokumentasi camera meminta kunci kamera dan mikrofon. image_picker meminta kunci galeri dan kamera (mikrofon hanya jika merekam video). permission_handler di iOS juga perlu mengaktifkan izin kamera di Podfile, seperti yang dibahas di Modul 17:

📄 ios/Podfile

post_install do |installer|
  installer.pods_project.targets.each do |target|
    flutter_additional_ios_build_settings(target)
    target.build_configurations.each do |config|
      config.build_settings['GCC_PREPROCESSOR_DEFINITIONS'] ||= [
        '$(inherited)',
        'PERMISSION_CAMERA=1',
      ]
    end
  end
end

Siapa yang meminta izin kamera?

SituasiYang terjadiJika ditolak
image_picker + galeriAndroid 13+ dan iOS 14+ memakai pemilih foto sistem, tanpa dialog izinTidak ada; jika batal hasilnya null
image_picker + kameraAndroid: jika manifest mendeklarasikan CAMERA, plugin meminta izin itu dulu. iOS: sistem meminta izin kameraPlatformException dengan code == 'camera_access_denied'
cameraDialog izin muncul saat controller.initialize()CameraException dengan kode CameraAccessDenied, CameraAccessDeniedWithoutPrompt (iOS, sudah pernah ditolak), atau CameraAccessRestricted (iOS)
permission_handlerKita yang meminta izin, sebelum membuka kameraPermissionStatus: denied atau permanentlyDenied

Error dari plugin kamera tidak membedakan "ditolak sekali" dan "ditolak permanen" di Android. Karena itu, untuk alur yang rapi (minta, jelaskan jika ditolak, arahkan ke Pengaturan jika ditolak permanen) kita meminta izin lebih dulu dengan permission_handler, persis pola Modul 17. Setelah izin diberikan, image_picker dan camera tidak akan menampilkan dialog lagi.

import 'package:flutter/material.dart';
import 'package:permission_handler/permission_handler.dart';

/// Mengembalikan true jika kamera boleh dipakai.
Future<bool> pastikanIzinKamera(BuildContext context) async {
  final status = await Permission.camera.request();
  if (status.isGranted) return true;
  if (!context.mounted) return false;

  if (status.isPermanentlyDenied || status.isRestricted) {
    // Dialog izin tidak akan muncul lagi: arahkan ke Pengaturan
    final buka = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Izin kamera ditolak'),
        content: const Text('Aktifkan izin Kamera di Pengaturan aplikasi.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Nanti'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Buka Pengaturan'),
          ),
        ],
      ),
    );
    if (buka == true) await openAppSettings();
  } else {
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Izin kamera diperlukan untuk memotret')),
    );
  }
  return false;
}
  • Permission.camera.request() menampilkan dialog sistem jika izin belum pernah diputuskan, dan langsung mengembalikan status jika sudah.
  • context.mounted dicek setelah await karena pengguna bisa saja meninggalkan halaman saat dialog izin terbuka.
  • isPermanentlyDenied berarti sistem tidak akan menampilkan dialog lagi, sehingga satu-satunya jalan adalah openAppSettings().

⚠️ Kesalahan umum

  • Lupa kunci NSCameraUsageDescription di iOS: aplikasi tertutup tanpa pesan error yang jelas begitu kamera dibuka.
  • Menambah izin penyimpanan (READ_EXTERNAL_STORAGE) "untuk jaga-jaga". Tidak perlu untuk image_picker modern.
  • Menjalankan hot reload setelah flutter pub add camera, lalu bingung karena muncul MissingPluginException. Stop dan jalankan ulang aplikasi.
