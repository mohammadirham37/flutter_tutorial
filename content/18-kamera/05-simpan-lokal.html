Foto dari image_picker maupun camera mendarat di folder cache. Folder ini boleh dibersihkan sistem kapan saja, jadi foto yang penting harus dipindahkan ke folder dokumen aplikasi. Bagian ini membahas cara menampilkan, menyimpan permanen, dan menghapus foto.

Menampilkan foto dari file

import 'dart:io';

import 'package:flutter/material.dart';
import 'package:image_picker/image_picker.dart';

List<Widget> caraMenampilkan(XFile xfile) {
  final file = File(xfile.path); // XFile -> File

  return [
    Image.file(file), // tampilkan apa adanya
    Image.file(file, fit: BoxFit.cover), // isi kotak, potong sisanya
    Image.file(file, cacheWidth: 300), // decode kecil untuk thumbnail
    CircleAvatar(radius: 40, backgroundImage: FileImage(file)), // avatar
  ];
}
  • Image.file butuh objek File dari dart:io, jadi XFile diubah dengan File(xfile.path).
  • cacheWidth membuat Flutter men-decode gambar dalam ukuran kecil. Foto 1080 px yang ditampilkan sebagai thumbnail 100 px tidak perlu disimpan di memori dalam ukuran penuh. Untuk grid berisi puluhan foto, ini mencegah aplikasi kehabisan memori.
  • FileImage(file) adalah versi ImageProvider untuk widget yang meminta provider, seperti CircleAvatar dan DecorationImage.

Cache vs dokumen

FolderCara mendapatkanSifat
Cache / temporarygetTemporaryDirectory() (tempat hasil kamera dan galeri)Bisa dihapus sistem saat penyimpanan penuh
Dokumen aplikasigetApplicationDocumentsDirectory()Permanen sampai aplikasi di-uninstall atau datanya dihapus

Keduanya folder privat milik aplikasi: tidak butuh izin, dan foto di sini tidak muncul di aplikasi Galeri HP. Menyimpan ke galeri publik membutuhkan package lain dan izin tambahan, sehingga tidak dibahas di bab ini.

Langkah menyalin ke folder dokumen

  1. Ambil folder dokumen dengan path_provider, lalu buat subfolder (misalnya album) dengan Directory.create(recursive: true).
  2. Buat nama file unik, misalnya dari DateTime.now().millisecondsSinceEpoch, dan pertahankan ekstensinya dengan p.extension() dari package path.
  3. Salin dengan xfile.saveTo(tujuan) (atau File(path).copy(tujuan)).
  4. Simpan path atau nama filenya, bukan isi gambarnya, jika perlu dicatat di database (Hive, SQLite, atau Supabase).

Contoh lengkap: Album Praktikum

Aplikasi kecil untuk mendokumentasikan praktikum: tambah foto dari kamera atau galeri, foto tersimpan permanen, tekan lama untuk menghapus.

📄 lib/main.dart

// lib/main.dart
import 'dart:io';

import 'package:flutter/material.dart';
import 'package:image_picker/image_picker.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

void main() {
  runApp(
    MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const AlbumPage(),
    ),
  );
}

class AlbumPage extends StatefulWidget {
  const AlbumPage({super.key});

  @override
  State<AlbumPage> createState() => _AlbumPageState();
}

class _AlbumPageState extends State<AlbumPage> {
  final ImagePicker _picker = ImagePicker();
  List<File> _foto = [];

  @override
  void initState() {
    super.initState();
    _muat();
  }

  // Folder permanen milik aplikasi: <dokumen>/album
  Future<Directory> _folderAlbum() async {
    final dokumen = await getApplicationDocumentsDirectory();
    final folder = Directory(p.join(dokumen.path, 'album'));
    if (!await folder.exists()) {
      await folder.create(recursive: true);
    }
    return folder;
  }

  Future<void> _muat() async {
    final folder = await _folderAlbum();
    final daftar = folder.listSync().whereType<File>().toList()
      ..sort((a, b) => b.path.compareTo(a.path)); // terbaru di atas
    if (!mounted) return;
    setState(() => _foto = daftar);
  }

  Future<void> _tambah(ImageSource sumber) async {
    final XFile? hasil = await _picker.pickImage(
      source: sumber,
      maxWidth: 1080,
      imageQuality: 80,
    );
    if (hasil == null) return;

    final folder = await _folderAlbum();
    // Nama unik: waktu sekarang + ekstensi asli (.jpg / .png)
    final nama =
        'foto_${DateTime.now().millisecondsSinceEpoch}${p.extension(hasil.path)}';
    final tujuan = p.join(folder.path, nama);
    await hasil.saveTo(tujuan); // salin dari cache ke folder dokumen

    await _muat();
  }

  Future<void> _hapus(File file) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Hapus foto?'),
        content: Text(p.basename(file.path)),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    if (yakin != true) return;

    if (await file.exists()) {
      await file.delete();
    }
    await _muat();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Album Praktikum (${_foto.length})')),
      body: _foto.isEmpty
          ? const Center(child: Text('Belum ada foto. Tekan tombol +'))
          : GridView.builder(
              padding: const EdgeInsets.all(8),
              gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
                crossAxisCount: 3,
                mainAxisSpacing: 8,
                crossAxisSpacing: 8,
              ),
              itemCount: _foto.length,
              itemBuilder: (context, index) {
                final file = _foto[index];
                return GestureDetector(
                  onLongPress: () => _hapus(file),
                  child: ClipRRect(
                    borderRadius: BorderRadius.circular(8),
                    child: Image.file(
                      file,
                      fit: BoxFit.cover,
                      cacheWidth: 300, // decode kecil: hemat memori
                    ),
                  ),
                );
              },
            ),
      floatingActionButton: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          FloatingActionButton.small(
            heroTag: 'galeri',
            onPressed: () => _tambah(ImageSource.gallery),
            child: const Icon(Icons.photo_library),
          ),
          const SizedBox(height: 12),
          FloatingActionButton(
            heroTag: 'kamera',
            onPressed: () => _tambah(ImageSource.camera),
            child: const Icon(Icons.add_a_photo),
          ),
        ],
      ),
    );
  }
}

Penjelasan:

  • p.join menyusun path dengan pemisah yang benar di setiap platform. Hindari menyambung string dengan '/' secara manual.
  • folder.listSync().whereType<File>() membaca isi folder dan hanya mengambil file (bukan subfolder). Karena nama file diawali waktu dalam milidetik, mengurutkan berdasarkan path sama dengan mengurutkan berdasarkan waktu.
  • hasil.saveTo(tujuan) menyalin file dari cache ke folder dokumen. File di cache boleh dibiarkan, sistem akan membersihkannya.
  • Sebelum file.delete(), periksa dulu file.exists(). Menghapus file yang sudah tidak ada menghasilkan PathNotFoundException.
  • Setelah menambah atau menghapus, _muat() membaca ulang folder sehingga grid selalu sesuai isi penyimpanan. Tutup aplikasi lalu buka lagi: foto tetap ada.

⚠️ Foto lama masih tampil setelah diganti

Flutter menyimpan gambar yang sudah di-decode di imageCache berdasarkan path file. Jika kamu menimpa file dengan path yang sama (misalnya selalu profil.jpg), Image.file bisa tetap menampilkan gambar lama. Solusi paling sederhana: selalu simpan dengan nama baru (berisi waktu) lalu hapus file lama, seperti di studi kasus bagian 8. Alternatifnya, panggil FileImage(file).evict() setelah menimpa file.

💡 Menyimpan path, bukan path lengkap

Di iOS, path lengkap folder dokumen bisa berubah setelah aplikasi di-update (ID folder aplikasi berganti). Jika path foto disimpan di database, simpan nama file-nya saja, lalu gabungkan lagi dengan getApplicationDocumentsDirectory() saat akan ditampilkan.
