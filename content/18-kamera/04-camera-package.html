Package camera memberi kendali penuh: preview langsung di layar kita, tombol potret sendiri, ganti kamera depan/belakang, dan flash. Konsekuensinya, kita yang bertanggung jawab membuka dan menutup kamera dengan benar.

Empat langkah dasar

import 'package:camera/camera.dart';
import 'package:flutter/foundation.dart';

Future<void> contohDasar() async {
  // 1. Daftar kamera yang ada di perangkat
  final List<CameraDescription> kamera = await availableCameras();
  for (final k in kamera) {
    debugPrint('${k.name} - ${k.lensDirection}'); // back / front / external
  }

  // 2. Buat controller untuk kamera pertama, lalu inisialisasi
  final controller = CameraController(kamera.first, ResolutionPreset.medium);
  await controller.initialize();

  // 3. Ambil foto: hasilnya XFile di folder sementara
  final XFile foto = await controller.takePicture();
  debugPrint('Foto tersimpan di ${foto.path}');

  // 4. Selesai: lepaskan kamera
  await controller.dispose();
}

Pilihan ResolutionPreset: low, medium, high, veryHigh, ultraHigh, dan max. Untuk foto profil atau presensi, high (sekitar 720p) sudah cukup dan jauh lebih ringan daripada max.

Lifecycle: tanggung jawab kita sendiri

Di CameraX, bindToLifecycle otomatis mematikan kamera saat aplikasi diminimalkan. Package camera tidak melakukannya (sejak versi 0.5.0). Jika kamera tidak dilepas, aplikasi lain (misalnya WhatsApp) tidak bisa memakai kamera, dan saat aplikasi kita dibuka lagi preview bisa hitam. Solusi resmi dari dokumentasi package: dengarkan perubahan lifecycle dengan WidgetsBindingObserver, lepas kamera saat inactive, dan buka lagi saat resumed.

Contoh lengkap: kamera dengan flash dan ganti kamera

📄 lib/main.dart

// lib/main.dart
import 'dart:io';

import 'package:camera/camera.dart';
import 'package:flutter/material.dart';

void main() {
  runApp(
    const MaterialApp(debugShowCheckedModeBanner: false, home: KameraPage()),
  );
}

class KameraPage extends StatefulWidget {
  const KameraPage({super.key});

  @override
  State<KameraPage> createState() => _KameraPageState();
}

class _KameraPageState extends State<KameraPage> with WidgetsBindingObserver {
  List<CameraDescription> _daftarKamera = [];
  int _indeksKamera = 0;
  CameraController? _controller;
  FlashMode _flash = FlashMode.off;
  XFile? _hasil;
  String? _pesan;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this); // dengarkan lifecycle aplikasi
    _siapkan();
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _controller?.dispose(); // WAJIB: lepaskan kamera
    super.dispose();
  }

  Future<void> _siapkan() async {
    try {
      _daftarKamera = await availableCameras();
    } on CameraException catch (e) {
      _tampilkanPesan('Gagal membaca daftar kamera: ${e.code}');
      return;
    }
    if (_daftarKamera.isEmpty) {
      _tampilkanPesan('Perangkat ini tidak punya kamera.');
      return;
    }
    await _bukaKamera(_daftarKamera[_indeksKamera]);
  }

  Future<void> _bukaKamera(CameraDescription kamera) async {
    final controller = CameraController(
      kamera,
      ResolutionPreset.high,
      enableAudio: false, // hanya foto, tidak perlu izin mikrofon
      imageFormatGroup: ImageFormatGroup.jpeg,
    );
    setState(() {
      _controller = controller;
      _pesan = null;
    });

    try {
      await controller.initialize();
    } on CameraException catch (e) {
      _tampilkanPesan(switch (e.code) {
        'CameraAccessDenied' => 'Izin kamera ditolak.',
        'CameraAccessDeniedWithoutPrompt' =>
          'Izin kamera ditolak permanen. Aktifkan lewat Pengaturan.',
        'CameraAccessRestricted' => 'Akses kamera dibatasi perangkat.',
        _ => 'Kamera error: ${e.description}',
      });
      return;
    }
    await _aturFlash(_flash);
    if (mounted) setState(() {});
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    final controller = _controller;
    if (state == AppLifecycleState.inactive) {
      // Aplikasi ke latar belakang: lepaskan kamera untuk aplikasi lain
      if (controller == null || !controller.value.isInitialized) return;
      setState(() => _controller = null);
      controller.dispose();
    } else if (state == AppLifecycleState.resumed) {
      // Kembali ke depan: buka lagi kamera yang terakhir dipakai
      if (controller == null && _daftarKamera.isNotEmpty) {
        _bukaKamera(_daftarKamera[_indeksKamera]);
      }
    }
  }

  Future<void> _potret() async {
    final controller = _controller;
    if (controller == null ||
        !controller.value.isInitialized ||
        controller.value.isTakingPicture) {
      return;
    }
    try {
      final XFile foto = await controller.takePicture();
      if (!mounted) return;
      setState(() => _hasil = foto);
    } on CameraException catch (e) {
      _tampilkanPesan('Gagal memotret: ${e.description}');
    }
  }

  Future<void> _gantiKamera() async {
    final controller = _controller;
    if (controller == null || _daftarKamera.length < 2) return;
    // Cari kamera yang arah lensanya berbeda (depan <-> belakang)
    final arahSekarang = _daftarKamera[_indeksKamera].lensDirection;
    final indeksBaru = _daftarKamera.indexWhere(
      (k) => k.lensDirection != arahSekarang,
    );
    if (indeksBaru == -1) return;
    _indeksKamera = indeksBaru;
    try {
      await controller.setDescription(_daftarKamera[indeksBaru]);
    } on CameraException catch (e) {
      _tampilkanPesan('Gagal mengganti kamera: ${e.description}');
    }
    if (mounted) setState(() {});
  }

  Future<void> _aturFlash(FlashMode mode) async {
    final controller = _controller;
    if (controller == null || !controller.value.isInitialized) return;
    try {
      await controller.setFlashMode(mode);
      _flash = mode;
    } on CameraException {
      // Kamera depan biasanya tidak punya flash: abaikan saja
    }
    if (mounted) setState(() {});
  }

  void _gilirFlash() {
    final berikutnya = switch (_flash) {
      FlashMode.off => FlashMode.auto,
      FlashMode.auto => FlashMode.always,
      _ => FlashMode.off,
    };
    _aturFlash(berikutnya);
  }

  void _tampilkanPesan(String pesan) {
    if (!mounted) return;
    setState(() => _pesan = pesan);
  }

  @override
  Widget build(BuildContext context) {
    final controller = _controller;
    final siap = controller != null && controller.value.isInitialized;

    return Scaffold(
      backgroundColor: Colors.black,
      appBar: AppBar(title: const Text('Kamera di Dalam Aplikasi')),
      body: Column(
        children: [
          Expanded(
            child: Center(
              child: _pesan != null
                  ? Padding(
                      padding: const EdgeInsets.all(24),
                      child: Text(
                        _pesan!,
                        textAlign: TextAlign.center,
                        style: const TextStyle(color: Colors.white),
                      ),
                    )
                  : siap
                  // CameraPreview sudah membungkus dirinya dengan
                  // AspectRatio yang benar, jadi jangan dipaksa memenuhi layar
                  ? CameraPreview(controller)
                  : const CircularProgressIndicator(),
            ),
          ),
          Container(
            color: Colors.black,
            padding: const EdgeInsets.symmetric(vertical: 16),
            child: Row(
              mainAxisAlignment: MainAxisAlignment.spaceEvenly,
              children: [
                IconButton(
                  onPressed: siap ? _gilirFlash : null,
                  color: Colors.white,
                  icon: Icon(switch (_flash) {
                    FlashMode.auto => Icons.flash_auto,
                    FlashMode.always => Icons.flash_on,
                    _ => Icons.flash_off,
                  }),
                ),
                FloatingActionButton.large(
                  onPressed: siap ? _potret : null,
                  child: const Icon(Icons.camera),
                ),
                IconButton(
                  onPressed: siap && _daftarKamera.length > 1
                      ? _gantiKamera
                      : null,
                  color: Colors.white,
                  icon: const Icon(Icons.cameraswitch),
                ),
              ],
            ),
          ),
          if (_hasil != null)
            Container(
              color: Colors.black,
              height: 96,
              padding: const EdgeInsets.only(bottom: 16),
              child: Image.file(File(_hasil!.path)),
            ),
        ],
      ),
    );
  }
}

Penjelasan baris penting:

  • with WidgetsBindingObserver + addObserver(this) di initState membuat method didChangeAppLifecycleState dipanggil setiap aplikasi berpindah ke latar belakang atau kembali. Jangan lupa removeObserver di dispose.
  • Saat inactive, controller dilepas dan _controller dijadikan null lewat setState, sehingga build() tidak lagi memakai controller yang sudah di-dispose. Saat resumed, kamera yang sama dibuka lagi.
  • Pengecekan !controller.value.isInitialized di bagian inactive itu penting: dialog izin kamera juga membuat aplikasi sesaat menjadi inactive. Tanpa pengecekan ini, kamera dilepas di tengah proses inisialisasi.
  • enableAudio: false karena kita hanya memotret. Tanpa ini, plugin juga meminta izin mikrofon.
  • CameraException dari initialize() ditangani berdasarkan e.code, sesuai daftar kode di dokumentasi package.
  • setDescription() mengganti kamera tanpa membuat controller baru, cara yang sama dengan contoh resmi package. Kamera tujuan dicari berdasarkan lensDirection yang berbeda (front ↔ back).
  • setFlashMode dibungkus try karena kamera depan umumnya tidak punya flash. Mode yang tersedia: off, auto, always, dan torch (senter menyala terus).
  • controller.value.isTakingPicture mencegah pengguna menekan tombol potret berkali-kali sebelum foto sebelumnya selesai. Memanggil takePicture() dua kali bersamaan menghasilkan CameraException.
  • CameraPreview diletakkan di dalam Center tanpa dipaksa memenuhi layar. Widget ini sudah membungkus dirinya dengan AspectRatio yang sesuai orientasi, sehingga gambar tidak gepeng.

ℹ️ Overlay di atas preview

CameraPreview punya parameter child yang ditumpuk di atas gambar kamera dengan ukuran yang sama persis. Gunakan untuk bingkai wajah, garis bantu, atau petunjuk teks. Contohnya ada di KameraView pada studi kasus bagian 8.

⚠️ Kesalahan umum

  • Lupa controller.dispose() di dispose(): kamera tetap terkunci, baterai boros, dan aplikasi kamera lain menampilkan "kamera sedang dipakai".
  • Memanggil CameraPreview(controller) sebelum initialize() selesai. Selalu periksa controller.value.isInitialized.
  • Memaksa CameraPreview memenuhi layar dengan SizedBox.expand atau ukuran tetap sembarang, sehingga gambar gepeng atau melar. Cara yang benar untuk preview penuh layar ada di bagian 9.
  • Menguji ganti kamera di emulator yang hanya punya satu kamera, lalu mengira kodenya salah.
