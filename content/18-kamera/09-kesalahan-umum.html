Preview penuh layar tanpa gepeng

import 'package:camera/camera.dart';
import 'package:flutter/material.dart';

/// Preview memenuhi layar tanpa gepeng: sisi yang berlebih dipotong.
Widget previewPenuhLayar(CameraController controller) {
  // previewSize dilaporkan dalam orientasi sensor (landscape),
  // jadi lebar dan tinggi ditukar untuk layar portrait.
  final ukuran = controller.value.previewSize!;
  return SizedBox.expand(
    child: FittedBox(
      fit: BoxFit.cover,
      child: SizedBox(
        width: ukuran.height,
        height: ukuran.width,
        child: CameraPreview(controller),
      ),
    ),
  );
}

FittedBox dengan BoxFit.cover memperbesar preview sampai menutupi seluruh layar dengan rasio tetap, lalu memotong sisi yang berlebih. Lebar dan tinggi ditukar karena sensor kamera melaporkan ukuran dalam posisi landscape. Ingat bahwa bagian yang terpotong tetap ada di foto hasil takePicture().

Pengembangan: memindai QR dan barcode dengan mobile_scanner

Untuk presensi berbasis QR, kartu perpustakaan, atau inventaris lab, kamu tidak perlu mengolah frame kamera sendiri. Package mobile_scanner (Android memakai ML Kit, iOS memakai Apple Vision) sudah menyediakan widget pemindai lengkap. Pasang dengan flutter pub add mobile_scanner, tambahkan NSCameraUsageDescription di iOS, lalu:

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:mobile_scanner/mobile_scanner.dart';

void main() {
  runApp(
    const MaterialApp(debugShowCheckedModeBanner: false, home: PindaiQrPage()),
  );
}

class PindaiQrPage extends StatefulWidget {
  const PindaiQrPage({super.key});

  @override
  State<PindaiQrPage> createState() => _PindaiQrPageState();
}

class _PindaiQrPageState extends State<PindaiQrPage> {
  final MobileScannerController _scanner = MobileScannerController(
    detectionSpeed: DetectionSpeed.noDuplicates, // satu kode dilaporkan sekali
    formats: const [BarcodeFormat.qrCode],
  );
  String? _hasil;

  @override
  void dispose() {
    _scanner.dispose();
    super.dispose();
  }

  void _saatTerdeteksi(BarcodeCapture capture) {
    final kode = capture.barcodes.firstOrNull?.rawValue;
    if (kode == null) return;
    setState(() => _hasil = kode);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Pindai QR Presensi'),
        actions: [
          IconButton(
            onPressed: _scanner.toggleTorch,
            icon: const Icon(Icons.flashlight_on),
          ),
        ],
      ),
      body: Column(
        children: [
          Expanded(
            child: MobileScanner(
              controller: _scanner,
              onDetect: _saatTerdeteksi,
            ),
          ),
          Padding(
            padding: const EdgeInsets.all(16),
            child: Text(_hasil ?? 'Arahkan kamera ke kode QR'),
          ),
        ],
      ),
    );
  }
}
  • MobileScanner adalah widget preview + pendeteksi. Callback onDetect menerima BarcodeCapture yang berisi daftar barcodes, dan isi kodenya ada di rawValue.
  • DetectionSpeed.noDuplicates mencegah kode yang sama dilaporkan berulang-ulang selama masih di depan kamera.
  • formats membatasi jenis kode yang dicari (di sini hanya QR) sehingga deteksi lebih cepat.
  • Berbeda dengan package camera, widget MobileScanner secara default (useAppLifecycleState: true) menghentikan dan menyalakan lagi kamera saat aplikasi berpindah ke latar belakang. Kita cukup memanggil dispose() pada controller. Jangan memakai mobile_scanner dan camera pada layar yang sama, karena keduanya berebut kamera.
  • Uji di emulator dengan kamera VirtualScene: ganti gambar dinding di Extended Controls → Camera dengan gambar QR, lalu "berjalan" ke arahnya.

Ringkasan bab

  • image_picker (setara Intent) untuk kamera sistem dan galeri; camera (setara CameraX) untuk kamera di dalam aplikasi.
  • Kompres saat mengambil (maxWidth, imageQuality), decode kecil saat menampilkan (cacheWidth).
  • CameraController: initialize → CameraPreview → takePicture → dispose, plus lifecycle lewat WidgetsBindingObserver.
  • Foto hasil ada di cache: salin ke folder dokumen dengan nama unik, hapus dengan File.delete().
  • Supabase Storage: upload/uploadBinary, getPublicUrl (public) atau createSignedUrl (private), dilindungi policy per folder user.
  • MVC GetX: service membungkus plugin, controller menyimpan state dan mengembalikan hasil aksi, view menampilkan dengan Obx dan mengurus dialog.
