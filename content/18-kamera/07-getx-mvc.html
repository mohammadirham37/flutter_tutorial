Contoh Album Praktikum di bagian 5 masih menaruh semuanya di satu State: memanggil plugin, mengurus file, dan menggambar UI. Sekarang kita pecah dengan pola MVC GetX dari Modul 08: service membungkus image_picker dan file sistem, controller menyimpan state .obs, dan view hanya menampilkan dengan Obx.

Langkah 1: Service

📄 lib/services/foto_service.dart

// lib/services/foto_service.dart
// SERVICE: satu-satunya tempat yang menyentuh image_picker dan file sistem.
import 'dart:io';

import 'package:flutter/services.dart';
import 'package:image_picker/image_picker.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

/// Sumber foto versi aplikasi kita, agar controller tidak bergantung
/// langsung pada enum ImageSource milik image_picker.
enum SumberFoto { kamera, galeri }

class FotoException implements Exception {
  const FotoException(this.pesan);
  final String pesan;

  @override
  String toString() => pesan;
}

class FotoService {
  final ImagePicker _picker = ImagePicker();

  Future<Directory> _folderAlbum() async {
    final dokumen = await getApplicationDocumentsDirectory();
    return Directory(p.join(dokumen.path, 'album')).create(recursive: true);
  }

  /// Semua foto di album, terbaru lebih dulu.
  Future<List<File>> semua() async {
    final folder = await _folderAlbum();
    final daftar = await folder.list().where((e) => e is File).toList();
    return daftar.cast<File>()..sort((a, b) => b.path.compareTo(a.path));
  }

  /// Mengambil foto lalu menyalinnya ke album.
  /// Mengembalikan null jika pengguna membatalkan.
  Future<File?> ambil(SumberFoto sumber) async {
    final XFile? hasil;
    try {
      hasil = await _picker.pickImage(
        source: sumber == SumberFoto.kamera
            ? ImageSource.camera
            : ImageSource.gallery,
        maxWidth: 1080,
        imageQuality: 80,
      );
    } on PlatformException catch (e) {
      throw FotoException(
        e.code == 'camera_access_denied'
            ? 'Izin kamera ditolak.'
            : 'Gagal mengambil foto (${e.code}).',
      );
    }
    if (hasil == null) return null;

    final folder = await _folderAlbum();
    final nama =
        'foto_${DateTime.now().millisecondsSinceEpoch}${p.extension(hasil.path)}';
    final tujuan = p.join(folder.path, nama);
    await hasil.saveTo(tujuan);
    return File(tujuan);
  }

  Future<void> hapus(File file) async {
    if (await file.exists()) {
      await file.delete();
    }
  }
}
  • Enum SumberFoto milik kita sendiri menyembunyikan ImageSource. Jika kelak service diganti (misalnya memakai package camera), controller dan view tidak ikut berubah.
  • PlatformException dari plugin diterjemahkan menjadi FotoException berisi pesan Bahasa Indonesia. Controller cukup menangkap satu jenis exception.
  • folder.list() adalah versi async dari listSync(), sehingga UI tidak tersendat saat folder berisi banyak file.

Langkah 2: Controller

📄 lib/controllers/album_controller.dart

// lib/controllers/album_controller.dart
// CONTROLLER: state reaktif + logika. Tidak mengimpor material.dart.
import 'dart:io';

import 'package:get/get.dart';

import '../services/foto_service.dart';

class AlbumController extends GetxController {
  AlbumController(this._service);
  final FotoService _service;

  final _foto = <File>[].obs;
  final _sibuk = false.obs;

  List<File> get foto => _foto;
  bool get sibuk => _sibuk.value;

  @override
  void onInit() {
    super.onInit();
    muat();
  }

  Future<void> muat() async {
    _foto.assignAll(await _service.semua());
  }

  /// Mengembalikan pesan error, atau null jika berhasil/dibatalkan.
  Future<String?> tambah(SumberFoto sumber) async {
    if (_sibuk.value) return null; // cegah tekan tombol dua kali
    _sibuk.value = true;
    try {
      final file = await _service.ambil(sumber);
      if (file != null) {
        _foto.insert(0, file); // langsung tampil tanpa membaca ulang folder
      }
      return null;
    } on FotoException catch (e) {
      return e.pesan;
    } finally {
      _sibuk.value = false;
    }
  }

  Future<void> hapus(File file) async {
    await _service.hapus(file);
    _foto.remove(file);
  }
}
  • _foto berupa RxList<File>. Method insert, remove, dan assignAll pada RxList otomatis memberi tahu Obx.
  • _sibuk mencegah dua pemanggilan kamera bersamaan dan dipakai view untuk menampilkan indikator loading.
  • tambah() mengembalikan pesan error (atau null) alih-alih menampilkan SnackBar sendiri, karena SnackBar butuh BuildContext yang menjadi urusan view.

Langkah 3: View

📄 lib/views/album_view.dart

// lib/views/album_view.dart
// VIEW: hanya menampilkan state dan meneruskan aksi ke controller.
import 'dart:io';

import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:path/path.dart' as p;

import '../controllers/album_controller.dart';
import '../services/foto_service.dart';

class AlbumView extends GetView<AlbumController> {
  const AlbumView({super.key});

  Future<void> _tambah(BuildContext context, SumberFoto sumber) async {
    final error = await controller.tambah(sumber);
    if (error == null || !context.mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(error)));
  }

  Future<void> _konfirmasiHapus(BuildContext context, File file) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Hapus foto?'),
        content: Text(p.basename(file.path)),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    if (yakin == true) await controller.hapus(file);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Obx(() => Text('Album Praktikum (${controller.foto.length})')),
      ),
      body: Obx(() {
        final daftar = controller.foto;
        if (daftar.isEmpty) {
          return const Center(child: Text('Belum ada foto. Tekan tombol +'));
        }
        return GridView.builder(
          padding: const EdgeInsets.all(8),
          gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
            crossAxisCount: 3,
            mainAxisSpacing: 8,
            crossAxisSpacing: 8,
          ),
          itemCount: daftar.length,
          itemBuilder: (context, index) {
            final file = daftar[index];
            return GestureDetector(
              onLongPress: () => _konfirmasiHapus(context, file),
              child: ClipRRect(
                borderRadius: BorderRadius.circular(8),
                child: Image.file(file, fit: BoxFit.cover, cacheWidth: 300),
              ),
            );
          },
        );
      }),
      floatingActionButton: Obx(
        () => controller.sibuk
            ? const FloatingActionButton(
                onPressed: null,
                child: CircularProgressIndicator(),
              )
            : Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  FloatingActionButton.small(
                    heroTag: 'galeri',
                    onPressed: () => _tambah(context, SumberFoto.galeri),
                    child: const Icon(Icons.photo_library),
                  ),
                  const SizedBox(height: 12),
                  FloatingActionButton(
                    heroTag: 'kamera',
                    onPressed: () => _tambah(context, SumberFoto.kamera),
                    child: const Icon(Icons.add_a_photo),
                  ),
                ],
              ),
      ),
    );
  }
}

Langkah 4: main.dart

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/album_controller.dart';
import 'services/foto_service.dart';
import 'views/album_view.dart';

void main() {
  // Wajib sebelum memakai plugin (path_provider) di onInit controller
  WidgetsFlutterBinding.ensureInitialized();
  Get.put(AlbumController(FotoService()));
  runApp(
    GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const AlbumView(),
    ),
  );
}

Penjelasan:

  • WidgetsFlutterBinding.ensureInitialized() wajib di sini karena Get.put langsung menjalankan onInit(), yang memanggil path_provider (plugin) sebelum runApp.
  • View memakai GetView<AlbumController> sehingga getter controller langsung tersedia. Hanya judul, grid, dan tombol yang dibungkus Obx.
  • Setelah await controller.tambah(...), view memeriksa context.mounted sebelum menampilkan SnackBar.

⚠️ Bentrok nama CameraController

Package camera sudah punya kelas bernama CameraController. Jika kamu membuat class CameraController extends GetxController, kedua nama bertabrakan dan muncul error ambiguous import. Beri nama lain seperti KameraController atau FotoController. Untuk alasan yang sama, di studi kasus CameraController milik package camera tetap dikelola di StatefulWidget (KameraView): ia terikat erat dengan widget preview dan lifecycle layar, sementara GetxController hanya menerima path hasil foto.
