image_picker adalah cara tercepat untuk mendapatkan foto: satu method untuk membuka kamera sistem atau galeri, dan hasilnya langsung berupa file.

Contoh kecil

import 'package:flutter/foundation.dart';
import 'package:image_picker/image_picker.dart';

Future<void> contohKecil() async {
  final picker = ImagePicker();

  // Buka kamera sistem
  final XFile? foto = await picker.pickImage(source: ImageSource.camera);

  // Buka galeri
  final XFile? dariGaleri = await picker.pickImage(source: ImageSource.gallery);

  if (foto != null) {
    debugPrint(foto.path); // lokasi file di folder cache aplikasi
  }
  debugPrint('Dari galeri: ${dariGaleri?.name}');
}

Hasilnya bertipe XFile?. Nilainya null jika pengguna menekan tombol kembali atau batal, jadi selalu periksa null sebelum memakainya.

Parameter penting pickImage

ParameterFungsi
sourceImageSource.camera atau ImageSource.gallery
maxWidth, maxHeightMemperkecil gambar agar lebar/tinggi tidak melebihi nilai ini (rasio tetap). Foto HP modern bisa 4000 px lebih; 1080 px sudah cukup untuk layar
imageQualityKualitas kompresi 0–100. Nilai 70–85 biasanya tidak terlihat bedanya tetapi ukurannya jauh lebih kecil
preferredCameraDeviceCameraDevice.rear atau CameraDevice.front. Hanya saran: banyak aplikasi kamera Android mengabaikannya
requestFullMetadataDefault true. Jika false, iOS tidak perlu meminta izin galeri penuh, tetapi data EXIF (lokasi, waktu) tidak ikut

Contoh lengkap: kamera dan galeri

📄 lib/main.dart

// lib/main.dart
import 'dart:io';

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:image_picker/image_picker.dart';

void main() {
  runApp(
    const MaterialApp(debugShowCheckedModeBanner: false, home: AmbilFotoPage()),
  );
}

class AmbilFotoPage extends StatefulWidget {
  const AmbilFotoPage({super.key});

  @override
  State<AmbilFotoPage> createState() => _AmbilFotoPageState();
}

class _AmbilFotoPageState extends State<AmbilFotoPage> {
  // Satu objek ImagePicker cukup untuk seluruh halaman
  final ImagePicker _picker = ImagePicker();

  XFile? _foto;
  int? _ukuranByte;

  Future<void> _ambil(ImageSource sumber) async {
    try {
      final XFile? hasil = await _picker.pickImage(
        source: sumber,
        maxWidth: 1080, // perkecil sisi terpanjang menjadi maks. 1080 px
        imageQuality: 80, // kompresi JPEG 0-100
        preferredCameraDevice: CameraDevice.rear,
      );
      if (hasil == null) return; // pengguna menekan Batal / kembali

      final ukuran = await hasil.length();
      if (!mounted) return;
      setState(() {
        _foto = hasil;
        _ukuranByte = ukuran;
      });
    } on PlatformException catch (e) {
      if (!mounted) return;
      final pesan = e.code == 'camera_access_denied'
          ? 'Izin kamera ditolak. Aktifkan di Pengaturan.'
          : 'Gagal mengambil foto: ${e.message}';
      ScaffoldMessenger.of(context)
          .showSnackBar(SnackBar(content: Text(pesan)));
    }
  }

  @override
  Widget build(BuildContext context) {
    final foto = _foto;
    return Scaffold(
      appBar: AppBar(title: const Text('image_picker')),
      body: Column(
        children: [
          Expanded(
            child: Center(
              child: foto == null
                  ? const Text('Belum ada foto')
                  : Image.file(File(foto.path), fit: BoxFit.contain),
            ),
          ),
          if (_ukuranByte != null)
            Text('Ukuran: ${(_ukuranByte! / 1024).toStringAsFixed(1)} KB'),
          Padding(
            padding: const EdgeInsets.all(16),
            child: Row(
              children: [
                Expanded(
                  child: FilledButton.icon(
                    onPressed: () => _ambil(ImageSource.camera),
                    icon: const Icon(Icons.photo_camera),
                    label: const Text('Kamera'),
                  ),
                ),
                const SizedBox(width: 12),
                Expanded(
                  child: OutlinedButton.icon(
                    onPressed: () => _ambil(ImageSource.gallery),
                    icon: const Icon(Icons.photo_library),
                    label: const Text('Galeri'),
                  ),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}

Penjelasan:

  • ImagePicker dibuat sekali sebagai field State, bukan di dalam build().
  • maxWidth: 1080 dan imageQuality: 80 membuat foto kamera yang aslinya bisa 3–8 MB menjadi sekitar 100–300 KB. Ukuran ditampilkan lewat hasil.length() agar kamu bisa membandingkannya sendiri.
  • if (!mounted) return; setelah setiap await: pengguna bisa saja menutup halaman selagi kamera terbuka.
  • PlatformException dengan kode camera_access_denied muncul jika izin kamera ditolak. Di bagian 8 kita menggantinya dengan alur izin lengkap memakai permission_handler.
  • Image.file(File(foto.path)) menampilkan file dari penyimpanan perangkat. Pembahasan lengkapnya di bagian 5.

Memilih banyak foto sekaligus

import 'package:image_picker/image_picker.dart';

final ImagePicker _picker = ImagePicker();

Future<List<XFile>> ambilBanyak() async {
  // Maksimal 5 foto sekaligus dari galeri
  final List<XFile> daftar = await _picker.pickMultiImage(
    maxWidth: 1080,
    imageQuality: 80,
    limit: 5,
  );
  return daftar; // list kosong jika pengguna membatalkan
}

Future<XFile?> pulihkanFotoHilang() async {
  final LostDataResponse respons = await _picker.retrieveLostData();
  if (respons.isEmpty) return null; // tidak ada yang hilang

  final List<XFile>? files = respons.files;
  if (files != null && files.isNotEmpty) {
    return files.first; // foto yang sempat diambil sebelum aplikasi dimatikan
  }
  // Jika gagal, exception-nya ada di respons.exception
  throw respons.exception!;
}
  • pickMultiImage selalu dari galeri dan mengembalikan List<XFile> (bukan nullable). List kosong berarti pengguna membatalkan.
  • limit membatasi jumlah foto yang boleh dipilih, berguna untuk lampiran laporan yang dibatasi (misalnya maksimal 5 foto).

Foto hilang di Android: retrieveLostData

Saat aplikasi kamera sistem terbuka, aplikasi kita berpindah ke latar belakang. Di HP dengan RAM kecil, Android bisa mematikan aplikasi kita untuk menghemat memori. Setelah pengguna selesai memotret, Android menjalankan ulang aplikasi kita dari awal, sehingga await pickImage() yang lama tidak pernah menerima hasilnya. Foto itu tidak benar-benar hilang: panggil retrieveLostData() (fungsi pulihkanFotoHilang di atas) sekali saat aplikasi dimulai untuk mengambilnya. Di iOS method ini tidak diperlukan.

💡 Cara menguji

Buka Developer options di HP atau emulator, aktifkan Don't keep activities. Setiap aplikasi yang ditinggalkan akan langsung dimatikan, sehingga kasus foto hilang selalu terjadi. Matikan lagi setelah selesai menguji.

⚠️ Kesalahan umum

  • Memakai foto! tanpa memeriksa null: aplikasi crash saat pengguna menekan batal.
  • Tidak memberi maxWidth/imageQuality: foto berukuran megabyte membuat daftar foto patah-patah dan unggahan lambat.
  • Menganggap foto dari image_picker tersimpan permanen. File ada di folder cache yang bisa dibersihkan sistem kapan saja. Salin ke folder dokumen (bagian 5) jika perlu disimpan.
