FutureBuilder cocok untuk satu layar sederhana. Namun jika data yang sama dipakai banyak layar (daftar, detail, form) dan bisa berubah (tambah/hapus), simpan data di Provider (Modul 08). Provider menyimpan tiga hal: status (loading/error/sukses), pesan error, dan data.

Konsep: State Hasil Request

enum LoadStatus { initial, loading, success, error }

Dengan enum, UI cukup memakai switch pada status. Ini lebih jelas daripada beberapa variabel bool yang bisa saling bertentangan (misalnya isLoading dan hasError sama-sama true).

Langkah 1: Provider

Provider memakai PostRepository dari section 9, sehingga tidak perlu tahu soal HTTP.

📄 lib/providers/post_provider.dart

import 'package:flutter/foundation.dart';

import '../models/post.dart';
import '../repositories/post_repository.dart';

enum LoadStatus { initial, loading, success, error }

class PostProvider extends ChangeNotifier {
  final PostRepository _repo;
  PostProvider(this._repo);

  List<Post> _posts = [];
  LoadStatus _status = LoadStatus.initial;
  String? _errorMessage;

  List<Post> get posts => List.unmodifiable(_posts); // UI tidak bisa mengubah langsung
  LoadStatus get status => _status;
  String? get errorMessage => _errorMessage;

  Future<void> fetchPosts() async {
    _status = LoadStatus.loading;
    _errorMessage = null;
    notifyListeners(); // UI menampilkan loading

    try {
      _posts = await _repo.getAll();
      _status = LoadStatus.success;
    } catch (e) {
      _errorMessage = e.toString();
      _status = LoadStatus.error;
    }
    notifyListeners(); // UI menampilkan data atau error
  }

  /// Optimistic delete: hapus dulu dari layar, kembalikan jika server gagal.
  Future<bool> deletePost(Post post) async {
    final index = _posts.indexOf(post);
    _posts.removeAt(index);
    notifyListeners();
    try {
      await _repo.delete(post.id!);
      return true;
    } catch (e) {
      _posts.insert(index, post); // rollback
      notifyListeners();
      return false;
    }
  }
}

Penjelasan: notifyListeners() dipanggil dua kali di fetchPosts: sekali sebelum request (agar spinner muncul), sekali setelah selesai. Pada deletePost kita memakai pola optimistic update: item langsung hilang sehingga aplikasi terasa cepat, lalu dikembalikan jika server menolak.

Langkah 2: Daftarkan Provider dan Panggil Data Pertama

Pasang package: flutter pub add provider. Operator ..fetchPosts() (cascade) memanggil fetch tepat saat provider dibuat.

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import 'core/api_client.dart';
import 'providers/post_provider.dart';
import 'repositories/post_repository.dart';

Widget buatApp(Widget home) {
  return ChangeNotifierProvider(
    create: (_) => PostProvider(
      RemotePostRepository(ApiClient(baseUrl: 'https://jsonplaceholder.typicode.com')),
    )..fetchPosts(),
    child: MaterialApp(home: home),
  );
}

Langkah 3: Contoh Lengkap

📄 lib/main.dart

// Butuh: flutter pub add http provider
// File: models/post.dart, core/api_exception.dart, core/api_client.dart,
//       repositories/post_repository.dart, providers/post_provider.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import 'core/api_client.dart';
import 'providers/post_provider.dart';
import 'repositories/post_repository.dart';

void main() {
  final repo = RemotePostRepository(
    ApiClient(baseUrl: 'https://jsonplaceholder.typicode.com'),
  );
  runApp(
    ChangeNotifierProvider(
      create: (_) => PostProvider(repo)..fetchPosts(),
      child: const MaterialApp(home: PostProviderScreen()),
    ),
  );
}

class PostProviderScreen extends StatelessWidget {
  const PostProviderScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final provider = context.watch<PostProvider>();

    final Widget body = switch (provider.status) {
      LoadStatus.initial || LoadStatus.loading =>
        const Center(child: CircularProgressIndicator()),
      LoadStatus.error => Center(
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              Text(provider.errorMessage ?? 'Terjadi kesalahan'),
              const SizedBox(height: 12),
              FilledButton(
                onPressed: () => context.read<PostProvider>().fetchPosts(),
                child: const Text('Coba Lagi'),
              ),
            ],
          ),
        ),
      LoadStatus.success => RefreshIndicator(
          onRefresh: () => context.read<PostProvider>().fetchPosts(),
          child: ListView.builder(
            itemCount: provider.posts.length,
            itemBuilder: (context, i) {
              final post = provider.posts[i];
              return Dismissible(
                key: ValueKey(post.id),
                direction: DismissDirection.endToStart,
                background: Container(
                  color: Colors.red,
                  alignment: Alignment.centerRight,
                  padding: const EdgeInsets.only(right: 20),
                  child: const Icon(Icons.delete, color: Colors.white),
                ),
                onDismissed: (_) async {
                  final messenger = ScaffoldMessenger.of(context);
                  final ok = await context.read<PostProvider>().deletePost(post);
                  messenger.showSnackBar(SnackBar(
                    content: Text(ok ? 'Post ${post.id} dihapus' : 'Gagal menghapus, data dikembalikan'),
                  ));
                },
                child: ListTile(
                  leading: CircleAvatar(child: Text('${post.id}')),
                  title: Text(post.title, maxLines: 1, overflow: TextOverflow.ellipsis),
                  subtitle: Text(post.body, maxLines: 1, overflow: TextOverflow.ellipsis),
                ),
              );
            },
          ),
        ),
    };

    return Scaffold(
      appBar: AppBar(title: Text('Post (${provider.posts.length})')),
      body: body,
    );
  }
}
Status success: daftar post dari PostProvider

Penjelasan:

  • context.watch di build membuat layar ikut berubah setiap notifyListeners(). Di dalam callback tombol, gunakan context.read.
  • switch expression memaksa kita menangani semua nilai enum; jika ada status baru yang lupa ditangani, analyzer langsung memberi error.
  • ScaffoldMessenger.of(context) disimpan ke variabel sebelum await, sehingga aman dipakai setelahnya.
  • Geser item ke kiri untuk menghapus. Karena JSONPlaceholder selalu menjawab sukses, rollback hanya terlihat jika internet dimatikan.

⚠️ Kesalahan Umum

  • Memanggil fetchPosts() di dalam build(): memicu loop rebuild tanpa akhir. Panggil di create provider atau initState.
  • Lupa notifyListeners() setelah mengubah data, sehingga UI tidak berubah.
  • Mengembalikan list internal secara langsung (get posts => _posts) lalu UI mengubahnya tanpa notifyListeners.
  • Memakai context.watch di dalam onPressed: error, gunakan context.read.
