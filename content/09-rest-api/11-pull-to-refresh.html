Pengguna terbiasa menarik layar ke bawah untuk memuat ulang data (Instagram, Gmail). Di Flutter, gestur ini disediakan widget RefreshIndicator.

Konsep

  • RefreshIndicator membungkus widget yang bisa di-scroll (ListView, CustomScrollView).
  • Parameter onRefresh wajib mengembalikan Future. Spinner tetap tampil sampai Future itu selesai.
  • Child harus bisa di-scroll meskipun isinya sedikit. Gunakan physics: const AlwaysScrollableScrollPhysics().

Contoh Kecil

import 'package:flutter/material.dart';

class AngkaAcak extends StatefulWidget {
  const AngkaAcak({super.key});

  @override
  State<AngkaAcak> createState() => _AngkaAcakState();
}

class _AngkaAcakState extends State<AngkaAcak> {
  int _versi = 1;

  Future<void> _refresh() async {
    await Future.delayed(const Duration(seconds: 1)); // pura-pura memanggil API
    setState(() => _versi++);
  }

  @override
  Widget build(BuildContext context) {
    return RefreshIndicator(
      onRefresh: _refresh,
      child: ListView(
        physics: const AlwaysScrollableScrollPhysics(),
        children: [ListTile(title: Text('Data versi $_versi'))],
      ),
    );
  }
}

Contoh Lengkap: FutureBuilder + Pull-to-Refresh

Memakai Post (section 3) dan PostService (section 5). Kuncinya: _refresh() membuat Future baru, menyimpannya lewat setState, lalu menunggu Future yang sama agar spinner RefreshIndicator berhenti tepat ketika data tiba.

📄 lib/main.dart

// Butuh: flutter pub add http, lib/models/post.dart, lib/services/post_service.dart
import 'package:flutter/material.dart';

import 'models/post.dart';
import 'services/post_service.dart';

void main() => runApp(const MaterialApp(home: RefreshPostScreen()));

class RefreshPostScreen extends StatefulWidget {
  const RefreshPostScreen({super.key});

  @override
  State<RefreshPostScreen> createState() => _RefreshPostScreenState();
}

class _RefreshPostScreenState extends State<RefreshPostScreen> {
  final _service = PostService();
  late Future<List<Post>> _future;
  DateTime _terakhir = DateTime.now();

  @override
  void initState() {
    super.initState();
    _future = _service.fetchPosts();
  }

  Future<void> _refresh() async {
    final future = _service.fetchPosts();
    setState(() {
      _future = future;
      _terakhir = DateTime.now();
    });
    try {
      await future; // spinner RefreshIndicator berhenti setelah ini
    } catch (_) {
      // error sudah ditampilkan oleh FutureBuilder, tidak perlu dilempar lagi
    }
  }

  @override
  Widget build(BuildContext context) {
    final jam = '${_terakhir.hour.toString().padLeft(2, '0')}:'
        '${_terakhir.minute.toString().padLeft(2, '0')}:'
        '${_terakhir.second.toString().padLeft(2, '0')}';
    return Scaffold(
      appBar: AppBar(title: const Text('Tarik untuk Refresh')),
      body: RefreshIndicator(
        onRefresh: _refresh,
        child: FutureBuilder<List<Post>>(
          future: _future,
          builder: (context, snapshot) {
            // Loading pertama kali: belum ada data sama sekali
            if (snapshot.connectionState == ConnectionState.waiting && !snapshot.hasData) {
              return const Center(child: CircularProgressIndicator());
            }
            // Error: tetap pakai ListView agar layar masih bisa ditarik
            if (snapshot.hasError) {
              return ListView(
                physics: const AlwaysScrollableScrollPhysics(),
                children: [
                  const SizedBox(height: 120),
                  const Icon(Icons.cloud_off, size: 64),
                  Center(child: Text('${snapshot.error}')),
                  const Center(child: Text('Tarik ke bawah untuk mencoba lagi')),
                ],
              );
            }
            final posts = snapshot.data ?? [];
            return ListView.builder(
              physics: const AlwaysScrollableScrollPhysics(),
              itemCount: posts.length + 1,
              itemBuilder: (context, index) {
                if (index == 0) {
                  return Padding(
                    padding: const EdgeInsets.all(12),
                    child: Text('Diperbarui pukul $jam • ${posts.length} post'),
                  );
                }
                final post = posts[index - 1];
                return ListTile(
                  leading: CircleAvatar(child: Text('${post.id}')),
                  title: Text(post.title, maxLines: 1, overflow: TextOverflow.ellipsis),
                );
              },
            );
          },
        ),
      ),
    );
  }
}
Baris pertama menunjukkan waktu pembaruan terakhir

Penjelasan:

  • Kondisi loading memakai && !snapshot.hasData. Saat refresh, Future baru sedang berjalan tetapi kita tidak ingin layar berkedip menjadi spinner besar karena RefreshIndicator sudah menampilkan spinner kecil di atas.
  • Tampilan error juga dibuat sebagai ListView dengan AlwaysScrollableScrollPhysics. Jika memakai Center biasa, layar error tidak bisa ditarik untuk mencoba lagi.
  • Baris pertama list menampilkan jam pembaruan sehingga efek refresh terlihat jelas.

⚠️ Kesalahan Umum

  • onRefresh: () { _load(); } tanpa async/return: spinner langsung hilang sebelum data datang. Pastikan fungsi mengembalikan Future yang ditunggu.
  • Membungkus Column atau Center dengan RefreshIndicator: tidak bisa ditarik karena bukan widget scroll.
  • Lupa AlwaysScrollableScrollPhysics ketika item sedikit, sehingga gestur tarik tidak berfungsi.
