Setelah bisa membaca data, sekarang kita mengirim data: membuat (POST), mengubah (PUT/PATCH), dan menghapus (DELETE). Ketiga method ini mirip GET, bedanya ada body JSON dan header Content-Type.

ℹ️ JSONPlaceholder Hanya Berpura-pura Menyimpan

JSONPlaceholder menerima POST/PUT/PATCH/DELETE dan membalas seolah berhasil, tetapi data tidak benar-benar tersimpan. POST selalu mengembalikan id: 101, dan jika kamu GET lagi, data baru tidak muncul. Ini normal. Untuk latihan, kita perbarui list di aplikasi secara lokal berdasarkan response server. Untuk data yang benar-benar tersimpan, gunakan mockapi.io atau backend sendiri (dan Supabase di Modul 12).

Pola Umum Request dengan Body

import 'dart:convert';

import 'package:http/http.dart' as http;

Future<void> contohPost() async {
  final response = await http.post(
    Uri.parse('https://jsonplaceholder.typicode.com/posts'),
    headers: {'Content-Type': 'application/json; charset=UTF-8'}, // wajib untuk JSON
    body: jsonEncode({'title': 'Halo', 'body': 'Isi', 'userId': 1}), // Map -> String
  );
  print(response.statusCode); // 201
  print(response.body);       // {"title": "Halo", "body": "Isi", "userId": 1, "id": 101}
}

Contoh Kecil Setiap Method

import 'dart:convert';

import 'package:http/http.dart' as http;

import 'models/post.dart';

const baseUrl = 'https://jsonplaceholder.typicode.com';
const jsonHeaders = {'Content-Type': 'application/json; charset=UTF-8'};

// CREATE: POST /posts -> 201 Created
Future<Post> createPost(Post post) async {
  final response = await http.post(
    Uri.parse('$baseUrl/posts'),
    headers: jsonHeaders,
    body: jsonEncode(post.toJson()),
  );
  if (response.statusCode != 201) {
    throw Exception('Gagal membuat post (HTTP ${response.statusCode})');
  }
  // Server mengembalikan data yang sudah memiliki id
  return Post.fromJson(jsonDecode(response.body) as Map<String, dynamic>);
}

// UPDATE penuh: PUT /posts/{id} -> 200 OK
Future<Post> updatePost(Post post) async {
  final response = await http.put(
    Uri.parse('$baseUrl/posts/${post.id}'),
    headers: jsonHeaders,
    body: jsonEncode(post.toJson()),
  );
  if (response.statusCode != 200) {
    throw Exception('Gagal mengubah post (HTTP ${response.statusCode})');
  }
  return Post.fromJson(jsonDecode(response.body) as Map<String, dynamic>);
}

// UPDATE sebagian: PATCH /posts/{id} -> 200 OK
Future<Post> updateTitle(int id, String title) async {
  final response = await http.patch(
    Uri.parse('$baseUrl/posts/$id'),
    headers: jsonHeaders,
    body: jsonEncode({'title': title}), // hanya field yang berubah
  );
  if (response.statusCode != 200) {
    throw Exception('Gagal mengubah judul (HTTP ${response.statusCode})');
  }
  return Post.fromJson(jsonDecode(response.body) as Map<String, dynamic>);
}

// DELETE /posts/{id} -> 200 OK (beberapa API memakai 204 No Content)
Future<void> deletePost(int id) async {
  final response = await http.delete(Uri.parse('$baseUrl/posts/$id'));
  if (response.statusCode != 200 && response.statusCode != 204) {
    throw Exception('Gagal menghapus post (HTTP ${response.statusCode})');
  }
}

Penjelasan: setiap fungsi mengecek status code yang sesuai standar (POST = 201, lainnya = 200). Fungsi create/update mengembalikan Post dari response server karena server bisa menambahkan data (misalnya id atau waktu dibuat). DELETE tidak perlu mengembalikan apa pun.

Contoh Lengkap: Playground CRUD

Aplikasi berikut punya 5 tombol (GET, POST, PUT, PATCH, DELETE) dan menampilkan status code serta body response. Cara cepat untuk melihat perilaku setiap method.

📄 lib/main.dart

// Pastikan sudah: flutter pub add http
import 'dart:convert';

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

void main() => runApp(const MaterialApp(home: CrudPlaygroundScreen()));

class CrudPlaygroundScreen extends StatefulWidget {
  const CrudPlaygroundScreen({super.key});

  @override
  State<CrudPlaygroundScreen> createState() => _CrudPlaygroundScreenState();
}

class _CrudPlaygroundScreenState extends State<CrudPlaygroundScreen> {
  static const _base = 'https://jsonplaceholder.typicode.com/posts';
  static const _headers = {'Content-Type': 'application/json; charset=UTF-8'};

  String _output = 'Pilih salah satu method di bawah.';
  bool _loading = false;

  // Satu fungsi pembantu agar setiap tombol cukup mengirim request-nya
  Future<void> _jalankan(String label, Future<http.Response> Function() request) async {
    setState(() {
      _loading = true;
      _output = 'Mengirim $label ...';
    });
    try {
      final res = await request();
      final pretty = res.body.isEmpty
          ? '(body kosong)'
          : const JsonEncoder.withIndent('  ').convert(jsonDecode(res.body));
      _output = '$label\nStatus: ${res.statusCode}\n\n$pretty';
    } catch (e) {
      _output = '$label gagal: $e';
    }
    if (mounted) setState(() => _loading = false);
  }

  @override
  Widget build(BuildContext context) {
    final tombol = <String, Future<http.Response> Function()>{
      'GET /posts/1': () => http.get(Uri.parse('$_base/1')),
      'POST /posts': () => http.post(
            Uri.parse(_base),
            headers: _headers,
            body: jsonEncode({'title': 'Post Baru', 'body': 'Dari Flutter', 'userId': 1}),
          ),
      'PUT /posts/1': () => http.put(
            Uri.parse('$_base/1'),
            headers: _headers,
            body: jsonEncode({'id': 1, 'title': 'Diganti total', 'body': 'Baru', 'userId': 1}),
          ),
      'PATCH /posts/1': () => http.patch(
            Uri.parse('$_base/1'),
            headers: _headers,
            body: jsonEncode({'title': 'Hanya judul berubah'}),
          ),
      'DELETE /posts/1': () => http.delete(Uri.parse('$_base/1')),
    };

    return Scaffold(
      appBar: AppBar(title: const Text('Playground CRUD HTTP')),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: Wrap(
              spacing: 8,
              runSpacing: 8,
              children: [
                for (final entry in tombol.entries)
                  FilledButton.tonal(
                    onPressed: _loading ? null : () => _jalankan(entry.key, entry.value),
                    child: Text(entry.key),
                  ),
              ],
            ),
          ),
          const Divider(height: 1),
          Expanded(
            child: SingleChildScrollView(
              padding: const EdgeInsets.all(16),
              child: SelectableText(
                _output,
                style: const TextStyle(fontFamily: 'monospace'),
              ),
            ),
          ),
        ],
      ),
    );
  }
}
POST /posts: status 201 dan id 101
PATCH /posts/1: hanya judul yang berubah

Coba tekan PATCH: response berisi seluruh post dengan judul baru, sedangkan PUT mengembalikan persis yang kita kirim. DELETE mengembalikan {} dengan status 200.

⚠️ Kesalahan Umum

  • Lupa jsonEncode: jika body diisi Map langsung, package http mengirimnya sebagai form (title=Halo&body=Isi), bukan JSON. Server JSON akan menolak atau mengabaikannya.
  • Lupa header Content-Type: banyak server (Laravel, Express) tidak membaca body sebagai JSON tanpa header ini.
  • Mengecek statusCode == 200 untuk POST, padahal standarnya 201. Lebih aman cek rentang 2xx.
  • Menganggap data JSONPlaceholder tersimpan, lalu bingung karena GET tidak menampilkan data baru.
  • PUT ke id yang tidak ada (mis. /posts/101) di JSONPlaceholder menghasilkan 500. Tangani error ini, jangan biarkan aplikasi crash.
