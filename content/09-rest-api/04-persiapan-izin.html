Sebelum request pertama, ada dua hal yang perlu disiapkan: memasang package http dan memastikan aplikasi diizinkan mengakses internet di setiap platform. Banyak mahasiswa mengira kodenya salah, padahal penyebabnya izin yang belum ditambahkan.

1. Memasang Package http

flutter pub add http

Lalu impor dengan awalan as http agar fungsi-fungsinya jelas berasal dari package ini (http.get, http.post, dan seterusnya):

import 'package:http/http.dart' as http;

Future<void> cobaKoneksi() async {
  final response = await http.get(
    Uri.parse('https://jsonplaceholder.typicode.com/posts/1'),
  );
  print('Status: ${response.statusCode}');
  print('Body: ${response.body}');
}

2. Android: Izin INTERNET

Mode debug otomatis punya izin internet, tetapi build release (APK yang dibagikan) tidak. Tambahkan baris berikut di android/app/src/main/AndroidManifest.xml, tepat di atas tag <application>:

📄 android/app/src/main/AndroidManifest.xml

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.INTERNET"/>

    <application
        android:label="aplikasi_saya"
        ...>

3. Android: Server Lokal Tanpa HTTPS

Saat backend dijalankan di laptop sendiri (Laravel, Express, dsb.) alamatnya biasanya http:// tanpa "s". Android 9 ke atas memblokir HTTP biasa (cleartext). Untuk keperluan belajar, izinkan lewat atribut di tag <application>:

<application
    android:usesCleartextTraffic="true"
    ...>

ℹ️ localhost di Emulator Android

Di dalam emulator Android, localhost berarti emulator itu sendiri, bukan laptop. Gunakan http://10.0.2.2:8000 untuk mengakses server di laptop. Jika memakai HP fisik, gunakan IP laptop di jaringan Wi-Fi yang sama, misalnya http://192.168.1.10:8000.

4. iOS

iOS tidak membutuhkan izin khusus untuk internet. Namun iOS memblokir http:// (App Transport Security). Untuk server lokal saat belajar, tambahkan di ios/Runner/Info.plist di dalam tag <dict> utama:

📄 ios/Runner/Info.plist

<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsLocalNetworking</key>
    <true/>
</dict>

Untuk server produksi, selalu gunakan https:// sehingga pengaturan ini tidak diperlukan.

5. macOS Desktop dan Web

  • macOS: tambahkan <key>com.apple.security.network.client</key><true/> di macos/Runner/DebugProfile.entitlements dan Release.entitlements.
  • Web (Chrome): tidak butuh izin, tetapi server harus mengizinkan CORS. JSONPlaceholder sudah mengizinkan. Jika API kampus menolak, error yang muncul adalah ClientException: XMLHttpRequest error.

Contoh Lengkap: Tes Koneksi

Gunakan aplikasi kecil ini untuk memastikan semua izin sudah benar sebelum lanjut ke section berikutnya.

📄 lib/main.dart

// Pastikan sudah: flutter pub add http
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

void main() => runApp(const MaterialApp(home: TesKoneksiScreen()));

class TesKoneksiScreen extends StatefulWidget {
  const TesKoneksiScreen({super.key});

  @override
  State<TesKoneksiScreen> createState() => _TesKoneksiScreenState();
}

class _TesKoneksiScreenState extends State<TesKoneksiScreen> {
  String _hasil = 'Tekan tombol untuk mengetes koneksi.';
  bool _loading = false;

  Future<void> _tes() async {
    setState(() => _loading = true);
    try {
      final response = await http.get(
        Uri.parse('https://jsonplaceholder.typicode.com/posts/1'),
      );
      _hasil = 'Status ${response.statusCode}\n\n${response.body}';
    } catch (e) {
      _hasil = 'Gagal terhubung: $e';
    }
    if (!mounted) return;
    setState(() => _loading = false);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tes Koneksi Internet')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: _loading
            ? const Center(child: CircularProgressIndicator())
            : SingleChildScrollView(child: Text(_hasil)),
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _loading ? null : _tes,
        icon: const Icon(Icons.wifi),
        label: const Text('Tes'),
      ),
    );
  }
}
Setelah tombol Tes ditekan: status 200 dan JSON post #1

Jika muncul Status 200 beserta JSON, koneksi sudah siap. Jika muncul Failed host lookup, cek internet emulator atau izin di atas.

⚠️ Kesalahan Umum

  • Aplikasi jalan saat debug tetapi APK release tidak bisa memuat data: lupa izin INTERNET.
  • Memakai http://localhost:8000 di emulator Android: gunakan 10.0.2.2.
  • Menambah izin di android/app/src/debug/AndroidManifest.xml, padahal yang dipakai release adalah folder main.
  • Mengira hot reload sudah cukup setelah mengubah file native (Manifest/Info.plist). Aplikasi harus di-stop lalu dijalankan ulang.
