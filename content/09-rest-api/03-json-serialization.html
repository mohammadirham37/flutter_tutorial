Jangan pernah menggunakan raw Map<String, dynamic> langsung di widget UI karena rentan salah ketik kunci string (typo) dan runtime error. Selalu petakan respon API ke dalam Model Class berstruktur kuat. Dengan model, editor akan memberi saran otomatis (autocomplete) dan kesalahan nama field langsung terdeteksi sebelum aplikasi dijalankan.

Pola Dasar: fromJson dan toJson

  • factory NamaModel.fromJson(Map<String, dynamic> json): mengubah Map hasil jsonDecode menjadi objek.
  • Map<String, dynamic> toJson(): mengubah objek menjadi Map yang siap di-jsonEncode.

Contoh model mahasiswa sederhana:

📄 lib/models/mahasiswa_model.dart

// lib/models/mahasiswa_model.dart
// Model Data Mahasiswa Berbasis JSON
class MahasiswaModel {
  final int id;
  final String nama;
  final String email;
  final String nim;
  final String avatarUrl;

  MahasiswaModel({
    required this.id,
    required this.nama,
    required this.email,
    required this.nim,
    required this.avatarUrl,
  });

  // Factory Constructor untuk mengurai JSON dari API Server
  factory MahasiswaModel.fromJson(Map<String, dynamic> json) {
    return MahasiswaModel(
      id: json['id'] as int,
      nama: json['nama'] as String? ?? 'Mahasiswa Anonim',
      email: json['email'] as String? ?? '-',
      nim: json['nim'] as String? ?? '-',
      avatarUrl: json['avatar'] as String? ?? 'https://i.pravatar.cc/150',
    );
  }

  // Method untuk mengirim data objek kembali ke format JSON payload
  Map<String, dynamic> toJson() {
    return {
      'nama': nama,
      'email': email,
      'nim': nim,
    };
  }
}

Penjelasan: json['nama'] as String? ?? 'Mahasiswa Anonim' dibaca: "ambil nama, boleh null, jika null pakai nilai default". Pola ini membuat aplikasi tidak crash ketika server lupa mengirim satu field. Perhatikan juga toJson() tidak menyertakan id karena id biasanya dibuat oleh server.

Model untuk JSONPlaceholder: Post

Sepanjang modul ini kita memakai API publik gratis jsonplaceholder.typicode.com. Satu post di sana berbentuk:

{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere repellat provident",
  "body": "quia et suscipit suscipit recusandae..."
}

📄 lib/models/post.dart

class Post {
  final int? id; // null ketika post belum dikirim ke server
  final int userId;
  final String title;
  final String body;

  const Post({
    this.id,
    required this.userId,
    required this.title,
    required this.body,
  });

  factory Post.fromJson(Map<String, dynamic> json) {
    return Post(
      id: json['id'] as int?,
      userId: json['userId'] as int? ?? 0,
      title: json['title'] as String? ?? '',
      body: json['body'] as String? ?? '',
    );
  }

  Map<String, dynamic> toJson() {
    return {
      if (id != null) 'id': id, // "collection if": id hanya ditulis jika ada
      'userId': userId,
      'title': title,
      'body': body,
    };
  }

  // copyWith: membuat salinan dengan sebagian field diganti (berguna saat edit)
  Post copyWith({int? id, int? userId, String? title, String? body}) {
    return Post(
      id: id ?? this.id,
      userId: userId ?? this.userId,
      title: title ?? this.title,
      body: body ?? this.body,
    );
  }

  @override
  String toString() => 'Post(id: $id, title: $title)';
}

Mengubah Array JSON Menjadi List<Post>

Endpoint /posts mengembalikan array. Polanya selalu sama: decode menjadi List, lalu map setiap elemen ke fromJson.

List<Post> parsePosts(String responseBody) {
  final List<dynamic> data = jsonDecode(responseBody) as List<dynamic>;
  return data
      .map((item) => Post.fromJson(item as Map<String, dynamic>))
      .toList();
}

Object Bersarang (Nested) dan List di Dalam Model

Endpoint /users berisi object di dalam object (address berisi geo, serta company). Buat satu class untuk setiap object, lalu panggil fromJson milik class anak dari dalam class induk.

{
  "id": 1,
  "name": "Leanne Graham",
  "email": "Sincere@april.biz",
  "address": {
    "street": "Kulas Light",
    "city": "Gwenborough",
    "geo": { "lat": "-37.3159", "lng": "81.1496" }
  },
  "company": { "name": "Romaguera-Crona" }
}

📄 lib/models/user.dart

class Geo {
  final double lat;
  final double lng;

  const Geo({required this.lat, required this.lng});

  // API mengirim koordinat sebagai String, jadi kita parse ke double
  factory Geo.fromJson(Map<String, dynamic> json) {
    return Geo(
      lat: double.tryParse(json['lat']?.toString() ?? '') ?? 0,
      lng: double.tryParse(json['lng']?.toString() ?? '') ?? 0,
    );
  }

  Map<String, dynamic> toJson() => {'lat': lat.toString(), 'lng': lng.toString()};
}

class Address {
  final String street;
  final String city;
  final Geo geo;

  const Address({required this.street, required this.city, required this.geo});

  factory Address.fromJson(Map<String, dynamic> json) {
    return Address(
      street: json['street'] as String? ?? '',
      city: json['city'] as String? ?? '',
      geo: Geo.fromJson(json['geo'] as Map<String, dynamic>? ?? {}),
    );
  }

  Map<String, dynamic> toJson() => {
        'street': street,
        'city': city,
        'geo': geo.toJson(), // anak juga di-toJson
      };
}

class User {
  final int id;
  final String name;
  final String email;
  final Address address;
  final String companyName;
  final List<String> roles; // contoh list String

  const User({
    required this.id,
    required this.name,
    required this.email,
    required this.address,
    required this.companyName,
    this.roles = const [],
  });

  factory User.fromJson(Map<String, dynamic> json) {
    final company = json['company'] as Map<String, dynamic>? ?? {};
    return User(
      id: json['id'] as int,
      name: json['name'] as String? ?? '',
      email: json['email'] as String? ?? '',
      address: Address.fromJson(json['address'] as Map<String, dynamic>),
      companyName: company['name'] as String? ?? '-',
      roles: List<String>.from(json['roles'] as List? ?? const []),
    );
  }

  Map<String, dynamic> toJson() => {
        'id': id,
        'name': name,
        'email': email,
        'address': address.toJson(),
        'company': {'name': companyName},
        'roles': roles,
      };
}

Contoh Lengkap yang Bisa Dijalankan

Program berikut memakai model Post dan User di atas dengan data JSON contoh (belum memakai internet), supaya kamu bisa fokus pada proses parsing.

📄 lib/contoh_model.dart

// Jalankan dengan: dart run lib/contoh_model.dart
import 'dart:convert';

import 'models/post.dart';
import 'models/user.dart';

const postsJson = '''
[
  {"userId": 1, "id": 1, "title": "Halo Flutter", "body": "Belajar REST API"},
  {"userId": 1, "id": 2, "title": "JSON itu mudah", "body": "Asal pakai model"}
]
''';

const userJson = '''
{
  "id": 1,
  "name": "Leanne Graham",
  "email": "Sincere@april.biz",
  "address": {
    "street": "Kulas Light",
    "city": "Gwenborough",
    "geo": {"lat": "-37.3159", "lng": "81.1496"}
  },
  "company": {"name": "Romaguera-Crona"},
  "roles": ["admin", "editor"]
}
''';

void main() {
  // Array -> List<Post>
  final List<dynamic> rawPosts = jsonDecode(postsJson) as List<dynamic>;
  final posts = rawPosts
      .map((e) => Post.fromJson(e as Map<String, dynamic>))
      .toList();
  for (final post in posts) {
    print('${post.id}. ${post.title}');
  }

  // Object bersarang -> User
  final user = User.fromJson(jsonDecode(userJson) as Map<String, dynamic>);
  print('${user.name} tinggal di ${user.address.city}');
  print('Koordinat: ${user.address.geo.lat}, ${user.address.geo.lng}');
  print('Peran: ${user.roles.join(', ')}');

  // Model -> JSON (untuk dikirim ke server)
  final baru = Post(userId: 1, title: 'Post baru', body: 'Isi');
  print(jsonEncode(baru.toJson())); // tanpa "id"

  // copyWith untuk edit
  final diedit = posts.first.copyWith(title: 'Judul diganti');
  print(diedit); // Post(id: 1, title: Judul diganti)
}

💡 Tips: Generator Otomatis

Untuk model yang sangat besar, ada package json_serializable yang membuat fromJson/toJson otomatis. Namun pahami dulu cara manual seperti di atas, karena hasil generator pun bentuknya sama.

⚠️ Kesalahan Umum

  • Lupa memanggil Address.fromJson(...) sehingga field bertipe Address diisi Map, hasilnya error tipe.
  • Lupa memanggil address.toJson() di dalam toJson() induk sehingga jsonEncode gagal mengubah objek Address.
  • Memakai json['id'] as int untuk field yang kadang dikirim sebagai String ("1"). Jika tidak yakin, gunakan int.tryParse(json['id'].toString()).
  • Nama kunci di model tidak sama persis dengan JSON (userid vs userId). Salin kunci langsung dari contoh response.
