Kebanyakan API sungguhan (SIA kampus, marketplace) hanya memberikan data kepada pengguna yang sudah login. Setelah login, server memberi token. Token itu kemudian dikirim di setiap request melalui header Authorization dengan format Bearer <token>.

Alur Autentikasi Token

1. POST /login  {email, password}        ──>  server cek akun
                                          <──  200 {"token": "abc.def.ghi"}
2. Simpan token (memori / SharedPreferences, lihat Modul 10)
3. GET /profil
   Authorization: Bearer abc.def.ghi      ──>  server cek token
                                          <──  200 {data profil}
4. Token salah / kedaluwarsa              <──  401 Unauthorized  -> arahkan ke login

Contoh Kecil: Menambahkan Header

Parameter headers menerima Map<String, String>. Perhatikan ada spasi setelah kata Bearer.

import 'package:http/http.dart' as http;

Future<void> ambilProfil(String token) async {
  final response = await http.get(
    Uri.parse('https://httpbin.org/bearer'),
    headers: {
      'Accept': 'application/json',
      'Authorization': 'Bearer $token',
    },
  );
  print(response.statusCode); // 200 jika ada token, 401 jika tidak
}

Kita memakai httpbin.org, layanan uji gratis. Endpoint /bearer membalas 200 jika header Bearer ada dan 401 jika tidak, sedangkan /headers mengembalikan semua header yang kita kirim.

Fungsi Pembuat Header

Daripada menulis header berulang di setiap request, buat satu fungsi:

Map<String, String> buildHeaders({String? token, bool json = true}) {
  return {
    'Accept': 'application/json',
    if (json) 'Content-Type': 'application/json; charset=UTF-8',
    if (token != null) 'Authorization': 'Bearer $token',
  };
}

Cara Lebih Rapi: http.BaseClient yang Menyisipkan Token Otomatis

Kita bisa membuat client sendiri yang otomatis menambahkan header ke setiap request. Ini mirip "interceptor" di library lain.

📄 lib/services/auth_client.dart

import 'package:http/http.dart' as http;

class AuthClient extends http.BaseClient {
  final http.Client _inner;
  String? token; // bisa diganti setelah login / logout

  AuthClient({http.Client? inner, this.token}) : _inner = inner ?? http.Client();

  @override
  Future<http.StreamedResponse> send(http.BaseRequest request) {
    request.headers['Accept'] = 'application/json';
    final t = token;
    if (t != null) {
      request.headers['Authorization'] = 'Bearer $t';
    }
    return _inner.send(request);
  }

  @override
  void close() {
    _inner.close();
    super.close();
  }
}

AuthClient bisa dipakai persis seperti package http: client.get(...), client.post(...), dan seterusnya. Semua method itu pada akhirnya memanggil send(), sehingga header pasti ikut.

Contoh Lengkap: Simulasi Login dengan Token

📄 lib/main.dart

// Pastikan sudah: flutter pub add http, dan membuat lib/services/auth_client.dart
import 'package:flutter/material.dart';

import 'services/auth_client.dart';

void main() => runApp(const MaterialApp(home: TokenDemoScreen()));

class TokenDemoScreen extends StatefulWidget {
  const TokenDemoScreen({super.key});

  @override
  State<TokenDemoScreen> createState() => _TokenDemoScreenState();
}

class _TokenDemoScreenState extends State<TokenDemoScreen> {
  final _client = AuthClient();
  String _hasil = '-';

  @override
  void dispose() {
    _client.close(); // tutup koneksi saat layar dibuang
    super.dispose();
  }

  void _login() {
    // Pada aplikasi nyata token didapat dari response POST /login
    setState(() => _client.token = 'token-rahasia-mahasiswa-123');
  }

  void _logout() {
    setState(() => _client.token = null);
  }

  Future<void> _panggilApi() async {
    setState(() => _hasil = 'Memanggil /bearer ...');
    try {
      final res = await _client.get(Uri.parse('https://httpbin.org/bearer'));
      final pesan = switch (res.statusCode) {
        200 => 'Diizinkan (200)\n${res.body}',
        401 => 'Ditolak (401 Unauthorized): silakan login dulu',
        _ => 'Status tak terduga: ${res.statusCode}',
      };
      if (mounted) setState(() => _hasil = pesan);
    } catch (e) {
      if (mounted) setState(() => _hasil = 'Error jaringan: $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    final sudahLogin = _client.token != null;
    return Scaffold(
      appBar: AppBar(title: const Text('Demo Bearer Token')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            Text(sudahLogin ? 'Token: ${_client.token}' : 'Belum login (tanpa token)'),
            const SizedBox(height: 12),
            OutlinedButton(
              onPressed: sudahLogin ? _logout : _login,
              child: Text(sudahLogin ? 'Logout' : 'Login (dapat token)'),
            ),
            FilledButton(onPressed: _panggilApi, child: const Text('Panggil API terlindungi')),
            const SizedBox(height: 16),
            Expanded(child: SingleChildScrollView(child: Text(_hasil))),
          ],
        ),
      ),
    );
  }
}
Memanggil API sebelum login: 401
Setelah login: token terkirim, status 200

Penjelasan: panggil API sebelum login, hasilnya 401. Tekan Login lalu panggil lagi, hasilnya 200 dan httpbin menampilkan token yang diterimanya. Ekspresi switch (Dart 3) membuat penanganan setiap status code ringkas.

⚠️ Kesalahan Umum & Keamanan

  • Menulis 'Bearer$token' tanpa spasi, atau 'bearer' huruf kecil pada server yang ketat.
  • Menyimpan API key rahasia (kunci admin, secret key) di kode Flutter. Aplikasi bisa dibongkar; kunci rahasia harus tetap di server.
  • Token login yang sensitif sebaiknya disimpan dengan flutter_secure_storage. SharedPreferences (Modul 10) cukup untuk latihan, tetapi tidak terenkripsi.
  • Tidak menangani 401. Saat token kedaluwarsa, hapus token dan arahkan pengguna ke halaman login.
