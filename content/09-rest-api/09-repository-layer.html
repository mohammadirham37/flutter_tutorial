1. ApiClient: Satu Pintu untuk Semua Request

File ini memakai ApiException dari section sebelumnya (salin ke lib/core/api_exception.dart).

📄 lib/core/api_exception.dart

class ApiException implements Exception {
  final String message;
  final int? statusCode;

  const ApiException(this.message, {this.statusCode});

  factory ApiException.fromStatus(int code) {
    final pesan = switch (code) {
      400 => 'Data yang dikirim tidak valid.',
      401 => 'Sesi berakhir, silakan login ulang.',
      403 => 'Anda tidak punya akses ke data ini.',
      404 => 'Data tidak ditemukan.',
      422 => 'Validasi gagal, periksa kembali isian.',
      >= 500 => 'Server sedang bermasalah. Coba beberapa saat lagi.',
      _ => 'Terjadi kesalahan (kode $code).',
    };
    return ApiException(pesan, statusCode: code);
  }

  @override
  String toString() => message;
}

📄 lib/core/api_client.dart

import 'dart:async';
import 'dart:convert';
import 'dart:io';

import 'package:http/http.dart' as http;

import 'api_exception.dart';

class ApiClient {
  final String baseUrl;
  final http.Client _http;
  final Duration timeout;
  String? token; // diisi setelah login (opsional)

  ApiClient({
    required this.baseUrl,
    http.Client? httpClient,
    this.timeout = const Duration(seconds: 15),
  }) : _http = httpClient ?? http.Client();

  Map<String, String> get _headers => {
        'Accept': 'application/json',
        'Content-Type': 'application/json; charset=UTF-8',
        if (token != null) 'Authorization': 'Bearer $token',
      };

  Uri _uri(String path, [Map<String, String>? query]) =>
      Uri.parse('$baseUrl$path').replace(queryParameters: query);

  Future<dynamic> get(String path, {Map<String, String>? query}) =>
      _send(() => _http.get(_uri(path, query), headers: _headers));

  Future<dynamic> post(String path, Object body) =>
      _send(() => _http.post(_uri(path), headers: _headers, body: jsonEncode(body)));

  Future<dynamic> put(String path, Object body) =>
      _send(() => _http.put(_uri(path), headers: _headers, body: jsonEncode(body)));

  Future<dynamic> patch(String path, Object body) =>
      _send(() => _http.patch(_uri(path), headers: _headers, body: jsonEncode(body)));

  Future<dynamic> delete(String path) =>
      _send(() => _http.delete(_uri(path), headers: _headers));

  // Semua request lewat sini: timeout, cek status, decode, terjemahkan error
  Future<dynamic> _send(Future<http.Response> Function() request) async {
    try {
      final res = await request().timeout(timeout);
      if (res.statusCode < 200 || res.statusCode >= 300) {
        throw ApiException.fromStatus(res.statusCode);
      }
      if (res.body.isEmpty) return null; // mis. 204 No Content
      return jsonDecode(utf8.decode(res.bodyBytes));
    } on SocketException {
      throw const ApiException('Tidak ada koneksi internet.');
    } on TimeoutException {
      throw const ApiException('Server tidak merespons. Coba lagi.');
    } on http.ClientException {
      throw const ApiException('Gagal menghubungi server.');
    } on FormatException {
      throw const ApiException('Format data dari server tidak valid.');
    }
  }
}

Penjelasan: lima method publik hanya berbeda pada fungsi http yang dipanggil. Semua logika berat ada di _send, sehingga cukup ditulis sekali. Uri.replace(queryParameters: null) tidak menambah apa pun jika query kosong.

2. Repository: Bahasa Bisnis

Repository dibuat sebagai abstract class (kontrak) plus implementasinya. Keuntungannya: UI bisa diuji dengan repository palsu (fake) tanpa internet, dan backend bisa diganti (mis. ke Supabase) tanpa mengubah UI.

📄 lib/repositories/post_repository.dart

import '../core/api_client.dart';
import '../models/post.dart';

/// Kontrak: apa saja yang bisa dilakukan terhadap data Post.
abstract class PostRepository {
  Future<List<Post>> getAll();
  Future<Post> getById(int id);
  Future<Post> create(Post post);
  Future<Post> update(Post post);
  Future<void> delete(int id);
}

/// Implementasi yang memakai REST API JSONPlaceholder.
class RemotePostRepository implements PostRepository {
  final ApiClient _api;
  RemotePostRepository(this._api);

  @override
  Future<List<Post>> getAll() async {
    final data = await _api.get('/posts', query: {'_limit': '20'}) as List<dynamic>;
    return data.map((e) => Post.fromJson(e as Map<String, dynamic>)).toList();
  }

  @override
  Future<Post> getById(int id) async {
    final data = await _api.get('/posts/$id') as Map<String, dynamic>;
    return Post.fromJson(data);
  }

  @override
  Future<Post> create(Post post) async {
    final data = await _api.post('/posts', post.toJson()) as Map<String, dynamic>;
    return Post.fromJson(data);
  }

  @override
  Future<Post> update(Post post) async {
    final data = await _api.put('/posts/${post.id}', post.toJson()) as Map<String, dynamic>;
    return Post.fromJson(data);
  }

  @override
  Future<void> delete(int id) => _api.delete('/posts/$id');
}

/// Implementasi palsu di memori: untuk testing atau saat server belum siap.
class FakePostRepository implements PostRepository {
  final List<Post> _data = [
    const Post(id: 1, userId: 1, title: 'Post palsu pertama', body: 'Tanpa internet'),
    const Post(id: 2, userId: 1, title: 'Post palsu kedua', body: 'Cocok untuk testing'),
  ];

  @override
  Future<List<Post>> getAll() async {
    await Future.delayed(const Duration(milliseconds: 500)); // simulasi jaringan
    return List.of(_data);
  }

  @override
  Future<Post> getById(int id) async => _data.firstWhere((p) => p.id == id);

  @override
  Future<Post> create(Post post) async {
    final baru = post.copyWith(id: _data.length + 1);
    _data.add(baru);
    return baru;
  }

  @override
  Future<Post> update(Post post) async {
    final i = _data.indexWhere((p) => p.id == post.id);
    _data[i] = post;
    return post;
  }

  @override
  Future<void> delete(int id) async => _data.removeWhere((p) => p.id == id);
}

3. Memakai Repository di UI

Perhatikan: file UI berikut tidak mengimpor http maupun dart:convert. Ubah variabel pakaiDataPalsu menjadi true untuk mencoba tanpa internet.

📄 lib/main.dart

// Butuh: lib/models/post.dart, lib/core/api_exception.dart,
// lib/core/api_client.dart, lib/repositories/post_repository.dart
import 'package:flutter/material.dart';

import 'core/api_client.dart';
import 'models/post.dart';
import 'repositories/post_repository.dart';

const pakaiDataPalsu = false;

void main() {
  final PostRepository repo = pakaiDataPalsu
      ? FakePostRepository()
      : RemotePostRepository(ApiClient(baseUrl: 'https://jsonplaceholder.typicode.com'));
  runApp(MaterialApp(home: PostScreen(repository: repo)));
}

class PostScreen extends StatefulWidget {
  final PostRepository repository;
  const PostScreen({super.key, required this.repository});

  @override
  State<PostScreen> createState() => _PostScreenState();
}

class _PostScreenState extends State<PostScreen> {
  List<Post> _posts = [];
  String? _error;
  bool _loading = true;

  @override
  void initState() {
    super.initState();
    _load();
  }

  Future<void> _load() async {
    try {
      final posts = await widget.repository.getAll();
      if (mounted) setState(() => _posts = posts);
    } catch (e) {
      if (mounted) setState(() => _error = '$e');
    } finally {
      if (mounted) setState(() => _loading = false);
    }
  }

  Future<void> _hapus(Post post) async {
    try {
      await widget.repository.delete(post.id!);
      setState(() => _posts.remove(post));
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('$e')));
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(pakaiDataPalsu ? 'Repository Palsu' : 'Repository REST')),
      body: _loading
          ? const Center(child: CircularProgressIndicator())
          : _error != null
              ? Center(child: Text(_error!))
              : ListView(
                  children: [
                    for (final post in _posts)
                      ListTile(
                        title: Text(post.title, maxLines: 1, overflow: TextOverflow.ellipsis),
                        subtitle: Text('id ${post.id}'),
                        trailing: IconButton(
                          icon: const Icon(Icons.delete_outline),
                          onPressed: () => _hapus(post),
                        ),
                      ),
                  ],
                ),
    );
  }
}

💡 Kenapa Repot Membuat Lapisan?

  • Mudah diganti: pindah dari REST ke Supabase (Modul 12) cukup membuat SupabasePostRepository baru.
  • Mudah diuji: Modul 15 (Testing) memakai FakePostRepository agar tes tidak bergantung internet.
  • Mudah dibaca: repository.delete(3) jauh lebih jelas daripada 10 baris kode HTTP.

⚠️ Kesalahan Umum

  • Mengimpor package:flutter/material.dart di repository atau ApiClient. Lapisan data tidak boleh bergantung pada UI.
  • Membuat http.Client() baru di setiap method tanpa ditutup. Buat sekali dan gunakan ulang.
  • Menangkap error di repository lalu mengembalikan list kosong. UI jadi tidak tahu bahwa terjadi error; biarkan exception naik ke Provider/UI.
