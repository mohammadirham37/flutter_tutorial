ℹ️ Menyiasati JSONPlaceholder

Karena server palsu selalu memberi id: 101 untuk post baru dan tidak menyimpan perubahan, controller kita (1) memberi id unik lokal untuk post baru, dan (2) tidak mengirim PUT untuk post buatan sendiri (id > 100) karena server akan membalas 500. Di backend sungguhan, dua siasat ini tidak diperlukan.

1. Controller CRUD

📄 lib/controllers/post_crud_controller.dart

import 'package:get/get.dart';

import '../models/post.dart';
import '../repositories/post_repository.dart';

class PostCrudController extends GetxController {
  PostCrudController(this._repo);
  final PostRepository _repo;

  final _posts = <Post>[].obs;
  final _isLoading = false.obs;
  final _error = RxnString();
  final _saving = false.obs; // true saat POST/PUT/DELETE berjalan

  List<Post> get posts => List.unmodifiable(_posts);
  bool get isLoading => _isLoading.value;
  String? get error => _error.value;
  bool get saving => _saving.value;

  Post? findById(int id) {
    for (final p in _posts) {
      if (p.id == id) return p;
    }
    return null;
  }

  @override
  void onInit() {
    super.onInit();
    load(); // READ pertama saat controller dibuat
  }

  // READ
  Future<void> load() async {
    _isLoading.value = true;
    _error.value = null;
    try {
      _posts.assignAll(await _repo.getAll());
    } catch (e) {
      _error.value = '$e';
    } finally {
      _isLoading.value = false;
    }
  }

  // CREATE
  Future<void> add(String title, String body) async {
    await _runSaving(() async {
      final created = await _repo.create(Post(userId: 1, title: title, body: body));
      // JSONPlaceholder selalu memberi id 101, jadi buat id unik lokal
      final nextId = _posts.fold<int>(100, (max, p) => p.id! > max ? p.id! : max) + 1;
      _posts.insert(0, created.copyWith(id: nextId));
    });
  }

  // UPDATE
  Future<void> edit(Post post) async {
    await _runSaving(() async {
      // Post buatan sendiri (id > 100) tidak dikenal server palsu, cukup ubah lokal
      final saved = post.id! > 100 ? post : await _repo.update(post);
      final i = _posts.indexWhere((p) => p.id == post.id);
      if (i != -1) _posts[i] = saved;
    });
  }

  // DELETE
  Future<void> remove(int id) async {
    await _runSaving(() async {
      if (id <= 100) await _repo.delete(id);
      _posts.removeWhere((p) => p.id == id);
    });
  }

  // Pembantu: set flag saving, jalankan aksi, lempar ulang error ke View
  Future<void> _runSaving(Future<void> Function() action) async {
    _saving.value = true;
    try {
      await action();
    } finally {
      _saving.value = false;
    }
  }
}

Penjelasan: method add, edit, dan remove tidak menangkap error. Error dibiarkan naik ke View form/detail agar View itu bisa menampilkan SnackBar dan tidak menutup form jika gagal. try/finally di _runSaving memastikan flag saving kembali false walaupun terjadi error. Perhatikan juga bahwa controller tidak bernavigasi dan tidak menampilkan SnackBar; semua itu tugas View.

2. View Daftar

📄 lib/views/post_list_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/post_crud_controller.dart';
import 'post_detail_view.dart';
import 'post_form_view.dart';

class PostListView extends GetView<PostCrudController> {
  const PostListView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Aplikasi Posts')),
      body: Obx(() {
        if (controller.isLoading) {
          return const Center(child: CircularProgressIndicator());
        }
        if (controller.error != null) {
          return Center(
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                const Icon(Icons.cloud_off, size: 56),
                const SizedBox(height: 8),
                Text(controller.error!),
                TextButton(onPressed: controller.load, child: const Text('Coba Lagi')),
              ],
            ),
          );
        }
        final posts = controller.posts;
        if (posts.isEmpty) {
          return const Center(child: Text('Belum ada post.'));
        }
        return RefreshIndicator(
          onRefresh: controller.load,
          child: ListView.separated(
            physics: const AlwaysScrollableScrollPhysics(),
            itemCount: posts.length,
            separatorBuilder: (_, _) => const Divider(height: 1),
            itemBuilder: (context, i) {
              final post = posts[i];
              return ListTile(
                leading: CircleAvatar(child: Text('${post.id}')),
                title: Text(post.title, maxLines: 1, overflow: TextOverflow.ellipsis),
                subtitle: Text(post.body, maxLines: 2, overflow: TextOverflow.ellipsis),
                onTap: () => Get.to(() => PostDetailView(postId: post.id!)),
              );
            },
          ),
        );
      }),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: () => Get.to(() => const PostFormView()),
        icon: const Icon(Icons.add),
        label: const Text('Post Baru'),
      ),
    );
  }
}

Penjelasan: Get.to(() => HalamanBaru()) adalah pengganti Navigator.push di GetX; tidak butuh context. Halaman detail dan form tidak perlu menerima controller lewat constructor, karena keduanya cukup memanggil Get.find (lewat GetView) untuk mendapatkan instance yang sama.

3. View Detail (dengan Edit & Hapus)

📄 lib/views/post_detail_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/post_crud_controller.dart';
import 'post_form_view.dart';

class PostDetailView extends GetView<PostCrudController> {
  final int postId;
  const PostDetailView({super.key, required this.postId});

  Future<void> _konfirmasiHapus(BuildContext context) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Hapus post?'),
        content: const Text('Post yang dihapus tidak bisa dikembalikan.'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Batal')),
          FilledButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Hapus')),
        ],
      ),
    );
    if (yakin != true || !context.mounted) return;

    final messenger = ScaffoldMessenger.of(context);
    try {
      await controller.remove(postId);
      Get.back(); // kembali ke daftar
      messenger.showSnackBar(const SnackBar(content: Text('Post dihapus')));
    } catch (e) {
      messenger.showSnackBar(SnackBar(content: Text('Gagal menghapus: $e')));
    }
  }

  @override
  Widget build(BuildContext context) {
    return Obx(() {
      final post = controller.findById(postId);

      // Post bisa saja sudah terhapus ketika layar ini masih terbuka
      if (post == null) {
        return Scaffold(appBar: AppBar(), body: const Center(child: Text('Post tidak ditemukan')));
      }

      return Scaffold(
        appBar: AppBar(
          title: Text('Post #${post.id}'),
          actions: [
            IconButton(
              tooltip: 'Edit',
              icon: const Icon(Icons.edit),
              onPressed: () => Get.to(() => PostFormView(post: post)),
            ),
            IconButton(
              tooltip: 'Hapus',
              icon: const Icon(Icons.delete_outline),
              onPressed: controller.saving ? null : () => _konfirmasiHapus(context),
            ),
          ],
        ),
        body: ListView(
          padding: const EdgeInsets.all(20),
          children: [
            Text(post.title, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 4),
            Text('Penulis: user ${post.userId}', style: Theme.of(context).textTheme.labelMedium),
            const Divider(height: 32),
            Text(post.body, style: Theme.of(context).textTheme.bodyLarge),
          ],
        ),
      );
    });
  }
}

Penjelasan: seluruh halaman dibungkus Obx karena isinya bergantung pada findById (yang membaca list reaktif) dan saving. Setelah post diedit, halaman detail otomatis menampilkan judul baru tanpa perlu dikirimi data ulang.

4. Satu Form untuk Tambah dan Edit

Jika parameter post bernilai null, form berada dalam mode tambah; jika diisi, mode edit dan field terisi data lama. TextEditingController adalah state lokal milik form, jadi tetap disimpan di StatefulWidget; controller GetX hanya dipakai untuk data post.

📄 lib/views/post_form_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/post_crud_controller.dart';
import '../models/post.dart';

class PostFormView extends StatefulWidget {
  final Post? post; // null = tambah, ada isi = edit
  const PostFormView({super.key, this.post});

  @override
  State<PostFormView> createState() => _PostFormViewState();
}

class _PostFormViewState extends State<PostFormView> {
  final _controller = Get.find<PostCrudController>();
  final _formKey = GlobalKey<FormState>();
  late final TextEditingController _titleCtrl;
  late final TextEditingController _bodyCtrl;

  bool get _isEdit => widget.post != null;

  @override
  void initState() {
    super.initState();
    _titleCtrl = TextEditingController(text: widget.post?.title ?? '');
    _bodyCtrl = TextEditingController(text: widget.post?.body ?? '');
  }

  @override
  void dispose() {
    _titleCtrl.dispose();
    _bodyCtrl.dispose();
    super.dispose();
  }

  Future<void> _simpan() async {
    if (!_formKey.currentState!.validate()) return;
    final title = _titleCtrl.text.trim();
    final body = _bodyCtrl.text.trim();

    try {
      if (_isEdit) {
        await _controller.edit(widget.post!.copyWith(title: title, body: body));
      } else {
        await _controller.add(title, body);
      }
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text(_isEdit ? 'Perubahan disimpan' : 'Post ditambahkan')),
      );
      Get.back();
    } catch (e) {
      if (!mounted) return;
      // Form TIDAK ditutup agar isian pengguna tidak hilang
      ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('Gagal: $e')));
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(_isEdit ? 'Edit Post' : 'Post Baru')),
      body: Form(
        key: _formKey,
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            TextFormField(
              controller: _titleCtrl,
              decoration: const InputDecoration(labelText: 'Judul', border: OutlineInputBorder()),
              validator: (v) => (v == null || v.trim().length < 3) ? 'Judul minimal 3 karakter' : null,
            ),
            const SizedBox(height: 12),
            TextFormField(
              controller: _bodyCtrl,
              maxLines: 5,
              decoration: const InputDecoration(labelText: 'Isi', border: OutlineInputBorder()),
              validator: (v) => (v == null || v.trim().isEmpty) ? 'Isi tidak boleh kosong' : null,
            ),
            const SizedBox(height: 20),
            // Hanya tombol ini yang dibangun ulang saat saving berubah
            Obx(() {
              final saving = _controller.saving;
              return FilledButton.icon(
                onPressed: saving ? null : _simpan,
                icon: saving
                    ? const SizedBox(width: 18, height: 18, child: CircularProgressIndicator(strokeWidth: 2))
                    : const Icon(Icons.save),
                label: Text(saving ? 'Menyimpan...' : 'Simpan'),
              );
            }),
          ],
        ),
      ),
    );
  }
}

5. main.dart

📄 lib/main.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/post_crud_controller.dart';
import 'core/api_client.dart';
import 'repositories/post_repository.dart';
import 'views/post_list_view.dart';

/// Mendaftarkan semua dependency aplikasi di satu tempat.
class AppBinding extends Bindings {
  @override
  void dependencies() {
    final api = ApiClient(baseUrl: 'https://jsonplaceholder.typicode.com');
    Get.put(PostCrudController(RemotePostRepository(api)), permanent: true);
  }
}

void main() {
  runApp(const PostsApp());
}

class PostsApp extends StatelessWidget {
  const PostsApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'Aplikasi Posts',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      initialBinding: AppBinding(),
      home: const PostListView(),
    );
  }
}

Penjelasan: AppBinding dijalankan oleh GetMaterialApp sebelum halaman pertama dibangun, sehingga PostListView sudah bisa menemukan PostCrudController. permanent: true menjaga controller tetap hidup selama aplikasi berjalan, karena dipakai oleh semua halaman.

Alur Data Saat Menambah Post

PostFormView._simpan()
   └─> PostCrudController.add()        saving.value = true (Obx tombol: "Menyimpan...")
         └─> RemotePostRepository.create()
               └─> ApiClient.post('/posts', json)   -> 201 Created
         <─ Post baru di-insert ke _posts (RxList), saving.value = false
   <─ SnackBar "Post ditambahkan", Get.back()
PostListView (Obx membaca controller.posts) otomatis rebuild, post baru muncul paling atas

⚠️ Kesalahan Umum pada Proyek CRUD

  • Menutup form (Get.back()) sebelum await selesai, sehingga error tidak pernah terlihat.
  • Mengirim objek yang sama ke halaman detail lalu mengeditnya: detail tidak berubah. Kirim id lalu cari data terbaru dari controller (seperti findById).
  • Menekan tombol Simpan berkali-kali sehingga data dobel. Nonaktifkan tombol saat saving.
  • Memakai context setelah await tanpa cek mounted/context.mounted.
  • Membuat controller baru di setiap halaman (Get.put(PostCrudController(...)) di detail/form). Data jadi tidak sinkron; cukup Get.find controller yang sudah didaftarkan di AppBinding.
  • Memanggil Get.back() atau menampilkan SnackBar dari dalam controller. Controller cukup melempar error atau mengembalikan hasil; View yang memutuskan navigasi dan pesan.
