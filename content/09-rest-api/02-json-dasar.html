Server mengirim data dalam bentuk teks JSON. Teks ini harus diubah dulu menjadi objek Dart (decode) agar bisa dipakai, dan objek Dart harus diubah menjadi teks JSON (encode) sebelum dikirim ke server. Keduanya disediakan library bawaan dart:convert, tanpa perlu package tambahan.

Wujud JSON

JSON hanya mengenal 6 jenis nilai. Hafalkan padanannya di Dart karena ini sumber error paling sering:

JSONContohHasil di Dart setelah jsonDecode
Object{"nama": "Budi"}Map<String, dynamic>
Array[1, 2, 3]List<dynamic> (bukan List<int>!)
String"halo"String
Number10 / 3.5int / double
Booleantruebool

Contoh JSON satu mahasiswa yang berisi object bersarang (prodi) dan array (hobi):

{
  "nim": "H1D022001",
  "nama": "Budi Santoso",
  "ipk": 3.75,
  "aktif": true,
  "prodi": { "kode": "IF", "nama": "Informatika" },
  "hobi": ["coding", "futsal"]
}

Contoh Kecil: jsonDecode dan jsonEncode

import 'dart:convert';

void main() {
  // Teks JSON (String) -> objek Dart
  const teks = '{"nama": "Budi", "umur": 20}';
  final Map<String, dynamic> data = jsonDecode(teks);
  print(data['nama']); // Budi

  // Objek Dart -> teks JSON (String)
  final kirim = {'nama': 'Siti', 'umur': 21};
  final String json = jsonEncode(kirim);
  print(json); // {"nama":"Siti","umur":21}
}

jsonDecode menerima String dan mengembalikan dynamic. Karena itu kita menyebutkan tipe tujuannya (Map<String, dynamic>) agar editor bisa membantu.

Contoh Lengkap: Membaca Data Bersarang dan Array

📄 lib/contoh_json.dart

// Jalankan dengan: dart run lib/contoh_json.dart
import 'dart:convert';

const String responseBody = '''
{
  "nim": "H1D022001",
  "nama": "Budi Santoso",
  "ipk": 3.75,
  "aktif": true,
  "prodi": { "kode": "IF", "nama": "Informatika" },
  "hobi": ["coding", "futsal"],
  "nilai": [
    { "matkul": "Pemrograman Mobile", "huruf": "A" },
    { "matkul": "Basis Data", "huruf": "AB" }
  ]
}
''';

void main() {
  // 1. Decode teks menjadi Map
  final Map<String, dynamic> mhs = jsonDecode(responseBody) as Map<String, dynamic>;

  // 2. Ambil nilai sederhana dengan cast "as"
  final String nama = mhs['nama'] as String;
  final double ipk = (mhs['ipk'] as num).toDouble(); // aman untuk 3 maupun 3.75
  final bool aktif = mhs['aktif'] as bool;
  print('$nama, IPK $ipk, aktif: $aktif');

  // 3. Object bersarang adalah Map di dalam Map
  final Map<String, dynamic> prodi = mhs['prodi'] as Map<String, dynamic>;
  print('Prodi: ${prodi['nama']}');

  // 4. Array berisi String: List<dynamic> harus dikonversi
  final List<String> hobi = List<String>.from(mhs['hobi'] as List);
  print('Hobi: ${hobi.join(', ')}');

  // 5. Array berisi object: tiap elemen adalah Map
  final List<dynamic> nilaiList = mhs['nilai'] as List<dynamic>;
  for (final item in nilaiList) {
    final nilai = item as Map<String, dynamic>;
    print('- ${nilai['matkul']}: ${nilai['huruf']}');
  }

  // 6. Field yang tidak ada menghasilkan null, gunakan ?? untuk nilai default
  final String? email = mhs['email'] as String?;
  print('Email: ${email ?? 'belum diisi'}');

  // 7. Encode kembali; JsonEncoder.withIndent membuat output rapi
  mhs['aktif'] = false;
  const encoder = JsonEncoder.withIndent('  ');
  print(encoder.convert(mhs));
}

Penjelasan baris penting:

  • Langkah 2: angka JSON 3 menjadi int, sedangkan 3.75 menjadi double. Menulis as double akan crash jika server mengirim 3. Pola (x as num).toDouble() aman untuk keduanya.
  • Langkah 4: hasil decode array selalu List<dynamic>. List<String>.from(...) menyalin isinya ke list bertipe benar.
  • Langkah 6: kunci yang tidak ada di Map menghasilkan null, bukan error. Pakai tipe nullable (String?) lalu beri nilai default.

Mengirim Data: Map Dart ke Body JSON

Saat mengirim POST/PUT, body harus berupa String JSON. Objek seperti DateTime tidak bisa langsung di-encode, jadi ubah dulu menjadi String:

import 'dart:convert';

void main() {
  final sekarang = DateTime(2026, 9, 1, 8, 30);

  final body = jsonEncode({
    'judul': 'Kuis 1',
    'tanggal': sekarang.toIso8601String(), // DateTime -> "2026-09-01T08:30:00.000"
    'peserta': ['Budi', 'Siti'],
    'selesai': false,
  });
  print(body);

  // Membaca kembali tanggal dari JSON
  final data = jsonDecode(body) as Map<String, dynamic>;
  final tanggal = DateTime.parse(data['tanggal'] as String);
  print(tanggal.day); // 1
}

⚠️ Kesalahan Umum

  • type 'List<dynamic>' is not a subtype of type 'List<String>': menulis mhs['hobi'] as List<String>. Gunakan List<String>.from(...) atau .cast<String>().
  • type 'int' is not a subtype of type 'double': lihat langkah 2, pakai num.
  • FormatException: Unexpected character: teks yang di-decode bukan JSON, biasanya halaman HTML error dari server. Cek statusCode sebelum decode.
  • Converting object to an encodable object failed: Instance of 'DateTime': encode objek yang bukan tipe JSON. Ubah ke String/Map dulu.
  • Salah huruf kunci: data['Nama'] berbeda dengan data['nama']. Kunci JSON case-sensitive. Inilah alasan kita membuat Model Class di section berikutnya.
