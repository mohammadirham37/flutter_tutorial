Di section GET kita menulis tiga variabel state (_loading, _error, _posts) secara manual. Widget FutureBuilder melakukan pekerjaan itu untuk kita: ia mengamati sebuah Future dan otomatis membangun ulang UI sesuai statusnya.

Konsep: AsyncSnapshot

Fungsi builder menerima snapshot yang berisi keadaan Future saat ini:

PropertiArtiTampilkan
snapshot.connectionState == ConnectionState.waitingFuture sedang berjalanLoading (spinner)
snapshot.hasError / snapshot.errorFuture selesai dengan exceptionPesan error + tombol coba lagi
snapshot.hasData / snapshot.dataFuture selesai dengan nilaiData (list, detail)
ConnectionState.doneFuture sudah selesai (sukses atau error)-

Contoh Kecil

import 'package:flutter/material.dart';

class JamServer extends StatefulWidget {
  const JamServer({super.key});

  @override
  State<JamServer> createState() => _JamServerState();
}

class _JamServerState extends State<JamServer> {
  // Future disimpan di field, dibuat sekali di initState
  late final Future<String> _future;

  @override
  void initState() {
    super.initState();
    _future = Future.delayed(const Duration(seconds: 2), () => 'Data siap!');
  }

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<String>(
      future: _future,
      builder: (context, snapshot) {
        if (snapshot.connectionState == ConnectionState.waiting) {
          return const CircularProgressIndicator(); // 1. loading
        }
        if (snapshot.hasError) {
          return Text('Error: ${snapshot.error}'); // 2. error
        }
        return Text(snapshot.data ?? '-'); // 3. data
      },
    );
  }
}

Urutan pengecekan selalu sama: loading → error → data. Jika urutannya terbalik, layar bisa menampilkan data lama ketika sedang memuat ulang.

Contoh Lengkap: Daftar Mahasiswa dari API

Contoh ini memakai MahasiswaModel (section 3) dan MahasiswaApiService (section 5). Tombol Coba Lagi bekerja dengan mengganti Future di dalam setState, sehingga FutureBuilder kembali ke status waiting lalu memuat ulang.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: flutter pub add http, serta membuat file model & service di atas.
import 'package:flutter/material.dart';

import 'models/mahasiswa_model.dart';
import 'services/mahasiswa_api_service.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: DaftarMahasiswaApiScreen(),
    );
  }
}

class DaftarMahasiswaApiScreen extends StatefulWidget {
  const DaftarMahasiswaApiScreen({super.key});

  @override
  State<DaftarMahasiswaApiScreen> createState() => _DaftarMahasiswaApiScreenState();
}

class _DaftarMahasiswaApiScreenState extends State<DaftarMahasiswaApiScreen> {
  late Future<List<MahasiswaModel>> _futureData;
  final MahasiswaApiService _apiService = MahasiswaApiService();

  @override
  void initState() {
    super.initState();
    // Simpan Future di initState agar tidak terpanggil berulang saat rebuild!
    _futureData = _apiService.fetchMahasiswa();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Data Mahasiswa dari Cloud")),
      body: FutureBuilder<List<MahasiswaModel>>(
        future: _futureData,
        builder: (context, snapshot) {
          // KONDISI 1: Sedang Menunggu Respon Jaringan (Loading)
          if (snapshot.connectionState == ConnectionState.waiting) {
            return const Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  CircularProgressIndicator(),
                  SizedBox(height: 12),
                  Text("Mengunduh data dari server kampus..."),
                ],
              ),
            );
          }

          // KONDISI 2: Terjadi Kesalahan Jaringan / Server Error
          if (snapshot.hasError) {
            return Center(
              child: Padding(
                padding: const EdgeInsets.all(20),
                child: Column(
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    const Icon(Icons.cloud_off, size: 64, color: Colors.red),
                    const SizedBox(height: 12),
                    Text("Terjadi Error: ${snapshot.error}"),
                    const SizedBox(height: 16),
                    ElevatedButton(
                      onPressed: () => setState(() => _futureData = _apiService.fetchMahasiswa()),
                      child: const Text("Coba Lagi"),
                    ),
                  ],
                ),
              ),
            );
          }

          // KONDISI 3: Data Berhasil Diterima
          final listMhs = snapshot.data ?? [];
          if (listMhs.isEmpty) {
            return const Center(child: Text("Tidak ada data mahasiswa ditemukan."));
          }

          return ListView.builder(
            itemCount: listMhs.length,
            itemBuilder: (context, index) {
              final mhs = listMhs[index];
              return ListTile(
                leading: CircleAvatar(
                  // foregroundImage + child: jika foto gagal dimuat, huruf awal nama tetap tampil
                  foregroundImage: NetworkImage(mhs.avatarUrl),
                  onForegroundImageError: (error, stackTrace) {},
                  child: Text(mhs.nama.isNotEmpty ? mhs.nama[0] : '?'),
                ),
                title: Text(mhs.nama, style: const TextStyle(fontWeight: FontWeight.bold)),
                subtitle: Text("NIM: ${mhs.nim} • ${mhs.email}"),
              );
            },
          );
        },
      ),
    );
  }
}
Kondisi 3 FutureBuilder: data berhasil dimuat

Penjelasan:

  • late Future<...> _futureData diisi di initState. Jika fungsi API dipanggil langsung di parameter future:, setiap rebuild (mis. keyboard muncul) akan mengirim request baru.
  • Kondisi 3 juga menangani list kosong. Data kosong bukan error, tetapi tetap perlu pesan agar layar tidak tampak "rusak".
  • foregroundImage + child pada CircleAvatar membuat huruf awal tetap tampil jika foto gagal dimuat.

⚠️ Kesalahan Umum

  • future: _apiService.fetchMahasiswa() langsung di build(): request berulang tanpa henti.
  • Hanya memeriksa snapshot.hasData tanpa hasError, sehingga saat error spinner berputar selamanya.
  • Memakai snapshot.data! sebelum memastikan statusnya, menyebabkan Null check operator used on a null value.
  • Data tidak muncul sama sekali di APK release: cek izin INTERNET (section 4).
