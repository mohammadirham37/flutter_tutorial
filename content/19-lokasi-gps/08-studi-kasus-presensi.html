Kita gabungkan seluruh materi bab ini menjadi aplikasi Presensi Kampus Berbasis Lokasi. Mahasiswa hanya bisa presensi jika berada dalam radius tertentu dari gedung kuliah (geofence sederhana), posisinya cukup akurat, dan lokasinya bukan lokasi palsu.

Aturan bisnis

  1. Layanan lokasi menyala dan izin lokasi diberikan. Jika tidak, tampilkan penjelasan dan tombol yang sesuai.
  2. Posisi diambil segar saat tombol ditekan (bukan posisi terakhir yang tersimpan).
  3. Posisi dengan isMocked == true ditolak.
  4. Akurasi harus diketahui dan tidak lebih dari 50 meter.
  5. Jarak ke titik kampus (distanceBetween) harus ≤ radius (100 meter).
  6. Satu kali presensi per hari.

Struktur proyek

flutter create --org id.ac.kampus presensi_kampus
cd presensi_kampus
flutter pub add geolocator flutter_map latlong2 get

// lib/services/aturan_presensi.dart
import 'package:geolocator/geolocator.dart';

import '../config/kampus.dart';

/// Hasil pemeriksaan: boleh presensi atau tidak, beserta alasannya.
class HasilValidasi {
  const HasilValidasi(this.boleh, this.pesan, {this.jarakMeter});

  final bool boleh;
  final String pesan;
  final double? jarakMeter;
}

/// Aturan presensi murni (tanpa UI dan tanpa GetX) sehingga mudah diuji.
class AturanPresensi {
  const AturanPresensi(this.kampus, {this.akurasiMaksimal = 50});

  final TitikKampus kampus;
  final double akurasiMaksimal;

  double jarakKeKampus(Position p) => Geolocator.distanceBetween(
    p.latitude,
    p.longitude,
    kampus.latitude,
    kampus.longitude,
  );

  HasilValidasi periksa(Position? posisi, {required bool sudahPresensi}) {
    if (sudahPresensi) {
      return const HasilValidasi(false, 'Kamu sudah presensi hari ini.');
    }
    if (posisi == null) {
      return const HasilValidasi(false, 'Menunggu posisi dari GPS...');
    }
    final jarak = jarakKeKampus(posisi);
    if (posisi.isMocked) {
      return HasilValidasi(
        false,
        'Terdeteksi lokasi palsu (mock location). Matikan aplikasi '
        'pemalsu lokasi lalu coba lagi.',
        jarakMeter: jarak,
      );
    }
    if (!posisi.hasAccuracy) {
      return HasilValidasi(
        false,
        'Akurasi GPS tidak diketahui. Tunggu sinyal yang lebih baik.',
        jarakMeter: jarak,
      );
    }
    if (posisi.accuracy > akurasiMaksimal) {
      return HasilValidasi(
        false,
        'Sinyal GPS belum akurat (± ${posisi.accuracy.toStringAsFixed(0)} m). '
        'Tunggu sebentar atau pindah ke ruang terbuka.',
        jarakMeter: jarak,
      );
    }
    if (jarak > kampus.radiusMeter) {
      return HasilValidasi(
        false,
        'Kamu berada ${jarak.toStringAsFixed(0)} m dari ${kampus.nama}. '
        'Presensi hanya bisa dalam radius '
        '${kampus.radiusMeter.toStringAsFixed(0)} m.',
        jarakMeter: jarak,
      );
    }
    return HasilValidasi(
      true,
      'Kamu berada di area kampus (${jarak.toStringAsFixed(0)} m).',
      jarakMeter: jarak,
    );
  }
}
  • Aturan dipisah dari controller agar bisa diuji dengan unit test tanpa emulator dan tanpa GPS (langkah 6).
  • Urutan pemeriksaan sengaja: sudah presensi, belum ada posisi, lokasi palsu, akurasi, baru jarak. Pesan yang paling relevan muncul lebih dulu.
  • Akurasi diperiksa karena posisi dengan akurasi ± 200 m bisa jatuh "di dalam" radius padahal pengguna sebenarnya di luar, atau sebaliknya.

📄 lib/controllers/riwayat_controller.dart

// lib/controllers/riwayat_controller.dart
import 'package:get/get.dart';

import '../models/catatan_presensi.dart';

/// Menyimpan riwayat presensi di memori selama aplikasi berjalan.
/// (Praktikum: simpan ke Hive atau kirim ke Supabase.)
class RiwayatController extends GetxController {
  final _daftar = <CatatanPresensi>[].obs;

  List<CatatanPresensi> get daftar => _daftar.reversed.toList();

  bool get sudahPresensiHariIni {
    final now = DateTime.now();
    return _daftar.any(
      (c) =>
          c.waktu.year == now.year &&
          c.waktu.month == now.month &&
          c.waktu.day == now.day,
    );
  }

  void tambah(CatatanPresensi catatan) => _daftar.add(catatan);
}

📄 lib/controllers/presensi_controller.dart

// lib/controllers/presensi_controller.dart
import 'dart:async';

import 'package:geolocator/geolocator.dart';
import 'package:get/get.dart';

import '../models/catatan_presensi.dart';
import '../services/aturan_presensi.dart';
import '../services/location_service.dart';
import 'riwayat_controller.dart';

class PresensiController extends GetxController {
  PresensiController(this._lokasi, this._aturan, this._riwayat);

  final LocationService _lokasi;
  final AturanPresensi _aturan;
  final RiwayatController _riwayat;

  final _posisi = Rxn<Position>();
  final _masalah = Rxn<KesiapanLokasi>(); // null = tidak ada masalah
  final _mengirim = false.obs;

  Position? get posisi => _posisi.value;
  KesiapanLokasi? get masalah => _masalah.value;
  bool get mengirim => _mengirim.value;

  /// Dihitung ulang setiap kali posisi atau riwayat berubah.
  HasilValidasi get validasi => _aturan.periksa(
    _posisi.value,
    sudahPresensi: _riwayat.sudahPresensiHariIni,
  );

  StreamSubscription<Position>? _langganan;

  @override
  void onInit() {
    super.onInit();
    mulai();
  }

  @override
  void onClose() {
    _langganan?.cancel(); // halaman ditutup = GPS berhenti
    super.onClose();
  }

  Future<void> mulai() async {
    final kesiapan = await _lokasi.periksaKesiapan();
    if (kesiapan != KesiapanLokasi.siap) {
      _masalah.value = kesiapan;
      return;
    }
    _masalah.value = null;

    await _langganan?.cancel();
    _langganan = _lokasi
        .aliranPosisi(jarakMinimal: 5)
        .listen(
          (p) => _posisi.value = p,
          onError: (Object e) => Get.snackbar('Lokasi', 'Pelacakan error: $e'),
        );
  }

  Future<void> bukaPengaturan() async {
    if (masalah == KesiapanLokasi.layananMati) {
      await _lokasi.bukaPengaturanLokasi();
    } else {
      await _lokasi.bukaPengaturanAplikasi();
    }
  }

  Future<void> kirimPresensi() async {
    if (_mengirim.value) return;
    _mengirim.value = true;
    try {
      // Ambil posisi segar tepat saat tombol ditekan, jangan hanya
      // mengandalkan update terakhir dari stream.
      final segar = await _lokasi.posisiSekarang(
        batasWaktu: const Duration(seconds: 10),
      );
      _posisi.value = segar;

      final hasil = validasi;
      if (!hasil.boleh) {
        Get.snackbar('Presensi ditolak', hasil.pesan);
        return;
      }
      _riwayat.tambah(
        CatatanPresensi(
          waktu: DateTime.now(),
          latitude: segar.latitude,
          longitude: segar.longitude,
          jarakMeter: hasil.jarakMeter ?? 0,
          akurasiMeter: segar.accuracy,
        ),
      );
      Get.back(); // kembali ke beranda
      Get.snackbar('Presensi berhasil', hasil.pesan);
    } on TimeoutException {
      Get.snackbar('Presensi', 'GPS tidak merespons, coba lagi.');
    } catch (e) {
      Get.snackbar('Presensi', 'Gagal: $e');
    } finally {
      _mengirim.value = false;
    }
  }
}
  • validasi adalah getter turunan, bukan state terpisah. Karena ia membaca _posisi dan daftar riwayat (keduanya .obs), setiap Obx yang memanggilnya otomatis diperbarui saat posisi berubah.
  • Stream memakai jarakMinimal: 5 sehingga lingkaran di peta berubah warna saat pengguna masuk atau keluar radius, tanpa membanjiri UI.
  • kirimPresensi() mengambil posisi segar dengan batas 10 detik sebelum memvalidasi. Posisi dari stream bisa saja sudah berumur beberapa menit jika pengguna diam.
  • Flag _mengirim mencegah tombol ditekan dua kali.
  • onClose() membatalkan stream. Karena controller ini didaftarkan lewat PresensiBinding, GetX menghapusnya saat halaman presensi ditutup, sehingga GPS ikut berhenti.

/// Controller halaman presensi: dibuat saat halaman dibuka,

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/riwayat_controller.dart';

class BerandaView extends GetView<RiwayatController> {
  const BerandaView({super.key});

  String _jam(DateTime w) =>
      '${w.hour.toString().padLeft(2, '0')}:'
      '${w.minute.toString().padLeft(2, '0')}';

  String _tanggal(DateTime w) => '${w.day}/${w.month}/${w.year}';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Presensi Kampus')),
      body: Obx(() {
        final daftar = controller.daftar;
        if (daftar.isEmpty) {
          return const Center(child: Text('Belum ada riwayat presensi.'));
        }
        return ListView.separated(
          itemCount: daftar.length,
          separatorBuilder: (_, _) => const Divider(height: 1),
          itemBuilder: (context, i) {
            final c = daftar[i];
            return ListTile(
              leading: const Icon(Icons.check_circle, color: Colors.green),
              title: Text('${_tanggal(c.waktu)} pukul ${_jam(c.waktu)}'),
              subtitle: Text(
                'Jarak ${c.jarakMeter.toStringAsFixed(0)} m • '
                'akurasi ± ${c.akurasiMeter.toStringAsFixed(0)} m',
              ),
            );
          },
        );
      }),
      floatingActionButton: Obx(
        () => FloatingActionButton.extended(
          onPressed: controller.sudahPresensiHariIni
              ? null
              : () => Get.toNamed('/presensi'),
          icon: const Icon(Icons.fingerprint),
          label: Text(
            controller.sudahPresensiHariIni
                ? 'Sudah presensi hari ini'
                : 'Presensi sekarang',
          ),
        ),
      ),
    );
  }
}

class _PanelMasalah extends GetView<PresensiController> {
  const _PanelMasalah({required this.masalah});

  final KesiapanLokasi masalah;

  @override
  Widget build(BuildContext context) {
    final (judul, bisaBuka) = switch (masalah) {
      KesiapanLokasi.layananMati => ('Layanan lokasi (GPS) mati.', true),
      KesiapanLokasi.ditolak => ('Presensi membutuhkan izin lokasi.', false),
      KesiapanLokasi.ditolakPermanen => (
        'Izin lokasi ditolak permanen. Aktifkan di pengaturan aplikasi.',
        true,
      ),
      KesiapanLokasi.siap => ('', false),
    };
    return Center(
      child: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            const Icon(Icons.location_off, size: 64),
            const SizedBox(height: 12),
            Text(judul, textAlign: TextAlign.center),
            const SizedBox(height: 16),
            FilledButton(
              onPressed: controller.mulai,
              child: const Text('Coba lagi'),
            ),
            if (bisaBuka)
              TextButton(
                onPressed: controller.bukaPengaturan,
                child: const Text('Buka pengaturan'),
              ),
          ],
        ),
      ),
    );
  }
}

📄 test/aturan_presensi_test.dart

// test/aturan_presensi_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:geolocator/geolocator.dart';
import 'package:presensi_kampus/config/kampus.dart';
import 'package:presensi_kampus/services/aturan_presensi.dart';

Position buatPosisi(
  double lat,
  double lng, {
  double akurasi = 10,
  bool palsu = false,
}) {
  return Position(
    latitude: lat,
    longitude: lng,
    timestamp: DateTime.now(),
    accuracy: akurasi,
    hasAccuracy: true,
    altitude: 0,
    altitudeAccuracy: 0,
    heading: 0,
    headingAccuracy: 0,
    speed: 0,
    speedAccuracy: 0,
    isMocked: palsu,
  );
}

void main() {
  const aturan = AturanPresensi(kampusUtama, akurasiMaksimal: 50);

  test('boleh presensi tepat di titik kampus', () {
    final hasil = aturan.periksa(
      buatPosisi(kampusUtama.latitude, kampusUtama.longitude),
      sudahPresensi: false,
    );
    expect(hasil.boleh, isTrue);
  });

  test('ditolak jika di luar radius (sekitar 1 km)', () {
    // 0.009 derajat lintang kira-kira 1 km
    final hasil = aturan.periksa(
      buatPosisi(kampusUtama.latitude + 0.009, kampusUtama.longitude),
      sudahPresensi: false,
    );
    expect(hasil.boleh, isFalse);
    expect(hasil.jarakMeter, greaterThan(900));
  });

  test('ditolak jika lokasi palsu walau di dalam radius', () {
    final hasil = aturan.periksa(
      buatPosisi(kampusUtama.latitude, kampusUtama.longitude, palsu: true),
      sudahPresensi: false,
    );
    expect(hasil.boleh, isFalse);
  });

  test('ditolak jika akurasi buruk', () {
    final hasil = aturan.periksa(
      buatPosisi(kampusUtama.latitude, kampusUtama.longitude, akurasi: 120),
      sudahPresensi: false,
    );
    expect(hasil.boleh, isFalse);
  });

  test('ditolak jika sudah presensi hari ini', () {
    final hasil = aturan.periksa(
      buatPosisi(kampusUtama.latitude, kampusUtama.longitude),
      sudahPresensi: true,
    );
    expect(hasil.boleh, isFalse);
  });
}

Jalankan dengan flutter test. Objek Position bisa dibuat sendiri dengan constructor-nya, dan distanceBetween adalah perhitungan murni, jadi test ini berjalan tanpa perangkat. Perhatikan hasAccuracy: true: nilai bawaannya false, sehingga tanpa baris itu semua posisi uji ditolak oleh aturan akurasi.

⚠️ isMocked bukan pengaman mutlak

isMocked bernilai true di Android jika posisi berasal dari aplikasi yang dipilih sebagai mock location app di Opsi Pengembang, dan di iOS 15+ jika sistem menandai lokasi disimulasikan perangkat lunak. Perangkat yang di-root atau dimodifikasi tetap bisa menyembunyikan tanda ini. Untuk presensi sungguhan, validasi akhir harus dilakukan di server: kirim koordinat, akurasi, waktu, dan flag mock ke backend (misalnya Supabase dari Modul 12), lalu gabungkan dengan bukti lain seperti jaringan Wi-Fi kampus, foto wajah (Modul 18), atau biometrik (Modul 21).
