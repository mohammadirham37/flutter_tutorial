Contoh di bagian sebelumnya menaruh semua logika di State widget. Itu cukup untuk belajar, tetapi sulit dipakai ulang dan diuji. Sekarang kita pecah dengan pola MVC dari Modul 08: LocationService membungkus geolocator, LocationController menyimpan state reaktif dan mengelola langganan stream, dan View hanya menampilkan lewat Obx.

Langkah 1: Service

📄 lib/services/location_service.dart

// lib/services/location_service.dart
import 'package:flutter/foundation.dart';
import 'package:geolocator/geolocator.dart';

/// Hasil pemeriksaan kesiapan lokasi (layanan + izin).
enum KesiapanLokasi { siap, layananMati, ditolak, ditolakPermanen }

/// Satu-satunya kelas yang memanggil package geolocator.
class LocationService {
  /// Cek layanan GPS, lalu cek dan (bila perlu) minta izin.
  Future<KesiapanLokasi> periksaKesiapan() async {
    if (!await Geolocator.isLocationServiceEnabled()) {
      return KesiapanLokasi.layananMati;
    }
    var izin = await Geolocator.checkPermission();
    if (izin == LocationPermission.denied) {
      izin = await Geolocator.requestPermission();
    }
    return switch (izin) {
      LocationPermission.whileInUse ||
      LocationPermission.always => KesiapanLokasi.siap,
      LocationPermission.deniedForever => KesiapanLokasi.ditolakPermanen,
      LocationPermission.denied ||
      LocationPermission.unableToDetermine => KesiapanLokasi.ditolak,
    };
  }

  /// Pengaturan per platform. [jarakMinimal] dalam meter.
  LocationSettings _pengaturan({int jarakMinimal = 0, Duration? batasWaktu}) {
    if (!kIsWeb && defaultTargetPlatform == TargetPlatform.android) {
      return AndroidSettings(
        accuracy: LocationAccuracy.high,
        distanceFilter: jarakMinimal,
        intervalDuration: const Duration(seconds: 5),
        timeLimit: batasWaktu,
      );
    }
    if (!kIsWeb && defaultTargetPlatform == TargetPlatform.iOS) {
      return AppleSettings(
        accuracy: LocationAccuracy.high,
        distanceFilter: jarakMinimal,
        activityType: ActivityType.fitness,
        pauseLocationUpdatesAutomatically: true,
        timeLimit: batasWaktu,
      );
    }
    return LocationSettings(
      accuracy: LocationAccuracy.high,
      distanceFilter: jarakMinimal,
      timeLimit: batasWaktu,
    );
  }

  Future<Position?> posisiTerakhir() => Geolocator.getLastKnownPosition();

  /// Melempar TimeoutException jika lewat [batasWaktu].
  Future<Position> posisiSekarang({
    Duration batasWaktu = const Duration(seconds: 15),
  }) {
    return Geolocator.getCurrentPosition(
      locationSettings: _pengaturan(batasWaktu: batasWaktu),
    );
  }

  Stream<Position> aliranPosisi({int jarakMinimal = 10}) {
    return Geolocator.getPositionStream(
      locationSettings: _pengaturan(jarakMinimal: jarakMinimal),
    );
  }

  double jarakMeter(double lat1, double lng1, double lat2, double lng2) =>
      Geolocator.distanceBetween(lat1, lng1, lat2, lng2);

  Future<bool> bukaPengaturanLokasi() => Geolocator.openLocationSettings();
  Future<bool> bukaPengaturanAplikasi() => Geolocator.openAppSettings();
}
  • periksaKesiapan() menggabungkan cek layanan dan alur izin dari bagian 2 menjadi satu enum milik aplikasi (KesiapanLokasi). Controller tidak perlu tahu ada lima nilai LocationPermission.
  • _pengaturan() menyembunyikan perbedaan Android dan iOS. Jika suatu saat akurasi atau interval ingin diubah, cukup ubah satu tempat.
  • Service tidak mengimpor GetX sama sekali, sehingga bisa dipakai ulang di proyek tanpa GetX.

Langkah 2: Controller

📄 lib/controllers/location_controller.dart

// lib/controllers/location_controller.dart
import 'dart:async';

import 'package:geolocator/geolocator.dart';
import 'package:get/get.dart';

import '../services/location_service.dart';

enum StatusLokasi {
  awal,
  memuat,
  siap,
  layananMati,
  ditolak,
  ditolakPermanen,
  gagal,
}

class LocationController extends GetxController {
  LocationController(this._service);
  final LocationService _service;

  // State reaktif privat + getter publik
  final _posisi = Rxn<Position>();
  final _status = StatusLokasi.awal.obs;
  final _pesan = ''.obs;
  final _melacak = false.obs;

  Position? get posisi => _posisi.value;
  StatusLokasi get status => _status.value;
  String get pesan => _pesan.value;
  bool get melacak => _melacak.value;

  StreamSubscription<Position>? _langganan;

  @override
  void onInit() {
    super.onInit();
    ambilPosisi();
  }

  @override
  void onClose() {
    _langganan?.cancel(); // hentikan GPS saat controller dihapus
    super.onClose();
  }

  /// Mengembalikan true jika lokasi boleh dipakai.
  Future<bool> _pastikanSiap() async {
    final kesiapan = await _service.periksaKesiapan();
    switch (kesiapan) {
      case KesiapanLokasi.siap:
        return true;
      case KesiapanLokasi.layananMati:
        _setStatus(StatusLokasi.layananMati, 'Layanan lokasi (GPS) mati.');
      case KesiapanLokasi.ditolak:
        _setStatus(StatusLokasi.ditolak, 'Izin lokasi ditolak.');
      case KesiapanLokasi.ditolakPermanen:
        _setStatus(
          StatusLokasi.ditolakPermanen,
          'Izin lokasi ditolak permanen. Aktifkan lewat pengaturan aplikasi.',
        );
    }
    return false;
  }

  void _setStatus(StatusLokasi s, [String pesan = '']) {
    _status.value = s;
    _pesan.value = pesan;
  }

  Future<void> ambilPosisi() async {
    _setStatus(StatusLokasi.memuat);
    if (!await _pastikanSiap()) return;

    // Tampilkan posisi terakhir dulu agar layar tidak kosong
    _posisi.value ??= await _service.posisiTerakhir();

    try {
      _posisi.value = await _service.posisiSekarang();
      _setStatus(StatusLokasi.siap);
    } on TimeoutException {
      _setStatus(StatusLokasi.gagal, 'Sinyal GPS lemah, coba lagi.');
    } on LocationServiceDisabledException {
      _setStatus(StatusLokasi.layananMati, 'Layanan lokasi (GPS) mati.');
    } on PermissionDeniedException {
      _setStatus(StatusLokasi.ditolak, 'Izin lokasi ditolak.');
    } catch (e) {
      _setStatus(StatusLokasi.gagal, 'Gagal mengambil lokasi: $e');
    }
  }

  Future<void> mulaiLacak() async {
    if (_langganan != null) return; // jangan dobel langganan
    if (!await _pastikanSiap()) return;

    _langganan = _service
        .aliranPosisi(jarakMinimal: 10)
        .listen(
          (p) {
            _posisi.value = p;
            _setStatus(StatusLokasi.siap);
          },
          onError: (Object e) {
            _setStatus(StatusLokasi.gagal, 'Pelacakan berhenti: $e');
            hentikanLacak();
          },
        );
    _melacak.value = true;
  }

  Future<void> hentikanLacak() async {
    await _langganan?.cancel();
    _langganan = null;
    _melacak.value = false;
  }

  /// Membuka halaman pengaturan yang sesuai dengan masalahnya.
  Future<void> bukaPengaturan() async {
    if (status == StatusLokasi.layananMati) {
      await _service.bukaPengaturanLokasi();
    } else {
      await _service.bukaPengaturanAplikasi();
    }
  }
}
  • Rxn<Position>() adalah Rx yang boleh bernilai null, cocok untuk "posisi belum ada".
  • State privat (_posisi, _status) dengan getter publik read-only, sama seperti pola Modul 08. View tidak bisa mengubah posisi secara langsung.
  • _posisi.value ??= await _service.posisiTerakhir(); mengisi posisi terakhir hanya jika belum ada posisi sama sekali, agar layar tidak kosong selama menunggu GPS.
  • mulaiLacak() menolak membuat langganan kedua (if (_langganan != null) return;).
  • onClose() membatalkan langganan. GetX memanggil onClose saat controller dihapus dari memori (misalnya halaman yang memakai binding ditutup). Ini padanan dispose() di StatefulWidget.
  • Controller tidak mengimpor material.dart. Pesan untuk pengguna disimpan sebagai String; cara menampilkannya urusan View.

Langkah 3: View

📄 lib/views/lokasi_view.dart

// lib/views/lokasi_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/location_controller.dart';

class LokasiView extends GetView<LocationController> {
  const LokasiView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Lokasi (GetX)'),
        actions: [
          IconButton(
            onPressed: controller.ambilPosisi,
            icon: const Icon(Icons.refresh),
            tooltip: 'Ambil ulang',
          ),
        ],
      ),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Obx(() {
          final p = controller.posisi;
          return Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              if (controller.status == StatusLokasi.memuat)
                const LinearProgressIndicator(),
              if (controller.pesan.isNotEmpty)
                _KartuMasalah(
                  pesan: controller.pesan,
                  bisaDibuka:
                      controller.status == StatusLokasi.layananMati ||
                      controller.status == StatusLokasi.ditolakPermanen,
                  onBuka: controller.bukaPengaturan,
                  onCobaLagi: controller.ambilPosisi,
                ),
              const SizedBox(height: 16),
              Text(
                p == null
                    ? 'Posisi belum tersedia'
                    : '${p.latitude.toStringAsFixed(6)}, '
                          '${p.longitude.toStringAsFixed(6)}',
                style: Theme.of(context).textTheme.headlineSmall,
                textAlign: TextAlign.center,
              ),
              if (p != null)
                Text(
                  'Akurasi ± ${p.accuracy.toStringAsFixed(0)} m'
                  '${p.isMocked ? ' • LOKASI PALSU' : ''}',
                  textAlign: TextAlign.center,
                ),
              const Spacer(),
              FilledButton.icon(
                onPressed: controller.melacak
                    ? controller.hentikanLacak
                    : controller.mulaiLacak,
                icon: Icon(controller.melacak ? Icons.stop : Icons.play_arrow),
                label: Text(
                  controller.melacak ? 'Hentikan pelacakan' : 'Lacak terus',
                ),
              ),
            ],
          );
        }),
      ),
    );
  }
}

class _KartuMasalah extends StatelessWidget {
  const _KartuMasalah({
    required this.pesan,
    required this.bisaDibuka,
    required this.onBuka,
    required this.onCobaLagi,
  });

  final String pesan;
  final bool bisaDibuka;
  final VoidCallback onBuka;
  final VoidCallback onCobaLagi;

  @override
  Widget build(BuildContext context) {
    return Card(
      color: Theme.of(context).colorScheme.errorContainer,
      child: Padding(
        padding: const EdgeInsets.all(12),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(pesan),
            const SizedBox(height: 8),
            Wrap(
              spacing: 8,
              children: [
                OutlinedButton(
                  onPressed: onCobaLagi,
                  child: const Text('Coba lagi'),
                ),
                if (bisaDibuka)
                  FilledButton(
                    onPressed: onBuka,
                    child: const Text('Buka pengaturan'),
                  ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}

GetView<LocationController> menyediakan getter controller (hasil Get.find). Seluruh isi body dibungkus satu Obx karena hampir semua bagiannya bergantung pada state controller. Tombol "Buka pengaturan" hanya muncul untuk masalah yang memang butuh pengaturan (GPS mati atau izin ditolak permanen). Untuk izin yang ditolak biasa, tombol "Coba lagi" sudah cukup karena dialog izin masih bisa muncul.

Langkah 4: main.dart

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/location_controller.dart';
import 'services/location_service.dart';
import 'views/lokasi_view.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  Get.put(LocationService(), permanent: true);
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      initialBinding: BindingsBuilder(() {
        Get.lazyPut(() => LocationController(Get.find<LocationService>()));
      }),
      home: const LokasiView(),
    );
  }
}

LocationService didaftarkan sekali dengan permanent: true karena dipakai seluruh aplikasi. LocationController didaftarkan lewat initialBinding dan menerima service lewat constructor, persis seperti pola Modul 08 bagian 4 dan 7.

ℹ️ Controller global vs per halaman

Controller dari initialBinding hidup selama aplikasi berjalan, jadi onClose-nya praktis tidak pernah dipanggil. Untuk fitur yang memakai stream GPS, lebih baik controller dibuat per halaman lewat binding di GetPage, sehingga stream otomatis berhenti saat halaman ditutup. Pola inilah yang dipakai di studi kasus berikutnya.

⚠️ Kesalahan umum

  • Memanggil Geolocator.getPositionStream() langsung dari View. Stream jadi sulit dihentikan dan logika izin tersebar di banyak widget.
  • Lupa super.onClose() atau lupa cancel() di onClose: GPS tetap aktif setelah halaman ditutup, baterai terkuras.
  • Membaca controller.posisi di luar Obx, sehingga tampilan tidak pernah berubah saat posisi baru datang.
