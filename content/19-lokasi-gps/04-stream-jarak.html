getCurrentPosition cocok untuk "sekali ambil". Untuk aplikasi yang harus mengikuti pergerakan pengguna (navigasi, pelacak lari, atau penanda yang bergerak di peta) kita berlangganan stream posisi. Bagian ini juga membahas cara menghitung jarak dan arah antara dua koordinat.

Contoh kecil: berlangganan stream

import 'package:flutter/foundation.dart';

import 'dart:async';

import 'package:geolocator/geolocator.dart';

StreamSubscription<Position>? langganan;

void mulaiDengar() {
  langganan =
      Geolocator.getPositionStream(
        locationSettings: const LocationSettings(
          accuracy: LocationAccuracy.high,
          distanceFilter: 10, // meter
        ),
      ).listen(
        (Position p) => debugPrint('Baru: ${p.latitude}, ${p.longitude}'),
        onError: (Object e) => debugPrint('Error: $e'),
      );
}

Future<void> berhentiDengar() async {
  await langganan?.cancel();
  langganan = null;
}
  • distanceFilter: 10 berarti stream hanya mengirim posisi baru jika perangkat sudah berpindah minimal 10 meter secara horizontal. Nilai 0 berarti setiap update dikirim, yang boros baterai dan membuat UI terus dibangun ulang.
  • listen mengembalikan StreamSubscription. Selama langganan aktif, GPS terus bekerja. Wajib dibatalkan dengan cancel() saat tidak dipakai.
  • onError menerima error stream, misalnya LocationServiceDisabledException saat pengguna mematikan GPS di tengah jalan, atau TimeoutException jika timeLimit diisi dan tidak ada update dalam rentang tersebut.
  • Di Android, AndroidSettings(intervalDuration: ...) mengatur jeda minimal antar-update. Di iOS, AppleSettings(pauseLocationUpdatesAutomatically: true) membiarkan sistem menjeda update saat pengguna diam.

Jarak dan arah antara dua titik

Bumi itu bulat, jadi jarak dua koordinat tidak bisa dihitung dengan rumus Pythagoras biasa. geolocator menyediakan dua fungsi statis yang tidak butuh izin maupun GPS (murni perhitungan):

import 'package:flutter/foundation.dart';
import 'package:geolocator/geolocator.dart';

void hitung() {
  // Dari Monas ke Bundaran HI (Jakarta)
  final meter = Geolocator.distanceBetween(
    -6.175392,
    106.827153,
    -6.194946,
    106.823053,
  );
  final derajat = Geolocator.bearingBetween(
    -6.175392,
    106.827153,
    -6.194946,
    106.823053,
  );
  debugPrint('Jarak: ${(meter / 1000).toStringAsFixed(2)} km');
  debugPrint('Arah: ${derajat.toStringAsFixed(0)}°');
}
  • distanceBetween(lat1, lng1, lat2, lng2) mengembalikan jarak garis lurus di permukaan bumi dalam meter, bukan jarak jalan kaki mengikuti jalan.
  • bearingBetween(...) mengembalikan arah dari titik pertama ke titik kedua dalam derajat, dengan 0 = utara, 90 = timur, dan nilai negatif untuk arah barat (rentang -180 sampai 180).
  • Urutan argumen selalu latitude dulu, baru longitude. Tertukar sedikit saja hasilnya meleset ribuan kilometer.

Contoh lengkap: pelacak jalan kaki

Aplikasi ini menjumlahkan jarak yang ditempuh selama pelacakan, menampilkan jarak dan arah ke gedung tujuan, serta mendengarkan perubahan status GPS.

📄 lib/main.dart

// lib/main.dart
import 'dart:async';
import 'dart:math' as math;

import 'package:flutter/material.dart';
import 'package:geolocator/geolocator.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const PelacakPage(),
    );
  }
}

// Titik tujuan contoh. Ganti dengan koordinat gedung di kampusmu.
const double tujuanLat = -6.3628;
const double tujuanLng = 106.8269;

class PelacakPage extends StatefulWidget {
  const PelacakPage({super.key});

  @override
  State<PelacakPage> createState() => _PelacakPageState();
}

class _PelacakPageState extends State<PelacakPage> {
  StreamSubscription<Position>? _langgananPosisi;
  StreamSubscription<ServiceStatus>? _langgananLayanan;

  Position? _posisi;
  double _totalJarak = 0; // meter
  int _jumlahUpdate = 0;
  String? _error;

  bool get _sedangMelacak => _langgananPosisi != null;

  @override
  void initState() {
    super.initState();
    // Dengarkan saat pengguna mematikan / menyalakan GPS (Android & iOS)
    _langgananLayanan = Geolocator.getServiceStatusStream().listen((status) {
      if (!mounted) return;
      setState(() {
        _error = status == ServiceStatus.disabled
            ? 'GPS dimatikan. Pelacakan berhenti menerima data.'
            : null;
      });
    });
  }

  Future<void> _mulai() async {
    var izin = await Geolocator.checkPermission();
    if (izin == LocationPermission.denied) {
      izin = await Geolocator.requestPermission();
    }
    if (!mounted) return;
    if (izin == LocationPermission.denied ||
        izin == LocationPermission.deniedForever) {
      setState(() => _error = 'Izin lokasi ditolak.');
      return;
    }

    const pengaturan = LocationSettings(
      accuracy: LocationAccuracy.high,
      distanceFilter: 5, // kirim update hanya jika berpindah >= 5 meter
    );

    setState(() {
      _error = null;
      _posisi = null;
      _totalJarak = 0;
      _jumlahUpdate = 0;
      _langgananPosisi = Geolocator.getPositionStream(
        locationSettings: pengaturan,
      ).listen(_saatPosisiBaru, onError: _saatError);
    });
  }

  void _saatPosisiBaru(Position baru) {
    final lama = _posisi;
    setState(() {
      if (lama != null) {
        _totalJarak += Geolocator.distanceBetween(
          lama.latitude,
          lama.longitude,
          baru.latitude,
          baru.longitude,
        );
      }
      _posisi = baru;
      _jumlahUpdate++;
    });
  }

  void _saatError(Object e) {
    if (!mounted) return;
    setState(() => _error = 'Stream lokasi error: $e');
    _berhenti();
  }

  Future<void> _berhenti() async {
    await _langgananPosisi?.cancel();
    if (!mounted) return;
    setState(() => _langgananPosisi = null);
  }

  @override
  void dispose() {
    // WAJIB: hentikan stream agar GPS tidak terus menyala
    _langgananPosisi?.cancel();
    _langgananLayanan?.cancel();
    super.dispose();
  }

  String _arahMataAngin(double derajat) {
    const arah = [
      'Utara',
      'Timur Laut',
      'Timur',
      'Tenggara',
      'Selatan',
      'Barat Daya',
      'Barat',
      'Barat Laut',
    ];
    final normal = (derajat + 360) % 360; // -180..180 menjadi 0..360
    return arah[((normal + 22.5) ~/ 45) % 8];
  }

  @override
  Widget build(BuildContext context) {
    final p = _posisi;
    double? jarakKeTujuan;
    double? bearing;
    if (p != null) {
      jarakKeTujuan = Geolocator.distanceBetween(
        p.latitude,
        p.longitude,
        tujuanLat,
        tujuanLng,
      );
      bearing = Geolocator.bearingBetween(
        p.latitude,
        p.longitude,
        tujuanLat,
        tujuanLng,
      );
    }

    return Scaffold(
      appBar: AppBar(title: const Text('Pelacak Jalan Kaki')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          if (_error != null)
            Card(
              color: Theme.of(context).colorScheme.errorContainer,
              child: ListTile(title: Text(_error!)),
            ),
          ListTile(
            leading: const Icon(Icons.route),
            title: const Text('Total jarak ditempuh'),
            subtitle: Text(
              '${_totalJarak.toStringAsFixed(1)} m '
              '($_jumlahUpdate update)',
            ),
          ),
          if (p != null)
            ListTile(
              leading: const Icon(Icons.place),
              title: const Text('Posisi sekarang'),
              subtitle: Text(
                '${p.latitude.toStringAsFixed(6)}, '
                '${p.longitude.toStringAsFixed(6)}',
              ),
            ),
          if (jarakKeTujuan != null && bearing != null)
            ListTile(
              leading: Transform.rotate(
                angle: bearing * math.pi / 180,
                child: const Icon(Icons.navigation),
              ),
              title: Text(
                'Gedung tujuan: ${(jarakKeTujuan / 1000).toStringAsFixed(2)} km',
              ),
              subtitle: Text(
                'Arah ${bearing.toStringAsFixed(0)}° '
                '(${_arahMataAngin(bearing)})',
              ),
            ),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _sedangMelacak ? _berhenti : _mulai,
        icon: Icon(_sedangMelacak ? Icons.stop : Icons.play_arrow),
        label: Text(_sedangMelacak ? 'Berhenti' : 'Mulai lacak'),
      ),
    );
  }
}

Penjelasan baris penting

  • Dua langganan, dua cancel(). _langgananPosisi untuk posisi dan _langgananLayanan untuk status GPS. Keduanya dibatalkan di dispose(). Lupa membatalkan berarti GPS terus menyala walau halaman sudah ditutup, dan callback memanggil setState pada widget yang sudah tidak ada.
  • getServiceStatusStream() mengirim ServiceStatus.enabled/disabled setiap kali pengguna menyalakan atau mematikan GPS. Fungsi ini tidak didukung di web.
  • Total jarak dihitung dengan menjumlahkan distanceBetween antara posisi lama dan posisi baru. Karena distanceFilter 5 meter, guncangan kecil saat diam tidak ikut terhitung.
  • _sedangMelacak diturunkan dari _langgananPosisi != null, sehingga tidak ada dua sumber kebenaran yang bisa tidak sinkron.
  • Ikon panah diputar dengan Transform.rotate sebesar bearing (diubah ke radian). Ini arah relatif terhadap utara peta, bukan terhadap arah hadap ponsel. Untuk kompas sungguhan dibutuhkan sensor magnetometer (Modul 20).

💡 Menyaring posisi yang buruk

Di dalam gedung, GPS kadang "melompat" puluhan meter, sehingga total jarak membengkak padahal pengguna diam. Trik sederhana: abaikan posisi dengan accuracy lebih dari 30 meter sebelum menambahkannya ke total. Trik ini juga dipakai di studi kasus presensi.

⚠️ Kesalahan umum

  • Memanggil getPositionStream(...).listen(...) di dalam build(). Setiap rebuild membuat langganan baru dan GPS dibuka berkali-kali.
  • Menekan tombol "Mulai" dua kali sehingga ada dua langganan aktif. Cek dulu apakah langganan sudah ada.
  • Menghitung jarak dengan sqrt(dLat² + dLng²). Hasilnya dalam "derajat", bukan meter, dan salah besar jauh dari khatulistiwa.
