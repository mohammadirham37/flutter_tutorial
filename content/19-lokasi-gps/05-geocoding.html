Koordinat seperti -6.175392, 106.827153 berguna bagi mesin, tetapi pengguna lebih paham "Gambir, Jakarta Pusat". Proses mengubah koordinat menjadi alamat disebut reverse geocoding, sedangkan alamat menjadi koordinat disebut geocoding (forward). Package geocoding memakai layanan bawaan Android dan iOS, sehingga tidak perlu API key.

Perubahan API terbaru

Sejak versi 5, semua fungsi geocoding dibungkus dalam kelas Geocoding. Tutorial lama yang memanggil fungsi global placemarkFromCoordinates(...) dan setLocaleIdentifier('id_ID') sudah tidak sesuai: bahasa sekarang diatur lewat parameter locale di constructor (atau per pemanggilan).

Contoh kecil

import 'package:flutter/widgets.dart';
import 'package:geocoding/geocoding.dart';

Future<void> alamatSingkat() async {
  final geocoding = Geocoding(locale: const Locale('id', 'ID'));
  final List<Placemark> hasil = await geocoding.placemarkFromCoordinates(
    -6.175392,
    106.827153,
  );
  if (hasil.isNotEmpty) {
    final p = hasil.first;
    debugPrint(
      '${p.street}, ${p.subLocality}, ${p.locality}, '
      '${p.administrativeArea}',
    );
  }
}

Fungsi yang tersedia di objek Geocoding:

MethodMasukanHasil
placemarkFromCoordinates(lat, lng)KoordinatList<Placemark> (alamat)
locationFromAddress(alamat)Teks alamatList<Location> berisi latitude, longitude, timestamp (bisa null)
placemarkFromAddress(alamat)Alamat sebagianList<Placemark> yang lebih lengkap
isPresent()-true jika layanan geocoder tersedia di perangkat

Isi Placemark dan pemetaannya di Indonesia

Semua field Placemark bertipe String? dan bisa kosong. Pemetaannya ke wilayah administrasi Indonesia tidak selalu konsisten antar-lokasi, jadi anggap tabel ini sebagai perkiraan:

FieldBiasanya berisi
street, thoroughfare, subThoroughfareNama jalan dan nomor
subLocalityKelurahan/desa atau kecamatan
localityKecamatan atau kota
subAdministrativeAreaKabupaten/kota
administrativeAreaProvinsi
postalCode, country, isoCountryCodeKode pos, negara, kode negara (ID)

Contoh lengkap: koordinat ⇄ alamat

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:geocoding/geocoding.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const AlamatPage(),
    );
  }
}

/// Menggabungkan bagian Placemark yang tidak kosong menjadi satu baris alamat.
String formatAlamat(Placemark p) {
  final bagian = [
    p.street,
    p.subLocality, // kelurahan / desa
    p.locality, // kecamatan / kota (tergantung data)
    p.subAdministrativeArea, // kabupaten / kota
    p.administrativeArea, // provinsi
    p.postalCode,
  ];
  return bagian.where((s) => s != null && s.trim().isNotEmpty).join(', ');
}

class AlamatPage extends StatefulWidget {
  const AlamatPage({super.key});

  @override
  State<AlamatPage> createState() => _AlamatPageState();
}

class _AlamatPageState extends State<AlamatPage> {
  // Satu instance untuk seluruh halaman, hasil dalam bahasa Indonesia
  final _geocoding = Geocoding(locale: const Locale('id', 'ID'));

  final _latC = TextEditingController(text: '-6.175392');
  final _lngC = TextEditingController(text: '106.827153');
  final _alamatC = TextEditingController(text: 'Monumen Nasional, Jakarta');

  String _hasil = '';
  bool _memuat = false;

  @override
  void dispose() {
    _latC.dispose();
    _lngC.dispose();
    _alamatC.dispose();
    super.dispose();
  }

  Future<void> _koordinatKeAlamat() async {
    final lat = double.tryParse(_latC.text);
    final lng = double.tryParse(_lngC.text);
    if (lat == null || lng == null) {
      setState(() => _hasil = 'Latitude/longitude tidak valid.');
      return;
    }
    setState(() => _memuat = true);
    try {
      final daftar = await _geocoding.placemarkFromCoordinates(lat, lng);
      if (!mounted) return;
      setState(() {
        _hasil = daftar.isEmpty
            ? 'Alamat tidak ditemukan.'
            : formatAlamat(daftar.first);
      });
    } on PlatformException catch (e) {
      if (!mounted) return;
      // IO_ERROR biasanya: tidak ada internet atau kena batas permintaan
      setState(() => _hasil = 'Gagal (${e.code}): ${e.message}');
    } finally {
      if (mounted) setState(() => _memuat = false);
    }
  }

  Future<void> _alamatKeKoordinat() async {
    setState(() => _memuat = true);
    try {
      final daftar = await _geocoding.locationFromAddress(_alamatC.text);
      if (!mounted) return;
      setState(() {
        _hasil = daftar.isEmpty
            ? 'Koordinat tidak ditemukan.'
            : '${daftar.first.latitude}, ${daftar.first.longitude}';
      });
    } on PlatformException catch (e) {
      if (!mounted) return;
      setState(() => _hasil = 'Gagal (${e.code}): ${e.message}');
    } finally {
      if (mounted) setState(() => _memuat = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Geocoding')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Row(
            children: [
              Expanded(
                child: TextField(
                  controller: _latC,
                  decoration: const InputDecoration(labelText: 'Latitude'),
                  keyboardType: const TextInputType.numberWithOptions(
                    signed: true,
                    decimal: true,
                  ),
                ),
              ),
              const SizedBox(width: 12),
              Expanded(
                child: TextField(
                  controller: _lngC,
                  decoration: const InputDecoration(labelText: 'Longitude'),
                  keyboardType: const TextInputType.numberWithOptions(
                    signed: true,
                    decimal: true,
                  ),
                ),
              ),
            ],
          ),
          const SizedBox(height: 8),
          FilledButton(
            onPressed: _memuat ? null : _koordinatKeAlamat,
            child: const Text('Koordinat → Alamat'),
          ),
          const Divider(height: 32),
          TextField(
            controller: _alamatC,
            decoration: const InputDecoration(labelText: 'Alamat'),
          ),
          const SizedBox(height: 8),
          FilledButton.tonal(
            onPressed: _memuat ? null : _alamatKeKoordinat,
            child: const Text('Alamat → Koordinat'),
          ),
          const SizedBox(height: 24),
          if (_memuat) const LinearProgressIndicator(),
          SelectableText(_hasil),
        ],
      ),
    );
  }
}

Penjelasan baris penting

  • Geocoding(locale: const Locale('id', 'ID')) dibuat sekali sebagai field, sehingga semua hasil berbahasa Indonesia (misalnya "Daerah Khusus Ibukota Jakarta").
  • formatAlamat menyaring field yang null atau kosong sebelum digabung. Tanpa ini, alamat bisa berisi teks "null, , Jakarta".
  • Di Android, jika tidak ada hasil, geocoding mengembalikan list kosong, jadi selalu cek isEmpty sebelum .first.
  • Kegagalan jaringan atau batas permintaan dilaporkan sebagai PlatformException. Kode IO_ERROR umumnya berarti tidak ada internet atau aplikasi terlalu sering meminta.
  • TextInputType.numberWithOptions(signed: true, decimal: true) memunculkan tombol minus dan titik desimal, karena latitude Indonesia bagian selatan bernilai negatif.

⚠️ Batasan geocoding gratis

  • Butuh internet dan, di Android, Google Play services. Emulator tanpa Play Store (image "Google APIs" tanpa Play) atau tanpa internet sering mengembalikan error.
  • Ada batas frekuensi. Jangan memanggil geocoding di setiap update stream posisi. Panggil sekali saat posisi berubah cukup jauh (misalnya lebih dari 50 meter) atau saat pengguna menekan tombol.
  • Hasil alamat adalah perkiraan. Untuk presensi, keputusan selalu berdasarkan koordinat dan jarak, bukan teks alamat.
