Menampilkan posisi di peta jauh lebih mudah dipahami daripada angka koordinat. Di bab ini kita memakai flutter_map dengan ubin (tile) OpenStreetMap (OSM). Tidak perlu akun cloud maupun API key, cocok untuk praktikum. Koordinat di flutter_map memakai kelas LatLng dari package latlong2.

Cara kerja peta ubin

Peta dunia dipotong menjadi gambar persegi 256×256 piksel untuk setiap tingkat zoom. URL https://tile.openstreetmap.org/{z}/{x}/{y}.png berarti: ambil ubin pada zoom z, kolom x, baris y. flutter_map mengunduh ubin yang terlihat di layar lalu menyusunnya. Di atas lapisan ubin kita bisa menumpuk lapisan lain: lingkaran, garis, dan penanda.

Widget/kelasFungsi
FlutterMapWidget peta. Anak-anaknya (children) adalah lapisan yang ditumpuk dari bawah ke atas
MapOptionsinitialCenter, initialZoom, onTap, batas zoom, dsb.
TileLayerLapisan ubin: urlTemplate dan userAgentPackageName
CircleLayer + CircleMarkerLingkaran, bisa dalam piksel atau meter (useRadiusInMeter: true)
MarkerLayer + MarkerWidget apa pun yang ditempel di sebuah koordinat
RichAttributionWidgetAtribusi sumber data peta
MapControllerMenggerakkan kamera dari kode: move(titik, zoom)

Contoh kecil: jarak dengan latlong2

latlong2 juga bisa menghitung jarak tanpa geolocator. Ini berguna di kode yang sudah memakai LatLng:

import 'package:flutter/foundation.dart';
import 'package:latlong2/latlong.dart';

void contohLatLng() {
  const kampus = LatLng(-6.3628, 106.8269);
  const halte = LatLng(-6.3605, 106.8312);
  const distance = Distance();
  final meter = distance.as(LengthUnit.Meter, kampus, halte);
  debugPrint('Kampus ke halte: $meter m');
}

Contoh lengkap: peta kampus dengan lokasi saya

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter_map/flutter_map.dart';
import 'package:geolocator/geolocator.dart';
import 'package:latlong2/latlong.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const PetaPage(),
    );
  }
}

// Titik contoh. Ganti dengan koordinat kampusmu.
const titikKampus = LatLng(-6.3628, 106.8269);

class PetaPage extends StatefulWidget {
  const PetaPage({super.key});

  @override
  State<PetaPage> createState() => _PetaPageState();
}

class _PetaPageState extends State<PetaPage> {
  final _mapController = MapController();
  LatLng? _posisiSaya;
  LatLng? _titikDipilih;

  @override
  void dispose() {
    _mapController.dispose();
    super.dispose();
  }

  Future<void> _keLokasiSaya() async {
    var izin = await Geolocator.checkPermission();
    if (izin == LocationPermission.denied) {
      izin = await Geolocator.requestPermission();
    }
    if (izin == LocationPermission.denied ||
        izin == LocationPermission.deniedForever) {
      if (!mounted) return;
      ScaffoldMessenger.of(context)
          .showSnackBar(const SnackBar(content: Text('Izin lokasi ditolak.')));
      return;
    }

    try {
      final p = await Geolocator.getCurrentPosition(
        locationSettings: const LocationSettings(
          accuracy: LocationAccuracy.high,
          timeLimit: Duration(seconds: 15),
        ),
      );
      if (!mounted) return;
      final titik = LatLng(p.latitude, p.longitude);
      setState(() => _posisiSaya = titik);
      _mapController.move(titik, 17); // geser kamera + zoom 17
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context)
          .showSnackBar(SnackBar(content: Text('Gagal mengambil lokasi: $e')));
    }
  }

  @override
  Widget build(BuildContext context) {
    final skema = Theme.of(context).colorScheme;
    return Scaffold(
      appBar: AppBar(title: const Text('Peta Kampus')),
      body: FlutterMap(
        mapController: _mapController,
        options: MapOptions(
          initialCenter: titikKampus,
          initialZoom: 16,
          onTap: (tapPosition, titik) => setState(() => _titikDipilih = titik),
        ),
        children: [
          // 1. Lapisan ubin (tile) dari OpenStreetMap
          TileLayer(
            urlTemplate: 'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
            userAgentPackageName: 'id.ac.kampus.v19',
          ),
          // 2. Lingkaran radius 100 meter di sekitar kampus
          CircleLayer(
            circles: [
              CircleMarker(
                point: titikKampus,
                radius: 100,
                useRadiusInMeter: true,
                color: skema.primary.withValues(alpha: 0.15),
                borderColor: skema.primary,
                borderStrokeWidth: 2,
              ),
            ],
          ),
          // 3. Penanda (marker)
          MarkerLayer(
            markers: [
              const Marker(
                point: titikKampus,
                width: 48,
                height: 48,
                child: Icon(Icons.school, size: 40, color: Colors.indigo),
              ),
              if (_posisiSaya != null)
                Marker(
                  point: _posisiSaya!,
                  width: 24,
                  height: 24,
                  child: Container(
                    decoration: BoxDecoration(
                      color: Colors.blue,
                      shape: BoxShape.circle,
                      border: Border.all(color: Colors.white, width: 3),
                    ),
                  ),
                ),
              if (_titikDipilih != null)
                Marker(
                  point: _titikDipilih!,
                  width: 40,
                  height: 40,
                  alignment: Alignment.topCenter, // ujung pin tepat di titik
                  child: const Icon(
                    Icons.location_pin,
                    size: 40,
                    color: Colors.red,
                  ),
                ),
            ],
          ),
          // 4. Atribusi wajib untuk data OpenStreetMap
          const RichAttributionWidget(
            attributions: [TextSourceAttribution('OpenStreetMap contributors')],
          ),
        ],
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _keLokasiSaya,
        tooltip: 'Lokasi saya',
        child: const Icon(Icons.my_location),
      ),
    );
  }
}

Penjelasan baris penting

  • Urutan children = urutan lapisan. TileLayer paling bawah, lalu lingkaran, lalu penanda, dan atribusi paling atas. Jika TileLayer diletakkan terakhir, ubin peta menutupi semua penanda.
  • userAgentPackageName diisi dengan package name aplikasimu (sama dengan applicationId di android/app/build.gradle.kts). Server OSM memakai User-Agent untuk mengenali aplikasi. Tanpa ini flutter_map mencetak peringatan di konsol debug, dan aplikasimu berisiko diblokir.
  • CircleMarker(useRadiusInMeter: true, radius: 100) menggambar lingkaran 100 meter sungguhan yang ikut membesar saat di-zoom. Tanpa useRadiusInMeter, radius dihitung dalam piksel layar.
  • Marker wajib punya point, width, height, dan child. Secara bawaan titik koordinat berada di tengah widget. Untuk ikon pin, alignment: Alignment.topCenter menaruh seluruh widget di atas titik sehingga ujung pin tepat menunjuk lokasinya.
  • MapOptions.onTap memberi LatLng titik yang disentuh. Ini dasar fitur "pilih lokasi di peta".
  • _mapController.move(titik, 17) memindahkan kamera. MapController dibuat sendiri, jadi dibuang di dispose().

⚠️ Atribusi dan kebijakan pemakaian OSM

Data OpenStreetMap berlisensi ODbL dan wajib menampilkan atribusi "© OpenStreetMap contributors". RichAttributionWidget menampilkan ikon info di pojok peta yang berisi teks tersebut (TextSourceAttribution otomatis menambah simbol ©). Server tile.openstreetmap.org dijalankan sukarelawan dengan Tile Usage Policy: boleh untuk belajar dan aplikasi bertrafik kecil, tetapi aplikasi produksi dengan banyak pengguna sebaiknya memakai penyedia ubin komersial atau server sendiri. Jangan pernah mengunduh massal ubin untuk mode offline dari server publik OSM.

💡 Peta kosong abu-abu?

Periksa tiga hal: (1) izin INTERNET di manifest main untuk build rilis, (2) emulator punya koneksi internet, (3) urlTemplate benar dan tidak memakai subdomain {s} lama (a.tile...), yang sudah tidak disarankan.
