Setelah layanan dan izin beres, kita bisa meminta posisi. geolocator menyediakan dua cara: getCurrentPosition yang meminta posisi baru (akurat, tetapi butuh waktu), dan getLastKnownPosition yang mengembalikan posisi terakhir yang tersimpan di perangkat (instan, tetapi bisa usang atau null).

Contoh kecil

import 'package:flutter/foundation.dart';
import 'package:geolocator/geolocator.dart';

Future<void> contohSingkat() async {
  final posisi = await Geolocator.getCurrentPosition(
    locationSettings: const LocationSettings(accuracy: LocationAccuracy.high),
  );
  debugPrint('${posisi.latitude}, ${posisi.longitude}');
}

Parameter locationSettings adalah cara terbaru untuk mengatur permintaan. Parameter lama desiredAccuracy, timeLimit, dan forceAndroidLocationManager langsung pada getCurrentPosition sudah deprecated, jadi jangan meniru tutorial lama yang masih memakainya.

Posisi terakhir yang diketahui

import 'package:flutter/foundation.dart';
import 'package:geolocator/geolocator.dart';

Future<void> posisiTerakhir() async {
  final Position? terakhir = await Geolocator.getLastKnownPosition();
  if (terakhir == null) {
    debugPrint('Belum ada posisi tersimpan di perangkat');
  } else {
    final umur = DateTime.now().difference(terakhir.timestamp);
    debugPrint(
      'Posisi ${umur.inMinutes} menit yang lalu: '
      '${terakhir.latitude}, ${terakhir.longitude}',
    );
  }
}

Ini setara dengan fusedLocationClient.lastLocation di modul lama Kotlin. Gunakan untuk menampilkan sesuatu dengan cepat (misalnya memusatkan peta), lalu ganti dengan hasil getCurrentPosition. Jangan memakai posisi terakhir untuk keputusan penting seperti presensi, karena bisa berumur berjam-jam. getLastKnownPosition tidak didukung di web.

Pengaturan khusus platform: AndroidSettings dan AppleSettings

LocationSettings berisi pengaturan umum (accuracy, distanceFilter, timeLimit). Kelas turunannya menambah opsi khusus platform dan sudah diekspor oleh package:geolocator/geolocator.dart:

KelasOpsi tambahan penting
AndroidSettingsintervalDuration (jeda antar-update stream), forceLocationManager (pakai LocationManager lama, bukan Fused), maxUpdateAge, foregroundNotificationConfig (lokasi saat aplikasi diminimalkan), useMSLAltitude
AppleSettingsactivityType (fitness, automotiveNavigation, dll.), pauseLocationUpdatesAutomatically, showBackgroundLocationIndicator, allowBackgroundLocationUpdates
WebSettingsmaximumAge

Contoh AndroidSettings untuk pelacakan yang terus berjalan saat aplikasi diminimalkan (butuh izin background di bagian 2, dan tidak dipakai di studi kasus):

import 'package:geolocator/geolocator.dart';

final pengaturanLatarBelakang = AndroidSettings(
  accuracy: LocationAccuracy.high,
  distanceFilter: 20,
  foregroundNotificationConfig: const ForegroundNotificationConfig(
    notificationTitle: 'Pelacakan rute aktif',
    notificationText: 'Aplikasi sedang merekam rute perjalananmu',
    enableWakeLock: true,
  ),
);

Contoh lengkap: posisi saya

Aplikasi berikut menampilkan posisi terakhir dulu (jika ada), lalu menggantinya dengan posisi baru, lengkap dengan batas waktu dan penanganan error.

📄 lib/main.dart

// lib/main.dart
import 'dart:async';

import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'package:geolocator/geolocator.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const PosisiPage(),
    );
  }
}

/// Pengaturan lokasi sesuai platform.
LocationSettings buatPengaturan() {
  if (!kIsWeb && defaultTargetPlatform == TargetPlatform.android) {
    return AndroidSettings(
      accuracy: LocationAccuracy.high,
      timeLimit: const Duration(seconds: 15),
    );
  }
  if (!kIsWeb && defaultTargetPlatform == TargetPlatform.iOS) {
    return AppleSettings(
      accuracy: LocationAccuracy.high,
      activityType: ActivityType.fitness,
      timeLimit: const Duration(seconds: 15),
    );
  }
  return const LocationSettings(
    accuracy: LocationAccuracy.high,
    timeLimit: Duration(seconds: 15),
  );
}

class PosisiPage extends StatefulWidget {
  const PosisiPage({super.key});

  @override
  State<PosisiPage> createState() => _PosisiPageState();
}

class _PosisiPageState extends State<PosisiPage> {
  Position? _posisi;
  bool _perkiraan = false; // true jika masih memakai posisi terakhir
  bool _memuat = false;
  String? _error;

  Future<void> _ambilPosisi() async {
    setState(() {
      _memuat = true;
      _error = null;
    });

    try {
      // Langkah 0: pastikan izin (versi singkat dari bagian 2)
      var izin = await Geolocator.checkPermission();
      if (izin == LocationPermission.denied) {
        izin = await Geolocator.requestPermission();
      }
      if (izin == LocationPermission.denied ||
          izin == LocationPermission.deniedForever) {
        _tampilkanError('Izin lokasi ditolak.');
        return;
      }

      // Langkah 1: tampilkan posisi terakhir (cepat, bisa null / usang)
      final terakhir = await Geolocator.getLastKnownPosition();
      if (!mounted) return;
      if (terakhir != null) {
        setState(() {
          _posisi = terakhir;
          _perkiraan = true;
        });
      }

      // Langkah 2: minta posisi baru yang akurat
      final baru = await Geolocator.getCurrentPosition(
        locationSettings: buatPengaturan(),
      );
      if (!mounted) return;
      setState(() {
        _posisi = baru;
        _perkiraan = false;
      });
    } on LocationServiceDisabledException {
      _tampilkanError('Layanan lokasi mati. Nyalakan GPS lalu coba lagi.');
    } on PermissionDeniedException {
      _tampilkanError('Izin lokasi belum diberikan.');
    } on TimeoutException {
      _tampilkanError(
        'Sinyal GPS lemah: posisi tidak didapat dalam 15 detik. '
        'Coba pindah ke dekat jendela atau ruang terbuka.',
      );
    } catch (e) {
      _tampilkanError('Gagal mengambil lokasi: $e');
    } finally {
      if (mounted) setState(() => _memuat = false);
    }
  }

  void _tampilkanError(String pesan) {
    if (!mounted) return;
    setState(() => _error = pesan);
  }

  @override
  Widget build(BuildContext context) {
    final p = _posisi;
    return Scaffold(
      appBar: AppBar(title: const Text('Posisi Saya')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          if (_memuat) const LinearProgressIndicator(),
          if (_error != null)
            Card(
              color: Theme.of(context).colorScheme.errorContainer,
              child: ListTile(
                leading: const Icon(Icons.error_outline),
                title: Text(_error!),
              ),
            ),
          if (p == null && !_memuat)
            const ListTile(title: Text('Belum ada data posisi.')),
          if (p != null) ...[
            if (_perkiraan)
              const ListTile(
                leading: Icon(Icons.history),
                title: Text('Posisi terakhir yang diketahui (mungkin usang)'),
              ),
            ListTile(
              title: const Text('Latitude, Longitude'),
              subtitle: Text(
                '${p.latitude.toStringAsFixed(6)}, '
                '${p.longitude.toStringAsFixed(6)}',
              ),
            ),
            ListTile(
              title: const Text('Akurasi'),
              subtitle: Text(
                p.hasAccuracy
                    ? '± ${p.accuracy.toStringAsFixed(1)} meter'
                    : 'Tidak dilaporkan perangkat',
              ),
            ),
            ListTile(
              title: const Text('Ketinggian'),
              subtitle: Text('${p.altitude.toStringAsFixed(1)} m'),
            ),
            ListTile(
              title: const Text('Kecepatan'),
              subtitle: Text('${(p.speed * 3.6).toStringAsFixed(1)} km/jam'),
            ),
            ListTile(
              title: const Text('Waktu'),
              subtitle: Text(p.timestamp.toLocal().toString()),
            ),
            ListTile(
              title: const Text('Lokasi palsu (mock)?'),
              subtitle: Text(p.isMocked ? 'Ya' : 'Tidak'),
            ),
          ],
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _memuat ? null : _ambilPosisi,
        icon: const Icon(Icons.my_location),
        label: const Text('Ambil posisi'),
      ),
    );
  }
}

Penjelasan baris penting

  • buatPengaturan() memilih AndroidSettings atau AppleSettings berdasarkan defaultTargetPlatform. Cek !kIsWeb diperlukan karena di browser Android pun defaultTargetPlatform bernilai android.
  • timeLimit: Duration(seconds: 15): jika dalam 15 detik tidak ada posisi, getCurrentPosition melempar TimeoutException (dari dart:async). Tanpa batas waktu, di dalam gedung pengguna bisa menunggu tanpa kepastian.
  • Tiga exception penting ditangkap terpisah agar pesannya jelas: LocationServiceDisabledException (GPS mati), PermissionDeniedException (izin dicabut), dan TimeoutException (sinyal lemah). Sisanya ditangkap catch (e).
  • Flag _perkiraan memberi tahu pengguna bahwa angka di layar masih posisi lama.
  • p.hasAccuracy dicek sebelum menampilkan akurasi, sehingga nilai 0.0 pengganti tidak dibaca sebagai "akurat 0 meter".
  • finally mematikan indikator memuat apa pun hasilnya, tetap dengan pengecekan mounted.

⚠️ Kesalahan umum

  • Memanggil getCurrentPosition tanpa timeLimit lalu mengira aplikasi "hang" saat diuji di dalam ruangan.
  • Menganggap getLastKnownPosition() selalu berisi. Pada perangkat baru di-reset atau emulator yang baru dinyalakan hasilnya null.
  • Membandingkan timestamp dengan waktu lokal tanpa toLocal(), sehingga jam tampil selisih 7 jam (WIB).
  • Meminta LocationAccuracy.best untuk fitur yang cukup dengan medium, sehingga baterai cepat habis.
