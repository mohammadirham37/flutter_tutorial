Seperti di Modul 09 (JSON), data dari database sebaiknya tidak dipakai sebagai Map mentah. Kita buat model dengan dua method: toMap() untuk menyimpan ke tabel dan fromMap() untuk membaca dari tabel.

Konsep: Konversi Tipe

Field DartKolom SQLitetoMap()fromMap()
int? idINTEGER PRIMARY KEYtidak ditulis jika null (dibuat otomatis)map['id'] as int?
bool isSelesaiINTEGERisSelesai ? 1 : 0map['isSelesai'] == 1

double ipkREALlangsung(map['ipk'] as num).toDouble()

Contoh Kecil

class Matkul {
  final int? id;
  final String nama;
  final int sks;

  const Matkul({this.id, required this.nama, required this.sks});

  Map<String, Object?> toMap() => {
        if (id != null) 'id': id,
        'nama': nama,
        'sks': sks,
      };

  factory Matkul.fromMap(Map<String, Object?> map) => Matkul(
        id: map['id'] as int?,
        nama: map['nama'] as String,
        sks: map['sks'] as int,
      );
}

Model Lengkap: Tugas Kuliah

Model ini dipakai di section CRUD berikutnya. Nama kunci Map harus sama persis dengan nama kolom tabel.

📄 lib/models/tugas.dart

class Tugas {
  final int? id;
  final String judul;
  final String matkul;
  final DateTime tenggat;
  final bool isSelesai;

  const Tugas({
    this.id,
    required this.judul,
    required this.matkul,
    required this.tenggat,
    this.isSelesai = false,
  });

  /// Dart -> baris tabel
  Map<String, Object?> toMap() {
    return {
      if (id != null) 'id': id,
      'judul': judul,
      'matkul': matkul,
      'tenggat': tenggat.toIso8601String(), // DateTime -> TEXT
      'isSelesai': isSelesai ? 1 : 0, // bool -> INTEGER
    };
  }

  /// Baris tabel -> Dart
  factory Tugas.fromMap(Map<String, Object?> map) {
    return Tugas(
      id: map['id'] as int?,
      judul: map['judul'] as String,
      matkul: map['matkul'] as String,
      tenggat: DateTime.parse(map['tenggat'] as String),
      isSelesai: map['isSelesai'] == 1,
    );
  }

  Tugas copyWith({int? id, String? judul, String? matkul, DateTime? tenggat, bool? isSelesai}) {
    return Tugas(
      id: id ?? this.id,
      judul: judul ?? this.judul,
      matkul: matkul ?? this.matkul,
      tenggat: tenggat ?? this.tenggat,
      isSelesai: isSelesai ?? this.isSelesai,
    );
  }

  /// Sisa hari menuju tenggat (negatif berarti terlambat)
  int get sisaHari => tenggat.difference(DateTime.now()).inDays;

  @override
  String toString() => 'Tugas(id: $id, judul: $judul, selesai: $isSelesai)';
}

Mencoba Konversi Tanpa Database

📄 lib/contoh_tugas.dart

// Jalankan dengan: dart run lib/contoh_tugas.dart
import 'models/tugas.dart';

void main() {
  final tugas = Tugas(
    judul: 'Laporan Praktikum 10',
    matkul: 'Pemrograman Mobile',
    tenggat: DateTime(2026, 11, 20, 23, 59),
  );

  final map = tugas.toMap();
  print(map);
  // {judul: Laporan Praktikum 10, matkul: Pemrograman Mobile,
  //  tenggat: 2026-11-20T23:59:00.000, isSelesai: 0}

  // Seolah-olah baris ini dibaca dari database (sudah punya id)
  final dariDb = Tugas.fromMap({...map, 'id': 7, 'isSelesai': 1});
  print(dariDb); // Tugas(id: 7, judul: Laporan Praktikum 10, selesai: true)
  print(dariDb.tenggat.year); // 2026
}

Penjelasan: {...map, 'id': 7} adalah spread operator: menyalin isi map lalu menambah/menimpa kunci tertentu. Perhatikan toMap() tidak menulis id ketika null, karena kolom AUTOINCREMENT akan mengisinya sendiri.

⚠️ Kesalahan Umum

  • Menyimpan bool langsung ('isSelesai': true). sqflite akan menolak atau menyimpan dengan tidak konsisten; selalu ubah ke 0/1.
  • Menyimpan DateTime langsung: error Unsupported value. Ubah ke String ISO 8601 (atau millisecondsSinceEpoch sebagai INTEGER).
  • Menulis 'id': null di toMap() lalu memakai ConflictAlgorithm.replace; lebih aman tidak menulis id sama sekali saat insert.
  • Nama kunci di Map berbeda dengan nama kolom (is_selesai vs isSelesai): muncul error no such column.
