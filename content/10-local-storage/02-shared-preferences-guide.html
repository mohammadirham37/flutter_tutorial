shared_preferences menyimpan data kecil berbentuk pasangan kunci-nilai (key-value), seperti kamus: kunci 'tema' bernilai 'gelap'. Di Android data disimpan di DataStore/SharedPreferences, di iOS di NSUserDefaults, dan di web di LocalStorage.

Pasang package: flutter pub add shared_preferences

flutter pub add shared_preferences

Tipe Data yang Didukung

intsetInt('counter', 10)getInt('counter')
doublesetDouble('ukuranFont', 1.2)getDouble('ukuranFont')
StringsetString('nama', 'Budi')getString('nama')
List<String>setStringList('riwayat', ['a', 'b'])getStringList('riwayat')

Tiga API: Mana yang Dipakai?

Sejak versi 2.3.0, package ini menyediakan tiga class. Dokumentasi resminya menyatakan class lama SharedPreferences akan di-deprecate dan menganjurkan dua class baru untuk kode baru.

ClassCara membuatBaca dataKapan dipakai
SharedPreferencesAsyncSharedPreferencesAsync()await (selalu dari disk)Pilihan default. Selalu membaca nilai terbaru.
SharedPreferencesWithCacheawait SharedPreferencesWithCache.create(...)Sinkron (dari cache memori)Nilai dibaca sangat sering, mis. di build() atau saat start aplikasi.
SharedPreferences (lama)await SharedPreferences.getInstance()SinkronKode lama/tutorial lama. Hindari untuk proyek baru.

Di modul ini kita memakai SharedPreferencesAsync untuk kebanyakan contoh dan SharedPreferencesWithCache ketika butuh baca sinkron.

Contoh Kecil: SharedPreferencesAsync

import 'package:shared_preferences/shared_preferences.dart';

Future<void> contohAsync() async {
  final prefs = SharedPreferencesAsync();

  // Simpan
  await prefs.setString('nama', 'Budi');
  await prefs.setInt('semester', 3);
  await prefs.setStringList('matkulFavorit', ['Mobile', 'Basis Data']);

  // Baca: hasilnya nullable, beri nilai default dengan ??
  final nama = await prefs.getString('nama') ?? 'Tamu';
  final semester = await prefs.getInt('semester') ?? 1;
  print('$nama semester $semester');

  // Cek dan hapus
  final ada = await prefs.containsKey('nama');
  await prefs.remove('nama');
  print('Sebelum dihapus ada: $ada');

  // Hapus beberapa kunci saja (lebih aman daripada clear() tanpa filter)
  await prefs.clear(allowList: {'semester', 'matkulFavorit'});
}

Contoh Kecil: SharedPreferencesWithCache

Class ini dibuat sekali (async), lalu pembacaan bersifat sinkron tanpa await. Parameter allowList membatasi kunci yang boleh dipakai; kunci di luar daftar akan memicu error, sehingga typo cepat ketahuan.

import 'package:shared_preferences/shared_preferences.dart';

Future<void> contohWithCache() async {
  final prefs = await SharedPreferencesWithCache.create(
    cacheOptions: const SharedPreferencesWithCacheOptions(
      allowList: {'tema', 'counter'},
    ),
  );

  await prefs.setInt('counter', 5); // tulis tetap async
  final int counter = prefs.getInt('counter') ?? 0; // baca sinkron, tanpa await
  print(counter);
}

Contoh Lengkap: Counter yang Tidak Hilang

Ini perbaikan dari contoh di section 1. Angka dibaca saat layar dibuka dan disimpan setiap kali bertambah.

📄 lib/main.dart

// Pastikan sudah: flutter pub add shared_preferences
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

void main() => runApp(const MaterialApp(home: CounterAwet()));

class CounterAwet extends StatefulWidget {
  const CounterAwet({super.key});

  @override
  State<CounterAwet> createState() => _CounterAwetState();
}

class _CounterAwetState extends State<CounterAwet> {
  static const _kunci = 'demo_counter';
  final _prefs = SharedPreferencesAsync();
  int? _counter; // null = sedang membaca dari penyimpanan

  @override
  void initState() {
    super.initState();
    _muat();
  }

  Future<void> _muat() async {
    final nilai = await _prefs.getInt(_kunci) ?? 0;
    if (mounted) setState(() => _counter = nilai);
  }

  Future<void> _tambah() async {
    final baru = (_counter ?? 0) + 1;
    setState(() => _counter = baru); // UI langsung berubah
    await _prefs.setInt(_kunci, baru); // lalu disimpan
  }

  Future<void> _reset() async {
    await _prefs.remove(_kunci);
    if (mounted) setState(() => _counter = 0);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Counter Tersimpan'),
        actions: [IconButton(onPressed: _reset, icon: const Icon(Icons.restart_alt))],
      ),
      body: Center(
        child: _counter == null
            ? const CircularProgressIndicator()
            : Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  Text('$_counter', style: Theme.of(context).textTheme.displayLarge),
                  const Text('Tutup aplikasi lalu buka lagi, angka tetap ada.'),
                ],
              ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _counter == null ? null : _tambah,
        child: const Icon(Icons.add),
      ),
    );
  }
}
Counter tersimpan dengan SharedPreferencesAsync

Penjelasan:

  • _counter bertipe int?. Nilai null berarti data belum selesai dibaca, sehingga kita menampilkan spinner. Membaca storage selalu butuh waktu.
  • Kunci disimpan dalam konstanta _kunci. Menulis string 'demo_counter' berulang kali berisiko typo.
  • Pada _tambah, UI diperbarui dulu baru disimpan, sehingga aplikasi terasa responsif.

⚠️ Kesalahan Umum

  • Menyimpan data penting/besar. Dokumentasi resmi menegaskan SharedPreferences bukan untuk data kritis. Gunakan untuk pengaturan kecil saja.
  • Lupa await pada SharedPreferencesAsync, sehingga yang didapat Future<int?>, bukan int?.
  • Membaca dengan tipe berbeda dari saat menyimpan (simpan setInt, baca getString): hasilnya error tipe.
  • Memanggil clear() tanpa allowList saat logout. Semua data ikut terhapus, termasuk pengaturan tema.
  • Data lama dari SharedPreferences versi lama tidak otomatis terbaca oleh SharedPreferencesAsync di Android. Untuk migrasi, package menyediakan fungsi migrateLegacySharedPreferencesToSharedPreferencesAsyncIfNecessary.
