Untuk data yang banyak dan terstruktur (daftar catatan, nilai mahasiswa, transaksi), kita memakai SQLite: database relasional kecil yang tersimpan sebagai satu file di HP. Package sqflite menghubungkan Flutter dengan SQLite bawaan Android dan iOS.

flutter pub add sqflite path

Package path dipakai untuk menggabungkan folder dan nama file database dengan benar (join).

⚠️ sqflite Tidak Berjalan di Chrome (Web)

sqflite hanya mendukung Android, iOS, dan macOS. Jika dijalankan dengan flutter run -d chrome, muncul MissingPluginException dan layar kosong. Gunakan emulator Android atau HP fisik.

Kilat SQL: 5 Perintah Dasar

Jika sudah mengambil mata kuliah Basis Data, ini hanya pengingat:

-- Membuat tabel
CREATE TABLE mahasiswa (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nim TEXT NOT NULL UNIQUE,
  nama TEXT NOT NULL,
  ipk REAL DEFAULT 0
);

-- Menambah data
INSERT INTO mahasiswa (nim, nama, ipk) VALUES ('H1D022001', 'Budi', 3.5);

-- Membaca data
SELECT * FROM mahasiswa WHERE ipk >= 3.0 ORDER BY nama ASC;

-- Mengubah data
UPDATE mahasiswa SET ipk = 3.8 WHERE id = 1;

-- Menghapus data
DELETE FROM mahasiswa WHERE id = 1;

Tipe Data SQLite dan Padanannya di Dart

SQLiteDartCatatan
INTEGERintJuga dipakai untuk bool (0/1)
REALdoubleIPK, harga, koordinat
TEXTStringJuga untuk DateTime (format ISO 8601)
BLOBUint8ListData biner (jarang dipakai, simpan path file saja)
NULLnullKolom tanpa NOT NULL boleh kosong

SQLite tidak punya tipe BOOLEAN dan DATETIME asli. Konversinya kita lakukan sendiri di model (section berikutnya).

Contoh Kecil: Membuka Database

import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

Future<Database> bukaDatabase() async {
  final folder = await getDatabasesPath(); // folder khusus database milik aplikasi
  final path = join(folder, 'kampus.db');   // .../databases/kampus.db

  return openDatabase(
    path,
    version: 1,
    // onCreate hanya dipanggil SEKALI: saat file database belum ada
    onCreate: (db, version) async {
      await db.execute('''
        CREATE TABLE mahasiswa (
          id INTEGER PRIMARY KEY AUTOINCREMENT,
          nim TEXT NOT NULL UNIQUE,
          nama TEXT NOT NULL,
          ipk REAL DEFAULT 0
        )
      ''');
    },
  );
}
  • getDatabasesPath() mengembalikan folder database aplikasi (di Android: /data/data/<package>/databases).
  • version adalah versi skema (struktur tabel), bukan versi aplikasi. Dipakai untuk migrasi di section 8.
  • onCreate berjalan hanya ketika file database belum ada. Mengubah isi onCreate tidak berpengaruh pada database yang sudah terbuat.

Pola Singleton: Satu Koneksi untuk Seluruh Aplikasi

Membuka database itu mahal. Simpan koneksinya dan gunakan ulang:

📄 lib/data/app_database.dart

import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

class AppDatabase {
  AppDatabase._(); // constructor privat: tidak bisa di-new dari luar
  static final AppDatabase instance = AppDatabase._();

  Database? _db;

  Future<Database> get database async {
    // ??= : buka hanya jika belum pernah dibuka
    return _db ??= await _open();
  }

  Future<Database> _open() async {
    final path = join(await getDatabasesPath(), 'intro_kampus.db');
    return openDatabase(
      path,
      version: 1,
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE mahasiswa (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nim TEXT NOT NULL UNIQUE,
            nama TEXT NOT NULL,
            ipk REAL DEFAULT 0
          )
        ''');
      },
    );
  }

  Future<void> close() async {
    await _db?.close();
    _db = null;
  }
}

Contoh Lengkap: Insert dan Hitung Baris

📄 lib/main.dart

// Pastikan sudah: flutter pub add sqflite path, dan membuat lib/data/app_database.dart
import 'package:flutter/material.dart';
import 'package:sqflite/sqflite.dart';

import 'data/app_database.dart';

void main() => runApp(const MaterialApp(home: IntroSqliteScreen()));

class IntroSqliteScreen extends StatefulWidget {
  const IntroSqliteScreen({super.key});

  @override
  State<IntroSqliteScreen> createState() => _IntroSqliteScreenState();
}

class _IntroSqliteScreenState extends State<IntroSqliteScreen> {
  int _jumlah = 0;
  String _path = '';
  List<Map<String, Object?>> _baris = [];

  @override
  void initState() {
    super.initState();
    _refresh();
  }

  Future<void> _refresh() async {
    final db = await AppDatabase.instance.database;
    final jumlah = Sqflite.firstIntValue(await db.rawQuery('SELECT COUNT(*) FROM mahasiswa')) ?? 0;
    final baris = await db.query('mahasiswa', orderBy: 'id DESC', limit: 5);
    if (!mounted) return;
    setState(() {
      _jumlah = jumlah;
      _path = db.path;
      _baris = baris;
    });
  }

  Future<void> _tambah() async {
    final db = await AppDatabase.instance.database;
    final n = DateTime.now().millisecondsSinceEpoch % 100000;
    await db.insert('mahasiswa', {'nim': 'H1D$n', 'nama': 'Mahasiswa $n', 'ipk': 3.25});
    await _refresh();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Halo SQLite')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Text('Jumlah baris: $_jumlah', style: Theme.of(context).textTheme.headlineSmall),
          const SizedBox(height: 8),
          Text('Lokasi file: $_path', style: Theme.of(context).textTheme.bodySmall),
          const Divider(height: 32),
          const Text('5 data terbaru (Map mentah dari db.query):'),
          for (final row in _baris) Text(row.toString()),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _tambah,
        icon: const Icon(Icons.add),
        label: const Text('Insert'),
      ),
    );
  }
}
Setelah dua kali Insert: jumlah baris dan Map hasil query

Penjelasan: setiap baris hasil db.query berbentuk Map<String, Object?> dengan nama kolom sebagai kunci. Sqflite.firstIntValue mengambil angka pertama dari hasil query seperti COUNT(*). Tutup lalu buka aplikasi: jumlah baris tetap.

⚠️ Kesalahan Umum

  • Membuka database baru (openDatabase) di setiap fungsi. Gunakan singleton.
  • Salah ketik SQL di onCreate (misalnya koma di akhir kolom terakhir). Error baru muncul saat aplikasi dijalankan, jadi baca pesan DatabaseException dengan teliti.
  • Mengubah CREATE TABLE lalu heran kolom baru tidak ada. onCreate tidak dijalankan ulang; lihat section Migrasi.
  • Menjalankan di Chrome: sqflite tidak mendukung web.
