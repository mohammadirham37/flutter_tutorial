Semua variabel di aplikasi Flutter disimpan di memori (RAM). Begitu aplikasi ditutup, isinya hilang. Agar data bertahan (tema pilihan pengguna, status login, catatan kuliah), data harus ditulis ke penyimpanan lokal di HP. Proses ini disebut persistensi.

Membuktikan Masalahnya

Jalankan contoh berikut, tekan tombol beberapa kali, lalu tutup aplikasi sepenuhnya (swipe dari recent apps) dan buka lagi. Angkanya kembali ke 0.

📄 lib/main.dart

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: CounterHilang()));

class CounterHilang extends StatefulWidget {
  const CounterHilang({super.key});

  @override
  State<CounterHilang> createState() => _CounterHilangState();
}

class _CounterHilangState extends State<CounterHilang> {
  int _counter = 0; // hanya ada di RAM

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Data di Memori Saja')),
      body: Center(
        child: Text('$_counter', style: Theme.of(context).textTheme.displayLarge),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _counter++),
        child: const Icon(Icons.add),
      ),
    );
  }
}
Counter di memori: kembali ke 0 setelah aplikasi ditutup

Pilihan Penyimpanan Lokal di Flutter

Kategori Package Populer Struktur Data Kasus Penggunaan Ideal
Key-Value Store shared_preferences Key-Value sederhana (String, int, double, bool, List<String>) Onboarding status, tema gelap/terang, bahasa, sesi login sederhana
Relational Database sqflite Tabel SQL, kolom, relasi Foreign Key Data banyak dan terstruktur: catatan, transaksi keuangan, tugas berelasi mata kuliah
NoSQL Fast Store hive_ce (Modul 11) Box berisi objek Dart Objek tanpa relasi rumit, baca-tulis sangat cepat tanpa SQL
Penyimpanan Aman flutter_secure_storage Key-Value terenkripsi (Keychain/Keystore) Token akses, refresh token, PIN
File path_provider + dart:io File bebas (teks, JSON, gambar) Ekspor laporan, cache gambar, file unduhan

Cara Memilih

Apakah datanya hanya beberapa nilai pengaturan (tema, flag, nama pengguna)?
 ├─ Ya  ──> SharedPreferences
 └─ Tidak
     Apakah datanya rahasia (token, password)?
      ├─ Ya  ──> flutter_secure_storage
      └─ Tidak
          Apakah datanya banyak, perlu dicari/difilter/diurutkan, atau saling berelasi?
           ├─ Ya  ──> SQLite (sqflite)  atau Hive untuk data tanpa relasi
           └─ Tidak, berupa dokumen/gambar ──> File (path_provider)
Perlu dipakai bersama banyak perangkat/pengguna? ──> database cloud (Supabase, Modul 12)

⚠️ Kesalahan Umum

  • Menyimpan ratusan data (mis. daftar transaksi) di SharedPreferences sebagai satu String JSON raksasa. Lambat dan sulit dicari; gunakan database.
  • Menganggap penyimpanan lokal sebagai backup. Data lokal hilang saat aplikasi di-uninstall atau "Clear data".
  • Menyimpan password asli di penyimpanan lokal. Jangan pernah; simpan token saja dan gunakan penyimpanan aman.
