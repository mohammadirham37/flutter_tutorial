Sekarang kita membuat operasi CRUD (Create, Read, Update, Delete) lengkap. sqflite menyediakan method siap pakai sehingga kita jarang menulis SQL mentah: insert, query, update, dan delete.

Peta Method sqflite

OperasiMethodNilai kembaliSQL yang dihasilkan
Createdb.insert('tugas', map)int id baris baruINSERT INTO tugas (...) VALUES (...)
Readdb.query('tugas', where: ..., orderBy: ...)List<Map>SELECT * FROM tugas WHERE ...
Updatedb.update('tugas', map, where: 'id = ?', whereArgs: [id])int jumlah baris berubahUPDATE tugas SET ... WHERE id = ?
Deletedb.delete('tugas', where: 'id = ?', whereArgs: [id])int jumlah baris terhapusDELETE FROM tugas WHERE id = ?

Langkah 1: DatabaseHelper (Singleton + Tabel + CRUD Map)

Buat folder lib/data/ lalu file database_helper.dart. Versi ini masih bekerja dengan Map agar alurnya mudah dilihat.

📄 lib/data/database_helper.dart

// lib/data/database_helper.dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';

class DatabaseHelper {
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;

  DatabaseHelper._init();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDB('tugas_kampus.db');
    return _database!;
  }

  Future<Database> _initDB(String filePath) async {
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE tugas (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            judul TEXT NOT NULL,
            matkul TEXT NOT NULL,
            tenggat TEXT NOT NULL,
            isSelesai INTEGER NOT NULL
          )
        ''');
      },
    );
  }

  // CREATE (Insert)
  Future<int> tambahTugas(Map<String, dynamic> row) async {
    final db = await instance.database;
    return await db.insert('tugas', row);
  }

  // READ (Query All)
  Future<List<Map<String, dynamic>>> ambilSemuaTugas() async {
    final db = await instance.database;
    return await db.query('tugas', orderBy: 'id DESC');
  }

  // UPDATE
  Future<int> updateStatus(int id, bool isSelesai) async {
    final db = await instance.database;
    return await db.update(
      'tugas',
      {'isSelesai': isSelesai ? 1 : 0},
      where: 'id = ?',
      whereArgs: [id],
    );
  }

  // DELETE
  Future<int> hapusTugas(int id) async {
    final db = await instance.database;
    return await db.delete('tugas', where: 'id = ?', whereArgs: [id]);
  }
}

Penjelasan: where: 'id = ?' berisi tanda tanya sebagai tempat nilai, dan nilainya diberikan lewat whereArgs. Jangan pernah menyambung nilai langsung ke string SQL (lihat section Query Lanjutan tentang SQL injection). Tanpa where, update dan delete akan mengenai semua baris.

Langkah 2: DAO Bertipe dengan Model Tugas

DAO (Data Access Object) membungkus helper agar UI bekerja dengan objek Tugas (section 6), bukan Map.

📄 lib/data/tugas_dao.dart

import 'package:sqflite/sqflite.dart';

import '../models/tugas.dart';
import 'database_helper.dart';

class TugasDao {
  Future<Database> get _db => DatabaseHelper.instance.database;

  // CREATE: kembalikan objek lengkap dengan id dari database
  Future<Tugas> insert(Tugas tugas) async {
    final db = await _db;
    final id = await db.insert('tugas', tugas.toMap());
    return tugas.copyWith(id: id);
  }

  // READ semua: belum selesai di atas, lalu tenggat terdekat
  Future<List<Tugas>> getAll() async {
    final db = await _db;
    final rows = await db.query('tugas', orderBy: 'isSelesai ASC, tenggat ASC');
    return rows.map(Tugas.fromMap).toList();
  }

  // READ satu
  Future<Tugas?> getById(int id) async {
    final db = await _db;
    final rows = await db.query('tugas', where: 'id = ?', whereArgs: [id], limit: 1);
    return rows.isEmpty ? null : Tugas.fromMap(rows.first);
  }

  // UPDATE seluruh kolom
  Future<int> update(Tugas tugas) async {
    final db = await _db;
    return db.update('tugas', tugas.toMap(), where: 'id = ?', whereArgs: [tugas.id]);
  }

  // DELETE
  Future<int> delete(int id) async {
    final db = await _db;
    return db.delete('tugas', where: 'id = ?', whereArgs: [id]);
  }
}

rows.map(Tugas.fromMap) adalah tear-off: mengoper constructor sebagai fungsi, sama dengan rows.map((r) => Tugas.fromMap(r)).

Langkah 3: Contoh Lengkap Aplikasi Tugas Kuliah

Fitur: tambah dan edit lewat dialog, centang selesai (UPDATE), geser untuk hapus (DELETE), dan data tetap ada setelah aplikasi ditutup.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: flutter pub add sqflite path, serta membuat
// lib/models/tugas.dart, lib/data/database_helper.dart, lib/data/tugas_dao.dart
// CATATAN: sqflite hanya berjalan di Android, iOS, dan macOS. TIDAK bisa di Chrome (web).
import 'package:flutter/material.dart';

import 'data/tugas_dao.dart';
import 'models/tugas.dart';

void main() {
  runApp(MaterialApp(
    debugShowCheckedModeBanner: false,
    theme: ThemeData(colorSchemeSeed: Colors.deepPurple),
    home: const DaftarTugasScreen(),
  ));
}

class DaftarTugasScreen extends StatefulWidget {
  const DaftarTugasScreen({super.key});

  @override
  State<DaftarTugasScreen> createState() => _DaftarTugasScreenState();
}

class _DaftarTugasScreenState extends State<DaftarTugasScreen> {
  final _dao = TugasDao();
  List<Tugas> _daftar = [];
  bool _loading = true;

  @override
  void initState() {
    super.initState();
    _muat();
  }

  Future<void> _muat() async {
    final data = await _dao.getAll();
    if (!mounted) return;
    setState(() {
      _daftar = data;
      _loading = false;
    });
  }

  /// Buka dialog tambah (tugas == null) atau edit (tugas != null)
  Future<void> _bukaForm([Tugas? tugas]) async {
    final hasil = await showDialog<Tugas>(
      context: context,
      builder: (_) => TugasDialog(tugas: tugas),
    );
    if (hasil == null) return; // dibatalkan

    if (hasil.id == null) {
      await _dao.insert(hasil);
    } else {
      await _dao.update(hasil);
    }
    await _muat();
  }

  Future<void> _toggle(Tugas t, bool selesai) async {
    await _dao.update(t.copyWith(isSelesai: selesai));
    await _muat();
  }

  Future<void> _hapus(Tugas t) async {
    await _dao.delete(t.id!);
    setState(() => _daftar.remove(t));
    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('"${t.judul}" dihapus'),
        action: SnackBarAction(
          label: 'URUNGKAN',
          onPressed: () async {
            await _dao.insert(t); // id lama ikut disimpan kembali
            await _muat();
          },
        ),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    final selesai = _daftar.where((t) => t.isSelesai).length;
    return Scaffold(
      appBar: AppBar(title: Text('Tugas Kuliah ($selesai/${_daftar.length} selesai)')),
      body: _loading
          ? const Center(child: CircularProgressIndicator())
          : _daftar.isEmpty
              ? const Center(child: Text('Belum ada tugas. Tekan tombol + untuk menambah.'))
              : ListView.builder(
                  itemCount: _daftar.length,
                  itemBuilder: (context, index) {
                    final t = _daftar[index];
                    final telat = !t.isSelesai && t.sisaHari < 0;
                    return Dismissible(
                      key: ValueKey(t.id),
                      direction: DismissDirection.endToStart,
                      background: Container(
                        color: Colors.red,
                        alignment: Alignment.centerRight,
                        padding: const EdgeInsets.only(right: 20),
                        child: const Icon(Icons.delete, color: Colors.white),
                      ),
                      onDismissed: (_) => _hapus(t),
                      child: CheckboxListTile(
                        value: t.isSelesai,
                        onChanged: (v) => _toggle(t, v ?? false),
                        title: Text(
                          t.judul,
                          style: TextStyle(
                            decoration: t.isSelesai ? TextDecoration.lineThrough : null,
                          ),
                        ),
                        subtitle: Text(
                          '${t.matkul} • ${telat ? 'TERLAMBAT' : '${t.sisaHari} hari lagi'}',
                          style: TextStyle(color: telat ? Colors.red : null),
                        ),
                        secondary: IconButton(
                          icon: const Icon(Icons.edit_outlined),
                          onPressed: () => _bukaForm(t),
                        ),
                      ),
                    );
                  },
                ),
      floatingActionButton: FloatingActionButton(
        tooltip: 'Tambah tugas',
        onPressed: () => _bukaForm(),
        child: const Icon(Icons.add),
      ),
    );
  }
}

/// Dialog form. Controller dimiliki State dialog sendiri sehingga
/// di-dispose otomatis SETELAH animasi tutup dialog selesai.
class TugasDialog extends StatefulWidget {
  final Tugas? tugas;
  const TugasDialog({super.key, this.tugas});

  @override
  State<TugasDialog> createState() => _TugasDialogState();
}

class _TugasDialogState extends State<TugasDialog> {
  late final _judulCtrl = TextEditingController(text: widget.tugas?.judul);
  late final _matkulCtrl =
      TextEditingController(text: widget.tugas?.matkul ?? 'Pemrograman Mobile');
  late DateTime _tenggat =
      widget.tugas?.tenggat ?? DateTime.now().add(const Duration(days: 7));

  @override
  void dispose() {
    _judulCtrl.dispose();
    _matkulCtrl.dispose();
    super.dispose();
  }

  Future<void> _pilihTanggal() async {
    final dipilih = await showDatePicker(
      context: context,
      initialDate: _tenggat,
      firstDate: DateTime(2020),
      lastDate: DateTime(2035),
    );
    if (dipilih != null) setState(() => _tenggat = dipilih);
  }

  void _simpan() {
    final judul = _judulCtrl.text.trim();
    if (judul.isEmpty) return;
    final lama = widget.tugas;
    final data = lama == null
        ? Tugas(judul: judul, matkul: _matkulCtrl.text.trim(), tenggat: _tenggat)
        : lama.copyWith(judul: judul, matkul: _matkulCtrl.text.trim(), tenggat: _tenggat);
    Navigator.pop(context, data); // kirim hasil ke pemanggil showDialog
  }

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: Text(widget.tugas == null ? 'Tugas Baru' : 'Edit Tugas'),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          TextField(controller: _judulCtrl, decoration: const InputDecoration(labelText: 'Judul')),
          TextField(controller: _matkulCtrl, decoration: const InputDecoration(labelText: 'Mata kuliah')),
          const SizedBox(height: 12),
          OutlinedButton.icon(
            icon: const Icon(Icons.event),
            label: Text('Tenggat: ${_tenggat.day}/${_tenggat.month}/${_tenggat.year}'),
            onPressed: _pilihTanggal,
          ),
        ],
      ),
      actions: [
        TextButton(onPressed: () => Navigator.pop(context), child: const Text('Batal')),
        FilledButton(onPressed: _simpan, child: const Text('Simpan')),
      ],
    );
  }
}

Penjelasan baris penting:

  • Setelah setiap perubahan kita memanggil _muat() agar list selalu sama dengan isi database (single source of truth).
  • Form dibuat sebagai widget terpisah TugasDialog yang mengembalikan objek Tugas lewat Navigator.pop(context, data). Controller dimiliki dialog sehingga di-dispose setelah dialog benar-benar tertutup.
  • Fitur URUNGKAN memasukkan kembali objek lama beserta id-nya, sehingga posisinya tetap sama.
  • Pada Dismissible, item dihapus dari list dulu (_daftar.remove) karena Flutter mewajibkan item yang sudah di-dismiss segera hilang dari tree.

⚠️ Kesalahan Umum

  • db.update('tugas', map) tanpa where: seluruh tugas ikut berubah.
  • Lupa memuat ulang data setelah insert/update sehingga layar tidak berubah walaupun database sudah berubah.
  • Membuat TextEditingController di method lalu langsung dispose() setelah showDialog selesai: dialog masih beranimasi menutup sehingga muncul error _dependents.isEmpty. Simpan controller di State widget dialog.
  • Error A dismissed Dismissible widget is still part of the tree: item belum dihapus dari list setelah digeser.
  • Error UNIQUE constraint failed: menyisipkan id/NIM yang sudah ada. Tangani dengan try/catch atau conflictAlgorithm.
