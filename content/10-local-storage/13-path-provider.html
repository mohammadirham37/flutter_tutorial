Kadang data lebih cocok disimpan sebagai file: ekspor catatan ke teks, cache JSON dari API, atau foto. Package path_provider memberi tahu lokasi folder yang boleh dipakai aplikasi, lalu kita menulis file dengan dart:io.

flutter pub add path_provider

Folder yang Tersedia

FungsiIsi yang cocokBisa dihapus sistem?
getApplicationDocumentsDirectory()Data buatan pengguna (ekspor, dokumen)Tidak
getApplicationSupportDirectory()File internal aplikasi yang tidak dilihat penggunaTidak
getTemporaryDirectory()Cache sementara (gambar, respons API)Ya, kapan saja
getDatabasesPath() (sqflite)File database SQLiteTidak

Contoh Kecil: Tulis dan Baca File Teks

import 'dart:io';

import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

Future<File> _fileCatatan() async {
  final dir = await getApplicationDocumentsDirectory();
  return File(p.join(dir.path, 'catatan.txt'));
}

Future<void> simpanTeks(String isi) async {
  final file = await _fileCatatan();
  await file.writeAsString(isi); // menimpa isi lama
}

Future<String> bacaTeks() async {
  final file = await _fileCatatan();
  if (!await file.exists()) return ''; // belum pernah disimpan
  return file.readAsString();
}

Contoh Lengkap: Buku Harian Sederhana

📄 lib/main.dart

// Pastikan sudah: flutter pub add path_provider path
import 'dart:io';

import 'package:flutter/material.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

void main() => runApp(const MaterialApp(home: BukuHarianScreen()));

class BukuHarianScreen extends StatefulWidget {
  const BukuHarianScreen({super.key});

  @override
  State<BukuHarianScreen> createState() => _BukuHarianScreenState();
}

class _BukuHarianScreenState extends State<BukuHarianScreen> {
  final _ctrl = TextEditingController();
  String _info = 'Memuat...';

  Future<File> get _file async {
    final dir = await getApplicationDocumentsDirectory();
    return File(p.join(dir.path, 'buku_harian.txt'));
  }

  @override
  void initState() {
    super.initState();
    _muat();
  }

  @override
  void dispose() {
    _ctrl.dispose();
    super.dispose();
  }

  Future<void> _muat() async {
    final file = await _file;
    final ada = await file.exists();
    final isi = ada ? await file.readAsString() : '';
    if (!mounted) return;
    setState(() {
      _ctrl.text = isi;
      _info = ada ? 'Dibaca dari ${file.path}' : 'File belum ada';
    });
  }

  Future<void> _simpan() async {
    final file = await _file;
    await file.writeAsString(_ctrl.text);
    final ukuran = await file.length();
    if (!mounted) return;
    setState(() => _info = 'Tersimpan ($ukuran byte) di ${file.path}');
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Buku Harian (File)'),
        actions: [IconButton(tooltip: 'Simpan', onPressed: _simpan, icon: const Icon(Icons.save))],
      ),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            Expanded(
              child: TextField(
                controller: _ctrl,
                expands: true,
                maxLines: null,
                textAlignVertical: TextAlignVertical.top,
                decoration: const InputDecoration(
                  hintText: 'Tulis ceritamu hari ini...',
                  border: OutlineInputBorder(),
                ),
              ),
            ),
            const SizedBox(height: 8),
            Text(_info, style: Theme.of(context).textTheme.bodySmall),
          ],
        ),
      ),
    );
  }
}
Teks tersimpan ke file di folder dokumen aplikasi

Penjelasan: File.writeAsString dan readAsString berasal dari dart:io. Jalur folder diambil dari path_provider, lalu digabung dengan nama file memakai p.join agar pemisah folder benar di semua platform.

⚠️ Kesalahan Umum

  • Menulis path secara manual ('/sdcard/...'): tidak portabel dan sering ditolak izin. Selalu pakai path_provider.
  • Menyimpan data penting di getTemporaryDirectory(): bisa dihapus sistem sewaktu-waktu.
  • Membaca file yang belum ada tanpa cek exists(): muncul PathNotFoundException.
  • dart:io tidak tersedia di Flutter Web.
