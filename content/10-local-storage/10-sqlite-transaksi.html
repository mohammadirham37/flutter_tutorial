Beberapa operasi harus berhasil semua atau tidak sama sekali. Contoh pengisian KRS: menambah baris KRS dan mengurangi kuota kelas. Jika langkah kedua gagal, langkah pertama harus dibatalkan. Inilah transaksi. Selain itu, ada batch untuk menjalankan banyak perintah sekaligus dengan cepat.

Konsep

db.transactiondb.batch
TujuanKeutuhan data (atomik)Kecepatan banyak perintah
Jika ada errorSemua perubahan di dalamnya dibatalkan (rollback)Jika di-commit tanpa transaksi, perintah sebelumnya bisa tetap tersimpan
Bisa membaca hasil di tengah?Ya (await txn.query)Tidak, hasil didapat setelah commit()

Contoh Kecil: Transaksi

import 'package:sqflite/sqflite.dart';

Future<void> transfer(Database db, int dari, int ke, int jumlah) async {
  await db.transaction((txn) async {
    // PENTING: di dalam transaksi gunakan txn, BUKAN db
    await txn.rawUpdate('UPDATE dompet SET saldo = saldo - ? WHERE id = ?', [jumlah, dari]);
    final rows = await txn.query('dompet', columns: ['saldo'], where: 'id = ?', whereArgs: [dari]);
    if ((rows.first['saldo'] as int) < 0) {
      throw Exception('Saldo tidak cukup'); // melempar = ROLLBACK otomatis
    }
    await txn.rawUpdate('UPDATE dompet SET saldo = saldo + ? WHERE id = ?', [jumlah, ke]);
  });
}

Contoh Kecil: Batch

import 'package:sqflite/sqflite.dart';

Future<void> imporNilai(Database db, List<Map<String, Object?>> data) async {
  await db.transaction((txn) async {
    final batch = txn.batch();
    for (final row in data) {
      batch.insert('nilai', row); // belum dijalankan, hanya dikumpulkan
    }
    await batch.commit(noResult: true); // dijalankan sekaligus
  });
}

Batch di dalam transaksi adalah kombinasi terbaik: cepat dan aman. noResult: true membuat lebih cepat lagi karena kita tidak butuh id setiap baris.

Contoh Lengkap: Simulasi Pengisian KRS

📄 lib/data/krs_database.dart

import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

class KrsDatabase {
  static Database? _db;

  static Future<Database> get database async => _db ??= await openDatabase(
        join(await getDatabasesPath(), 'krs_demo.db'),
        version: 1,
        onCreate: (db, version) async {
          await db.execute('''
            CREATE TABLE kelas (
              id INTEGER PRIMARY KEY,
              nama TEXT NOT NULL,
              kuota INTEGER NOT NULL
            )
          ''');
          await db.execute('''
            CREATE TABLE krs (
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              kelas_id INTEGER NOT NULL,
              waktu TEXT NOT NULL
            )
          ''');
          await db.insert('kelas', {'id': 1, 'nama': 'Pemrograman Mobile A', 'kuota': 2});
          await db.insert('kelas', {'id': 2, 'nama': 'Basis Data B', 'kuota': 5});
        },
      );

  /// Ambil kelas: tambah KRS + kurangi kuota, dalam SATU transaksi.
  static Future<void> ambilKelas(int kelasId) async {
    final db = await database;
    await db.transaction((txn) async {
      await txn.insert('krs', {
        'kelas_id': kelasId,
        'waktu': DateTime.now().toIso8601String(),
      });
      final rows = await txn.query('kelas', where: 'id = ?', whereArgs: [kelasId]);
      final kuota = rows.first['kuota'] as int;
      if (kuota <= 0) {
        // Insert KRS di atas ikut dibatalkan karena exception ini
        throw StateError('Kuota kelas sudah penuh');
      }
      await txn.update('kelas', {'kuota': kuota - 1}, where: 'id = ?', whereArgs: [kelasId]);
    });
  }

  /// Isi 500 baris KRS dummy memakai batch.
  static Future<Duration> imporDummy() async {
    final db = await database;
    final sw = Stopwatch()..start();
    await db.transaction((txn) async {
      final batch = txn.batch();
      for (var i = 0; i < 500; i++) {
        batch.insert('krs', {'kelas_id': 2, 'waktu': 'dummy-$i'});
      }
      await batch.commit(noResult: true);
    });
    return sw.elapsed;
  }

  static Future<List<Map<String, Object?>>> ringkasan() async {
    final db = await database;
    return db.rawQuery('''
      SELECT k.id, k.nama, k.kuota, COUNT(r.id) AS terisi
      FROM kelas k LEFT JOIN krs r ON r.kelas_id = k.id
      GROUP BY k.id
    ''');
  }
}

📄 lib/main.dart

// Pastikan sudah: flutter pub add sqflite path, dan membuat lib/data/krs_database.dart
import 'package:flutter/material.dart';

import 'data/krs_database.dart';

void main() => runApp(const MaterialApp(home: KrsScreen()));

class KrsScreen extends StatefulWidget {
  const KrsScreen({super.key});

  @override
  State<KrsScreen> createState() => _KrsScreenState();
}

class _KrsScreenState extends State<KrsScreen> {
  List<Map<String, Object?>> _kelas = [];
  String _log = 'Tekan "Ambil" berkali-kali sampai kuota habis.';

  @override
  void initState() {
    super.initState();
    _muat();
  }

  Future<void> _muat() async {
    final data = await KrsDatabase.ringkasan();
    if (mounted) setState(() => _kelas = data);
  }

  Future<void> _ambil(int id) async {
    try {
      await KrsDatabase.ambilKelas(id);
      _log = 'Berhasil mengambil kelas $id';
    } on StateError catch (e) {
      _log = 'Gagal: ${e.message} (transaksi di-rollback, KRS tidak bertambah)';
    }
    await _muat();
  }

  Future<void> _impor() async {
    final durasi = await KrsDatabase.imporDummy();
    _log = '500 baris dimasukkan dengan batch dalam ${durasi.inMilliseconds} ms';
    await _muat();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Simulasi KRS (Transaksi)')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          for (final k in _kelas)
            Card(
              child: ListTile(
                title: Text(k['nama'] as String),
                subtitle: Text('Sisa kuota: ${k['kuota']} • Baris KRS: ${k['terisi']}'),
                trailing: FilledButton(
                  onPressed: () => _ambil(k['id'] as int),
                  child: const Text('Ambil'),
                ),
              ),
            ),
          const SizedBox(height: 12),
          OutlinedButton.icon(
            onPressed: _impor,
            icon: const Icon(Icons.bolt),
            label: const Text('Impor 500 data (batch)'),
          ),
          const SizedBox(height: 16),
          Text(_log),
        ],
      ),
    );
  }
}
Setelah Ambil ditekan 3 kali: kuota 0, baris KRS tetap 2

Penjelasan: pada kelas "Pemrograman Mobile A" (kuota 2), tekan Ambil tiga kali. Pada percobaan ketiga, insert ke tabel krs sebenarnya sudah dijalankan, tetapi karena exception dilempar sebelum transaksi selesai, SQLite membatalkan insert tersebut. Angka "Baris KRS" tetap 2.

⚠️ Kesalahan Umum

  • Memakai db di dalam db.transaction: aplikasi macet (deadlock) karena db menunggu transaksi selesai. Selalu pakai txn.
  • Menangkap exception di dalam blok transaksi (try/catch di dalamnya) sehingga rollback tidak terjadi. Biarkan exception keluar dari callback.
  • Insert ribuan baris satu per satu dengan await db.insert di loop. Gunakan batch.
  • Lupa await batch.commit(): tidak ada data yang tersimpan.
