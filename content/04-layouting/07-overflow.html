Garis kuning-hitam bergaris miring di tepi layar adalah tanda overflow: konten lebih besar daripada ruang yang tersedia. Garis ini hanya muncul di mode debug, tetapi di mode rilis kontennya tetap terpotong. Jadi wajib diperbaiki.

Membaca pesan error

══╡ EXCEPTION CAUGHT BY RENDERING LIBRARY ╞═════════════════
A RenderFlex overflowed by 74 pixels on the right.
The relevant error-causing widget was:
  Row Row:file:///.../lib/main.dart:27:20
  • RenderFlex = Row atau Column (keduanya turunan Flex).
  • 74 pixels on the right = kelebihan 74 px ke kanan, jadi masalahnya di Row. Jika "on the bottom", masalahnya di Column.
  • main.dart:27:20 = baris dan kolom kode penyebabnya. Klik di VS Code untuk langsung melompat ke sana.

Lima kasus overflow dan obatnya

KasusGejalaObat
1. Teks panjang di RowOverflow "on the right"Bungkus teks dengan Expanded/Flexible, tambah overflow: TextOverflow.ellipsis
2. Terlalu banyak anak di RowOverflow "on the right"Ganti Row dengan Wrap, atau buat bisa digeser horizontal
3. Column lebih tinggi dari layarOverflow "on the bottom"Bungkus dengan SingleChildScrollView atau ganti dengan ListView
4. Keyboard muncul menutupi formOverflow "on the bottom" saat mengetikForm dalam SingleChildScrollView
5. ListView di dalam ColumnError "Vertical viewport was given unbounded height"Bungkus ListView dengan Expanded

Kasus 1: teks panjang (sebelum dan sesudah)

// SALAH: teks panjang mendorong ikon keluar layar

  children: const [
    Icon(Icons.article),
    SizedBox(width: 8),

  ],
)
SALAH: teks panjang menimbulkan garis kuning-hitam
// BENAR: teks hanya boleh memakai sisa ruang
Row(

    Icon(Icons.article),

    Expanded(
      child: Text(

Contoh lengkap: tombol "Rusak" dan "Perbaiki"

Aplikasi berikut sengaja membuat tiga overflow. Tekan saklar Mode perbaikan untuk melihat versi yang sudah diperbaiki. Bandingkan kedua versi di kodenya.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: DemoOverflow()));
}

class DemoOverflow extends StatefulWidget {
  const DemoOverflow({super.key});

  @override
  State<DemoOverflow> createState() => _DemoOverflowState();
}

class _DemoOverflowState extends State<DemoOverflow> {
  bool _diperbaiki = false;

  static const _judul = 'Pengumuman Jadwal Ujian Akhir Semester Gasal Tahun Akademik 2026/2027';
  static const _hari = ['Senin', 'Selasa', 'Rabu', 'Kamis', 'Jumat', 'Sabtu'];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Demo Overflow'),
        actions: [
          const Text('Mode perbaikan'),
          Switch(
            value: _diperbaiki,
            onChanged: (v) => setState(() => _diperbaiki = v),
          ),
        ],
      ),
      body: _diperbaiki ? _versiBenar() : _versiRusak(),
    );
  }

  // Versi RUSAK: tiga overflow sekaligus
  Widget _versiRusak() {
    return Column(
      children: [
        const Row(
          children: [
            Icon(Icons.article),
            SizedBox(width: 8),
            Text(_judul), // overflow 1: teks panjang di Row
          ],
        ),
        Row(
          children: [
            for (final h in _hari) Chip(label: Text(h)), // overflow 2: terlalu banyak anak
          ],
        ),
        // overflow 3: total tinggi 20 x 56 px lebih dari tinggi layar
        for (var i = 1; i <= 20; i++) ListTile(title: Text('Pertemuan $i')),
      ],
    );
  }

  // Versi BENAR
  Widget _versiBenar() {
    return SingleChildScrollView( // perbaikan 3: bisa digulir
      child: Column(
        children: [
          const Row(
            children: [
              Icon(Icons.article),
              SizedBox(width: 8),
              Expanded( // perbaikan 1: batasi lebar teks
                child: Text(_judul, maxLines: 1, overflow: TextOverflow.ellipsis),
              ),
            ],
          ),
          Wrap( // perbaikan 2: turun baris otomatis
            spacing: 8,
            children: [for (final h in _hari) Chip(label: Text(h))],
          ),
          for (var i = 1; i <= 20; i++) ListTile(title: Text('Pertemuan $i')),
        ],
      ),
    );
  }
}
Versi rusak: tiga overflow sekaligus
Setelah mode perbaikan diaktifkan

Penjelasan kode

  • Di versi rusak, Debug Console menampilkan beberapa pesan "A RenderFlex overflowed by ... pixels". Coba baca dan cocokkan arahnya (right/bottom) dengan Row atau Column penyebabnya.
  • Setiap perbaikan diberi komentar nomor yang sama dengan masalahnya.
  • Untuk 20 item, SingleChildScrollView + Column masih wajar. Untuk ratusan item atau data dari server, gunakan ListView.builder (Modul 06) yang hanya membangun item yang terlihat.

💡 Flutter Inspector

Di VS Code, buka Flutter DevTools → Widget Inspector lalu aktifkan Show Guidelines atau Layout Explorer. Kamu bisa melihat ukuran dan constraints setiap widget secara visual untuk mencari sumber overflow.

⚠️ Kesalahan umum saat memperbaiki

  • Membungkus semua halaman dengan SingleChildScrollView walaupun isinya memakai Expanded. Expanded di dalam ruang yang bisa digulir akan error.
  • Mengecilkan ukuran font sampai muat di HP sendiri. Di HP lain yang lebih sempit atau dengan ukuran font sistem lebih besar, overflow muncul lagi.
  • Mengabaikan overflow karena "hanya muncul di debug". Di rilis, garisnya hilang tetapi konten tetap terpotong.
