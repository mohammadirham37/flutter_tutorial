Tiga widget kecil untuk mengatur jarak dan proporsi: SizedBox (jarak tetap), Spacer (jarak fleksibel yang mendorong widget lain), dan AspectRatio (menjaga perbandingan lebar : tinggi).

WidgetUkuran jarakContoh pemakaian
SizedBox(width: 8)Tetap, persis 8 pxJarak ikon ke teks
Spacer()Mengisi seluruh sisa ruangMendorong tombol ke ujung kanan
AspectRatio(aspectRatio: 16 / 9)Tinggi dihitung dari lebarBanner, thumbnail video

Spacer

Spacer sebenarnya adalah Expanded yang berisi kotak kosong. Ia hanya bisa dipakai di Row/Column.

Row(
  children: [
    const Text('Total SKS'),
    const Spacer(), // dorong widget berikutnya ke ujung kanan
    const Text('21'),
    const SizedBox(width: 8),
    IconButton(onPressed: () {}, icon: const Icon(Icons.info_outline)),
  ],
)
Spacer mendorong nilai dan tombol ke kanan

Seperti Expanded, Spacer punya flex. Spacer(flex: 2) mengambil jatah dua kali Spacer().

AspectRatio

AspectRatio(
  aspectRatio: 16 / 9, // lebar : tinggi
  child: Container(
    color: Colors.black12,
    alignment: Alignment.center,
    child: const Icon(Icons.play_circle, size: 64),
  ),
)
AspectRatio 16:9

Jika lebar tersedia 360 px, tinggi otomatis menjadi 360 / (16/9) = 202,5 px. Di tablet yang lebih lebar, tinggi ikut membesar sehingga proporsinya tetap.

Contoh lengkap: kartu video kuliah

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(MaterialApp(
    debugShowCheckedModeBanner: false,
    theme: ThemeData(colorSchemeSeed: Colors.red),
    home: const DaftarVideo(),
  ));
}

class DaftarVideo extends StatelessWidget {
  const DaftarVideo({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Rekaman Kuliah')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: const [
          KartuVideo(judul: 'Pertemuan 3: Widget Dasar', durasi: '1:32:10', ditonton: true),
          SizedBox(height: 16),
          KartuVideo(judul: 'Pertemuan 4: Layouting', durasi: '1:45:02'),
          SizedBox(height: 24),
          // Tiga kotak persegi (1:1) sejajar, sama besar
          Text('Galeri praktikum (AspectRatio 1:1):'),
          SizedBox(height: 8),
          Row(
            children: [
              Expanded(child: KotakPersegi(warna: Colors.orange)),
              SizedBox(width: 8),
              Expanded(child: KotakPersegi(warna: Colors.teal)),
              SizedBox(width: 8),
              Expanded(child: KotakPersegi(warna: Colors.purple)),
            ],
          ),
        ],
      ),
    );
  }
}

class KartuVideo extends StatelessWidget {
  final String judul;
  final String durasi;
  final bool ditonton;

  const KartuVideo({super.key, required this.judul, required this.durasi, this.ditonton = false});

  @override
  Widget build(BuildContext context) {
    return Card(
      clipBehavior: Clip.antiAlias,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          // Thumbnail selalu 16:9 berapa pun lebar layar
          AspectRatio(
            aspectRatio: 16 / 9,
            child: Container(
              color: Colors.blueGrey.shade800,
              alignment: Alignment.center,
              child: const Icon(Icons.play_circle_fill, size: 64, color: Colors.white),
            ),
          ),
          Padding(
            padding: const EdgeInsets.all(12),
            child: Row(
              children: [
                Expanded(
                  child: Text(judul, style: const TextStyle(fontWeight: FontWeight.bold)),
                ),
                const SizedBox(width: 8),
                Text(durasi),
              ],
            ),
          ),
          Padding(
            padding: const EdgeInsets.fromLTRB(12, 0, 4, 4),
            child: Row(
              children: [
                if (ditonton) const Chip(label: Text('Sudah ditonton')),
                const Spacer(), // tombol selalu di kanan, ada chip atau tidak
                IconButton(onPressed: () {}, icon: const Icon(Icons.download)),
                IconButton(onPressed: () {}, icon: const Icon(Icons.share)),
              ],
            ),
          ),
        ],
      ),
    );
  }
}

class KotakPersegi extends StatelessWidget {
  final Color warna;

  const KotakPersegi({super.key, required this.warna});

  @override
  Widget build(BuildContext context) {
    return AspectRatio(
      aspectRatio: 1,
      child: DecoratedBox(
        decoration: BoxDecoration(color: warna, borderRadius: BorderRadius.circular(12)),
      ),
    );
  }
}
Kartu video dengan AspectRatio dan Spacer

Penjelasan kode

  • Thumbnail: AspectRatio(16 / 9) menjamin proporsi video tidak gepeng di HP mana pun.
  • Baris tombol: Spacer mendorong tombol unduh dan bagikan ke kanan, baik saat chip "Sudah ditonton" ada maupun tidak.
  • Galeri: Expanded membagi lebar sama rata, lalu AspectRatio(1) membuat tinggi sama dengan lebar sehingga kotak benar-benar persegi.
  • DecoratedBox adalah versi ringan Container yang hanya memberi dekorasi.

⚠️ Kesalahan umum

  • Spacer di luar Row/Column, misalnya di dalam Stack atau ListView, menimbulkan error ParentDataWidget.
  • Spacer di Row yang berada di ruang tak terbatas (misalnya di dalam SingleChildScrollView horizontal). Tidak ada sisa ruang yang bisa diisi.
  • AspectRatio di dalam constraint ketat, misalnya SizedBox(width: 100, height: 100). Ukurannya sudah dipaksa, jadi rasio tidak berlaku.
  • Menulis aspectRatio: 16 / 9 sebagai 9 / 16. Ingat urutannya lebar dibagi tinggi.
