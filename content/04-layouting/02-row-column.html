Widget Row (horizontal) dan Column (vertikal) adalah fondasi 80% susunan UI:

Column (Vertikal)
  • MainAxis: Atas ke Bawah (Y-axis)
  • CrossAxis: Kiri ke Kanan (X-axis)
  • Contoh alignment: MainAxisAlignment.spaceBetween, CrossAxisAlignment.center
Row (Horizontal)
  • MainAxis: Kiri ke Kanan (X-axis)
  • CrossAxis: Atas ke Bawah (Y-axis)
  • Contoh alignment: MainAxisAlignment.spaceEvenly, CrossAxisAlignment.stretch

Contoh kecil

Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly, // atur di sumbu utama (horizontal)
  crossAxisAlignment: CrossAxisAlignment.center,    // atur di sumbu silang (vertikal)
  children: const [
    Icon(Icons.home),
    Icon(Icons.search),
    Icon(Icons.person),
  ],
)
Row dengan MainAxisAlignment.spaceEvenly

Nilai MainAxisAlignment

Gambar di bawah memakai tiga kotak (■) di dalam sebuah Row selebar layar:

start         |■■■                  |
center        |         ■■■         |
end           |                  ■■■|
spaceBetween  |■         ■         ■|   jarak hanya di ANTARA kotak
spaceAround   |  ■      ■      ■    |   jarak tepi = setengah jarak antar kotak
spaceEvenly   |    ■     ■     ■    |   semua jarak sama besar

Nilai CrossAxisAlignment

NilaiPada Row (sumbu silang = vertikal)Pada Column (sumbu silang = horizontal)
startRata atasRata kiri
center (default)Tengah vertikalTengah horizontal
endRata bawahRata kanan
stretchAnak ditarik setinggi RowAnak ditarik selebar Column

MainAxisSize: seberapa besar Row/Column itu sendiri?

Secara default, Row mengambil seluruh lebar yang tersedia dan Column mengambil seluruh tinggi (MainAxisSize.max). Dengan MainAxisSize.min, ukurannya menyusut sebesar anak-anaknya saja. Ini berguna misalnya untuk tombol berisi ikon dan teks.

Column(
  mainAxisSize: MainAxisSize.min, // tinggi Column = total tinggi anak
  children: const [
    Icon(Icons.cloud_done, size: 64),
    Text('Data tersimpan'),
  ],
)
Column dengan MainAxisSize.min

Contoh lengkap: playground alignment

Jalankan contoh ini lalu ganti pilihan pada dropdown. Kamu bisa langsung melihat efek setiap nilai alignment pada Row dan Column.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: PlaygroundAlignment()));
}

class PlaygroundAlignment extends StatefulWidget {
  const PlaygroundAlignment({super.key});

  @override
  State<PlaygroundAlignment> createState() => _PlaygroundAlignmentState();
}

class _PlaygroundAlignmentState extends State<PlaygroundAlignment> {
  MainAxisAlignment _main = MainAxisAlignment.start;
  CrossAxisAlignment _cross = CrossAxisAlignment.center;

  // Tiga kotak dengan ukuran berbeda agar efek cross axis terlihat
  List<Widget> get _kotak => [
        Container(width: 50, height: 50, color: Colors.red),
        Container(width: 50, height: 80, color: Colors.green),
        Container(width: 50, height: 30, color: Colors.blue),
      ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Playground Row & Column')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // Pilihan mainAxisAlignment
          DropdownButton<MainAxisAlignment>(
            value: _main,
            isExpanded: true,
            items: [
              for (final v in MainAxisAlignment.values)
                DropdownMenuItem(value: v, child: Text('mainAxisAlignment: ${v.name}')),
            ],
            onChanged: (v) => setState(() => _main = v!),
          ),
          // Pilihan crossAxisAlignment (baseline butuh pengaturan khusus, jadi dilewati)
          DropdownButton<CrossAxisAlignment>(
            value: _cross,
            isExpanded: true,
            items: [
              for (final v in CrossAxisAlignment.values)
                if (v != CrossAxisAlignment.baseline)
                  DropdownMenuItem(value: v, child: Text('crossAxisAlignment: ${v.name}')),
            ],
            onChanged: (v) => setState(() => _cross = v!),
          ),
          const SizedBox(height: 16),
          const Text('Row (sumbu utama = horizontal)'),
          Container(
            height: 120,
            color: Colors.grey.shade200,
            child: Row(
              mainAxisAlignment: _main,
              crossAxisAlignment: _cross,
              children: _kotak,
            ),
          ),
          const SizedBox(height: 16),
          const Text('Column (sumbu utama = vertikal)'),
          Container(
            height: 260,
            color: Colors.grey.shade200,
            child: Column(
              mainAxisAlignment: _main,
              crossAxisAlignment: _cross,
              children: _kotak,
            ),
          ),
        ],
      ),
    );
  }
}
Playground alignment: start dan center
Setelah memilih spaceBetween

Penjelasan kode

  • MainAxisAlignment.values berisi semua nilai enum, sehingga dropdown dibuat dengan perulangan for di dalam list (collection for).
  • Kotak hijau lebih tinggi daripada yang lain sehingga perbedaan start, center, end di sumbu silang terlihat jelas pada Row.
  • Coba pilih stretch: di Column, kotak yang ditulis width: 50 justru melebar penuh. Stretch memberi constraint ketat selebar Column, sehingga permintaan width: 50 diabaikan. Ini bukti aturan "constraints go down".
  • v! dipakai karena onChanged memberi nilai nullable.

Contoh praktis: baris profil dan kolom statistik

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: ProfilSingkat()));
}

class ProfilSingkat extends StatelessWidget {
  const ProfilSingkat({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Row & Column Praktis')),
      body: const Padding(
        padding: EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start, // semua rata kiri
          children: [
            // Row 1: avatar + nama (Column di dalam Row)
            Row(
              children: [
                CircleAvatar(radius: 32, child: Icon(Icons.person, size: 32)),
                SizedBox(width: 16),
                Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text('Nadia Putri', style: TextStyle(fontSize: 20, fontWeight: FontWeight.bold)),
                    Text('H1D021001 • Informatika'),
                  ],
                ),
              ],
            ),
            SizedBox(height: 24),
            // Row 2: tiga statistik dengan jarak merata
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceAround,
              children: [
                Statistik(nilai: '3.85', label: 'IPK'),
                Statistik(nilai: '98', label: 'SKS'),
                Statistik(nilai: '5', label: 'Semester'),
              ],
            ),
            Divider(height: 32),
            // Row 3: label kiri, nilai kanan
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [Text('Dosen Wali'), Text('Dr. Ratna Dewi')],
            ),
            SizedBox(height: 8),
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [Text('Status'), Text('Aktif', style: TextStyle(color: Colors.green))],
            ),
          ],
        ),
      ),
    );
  }
}

class Statistik extends StatelessWidget {
  final String nilai;
  final String label;

  const Statistik({super.key, required this.nilai, required this.label});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        Text(nilai, style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
        Text(label, style: const TextStyle(color: Colors.grey)),
      ],
    );
  }
}
Row dan Column praktis untuk profil singkat

Pola spaceBetween untuk "label di kiri, nilai di kanan" dan spaceAround untuk deretan statistik akan sangat sering kamu pakai.

⚠️ Kesalahan umum

  • Tertukar sumbu. Ingat: mainAxis selalu searah susunan anak. Row = horizontal, Column = vertikal.
  • Memakai Center untuk menengahkan anak Column secara vertikal. Pakai mainAxisAlignment: MainAxisAlignment.center.
  • mainAxisAlignment tidak berefek karena Row/Column memakai MainAxisSize.min (tidak ada ruang sisa untuk dibagi).
  • Teks rata kiri tidak jalan di Column: default crossAxisAlignment adalah center. Tulis CrossAxisAlignment.start.
