Aplikasi mobile harus tampil proporsional di smartphone layar kecil (5 inci), tablet (10 inci), maupun saat orientasi layar diputar (landscape). Flutter menyediakan tiga alat utama: MediaQuery (info layar), LayoutBuilder (info ruang dari induk), dan OrientationBuilder (info orientasi).

AlatMemberi informasiCocok untuk
MediaQueryUkuran seluruh layar, padding sistem, orientasi, skala teksKeputusan tingkat halaman (pakai menu samping atau tidak)
LayoutBuilderConstraints dari induk langsungWidget yang bisa dipakai di mana saja (kartu, grid)
OrientationBuilderPortrait/landscape berdasarkan ruang indukMengubah jumlah kolom saat HP diputar

MediaQuery: membaca info layar

Widget infoLayar(BuildContext context) {
  final ukuran = MediaQuery.sizeOf(context);          // Size(lebar, tinggi)
  final orientasi = MediaQuery.orientationOf(context); // portrait / landscape
  final padding = MediaQuery.paddingOf(context);      // area status bar, notch
  final skalaTeks = MediaQuery.textScalerOf(context); // pengaturan ukuran font HP

  return Text(
    'Lebar: ${ukuran.width.toStringAsFixed(0)}, tinggi: ${ukuran.height.toStringAsFixed(0)}\n'
    'Orientasi: ${orientasi.name}, status bar: ${padding.top}\n'
    '14 px menjadi ${skalaTeks.scale(14).toStringAsFixed(1)} px',
  );
}
Informasi layar dari MediaQuery

💡 Pakai sizeOf, bukan of(context).size

MediaQuery.sizeOf(context) hanya membangun ulang widget saat ukuran berubah. MediaQuery.of(context).size membangun ulang setiap kali data MediaQuery apa pun berubah (misalnya keyboard muncul), sehingga lebih boros.

Breakpoint: batas lebar untuk berganti tata letak

Material 3 menyarankan tiga kelas ukuran jendela. Simpan sebagai konstanta agar konsisten di seluruh aplikasi:

KelasLebarPerangkat umumNavigasi yang disarankan
Compact< 600HP portraitNavigationBar di bawah
Medium600 - 839Tablet portrait, HP lipatNavigationRail di samping
Expanded≥ 840Tablet landscape, desktopNavigationRail diperluas / drawer permanen
 
class Breakpoint {
  static const double medium = 600;
  static const double expanded = 840;
}

enum KelasLayar { compact, medium, expanded }

KelasLayar kelasDariLebar(double lebar) {
  if (lebar >= Breakpoint.expanded) return KelasLayar.expanded;
  if (lebar >= Breakpoint.medium) return KelasLayar.medium;
  return KelasLayar.compact;
}

Contoh lengkap 1: MediaQuery untuk menu samping

Jalankan di Chrome (flutter run -d chrome) lalu ubah lebar jendela browser untuk melihat tata letak berganti antara mode HP dan tablet.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: DashboardScreen(),
    );
  }
}

class DashboardScreen extends StatelessWidget {
  const DashboardScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // Mendapatkan ukuran & orientasi layar perangkat saat ini
    final Size screenSize = MediaQuery.sizeOf(context);
    final Orientation orientasi = MediaQuery.orientationOf(context);
    final bool isTablet = screenSize.width > 600;

    return Scaffold(
      appBar: AppBar(
        title: Text("Dashboard (${orientasi == Orientation.portrait ? 'Portrait' : 'Landscape'})"),
      ),
      body: isTablet
          ? Row(
              children: [
                // Di tablet / layar lebar tampilkan menu samping
                Container(
                  width: 250,
                  color: Colors.blueGrey[50],
                  child: ListView(
                    children: const [
                      ListTile(leading: Icon(Icons.home), title: Text("Beranda")),
                      ListTile(leading: Icon(Icons.calendar_month), title: Text("Jadwal")),
                      ListTile(leading: Icon(Icons.person), title: Text("Profil")),
                    ],
                  ),
                ),
                const Expanded(child: KontenUtama()),
              ],
            )
          : const KontenUtama(), // Di HP tampilkan satu kolom penuh
    );
  }
}

class KontenUtama extends StatelessWidget {
  const KontenUtama({super.key});

  @override
  Widget build(BuildContext context) {
    final lebar = MediaQuery.sizeOf(context).width;
    return Center(
      child: Text(
        "Lebar layar: ${lebar.toStringAsFixed(0)} px\n"
        "${lebar > 600 ? 'Mode Tablet (menu samping tampil)' : 'Mode HP (satu kolom)'}",
        textAlign: TextAlign.center,
        style: const TextStyle(fontSize: 18),
      ),
    );
  }
}
Dashboard di layar HP (mode satu kolom)

LayoutBuilder: responsif berdasarkan ruang induk

MediaQuery melihat ukuran layar. Masalahnya, sebuah widget belum tentu mendapat seluruh layar. Misalnya KontenUtama di contoh tadi hanya mendapat (lebar layar - 250) di mode tablet. LayoutBuilder memberi constraints yang benar-benar diterima widget tersebut.

LayoutBuilder(
  builder: (context, constraints) {
    // constraints.maxWidth = lebar yang diberikan induk
    final kolom = constraints.maxWidth >= 600 ? 3 : 2;
    return Text('Ruang ${constraints.maxWidth.toStringAsFixed(0)} px → $kolom kolom');
  },
)
LayoutBuilder menentukan jumlah kolom

Contoh lengkap 2: grid responsif dengan LayoutBuilder dan breakpoint

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(MaterialApp(
    debugShowCheckedModeBanner: false,
    theme: ThemeData(colorSchemeSeed: Colors.indigo),
    home: const KatalogMatkul(),
  ));
}

class KatalogMatkul extends StatelessWidget {
  const KatalogMatkul({super.key});

  static const _matkul = [
    'Pemrograman Mobile', 'Basis Data', 'Jaringan Komputer', 'Kecerdasan Buatan',
    'Sistem Operasi', 'Rekayasa Perangkat Lunak', 'Grafika Komputer', 'Keamanan Informasi',
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Katalog Mata Kuliah')),
      body: LayoutBuilder(
        builder: (context, constraints) {
          final lebar = constraints.maxWidth;
          // Jumlah kolom ditentukan dari breakpoint
          final int kolom;
          if (lebar >= 840) {
            kolom = 4;
          } else if (lebar >= 600) {
            kolom = 3;
          } else {
            kolom = 2;
          }

          return Column(
            children: [
              Padding(
                padding: const EdgeInsets.all(8),
                child: Text('Lebar ${lebar.toStringAsFixed(0)} px → $kolom kolom'),
              ),
              Expanded(
                child: GridView.count(
                  crossAxisCount: kolom,
                  padding: const EdgeInsets.all(8),
                  mainAxisSpacing: 8,
                  crossAxisSpacing: 8,
                  childAspectRatio: 1.2,
                  children: [
                    for (final m in _matkul)
                      Card.filled(
                        child: Padding(
                          padding: const EdgeInsets.all(12),
                          child: Column(
                            crossAxisAlignment: CrossAxisAlignment.start,
                            mainAxisAlignment: MainAxisAlignment.spaceBetween,
                            children: [
                              const Icon(Icons.menu_book),
                              Text(m, maxLines: 2, overflow: TextOverflow.ellipsis),
                            ],
                          ),
                        ),
                      ),
                  ],
                ),
              ),
            ],
          );
        },
      ),
    );
  }
}
Grid responsif: 2 kolom di HP portrait

GridView.count membuat grid dengan jumlah kolom tetap (dibahas lebih lengkap di Modul 06). Di sini jumlah kolomnya dihitung dari lebar yang diberikan LayoutBuilder.

OrientationBuilder: portrait vs landscape

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: HalamanKtm()));
}

class HalamanKtm extends StatelessWidget {
  const HalamanKtm({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('KTM Digital')),
      body: OrientationBuilder(
        builder: (context, orientation) {
          const foto = CircleAvatar(radius: 56, child: Icon(Icons.person, size: 64));
          const data = Column(
            mainAxisSize: MainAxisSize.min,
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Nadia Putri', style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
              Text('NIM: H1D021001'),
              Text('S1 Informatika • Angkatan 2021'),
            ],
          );

          // Portrait: foto di atas data. Landscape: foto di samping data.
          if (orientation == Orientation.portrait) {
            return const Center(
              child: Column(
                mainAxisSize: MainAxisSize.min,
                children: [foto, SizedBox(height: 16), data],
              ),
            );
          }
          return const Center(
            child: Row(
              mainAxisSize: MainAxisSize.min,
              children: [foto, SizedBox(width: 32), data],
            ),
          );
        },
      ),
    );
  }
}
OrientationBuilder pada mode portrait

Putar emulator (tombol rotasi di panel samping emulator) untuk melihat foto berpindah dari atas ke samping. Pastikan rotasi otomatis di emulator aktif.

⚠️ Kesalahan umum

  • Menulis ukuran piksel tetap seperti width: 360 untuk konten utama. Di HP 320 px terjadi overflow, di tablet tampak kecil di tengah. Gunakan Expanded, persentase dari lebar, atau breakpoint.
  • Memakai MediaQuery untuk widget yang ada di dalam panel sempit. Lebar layar besar, tetapi ruang widget kecil. Pakai LayoutBuilder.
  • Mengecek Platform.isAndroid untuk menentukan layout. Tablet Android dan HP Android sama-sama Android. Tentukan layout dari ukuran, bukan dari jenis platform.
  • Mengabaikan skala teks. Pengguna dengan font sistem besar membuat teks lebih tinggi; hindari tinggi tetap pada kotak berisi teks.
