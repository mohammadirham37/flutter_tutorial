Di dalam Row dan Column, anak biasanya berukuran sesuai isinya. Jika kita ingin anak mengisi sisa ruang, bungkus dengan Expanded atau Flexible.

ExpandedFlexible
Sifatfit: FlexFit.tight: anak dipaksa mengisi seluruh jatah ruangnyafit: FlexFit.loose: anak boleh lebih kecil dari jatahnya
AnalogiAir yang selalu memenuhi gelasBatu di dalam gelas: maksimal sebesar gelas
Cocok untukKolom isi, kartu sejajar sama lebar, TextField di samping tombolTeks yang bisa pendek atau panjang di samping ikon

Cara kerja: ruang sisa dibagi menurut flex

  1. Row menghitung dulu ukuran anak yang tidak dibungkus Expanded/Flexible.
  2. Sisa ruang dibagi ke anak Expanded/Flexible sesuai angka flex (default 1).
Row(
  children: [
    Expanded(flex: 2, child: Container(height: 50, color: Colors.red)),   // 2/3 ruang
    Expanded(flex: 1, child: Container(height: 50, color: Colors.blue)),  // 1/3 ruang
  ],
)
Expanded flex 2 : 1

Expanded vs Flexible dalam satu contoh kecil

Column(
  children: [
    // Expanded: kotak hijau dipaksa selebar sisa ruang
    Row(children: [
      const Icon(Icons.star),
      Expanded(child: Container(color: Colors.green, child: const Text('Expanded'))),
    ]),
    // Flexible: kotak kuning hanya selebar teksnya
    Row(children: [
      const Icon(Icons.star),
      Flexible(child: Container(color: Colors.amber, child: const Text('Flexible'))),
    ]),
  ],
)
Expanded (penuh) vs Flexible (seukuran isi)

Contoh lengkap 1: membandingkan flex, Expanded, dan Flexible

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: DemoFlex()));
}

class DemoFlex extends StatelessWidget {
  const DemoFlex({super.key});

  Widget _kotak(String teks, Color warna) {
    return Container(
      height: 56,
      color: warna,
      alignment: Alignment.center,
      child: Text(teks, style: const TextStyle(color: Colors.white)),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Expanded vs Flexible')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          const Text('1. Tiga Expanded flex sama (1:1:1)'),
          Row(children: [
            Expanded(child: _kotak('1', Colors.red)),
            Expanded(child: _kotak('1', Colors.green)),
            Expanded(child: _kotak('1', Colors.blue)),
          ]),
          const SizedBox(height: 16),

          const Text('2. Flex berbeda (1:2:3)'),
          Row(children: [
            Expanded(flex: 1, child: _kotak('1', Colors.red)),
            Expanded(flex: 2, child: _kotak('2', Colors.green)),
            Expanded(flex: 3, child: _kotak('3', Colors.blue)),
          ]),
          const SizedBox(height: 16),

          const Text('3. Lebar tetap + Expanded mengisi sisa'),
          Row(children: [
            SizedBox(width: 80, child: _kotak('80 px', Colors.grey)),
            Expanded(child: _kotak('sisa ruang', Colors.indigo)),
            SizedBox(width: 80, child: _kotak('80 px', Colors.grey)),
          ]),
          const SizedBox(height: 16),

          const Text('4. Expanded (tight) vs Flexible (loose)'),
          Row(children: [
            Expanded(child: Container(color: Colors.teal.shade100, child: const Text('Expanded'))),
            Flexible(child: Container(color: Colors.orange.shade100, child: const Text('Flexible'))),
          ]),
          const SizedBox(height: 16),

          const Text('5. Expanded di Column (sumbu vertikal)'),
          SizedBox(
            height: 200,
            child: Column(children: [
              _kotak('header tetap', Colors.grey),
              Expanded(child: Container(color: Colors.purple.shade100, alignment: Alignment.center, child: const Text('isi mengisi sisa tinggi'))),
              _kotak('footer tetap', Colors.grey),
            ]),
          ),
        ],
      ),
    );
  }
}
Perbandingan flex, Expanded, dan Flexible

Penjelasan

  • Baris 4: Expanded dan Flexible sama-sama mendapat jatah separuh lebar. Kotak Expanded memenuhi jatahnya, kotak Flexible hanya selebar teks "Flexible".
  • Baris 5: Expanded juga bekerja di Column. Pola header-isi-footer seperti ini sering dipakai pada halaman chat atau keranjang belanja.
  • Method _kotak adalah helper kecil agar kode tidak berulang.

Contoh lengkap 2: teks panjang di samping ikon

Ketika teks atau konten terlalu panjang di dalam Row, layar akan menampilkan garis kuning-hitam "A RenderFlex overflowed by xxx pixels". Solusinya adalah membungkus widget tersebut dengan Expanded:

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text("Contoh Expanded")),
        body: Padding(
          padding: const EdgeInsets.all(16),
          // Contoh Menghindari Overflow pada Row
          child: Row(
            children: [
              const Icon(Icons.school, size: 40, color: Colors.indigo),
              const SizedBox(width: 12),
              // Expanded memaksa teks mengambil sisa ruang yang tersedia saja!
              // Coba hapus Expanded ini lalu hot reload: muncul garis kuning-hitam overflow.
              const Expanded(
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text(
                      "Mata Kuliah Rekayasa Perangkat Lunak Berorientasi Objek Lanjutan",
                      style: TextStyle(fontWeight: FontWeight.bold),
                      maxLines: 2,
                      overflow: TextOverflow.ellipsis, // Tambahkan '...' jika terpotong
                    ),
                    Text("Kode: IF-3021 • 3 SKS", style: TextStyle(color: Colors.grey)),
                  ],
                ),
              ),
              IconButton(
                icon: const Icon(Icons.bookmark_border),
                onPressed: () {},
              ),
            ],
          ),
        ),
      ),
    );
  }
}
Teks panjang dibungkus Expanded sehingga tidak overflow

Contoh lengkap 3: TextField di samping tombol

TextField ingin selebar mungkin. Di dalam Row (lebar tak terbatas), ini menimbulkan error. Expanded memberi batas lebar yang jelas.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: KolomCari()));
}

class KolomCari extends StatelessWidget {
  const KolomCari({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Cari Mata Kuliah')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Row(
          children: [
            // Tanpa Expanded: error "An InputDecorator ... cannot have an unbounded width"
            const Expanded(
              child: TextField(
                decoration: InputDecoration(
                  hintText: 'Nama mata kuliah...',
                  border: OutlineInputBorder(),
                ),
              ),
            ),
            const SizedBox(width: 8),
            FilledButton(onPressed: () {}, child: const Text('Cari')),
          ],
        ),
      ),
    );
  }
}
TextField di dalam Expanded di samping tombol

⚠️ Kesalahan umum

  • Memakai Expanded di luar Row/Column/Flex. Contoh: Expanded langsung di dalam Container atau Stack. Hasilnya error "Incorrect use of ParentDataWidget".
  • Expanded di dalam Column yang berada di SingleChildScrollView. Tinggi tak terbatas tidak bisa dibagi, sehingga error. Hapus Expanded atau beri tinggi tetap.
  • Memberi width pada anak Expanded di Row. Lebarnya tetap dipaksa sesuai jatah flex; width diabaikan.
