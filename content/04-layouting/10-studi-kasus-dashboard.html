Saatnya menggabungkan semua yang sudah dipelajari menjadi satu halaman utuh: Dashboard Portal Mahasiswa. Halaman ini memakai Stack, Row, Column, Expanded, Wrap, AspectRatio, Spacer, SafeArea, SingleChildScrollView, dan LayoutBuilder sekaligus.

Langkah 1: rancang dulu di atas kertas

Sebelum menulis kode, pecah halaman menjadi kotak-kotak. Setiap kotak nantinya menjadi satu widget.

Scaffold
└── SafeArea (bagian bawah)
    └── SingleChildScrollView
        └── Column
            ├── HeaderDashboard      ← Stack: banner gradasi + avatar + sapaan
            ├── RingkasanAkademik    ← Row + 3 x Expanded(KartuStatistik)
            ├── JudulBagian "Menu"
            ├── MenuCepat            ← LayoutBuilder + Wrap (jumlah per baris menyesuaikan)
            ├── JudulBagian "Jadwal Hari Ini"
            ├── KartuJadwal x 3      ← Row: jam | garis | detail(Expanded)
            ├── JudulBagian "Pengumuman"
            └── BannerPengumuman     ← AspectRatio 16:7 + Stack

class KartuStatistik extends StatelessWidget {

          ],
        ),
      ),
    );
  }
}

// ======================= MENU CEPAT (LayoutBuilder + Wrap) =======================

class MenuCepat extends StatelessWidget {
  const MenuCepat({super.key});

  static const _menu = [
    (Icons.edit_note, 'KRS'),
    (Icons.calendar_month, 'Jadwal'),
    (Icons.grade, 'Transkrip'),
    (Icons.payments, 'Tagihan UKT'),
    (Icons.local_library, 'Perpustakaan'),
    (Icons.campaign, 'Pengumuman'),
    (Icons.event_available, 'Presensi'),
    (Icons.support_agent, 'Layanan'),
  ];

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.symmetric(horizontal: 16),
      child: LayoutBuilder(
        builder: (context, constraints) {
          // HP: 4 per baris. Layar lebar: 8 per baris.
          final perBaris = constraints.maxWidth >= 600 ? 8 : 4;
          final lebarItem = constraints.maxWidth / perBaris;
          return Wrap(
            runSpacing: 12,
            children: [
              for (final (ikon, label) in _menu)
                SizedBox(width: lebarItem, child: ItemMenu(ikon: ikon, label: label)),
            ],
          );
        },
      ),
    );
  }
}

class ItemMenu extends StatelessWidget {
  final IconData ikon;
  final String label;

  const ItemMenu({super.key, required this.ikon, required this.label});

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return InkWell(
      onTap: () {},
      borderRadius: BorderRadius.circular(12),
      child: Column(
        children: [
          Container(
            width: 52,
            height: 52,
            decoration: BoxDecoration(
              color: warna.primaryContainer,
              borderRadius: BorderRadius.circular(16),
            ),
            child: Icon(ikon, color: warna.onPrimaryContainer),
          ),
          const SizedBox(height: 6),
          Text(
            label,
            textAlign: TextAlign.center,
            maxLines: 1,
            overflow: TextOverflow.ellipsis,
            style: const TextStyle(fontSize: 12),
          ),
        ],
      ),
    );
  }
}

class KartuJadwal extends StatelessWidget {
  final String jam;
  final String matkul;
  final String ruang;
  final bool sedangBerlangsung;

  const KartuJadwal({
    super.key,
    required this.jam,
    required this.matkul,
    required this.ruang,
    this.sedangBerlangsung = false,
  });

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return Card.outlined(
      margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 4),
      child: Padding(
        padding: const EdgeInsets.all(12),
        child: Row(
          children: [
            SizedBox(
              width: 52,
              child: Text(jam, style: const TextStyle(fontWeight: FontWeight.bold)),
            ),
            Container(
              width: 4,
              height: 44,
              decoration: BoxDecoration(
                color: sedangBerlangsung ? Colors.green : warna.outlineVariant,
                borderRadius: BorderRadius.circular(2),
              ),
            ),
            const SizedBox(width: 12),
            Expanded(
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(matkul, maxLines: 1, overflow: TextOverflow.ellipsis,
                      style: const TextStyle(fontWeight: FontWeight.w600)),
                  Row(
                    children: [
                      const Icon(Icons.room, size: 14, color: Colors.grey),
                      const SizedBox(width: 4),
                      Text(ruang, style: const TextStyle(color: Colors.grey)),
                    ],
                  ),
                ],
              ),
            ),
            if (sedangBerlangsung) const Chip(label: Text('Berlangsung')),
          ],
        ),
      ),
    );
  }
}

Langkah 3: bedah kode per bagian

BagianTeknik layoutKenapa?
DashboardMahasiswaSafeArea(top: false) + SingleChildScrollViewHeader boleh sampai ke status bar, tetapi bagian bawah aman. Seluruh halaman bisa digulir sehingga tidak overflow di HP kecil atau landscape.
HeaderDashboardStack + Positioned + ExpandedLingkaran dekorasi ditumpuk di atas gradasi. Nama panjang tidak mendorong ikon notifikasi keluar.
RingkasanAkademik3 x Expanded + Transform.translateTiga kartu selalu sama lebar, dan digeser ke atas agar menumpuk di tepi header.
JudulBagianRow + SpacerJudul di kiri, "Lihat semua" di kanan.
MenuCepatLayoutBuilder + WrapLebar item dihitung dari ruang yang tersedia: 4 per baris di HP, 8 di tablet.
KartuJadwalRow: lebar tetap | garis | ExpandedKolom jam rapi sejajar; nama mata kuliah panjang dipotong dengan ellipsis.
BannerPengumumanAspectRatio + Stack(fit: StackFit.expand)Proporsi banner tetap di semua ukuran layar.
  • static const _menu = [(Icons.edit_note, 'KRS'), ...] memakai record Dart 3, lalu dibongkar dengan for (final (ikon, label) in _menu) (lihat Modul 02).
  • FittedBox mengecilkan label statistik secara otomatis jika kartu terlalu sempit, sebagai pengaman tambahan dari overflow.
  • Badge adalah widget Material 3 untuk angka kecil di pojok ikon.

Langkah 4: uji ketahanan layout

  1. Putar emulator ke landscape: halaman tetap bisa digulir tanpa garis kuning-hitam.
  2. Jalankan di Chrome (flutter run -d chrome) dan lebarkan jendela: menu cepat berubah menjadi 8 per baris.
  3. Ganti nama di HeaderDashboard dengan nama yang sangat panjang: nama terpotong dengan "...".
  4. Perbesar ukuran font di pengaturan HP (Settings → Display → Font size): periksa apakah ada yang terpotong.

⚠️ Kesalahan umum pada studi kasus

  • Menulis semua bagian di satu method build sampai ratusan baris. Pecah seperti contoh: satu bagian = satu class.
  • Memakai Expanded di dalam Column halaman padahal Column berada di SingleChildScrollView. Tinggi tak terbatas tidak bisa dibagi dan akan error.
  • Lupa maxLines + ellipsis pada teks yang datanya berasal dari server. Panjang data asli sering di luar dugaan.
