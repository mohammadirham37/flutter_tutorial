Row tidak pernah pindah baris: jika anaknya terlalu banyak, terjadi overflow. Wrap menyusun anak berderet seperti Row, tetapi otomatis turun ke baris baru saat ruangnya habis, seperti kata-kata dalam paragraf.

Row vs Wrap

Row  (overflow):  [Flutter] [Dart] [Firebase] [Supabase] [Hi▓▓▓▓
Wrap (rapi)    :  [Flutter] [Dart] [Firebase]
                  [Supabase] [Hive] [REST API]

Contoh kecil

Wrap(
  spacing: 8,      // jarak horizontal antar anak
  runSpacing: 8,   // jarak vertikal antar baris
  children: const [
    Chip(label: Text('Flutter')),
    Chip(label: Text('Dart')),
    Chip(label: Text('Firebase')),
    Chip(label: Text('Supabase')),
    Chip(label: Text('Hive')),
  ],
)
Chip di dalam Wrap turun baris otomatis

Properti penting

PropertiFungsi
directionAxis.horizontal (default) atau Axis.vertical.
spacingJarak antar anak dalam satu baris.
runSpacingJarak antar baris.
alignmentPerataan anak di setiap baris: WrapAlignment.start, center, spaceBetween, dll.

Contoh lengkap: pilih minat dan menu ikon

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(MaterialApp(
    debugShowCheckedModeBanner: false,
    theme: ThemeData(colorSchemeSeed: Colors.indigo),
    home: const DemoWrap(),
  ));
}

class DemoWrap extends StatefulWidget {
  const DemoWrap({super.key});

  @override
  State<DemoWrap> createState() => _DemoWrapState();
}

class _DemoWrapState extends State<DemoWrap> {
  final List<String> _topik = [
    'Mobile', 'Web', 'AI', 'Data Science', 'Keamanan Siber',
    'IoT', 'Game', 'UI/UX', 'Cloud', 'Jaringan',
  ];
  final Set<String> _dipilih = {'Mobile'};

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Demo Wrap')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Text('Pilih minat peminatan (${_dipilih.length} dipilih):'),
          const SizedBox(height: 8),
          // 1. Chip yang bisa dipilih, otomatis turun baris
          Wrap(
            spacing: 8,
            runSpacing: 4,
            children: [
              for (final t in _topik)
                FilterChip(
                  label: Text(t),
                  selected: _dipilih.contains(t),
                  onSelected: (pilih) {
                    setState(() {
                      if (pilih) {
                        _dipilih.add(t);
                      } else {
                        _dipilih.remove(t);
                      }
                    });
                  },
                ),
            ],
          ),
          const Divider(height: 32),
          const Text('Menu cepat (rata tengah):'),
          const SizedBox(height: 8),
          // 2. Menu ikon dengan lebar tetap, rata tengah
          const Wrap(
            alignment: WrapAlignment.center,
            spacing: 16,
            runSpacing: 16,
            children: [
              MenuIkon(ikon: Icons.edit_note, label: 'KRS'),
              MenuIkon(ikon: Icons.calendar_month, label: 'Jadwal'),
              MenuIkon(ikon: Icons.grade, label: 'Nilai'),
              MenuIkon(ikon: Icons.payments, label: 'UKT'),
              MenuIkon(ikon: Icons.local_library, label: 'Perpus'),
              MenuIkon(ikon: Icons.campaign, label: 'Info'),
              MenuIkon(ikon: Icons.event_available, label: 'Presensi'),
            ],
          ),
        ],
      ),
    );
  }
}

class MenuIkon extends StatelessWidget {
  final IconData ikon;
  final String label;

  const MenuIkon({super.key, required this.ikon, required this.label});

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return SizedBox(
      width: 72,
      child: Column(
        children: [
          Container(
            width: 56,
            height: 56,
            decoration: BoxDecoration(
              color: warna.primaryContainer,
              borderRadius: BorderRadius.circular(16),
            ),
            child: Icon(ikon, color: warna.onPrimaryContainer),
          ),
          const SizedBox(height: 4),
          Text(label, style: const TextStyle(fontSize: 12)),
        ],
      ),
    );
  }
}
FilterChip dan menu ikon di dalam Wrap
Setelah memilih beberapa minat

Penjelasan kode

  • FilterChip adalah chip yang bisa dipilih. Pilihan disimpan di Set agar tidak ada nama ganda.
  • Setiap MenuIkon lebarnya tetap 72 px. Di HP sempit menjadi 4 per baris, di HP lebar atau landscape lebih banyak per baris, tanpa kode tambahan.
  • WrapAlignment.center membuat baris terakhir yang tidak penuh tetap di tengah.

⚠️ Kesalahan umum

  • Memakai Expanded di dalam Wrap. Wrap bukan Flex, jadi Expanded tidak bekerja dan memicu error.
  • Memakai Wrap untuk ratusan item. Wrap membangun semua anak sekaligus. Untuk daftar panjang, gunakan GridView.builder (Modul 06).
  • Lupa runSpacing sehingga baris-baris saling menempel.
