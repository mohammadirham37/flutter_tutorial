Layar HP modern tidak lagi persegi panjang sempurna: ada status bar, notch/poni, lubang kamera, sudut membulat, dan garis navigasi gestur di bawah. SafeArea memberi padding otomatis agar konten tidak tertutup bagian-bagian tersebut.

┌──────────────────────────┐
│ 12:30   ▀▀▀▀▀▀     ▮ 85% │ ← status bar + notch (tidak aman)
├──────────────────────────┤
│                          │
│     AREA AMAN            │ ← SafeArea menaruh konten di sini
│                          │
├──────────────────────────┤
│         ───────          │ ← garis navigasi gestur (tidak aman)
└──────────────────────────┘

Kapan perlu SafeArea?

  • Halaman dengan AppBar: AppBar sudah otomatis menghindari status bar. body tidak perlu SafeArea untuk bagian atas.
  • Halaman tanpa AppBar (splash screen, halaman login penuh, halaman dengan header gambar): perlu SafeArea.
  • Konten menempel di bawah layar (tombol "Bayar" di bawah): perlu SafeArea bagian bawah agar tidak tertutup garis gestur.

Contoh kecil

Scaffold(
  // Tanpa AppBar: teks ini akan tertutup status bar jika tanpa SafeArea
  body: SafeArea(
    child: Column(
      children: const [
        Text('Selamat Datang', style: TextStyle(fontSize: 28)),
        Text('Silakan masuk dengan akun SSO UNSOED'),
      ],
    ),
  ),
)
Halaman tanpa AppBar dengan SafeArea

Memilih sisi yang dilindungi

SafeArea(
  top: false,   // atas boleh menempel (misal gambar header sampai ke status bar)
  bottom: true, // bawah tetap aman dari garis gestur
  minimum: const EdgeInsets.all(16), // padding minimum walau HP tidak punya notch
  child: FilledButton(onPressed: () {}, child: const Text('Bayar UKT')),
)
SafeArea bagian bawah dengan padding minimum

Contoh lengkap: membandingkan dengan dan tanpa SafeArea

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(debugShowCheckedModeBanner: false, home: DemoSafeArea()));
}

class DemoSafeArea extends StatefulWidget {
  const DemoSafeArea({super.key});

  @override
  State<DemoSafeArea> createState() => _DemoSafeAreaState();
}

class _DemoSafeAreaState extends State<DemoSafeArea> {
  bool _pakaiSafeArea = false;

  @override
  Widget build(BuildContext context) {
    // Besar area yang tidak aman di HP ini
    final padding = MediaQuery.paddingOf(context);

    final isi = Container(
      color: Colors.teal.shade100,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          Container(
            color: Colors.teal,
            padding: const EdgeInsets.all(8),
            child: const Text('TEKS PALING ATAS', style: TextStyle(color: Colors.white)),
          ),
          Expanded(
            child: Center(
              child: Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  Text('Padding atas (status bar): ${padding.top.toStringAsFixed(0)} px'),
                  Text('Padding bawah (navigasi): ${padding.bottom.toStringAsFixed(0)} px'),
                  const SizedBox(height: 16),
                  SwitchListTile(
                    title: const Text('Pakai SafeArea'),
                    value: _pakaiSafeArea,
                    onChanged: (v) => setState(() => _pakaiSafeArea = v),
                  ),
                ],
              ),
            ),
          ),
          Container(
            color: Colors.teal,
            padding: const EdgeInsets.all(8),
            child: const Text('TEKS PALING BAWAH', style: TextStyle(color: Colors.white)),
          ),
        ],
      ),
    );

    return Scaffold(
      // Sengaja tanpa AppBar
      body: _pakaiSafeArea ? SafeArea(child: isi) : isi,
    );
  }
}
Tanpa SafeArea: teks paling atas tertutup status bar
Dengan SafeArea: konten turun ke area aman

Penjelasan kode

  • MediaQuery.paddingOf(context) berisi ukuran area tidak aman. Nilai inilah yang dipakai SafeArea sebagai padding.
  • Saat SafeArea mati, teks "PALING ATAS" bertabrakan dengan jam dan ikon baterai. Saat SafeArea aktif, teks turun ke area aman.
  • Widget isi disimpan dalam variabel agar bisa dipakai dengan atau tanpa SafeArea tanpa menulis ulang.

⚠️ Kesalahan umum

  • Membungkus seluruh Scaffold dengan SafeArea. Latar AppBar jadi tidak menyatu dengan status bar dan muncul strip kosong. Taruh SafeArea di dalam body.
  • Hanya menguji di emulator tanpa notch. Coba juga emulator dengan notch/lubang kamera dan mode landscape (notch pindah ke samping).
  • Lupa sisi bawah untuk tombol yang menempel di bawah layar pada HP dengan navigasi gestur.
