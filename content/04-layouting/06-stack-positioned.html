Jika Row dan Column menyusun widget secara berurutan tanpa tumpang tindih, widget Stack menumpuk widget di atas widget lainnya (z-index). Anak pertama berada paling bawah, anak terakhir paling atas, seperti layer di aplikasi desain.

children: [A, B, C]      tampak dari samping:   C  ← paling atas
                                                 B
                                                 A  ← paling bawah

Contoh kecil: teks di atas gambar

Stack(
  children: [
    Container(width: 300, height: 160, color: Colors.indigo), // lapisan bawah
    const Positioned(
      left: 16,
      bottom: 16,
      child: Text('Fakultas Teknik', style: TextStyle(color: Colors.white, fontSize: 20)),
    ),
  ],
)
Teks ditumpuk di atas kotak dengan Positioned

Positioned dan alignment

  • Anak tanpa Positioned diletakkan menurut Stack.alignment (default AlignmentDirectional.topStart, pojok kiri atas).
  • Positioned(top, bottom, left, right, width, height) mengatur jarak anak dari tepi Stack. Isi dua sisi yang berlawanan (misal left: 0, right: 0) untuk merentangkan anak.
  • Positioned.fill() membuat anak memenuhi seluruh Stack, cocok untuk lapisan gradasi gelap di atas foto.
  • Ukuran Stack mengikuti anak terbesar yang tidak memakai Positioned.
Stack(
  alignment: Alignment.center, // anak tanpa Positioned ditaruh di tengah
  children: [
    Container(width: 200, height: 200, color: Colors.amber),
    Container(width: 120, height: 120, color: Colors.orange),
    Container(width: 60, height: 60, color: Colors.red),
  ],
)

Header profil dengan banner dan avatar menumpuk

Penjelasan kode

  • Stack diberi tinggi 260 lewat SizedBox, sedangkan banner hanya 200. Sisa 60 px dipakai avatar yang menjorok ke bawah banner.
  • top: -40, right: -40: nilai negatif menggeser lingkaran keluar dari Stack. Bagian yang keluar terpotong karena default clipBehavior Stack adalah Clip.hardEdge; di contoh pertama kita memakai Clip.none agar badge boleh keluar.
  • MediaQuery.paddingOf(context).top adalah tinggi status bar, agar tombol kembali tidak tertutup jam dan baterai (dibahas di section SafeArea).
  • Urutan anak menentukan lapisan: avatar ditulis setelah banner, maka avatar tampil di atasnya.

⚠️ Kesalahan umum

  • Stack berisi hanya anak Positioned. Stack tidak punya acuan ukuran, sehingga ukurannya mengikuti constraint terbesar atau malah nol. Beri satu anak tidak-Positioned atau bungkus dengan SizedBox.
  • Positioned di luar Stack menimbulkan error "Incorrect use of ParentDataWidget".
  • Urutan terbalik: widget yang ditulis paling akhir menutupi yang lain, termasuk menghalangi sentuhan ke tombol di bawahnya.
  • Memakai Stack + Positioned untuk seluruh layout halaman dengan angka piksel tetap. Hasilnya berantakan di layar berbeda. Gunakan Stack hanya untuk bagian yang memang bertumpuk.
