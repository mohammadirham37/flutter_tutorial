Setelah pengguna menekan tombol, aplikasi harus memberi tanggapan: "berhasil disimpan", "yakin ingin menghapus?", atau menampilkan pilihan tambahan. Tiga alat utamanya adalah SnackBar, AlertDialog, dan BottomSheet.

WidgetSifatKapan dipakai
SnackBarPesan singkat di bawah layar, hilang sendiri, tidak menghalangiKonfirmasi berhasil, tombol Urungkan
AlertDialogKotak di tengah layar, menghentikan interaksi sampai dijawabKonfirmasi hapus, peringatan penting
showModalBottomSheetPanel dari bawah layarDaftar pilihan aksi, form singkat

1. SnackBar

SnackBar ditampilkan lewat ScaffoldMessenger.of(context).showSnackBar(...). Tanda .. (cascade) memanggil dua method berturut-turut pada objek yang sama.

void _tampilkanSnackBar(BuildContext context) {
  ScaffoldMessenger.of(context)
    ..hideCurrentSnackBar() // tutup SnackBar lama agar tidak antre
    ..showSnackBar(
      SnackBar(
        content: const Text('Tugas berhasil dikumpulkan'),
        behavior: SnackBarBehavior.floating, // melayang, sudut membulat
        duration: const Duration(seconds: 3),
        action: SnackBarAction(
          label: 'LIHAT',
          onPressed: () => debugPrint('Buka detail tugas'),
        ),
      ),
    );
}
SnackBar mengambang dengan tombol LIHAT

2. AlertDialog yang mengembalikan jawaban

showDialog<bool> menunggu sampai dialog ditutup. Nilai yang dikirim lewat Navigator.pop(dialogContext, nilai) menjadi hasil await.

Future<void> _konfirmasiHapus(BuildContext context) async {
  // showDialog mengembalikan nilai yang dikirim lewat Navigator.pop
  final yakin = await showDialog<bool>(
    context: context,
    builder: (dialogContext) => AlertDialog(
      icon: const Icon(Icons.warning_amber),
      title: const Text('Hapus mata kuliah?'),
      content: const Text('Data yang dihapus tidak dapat dikembalikan.'),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(dialogContext, false),
          child: const Text('Batal'),
        ),
        FilledButton(
          onPressed: () => Navigator.pop(dialogContext, true),
          child: const Text('Hapus'),
        ),
      ],
    ),
  );

  // yakin bisa null jika dialog ditutup dengan mengetuk area luar
  if (yakin == true && context.mounted) {
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Mata kuliah dihapus')),
    );
  }
}
AlertDialog konfirmasi hapus

Perhatikan context.mounted: setelah await, layar bisa saja sudah ditutup. Memakai context yang sudah tidak terpasang akan menimbulkan error, jadi selalu periksa dulu.

3. Modal BottomSheet

Future<void> _pilihSumberFoto(BuildContext context) async {
  final pilihan = await showModalBottomSheet<String>(
    context: context,
    showDragHandle: true, // garis kecil di atas sheet
    builder: (sheetContext) => SafeArea(
      child: Column(
        mainAxisSize: MainAxisSize.min, // tinggi sheet secukupnya
        children: [
          ListTile(
            leading: const Icon(Icons.camera_alt),
            title: const Text('Kamera'),
            onTap: () => Navigator.pop(sheetContext, 'kamera'),
          ),
          ListTile(
            leading: const Icon(Icons.photo_library),
            title: const Text('Galeri'),
            onTap: () => Navigator.pop(sheetContext, 'galeri'),
          ),
        ],
      ),
    ),
  );
  debugPrint('Dipilih: $pilihan'); // null jika sheet ditutup tanpa memilih
}
BottomSheet berisi pilihan Kamera dan Galeri

mainAxisSize: MainAxisSize.min membuat tinggi sheet mengikuti isinya. SafeArea mencegah isi tertutup bilah navigasi HP.

Contoh lengkap: catatan tugas dengan tiga jenis umpan balik

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: const CatatanTugasScreen(),
    );
  }
}

class CatatanTugasScreen extends StatefulWidget {
  const CatatanTugasScreen({super.key});

  @override
  State<CatatanTugasScreen> createState() => _CatatanTugasScreenState();
}

class _CatatanTugasScreenState extends State<CatatanTugasScreen> {
  final List<String> _tugas = [
    'Laporan Praktikum Basis Data',
    'Kuis Pemrograman Mobile',
    'Makalah Etika Profesi',
  ];

  // ---------- 1. SnackBar dengan tombol UNDO ----------
  void _hapusDenganUndo(int index) {
    final terhapus = _tugas[index];
    setState(() => _tugas.removeAt(index));

    ScaffoldMessenger.of(context)
      ..hideCurrentSnackBar()
      ..showSnackBar(
        SnackBar(
          content: Text('"$terhapus" dihapus'),
          action: SnackBarAction(
            label: 'URUNGKAN',
            onPressed: () => setState(() => _tugas.insert(index, terhapus)),
          ),
        ),
      );
  }

  // ---------- 2. AlertDialog konfirmasi ----------
  Future<void> _konfirmasiHapusSemua() async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Hapus semua tugas?'),
        content: Text('${_tugas.length} tugas akan dihapus.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Hapus Semua'),
          ),
        ],
      ),
    );
    if (yakin != true || !mounted) return;
    setState(() => _tugas.clear());
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Semua tugas dihapus')),
    );
  }

  // ---------- 3. Dialog berisi TextField untuk menambah data ----------
  Future<void> _dialogTambah() async {
    // Cukup simpan teks di variabel lokal lewat onChanged.
    // (Membuat TextEditingController di sini berisiko: controller harus
    // di-dispose, padahal TextField masih hidup selama animasi dialog ditutup.)
    var teks = '';
    final judul = await showDialog<String>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Tugas baru'),
        content: TextField(
          autofocus: true,
          decoration: const InputDecoration(hintText: 'Judul tugas'),
          onChanged: (v) => teks = v,
          onSubmitted: (v) => Navigator.pop(dialogContext, v),
        ),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, teks),
            child: const Text('Tambah'),
          ),
        ],
      ),
    );

    if (judul == null || judul.trim().isEmpty || !mounted) return;
    setState(() => _tugas.add(judul.trim()));
  }

  // ---------- 4. BottomSheet berisi pilihan aksi ----------
  Future<void> _menuTugas(int index) async {
    final aksi = await showModalBottomSheet<String>(
      context: context,
      showDragHandle: true,
      builder: (sheetContext) => SafeArea(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Padding(
              padding: const EdgeInsets.all(8),
              child: Text(_tugas[index], style: const TextStyle(fontWeight: FontWeight.bold)),
            ),
            ListTile(
              leading: const Icon(Icons.check_circle_outline),
              title: const Text('Tandai selesai'),
              onTap: () => Navigator.pop(sheetContext, 'selesai'),
            ),
            ListTile(
              leading: const Icon(Icons.delete_outline),
              title: const Text('Hapus'),
              onTap: () => Navigator.pop(sheetContext, 'hapus'),
            ),
          ],
        ),
      ),
    );
    if (!mounted) return;
    if (aksi == 'hapus') _hapusDenganUndo(index);
    if (aksi == 'selesai') {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Mantap! "${_tugas[index]}" selesai'),
          behavior: SnackBarBehavior.floating,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Catatan Tugas'),
        actions: [
          IconButton(
            tooltip: 'Hapus semua',
            icon: const Icon(Icons.delete_sweep),
            onPressed: _tugas.isEmpty ? null : _konfirmasiHapusSemua,
          ),
        ],
      ),
      body: _tugas.isEmpty
          ? const Center(child: Text('Tidak ada tugas. Santai dulu!'))
          : ListView(
              children: [
                for (var i = 0; i < _tugas.length; i++)
                  ListTile(
                    leading: CircleAvatar(child: Text('${i + 1}')),
                    title: Text(_tugas[i]),
                    subtitle: const Text('Ketuk untuk opsi'),
                    onTap: () => _menuTugas(i),
                  ),
              ],
            ),
      floatingActionButton: FloatingActionButton(
        tooltip: 'Tambah tugas',
        onPressed: _dialogTambah,
        child: const Icon(Icons.add),
      ),
    );
  }
}
Menu bottom sheet saat tugas diketuk
SnackBar dengan tombol URUNGKAN setelah tugas dihapus
Dialog berisi TextField untuk menambah tugas

Penjelasan kode:

  • Urungkan: sebelum menghapus, item dan posisinya disimpan (terhapus, index). Tombol URUNGKAN memasukkannya kembali dengan insert(index, terhapus).
  • Hapus semua: dialog mengembalikan bool?. Ditulis yakin != true agar nilai null (dialog ditutup dengan mengetuk luar) dianggap batal.
  • Tambah: dialog bisa berisi TextField. Teks disimpan ke variabel lokal lewat onChanged lalu dikirim lewat Navigator.pop.
  • Menu tugas: bottom sheet mengembalikan String berisi aksi yang dipilih, lalu diproses setelah sheet tertutup.
  • Tombol hapus semua di AppBar diberi onPressed: _tugas.isEmpty ? null : ... sehingga nonaktif saat daftar kosong.

⚠️ Kesalahan umum

  • Memakai context milik layar untuk menutup dialog. Gunakan context dari builder dialog (dialogContext) di Navigator.pop.
  • SnackBar menumpuk dan antre lama. Panggil hideCurrentSnackBar() sebelum menampilkan yang baru.
  • Lupa memeriksa mounted setelah await showDialog. Muncul peringatan "use_build_context_synchronously".
  • BottomSheet berisi form tertutup keyboard. Gunakan isScrollControlled: true dan padding sebesar MediaQuery.viewInsetsOf(context).bottom (lihat studi kasus Modul 06).
