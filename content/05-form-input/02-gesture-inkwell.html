Tidak semua yang bisa ditekan harus berbentuk tombol. Kartu mata kuliah, foto profil, atau kotak menu juga bisa dibuat responsif terhadap sentuhan menggunakan GestureDetector atau InkWell.

Konsep

GestureDetectorInkWell
Efek visual saat ditekanTidak adaRiak air (ripple) khas Material
Jenis gesturSangat lengkap: tap, double tap, long press, drag, pan, scaleTap, double tap, long press, hover
SyaratTidak adaHarus ada widget Material (atau Card, Scaffold) di atasnya
Cocok untukGestur khusus (geser, cubit), area tanpa efekKartu atau baris yang bisa diklik

Contoh kecil: GestureDetector

Bungkus widget apa pun dengan GestureDetector lalu isi callback gestur yang ingin ditangkap.

GestureDetector(
  onTap: () => debugPrint('Tap sekali'),
  onDoubleTap: () => debugPrint('Tap dua kali'),
  onLongPress: () => debugPrint('Tekan lama'),
  child: Container(
    padding: const EdgeInsets.all(24),
    color: Colors.amber,
    child: const Text('Sentuh saya'),
  ),
),
Kotak kuning yang bisa disentuh. Tidak ada efek visual apa pun saat ditekan

Contoh kecil: InkWell

InkWell menggambar efek riak di atas widget Material terdekat. Karena itu warna latar sebaiknya diberikan ke Material, bukan ke Container di dalam InkWell (Container berwarna akan menutupi riaknya).

// Material memberi "kanvas" tempat efek riak digambar
Material(
  color: Colors.indigo.shade50,
  borderRadius: BorderRadius.circular(12),
  child: InkWell(
    borderRadius: BorderRadius.circular(12), // riak ikut melengkung
    onTap: () => debugPrint('Kartu ditekan'),
    child: const Padding(
      padding: EdgeInsets.all(24),
      child: Text('Kartu dengan efek riak'),
    ),
  ),
),
Kartu dengan efek riak saat ditekan

Contoh lengkap: berbagai gestur dalam satu layar

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const GestureDemoScreen(),
    );
  }
}

class GestureDemoScreen extends StatefulWidget {
  const GestureDemoScreen({super.key});

  @override
  State<GestureDemoScreen> createState() => _GestureDemoScreenState();
}

class _GestureDemoScreenState extends State<GestureDemoScreen> {
  String _log = 'Belum ada gestur';
  bool _disukai = false;
  double _geserX = 0;

  void _tulisLog(String pesan) => setState(() => _log = pesan);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('GestureDetector & InkWell')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Card(
            child: Padding(
              padding: const EdgeInsets.all(16),
              child: Text('Log: $_log', style: const TextStyle(fontSize: 16)),
            ),
          ),
          const SizedBox(height: 16),

          // 1. GestureDetector: banyak jenis gestur, TANPA efek visual
          GestureDetector(
            onTap: () => _tulisLog('GestureDetector: tap'),
            onDoubleTap: () {
              setState(() => _disukai = !_disukai);
              _tulisLog('GestureDetector: double tap -> suka = $_disukai');
            },
            onLongPress: () => _tulisLog('GestureDetector: long press'),
            child: Container(
              height: 120,
              decoration: BoxDecoration(
                color: Colors.amber.shade100,
                borderRadius: BorderRadius.circular(12),
              ),
              alignment: Alignment.center,
              child: Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  Icon(
                    _disukai ? Icons.favorite : Icons.favorite_border,
                    color: Colors.red,
                    size: 40,
                  ),
                  const Text('Tap, double tap, atau tekan lama'),
                ],
              ),
            ),
          ),
          const SizedBox(height: 16),

          // 2. GestureDetector untuk drag horizontal
          GestureDetector(
            onHorizontalDragUpdate: (details) {
              setState(() => _geserX = (_geserX + details.delta.dx).clamp(0, 200));
            },
            onHorizontalDragEnd: (_) => _tulisLog('Geser selesai di x = ${_geserX.toStringAsFixed(0)}'),
            child: Container(
              height: 60,
              color: Colors.grey.shade200,
              alignment: Alignment.centerLeft,
              child: Transform.translate(
                offset: Offset(_geserX, 0),
                child: const Chip(label: Text('Geser saya')),
              ),
            ),
          ),
          const SizedBox(height: 16),

          // 3. InkWell: efek riak Material saat ditekan
          Material(
            color: Colors.teal.shade50,
            borderRadius: BorderRadius.circular(12),
            child: InkWell(
              borderRadius: BorderRadius.circular(12),
              onTap: () => _tulisLog('InkWell: kartu Pemrograman Mobile ditekan'),
              onLongPress: () => _tulisLog('InkWell: long press'),
              child: const Padding(
                padding: EdgeInsets.all(20),
                child: Row(
                  children: [
                    Icon(Icons.phone_android, size: 36),
                    SizedBox(width: 16),
                    Expanded(
                      child: Text('Pemrograman Mobile\n4 SKS - Kelas A'),
                    ),
                    Icon(Icons.chevron_right),
                  ],
                ),
              ),
            ),
          ),
          const SizedBox(height: 16),

          // 4. Cara paling ringkas: Card + InkWell (Card sudah berupa Material)
          Card(
            clipBehavior: Clip.antiAlias, // agar riak tidak keluar dari sudut kartu
            child: InkWell(
              onTap: () => _tulisLog('InkWell di dalam Card ditekan'),
              child: const ListTile(
                leading: Icon(Icons.menu_book),
                title: Text('Basis Data'),
                subtitle: Text('3 SKS - Kelas B'),
              ),
            ),
          ),
        ],
      ),
    );
  }
}
Tampilan awal
Setelah kotak kuning diketuk: log berubah

Penjelasan kode:

  • Kotak kuning memakai GestureDetector dengan tiga callback. Double tap membalik nilai _disukai sehingga ikon hati berganti.
  • Chip "Geser saya" memakai onHorizontalDragUpdate. details.delta.dx adalah jarak geser jari sejak frame sebelumnya; nilainya dijumlahkan lalu dibatasi dengan clamp(0, 200).
  • Kartu Pemrograman Mobile memakai pola Material + InkWell. Nilai borderRadius diberikan ke keduanya agar riak ikut melengkung.
  • Kartu Basis Data memakai Card, yang sudah berupa Material. clipBehavior: Clip.antiAlias memotong riak agar tidak keluar dari sudut kartu.

💡 Tips

Untuk baris daftar, ListTile sudah punya onTap dan efek riak sendiri, jadi tidak perlu dibungkus InkWell. Untuk tombol, gunakan widget tombol bawaan. InkWell paling berguna untuk kartu atau tata letak kustom.

⚠️ Kesalahan umum

  • Riak InkWell tidak terlihat. Biasanya karena tidak ada Material di atasnya, atau anak InkWell adalah Container berwarna yang menutupi riak.
  • Area kosong di GestureDetector tidak bisa ditekan. Secara bawaan hanya bagian yang "terlihat" yang menerima sentuhan. Tambahkan behavior: HitTestBehavior.opaque jika seluruh area harus responsif.
  • Memasang GestureDetector di atas tombol. Tombol sudah menangani sentuhannya sendiri, sehingga kedua penangan bisa saling berebut.
