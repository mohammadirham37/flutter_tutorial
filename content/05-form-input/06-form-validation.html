Memeriksa setiap field satu per satu dengan if cepat menjadi berantakan. Flutter menyediakan Form, TextFormField, dan GlobalKey<FormState> untuk memvalidasi semua field sekaligus. Pola di section ini akan kita pakai lagi untuk layar login dan register pada Modul 13-14.

Konsep: empat bagian

  1. GlobalKey<FormState>: "kunci" untuk mengakses form dari luar, misalnya dari tombol Kirim.
  2. Form: pembungkus semua field.
  3. TextFormField: seperti TextField tetapi punya parameter validator.
  4. _formKey.currentState!.validate(): menjalankan semua validator. Hasilnya true jika semua valid.

Aturan validator: kembalikan null jika valid, atau kembalikan String berisi pesan error jika tidak valid. Pesan itu otomatis tampil merah di bawah field.

Contoh kecil

// 1. Kunci untuk mengakses FormState
final _formKey = GlobalKey<FormState>();

@override
Widget build(BuildContext context) {
  // 2. Bungkus semua field dengan Form
  return Form(
    key: _formKey,
    child: Column(
      children: [
        // 3. Pakai TextFormField (bukan TextField) agar punya validator
        TextFormField(
          decoration: const InputDecoration(labelText: 'Nama'),
          validator: (value) {
            if (value == null || value.trim().isEmpty) {
              return 'Nama wajib diisi'; // String = pesan error
            }
            return null; // null = valid
          },
        ),
        FilledButton(
          onPressed: () {
            // 4. Jalankan SEMUA validator sekaligus
            if (_formKey.currentState!.validate()) {
              debugPrint('Form valid, data boleh diproses');
            }
          },
          child: const Text('Kirim'),
        ),
      ],
    ),
  );
}

Mengumpulkan aturan dalam kelas Validators

Aturan yang sama (email, password) akan dipakai di banyak layar. Lebih rapi jika dikumpulkan dalam satu kelas berisi fungsi static. Pada proyek nyata, kelas ini bisa disimpan di lib/utils/validators.dart.

class Validators {
  // Pola email sederhana: teks@teks.domain
  static final _emailRegex = RegExp(r'^[\w.+-]+@[\w-]+(\.[\w-]+)+$');

  static String? wajib(String? value, String namaField) {
    if (value == null || value.trim().isEmpty) {
      return '$namaField wajib diisi';
    }
    return null;
  }

  static String? email(String? value) {
    if (value == null || value.trim().isEmpty) return 'Email wajib diisi';
    if (!_emailRegex.hasMatch(value.trim())) return 'Format email tidak valid';
    return null;
  }

  static String? password(String? value, {int minPanjang = 8}) {
    if (value == null || value.isEmpty) return 'Password wajib diisi';
    if (value.length < minPanjang) return 'Password minimal $minPanjang karakter';
    if (!RegExp(r'[0-9]').hasMatch(value)) return 'Password harus mengandung angka';
    return null;
  }

  static String? konfirmasi(String? value, String passwordAsli) {
    if (value == null || value.isEmpty) return 'Ulangi password';
    if (value != passwordAsli) return 'Konfirmasi password tidak sama';
    return null;
  }
}
  • RegExp(r'^[\w.+-]+@[\w-]+(\.[\w-]+)+$') berarti: satu atau lebih huruf/angka/titik/plus/strip, lalu @, lalu nama domain, lalu minimal satu bagian .xxx. Awalan r membuat string "mentah" sehingga \ tidak perlu ditulis dua kali.
  • konfirmasi menerima dua nilai: isian konfirmasi dan password asli. Keduanya dibandingkan dengan !=.

Contoh lengkap: form registrasi akun

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const RegisterScreen(),
    );
  }
}

// ===== Kumpulan validator (nanti bisa dipindah ke lib/utils/validators.dart) =====

  static String? wajib(String? value, String namaField) {
    if (value == null || value.trim().isEmpty) return '$namaField wajib diisi';
    return null;
  }

  static String? email(String? value) {
    if (value == null || value.trim().isEmpty) return 'Email wajib diisi';
    if (!_emailRegex.hasMatch(value.trim())) return 'Format email tidak valid';
    return null;
  }

  static String? password(String? value, {int minPanjang = 8}) {
    if (value == null || value.isEmpty) return 'Password wajib diisi';
    if (value.length < minPanjang) return 'Password minimal $minPanjang karakter';
    if (!RegExp(r'[0-9]').hasMatch(value)) return 'Password harus mengandung angka';
    return null;
  }

  static String? konfirmasi(String? value, String passwordAsli) {
    if (value == null || value.isEmpty) return 'Ulangi password';

// ===== Layar registrasi =====
class RegisterScreen extends StatefulWidget {
  const RegisterScreen({super.key});

  @override
  State<RegisterScreen> createState() => _RegisterScreenState();
}

class _RegisterScreenState extends State<RegisterScreen> {
  final _formKey = GlobalKey<FormState>();
  final _namaController = TextEditingController();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  final _konfirmasiController = TextEditingController();

  bool _sembunyikanPassword = true;
  bool _sedangMengirim = false;

  @override
  void dispose() {
    _namaController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _konfirmasiController.dispose();
    super.dispose();
  }

  Future<void> _daftar() async {
    // Tutup keyboard lalu validasi semua field
    FocusScope.of(context).unfocus();
    if (!_formKey.currentState!.validate()) return;

    setState(() => _sedangMengirim = true);
    // Simulasi mengirim data ke server selama 2 detik
    await Future.delayed(const Duration(seconds: 2));
    if (!mounted) return; // widget bisa saja sudah ditutup selama menunggu

    setState(() => _sedangMengirim = false);
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Akun ${_emailController.text.trim()} berhasil dibuat')),
    );
    _formKey.currentState!.reset(); // kosongkan error
    _namaController.clear();
    _emailController.clear();
    _passwordController.clear();
    _konfirmasiController.clear();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Registrasi Akun')),
      body: Form(
        key: _formKey,
        // Validasi ulang otomatis setelah pengguna mulai berinteraksi
        autovalidateMode: AutovalidateMode.onUserInteraction,
        child: ListView(
          padding: const EdgeInsets.all(24),
          children: [
            TextFormField(
              controller: _namaController,
              textInputAction: TextInputAction.next,
              textCapitalization: TextCapitalization.words,
              decoration: const InputDecoration(
                labelText: 'Nama Lengkap',
                prefixIcon: Icon(Icons.person_outline),
                border: OutlineInputBorder(),
              ),
              validator: (v) => Validators.wajib(v, 'Nama'),
            ),
            const SizedBox(height: 16),
            TextFormField(
              controller: _emailController,
              keyboardType: TextInputType.emailAddress,
              textInputAction: TextInputAction.next,
              decoration: const InputDecoration(
                labelText: 'Email',
                hintText: 'nama@mhs.unsoed.ac.id',
                prefixIcon: Icon(Icons.email_outlined),
                border: OutlineInputBorder(),
              ),
              validator: Validators.email,
            ),
            const SizedBox(height: 16),
            TextFormField(
              controller: _passwordController,
              obscureText: _sembunyikanPassword,
              textInputAction: TextInputAction.next,
              decoration: InputDecoration(
                labelText: 'Password',
                helperText: 'Minimal 8 karakter dan mengandung angka',
                prefixIcon: const Icon(Icons.lock_outline),
                border: const OutlineInputBorder(),
                suffixIcon: IconButton(
                  icon: Icon(_sembunyikanPassword ? Icons.visibility : Icons.visibility_off),
                  onPressed: () =>
                      setState(() => _sembunyikanPassword = !_sembunyikanPassword),
                ),
              ),
              validator: (v) => Validators.password(v),
            ),
            const SizedBox(height: 16),
            TextFormField(
              controller: _konfirmasiController,
              obscureText: _sembunyikanPassword,
              textInputAction: TextInputAction.done,
              onFieldSubmitted: (_) => _daftar(),
              decoration: const InputDecoration(
                labelText: 'Konfirmasi Password',
                prefixIcon: Icon(Icons.lock_reset),
                border: OutlineInputBorder(),
              ),
              // Bandingkan dengan isi controller password
              validator: (v) => Validators.konfirmasi(v, _passwordController.text),
            ),
            const SizedBox(height: 24),
            FilledButton(
              // null saat mengirim -> tombol disabled, cegah klik ganda
              onPressed: _sedangMengirim ? null : _daftar,
              style: FilledButton.styleFrom(minimumSize: const Size.fromHeight(50)),
              child: _sedangMengirim
                  ? const SizedBox(
                      width: 22,
                      height: 22,
                      child: CircularProgressIndicator(strokeWidth: 2),
                    )
                  : const Text('Daftar'),
            ),
          ],
        ),
      ),
    );
  }
}

Penjelasan kode:

  • validator: Validators.email bisa ditulis tanpa lambda karena tipe fungsinya sama persis dengan yang diminta (String? Function(String?)). Untuk fungsi dengan parameter tambahan, pakai lambda: (v) => Validators.wajib(v, 'Nama').
  • Validator konfirmasi membaca _passwordController.text, inilah alasan password perlu controller.
  • autovalidateMode: AutovalidateMode.onUserInteraction membuat pesan error diperbarui sambil mengetik, tetapi hanya setelah field pernah disentuh. Pengguna tidak langsung "dimarahi" saat layar baru dibuka.
  • Selama _sedangMengirim bernilai true, onPressed menjadi null (tombol nonaktif) dan isi tombol diganti CircularProgressIndicator. Ini mencegah data terkirim dua kali.
  • if (!mounted) return; setelah await memastikan layar masih ada sebelum memakai context atau setState.
  • _formKey.currentState!.reset() menghapus pesan error; controller dikosongkan dengan clear().

Contoh lengkap kedua: form KRS dengan Dropdown dan Checkbox

Contoh ini memperlihatkan bahwa DropdownButtonFormField juga punya validator dan ikut diperiksa oleh validate(). Checkbox tidak punya validator, sehingga diperiksa manual dengan if.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: Scaffold(
        appBar: AppBar(title: const Text("Formulir KRS Mahasiswa")),
        // PENTING: TextFormField, Checkbox & SnackBar butuh Scaffold/Material sebagai induk.
        // Jika FormKrsMahasiswa dipasang langsung sebagai home tanpa Scaffold, akan muncul
        // error "No Material widget found" (layar merah / kosong).
        body: const FormKrsMahasiswa(),
      ),
    );
  }
}


class FormKrsMahasiswa extends StatefulWidget {
  const FormKrsMahasiswa({super.key});

  @override
  State<FormKrsMahasiswa> createState() => _FormKrsMahasiswaState();
}

class _FormKrsMahasiswaState extends State<FormKrsMahasiswa> {
  // 1. Kunci Global untuk mengontrol dan memvalidasi FormState
  final _formKey = GlobalKey<FormState>();

  // 2. Controller untuk membaca teks dari input field
  final TextEditingController _nimController = TextEditingController();
  final TextEditingController _namaController = TextEditingController();

  String? _prodiTerpilih;
  bool _setujuSyarat = false;

  final List<String> _daftarProdi = [
    'Teknik Informatika',
    'Sistem Informasi',
    'Teknologi Rekayasa Perangkat Lunak',
    'Sains Data',
  ];

  // 3. WAJIB dispose controller agar tidak terjadi memory leak!
  @override
  void dispose() {
    _nimController.dispose();
    _namaController.dispose();
    super.dispose();
  }

  void _submitForm() {
    // Mengeksekusi seluruh fungsi validator pada setiap FormField di dalam Form
    if (_formKey.currentState!.validate()) {
      if (!_setujuSyarat) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text("Anda harus menyetujui syarat & ketentuan KRS!"),
            backgroundColor: Colors.red,
          ),
        );
        return;
      }

      // Jika lolos validasi, proses data
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text("Data Mahasiswa ${_namaController.text} (${_nimController.text}) Berhasil Diverifikasi!"),
          backgroundColor: Colors.green,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: ListView(
        padding: const EdgeInsets.all(20),
        children: [
          // Input NIM dengan Validasi Regex
          TextFormField(
            controller: _nimController,
            keyboardType: TextInputType.number,
            decoration: const InputDecoration(
              labelText: "Nomor Induk Mahasiswa (NIM)",
              hintText: "Contoh: 21102001",
              prefixIcon: Icon(Icons.badge),
              border: OutlineInputBorder(),
            ),
            validator: (value) {
              if (value == null || value.trim().isEmpty) {
                return "NIM wajib diisi!";
              }
              if (!RegExp(r'^[0-9]{8,}$').hasMatch(value.trim())) {
                return "NIM harus berupa angka minimal 8 digit!";
              }
              return null; // Nilai null berarti VALID
            },
          ),
          const SizedBox(height: 16),

          // Input Nama Lengkap
          TextFormField(
            controller: _namaController,
            decoration: const InputDecoration(
              labelText: "Nama Lengkap Mahasiswa",
              prefixIcon: Icon(Icons.person),
              border: OutlineInputBorder(),
            ),
            validator: (value) {
              if (value == null || value.trim().isEmpty) {
                return "Nama lengkap tidak boleh kosong!";
              }
              return null;
            },
          ),
          const SizedBox(height: 16),

          // Input Dropdown Pilihan Program Studi
          DropdownButtonFormField<String>(
            initialValue: _prodiTerpilih, // Flutter < 3.35: gunakan `value:`
            isExpanded: true, // Wajib agar nama prodi yang panjang tidak overflow di layar HP kecil
            decoration: const InputDecoration(
              labelText: "Program Studi",
              prefixIcon: Icon(Icons.school),
              border: OutlineInputBorder(),
            ),
            items: _daftarProdi.map((prodi) {
              return DropdownMenuItem(value: prodi, child: Text(prodi));
            }).toList(),
            onChanged: (val) => setState(() => _prodiTerpilih = val),
            validator: (val) => val == null ? "Silakan pilih program studi!" : null,
          ),
          const SizedBox(height: 16),

          // Checkbox Persetujuan
          CheckboxListTile(
            title: const Text("Saya menyatakan data rencana studi ini sudah benar."),
            value: _setujuSyarat,
            onChanged: (val) => setState(() => _setujuSyarat = val ?? false),
            controlAffinity: ListTileControlAffinity.leading,
          ),
          const SizedBox(height: 24),

          // Tombol Submit
          FilledButton.icon(
            onPressed: _submitForm,
            icon: const Icon(Icons.check_circle),
            label: const Text("Simpan Data KRS", style: TextStyle(fontSize: 16)),
            style: FilledButton.styleFrom(padding: const EdgeInsets.symmetric(vertical: 14)),
          ),
        ],
      ),
    );
  }
}
Form KRS setelah tombol Simpan ditekan tanpa isian

ℹ️ onSaved dan save()

Selain validator, TextFormField punya onSaved yang dipanggil oleh _formKey.currentState!.save(). Ini alternatif dari controller: setiap field menyimpan nilainya ke variabel saat save() dipanggil. Pada modul ini kita memakai controller karena lebih mudah dibaca dan bisa dipakai untuk mengosongkan field.

⚠️ Kesalahan umum

  • Validator mengembalikan "" (string kosong) untuk input valid. String kosong tetap dianggap error. Yang benar return null;.
  • Memakai TextField di dalam Form. TextField tidak punya validator. Gunakan TextFormField.
  • Membuat GlobalKey di dalam build. Key baru di setiap build membuat form kehilangan state. Jadikan field di State.
  • Lupa trim(). Isian berupa spasi saja akan lolos pemeriksaan isEmpty.
  • Error "No Material widget found". Form harus berada di dalam Scaffold.
