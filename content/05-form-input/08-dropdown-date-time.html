Untuk pilihan yang banyak (program studi, dosen) dan untuk tanggal/jam, pengguna sebaiknya memilih, bukan mengetik. Bagian ini membahas DropdownButtonFormField, showDatePicker, dan showTimePicker.

1. DropdownButtonFormField

Versi ...FormField dipilih karena bisa memakai InputDecoration dan validator seperti TextFormField.

final List<String> _daftarSemester = ['Ganjil 2025/2026', 'Genap 2025/2026'];
String? _semester; // null = belum memilih

@override
Widget build(BuildContext context) {
  return DropdownButtonFormField<String>(
    initialValue: _semester, // nilai awal (Flutter < 3.35: pakai `value:`)
    hint: const Text('Pilih semester'),
    decoration: const InputDecoration(
      labelText: 'Semester',
      border: OutlineInputBorder(),
    ),
    items: _daftarSemester
        .map((s) => DropdownMenuItem(value: s, child: Text(s)))
        .toList(),
    onChanged: (baru) => setState(() => _semester = baru),
    validator: (v) => v == null ? 'Semester wajib dipilih' : null,
  );
}
Dropdown sebelum dipilih
Daftar pilihan setelah dropdown diketuk
  • items adalah daftar DropdownMenuItem. Setiap item punya value (nilai yang disimpan) dan child (yang ditampilkan).
  • .map(...).toList() mengubah List<String> menjadi List<DropdownMenuItem>.
  • Nilai awal ditulis di initialValue. Pada Flutter sebelum 3.35 namanya value.

2. showDatePicker dan showTimePicker

Keduanya adalah fungsi async yang membuka dialog dan mengembalikan nilai pilihan setelah dialog ditutup, atau null jika pengguna menekan Batal.

DateTime? _tanggal;
TimeOfDay? _jam;

Future<void> _pilihTanggal() async {
  final hasil = await showDatePicker(
    context: context,
    initialDate: _tanggal ?? DateTime.now(),
    firstDate: DateTime(2020),
    lastDate: DateTime(2030),
    helpText: 'Pilih tanggal seminar',
  );
  // hasil == null jika pengguna menekan Batal
  if (hasil != null) setState(() => _tanggal = hasil);
}

Future<void> _pilihJam() async {
  final hasil = await showTimePicker(
    context: context,
    initialTime: _jam ?? const TimeOfDay(hour: 9, minute: 0),
  );
  if (hasil != null) setState(() => _jam = hasil);
}

TimeOfDay hanya berisi jam dan menit (tanpa tanggal). DateTime berisi tanggal lengkap. firstDate dan lastDate membatasi tanggal yang bisa dipilih.

Contoh lengkap: form pengajuan jadwal bimbingan

Trik yang sering dipakai: tanggal dan jam ditampilkan di TextFormField dengan readOnly: true. Field tidak bisa diketik, tetapi tetap bisa memakai validator, dan onTap membuka picker.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const JadwalBimbinganScreen(),
    );
  }
}

class JadwalBimbinganScreen extends StatefulWidget {
  const JadwalBimbinganScreen({super.key});

  @override
  State<JadwalBimbinganScreen> createState() => _JadwalBimbinganScreenState();
}

class _JadwalBimbinganScreenState extends State<JadwalBimbinganScreen> {
  final _formKey = GlobalKey<FormState>();
  final _tanggalController = TextEditingController();
  final _jamController = TextEditingController();

  final List<String> _daftarDosen = [
    'Dr. Bambang Susilo, M.Kom.',
    'Nadia Fitri, M.T.',
    'Irham Akbar, M.Cs.',
  ];
  String? _dosen;
  DateTime? _tanggal;
  TimeOfDay? _jam;

  static const _namaBulan = [
    'Jan', 'Feb', 'Mar', 'Apr', 'Mei', 'Jun',
    'Jul', 'Agu', 'Sep', 'Okt', 'Nov', 'Des',
  ];

  String _formatTanggal(DateTime t) => '${t.day} ${_namaBulan[t.month - 1]} ${t.year}';

  String _formatJam(TimeOfDay j) =>
      '${j.hour.toString().padLeft(2, '0')}:${j.minute.toString().padLeft(2, '0')}';

  @override
  void dispose() {
    _tanggalController.dispose();
    _jamController.dispose();
    super.dispose();
  }

  Future<void> _pilihTanggal() async {
    final sekarang = DateTime.now();
    final hasil = await showDatePicker(
      context: context,
      initialDate: _tanggal ?? sekarang,
      firstDate: sekarang, // tidak boleh memilih tanggal yang sudah lewat
      lastDate: sekarang.add(const Duration(days: 60)),
      // Hari Sabtu dan Minggu tidak bisa dipilih
      selectableDayPredicate: (hari) =>
          hari.weekday != DateTime.saturday && hari.weekday != DateTime.sunday,
    );
    if (hasil == null) return;
    setState(() {
      _tanggal = hasil;
      _tanggalController.text = _formatTanggal(hasil);
    });
  }

  Future<void> _pilihJam() async {
    final hasil = await showTimePicker(
      context: context,
      initialTime: _jam ?? const TimeOfDay(hour: 9, minute: 0),
    );
    if (hasil == null) return;
    setState(() {
      _jam = hasil;
      _jamController.text = _formatJam(hasil);
    });
  }

  void _simpan() {
    if (!_formKey.currentState!.validate()) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text(
          'Bimbingan dengan $_dosen pada ${_formatTanggal(_tanggal!)} '
          'pukul ${_formatJam(_jam!)}',
        ),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Jadwal Bimbingan')),
      body: Form(
        key: _formKey,
        child: ListView(
          padding: const EdgeInsets.all(24),
          children: [
            DropdownButtonFormField<String>(
              initialValue: _dosen,
              isExpanded: true,
              decoration: const InputDecoration(
                labelText: 'Dosen Pembimbing',
                prefixIcon: Icon(Icons.person_search),
                border: OutlineInputBorder(),
              ),
              items: _daftarDosen
                  .map((d) => DropdownMenuItem(value: d, child: Text(d)))
                  .toList(),
              onChanged: (baru) => setState(() => _dosen = baru),
              validator: (v) => v == null ? 'Pilih dosen pembimbing' : null,
            ),
            const SizedBox(height: 16),

            // TextFormField readOnly: tidak bisa diketik, tapi bisa divalidasi
            TextFormField(
              controller: _tanggalController,
              readOnly: true,
              onTap: _pilihTanggal,
              decoration: const InputDecoration(
                labelText: 'Tanggal',
                prefixIcon: Icon(Icons.calendar_month),
                border: OutlineInputBorder(),
              ),
              validator: (v) => (v == null || v.isEmpty) ? 'Pilih tanggal' : null,
            ),
            const SizedBox(height: 16),

            TextFormField(
              controller: _jamController,
              readOnly: true,
              onTap: _pilihJam,
              decoration: const InputDecoration(
                labelText: 'Jam',
                prefixIcon: Icon(Icons.access_time),
                border: OutlineInputBorder(),
              ),
              validator: (v) {
                if (_jam == null) return 'Pilih jam';
                if (_jam!.hour < 8 || _jam!.hour >= 16) {
                  return 'Bimbingan hanya pukul 08:00 - 16:00';
                }
                return null;
              },
            ),
            const SizedBox(height: 24),
            FilledButton.icon(
              onPressed: _simpan,
              icon: const Icon(Icons.event_available),
              label: const Text('Ajukan Jadwal'),
            ),
          ],
        ),
      ),
    );
  }
}
Ajukan Jadwal ditekan saat form kosong
Dialog DatePicker terbuka saat field Tanggal diketuk
Dialog TimePicker terbuka saat field Jam diketuk

Penjelasan kode:

  • firstDate: sekarang membuat tanggal yang sudah lewat tidak bisa dipilih. lastDate dibatasi 60 hari ke depan.
  • selectableDayPredicate menerima fungsi yang mengembalikan false untuk hari yang tidak boleh dipilih (Sabtu dan Minggu).
  • Setelah tanggal dipilih, teksnya ditulis ke _tanggalController sehingga tampil di field dan lolos validator.
  • Validator jam memeriksa jam kerja (08:00-16:00). Validator tidak harus membaca v, bisa juga membaca variabel State seperti _jam.
  • _formatTanggal dan _formatJam memformat secara manual. Untuk format yang lebih lengkap (nama hari, bahasa lain), kelak bisa memakai package intl.

⚠️ Kesalahan umum

  • Error "There should be exactly one item with value ..." pada dropdown. Terjadi jika nilai terpilih tidak ada di items atau ada dua item dengan value sama.
  • Teks dropdown panjang overflow. Tambahkan isExpanded: true.
  • initialDate di luar rentang firstDate-lastDate. Menyebabkan error. Pastikan nilai awal berada dalam rentang.
  • Tidak memeriksa null. Hasil picker bernilai null jika pengguna membatalkan.
