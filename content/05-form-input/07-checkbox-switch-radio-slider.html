Tidak semua input berupa ketikan. Untuk pilihan ya/tidak, satu dari beberapa opsi, atau nilai dalam rentang, Flutter menyediakan Checkbox, Switch, Radio, dan Slider. Semuanya bekerja dengan pola yang sama: nilai disimpan di State, ditampilkan lewat value, dan diubah lewat onChanged + setState.

WidgetTipe nilaiKapan dipakai
Checkbox / CheckboxListTileboolPersetujuan, boleh memilih banyak opsi
Switch / SwitchListTileboolPengaturan on/off yang langsung berlaku
RadioGroup + RadioListTileSatu nilai (sering enum)Pilih tepat satu dari beberapa opsi
Slider / RangeSliderdouble / RangeValuesNilai atau rentang angka

1. Checkbox dan Switch

Versi ...ListTile sudah termasuk judul, dan seluruh barisnya bisa diketuk. Hampir selalu lebih nyaman dipakai daripada versi polos.

bool _setuju = false;
bool _notifikasi = true;

@override
Widget build(BuildContext context) {
  return Column(
    children: [
      // Checkbox polos: hanya kotaknya saja
      Checkbox(
        value: _setuju,
        onChanged: (baru) => setState(() => _setuju = baru ?? false),
      ),

      // CheckboxListTile: kotak + judul, seluruh baris bisa diketuk
      CheckboxListTile(
        title: const Text('Saya menyetujui tata tertib'),
        value: _setuju,
        onChanged: (baru) => setState(() => _setuju = baru ?? false),
      ),

      // SwitchListTile: saklar on/off + judul
      SwitchListTile(
        title: const Text('Notifikasi jadwal kuliah'),
        subtitle: const Text('Ingatkan 15 menit sebelum kelas'),
        value: _notifikasi,
        onChanged: (baru) => setState(() => _notifikasi = baru),
      ),
    ],
  );
}
Checkbox polos, CheckboxListTile, dan SwitchListTile

Parameter onChanged Checkbox menerima bool? (bisa null untuk mode tiga keadaan), sehingga kita menulis baru ?? false. Switch menerima bool biasa.

2. Radio dengan RadioGroup

Sejak Flutter 3.35, nilai terpilih tidak lagi ditulis di setiap Radio (groupValue dan onChanged di Radio sudah deprecated). Sekarang semua radio dibungkus satu RadioGroup yang memegang groupValue dan onChanged, dan setiap radio cukup diberi value.

enum Kelas { pagi, siang, malam }

class _ContohState extends State<Contoh> {
  Kelas? _kelas = Kelas.pagi;

  @override
  Widget build(BuildContext context) {
    // RadioGroup menyimpan nilai terpilih untuk SEMUA radio di dalamnya
    return RadioGroup<Kelas>(
      groupValue: _kelas,
      onChanged: (baru) => setState(() => _kelas = baru),
      child: const Column(
        children: [
          // Tiap radio cukup diberi value-nya masing-masing
          RadioListTile<Kelas>(value: Kelas.pagi, title: Text('Kelas Pagi')),
          RadioListTile<Kelas>(value: Kelas.siang, title: Text('Kelas Siang')),
          RadioListTile<Kelas>(value: Kelas.malam, title: Text('Kelas Malam')),
        ],
      ),
    );
  }
}
RadioGroup dengan tiga pilihan kelas

ℹ️ Kenapa memakai enum?

Dengan enum Kelas { pagi, siang, malam }, salah ketik seperti 'Pagi' vs 'pagi' tidak mungkin terjadi, karena compiler langsung memberi tahu jika nilai tidak dikenal. Nama enum bisa ditampilkan dengan kelas.name.

3. Slider

double _sks = 20;

@override
Widget build(BuildContext context) {
  return Column(
    children: [
      Text('Rencana SKS: ${_sks.round()}'),
      Slider(
        value: _sks,
        min: 12,
        max: 24,
        divisions: 12, // 12 langkah -> nilainya bulat 12, 13, ..., 24
        label: '${_sks.round()} SKS', // gelembung saat digeser
        onChanged: (baru) => setState(() => _sks = baru),
      ),
    ],
  );
}
Slider rencana SKS

Tanpa divisions, nilai Slider berupa pecahan (misalnya 17.3826). Dengan divisions, nilai melompat per langkah, dan label menampilkan gelembung nilai saat digeser.

Contoh lengkap: halaman preferensi belajar

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepPurple),
      home: const PreferensiScreen(),
    );
  }
}

enum ModeBelajar { luring, daring, hybrid }

class PreferensiScreen extends StatefulWidget {
  const PreferensiScreen({super.key});

  @override
  State<PreferensiScreen> createState() => _PreferensiScreenState();
}

class _PreferensiScreenState extends State<PreferensiScreen> {
  // Checkbox: boleh memilih lebih dari satu
  final Map<String, bool> _minat = {
    'Mobile Development': true,
    'Web Development': false,
    'Data Science': false,
    'Jaringan Komputer': false,
  };

  // Switch: on/off
  bool _notifikasi = true;
  bool _modeGelap = false;

  // Radio: hanya satu pilihan
  ModeBelajar _mode = ModeBelajar.luring;

  // Slider: nilai dalam rentang
  double _targetIpk = 3.5;
  RangeValues _jamBelajar = const RangeValues(19, 22);

  String get _ringkasan {
    final minatDipilih =
        _minat.entries.where((e) => e.value).map((e) => e.key).join(', ');
    return 'Minat: ${minatDipilih.isEmpty ? '-' : minatDipilih}\n'
        'Notifikasi: ${_notifikasi ? 'aktif' : 'mati'}, '
        'Mode gelap: ${_modeGelap ? 'ya' : 'tidak'}\n'
        'Mode belajar: ${_mode.name}\n'
        'Target IPK: ${_targetIpk.toStringAsFixed(2)}\n'
        'Jam belajar: ${_jamBelajar.start.round()}.00 - ${_jamBelajar.end.round()}.00';
  }

  @override
  Widget build(BuildContext context) {
    final judul = Theme.of(context).textTheme.titleMedium;

    return Scaffold(
      appBar: AppBar(title: const Text('Preferensi Belajar')),
      body: ListView(
        padding: const EdgeInsets.symmetric(vertical: 8),
        children: [
          Padding(
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 0),
            child: Text('Bidang minat (boleh lebih dari satu)', style: judul),
          ),
          for (final nama in _minat.keys)
            CheckboxListTile(
              title: Text(nama),
              value: _minat[nama],
              onChanged: (baru) => setState(() => _minat[nama] = baru ?? false),
            ),
          const Divider(),

          SwitchListTile(
            secondary: const Icon(Icons.notifications_active_outlined),
            title: const Text('Notifikasi tugas'),
            value: _notifikasi,
            onChanged: (baru) => setState(() => _notifikasi = baru),
          ),
          SwitchListTile(
            secondary: const Icon(Icons.dark_mode_outlined),
            title: const Text('Mode gelap'),
            value: _modeGelap,
            onChanged: (baru) => setState(() => _modeGelap = baru),
          ),
          const Divider(),

          Padding(
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 0),
            child: Text('Mode belajar (pilih satu)', style: judul),
          ),
          RadioGroup<ModeBelajar>(
            groupValue: _mode,
            onChanged: (baru) {
              if (baru != null) setState(() => _mode = baru);
            },
            child: const Column(
              children: [
                RadioListTile(value: ModeBelajar.luring, title: Text('Luring (tatap muka)')),
                RadioListTile(value: ModeBelajar.daring, title: Text('Daring (online)')),
                RadioListTile(value: ModeBelajar.hybrid, title: Text('Hybrid')),
              ],
            ),
          ),
          const Divider(),

          Padding(
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 0),
            child: Text('Target IPK: ${_targetIpk.toStringAsFixed(2)}', style: judul),
          ),
          Slider(
            value: _targetIpk,
            min: 2.0,
            max: 4.0,
            divisions: 40, // langkah 0.05
            label: _targetIpk.toStringAsFixed(2),
            onChanged: (baru) => setState(() => _targetIpk = baru),
          ),
          Padding(
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 0),
            child: Text(
              'Jam belajar: ${_jamBelajar.start.round()}.00 - ${_jamBelajar.end.round()}.00',
              style: judul,
            ),
          ),
          // RangeSlider: memilih rentang (dua titik)
          RangeSlider(
            values: _jamBelajar,
            min: 0,
            max: 24,
            divisions: 24,
            labels: RangeLabels(
              '${_jamBelajar.start.round()}.00',
              '${_jamBelajar.end.round()}.00',
            ),
            onChanged: (baru) => setState(() => _jamBelajar = baru),
          ),
          const Divider(),

          Card(
            margin: const EdgeInsets.all(16),
            child: Padding(
              padding: const EdgeInsets.all(16),
              child: Text(_ringkasan),
            ),
          ),
        ],
      ),
    );
  }
}
Bagian atas: daftar Checkbox dan Switch
Setelah digulir: Radio, Slider, RangeSlider, dan ringkasan

Penjelasan kode:

  • Map<String, bool> _minat menyimpan status setiap checkbox. for (final nama in _minat.keys) di dalam children membuat satu CheckboxListTile per minat.
  • RadioGroup<ModeBelajar> membungkus Column berisi tiga RadioListTile. Karena RadioListTile di dalamnya tidak berubah, Column bisa const.
  • divisions: 40 pada rentang 2.0-4.0 menghasilkan langkah 0.05.
  • RangeSlider memakai RangeValues(start, end) untuk dua titik sekaligus.
  • Getter _ringkasan menyusun semua nilai menjadi teks. Karena dihitung ulang setiap build, ringkasan selalu sesuai pilihan terbaru.

⚠️ Kesalahan umum

  • Lupa setState di onChanged. Nilai variabel berubah tetapi tampilan tidak; checkbox terlihat "macet".
  • Menulis Radio(groupValue: ..., onChanged: ...). Cara lama ini menghasilkan peringatan deprecated. Gunakan RadioGroup.
  • Nilai awal Slider di luar min-max. Menyebabkan error assertion. Pastikan min <= value <= max.
  • Menyimpan nilai di variabel lokal dalam build. Nilai akan kembali ke awal di setiap build. Simpan sebagai field State.
