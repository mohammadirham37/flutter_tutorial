TextField adalah kotak tempat pengguna mengetik teks. Tampilannya (label, ikon, garis tepi, pesan error) diatur oleh satu objek bernama InputDecoration.

Konsep

  • TextField mengurus perilaku: menerima ketikan, menampilkan kursor, membuka keyboard.
  • InputDecoration mengurus tampilan: labelText, hintText, prefixIcon, suffixIcon, helperText, errorText, border, dan lain-lain.
  • Untuk membaca isi teks, cara paling sederhana adalah onChanged: fungsi yang dipanggil setiap kali isi berubah. Cara yang lebih lengkap (controller) dibahas di section berikutnya.

Contoh kecil

// Versi paling sederhana
const TextField(),

// Dengan label, petunjuk, dan ikon
TextField(
  decoration: const InputDecoration(
    labelText: 'Nama Lengkap',        // label yang naik ke atas saat fokus
    hintText: 'Contoh: Nadia Putri',  // teks samar saat kosong
    prefixIcon: Icon(Icons.person),   // ikon di kiri
    border: OutlineInputBorder(),     // kotak bergaris
  ),
  onChanged: (teks) => debugPrint('Diketik: $teks'),
),
TextField polos (atas) dan TextField dengan label, hint, ikon, serta kotak garis
Properti InputDecorationFungsi
labelTextLabel di dalam kotak, naik ke atas saat field fokus atau berisi
hintTextContoh isian yang tampil samar saat kosong
helperTextTeks bantuan kecil di bawah field
errorTextPesan error merah di bawah field (garis ikut merah)
prefixIcon / suffixIconIkon di kiri / kanan
prefixText / suffixTextTeks tetap di kiri / kanan, misalnya "Rp" atau "kg"
borderUnderlineInputBorder() (bawaan) atau OutlineInputBorder()
filled + fillColorMemberi warna latar pada field

Contoh lengkap: katalog gaya TextField

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const KatalogTextFieldScreen(),
    );
  }
}

class KatalogTextFieldScreen extends StatefulWidget {
  const KatalogTextFieldScreen({super.key});

  @override
  State<KatalogTextFieldScreen> createState() => _KatalogTextFieldScreenState();
}

class _KatalogTextFieldScreenState extends State<KatalogTextFieldScreen> {
  String _nama = '';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Katalog TextField')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // 1. Gaya garis bawah (bawaan)
          const TextField(
            decoration: InputDecoration(labelText: '1. Gaya bawaan (garis bawah)'),
          ),
          const SizedBox(height: 16),

          // 2. Gaya kotak + onChanged untuk membaca teks secara langsung
          TextField(
            decoration: const InputDecoration(
              labelText: '2. Nama Panggilan',
              hintText: 'Ketik nama panggilanmu',
              border: OutlineInputBorder(),
            ),
            onChanged: (value) => setState(() => _nama = value),
          ),
          Padding(
            padding: const EdgeInsets.only(top: 4, left: 12),
            child: Text('Halo, ${_nama.isEmpty ? '...' : _nama}!'),
          ),
          const SizedBox(height: 16),

          // 3. Latar terisi (filled) + ikon depan dan belakang
          const TextField(
            decoration: InputDecoration(
              labelText: '3. Email Kampus',
              prefixIcon: Icon(Icons.email_outlined),
              suffixIcon: Icon(Icons.check_circle_outline),
              filled: true,
            ),
          ),
          const SizedBox(height: 16),

          // 4. Teks bantuan + batas karakter (counter otomatis muncul)
          const TextField(
            maxLength: 12,
            decoration: InputDecoration(
              labelText: '4. NIM',
              helperText: 'Lihat di Kartu Tanda Mahasiswa',
              prefixText: 'H1D',
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 16),

          // 5. Multi-baris untuk teks panjang
          const TextField(
            minLines: 3,
            maxLines: 5,
            decoration: InputDecoration(
              labelText: '5. Alamat Kos',
              alignLabelWithHint: true,
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 16),

          // 6. Tampilan error manual (tanpa Form)
          const TextField(
            decoration: InputDecoration(
              labelText: '6. Contoh Error',
              errorText: 'Field ini wajib diisi',
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 16),

          // 7. Nonaktif dan hanya-baca
          const TextField(
            enabled: false,
            decoration: InputDecoration(
              labelText: '7. Fakultas (tidak bisa diubah)',
              hintText: 'Fakultas Teknik',
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 16),

          // 8. Sudut membulat + warna garis saat fokus
          TextField(
            decoration: InputDecoration(
              labelText: '8. Cari mata kuliah',
              prefixIcon: const Icon(Icons.search),
              border: OutlineInputBorder(borderRadius: BorderRadius.circular(30)),
              focusedBorder: OutlineInputBorder(
                borderRadius: BorderRadius.circular(30),
                borderSide: const BorderSide(color: Colors.orange, width: 2),
              ),
            ),
          ),
        ],
      ),
    );
  }
}
Bagian atas katalog TextField
Setelah mengetik "Budi" di field nomor 2

Penjelasan kode:

  • Field 2 memakai onChanged untuk menyimpan teks ke _nama lalu memanggil setState, sehingga sapaan di bawahnya ikut berubah setiap huruf diketik.
  • Field 4 memakai maxLength: 12. Flutter otomatis menampilkan penghitung "0/12" dan menolak huruf ke-13.
  • Field 5 memakai minLines dan maxLines sehingga kotak setinggi 3 baris dan bisa membesar sampai 5 baris. alignLabelWithHint: true membuat label sejajar di atas, bukan di tengah.
  • Field 6 menampilkan error secara manual dengan errorText. Pada form sungguhan, error lebih mudah diatur dengan Form dan validator (section 6).
  • Field 8 membedakan garis saat normal (border) dan saat fokus (focusedBorder).

💡 Tema global

Agar semua TextField di aplikasi otomatis memakai kotak garis, atur sekali di tema: ThemeData(inputDecorationTheme: const InputDecorationThemeData(border: OutlineInputBorder())). Dengan begitu kita tidak perlu menulis border: di setiap field.

⚠️ Kesalahan umum

  • Error "InputDecorator ... unbounded width". Terjadi saat TextField diletakkan langsung di dalam Row. Bungkus dengan Expanded atau beri lebar dengan SizedBox.
  • Error "No Material widget found". TextField harus berada di bawah Scaffold atau Material.
  • Keyboard menutupi field di bagian bawah layar. Pakai ListView atau SingleChildScrollView sebagai pembungkus agar halaman bisa digulir.
