Tombol adalah cara paling dasar pengguna "berbicara" dengan aplikasi. Material Design 3 (M3) menyediakan beberapa jenis tombol dengan hierarki yang jelas: aksi paling penting dibuat paling menonjol, aksi pendukung dibuat lebih kalem.

Konsep: memilih tombol sesuai tingkat kepentingan

WidgetKapan dipakaiContoh di aplikasi kampus
FilledButtonAksi utama, paling menonjol. Idealnya satu per layar.Simpan KRS, Kirim, Masuk
FilledButton.tonalAksi penting tapi bukan yang utama.Simpan sebagai draft
ElevatedButtonTombol berbayang, dipakai jika latar belakang ramai sehingga tombol perlu "terangkat".Lihat KHS di atas gambar
OutlinedButtonAksi sekunder, sering berpasangan dengan FilledButton.Batal, Kembali
TextButtonAksi prioritas rendah, tampil seperti tautan.Lupa password?, Lihat semua
IconButtonAksi berupa ikon saja, di AppBar, kartu, atau baris daftar.Hapus, Favorit, Bagikan
FloatingActionButton (FAB)Aksi utama sebuah layar yang "melayang" di pojok kanan bawah.Tambah catatan, Isi KRS

Contoh kecil: tombol aktif dan tombol nonaktif

Semua tombol di atas punya dua parameter utama: onPressed (fungsi yang dijalankan saat ditekan) dan child (isi tombol, biasanya Text). Aturan pentingnya: jika onPressed bernilai null, tombol otomatis menjadi nonaktif (disabled), warnanya memudar dan tidak bisa ditekan.

// Tombol AKTIF: onPressed berisi fungsi
FilledButton(
  onPressed: () {
    debugPrint('Tombol Simpan ditekan');
  },
  child: const Text('Simpan'),
),

// Tombol NONAKTIF (disabled): onPressed bernilai null
const FilledButton(
  onPressed: null,
  child: Text('Simpan'),
),
Atas: tombol aktif. Bawah: tombol dengan onPressed null (disabled)

Contoh lengkap: galeri tombol Material 3

Program berikut menampilkan semua jenis tombol, menghitung jumlah klik, dan punya satu tombol untuk menonaktifkan semua tombol lain sekaligus. Salin ke lib/main.dart lalu jalankan.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const GaleriTombolScreen(),
    );
  }
}

class GaleriTombolScreen extends StatefulWidget {
  const GaleriTombolScreen({super.key});

  @override
  State<GaleriTombolScreen> createState() => _GaleriTombolScreenState();
}

class _GaleriTombolScreenState extends State<GaleriTombolScreen> {
  int _jumlahKlik = 0;
  bool _tombolAktif = true;
  String _aksiTerakhir = '-';

  void _catat(String aksi) {
    setState(() {
      _jumlahKlik++;
      _aksiTerakhir = aksi;
    });
  }

  @override
  Widget build(BuildContext context) {
    // Jika _tombolAktif false, semua callback menjadi null -> tombol disabled
    final VoidCallback? aksiSimpan = _tombolAktif ? () => _catat('Simpan') : null;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Galeri Tombol M3'),
        actions: [
          IconButton(
            tooltip: 'Reset',
            icon: const Icon(Icons.refresh),
            onPressed: () => setState(() {
              _jumlahKlik = 0;
              _aksiTerakhir = '-';
            }),
          ),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(20),
        children: [
          Text('Jumlah klik: $_jumlahKlik', style: Theme.of(context).textTheme.headlineSmall),
          Text('Aksi terakhir: $_aksiTerakhir'),
          const Divider(height: 32),

          // 1. Prioritas tertinggi
          FilledButton(onPressed: aksiSimpan, child: const Text('FilledButton - Simpan')),
          const SizedBox(height: 8),
          FilledButton.tonal(
            onPressed: _tombolAktif ? () => _catat('Tonal') : null,
            child: const Text('FilledButton.tonal - Draft'),
          ),
          const SizedBox(height: 8),

          // 2. Tombol dengan bayangan (elevasi)
          ElevatedButton(
            onPressed: _tombolAktif ? () => _catat('Elevated') : null,
            child: const Text('ElevatedButton - Lihat KHS'),
          ),
          const SizedBox(height: 8),

          // 3. Aksi sekunder
          OutlinedButton(
            onPressed: _tombolAktif ? () => _catat('Batal') : null,
            child: const Text('OutlinedButton - Batal'),
          ),
          const SizedBox(height: 8),

          // 4. Aksi prioritas rendah
          TextButton(
            onPressed: _tombolAktif ? () => _catat('Lupa Password') : null,
            child: const Text('TextButton - Lupa Password?'),
          ),
          const SizedBox(height: 8),

          // 5. Versi .icon: ikon + label
          FilledButton.icon(
            onPressed: _tombolAktif ? () => _catat('Unduh') : null,
            icon: const Icon(Icons.download),
            label: const Text('Unduh Transkrip'),
          ),
          const SizedBox(height: 16),

          // 6. IconButton dan variannya
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceEvenly,
            children: [
              IconButton(
                tooltip: 'Favorit',
                onPressed: _tombolAktif ? () => _catat('Favorit') : null,
                icon: const Icon(Icons.favorite_border),
              ),
              IconButton.filled(
                tooltip: 'Tambah',
                onPressed: _tombolAktif ? () => _catat('Tambah') : null,
                icon: const Icon(Icons.add),
              ),
              IconButton.filledTonal(
                tooltip: 'Bagikan',
                onPressed: _tombolAktif ? () => _catat('Bagikan') : null,
                icon: const Icon(Icons.share),
              ),
              IconButton.outlined(
                tooltip: 'Hapus',
                onPressed: _tombolAktif ? () => _catat('Hapus') : null,
                icon: const Icon(Icons.delete_outline),
              ),
            ],
          ),
          const Divider(height: 32),

          // Saklar untuk mengaktifkan / menonaktifkan semua tombol
          OutlinedButton.icon(
            onPressed: () => setState(() => _tombolAktif = !_tombolAktif),
            icon: Icon(_tombolAktif ? Icons.lock_open : Icons.lock),
            label: Text(_tombolAktif ? 'Nonaktifkan semua tombol' : 'Aktifkan semua tombol'),
          ),
          const SizedBox(height: 80), // ruang agar FAB tidak menutupi tombol terakhir
        ],
      ),
      // 7. FloatingActionButton: aksi utama layar
      floatingActionButton: FloatingActionButton.extended(
        onPressed: () => _catat('FAB'),
        icon: const Icon(Icons.edit),
        label: const Text('Isi KRS'),
      ),
    );
  }
}
Galeri tombol saat semua tombol aktif
Setelah menekan "Nonaktifkan semua tombol"

Penjelasan kode:

  • final VoidCallback? aksiSimpan = _tombolAktif ? () => _catat('Simpan') : null; adalah pola paling umum untuk mengaktifkan atau menonaktifkan tombol berdasarkan kondisi. VoidCallback? berarti "fungsi tanpa parameter, boleh null".
  • FilledButton.icon, OutlinedButton.icon, dan sejenisnya menerima icon dan label sebagai pengganti child.
  • IconButton.filled, .filledTonal, dan .outlined adalah varian IconButton khas M3. Selalu isi tooltip agar pembaca layar (aksesibilitas) tahu fungsi ikon tersebut.
  • FloatingActionButton.extended adalah FAB dengan ikon dan teks. Karena FAB menutupi sebagian konten, kita beri SizedBox(height: 80) di akhir daftar.

Mengubah gaya tombol

Setiap jenis tombol punya fungsi statis styleFrom() untuk mengubah warna, ukuran, dan bentuk. Untuk tombol selebar layar, cara paling mudah adalah minimumSize: Size.fromHeight(...) atau membungkus tombol dengan SizedBox(width: double.infinity).

// Mengubah gaya satu tombol dengan styleFrom
FilledButton(
  style: FilledButton.styleFrom(
    backgroundColor: Colors.red,          // warna latar
    foregroundColor: Colors.white,        // warna teks & ikon
    minimumSize: const Size.fromHeight(52), // tinggi 52, lebar penuh
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(12),
    ),
    textStyle: const TextStyle(fontSize: 16, fontWeight: FontWeight.bold),
  ),
  onPressed: () {},
  child: const Text('Hapus Akun'),
),

// Tombol selebar layar tanpa styleFrom: bungkus dengan SizedBox
SizedBox(
  width: double.infinity,
  child: OutlinedButton(onPressed: () {}, child: const Text('Batal')),
),
Tombol merah selebar layar dengan styleFrom dan OutlinedButton selebar layar

Ragam FloatingActionButton

// FAB standar (ikon saja)
FloatingActionButton(
  onPressed: () {},
  tooltip: 'Tambah catatan',
  child: const Icon(Icons.add),
),

// FAB kecil dan besar
FloatingActionButton.small(onPressed: () {}, child: const Icon(Icons.edit)),
FloatingActionButton.large(onPressed: () {}, child: const Icon(Icons.camera_alt)),

// FAB dengan label teks
FloatingActionButton.extended(
  onPressed: () {},
  icon: const Icon(Icons.upload_file),
  label: const Text('Unggah Tugas'),
),
FAB standar, small, large, dan extended

ℹ️ FAB biasanya hanya satu

Contoh di atas sengaja menampilkan beberapa FAB untuk perbandingan. Dalam aplikasi nyata, satu layar sebaiknya hanya punya satu FAB yang dipasang di parameter floatingActionButton milik Scaffold. Jika terpaksa memakai beberapa FAB di satu layar, beri masing-masing heroTag yang berbeda agar tidak terjadi error saat pindah halaman.

⚠️ Kesalahan umum

  • Menulis onPressed: _simpan() (dengan tanda kurung). Ini MEMANGGIL fungsi saat build, bukan saat ditekan. Tulis onPressed: _simpan atau onPressed: () => _simpan().
  • Bingung kenapa tombol abu-abu dan tidak bisa ditekan. Periksa apakah onPressed bernilai null.
  • Memakai banyak FilledButton dalam satu layar. Pengguna jadi bingung mana aksi utama. Pakai Outlined atau Text untuk aksi pendukung.
  • Lupa tooltip pada IconButton. Ikon saja sering tidak jelas maknanya.
