Form yang nyaman dipakai di HP bukan hanya soal tampilan. Jenis keyboard yang tepat, password yang bisa diintip, dan perpindahan fokus otomatis membuat pengguna bisa mengisi form lebih cepat.

1. keyboardType: memilih jenis keyboard

Parameter keyboardType menentukan keyboard yang muncul. Ini tidak membatasi isi (pengguna tetap bisa menempelkan huruf), tapi sangat memudahkan pengisian.

TextField(
  keyboardType: TextInputType.emailAddress, // keyboard dengan tombol @
  decoration: InputDecoration(labelText: 'Email'),
),
TextField(
  keyboardType: TextInputType.number, // keyboard angka
  decoration: InputDecoration(labelText: 'IPK Semester Lalu'),
),
TextField(
  keyboardType: TextInputType.phone, // keyboard telepon
  decoration: InputDecoration(labelText: 'Nomor WhatsApp'),
),
TextField(
  keyboardType: TextInputType.multiline, // Enter = baris baru
  maxLines: null,
  decoration: InputDecoration(labelText: 'Catatan'),
),

2. obscureText: password dengan tombol tampilkan/sembunyikan

obscureText: true mengganti setiap huruf dengan titik. Agar pengguna bisa memeriksa ketikannya, kita simpan nilai obscureText di variabel State lalu membaliknya lewat IconButton di suffixIcon.

class PasswordField extends StatefulWidget {
  const PasswordField({super.key});

  @override
  State<PasswordField> createState() => _PasswordFieldState();
}

class _PasswordFieldState extends State<PasswordField> {
  bool _sembunyikan = true; // awalnya password disembunyikan

  @override
  Widget build(BuildContext context) {
    return TextField(
      obscureText: _sembunyikan, // true -> teks tampil sebagai titik
      enableSuggestions: false,
      autocorrect: false,
      decoration: InputDecoration(
        labelText: 'Password',
        prefixIcon: const Icon(Icons.lock_outline),
        suffixIcon: IconButton(
          tooltip: _sembunyikan ? 'Tampilkan password' : 'Sembunyikan password',
          icon: Icon(_sembunyikan ? Icons.visibility : Icons.visibility_off),
          onPressed: () => setState(() => _sembunyikan = !_sembunyikan),
        ),
      ),
    );
  }
}
Password tersembunyi (titik-titik)
Setelah ikon mata ditekan, password terlihat

enableSuggestions: false dan autocorrect: false mencegah keyboard menyimpan atau mengoreksi password.

3. textInputAction dan FocusNode: berpindah antar field

  • textInputAction mengganti tombol Enter di keyboard menjadi Next (TextInputAction.next), Done (.done), Search (.search), dan lainnya.
  • onSubmitted dipanggil saat tombol tersebut ditekan.
  • FocusNode adalah "remote" untuk sebuah field. focusNode.requestFocus() memindahkan kursor ke field itu, sedangkan FocusScope.of(context).unfocus() melepas fokus dan menutup keyboard. Sama seperti controller, FocusNode wajib di-dispose.

Contoh lengkap: login dengan perpindahan fokus

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const LoginSederhanaScreen(),
    );
  }
}

class LoginSederhanaScreen extends StatefulWidget {
  const LoginSederhanaScreen({super.key});

  @override
  State<LoginSederhanaScreen> createState() => _LoginSederhanaScreenState();
}

class _LoginSederhanaScreenState extends State<LoginSederhanaScreen> {
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();

  // FocusNode = "remote" untuk mengatur fokus sebuah TextField
  final _emailFocus = FocusNode();
  final _passwordFocus = FocusNode();

  bool _sembunyikan = true;
  String _status = 'Silakan login';

  @override
  void dispose() {
    _emailController.dispose();
    _passwordController.dispose();
    _emailFocus.dispose();
    _passwordFocus.dispose();
    super.dispose();
  }

  void _login() {
    // Tutup keyboard dengan melepas fokus
    FocusScope.of(context).unfocus();

    final email = _emailController.text.trim();
    final password = _passwordController.text;

    if (email.isEmpty) {
      setState(() => _status = 'Email masih kosong');
      _emailFocus.requestFocus(); // arahkan kursor ke field yang bermasalah
      return;
    }
    if (password.isEmpty) {
      setState(() => _status = 'Password masih kosong');
      _passwordFocus.requestFocus();
      return;
    }
    setState(() => _status = 'Login sebagai $email');
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Keyboard & Fokus')),
      // Ketuk area kosong untuk menutup keyboard
      body: GestureDetector(
        onTap: () => FocusScope.of(context).unfocus(),
        child: ListView(
          padding: const EdgeInsets.all(24),
          children: [
            const Icon(Icons.school, size: 72),
            const SizedBox(height: 24),
            TextField(
              controller: _emailController,
              focusNode: _emailFocus,
              autofocus: true, // langsung fokus saat layar dibuka
              keyboardType: TextInputType.emailAddress,
              textInputAction: TextInputAction.next, // tombol "Next" di keyboard
              // Saat "Next" ditekan, pindah ke field password
              onSubmitted: (_) => _passwordFocus.requestFocus(),
              decoration: const InputDecoration(
                labelText: 'Email Kampus',
                prefixIcon: Icon(Icons.email_outlined),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            TextField(
              controller: _passwordController,
              focusNode: _passwordFocus,
              obscureText: _sembunyikan,
              textInputAction: TextInputAction.done, // tombol "Done" di keyboard
              onSubmitted: (_) => _login(), // tekan Done = login
              decoration: InputDecoration(
                labelText: 'Password',
                prefixIcon: const Icon(Icons.lock_outline),
                border: const OutlineInputBorder(),
                suffixIcon: IconButton(
                  icon: Icon(_sembunyikan ? Icons.visibility : Icons.visibility_off),
                  onPressed: () => setState(() => _sembunyikan = !_sembunyikan),
                ),
              ),
            ),
            const SizedBox(height: 24),
            FilledButton(onPressed: _login, child: const Text('Masuk')),
            const SizedBox(height: 16),
            Text(_status, textAlign: TextAlign.center),
          ],
        ),
      ),
    );
  }
}
Field email langsung fokus (autofocus) dan keyboard email terbuka
Email diisi, Masuk ditekan: kursor dipindah ke Password

Penjelasan kode:

  • autofocus: true pada email membuat keyboard langsung muncul saat layar dibuka.
  • Pada email, onSubmitted: (_) => _passwordFocus.requestFocus() memindahkan kursor ke password ketika tombol Next ditekan.
  • Pada password, TextInputAction.done + onSubmitted: (_) => _login() membuat pengguna bisa login langsung dari keyboard.
  • Di _login, jika ada field kosong, kursor diarahkan ke field tersebut dengan requestFocus().
  • GestureDetector di luar ListView menutup keyboard saat area kosong diketuk.

⚠️ Kesalahan umum

  • Membuat FocusNode() di dalam build. Sama seperti controller: buat di State dan dispose.
  • Memberi obscureText: true pada field multi-baris. Flutter menolak kombinasi ini (maxLines harus 1).
  • Mengandalkan keyboardType.number sebagai validasi. Pengguna tetap bisa menempelkan huruf. Validasi tetap dilakukan di validator (section berikutnya).
