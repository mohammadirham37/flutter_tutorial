onChanged cukup untuk membaca teks. Namun sering kita juga perlu mengubah isi field dari kode, mengosongkan field setelah tombol Simpan ditekan, atau memberi nilai awal. Untuk itu Flutter menyediakan TextEditingController.

Konsep: tiga langkah wajib

  1. Buat controller sebagai field di dalam State (bukan di dalam build).
  2. Hubungkan ke TextField lewat parameter controller:.
  3. Buang (dispose()) controller di method dispose() milik State.

Setelah terhubung, kita bisa memakai controller.text (membaca atau mengubah isi), controller.clear() (mengosongkan), dan controller.addListener(...) (dipanggil setiap isi berubah).

Contoh kecil

class ContohController extends StatefulWidget {
  const ContohController({super.key});

  @override
  State<ContohController> createState() => _ContohControllerState();
}

class _ContohControllerState extends State<ContohController> {
  // 1. Buat controller sebagai field di State
  final _namaController = TextEditingController();

  // 3. Wajib dibuang saat widget dihapus dari layar
  @override
  void dispose() {
    _namaController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // 2. Hubungkan controller ke TextField
        TextField(controller: _namaController),
        FilledButton(
          // Baca isi TextField kapan saja lewat .text
          onPressed: () => debugPrint('Nama: ${_namaController.text}'),
          child: const Text('Cetak'),
        ),
      ],
    );
  }
}
TextField terhubung controller dan tombol Cetak

Contoh lengkap: membaca, mengubah, mengosongkan, dan mendengarkan

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const ControllerDemoScreen(),
    );
  }
}

class ControllerDemoScreen extends StatefulWidget {
  const ControllerDemoScreen({super.key});

  @override
  State<ControllerDemoScreen> createState() => _ControllerDemoScreenState();
}

class _ControllerDemoScreenState extends State<ControllerDemoScreen> {
  // Nilai awal bisa diisi lewat parameter text
  final _judulController = TextEditingController(text: 'Rancang Bangun Aplikasi');
  final List<String> _riwayat = [];
  int _jumlahKata = 0;

  @override
  void initState() {
    super.initState();
    _jumlahKata = _hitung(_judulController.text);
    // Listener dipanggil SETIAP kali teks (atau posisi kursor) berubah
    _judulController.addListener(_hitungKata);
  }

  int _hitung(String teks) {
    final bersih = teks.trim();
    return bersih.isEmpty ? 0 : bersih.split(RegExp(r'\s+')).length;
  }

  void _hitungKata() {
    setState(() => _jumlahKata = _hitung(_judulController.text));
  }

  @override
  void dispose() {
    _judulController.removeListener(_hitungKata);
    _judulController.dispose();
    super.dispose();
  }

  void _simpan() {
    final judul = _judulController.text.trim();
    if (judul.isEmpty) return;
    setState(() => _riwayat.insert(0, judul));
    _judulController.clear(); // mengosongkan TextField
  }

  void _isiContoh() {
    // Mengubah isi TextField dari kode
    _judulController.text = 'Sistem Informasi Presensi Berbasis Flutter';
  }

  void _hurufBesar() {
    _judulController.text = _judulController.text.toUpperCase();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('TextEditingController')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            TextField(
              controller: _judulController,
              decoration: InputDecoration(
                labelText: 'Judul Skripsi',
                border: const OutlineInputBorder(),
                helperText: 'Jumlah kata: $_jumlahKata',
                // Tombol hapus hanya muncul jika ada teks
                suffixIcon: _judulController.text.isEmpty
                    ? null
                    : IconButton(
                        icon: const Icon(Icons.clear),
                        onPressed: _judulController.clear,
                      ),
              ),
            ),
            const SizedBox(height: 12),
            Wrap(
              spacing: 8,
              runSpacing: 8,
              children: [
                FilledButton.icon(
                  onPressed: _simpan,
                  icon: const Icon(Icons.save),
                  label: const Text('Simpan'),
                ),
                OutlinedButton(onPressed: _isiContoh, child: const Text('Isi contoh')),
                OutlinedButton(onPressed: _hurufBesar, child: const Text('HURUF BESAR')),
              ],
            ),
            const Divider(height: 32),
            Text('Riwayat judul (${_riwayat.length})',
                style: Theme.of(context).textTheme.titleMedium),
            Expanded(
              child: ListView(
                children: [
                  for (final judul in _riwayat)
                    ListTile(leading: const Icon(Icons.history), title: Text(judul)),
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}
Nilai awal dari TextEditingController(text: ...) dan jumlah kata
Setelah Isi contoh, Simpan, lalu field kosong kembali

Penjelasan kode:

  • TextEditingController(text: '...') memberi isi awal pada field.
  • addListener(_hitungKata) di initState membuat _hitungKata dipanggil setiap teks berubah, baik karena diketik maupun diubah dari kode. Inilah bedanya dengan onChanged, yang hanya terpanggil saat pengguna mengetik.
  • _judulController.text = '...' mengganti isi field dari kode (tombol "Isi contoh" dan "HURUF BESAR").
  • _judulController.clear() mengosongkan field setelah disimpan. Tombol silang di suffixIcon juga memanggil clear.
  • Di dispose() kita melepas listener lalu membuang controller. Urutannya: bersihkan milik kita dulu, super.dispose() paling akhir.

⚠️ Kesalahan umum

  • Membuat controller di dalam build(). Setiap kali setState dipanggil, controller baru dibuat sehingga teks yang diketik hilang. Selalu jadikan field di State.
  • Lupa dispose(). Controller tetap tersimpan di memori setelah layar ditutup (memory leak).
  • Memakai controller di StatelessWidget. StatelessWidget tidak punya dispose, jadi controller harus berada di StatefulWidget.
  • Memanggil setState di initState sebelum layar tampil. Cukup isi variabel langsung, seperti _jumlahKata = _hitung(...) pada contoh.
