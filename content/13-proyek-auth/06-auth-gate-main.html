Bagaimana aplikasi tahu harus menampilkan Login atau Home? Kita tidak memakai Navigator.pushReplacement setelah login. Sebagai gantinya, satu widget bernama AuthGate mendengarkan stream status login dan memilih layar secara otomatis.

Kenapa AuthGate lebih baik daripada navigasi manual?

SituasiNavigasi manualAuthGate (reaktif)
Login berhasilHarus memanggil pushReplacement(Home)Otomatis pindah ke Home
LogoutHarus pushAndRemoveUntil(Login)Otomatis kembali ke Login
Aplikasi dibuka ulang, sesi masih adaPerlu cek manual di splash screenLangsung ke Home (event initialSession)
Sesi kedaluwarsa / dicabutSering terlupaOtomatis ke Login (event signedOut)

📄 lib/screens/auth_gate.dart

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import '../providers/auth_provider.dart';
import 'home_screen.dart';
import 'login_screen.dart';

/// "Penjaga pintu" aplikasi: mendengarkan perubahan status login lalu
/// memilih halaman yang tepat secara otomatis.
class AuthGate extends StatefulWidget {
  const AuthGate({super.key});

  @override
  State<AuthGate> createState() => _AuthGateState();
}

class _AuthGateState extends State<AuthGate> {
  // Simpan stream di State agar tidak dibuat ulang setiap build.
  late final Stream<AuthState> _authStream;

  @override
  void initState() {
    super.initState();
    _authStream = context.read<AuthProvider>().authStateChanges;
  }

  @override
  Widget build(BuildContext context) {
    return StreamBuilder<AuthState>(
      stream: _authStream,
      builder: (context, snapshot) {
        // Sebelum event pertama datang, pakai sesi yang tersimpan di perangkat.
        final session = snapshot.hasData
            ? snapshot.data!.session
            : context.read<AuthProvider>().currentSession;

        if (session == null) {
          return const LoginScreen();
        }
        return const HomeScreen();
      },
    );
  }
}
  • Stream disimpan di initState sebagai late final. Jika stream: diisi langsung dengan getter di dalam build(), setiap rebuild bisa membuat StreamBuilder berlangganan ulang.
  • context.read boleh dipakai di initState karena kita hanya membaca sekali, tanpa mendengarkan perubahan.
  • snapshot.hasData ? ... : currentSession: sebelum event pertama tiba (beberapa milidetik), kita memakai sesi tersimpan agar layar Login tidak "berkedip" sesaat bagi user yang sudah login.
  • Setiap event (signedIn, signedOut, tokenRefreshed, ...) membawa session terbaru, jadi cukup cek session == null.

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import '../providers/auth_provider.dart';

/// HomeScreen sementara untuk Bagian 1. Di Modul 14 file ini diganti
/// dengan daftar catatan lengkap.
class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  Future<void> _logout(BuildContext context) async {
    await context.read<AuthProvider>().signOut();
    // Tidak perlu Navigator: AuthGate otomatis menampilkan LoginScreen.
  }

  @override
  Widget build(BuildContext context) {
    final auth = context.watch<AuthProvider>();
    final user = auth.currentUser;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Catatan Kuliah'),
        actions: [
          IconButton(
            tooltip: 'Keluar',
            icon: const Icon(Icons.logout),
            onPressed: () => _logout(context),
          ),
        ],
      ),
      body: Center(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              const Icon(Icons.verified_user, size: 72, color: Colors.green),
              const SizedBox(height: 16),
              Text(
                'Halo, ${auth.displayName}!',
                style: Theme.of(context).textTheme.headlineSmall,
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 8),
              Text('Login sebagai ${user?.email ?? '-'}'),
              const SizedBox(height: 4),
              SelectableText(
                'User ID: ${user?.id ?? '-'}',
                style: Theme.of(context).textTheme.bodySmall,
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 24),
              const Text(
                'Autentikasi berhasil. Daftar catatan dibuat di Modul 14.',
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 24),
              OutlinedButton.icon(
                onPressed: () => _logout(context),
                icon: const Icon(Icons.logout),
                label: const Text('Keluar'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Perhatikan _logout: setelah signOut() tidak ada Navigator sama sekali. Stream memancarkan signedOut, lalu AuthGate menampilkan LoginScreen.

File 7: lib/main.dart (versi Bagian 1)

📄 lib/main.dart

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'config/env.dart';
import 'providers/auth_provider.dart';
import 'screens/auth_gate.dart';
import 'services/auth_service.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  if (!Env.isConfigured) {
    runApp(const ConfigErrorApp());
    return;
  }

  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabasePublishableKey,
  );

  final authService = AuthService(Supabase.instance.client);

  runApp(
    ChangeNotifierProvider(
      create: (_) => AuthProvider(authService),
      child: const CatatanKuliahApp(),
    ),
  );
}

class CatatanKuliahApp extends StatelessWidget {
  const CatatanKuliahApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Catatan Kuliah',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
      ),
      home: const AuthGate(),
    );
  }
}

}
  • if (!Env.isConfigured): jika lupa --dart-define-from-file, aplikasi menampilkan petunjuk yang jelas, bukan error membingungkan dari Supabase.
  • AuthService(Supabase.instance.client) dibuat sesudah initialize selesai, lalu disuntikkan ke AuthProvider.
  • ChangeNotifierProvider di atas MaterialApp membuat AuthProvider bisa diakses dari semua halaman, termasuk halaman yang di-push.
