Ringkasan Modul 13

  • Arsitektur berlapis: UI → Provider → Service/Repository → Supabase/Hive.
  • Tabel profiles diisi otomatis oleh trigger security definer dari raw_user_meta_data.
  • AuthService membungkus Supabase Auth, sedangkan AuthProvider menyimpan loading/error dan menerjemahkan kode error.
  • AuthGate + onAuthStateChange membuat navigasi login/logout otomatis tanpa Navigator manual.
  • Login dan Register memakai Form + validator + show/hide password + tombol loading + SnackBar.

Di Modul 14 kita melanjutkan kode yang sama: menambah tabel notes, cache Hive, dan mengganti HomeScreen sementara dengan daftar catatan lengkap.
