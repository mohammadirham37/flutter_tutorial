Langkah 1: Membuat proyek dan memasang package

flutter create catatan_kuliah
cd catatan_kuliah

flutter pub add supabase_flutter provider hive_ce hive_ce_flutter
PackageKegunaan di proyek
supabase_flutterAuth dan database cloud (Modul 12)
providerState management (Modul 08)
hive_ceDatabase key-value lokal untuk cache (Modul 11)
hive_ce_flutterHive.initFlutter(): menentukan folder penyimpanan di HP

Setelah perintah di atas, bagian dependencies di pubspec.yaml kira-kira seperti ini (nomor versi mengikuti yang terbaru saat Anda menjalankan perintah):

📄 pubspec.yaml

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8
  supabase_flutter: ^x.y.z
  provider: ^x.y.z
  hive_ce: ^x.y.z
  hive_ce_flutter: ^x.y.z

Langkah 2: Siapkan folder dan file konfigurasi

mkdir -p lib/config lib/models lib/services lib/data lib/providers lib/screens lib/widgets lib/utils

Buat env.json di root proyek (sejajar pubspec.yaml) dan isi dengan nilai dari dashboard Supabase Anda (Modul 12 section 2):

📄 env.json

{
  "SUPABASE_URL": "https://YOUR-PROJECT-REF.supabase.co",
  "SUPABASE_PUBLISHABLE_KEY": "sb_publishable_YOUR_KEY"
}

Tambahkan ke .gitignore:

📄 .gitignore

# Kunci Supabase
env.json

Lalu salin env.json menjadi env.example.json dengan nilai placeholder, agar teman satu tim tahu format yang dibutuhkan.

Terakhir, tambahkan izin internet untuk build release di android/app/src/main/AndroidManifest.xml (di atas tag <application>):

<uses-permission android:name="android.permission.INTERNET"/>
