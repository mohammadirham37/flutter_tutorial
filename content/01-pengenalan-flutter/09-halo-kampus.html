Saatnya membuat aplikasi pertama Anda sendiri: Halo Kampus, halaman profil mahasiswa dengan tombol presensi. Aplikasi ini memakai konsep yang baru saja dibahas (StatelessWidget, StatefulWidget, setState, tema Material 3) ditambah beberapa widget yang akan dipelajari lebih dalam di Modul 03 dan 04.

Langkah 1: Buat proyek

flutter create --org id.ac.unsoed halo_kampus
cd halo_kampus
code .            # buka di VS Code (opsional)

Langkah 2: Ganti isi lib/main.dart

Hapus seluruh isi lib/main.dart, lalu ketik (atau tempel) kode berikut:

📄 lib/main.dart

import 'package:flutter/material.dart';

void main() {
  runApp(const HaloKampusApp());
}

/// Akar aplikasi: mengatur tema dan halaman pertama.
class HaloKampusApp extends StatelessWidget {
  const HaloKampusApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Halo Kampus',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: const Color(0xFFF2B705)),
      ),
      home: const ProfilPage(),
    );
  }
}

/// Halaman profil mahasiswa. Stateful karena ada data yang berubah (jumlah hadir).
class ProfilPage extends StatefulWidget {
  const ProfilPage({super.key});

  @override
  State<ProfilPage> createState() => _ProfilPageState();
}

class _ProfilPageState extends State<ProfilPage> {
  // Data mahasiswa: ganti dengan identitas Anda sendiri.
  final String _nama = 'Budi Santoso';
  final String _nim = 'H1D024001';
  final String _prodi = 'S1 Informatika';

  int _jumlahHadir = 0;

  void _presensi() {
    setState(() {
      _jumlahHadir++;
    });
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Presensi ke-$_jumlahHadir tercatat. Semangat!')),
    );
  }

  void _reset() {
    setState(() {
      _jumlahHadir = 0;
    });
  }

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Halo Kampus'),
        backgroundColor: warna.primaryContainer,
        actions: [
          IconButton(
            tooltip: 'Reset presensi',
            onPressed: _reset,
            icon: const Icon(Icons.refresh),
          ),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // Bagian 1: foto dan nama
          CircleAvatar(
            radius: 48,
            backgroundColor: warna.primary,
            child: Text(
              _nama[0],
              style: TextStyle(fontSize: 40, color: warna.onPrimary),
            ),
          ),
          const SizedBox(height: 12),
          Text(
            _nama,
            textAlign: TextAlign.center,
            style: Theme.of(context).textTheme.headlineSmall,
          ),
          Text(
            '$_nim - $_prodi',
            textAlign: TextAlign.center,
            style: Theme.of(context).textTheme.bodyMedium,
          ),
          const SizedBox(height: 16),

          // Bagian 2: kartu informasi
          Card(
            child: Column(
              children: const [
                ListTile(
                  leading: Icon(Icons.school),
                  title: Text('Universitas Jenderal Soedirman'),
                  subtitle: Text('Fakultas Teknik'),
                ),
                ListTile(
                  leading: Icon(Icons.location_on),
                  title: Text('Purwokerto, Jawa Tengah'),
                ),
                ListTile(
                  leading: Icon(Icons.phone_android),
                  title: Text('Mata kuliah: Pemrograman Mobile'),
                ),
              ],
            ),
          ),
          const SizedBox(height: 16),

          // Bagian 3: penghitung presensi
          Card(
            color: warna.secondaryContainer,
            child: Padding(
              padding: const EdgeInsets.all(16),
              child: Column(
                children: [
                  const Text('Jumlah presensi hari ini'),
                  Text(
                    '$_jumlahHadir',
                    style: Theme.of(context).textTheme.displaySmall,
                  ),
                ],
              ),
            ),
          ),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _presensi,
        icon: const Icon(Icons.check),
        label: const Text('Presensi'),
      ),
    );
  }
}

Penjelasan bagian penting

  • HaloKampusApp hanya mengatur tema dan halaman awal, sehingga cukup Stateless. seedColor: Color(0xFFF2B705) adalah kuning keemasan; Material 3 otomatis membuat palet lengkap dari satu warna ini. Format 0xFF + kode hex RGB: FF berarti tidak transparan.
  • _ProfilPageState menyimpan data mahasiswa sebagai final (tidak berubah) dan _jumlahHadir sebagai data yang berubah.
  • _presensi() menaikkan angka dengan setState, lalu menampilkan SnackBar (pesan singkat di bawah layar) lewat ScaffoldMessenger.
  • Theme.of(context).colorScheme mengambil warna dari tema, sehingga mengganti seedColor otomatis mengubah warna AppBar, avatar, dan kartu.
  • ListView dipakai sebagai body agar halaman bisa di-scroll di layar kecil, tidak muncul error overflow garis kuning-hitam.
  • _nama[0] mengambil huruf pertama nama untuk ditampilkan di avatar.

Langkah 4: Eksperimen

  1. Ganti _nama, _nim, dan _prodi dengan data Anda, lalu tekan R (field ini adalah nilai awal State, ingat percobaan di section sebelumnya).
  2. Ganti seedColor menjadi Colors.green lalu tekan r. Tekan Presensi beberapa kali dulu agar terlihat bahwa angkanya tidak hilang.
  3. Tambahkan satu ListTile baru berisi hobi Anda, misalnya dengan ikon Icons.sports_soccer.
  4. Ubah tema menjadi gelap dengan menambahkan brightness: Brightness.dark di dalam ColorScheme.fromSeed(...).
Hasil eksperimen 2 dan 4: seedColor Colors.green dengan brightness: Brightness.dark

⚠️ Kesalahan umum

  • Error Undefined name '_nama': field ditulis di kelas ProfilPage, bukan di _ProfilPageState.
  • Menambah ListTile tidak muncul / error const: daftar children: const [...] hanya boleh berisi widget const. Pastikan widget baru juga const (semua argumennya nilai tetap).
  • Kurung tutup kurang: aktifkan Format on Save di VS Code dan perhatikan koma di akhir argumen (trailing comma) agar formatter menyusun kode bertingkat dengan rapi.
