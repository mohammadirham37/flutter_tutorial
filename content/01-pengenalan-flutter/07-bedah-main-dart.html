Setiap proyek baru dari flutter create berisi aplikasi counter: layar dengan angka dan tombol +. Aplikasi kecil ini sudah memuat hampir semua konsep dasar Flutter, jadi kita bedah bagian per bagian. Komentar bawaan sudah dihapus dan diganti nomor penanda.

Sebelum itu: aplikasi Flutter paling kecil

Agar terlihat bahwa "semua adalah widget", ini program Flutter terkecil yang bisa dijalankan. Tidak ada AppBar, tema, atau tombol, hanya satu teks di tengah layar:

📄 lib/main.dart

import 'package:flutter/material.dart';

void main() {
  runApp(
    const Center(
      child: Text(
        'Halo, Flutter!',
        textDirection: TextDirection.ltr,
        style: TextStyle(fontSize: 32),
      ),
    ),
  );
}
Aplikasi paling kecil: hanya satu Text tanpa MaterialApp

runApp() menerima satu widget dan menjadikannya akar (root) seluruh tampilan. Karena tidak memakai MaterialApp, kita harus menyebut arah teks (textDirection) sendiri. Inilah alasan hampir semua aplikasi dibungkus MaterialApp: ia menyediakan arah teks, tema, navigasi, dan banyak hal lain secara otomatis.

Kode counter bawaan

📄 lib/main.dart

// 1
import 'package:flutter/material.dart';

// 2
void main() {
  runApp(const MyApp());
}

// 3
class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    // 4
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
      ),
      home: const MyHomePage(title: 'Flutter Demo Home Page'),
    );
  }
}

// 5
class MyHomePage extends StatefulWidget {
  const MyHomePage({super.key, required this.title});

  final String title;

  @override
  State<MyHomePage> createState() => _MyHomePageState();
}

// 6
class _MyHomePageState extends State<MyHomePage> {
  int _counter = 0;

  // 7
  void _incrementCounter() {
    setState(() {
      _counter++;
    });
  }

  // 8
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        backgroundColor: Theme.of(context).colorScheme.inversePrimary,
        title: Text(widget.title),
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Text('You have pushed the button this many times:'),
            Text(
              '$_counter',
              style: Theme.of(context).textTheme.headlineMedium,
            ),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _incrementCounter,
        tooltip: 'Increment',
        child: const Icon(Icons.add),
      ),
    );
  }
}

ℹ️ Kode Anda sedikit berbeda?

Versi Flutter terbaru memakai fitur Dart dot shorthand, sehingga flutter create menulis .fromSeed(...) dan .center alih-alih ColorScheme.fromSeed(...) dan MainAxisAlignment.center. Artinya sama persis. Di materi ini kita memakai bentuk lengkap agar asal setiap nilai terlihat jelas.

Penjelasan baris per baris

No.KodePenjelasan
1import 'package:flutter/material.dart';Mengimpor pustaka Material Design: semua widget seperti Scaffold, AppBar, Text, dan Icons berasal dari sini.
2void main() dan runApp(const MyApp())Titik masuk program. runApp memasang widget MyApp sebagai akar tampilan. const berarti objek dibuat sekali saat kompilasi sehingga lebih hemat.
3class MyApp extends StatelessWidgetWidget akar yang tidak punya data berubah. const MyApp({super.key}) adalah constructor yang meneruskan key ke kelas induk.
4MaterialApp(...)Pembungkus aplikasi: title (nama di task switcher), theme (warna dari satu seedColor menjadi palet Material 3), dan home (halaman pertama).
5class MyHomePage extends StatefulWidgetHalaman yang datanya berubah (angka counter). Field title bersifat final, diisi lewat parameter required this.title. createState() membuat objek State pasangannya.
6class _MyHomePageState extends State<MyHomePage>Tempat data yang bisa berubah disimpan: int _counter = 0. Garis bawah (_) artinya privat, hanya bisa diakses dari file ini.
7setState(() { _counter++; })Mengubah data sekaligus memberi tahu Flutter agar memanggil build() lagi. Tanpa setState, angka berubah di memori tetapi layar tidak ikut berubah.
8Widget build(BuildContext context)Menggambarkan tampilan: Scaffold (kerangka halaman) berisi AppBar, body berupa Center > Column > dua Text, dan FloatingActionButton yang memanggil _incrementCounter saat ditekan. widget.title dipakai untuk membaca field dari kelas MyHomePage.

Pohon widget (widget tree) aplikasi counter

MyApp
└── MaterialApp
    └── MyHomePage
        └── Scaffold
            ├── AppBar
            │   └── Text (judul)
            ├── Center
            │   └── Column

Alur ketika tombol + ditekan

  1. Pengguna mengetuk FloatingActionButton, sehingga onPressed memanggil _incrementCounter().
  2. setState menjalankan _counter++ lalu menandai widget sebagai "kotor" (perlu digambar ulang).
  3. Pada frame berikutnya Flutter memanggil build() lagi, dan Text('$_counter') kini berisi angka baru.

⚠️ Kesalahan umum

  • Mengubah _counter++ di luar setState: angka tidak muncul di layar.
  • Menaruh variabel _counter di dalam build(): nilainya kembali ke 0 setiap kali layar digambar ulang.
  • Menulis title alih-alih widget.title di dalam kelas State: error Undefined name 'title'.
