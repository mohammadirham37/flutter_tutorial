Hampir semua mahasiswa menemui setidaknya satu error saat setup. Jangan panik: baca pesan flutter doctor, cari pesan yang sama di tabel ini, lalu jalankan perbaikannya. Setelah memperbaiki, selalu jalankan ulang flutter doctor.

1. Android license status unknown

[!] Android toolchain - develop for Android devices
    ! Some Android licenses not accepted. To resolve this, run: flutter doctor --android-licenses

Penyebab: lisensi Android SDK belum disetujui. Perbaikan:

flutter doctor --android-licenses
# Ketik y lalu Enter untuk setiap lisensi yang ditanyakan

2. cmdline-tools component is missing

[✗] Android toolchain - develop for Android devices
    ✗ cmdline-tools component is missing

Penyebab: Android SDK Command-line Tools belum dipasang (dan perintah lisensi di atas juga akan gagal karenanya). Perbaikan: buka Android Studio > Settings > Languages & Frameworks > Android SDK > tab SDK Tools > centang Android SDK Command-line Tools (latest) > Apply. Jika Flutter tidak menemukan lokasi SDK, beri tahu secara manual:

# macOS (lokasi default)
flutter config --android-sdk "$HOME/Library/Android/sdk"

# Windows (lokasi default, ganti NamaUser)
flutter config --android-sdk "C:\Users\NamaUser\AppData\Local\Android\Sdk"

3. JAVA_HOME / versi Java tidak cocok

ERROR: JAVA_HOME is set to an invalid directory
# atau saat build:
Unsupported class file major version 65

Penyebab: Gradle memakai Java yang salah, biasanya JDK lama yang terpasang terpisah. Cara paling aman adalah memakai JDK bawaan Android Studio (folder jbr):

# Arahkan Flutter ke JDK bawaan Android Studio (macOS)
flutter config --jdk-dir "/Applications/Android Studio.app/Contents/jbr/Contents/Home"

# Atau set JAVA_HOME di ~/.zshrc (macOS), lalu: source ~/.zshrc
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"

# Windows (PowerShell), lalu tutup dan buka ulang terminal
setx JAVA_HOME "C:\Program Files\Android\Android Studio\jbr"

# Cek hasilnya
flutter doctor -v

4. CocoaPods not installed (khusus macOS untuk iOS)

[!] Xcode - develop for iOS and macOS
    ✗ CocoaPods not installed.

Penyebab: plugin iOS dikelola oleh CocoaPods. Perbaikan (pilih salah satu):

# Lewat Homebrew (disarankan di Apple Silicon)
brew install cocoapods

# Atau lewat RubyGems
sudo gem install cocoapods

# Jika build iOS gagal setelah menambah package
cd ios
pod repo update
pod install
cd ..

Sekalian pastikan Xcode sudah dikonfigurasi:

sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -runFirstLaunch

💡 Cara bertanya yang baik saat error

Saat bertanya ke asisten praktikum atau forum, sertakan: (1) hasil lengkap flutter doctor -v, (2) perintah yang Anda jalankan, (3) potongan pesan error paling atas (bukan hanya baris terakhir). Pesan error yang lengkap biasanya sudah menyebutkan solusinya.
