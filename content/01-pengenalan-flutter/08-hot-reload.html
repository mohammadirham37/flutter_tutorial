Lab mini: membuktikan perbedaannya

Jalankan kode berikut dengan flutter run, lalu tekan tombol di layar sampai angkanya 5. Huruf (A) sampai (E) adalah titik yang akan kita ubah.

📄 lib/main.dart

import 'package:flutter/material.dart';

// Variabel global: nilai awalnya hanya dihitung SEKALI saat pertama dipakai.
final String namaKampus = 'UNSOED';

void main() {
  runApp(const LabReloadApp());
}

class LabReloadApp extends StatelessWidget {
  const LabReloadApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo), // (A)
      ),
      home: const HalamanLab(),
    );
  }
}

class HalamanLab extends StatefulWidget {
  const HalamanLab({super.key});

  @override
  State<HalamanLab> createState() => _HalamanLabState();
}

class _HalamanLabState extends State<HalamanLab> {
  int _klik = 0; // (B)

  @override
  void initState() {
    super.initState();
    debugPrint('initState dipanggil'); // (C)
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Lab Reload - $namaKampus')), // (D)
      body: Center(
        child: Text(
          'Tombol ditekan $_klik kali',
          style: const TextStyle(fontSize: 24, color: Colors.black87), // (E)
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _klik++),
        child: const Icon(Icons.touch_app),
      ),
    );
  }
}
Kondisi awal percobaan: tombol sudah ditekan 5 kali

Lakukan percobaan berikut satu per satu dan amati hasilnya:

PercobaanUbah menjadiHot Reload (r)Hot Restart (R)
(E) warna teksColors.redTeks langsung merah, angka tetap 5Teks merah, angka kembali 0
(A) warna temaColors.tealTombol dan latar halaman berubah nuansa teal, angka tetap 5Berubah, angka kembali 0
(B) nilai awalint _klik = 100;Tidak berubah, angka tetap 5 karena objek State lama dipertahankanAngka mulai dari 100
(C) isi initStatedebugPrint('initState versi 2');Tidak tercetak, initState tidak dipanggil lagiTercetak di terminal
Variabel globalfinal String namaKampus = 'Universitas Jenderal Soedirman';Judul AppBar tetap "UNSOED"Judul berubah
Setelah mengubah (A) teal, (B) 100, dan (E) merah lalu menekan Hot Restart: semua perubahan tampil dan angka mulai dari 100

Percobaan (D) menunjukkan sisi sebaliknya: judul AppBar memakai namaKampus, tetapi variabel global hanya dihitung sekali. Hot Reload mengganti kode build(), bukan nilai yang sudah tersimpan di memori.

Kapan wajib Full Restart?

# Contoh: menambah package yang punya kode native (Android/iOS)
flutter pub add shared_preferences

# Hot Reload / Hot Restart TIDAK cukup. Hentikan aplikasi (tekan q), lalu:
flutter run

Jika Anda hanya menekan R setelah menambah package native, biasanya muncul error MissingPluginException. Ini bukan bug kode Anda; aplikasinya hanya perlu dikompilasi ulang.

💡 Aturan praktis

Ubah tampilan: r. Ubah data awal atau ganti seluruh main.dart: R. Ubah pubspec.yaml (package native, aset) atau folder android/ / ios/: stop lalu flutter run. Jika ragu dan hasil tampak aneh, naikkan satu tingkat.
