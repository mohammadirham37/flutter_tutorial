Berikut adalah langkah-langkah menyiapkan Flutter di komputer pengembangan. Ikuti berurutan dan jangan lanjut ke langkah berikutnya sebelum langkah sebelumnya berhasil.

Langkah 1: Mengunduh Flutter SDK

Unduh paket SDK resmi dari docs.flutter.dev sesuai sistem operasi Anda, lalu ekstrak ke direktori permanen (contoh: ~/development/flutter di Mac/Linux atau C:\src\flutter di Windows).

⚠️ Hindari folder bermasalah

Jangan ekstrak Flutter ke folder yang butuh hak admin (misal C:\Program Files\) atau yang namanya mengandung spasi. Hindari juga folder yang disinkronkan OneDrive/iCloud karena bisa merusak file cache SDK.

Langkah 2: Menambahkan Path ke Environment Variable

macOS / Linux (zsh):

# Contoh untuk Mac / Linux (zsh) pada ~/.zshrc:
export PATH="$PATH:$HOME/development/flutter/bin"

# Reload shell configuration
source ~/.zshrc

# Cek: harus menampilkan lokasi folder flutter/bin
which flutter

Windows: buka Start > ketik "environment variables" > Edit environment variables for your account > pilih Path > Edit > New > isi C:\src\flutter\bin. Tutup lalu buka ulang terminal, kemudian cek di PowerShell:

where.exe flutter
flutter --version

Langkah 3: Memasang Android Studio dan Android SDK

Pasang Android Studio, buka sekali agar wizard mengunduh Android SDK. Lalu buka Settings > Languages & Frameworks > Android SDK > tab SDK Tools dan pastikan tercentang:

  • Android SDK Build-Tools
  • Android SDK Command-line Tools (latest)
  • Android SDK Platform-Tools
  • Android Emulator

Buat emulator lewat Device Manager > Create Virtual Device (pilih Pixel dengan image Android terbaru).

Langkah 4: Menjalankan flutter doctor

Buka terminal lalu ketik perintah diagnostik utama:

flutter doctor

# Versi detail (lokasi SDK, versi Java, dll). Pakai saat mencari penyebab error.
flutter doctor -v

Perintah ini akan memindai sistem Anda dan memberi centang hijau jika dependensi sudah terpasang:

[✓] Flutter (Channel stable, 3.x.x, on macOS / Windows)
[✓] Android toolchain - develop for Android devices (Android SDK version 3x.x.x)
[✓] Xcode - develop for iOS and macOS (Xcode 16.x)  <-- Opsional untuk pengguna Mac
[✓] Chrome - develop for the web
[✓] Android Studio (version 202x.x)
[✓] VS Code (version 1.9x.x)
[✓] Connected device (2 available)

Tanda [!] berarti ada peringatan dan [✗] berarti komponen belum terpasang. Solusi untuk error yang paling sering muncul dibahas di section berikutnya.

💡 Tips Mahasiswa: Ekstensi VS Code Wajib

Jika menggunakan Visual Studio Code, buka menu Extensions (Ctrl+Shift+X atau Cmd+Shift+X) dan pasang:

  1. Flutter (oleh Dart-Code) — otomatis memasang dependensi Dart.
  2. Awesome Flutter Snippets — shortcut pengetikan widget cepat (misal ketik stless untuk StatelessWidget).
  3. Error Lens — menampilkan error kompilasi langsung di baris kode tanpa perlu membuka tab terminal.

Langkah 5: Menyiapkan HP Android fisik (opsional, disarankan untuk RAM 8 GB)

  1. Buka Setelan > Tentang ponsel, ketuk Nomor versi / Build number 7 kali sampai muncul "Anda sekarang developer".
  2. Buka Setelan > Opsi pengembang, aktifkan USB debugging.
  3. Hubungkan kabel USB (kabel data, bukan kabel charger saja), lalu izinkan dialog "Allow USB debugging" di HP.
  4. Cek dari terminal:
flutter devices
