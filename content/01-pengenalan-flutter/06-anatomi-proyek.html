Untuk membuat proyek baru, jalankan perintah CLI:

flutter create halo_kampus
cd halo_kampus

Struktur folder yang dihasilkan memiliki fungsi spesifik:

halo_kampus/
├── android/          <-- Konfigurasi proyek native Android (Gradle, Manifest, build.gradle)
├── ios/              <-- Konfigurasi proyek native iOS (Podfile, Info.plist, Xcode project)
├── lib/              <-- KODE UTAMA DART KITA (95% waktu coding di sini!)
│   └── main.dart     <-- Titik masuk utama aplikasi (entry point)
├── test/             <-- Berkas unit test dan widget test otomatis
├── web/ & linux/ & windows/ & macos/ <-- Konfigurasi platform desktop & browser
├── pubspec.yaml      <-- MANIFEST PROYEK: Dependensi package, asset gambar, font & versi
├── pubspec.lock      <-- Berkas pengunci versi dependencies riil
└── README.md         <-- Dokumentasi proyek

Memahami pubspec.yaml

File pubspec.yaml adalah file konfigurasi sentral dalam Flutter (mirip package.json di Node.js atau composer.json di PHP Laravel):

name: halo_kampus
description: "Aplikasi praktikum pertama mahasiswa"
publish_to: 'none'
version: 1.0.0+1

environment:
  sdk: ^3.5.0                 # Biarkan sesuai hasil 'flutter create' di laptop Anda

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8     # Ikon iOS style
  # Package eksternal ditambahkan lewat perintah 'flutter pub add <nama>', contoh:
  # flutter pub add http

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^6.0.0       # Aturan coding standard resmi (versi mengikuti flutter create)

flutter:
  uses-material-design: true
  # Hapus tanda '#' di dua baris berikut HANYA setelah folder assets/images/ benar-benar dibuat.
  # Jika foldernya belum ada, build akan gagal: "unable to find directory entry in pubspec.yaml".
  # assets:
  #   - assets/images/

⚠️ Hati-Hati dengan Indentasi YAML!

File .yaml sangat sensitif terhadap spasi. Gunakan 2 spasi (bukan tab). Salah 1 spasi saja dapat menyebabkan flutter pub get gagal membaca file konfigurasi.

▶️ Cara Menjalankan Contoh Kode di Modul Ini

  • Contoh berlabel lib/main.dart adalah program lengkap. Hapus seluruh isi lib/main.dart bawaan, tempel kode contoh, lalu jalankan flutter run.
  • Jika aplikasi sudah berjalan lalu Anda mengganti seluruh isi main.dart, tekan R (Hot Restart), bukan r (Hot Reload). Hot Reload tidak menjalankan ulang main() dan initState(), sehingga tampilan bisa tetap lama atau kosong.
  • Contoh berlabel file lain (misal lib/providers/krs_provider.dart) dibuat sebagai file baru di folder yang sama persis, karena di-import oleh main.dart.
  • Contoh Dart murni (Modul 02) tidak butuh Flutter: jalankan di dartpad.dev.
  • Setelah mengganti main.dart, hapus test/widget_test.dart bawaan (berisi tes aplikasi counter) agar flutter test tidak gagal.
