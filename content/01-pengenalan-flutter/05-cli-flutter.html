VS Code dan Android Studio punya tombol untuk semua hal, tetapi memahami perintah CLI (terminal) membuat Anda tahu apa yang sebenarnya terjadi dan sangat membantu saat debugging. Berikut perintah yang akan dipakai sepanjang semester.

1. Membuat proyek: flutter create

# Bentuk paling sederhana (nama proyek: huruf kecil + garis bawah)
flutter create halo_kampus

# Menentukan organisasi (dipakai sebagai package name Android: id.ac.unsoed.halo_kampus)
flutter create --org id.ac.unsoed halo_kampus

# Hanya membuat folder platform tertentu agar proyek lebih ringan
flutter create --platforms=android,ios,web halo_kampus

# Proyek kosong tanpa contoh counter dan komentar panjang
flutter create --empty halo_kampus

⚠️ Aturan nama proyek

Nama proyek harus huruf kecil dan garis bawah (snake_case), tidak boleh diawali angka dan tidak boleh memakai tanda minus. halo-kampus dan HaloKampus akan ditolak, gunakan halo_kampus.

2. Melihat dan menyalakan device

# Daftar device yang tersambung (HP, emulator yang sudah menyala, Chrome, desktop)
flutter devices

# Daftar emulator yang sudah dibuat di Android Studio
flutter emulators

# Menyalakan emulator berdasarkan id dari perintah di atas
flutter emulators --launch Pixel_8_API_35

3. Menjalankan aplikasi: flutter run

# Jalankan di device default (jika hanya ada satu)
flutter run

# Pilih device tertentu dengan -d (id atau nama dari 'flutter devices')
flutter run -d chrome
flutter run -d emulator-5554

# Mode release: lebih cepat, tanpa Hot Reload (untuk uji performa)
flutter run --release

Selama flutter run berjalan, terminal menerima tombol berikut:

TombolFungsi
rHot Reload: suntikkan perubahan kode, state dipertahankan
RHot Restart: jalankan ulang aplikasi dari main(), state direset
hTampilkan semua perintah yang tersedia
dDetach: lepas terminal tanpa menutup aplikasi
cBersihkan layar terminal
qQuit: hentikan aplikasi

4. Mengelola package: flutter pub

# Menambah package dari pub.dev (otomatis menulis ke pubspec.yaml + mengunduh)
flutter pub add http
flutter pub add provider

# Menambah package khusus pengembangan (masuk ke dev_dependencies)
flutter pub add dev:mocktail

# Menghapus package
flutter pub remove http

# Mengunduh ulang semua package sesuai pubspec.yaml (misal setelah git clone)
flutter pub get

# Melihat package yang punya versi lebih baru
flutter pub outdated

5. Memeriksa dan merapikan kode

# Cari error dan peringatan tanpa menjalankan aplikasi
flutter analyze

# Rapikan format (indentasi, spasi) seluruh file Dart di folder lib
dart format lib

# Jalankan semua test di folder test/
flutter test

6. Membersihkan dan memperbarui

# Hapus folder build/ dan cache proyek. Obat pertama untuk error build yang aneh.
flutter clean
flutter pub get

# Perbarui Flutter SDK ke versi stable terbaru
flutter upgrade

# Membuat berkas rilis (dibahas di Modul 16)
flutter build apk --release
