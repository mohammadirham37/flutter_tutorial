Dua fitur klasik yang cukup memakai akselerometer: deteksi guncangan (misalnya "guncang untuk melaporkan bug" atau "guncang untuk acak") dan waterpass digital yang menampilkan sudut kemiringan HP. Keduanya memakai sedikit matematika vektor yang akan dipakai lagi di kompas.

Deteksi guncangan

Saat HP diam, besar (panjang) vektor akselerometer kira-kira sama dengan gravitasi:

|a| = √(x² + y² + z²) ≈ 9,81 m/s²   →   gForce = |a| / 9,81 ≈ 1

Ayunan tangan biasa menghasilkan sekitar 1,2 sampai 2 g, sedangkan guncangan sengaja bisa melebihi 2,5 g. Karena kita memakai besar vektor, arah HP tidak berpengaruh. Aturan deteksinya:

  1. Hitung gForce dari setiap sampel mentah. Jangan memakai data yang sudah di-low-pass, karena puncak guncangan justru akan teredam.
  2. Jika gForce melewati ambang (misalnya 2,5), hitung sebagai guncangan.
  3. Abaikan puncak berikutnya selama jeda tertentu (misalnya 800 ms). Satu kali mengguncang menghasilkan beberapa puncak bolak-balik, dan kita ingin menghitungnya sebagai satu kejadian.

Pakai gameInterval (20 ms) agar puncak yang singkat tidak terlewat. Dengan normalInterval (200 ms), guncangan cepat bisa jatuh di antara dua sampel.

Waterpass: kemiringan dengan atan2

Saat HP diam, akselerometer hanya berisi gravitasi. Ketika HP dimiringkan, vektor 9,8 m/s² itu "terbagi" ke sumbu-sumbu lain. Misalnya, jika sisi kanan HP diangkat 30°, gravitasi terbagi menjadi x = 9,81 × sin 30° ≈ 4,9 dan z = 9,81 × cos 30° ≈ 8,5. Sudutnya didapat kembali dengan atan2:

sudutX (kiri-kanan) = atan2( x, √(y² + z²) )     > 0 berarti sisi kanan lebih tinggi
sudutY (atas-bawah) = atan2( y, √(x² + z²) )     > 0 berarti sisi atas lebih tinggi
total kemiringan    = acos( z / |a| )             0° = mendatar, 90° = tegak

Kenapa atan2, bukan asin(x / 9,81)? Karena atan2(y, x) memakai perbandingan dua komponen, sehingga hasilnya tetap benar walaupun besar gravitasi yang terbaca sedikit berbeda dari 9,81. Fungsi ini juga tidak pernah gagal karena pembagian dengan nol, dan selalu memberi kuadran yang tepat (rentang -180° sampai 180°). Hasilnya dalam radian, jadi dikali 180 / π untuk mendapat derajat.

Gelembung waterpass asli selalu bergerak ke sisi yang lebih tinggi. Jika sisi kanan terangkat (sudutX positif), gelembung bergeser ke kanan. Jika sisi atas terangkat (sudutY positif), gelembung naik. Ingat, sumbu y layar Flutter mengarah ke bawah, sehingga posisi vertikal gelembung memakai -sudutY.

/// Mendeteksi guncangan dari besar total percepatan (dalam satuan g).
class DeteksiGuncangan {
  DeteksiGuncangan({
    this.ambangG = 2.5,
    this.jeda = const Duration(milliseconds: 800),
  });

  final double ambangG; // diam = 1 g, guncangan keras > 2,5 g
  final Duration jeda; // satu guncangan tidak dihitung berkali-kali
  DateTime? _terakhir;

  bool proses(double x, double y, double z, DateTime waktu) {
    final gForce = math.sqrt(x * x + y * y + z * z) / 9.81;
    if (gForce < ambangG) return false;
    final terakhir = _terakhir;
    if (terakhir != null && waktu.difference(terakhir) < jeda) return false;
    _terakhir = waktu;
    return true;
  }
}

/// Sudut kemiringan dari akselerometer (perangkat diam).
/// sudutX > 0: sisi kanan terangkat. sudutY > 0: sisi atas terangkat.
({double sudutX, double sudutY}) hitungKemiringan(
  double x,
  double y,
  double z,
) {
  const keDerajat = 180 / math.pi;
  final sudutX = math.atan2(x, math.sqrt(y * y + z * z)) * keDerajat;
  final sudutY = math.atan2(y, math.sqrt(x * x + z * z)) * keDerajat;
  return (sudutX: sudutX, sudutY: sudutY);
}

class GuncangWaterpassPage extends StatefulWidget {
  const GuncangWaterpassPage({super.key});

  @override
  State<GuncangWaterpassPage> createState() => _GuncangWaterpassPageState();
}

class _GuncangWaterpassPageState extends State<GuncangWaterpassPage> {
  StreamSubscription<AccelerometerEvent>? _langganan;
  final _detektor = DeteksiGuncangan();
  int _jumlahGuncangan = 0;
  double _sudutX = 0;
  double _sudutY = 0;
  String? _error;

  @override
  void initState() {
    super.initState();
    _langganan =
        accelerometerEventStream(samplingPeriod: SensorInterval.gameInterval)
            .listen(
              _olah,
              onError: (Object e) {
                if (mounted) setState(() => _error = e.toString());
              },
              cancelOnError: true,
            );
  }

  void _olah(AccelerometerEvent e) {
    final terguncang = _detektor.proses(e.x, e.y, e.z, DateTime.now());
    final k = hitungKemiringan(e.x, e.y, e.z);
    setState(() {
      if (terguncang) _jumlahGuncangan++;
      // low-pass sederhana supaya gelembung tidak gemetar
      _sudutX += 0.2 * (k.sudutX - _sudutX);
      _sudutY += 0.2 * (k.sudutY - _sudutY);
    });
  }

  @override
  void dispose() {
    _langganan?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    if (_error != null) {
      return Scaffold(body: Center(child: Text('Sensor error: $_error')));
    }
    final datar = _sudutX.abs() < 1 && _sudutY.abs() < 1;
    // Gelembung bergerak ke sisi yang lebih TINGGI, dibatasi ±20°
    final posisi = Alignment(
      (_sudutX / 20).clamp(-1.0, 1.0),
      (-_sudutY / 20).clamp(-1.0, 1.0), // sumbu y layar mengarah ke bawah
    );

    return Scaffold(
      appBar: AppBar(title: const Text('Guncang & Waterpass')),
      body: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          children: [
            Text(
              'Guncangan terdeteksi: $_jumlahGuncangan',
              style: Theme.of(context).textTheme.titleLarge,
            ),
            const SizedBox(height: 32),
            Container(
              width: 240,
              height: 240,
              decoration: BoxDecoration(
                shape: BoxShape.circle,
                color: (datar ? Colors.green : Colors.orange).withValues(
                  alpha: 0.15,
                ),
                border: Border.all(width: 2),
              ),
              child: AnimatedAlign(
                duration: const Duration(milliseconds: 100),
                alignment: posisi,
                child: Container(
                  width: 36,
                  height: 36,
                  decoration: BoxDecoration(
                    shape: BoxShape.circle,
                    color: datar ? Colors.green : Colors.orange,
                  ),
                ),
              ),
            ),
            const SizedBox(height: 24),
            Text('Kiri-kanan: ${_sudutX.toStringAsFixed(1)}°'),
            Text('Atas-bawah: ${_sudutY.toStringAsFixed(1)}°'),
            Text(
              datar ? 'DATAR' : 'Belum datar',
              style: Theme.of(context).textTheme.headlineSmall,
            ),
          ],
        ),
      ),
    );
  }
}
  • DeteksiGuncangan.proses mengembalikan true hanya sekali per guncangan berkat _terakhir dan jeda.
  • hitungKemiringan mengembalikan record Dart 3 ({double sudutX, double sudutY}), sehingga dua nilai bisa dikembalikan tanpa membuat class.
  • Sudut dihaluskan dengan low-pass sederhana (_sudutX += 0.2 * (baru - lama)) supaya gelembung tidak gemetar.
  • Alignment(dx, dy) menerima nilai -1 sampai 1. Sudut dibagi 20 lalu di-clamp, artinya gelembung menyentuh tepi lingkaran saat miring 20°.
  • AnimatedAlign membuat perpindahan gelembung terlihat mulus di antara dua sampel.

Mode tegak: meluruskan bingkai foto

Rumus di atas cocok untuk HP yang diletakkan mendatar. Untuk menempelkan sisi HP ke dinding atau bingkai foto (HP tegak, layar menghadap kamu), yang dicari adalah rotasi HP pada bidang layar. Rumusnya cukup memakai x dan y:

sudutTegak = atan2(x, y) × 180 / π      0° = tegak lurus sempurna

Saat HP tegak lurus, x ≈ 0 dan y ≈ 9,8, sehingga sudutnya 0°. Rumus ini tidak stabil jika HP hampir mendatar (x dan y sama-sama mendekati 0). Karena itu aplikasi waterpass sungguhan berganti mode berdasarkan total kemiringan.

⚠️ Kemiringan hanya valid saat HP diam

Rumus kemiringan mengasumsikan akselerometer hanya berisi gravitasi. Saat HP digerakkan, percepatan tangan ikut terbaca, sehingga sudut melonjak sesaat. Low-pass filter meredam efek ini. Untuk aplikasi presisi (misalnya stabilisasi kamera), sistem menggabungkan akselerometer dengan giroskop (sensor fusion). Itu di luar cakupan modul ini.
