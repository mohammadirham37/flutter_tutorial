Contoh-contoh sebelumnya menaruh langganan sensor di State sebuah widget. Untuk aplikasi yang lebih besar, kita pindahkan ke pola MVC GetX seperti di Modul 08: service membungkus sensors_plus, controller mengolah data dan menyimpan state .obs, dan view hanya menampilkan dengan Obx.

Langkah 1: Model dan utilitas

📄 lib/models/vektor3.dart

// lib/models/vektor3.dart
import 'dart:math' as math;

/// Satu pembacaan sensor tiga sumbu (x, y, z) yang tidak bergantung
/// pada package sensor tertentu.
class Vektor3 {
  const Vektor3(this.x, this.y, this.z);

  static const nol = Vektor3(0, 0, 0);

  final double x;
  final double y;
  final double z;

  /// Besar vektor: akar(x² + y² + z²).
  double get panjang => math.sqrt(x * x + y * y + z * z);
}

📄 lib/utils/filter_sensor.dart

// lib/utils/filter_sensor.dart
import '../models/vektor3.dart';

/// Low-pass filter untuk data tiga sumbu.
class LowPassVektor {
  LowPassVektor({this.alpha = 0.15});

  final double alpha; // 0..1, makin kecil makin halus
  Vektor3? _nilai;

  Vektor3 saring(Vektor3 baru) {
    final lama = _nilai;
    final hasil = lama == null
        ? baru
        : Vektor3(
            lama.x + alpha * (baru.x - lama.x),
            lama.y + alpha * (baru.y - lama.y),
            lama.z + alpha * (baru.z - lama.z),
          );
    _nilai = hasil;
    return hasil;
  }

  void reset() => _nilai = null;
}

/// Mendeteksi guncangan dari besar percepatan (termasuk gravitasi).
class DeteksiGuncangan {
  DeteksiGuncangan({
    this.ambangG = 2.5,
    this.jeda = const Duration(milliseconds: 800),
  });

  final double ambangG;
  final Duration jeda;
  DateTime? _terakhir;

  bool proses(Vektor3 aksel, [DateTime? waktu]) {
    final sekarang = waktu ?? DateTime.now();
    if (aksel.panjang / 9.81 < ambangG) return false;
    final terakhir = _terakhir;
    if (terakhir != null && sekarang.difference(terakhir) < jeda) return false;
    _terakhir = sekarang;
    return true;
  }
}

Kedua file ini hanya Dart murni. DeteksiGuncangan.proses menerima parameter waktu opsional supaya unit test bisa memberikan waktu buatan, tanpa harus benar-benar menunggu 800 ms.

Langkah 2: Service

📄 lib/services/sensor_service.dart

// lib/services/sensor_service.dart
import 'dart:async';

import 'package:flutter/services.dart';
import 'package:sensors_plus/sensors_plus.dart';

import '../models/vektor3.dart';

/// Error yang lebih ramah daripada PlatformException mentah.
class SensorTidakTersedia implements Exception {
  const SensorTidakTersedia(this.namaSensor, this.detail);

  final String namaSensor;
  final String detail;

  @override
  String toString() => '$namaSensor tidak tersedia ($detail)';
}

/// Satu-satunya kelas yang mengimpor sensors_plus.
class SensorService {
  // Konstanta periode supaya controller tidak perlu mengimpor sensors_plus.
  static const periodeUi = SensorInterval.uiInterval; // ~15 Hz
  static const periodeGame = SensorInterval.gameInterval; // 50 Hz

  Stream<Vektor3> akselerometer({Duration periode = periodeUi}) => _bungkus(
    'Akselerometer',
    accelerometerEventStream(samplingPeriod: periode)
        .map((e) => Vektor3(e.x, e.y, e.z)),
  );

  Stream<Vektor3> giroskop({Duration periode = periodeUi}) => _bungkus(
    'Giroskop',
    gyroscopeEventStream(samplingPeriod: periode)
        .map((e) => Vektor3(e.x, e.y, e.z)),
  );

  Stream<Vektor3> magnetometer({Duration periode = periodeUi}) => _bungkus(
    'Magnetometer',
    magnetometerEventStream(samplingPeriod: periode)
        .map((e) => Vektor3(e.x, e.y, e.z)),
  );

  /// Mengubah error platform menjadi SensorTidakTersedia.
  Stream<Vektor3> _bungkus(String nama, Stream<Vektor3> sumber) {
    return sumber.transform(
      StreamTransformer<Vektor3, Vektor3>.fromHandlers(
        handleError: (error, stackTrace, sink) {
          // Kode dari plugin: NO_SENSOR (Android), UNAVAILABLE (iOS)
          final detail = error is PlatformException
              ? error.code
              : error.toString();
          sink.addError(SensorTidakTersedia(nama, detail), stackTrace);
        },
      ),
    );
  }
}
  • Service mengembalikan Stream<Vektor3>, bukan AccelerometerEvent. Controller dan view tidak perlu tahu package sensor apa yang dipakai. Jika suatu saat diganti, cukup file ini yang berubah.
  • StreamTransformer.fromHandlers(handleError: ...) menangkap PlatformException dari plugin lalu meneruskan SensorTidakTersedia yang punya nama sensor dan pesan yang jelas.
  • Service tidak menyimpan langganan. Yang memanggil listen (controller) bertanggung jawab memanggil cancel.

Langkah 3: Controller

📄 lib/controllers/gerak_controller.dart

// lib/controllers/gerak_controller.dart
import 'dart:async';

// Hanya AppLifecycleListener yang diambil, bukan seluruh material.dart.
import 'package:flutter/widgets.dart' show AppLifecycleListener;
import 'package:get/get.dart';

import '../models/vektor3.dart';
import '../services/sensor_service.dart';
import '../utils/filter_sensor.dart';

class GerakController extends GetxController {
  GerakController(this._service);
  final SensorService _service;

  static const _jedaUi = Duration(milliseconds: 100);

  // State reaktif privat + getter publik
  final _aksel = Vektor3.nol.obs;
  final _giro = Vektor3.nol.obs;
  final _jumlahGuncangan = 0.obs;
  final _error = RxnString();
  final _aktif = false.obs;

  Vektor3 get aksel => _aksel.value;
  Vektor3 get giro => _giro.value;
  int get jumlahGuncangan => _jumlahGuncangan.value;
  String? get error => _error.value;
  bool get aktif => _aktif.value;

  final _filter = LowPassVektor(alpha: 0.2);
  final _detektor = DeteksiGuncangan();
  final _langganan = <StreamSubscription<Vektor3>>[];
  late final AppLifecycleListener _siklusHidup;
  bool _dijedaPengguna = false;
  DateTime _terakhirUi = DateTime.fromMillisecondsSinceEpoch(0);

  @override
  void onInit() {
    super.onInit();
    // Hentikan sensor saat aplikasi ke background, nyalakan lagi saat kembali.
    _siklusHidup = AppLifecycleListener(
      onPause: _berhenti,
      onResume: () {
        if (!_dijedaPengguna) _mulai();
      },
    );
    _mulai();
  }

  void _mulai() {
    if (_aktif.value) return;
    _error.value = null;
    _filter.reset();
    _langganan
      ..add(
        _service
            .akselerometer(periode: SensorService.periodeGame)
            .listen(_olahAksel, onError: _tanganiError, cancelOnError: true),
      )
      ..add(
        _service.giroskop().listen(
          (v) => _giro.value = v,
          onError: _tanganiError,
          cancelOnError: true,
        ),
      );
    _aktif.value = true;
  }

  void _berhenti() {
    for (final l in _langganan) {
      l.cancel();
    }
    _langganan.clear();
    _aktif.value = false;
  }

  void _olahAksel(Vektor3 mentah) {
    // Deteksi guncangan memakai data mentah (puncaknya jangan dihaluskan)
    if (_detektor.proses(mentah)) _jumlahGuncangan.value++;

    final halus = _filter.saring(mentah);
    final sekarang = DateTime.now();
    if (sekarang.difference(_terakhirUi) < _jedaUi) return; // throttle UI
    _terakhirUi = sekarang;
    _aksel.value = halus;
  }

  void _tanganiError(Object e) {
    _error.value = e.toString();
  }

  /// Dipanggil tombol Jeda/Lanjut di view.
  void aturJeda() {
    if (_aktif.value) {
      _dijedaPengguna = true;
      _berhenti();
    } else {
      _dijedaPengguna = false;
      _mulai();
    }
  }

  void resetGuncangan() => _jumlahGuncangan.value = 0;

  @override
  void onClose() {
    _berhenti(); // batalkan semua StreamSubscription
    _siklusHidup.dispose();
    super.onClose();
  }
}

Penjelasan bagian penting:

  • State privat + getter publik, sama seperti pola di Modul 08. RxnString adalah .obs yang boleh bernilai null.
  • _langganan menyimpan semua StreamSubscription. _berhenti() membatalkan semuanya dan mengosongkan list, sehingga _mulai() bisa dipanggil lagi dengan aman.
  • onClose() memanggil _berhenti(). GetX memanggil onClose saat controller dihapus dari memori (misalnya saat halaman yang memakai Get.put ditutup). Ini padanan dispose() pada StatefulWidget.
  • AppLifecycleListener (bawaan Flutter) memanggil onPause saat aplikasi masuk background dan onResume saat kembali. Sensor dimatikan selama aplikasi tidak terlihat. Listener ini juga harus di-dispose() di onClose.
  • _dijedaPengguna memastikan sensor tidak menyala sendiri saat aplikasi kembali ke foreground jika pengguna sebelumnya menekan Jeda.
  • Deteksi guncangan memakai data mentah, sedangkan tampilan memakai data hasil filter dengan throttle 100 ms.
  • Controller hanya mengimpor AppLifecycleListener dari flutter/widgets.dart (lewat show), bukan material.dart. Controller tetap tidak menyentuh widget, BuildContext, SnackBar, atau dialog.

📄 lib/views/gerak_view.dart

// lib/views/gerak_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/gerak_controller.dart';
import '../models/vektor3.dart';

class GerakView extends GetView<GerakController> {
  const GerakView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Monitor Gerak')),
      floatingActionButton: Obx(
        () => FloatingActionButton.extended(
          onPressed: controller.aturJeda,
          icon: Icon(controller.aktif ? Icons.pause : Icons.play_arrow),
          label: Text(controller.aktif ? 'Jeda' : 'Lanjut'),
        ),
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Obx(() {
            final error = controller.error;
            if (error == null) return const SizedBox.shrink();
            return Card(
              color: Theme.of(context).colorScheme.errorContainer,
              child: ListTile(
                leading: const Icon(Icons.sensors_off),
                title: Text(error),
              ),
            );
          }),
          Obx(
            () => _KartuVektor(
              judul: 'Akselerometer (dihaluskan)',
              satuan: 'm/s²',
              nilai: controller.aksel,
            ),
          ),
          Obx(
            () => _KartuVektor(
              judul: 'Giroskop',
              satuan: 'rad/s',
              nilai: controller.giro,
            ),
          ),
          Card(
            child: ListTile(
              leading: const Icon(Icons.vibration),
              title: const Text('Guncangan terdeteksi'),
              subtitle: const Text('Guncang HP dengan cepat'),
              trailing: Obx(
                () => Text(
                  '${controller.jumlahGuncangan}',
                  style: Theme.of(context).textTheme.headlineMedium,
                ),
              ),
              onLongPress: controller.resetGuncangan,
            ),
          ),
        ],
      ),
    );
  }
}

class _KartuVektor extends StatelessWidget {
  const _KartuVektor({
    required this.judul,
    required this.satuan,
    required this.nilai,
  });

  final String judul;
  final String satuan;
  final Vektor3 nilai;

  @override
  Widget build(BuildContext context) {
    String f(double v) => v.toStringAsFixed(2).padLeft(7);
    return Card(
      child: ListTile(
        title: Text(judul),
        subtitle: Text(
          'x:${f(nilai.x)}  y:${f(nilai.y)}  z:${f(nilai.z)}  $satuan',
          style: const TextStyle(fontFamily: 'monospace'),
        ),
      ),
    );
  }
}

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/gerak_controller.dart';
import 'services/sensor_service.dart';
import 'views/gerak_view.dart';

void main() {
  // Wajib sebelum Get.put: onInit controller memakai AppLifecycleListener.
  WidgetsFlutterBinding.ensureInitialized();
  Get.put(GerakController(SensorService()));
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      title: 'Monitor Gerak',
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const GerakView(),
    );
  }
}
  • GetView<GerakController> menyediakan properti controller yang otomatis memanggil Get.find.
  • Setiap Obx dibuat sekecil mungkin. Saat hanya jumlah guncangan yang berubah, kartu akselerometer tidak ikut dibangun ulang.
  • Kartu error hanya muncul jika controller.error tidak null. Sensor yang tersedia tetap berjalan.
  • WidgetsFlutterBinding.ensureInitialized() wajib dipanggil sebelum Get.put, karena onInit controller langsung berjalan dan AppLifecycleListener membutuhkan binding yang sudah siap.

⚠️ Kesalahan umum

  • Memanggil listen di dalam build() view. Setiap rebuild menambah satu langganan baru yang tidak pernah dibatalkan.
  • Lupa cancel di onClose, atau membuat controller dengan permanent: true sehingga onClose tidak pernah terpanggil sementara sensor terus berjalan.
  • Mengubah nilai .obs di setiap event 50 Hz. Hasilnya sama buruknya dengan setState berlebihan. Throttle tetap diperlukan.
  • Mengimpor sensors_plus di view atau controller. Biarkan hanya service yang tahu package tersebut.
