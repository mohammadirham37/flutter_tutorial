Sekarang rumus dari bagian 5 kita pakai untuk membuat kompas yang piringannya berputar mengikuti arah HP, lengkap dengan penanda arah kiblat sebagai pengembangan opsional. Kuncinya ada di Transform.rotate.

Ide utama: putar piringan berlawanan dengan heading

Pada kompas fisik, jarum selalu menunjuk utara sementara badan kompas ikut diputar tangan. Di layar HP, "badan kompas" adalah layar itu sendiri. Jadi yang perlu kita putar adalah piringan, dengan sudut negatif heading:

  • Heading 0° (sisi atas HP menghadap utara): piringan tidak diputar, huruf U di atas.
  • Heading 90° (HP menghadap timur): utara ada di sebelah kiri, maka piringan diputar -90° (berlawanan jarum jam) sehingga huruf U pindah ke kiri.

Transform.rotate(angle: ...) menerima sudut dalam radian, dan nilai positif berarti searah jarum jam di layar. Jadi rumusnya angle: -heading * pi / 180.

Transform.rotate(
  angle: -heading * math.pi / 180,
  child: const Icon(Icons.navigation, size: 120), // jarum utara
)

Untuk menaruh penanda tujuan (misalnya kiblat) di dalam piringan, putar penanda sebesar +bearing relatif terhadap piringan. Karena piringan sudah diputar -heading, penanda akan tampil di layar pada sudut bearing − heading. Itulah arah yang harus kamu hadapi.

📄 lib/main.dart

// lib/main.dart
import 'dart:async';
import 'dart:math' as math;

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:sensors_plus/sensors_plus.dart';

import 'utils/kompas_math.dart';

// Contoh koordinat titik asal. Ganti dengan koordinat kampusmu,
// atau ambil dari GPS seperti di Modul 19.
const double latAsal = -6.3628;
const double lonAsal = 106.8269;
const double latKabah = 21.4225;
const double lonKabah = 39.8262;
// Deklinasi magnetik lokasi (derajat, timur positif). Cari nilainya
// di kalkulator deklinasi NOAA untuk koordinat dan tanggal sekarang.
const double deklinasi = 0.0;

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  // Kunci potret: sumbu sensor tidak ikut berputar bersama layar.
  await SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp]);
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const KompasPage(),
    );
  }
}

class KompasPage extends StatefulWidget {
  const KompasPage({super.key});

  @override
  State<KompasPage> createState() => _KompasPageState();
}

class _KompasPageState extends State<KompasPage> {
  static const _alpha = 0.15; // kekuatan low-pass filter

  StreamSubscription<AccelerometerEvent>? _subAksel;
  StreamSubscription<MagnetometerEvent>? _subMagnet;
  List<double>? _a; // akselerometer yang sudah dihaluskan
  List<double>? _m; // magnetometer yang sudah dihaluskan

  double? _heading; // heading sejati (sudah + deklinasi)
  double _kuatMedan = 0; // µT
  String? _error;
  DateTime _terakhirGambar = DateTime.fromMillisecondsSinceEpoch(0);

  final double _kiblat = bearingDerajat(latAsal, lonAsal, latKabah, lonKabah);

  @override
  void initState() {
    super.initState();
    _subAksel =
        accelerometerEventStream(samplingPeriod: SensorInterval.uiInterval)
            .listen(
              (e) {
                _a = _haluskan(_a, [e.x, e.y, e.z]);
                _hitung();
              },
              onError: _tanganiError,
              cancelOnError: true,
            );
    _subMagnet =
        magnetometerEventStream(samplingPeriod: SensorInterval.uiInterval)
            .listen(
              (e) {
                _m = _haluskan(_m, [e.x, e.y, e.z]);
                _hitung();
              },
              onError: _tanganiError,
              cancelOnError: true,
            );
  }

  List<double> _haluskan(List<double>? lama, List<double> baru) {
    if (lama == null) return baru;
    return [for (var i = 0; i < 3; i++) lama[i] + _alpha * (baru[i] - lama[i])];
  }

  void _hitung() {
    final a = _a, m = _m;
    if (a == null || m == null) return; // tunggu kedua sensor mengirim data
    final magnetik = headingDerajat(a[0], a[1], a[2], m[0], m[1], m[2]);
    if (magnetik == null) return;

    final sekarang = DateTime.now();
    if (sekarang.difference(_terakhirGambar).inMilliseconds < 50) return;
    _terakhirGambar = sekarang;
    if (!mounted) return;
    setState(() {
      _heading = headingSejati(magnetik, deklinasi);
      _kuatMedan = math.sqrt(m[0] * m[0] + m[1] * m[1] + m[2] * m[2]);
    });
  }

  void _tanganiError(Object e) {
    if (!mounted) return;
    setState(() {
      _error = e is PlatformException ? (e.details ?? e.code).toString() : '$e';
    });
  }

  @override
  void dispose() {
    _subAksel?.cancel();
    _subMagnet?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final heading = _heading;
    final teks = Theme.of(context).textTheme;

    if (_error != null) {
      return Scaffold(
        appBar: AppBar(title: const Text('Kompas')),
        body: Center(child: Text('Kompas tidak bisa dipakai:\n$_error')),
      );
    }
    if (heading == null) {
      return const Scaffold(body: Center(child: CircularProgressIndicator()));
    }

    // Medan magnet bumi sekitar 25–65 µT. Di luar itu ada gangguan.
    final terganggu = _kuatMedan < 20 || _kuatMedan > 70;
    final keKiblat = selisihSudut(heading, _kiblat);
    final petunjuk = keKiblat.abs() < 3
        ? 'Sudah menghadap kiblat'
        : 'Putar ${keKiblat > 0 ? 'ke kanan' : 'ke kiri'} '
              '${keKiblat.abs().toStringAsFixed(0)}°';

    return Scaffold(
      appBar: AppBar(title: const Text('Kompas')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(
              '${heading.toStringAsFixed(0)}°  ${arahMataAngin(heading)}',
              style: teks.headlineMedium,
            ),
            const SizedBox(height: 8),
            const Icon(Icons.arrow_drop_down, size: 48), // arah sisi atas HP
            Transform.rotate(
              angle: -heading * math.pi / 180, // putar piringan berlawanan
              child: Piringan(kiblat: _kiblat),
            ),
            const SizedBox(height: 16),
            Text('Kiblat ${_kiblat.toStringAsFixed(1)}° dari utara'),
            Text(petunjuk, style: teks.titleMedium),
            Text(
              'Kuat medan: ${_kuatMedan.toStringAsFixed(1)} µT',
              style: TextStyle(color: terganggu ? Colors.red : null),
            ),
            if (terganggu)
              const Padding(
                padding: EdgeInsets.all(16),
                child: Text(
                  'Ada gangguan magnet. Jauhkan dari logam/magnet lalu '
                  'gerakkan HP membentuk angka 8.',
                  textAlign: TextAlign.center,
                ),
              ),
          ],
        ),
      ),
    );
  }
}

/// Piringan kompas: huruf U di atas, penanda kiblat di sudut [kiblat].
class Piringan extends StatelessWidget {
  const Piringan({super.key, required this.kiblat});

  final double kiblat;

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return Container(
      width: 260,
      height: 260,
      decoration: BoxDecoration(
        shape: BoxShape.circle,
        color: warna.primaryContainer.withValues(alpha: 0.4),
        border: Border.all(color: warna.primary, width: 3),
      ),
      child: Stack(
        children: [
          const Align(alignment: Alignment(0, -0.9), child: Text('U')),
          const Align(alignment: Alignment(0.9, 0), child: Text('T')),
          const Align(alignment: Alignment(0, 0.9), child: Text('S')),
          const Align(alignment: Alignment(-0.9, 0), child: Text('B')),
          // Jarum utara (merah) selalu menunjuk huruf U
          const Align(
            alignment: Alignment(0, -0.45),
            child: Icon(Icons.navigation, color: Colors.red, size: 40),
          ),
          // Penanda kiblat: diputar sebesar bearing kiblat dari utara
          Positioned.fill(
            child: Transform.rotate(
              angle: kiblat * math.pi / 180,
              child: const Align(
                alignment: Alignment(0, -0.65),
                child: Icon(Icons.mosque, color: Colors.green),
              ),
            ),
          ),
        ],
      ),
    );
  }
}

Penjelasan bagian penting:

  • SystemChrome.setPreferredOrientations mengunci layar ke potret. Ingat bagian 1: sumbu sensor tidak ikut berputar saat tampilan berpindah ke lanskap, sehingga piringan akan meleset 90° jika layar dibiarkan berputar. Pemanggilan ini memerlukan WidgetsFlutterBinding.ensureInitialized() lebih dulu.
  • Dua langganan, akselerometer dan magnetometer, masing-masing menyimpan nilai terakhir yang sudah dihaluskan di _a dan _m. _hitung() dipanggil dari keduanya, tetapi baru bekerja setelah kedua sensor pernah mengirim data.
  • Yang dihaluskan adalah vektor, bukan sudut. Menghaluskan sudut secara langsung bermasalah di batas 359° ke 0°: rata-rata 359° dan 1° akan menghasilkan 180°, arah yang berlawanan. Menghaluskan vektor a dan m lalu menghitung heading dari hasilnya tidak punya masalah ini.
  • Throttle 50 ms: piringan digambar ulang maksimal 20 kali per detik.
  • _kiblat dihitung sekali dengan bearingDerajat, karena titik asal dan Ka'bah tidak berubah. Jika titik asal diambil dari GPS (Modul 19), hitung ulang setiap kali lokasi berubah.
  • selisihSudut(heading, _kiblat) menentukan teks "Putar ke kanan/kiri". Toleransi 3° dianggap sudah menghadap kiblat.
  • Kuat medan di luar 20 sampai 70 µT ditampilkan merah beserta ajakan kalibrasi angka 8.
  • Penanda kiblat di Piringan memakai Positioned.fill + Transform.rotate + Align di dekat tepi atas. Memutar kotak seukuran piringan membuat ikon bergerak mengelilingi pusat, bukan berputar di tempat.

💡 Animasi rotasi dan masalah 359° → 0°

Jika ingin rotasi beranimasi dengan AnimatedRotation (parameter turns), hati-hati saat heading melompat dari 359° ke 1°. Animasi akan berputar hampir satu lingkaran penuh ke arah sebaliknya. Solusinya, simpan sudut kumulatif: sudutTampil += selisihSudut(sudutTampil, headingBaru), lalu pakai turns: -sudutTampil / 360. Dengan cara ini sudut boleh melewati 360 dan animasi selalu mengambil jalur terpendek.

⚠️ Kesalahan umum

  • Memutar piringan dengan +heading. Huruf U akan bergerak ke arah yang salah. Cek dengan memutar HP ke kanan: piringan harus berputar ke kiri.
  • Lupa mengubah derajat ke radian. Transform.rotate(angle: 90) berarti 90 radian, kira-kira 14 putaran.
  • Menganggap arah kiblat = 270° (barat). Dari Indonesia arah kiblat sekitar 290 sampai 295°, tergantung lokasi.
  • Mengabaikan deklinasi saat membandingkan dengan bearing dari peta. Heading magnetik harus diubah menjadi heading sejati dulu.
