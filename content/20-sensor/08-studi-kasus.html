Studi kasus ini menggabungkan semua yang sudah dipelajari menjadi satu aplikasi: Kompas & Waterpass Kampus. Tab Kompas menampilkan arah mata angin dengan kompensasi kemiringan, deklinasi yang bisa diatur, dan penunjuk arah ke tujuan (kiblat atau gedung kampus). Tab Waterpass menampilkan gelembung dan sudut kemiringan. Guncangan HP mengunci atau membuka kunci bacaan, berguna saat kamu ingin mencatat arah lalu menurunkan HP.

Langkah 2: Rumus waterpass

📄 lib/utils/waterpass_math.dart

// lib/utils/waterpass_math.dart
import 'dart:math' as math;

import '../models/vektor3.dart';

const double _keDerajat = 180 / math.pi;

/// Hasil perhitungan kemiringan perangkat dari akselerometer.
class Kemiringan {
  const Kemiringan({
    required this.sudutX,
    required this.sudutY,
    required this.total,
  });

  static const datarSempurna = Kemiringan(sudutX: 0, sudutY: 0, total: 0);

  /// > 0 berarti sisi kanan perangkat lebih tinggi.
  final double sudutX;

  /// > 0 berarti sisi atas perangkat lebih tinggi.
  final double sudutY;

  /// Sudut antara layar dan bidang datar (0° = mendatar, 90° = tegak).
  final double total;

  bool datar({double toleransi = 1.0}) =>
      sudutX.abs() < toleransi && sudutY.abs() < toleransi;
}

/// Hanya valid saat perangkat relatif diam (akselerometer ≈ gravitasi).
Kemiringan hitungKemiringan(Vektor3 a) {
  final panjang = a.panjang;
  if (panjang < 0.1) return Kemiringan.datarSempurna; // jatuh bebas
  final sudutX = math.atan2(a.x, math.sqrt(a.y * a.y + a.z * a.z));
  final sudutY = math.atan2(a.y, math.sqrt(a.x * a.x + a.z * a.z));
  final total = math.acos((a.z / panjang).clamp(-1.0, 1.0));
  return Kemiringan(
    sudutX: sudutX * _keDerajat,
    sudutY: sudutY * _keDerajat,
    total: total * _keDerajat,
  );
}

Rumusnya sama dengan bagian 4, kini dikemas dalam class Kemiringan dan ditambah total, yaitu sudut antara layar dan bidang datar. Nilai total dipakai kompas untuk memperingatkan pengguna jika HP terlalu miring. clamp(-1.0, 1.0) sebelum acos mencegah NaN akibat galat pembulatan (misalnya 1,0000001).

Langkah 3: Controller

Satu controller mengelola kedua tab karena keduanya memakai akselerometer yang sama. Jika dipisah menjadi dua controller yang masing-masing memanggil accelerometerEventStream, keduanya tetap berbagi satu stream di plugin (lihat bagian 2), jadi lebih jelas jika diurus di satu tempat.

📄 lib/controllers/orientasi_controller.dart

// lib/controllers/orientasi_controller.dart
import 'dart:async';

import 'package:flutter/widgets.dart' show AppLifecycleListener;
import 'package:get/get.dart';

import '../models/titik_tujuan.dart';
import '../models/vektor3.dart';
import '../services/sensor_service.dart';
import '../utils/filter_sensor.dart';
import '../utils/kompas_math.dart';
import '../utils/waterpass_math.dart';

class OrientasiController extends GetxController {
  OrientasiController(this._service);
  final SensorService _service;

  static const _jedaUi = Duration(milliseconds: 50); // UI maks 20x/detik

  // ---------- State reaktif ----------
  final _heading = RxnDouble(); // heading sejati, null = belum ada data
  final _kuatMedan = 0.0.obs; // µT
  final _kemiringan = Kemiringan.datarSempurna.obs;
  final _error = RxnString();
  final _dikunci = false.obs; // dikunci lewat guncangan
  final _deklinasi = 0.0.obs;
  final _tujuan = daftarTujuan.first.obs;
  final _tab = 0.obs;

  double? get heading => _heading.value;
  double get kuatMedan => _kuatMedan.value;
  Kemiringan get kemiringan => _kemiringan.value;
  String? get error => _error.value;
  bool get dikunci => _dikunci.value;
  double get deklinasi => _deklinasi.value;
  TitikTujuan get tujuan => _tujuan.value;
  int get tab => _tab.value;

  // ---------- Data turunan (getter) ----------
  /// Medan magnet bumi kira-kira 25–65 µT. Di luar rentang ini
  /// kemungkinan besar ada gangguan hard/soft iron.
  bool get perluKalibrasi => kuatMedan < 20 || kuatMedan > 70;

  /// Heading hanya akurat jika HP dipegang mendatar.
  bool get terlaluMiring => kemiringan.total > 35;

  double get bearingTujuan =>
      bearingDerajat(titikKampus.lat, titikKampus.lon, tujuan.lat, tujuan.lon);

  /// Negatif = belok kiri, positif = belok kanan.
  double? get selisihKeTujuan {
    final h = heading;
    return h == null ? null : selisihSudut(h, bearingTujuan);
  }

  String get arah => heading == null ? '-' : arahMataAngin(heading!);

  // ---------- Internal ----------
  final _filterAksel = LowPassVektor(alpha: 0.15);
  final _filterMagnet = LowPassVektor(alpha: 0.15);
  final _detektor = DeteksiGuncangan();
  final _langganan = <StreamSubscription<Vektor3>>[];
  late final AppLifecycleListener _siklusHidup;
  Vektor3? _a;
  Vektor3? _m;
  DateTime _terakhirUi = DateTime.fromMillisecondsSinceEpoch(0);

  @override
  void onInit() {
    super.onInit();
    _siklusHidup = AppLifecycleListener(onPause: _berhenti, onResume: _mulai);
    _mulai();
  }

  void _mulai() {
    if (_langganan.isNotEmpty) return; // sudah berjalan
    _error.value = null;
    _filterAksel.reset();
    _filterMagnet.reset();
    _langganan
      ..add(
        _service
            .akselerometer(periode: SensorService.periodeGame)
            .listen(_olahAksel, onError: _tanganiError, cancelOnError: true),
      )
      ..add(
        _service
            .magnetometer(periode: SensorService.periodeGame)
            .listen(_olahMagnet, onError: _tanganiError, cancelOnError: true),
      );
  }

  void _berhenti() {
    for (final l in _langganan) {
      l.cancel();
    }
    _langganan.clear();
  }

  void _olahAksel(Vektor3 mentah) {
    if (_detektor.proses(mentah)) {
      _dikunci.toggle(); // guncang = kunci / buka kunci bacaan
      return; // sampel guncangan jangan masuk filter
    }
    _a = _filterAksel.saring(mentah);
    _perbaruiUi();
  }

  void _olahMagnet(Vektor3 mentah) {
    _m = _filterMagnet.saring(mentah);
    _perbaruiUi();
  }

  void _perbaruiUi() {
    final a = _a, m = _m;
    if (a == null || _dikunci.value) return;

    final sekarang = DateTime.now();
    if (sekarang.difference(_terakhirUi) < _jedaUi) return;
    _terakhirUi = sekarang;

    _kemiringan.value = hitungKemiringan(a);
    if (m == null) return; // waterpass tetap jalan tanpa magnetometer
    _kuatMedan.value = m.panjang;
    final magnetik = headingDerajat(a.x, a.y, a.z, m.x, m.y, m.z);
    if (magnetik != null) {
      _heading.value = headingSejati(magnetik, _deklinasi.value);
    }
  }

  void _tanganiError(Object e) => _error.value = e.toString();

  // ---------- Aksi dari view ----------
  void pilihTab(int i) => _tab.value = i;
  void pilihTujuan(TitikTujuan t) => _tujuan.value = t;
  void bukaKunci() => _dikunci.value = false;
  void aturDeklinasi(double nilai) => _deklinasi.value = nilai;

  @override
  void onClose() {
    _berhenti();
    _siklusHidup.dispose();
    super.onClose();
  }
}
  • Data turunan sebagai getter: perluKalibrasi, terlaluMiring, bearingTujuan, selisihKeTujuan, dan arah dihitung dari state yang ada, bukan disimpan terpisah. Karena getter ini membaca nilai .obs, Obx yang memanggilnya tetap reaktif.
  • _olahAksel: sampel yang memicu guncangan dipakai untuk _dikunci.toggle() lalu dibuang dengan return, supaya lonjakan guncangan tidak mengacaukan filter.
  • _perbaruiUi: berhenti jika bacaan dikunci. Waterpass tetap diperbarui walaupun magnetometer tidak ada (m == null). HP tanpa kompas tetap bisa memakai tab Waterpass.
  • Deklinasi ditambahkan ke heading magnetik melalui headingSejati sebelum disimpan, sehingga semua perhitungan setelahnya (arah mata angin, selisih ke tujuan) memakai utara sejati.
  • Siklus hidup: AppLifecycleListener mematikan sensor saat aplikasi ke background. _mulai() aman dipanggil berulang karena memeriksa _langganan.isNotEmpty. onClose membatalkan semua langganan dan membuang listener.

// lib/views/widgets/piringan_kompas.dart
import 'dart:math' as math;

import 'package:flutter/material.dart';

/// Piringan kompas yang diputar sebesar -heading sehingga huruf U
/// selalu menunjuk utara. Penanda tujuan diletakkan pada [bearingTujuan].
class PiringanKompas extends StatelessWidget {
  const PiringanKompas({
    super.key,
    required this.heading,
    required this.bearingTujuan,
    this.ukuran = 280,
  });

  final double heading;
  final double bearingTujuan;
  final double ukuran;

  static double _rad(double derajat) => derajat * math.pi / 180;

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        // Penanda tetap: arah sisi atas HP
        Icon(Icons.arrow_drop_down, size: 48, color: warna.primary),
        Transform.rotate(
          angle: _rad(-heading),
          child: Container(
            width: ukuran,
            height: ukuran,
            decoration: BoxDecoration(
              shape: BoxShape.circle,
              color: warna.surfaceContainerHighest,
              border: Border.all(color: warna.outline, width: 2),
            ),
            child: Stack(
              children: [
                for (final (label, sudut) in const [
                  ('U', 0.0),
                  ('T', 90.0),
                  ('S', 180.0),
                  ('B', 270.0),
                ])
                  Positioned.fill(
                    child: Transform.rotate(
                      angle: _rad(sudut),
                      child: Align(
                        alignment: const Alignment(0, -0.88),
                        child: Text(
                          label,
                          style: TextStyle(
                            fontSize: 22,
                            fontWeight: FontWeight.bold,
                            color: label == 'U' ? Colors.red : null,
                          ),
                        ),
                      ),
                    ),
                  ),
                const Center(
                  child: Icon(Icons.navigation, size: 72, color: Colors.red),
                ),
                Positioned.fill(
                  child: Transform.rotate(
                    angle: _rad(bearingTujuan),
                    child: Align(
                      alignment: const Alignment(0, -0.62),
                      child: Icon(Icons.place, size: 36, color: warna.tertiary),
                    ),
                  ),
                ),
              ],
            ),
          ),
        ),
      ],
    );
  }
}

Huruf U, T, S, B diletakkan dengan pola yang sama seperti penanda kiblat di bagian 6: kotak seukuran piringan diputar sebesar sudut arahnya, lalu huruf diletakkan di dekat tepi atas kotak itu. Loop for (final (label, sudut) in ...) memakai destructuring record Dart 3. Penanda tujuan (Icons.place) diputar sebesar bearingTujuan, sehingga di layar ia tampil pada sudut bearing − heading.

// lib/views/kompas_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/orientasi_controller.dart';
import '../models/titik_tujuan.dart';
import 'widgets/piringan_kompas.dart';

class KompasView extends GetView<OrientasiController> {
  const KompasView({super.key});

  @override
  Widget build(BuildContext context) {
    final teks = Theme.of(context).textTheme;
    return Obx(() {
      final heading = controller.heading;
      if (heading == null) {
        return const Center(child: Text('Menunggu data magnetometer...'));
      }
      final selisih = controller.selisihKeTujuan ?? 0;
      final petunjuk = selisih.abs() < 5
          ? 'Lurus ke depan'
          : 'Putar ${selisih > 0 ? 'kanan' : 'kiri'} '
                '${selisih.abs().toStringAsFixed(0)}°';

      return ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Text(
            '${heading.toStringAsFixed(0)}° ${controller.arah}',
            textAlign: TextAlign.center,
            style: teks.displaySmall,
          ),
          if (controller.dikunci)
            Center(
              child: ActionChip(
                avatar: const Icon(Icons.lock),
                label: const Text('Bacaan dikunci (guncang/tap untuk buka)'),
                onPressed: controller.bukaKunci,
              ),
            ),
          const SizedBox(height: 8),
          Center(
            child: PiringanKompas(
              heading: heading,
              bearingTujuan: controller.bearingTujuan,
            ),
          ),
          const SizedBox(height: 16),
          DropdownButtonFormField<TitikTujuan>(
            initialValue: controller.tujuan,
            decoration: const InputDecoration(
              labelText: 'Tujuan',
              border: OutlineInputBorder(),
            ),
            items: [
              for (final t in daftarTujuan)
                DropdownMenuItem(value: t, child: Text(t.nama)),
            ],
            onChanged: (t) {
              if (t != null) controller.pilihTujuan(t);
            },
          ),
          ListTile(
            leading: const Icon(Icons.place),
            title: Text(
              '${controller.tujuan.nama}: '
              '${controller.bearingTujuan.toStringAsFixed(1)}°',
            ),
            subtitle: Text(petunjuk),
          ),
          ListTile(
            leading: const Icon(Icons.explore),
            title: Text(
              'Deklinasi: '
              '${controller.deklinasi.toStringAsFixed(1)}° (timur +)',
            ),
            subtitle: Slider(
              value: controller.deklinasi,
              min: -10,
              max: 10,
              divisions: 40,
              onChanged: controller.aturDeklinasi,
            ),
          ),
          if (controller.terlaluMiring)
            const _Peringatan(
              ikon: Icons.screen_rotation_alt,
              pesan: 'Pegang HP mendatar agar arah kompas akurat.',
            ),
          if (controller.perluKalibrasi)
            _Peringatan(
              ikon: Icons.all_inclusive,
              pesan:
                  'Kuat medan ${controller.kuatMedan.toStringAsFixed(0)} µT '
                  'tidak wajar. Jauhkan dari logam/magnet, lalu gerakkan HP '
                  'membentuk angka 8 beberapa kali.',
            ),
        ],
      );
    });
  }
}

class _Peringatan extends StatelessWidget {

// lib/views/waterpass_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/orientasi_controller.dart';

class WaterpassView extends GetView<OrientasiController> {
  const WaterpassView({super.key});

  static const _batasSudut = 15.0; // gelembung mentok di tepi pada 15°

  @override
  Widget build(BuildContext context) {
    final teks = Theme.of(context).textTheme;
    return Obx(() {
      final k = controller.kemiringan;
      final datar = k.datar();
      final warna = datar ? Colors.green : Colors.orange;
      // Gelembung bergerak ke sisi yang lebih tinggi.
      final posisi = Alignment(
        (k.sudutX / _batasSudut).clamp(-1.0, 1.0),
        (-k.sudutY / _batasSudut).clamp(-1.0, 1.0),
      );

      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(
              datar ? 'DATAR' : 'MIRING',
              style: teks.displaySmall?.copyWith(color: warna),
            ),
            const SizedBox(height: 24),
            Container(
              width: 260,
              height: 260,
              decoration: BoxDecoration(
                shape: BoxShape.circle,
                color: warna.withValues(alpha: 0.12),
                border: Border.all(color: warna, width: 3),
              ),
              child: Stack(
                children: [
                  // Lingkaran target di tengah
                  Center(
                    child: Container(
                      width: 52,
                      height: 52,
                      decoration: BoxDecoration(
                        shape: BoxShape.circle,
                        border: Border.all(color: warna),
                      ),
                    ),
                  ),
                  AnimatedAlign(
                    duration: const Duration(milliseconds: 80),
                    alignment: posisi,
                    child: Container(
                      width: 44,
                      height: 44,
                      decoration: BoxDecoration(
                        shape: BoxShape.circle,
                        color: warna.withValues(alpha: 0.8),
                      ),
                    ),
                  ),
                ],
              ),
            ),

            Text(
              'Kiri-kanan: ${k.sudutX.toStringAsFixed(1)}°',
              style: teks.titleMedium,

            Text(
              'Atas-bawah: ${k.sudutY.toStringAsFixed(1)}°',
              style: teks.titleMedium,

            Text('Total kemiringan: ${k.total.toStringAsFixed(1)}°'),
          ],
        ),
      );
    });
  }
}

Cara mencoba

  1. Jalankan di HP fisik. Letakkan HP mendatar di lantai yang jauh dari meja besi, lalu putar perlahan. Bandingkan dengan aplikasi kompas bawaan HP atau Google Maps. Selisih beberapa derajat masih wajar.
  2. Dekatkan HP ke speaker atau magnet kulkas. Kuat medan melonjak dan peringatan kalibrasi muncul. Jauhkan lagi lalu lakukan gerakan angka 8.
  3. Pilih tujuan "Kiblat" dan putar badan sampai teks berubah menjadi "Lurus ke depan".
  4. Guncang HP: chip "Bacaan dikunci" muncul dan angka berhenti berubah. Guncang lagi atau ketuk chip untuk membuka kunci.
