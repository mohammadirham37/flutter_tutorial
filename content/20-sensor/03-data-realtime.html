Data sensor mentah selalu "gemetar". Tangan tidak pernah benar-benar diam, dan sensor MEMS di HP punya derau (noise) bawaan. Selain itu, data datang jauh lebih sering daripada yang perlu digambar di layar. Bagian ini membahas dua teknik dasar: low-pass filter untuk menghaluskan nilai dan throttle untuk membatasi rebuild UI.

Low-pass filter sederhana

Low-pass filter meloloskan perubahan yang lambat (misalnya kemiringan HP) dan meredam perubahan yang cepat (getaran). Bentuk paling sederhana adalah exponential moving average:

nilaiHalus = nilaiHalus + alpha × (nilaiBaru − nilaiHalus)      dengan 0 < alpha ≤ 1
  • alpha = 1: tidak ada penghalusan, sama dengan data mentah.
  • alpha = 0,1: sangat halus, tetapi butuh beberapa puluh sampel untuk mengejar perubahan. Pada 50 Hz, itu berarti jeda sekitar setengah detik.
  • Nilai 0,1 sampai 0,25 biasanya cukup untuk kompas dan waterpass. Pilih lewat percobaan.

Hal sebaliknya, high-pass filter (mentah − halus), menyisakan perubahan cepat saja. Inilah ide dasar cara sistem memisahkan gravitasi dari gerakan pengguna.

Throttle UI

Memanggil setState 50 kali per detik untuk setiap sensor membuat Flutter membangun ulang widget jauh lebih sering dari yang bisa dilihat mata. Polanya:

  1. Simpan nilai terbaru di variabel biasa setiap kali event datang. Filter tetap memproses setiap sampel.
  2. Panggil setState hanya jika sudah lewat, misalnya, 100 ms sejak gambar terakhir.

Dengan begitu, laju pengambilan data (samplingPeriod) dan laju gambar UI bisa diatur terpisah.

Contoh lengkap: dashboard semua sensor

Aplikasi berikut menampilkan lima sensor sekaligus, membandingkan akselerometer mentah dengan hasil low-pass, membatasi UI maksimal 10 kali per detik, dan menandai sensor yang tidak tersedia tanpa membuat sensor lain berhenti.

📄 lib/main.dart

// lib/main.dart
import 'dart:async';

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:sensors_plus/sensors_plus.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const DashboardSensorPage(),
    );
  }
}

/// Low-pass filter: setiap sampel baru hanya "menarik" nilai lama
/// sebesar alpha (0..1). Makin kecil alpha, makin halus tapi makin lambat.
class LowPassFilter {
  LowPassFilter({this.alpha = 0.15});

  final double alpha;
  List<double>? _nilai;

  List<double> saring(List<double> baru) {
    final lama = _nilai;
    if (lama == null) {
      _nilai = List.of(baru); // sampel pertama dipakai apa adanya
    } else {
      for (var i = 0; i < baru.length; i++) {
        lama[i] = lama[i] + alpha * (baru[i] - lama[i]);
      }
    }
    return List.unmodifiable(_nilai!);
  }
}

class DashboardSensorPage extends StatefulWidget {
  const DashboardSensorPage({super.key});

  @override
  State<DashboardSensorPage> createState() => _DashboardSensorPageState();
}

class _DashboardSensorPageState extends State<DashboardSensorPage> {
  static const _periode = SensorInterval.gameInterval; // 20 ms = 50 Hz
  static const _jedaUi = Duration(milliseconds: 100); // UI maks 10x/detik

  final _langganan = <StreamSubscription<dynamic>>[];
  final _filterAksel = LowPassFilter(alpha: 0.1);

  // Nilai terbaru disimpan di variabel biasa (bukan langsung setState)
  List<double> _akselMentah = const [0, 0, 0];
  List<double> _akselHalus = const [0, 0, 0];
  List<double> _userAksel = const [0, 0, 0];
  List<double> _giro = const [0, 0, 0];
  List<double> _magnet = const [0, 0, 0];
  double? _tekanan;
  final _error = <String, String>{};

  DateTime _terakhirGambar = DateTime.fromMillisecondsSinceEpoch(0);

  @override
  void initState() {
    super.initState();
    _dengar(
      'Akselerometer',
      accelerometerEventStream(samplingPeriod: _periode),
      (AccelerometerEvent e) {
        _akselMentah = [e.x, e.y, e.z];
        _akselHalus = _filterAksel.saring(_akselMentah);
      },
    );
    _dengar(
      'User akselerometer',
      userAccelerometerEventStream(samplingPeriod: _periode),
      (UserAccelerometerEvent e) => _userAksel = [e.x, e.y, e.z],
    );
    _dengar(
      'Giroskop',
      gyroscopeEventStream(samplingPeriod: _periode),
      (GyroscopeEvent e) => _giro = [e.x, e.y, e.z],
    );
    _dengar(
      'Magnetometer',
      magnetometerEventStream(samplingPeriod: _periode),
      (MagnetometerEvent e) => _magnet = [e.x, e.y, e.z],
    );
    _dengar(
      'Barometer',
      barometerEventStream(),
      (BarometerEvent e) => _tekanan = e.pressure,
    );
  }

  /// Mendengarkan satu stream sensor, mencatat error, dan
  /// menggambar ulang UI paling sering setiap [_jedaUi].
  void _dengar<T>(String nama, Stream<T> stream, void Function(T) simpan) {
    _langganan.add(
      stream.listen(
        (event) {
          simpan(event);
          _gambarUlangJikaPerlu();
        },
        onError: (Object e) {
          if (!mounted) return;
          setState(() {
            _error[nama] = e is PlatformException ? e.code : e.toString();
          });
        },
        cancelOnError: true,
      ),
    );
  }

  void _gambarUlangJikaPerlu() {
    final sekarang = DateTime.now();
    if (sekarang.difference(_terakhirGambar) < _jedaUi) return;
    _terakhirGambar = sekarang;
    if (mounted) setState(() {});
  }

  @override
  void dispose() {
    for (final l in _langganan) {
      l.cancel();
    }
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Dashboard Sensor')),
      body: ListView(
        padding: const EdgeInsets.all(12),
        children: [
          _kartu('Akselerometer (mentah)', 'm/s²', _akselMentah),
          _kartu('Akselerometer (low-pass)', 'm/s²', _akselHalus),
          _kartu('User akselerometer', 'm/s²', _userAksel),
          _kartu('Giroskop', 'rad/s', _giro),
          _kartu('Magnetometer', 'µT', _magnet),
          Card(
            child: ListTile(
              title: const Text('Barometer'),
              subtitle: Text(
                _error['Barometer'] != null
                    ? 'Tidak tersedia (${_error['Barometer']})'
                    : _tekanan == null
                    ? 'Menunggu data...'
                    : '${_tekanan!.toStringAsFixed(1)} hPa',
              ),
            ),
          ),
        ],
      ),
    );
  }

  Widget _kartu(String judul, String satuan, List<double> v) {
    final namaSensor = judul.split(' (').first;
    final error = _error[namaSensor];
    return Card(
      child: ListTile(
        title: Text(judul),
        subtitle: Text(
          error != null
              ? 'Tidak tersedia ($error)'
              : 'x: ${v[0].toStringAsFixed(2)}   '
                    'y: ${v[1].toStringAsFixed(2)}   '
                    'z: ${v[2].toStringAsFixed(2)}  $satuan',
          style: const TextStyle(fontFeatures: [FontFeature.tabularFigures()]),
        ),
      ),
    );
  }
}

Penjelasan bagian penting:

  • LowPassFilter menyimpan nilai halus terakhir. Sampel pertama langsung dipakai apa adanya supaya filter tidak "merangkak" dari nol.
  • _dengar<T> adalah fungsi generik yang memasang listen untuk stream bertipe apa pun dan memasukkan StreamSubscription ke satu list. Di dispose semua langganan dibatalkan dalam satu loop.
  • Callback simpan hanya mengisi variabel. Yang memicu rebuild adalah _gambarUlangJikaPerlu(), yang menolak setState jika belum 100 ms sejak gambar terakhir.
  • mounted dicek sebelum setState karena event bisa datang tepat saat halaman sedang ditutup.
  • Error dicatat per sensor di Map _error. Di emulator yang tidak punya barometer, hanya kartu barometer yang menampilkan "Tidak tersedia".
  • FontFeature.tabularFigures() membuat lebar setiap digit sama, sehingga angka tidak bergeser-geser saat nilainya berubah.

Saat HP diletakkan di meja, perhatikan bahwa digit terakhir akselerometer mentah terus berubah, sedangkan nilai low-pass hampir diam. Ketuk meja pelan-pelan: nilai mentah melonjak, nilai halus hanya bergeser sedikit.

💡 Pakai timestamp untuk perhitungan berbasis waktu

Setiap event membawa timestamp dari platform. Untuk perhitungan yang bergantung selang waktu (misalnya mengintegrasikan giroskop menjadi sudut: sudut += kecepatanSudut × Δt), pakai selisih timestamp antar-event, bukan menganggap interval selalu sama dengan samplingPeriod. Interval yang sebenarnya bisa berbeda dari yang diminta.

⚠️ Kesalahan umum

  • Memanggil setState di setiap event dari banyak sensor dengan gameInterval. UI jadi tersendat dan baterai cepat habis.
  • Menghaluskan data dengan alpha sangat kecil lalu heran kenapa tampilannya "telat". Low-pass filter selalu menukar kehalusan dengan keterlambatan.
  • Membiarkan satu onError menghentikan seluruh layar. Tangani error per sensor.
