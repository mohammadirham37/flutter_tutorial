Fitur pencarian membuat daftar panjang mudah dipakai. Kuncinya sederhana: jangan ubah data asli. Simpan kata kunci di State, lalu hitung daftar yang ditampilkan dari data asli setiap kali build.

Konsep

  1. _semua: data asli, tidak pernah dikurangi oleh pencarian.
  2. _kataKunci: diperbarui oleh onChanged TextField + setState.
  3. Daftar tampil = _semua.where(...) berdasarkan kata kunci.

Contoh kecil

final List<String> _semua = ['Algoritma', 'Basis Data', 'Kalkulus', 'Jaringan'];
String _kataKunci = '';

@override
Widget build(BuildContext context) {
  // Data yang DITAMPILKAN dihitung ulang setiap build dari data asli
  final hasil = _semua
      .where((m) => m.toLowerCase().contains(_kataKunci.toLowerCase()))
      .toList();

  return Column(
    children: [
      TextField(
        decoration: const InputDecoration(hintText: 'Cari...'),
        onChanged: (teks) => setState(() => _kataKunci = teks),
      ),
      Expanded(
        child: ListView.builder(
          itemCount: hasil.length,
          itemBuilder: (context, i) => ListTile(title: Text(hasil[i])),
        ),
      ),
    ],
  );
}
Mengetik "da" menyisakan Basis Data

toLowerCase() pada kedua sisi membuat pencarian tidak membedakan huruf besar dan kecil.

Contoh lengkap: direktori dosen dengan pencarian dan filter

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const DirektoriDosenScreen(),
    );
  }
}

class Dosen {
  final String nama;
  final String bidang;
  final bool tersedia;

  const Dosen(this.nama, this.bidang, this.tersedia);
}

class DirektoriDosenScreen extends StatefulWidget {
  const DirektoriDosenScreen({super.key});

  @override
  State<DirektoriDosenScreen> createState() => _DirektoriDosenScreenState();
}

class _DirektoriDosenScreenState extends State<DirektoriDosenScreen> {
  static const _semuaDosen = [
    Dosen('Dr. Bambang Susilo', 'Kecerdasan Buatan', true),
    Dosen('Nadia Fitri, M.T.', 'Rekayasa Perangkat Lunak', false),
    Dosen('Irham Akbar, M.Cs.', 'Pemrograman Mobile', true),
    Dosen('Prof. Hartono', 'Kecerdasan Buatan', false),
    Dosen('Eko Prasetyo, Ph.D.', 'Keamanan Siber', true),
    Dosen('Sari Wulandari, M.Kom.', 'Basis Data', true),
    Dosen('Andi Wijaya, M.T.', 'Jaringan Komputer', false),
    Dosen('Rina Kartika, M.Sc.', 'Data Science', true),
  ];

  final _cariController = TextEditingController();
  String _kataKunci = '';
  String _bidang = 'Semua';
  bool _hanyaTersedia = false;

  @override
  void dispose() {
    _cariController.dispose();
    super.dispose();
  }

  List<Dosen> get _hasilFilter {
    final kunci = _kataKunci.toLowerCase().trim();
    return _semuaDosen.where((d) {
      final cocokTeks = d.nama.toLowerCase().contains(kunci) ||
          d.bidang.toLowerCase().contains(kunci);
      final cocokBidang = _bidang == 'Semua' || d.bidang == _bidang;
      final cocokStatus = !_hanyaTersedia || d.tersedia;
      return cocokTeks && cocokBidang && cocokStatus;
    }).toList();
  }

  @override
  Widget build(BuildContext context) {
    final hasil = _hasilFilter;
    final daftarBidang = ['Semua', ..._semuaDosen.map((d) => d.bidang).toSet()];

    return Scaffold(
      appBar: AppBar(title: const Text('Direktori Dosen')),
      body: Column(
        children: [
          // 1. Kolom pencarian
          Padding(
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 0),
            child: TextField(
              controller: _cariController,
              decoration: InputDecoration(
                hintText: 'Cari nama atau bidang...',
                prefixIcon: const Icon(Icons.search),
                border: const OutlineInputBorder(),
                suffixIcon: _kataKunci.isEmpty
                    ? null
                    : IconButton(
                        icon: const Icon(Icons.clear),
                        onPressed: () {
                          _cariController.clear();
                          setState(() => _kataKunci = '');
                        },
                      ),
              ),
              onChanged: (teks) => setState(() => _kataKunci = teks),
            ),
          ),

          // 2. Filter bidang dengan ChoiceChip (gulir horizontal)
          SingleChildScrollView(
            scrollDirection: Axis.horizontal,
            padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
            child: Row(
              children: [
                for (final b in daftarBidang)
                  Padding(
                    padding: const EdgeInsets.symmetric(horizontal: 4),
                    child: ChoiceChip(
                      label: Text(b),
                      selected: _bidang == b,
                      onSelected: (_) => setState(() => _bidang = b),
                    ),
                  ),
              ],
            ),
          ),

          // 3. Filter status
          SwitchListTile(
            dense: true,
            title: const Text('Hanya dosen yang tersedia untuk bimbingan'),
            value: _hanyaTersedia,
            onChanged: (v) => setState(() => _hanyaTersedia = v),
          ),
          Padding(
            padding: const EdgeInsets.symmetric(horizontal: 16),
            child: Align(
              alignment: Alignment.centerLeft,
              child: Text('${hasil.length} dari ${_semuaDosen.length} dosen'),
            ),
          ),
          const Divider(),

          // 4. Hasil (Expanded agar ListView punya tinggi yang jelas)
          Expanded(
            child: hasil.isEmpty
                ? const Center(child: Text('Tidak ada dosen yang cocok'))
                : ListView.builder(
                    itemCount: hasil.length,
                    itemBuilder: (context, i) {
                      final d = hasil[i];
                      return ListTile(
                        leading: CircleAvatar(child: Text(d.nama[0])),
                        title: Text(d.nama),
                        subtitle: Text(d.bidang),
                        trailing: Icon(
                          Icons.circle,
                          size: 12,
                          color: d.tersedia ? Colors.green : Colors.grey,
                        ),
                      );
                    },
                  ),
          ),
        ],
      ),
    );
  }
}

Penjelasan kode:

  • Getter _hasilFilter menggabungkan tiga syarat dengan &&: cocok teks (nama atau bidang), cocok bidang dari chip, dan cocok status ketersediaan.
  • .map((d) => d.bidang).toSet() menghilangkan bidang yang kembar sebelum dibuat menjadi chip. ['Semua', ...] menambahkan pilihan "Semua" di depan dengan spread operator.
  • ChoiceChip adalah chip yang hanya bisa dipilih satu (seperti radio).
  • Daftar dibungkus Expanded karena berada di dalam Column.
  • Teks "x dari y dosen" memberi tahu pengguna bahwa filter sedang aktif.

⚠️ Kesalahan umum

  • Menghapus item dari data asli saat mencari (_semua.removeWhere(...)). Setelah kata kunci dihapus, data tidak bisa kembali.
  • Memakai index hasil filter untuk menghapus dari data asli. Index keduanya berbeda; hapus berdasarkan objek atau id (lihat studi kasus).
  • Lupa setState di onChanged, sehingga daftar tidak berubah saat mengetik.
