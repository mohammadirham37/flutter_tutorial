Jika ListView menyusun item ke bawah, GridView menyusunnya dalam baris dan kolom. Cocok untuk menu ikon, galeri foto, atau katalog produk.

Konsep: dua cara utama

KonstruktorCara kerjaCocok untuk
GridView.countJumlah kolom tetap (crossAxisCount), semua anak dibuat sekaligusMenu dengan item sedikit
GridView.builderLazy seperti ListView.builder, tata letak diatur gridDelegateData banyak / dinamis

childAspectRatio adalah perbandingan lebar : tinggi tiap kotak. Nilai 1 = persegi, kurang dari 1 = lebih tinggi, lebih dari 1 = lebih lebar.

Contoh kecil: GridView.count

body: GridView.count(
  crossAxisCount: 3,       // 3 kolom
  mainAxisSpacing: 8,      // jarak vertikal antar kotak
  crossAxisSpacing: 8,     // jarak horizontal antar kotak
  padding: const EdgeInsets.all(8),
  children: [
    for (var i = 1; i <= 12; i++)
      Container(
        color: Colors.indigo.shade100,
        alignment: Alignment.center,
        child: Text('Kotak $i'),
      ),
  ],
),
GridView tiga kolom berisi 12 kotak

Contoh lengkap 1: menu akademik dengan GridView.count

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const MenuAkademikScreen(),
    );
  }
}

class MenuItem {
  final String label;
  final IconData ikon;
  final Color warna;

  const MenuItem(this.label, this.ikon, this.warna);
}

class MenuAkademikScreen extends StatelessWidget {
  const MenuAkademikScreen({super.key});

  static const _menu = [
    MenuItem('KRS', Icons.edit_note, Colors.indigo),
    MenuItem('KHS', Icons.grading, Colors.teal),
    MenuItem('Jadwal', Icons.calendar_month, Colors.orange),
    MenuItem('Presensi', Icons.fact_check, Colors.green),
    MenuItem('Tagihan', Icons.receipt_long, Colors.red),
    MenuItem('E-Learning', Icons.cast_for_education, Colors.purple),
    MenuItem('Perpustakaan', Icons.local_library, Colors.brown),
    MenuItem('Beasiswa', Icons.workspace_premium, Colors.amber),
    MenuItem('Pengumuman', Icons.campaign, Colors.blue),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Menu Akademik')),
      body: GridView.count(
        crossAxisCount: 3,
        padding: const EdgeInsets.all(16),
        mainAxisSpacing: 12,
        crossAxisSpacing: 12,
        childAspectRatio: 0.9, // lebar : tinggi = 0.9 (sedikit lebih tinggi)
        children: [
          for (final m in _menu)
            Card(
              clipBehavior: Clip.antiAlias,
              child: InkWell(
                onTap: () => ScaffoldMessenger.of(context).showSnackBar(
                  SnackBar(content: Text('Membuka menu ${m.label}')),
                ),
                child: Column(
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    CircleAvatar(
                      radius: 26,
                      backgroundColor: m.warna.withValues(alpha: 0.15),
                      child: Icon(m.ikon, color: m.warna, size: 28),
                    ),
                    const SizedBox(height: 8),
                    Text(m.label, textAlign: TextAlign.center),
                  ],
                ),
              ),
            ),
        ],
      ),
    );
  }
}
Menu akademik 3 kolom dengan ikon berwarna
  • Setiap menu berupa Card + InkWell sehingga ada efek riak saat ditekan.
  • m.warna.withValues(alpha: 0.15) membuat latar ikon transparan 15%.

Contoh lengkap 2: katalog buku dengan GridView.builder

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepOrange),
      home: const KatalogBukuScreen(),
    );
  }
}

class KatalogBukuScreen extends StatefulWidget {
  const KatalogBukuScreen({super.key});

  @override
  State<KatalogBukuScreen> createState() => _KatalogBukuScreenState();
}

class _KatalogBukuScreenState extends State<KatalogBukuScreen> {
  // 60 buku contoh, dibuat otomatis
  final _buku = List.generate(
    60,
    (i) => (judul: 'Buku Informatika ${i + 1}', stok: (i * 7) % 5),
  );
  final Set<int> _favorit = {};

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Katalog Buku (${_favorit.length} favorit)')),
      body: GridView.builder(
        padding: const EdgeInsets.all(12),
        itemCount: _buku.length,
        // Lebar maksimum tiap kotak 180 px: jumlah kolom menyesuaikan lebar layar
        gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
          maxCrossAxisExtent: 180,
          mainAxisSpacing: 12,
          crossAxisSpacing: 12,
          childAspectRatio: 0.7,
        ),
        itemBuilder: (context, index) {
          final b = _buku[index];
          final favorit = _favorit.contains(index);
          return Card(
            clipBehavior: Clip.antiAlias,
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                Expanded(
                  child: Container(
                    color: Colors.primaries[index % Colors.primaries.length].shade200,
                    child: const Icon(Icons.menu_book, size: 48, color: Colors.white),
                  ),
                ),
                Padding(
                  padding: const EdgeInsets.fromLTRB(8, 8, 8, 0),
                  child: Text(b.judul, maxLines: 2, overflow: TextOverflow.ellipsis),
                ),
                Row(
                  children: [
                    const SizedBox(width: 8),
                    Expanded(
                      child: Text(
                        b.stok == 0 ? 'Habis' : 'Stok: ${b.stok}',
                        style: TextStyle(color: b.stok == 0 ? Colors.red : null),
                      ),
                    ),
                    IconButton(
                      icon: Icon(favorit ? Icons.favorite : Icons.favorite_border),
                      color: Colors.red,
                      onPressed: () => setState(() {
                        favorit ? _favorit.remove(index) : _favorit.add(index);
                      }),
                    ),
                  ],
                ),
              ],
            ),
          );
        },
      ),
    );
  }
}
Katalog 60 buku dengan GridView.builder

Penjelasan kode:

  • SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 180) artinya "setiap kotak maksimal 180 piksel". Di HP muncul 2 kolom, di tablet bisa 4-5 kolom secara otomatis. Inilah cara mudah membuat grid responsif.
  • Alternatifnya, SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 2) memberi jumlah kolom tetap.
  • Data buku dibuat dengan List.generate berisi record (judul: ..., stok: ...).
  • Favorit disimpan di Set<int> berisi index buku.

⚠️ Kesalahan umum

  • Garis kuning overflow di dalam kotak grid. Tinggi kotak ditentukan oleh childAspectRatio, bukan oleh isinya. Kecilkan isi atau ubah rasio (misalnya 0.7).
  • GridView di dalam Column tanpa Expanded: error unbounded height, sama seperti ListView.
  • Memakai GridView.count untuk ratusan item: semua kotak dibuat sekaligus. Pakai builder.
