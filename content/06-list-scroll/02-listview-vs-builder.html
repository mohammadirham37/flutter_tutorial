ListView adalah widget daftar yang bisa digulir. Ada tiga cara membuatnya, dan memilih yang tepat sangat berpengaruh pada kelancaran aplikasi.

ListView (children)

Membuat seluruh item sekaligus saat layar dibuka. Jika ada 1.000 data mahasiswa, Flutter membuat 1.000 widget meskipun hanya 8 yang terlihat. Cocok hanya untuk daftar pendek yang tetap, misalnya menu pengaturan.

ListView.builder (lazy)

Hanya membuat item yang sedang terlihat di layar ditambah sedikit cadangan. Item yang keluar layar dibuang. 100.000 data pun tetap ringan. Gunakan untuk data dari database atau API.

1. ListView biasa

body: ListView(
  children: const [
    ListTile(title: Text('Senin - Algoritma')),
    ListTile(title: Text('Selasa - Basis Data')),
    ListTile(title: Text('Rabu - Pemrograman Mobile')),
    ListTile(title: Text('Kamis - Jaringan Komputer')),
  ],
),
ListView biasa dengan empat ListTile

2. ListView.builder

Dua parameter wajib: itemCount (jumlah item) dan itemBuilder (fungsi yang membuat widget untuk posisi index).

final mahasiswa = List.generate(1000, (i) => 'Mahasiswa ke-${i + 1}');

return Scaffold(
  body: ListView.builder(
    itemCount: mahasiswa.length, // jumlah item
    itemBuilder: (context, index) {
      // Dipanggil HANYA untuk item yang akan tampil di layar
      return ListTile(
        leading: CircleAvatar(child: Text('${index + 1}')),
        title: Text(mahasiswa[index]),
      );
    },
  ),
);
ListView.builder dengan 1000 item, hanya yang terlihat yang dibuat

3. ListView.separated

Sama seperti builder, ditambah separatorBuilder untuk membuat pemisah di antara item.

body: ListView.separated(
  itemCount: hari.length,
  itemBuilder: (context, index) => ListTile(title: Text(hari[index])),
  // Pemisah dibuat DI ANTARA item (jumlahnya itemCount - 1)
  separatorBuilder: (context, index) => const Divider(height: 1),
),
Garis pemisah di antara item

Contoh lengkap: tiga jenis ListView dalam tab

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const PerbandinganListScreen(),
    );
  }
}

class PerbandinganListScreen extends StatelessWidget {
  const PerbandinganListScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // DefaultTabController: tiga tab untuk tiga jenis ListView
    return DefaultTabController(
      length: 3,
      child: Scaffold(
        appBar: AppBar(
          title: const Text('Tiga Jenis ListView'),
          bottom: const TabBar(
            tabs: [
              Tab(text: 'ListView'),
              Tab(text: '.builder'),
              Tab(text: '.separated'),
            ],
          ),
        ),
        body: const TabBarView(
          children: [ListBiasa(), ListBuilder(), ListSeparated()],
        ),
      ),
    );
  }
}

// 1. ListView biasa: cocok untuk item SEDIKIT dan TETAP
class ListBiasa extends StatelessWidget {
  const ListBiasa({super.key});

  @override
  Widget build(BuildContext context) {
    return ListView(
      padding: const EdgeInsets.all(8),
      children: const [
        ListTile(leading: Icon(Icons.person), title: Text('Profil')),
        ListTile(leading: Icon(Icons.lock), title: Text('Ganti Password')),
        ListTile(leading: Icon(Icons.language), title: Text('Bahasa')),
        ListTile(leading: Icon(Icons.info), title: Text('Tentang Aplikasi')),
        ListTile(leading: Icon(Icons.logout), title: Text('Keluar')),
      ],
    );
  }
}

// 2. ListView.builder: cocok untuk data BANYAK / dinamis
class ListBuilder extends StatelessWidget {
  const ListBuilder({super.key});

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      itemCount: 10000,
      itemBuilder: (context, index) {
        final nim = 'H1D0240${(index + 1).toString().padLeft(5, '0')}';
        return ListTile(
          leading: CircleAvatar(child: Text('${(index % 99) + 1}')),
          title: Text('Mahasiswa #${index + 1}'),
          subtitle: Text(nim),
        );
      },
    );
  }
}

// 3. ListView.separated: builder + pemisah otomatis
class ListSeparated extends StatelessWidget {
  const ListSeparated({super.key});

  static const _pengumuman = [
    'Batas pengisian KRS: 30 Agustus',
    'UTS dimulai minggu ke-8',
    'Libur nasional 17 Agustus',
    'Seminar karier di Aula Fakultas',
    'Pendaftaran asisten praktikum dibuka',
  ];

  @override
  Widget build(BuildContext context) {
    return ListView.separated(
      itemCount: _pengumuman.length,
      itemBuilder: (context, index) => ListTile(
        leading: const Icon(Icons.campaign_outlined),
        title: Text(_pengumuman[index]),
      ),
      separatorBuilder: (context, index) => const Divider(height: 1, indent: 56),
    );
  }
}
Tab ListView: menu pengaturan
Tab .builder: 10.000 mahasiswa tetap lancar
Tab .separated: pengumuman dengan pemisah

Penjelasan kode:

  • DefaultTabController + TabBar + TabBarView membuat tiga tab. (Tab dibahas lebih lanjut di Modul 07.)
  • Tab ListView berisi menu yang tetap dan pendek, jadi children biasa sudah tepat.
  • Tab .builder berisi 10.000 item. Coba gulir cepat: tetap lancar karena hanya sekitar 10-15 ListTile yang benar-benar ada di memori.
  • Tab .separated memakai Divider(indent: 56) agar garis dimulai sejajar teks, bukan ikon.

⚠️ Kesalahan umum

  • Error "Vertical viewport was given unbounded height". Terjadi saat ListView diletakkan langsung di dalam Column. Bungkus ListView dengan Expanded.
  • Lupa itemCount. Builder akan meminta item tanpa batas dan terjadi RangeError saat index melebihi panjang list.
  • Melakukan pekerjaan berat di itemBuilder (misalnya mengurutkan seluruh list). itemBuilder dipanggil sangat sering saat menggulir; siapkan data di luar.
