Menggeser baris ke kiri untuk menghapus (swipe to delete) adalah gestur yang sudah akrab bagi pengguna HP. Di Flutter, gestur ini dibuat dengan membungkus item daftar memakai Dismissible.

Konsep

  • key: wajib dan harus unik untuk setiap item, biasanya dari id data: ValueKey(item.id).
  • background: tampilan di balik item saat digeser ke kanan (atau ke dua arah jika secondaryBackground tidak diisi). secondaryBackground: tampilan saat digeser ke kiri.
  • direction: membatasi arah geser.
  • confirmDismiss: fungsi async yang dipanggil sebelum item hilang. Kembalikan false untuk membatalkan.
  • onDismissed: dipanggil setelah item hilang dari layar. Di sini data wajib dihapus dari list.

Contoh kecil

itemBuilder: (context, index) {
  final item = _items[index];
  return Dismissible(
    key: ValueKey(item), // WAJIB unik dan stabil untuk tiap item
    direction: DismissDirection.endToStart, // hanya geser ke kiri
    background: Container(
      color: Colors.red,
      alignment: Alignment.centerRight,
      padding: const EdgeInsets.only(right: 20),
      child: const Icon(Icons.delete, color: Colors.white),
    ),
    onDismissed: (direction) {
      // WAJIB hapus data dari list, kalau tidak akan error
      setState(() => _items.removeAt(index));
    },
    child: ListTile(title: Text(item)),
  );
},
Daftar sederhana; setiap baris bisa digeser ke kiri untuk dihapus

Contoh lengkap: kotak masuk dengan hapus, urungkan, dan arsip

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const KotakMasukScreen(),
    );
  }
}

class Pesan {
  final int id;
  final String pengirim;
  final String isi;
  bool diarsipkan;

  Pesan(this.id, this.pengirim, this.isi, {this.diarsipkan = false});
}

class KotakMasukScreen extends StatefulWidget {
  const KotakMasukScreen({super.key});

  @override
  State<KotakMasukScreen> createState() => _KotakMasukScreenState();
}

class _KotakMasukScreenState extends State<KotakMasukScreen> {
  final List<Pesan> _pesan = [
    Pesan(1, 'Akademik', 'Jadwal UTS sudah terbit'),
    Pesan(2, 'Dosen Wali', 'Silakan konsultasi KRS minggu ini'),
    Pesan(3, 'Himpunan', 'Rapat anggota hari Jumat'),
    Pesan(4, 'Perpustakaan', 'Buku yang dipinjam jatuh tempo besok'),
    Pesan(5, 'BEM', 'Open recruitment panitia dies natalis'),
    Pesan(6, 'Lab Komputer', 'Praktikum minggu ini diganti online'),
  ];

  void _hapus(int index) {
    final terhapus = _pesan[index];
    setState(() => _pesan.removeAt(index));

    ScaffoldMessenger.of(context)
      ..hideCurrentSnackBar()
      ..showSnackBar(
        SnackBar(
          content: Text('Pesan dari ${terhapus.pengirim} dihapus'),
          action: SnackBarAction(
            label: 'URUNGKAN',
            // Kembalikan ke posisi semula
            onPressed: () => setState(() => _pesan.insert(index, terhapus)),
          ),
        ),
      );
  }

  Future<bool> _konfirmasiHapus(Pesan p) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Hapus pesan?'),
        content: Text('Pesan dari ${p.pengirim} akan dihapus.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    return yakin ?? false;
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Kotak Masuk (${_pesan.length})')),
      body: _pesan.isEmpty
          ? const Center(child: Text('Kotak masuk kosong'))
          : ListView.builder(
              itemCount: _pesan.length,
              itemBuilder: (context, index) {
                final p = _pesan[index];
                return Dismissible(
                  // Pakai id unik dari data, BUKAN index
                  key: ValueKey(p.id),
                  // Geser ke kanan -> arsip (latar hijau)
                  background: Container(
                    color: Colors.green,
                    alignment: Alignment.centerLeft,
                    padding: const EdgeInsets.only(left: 24),
                    child: const Icon(Icons.archive, color: Colors.white),
                  ),
                  // Geser ke kiri -> hapus (latar merah)
                  secondaryBackground: Container(
                    color: Colors.red,
                    alignment: Alignment.centerRight,
                    padding: const EdgeInsets.only(right: 24),
                    child: const Icon(Icons.delete, color: Colors.white),
                  ),
                  // Dipanggil SEBELUM item hilang. Return false = batal.
                  confirmDismiss: (direction) async {
                    if (direction == DismissDirection.startToEnd) {
                      // Arsip: ubah status saja, item tidak dihapus dari list
                      setState(() => p.diarsipkan = !p.diarsipkan);
                      return false;
                    }
                    return _konfirmasiHapus(p);
                  },
                  onDismissed: (_) => _hapus(index),
                  child: ListTile(
                    leading: CircleAvatar(child: Text(p.pengirim[0])),
                    title: Text(p.pengirim),
                    subtitle: Text(p.isi),
                    trailing: p.diarsipkan
                        ? const Icon(Icons.archive, color: Colors.green)
                        : null,
                  ),
                );
              },
            ),
    );
  }
}
Daftar pesan awal
Pesan digeser ke kiri: dialog konfirmasi muncul
Setelah dihapus: SnackBar dengan tombol URUNGKAN

Penjelasan kode:

  • key: ValueKey(p.id) memakai id unik dari data. Jika memakai index, setelah satu item dihapus semua index bergeser dan Flutter bisa salah mengenali item.
  • Geser ke kanan (startToEnd) hanya mengubah status arsip lalu return false, sehingga item kembali ke tempatnya.
  • Geser ke kiri memanggil _konfirmasiHapus yang menampilkan dialog. Hasil dialog (true/false) langsung menjadi hasil confirmDismiss.
  • _hapus menyimpan item dan posisinya sebelum menghapus, lalu tombol URUNGKAN memasukkannya kembali dengan insert.

⚠️ Kesalahan umum

  • Error "A dismissed Dismissible widget is still part of the tree". Terjadi jika onDismissed tidak menghapus data dari list. Selalu removeAt/remove lalu setState.
  • Key memakai index atau nama yang bisa kembar. Gunakan id unik.
  • Menghapus permanen ke database langsung di onDismissed padahal ada tombol Urungkan. Pada aplikasi nyata, tunda penghapusan permanen sampai SnackBar hilang, atau kembalikan data ke database saat diurungkan.
