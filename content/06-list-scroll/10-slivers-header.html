Sliver adalah potongan area gulir. Dengan CustomScrollView, beberapa sliver (app bar, grid, list, widget biasa) digabung menjadi satu area gulir yang mulus. Contoh paling terkenal: header bergambar yang mengecil saat digulir (collapsing header).

Konsep

SliverPadanan widget biasa
SliverAppBarAppBar yang bisa membesar/mengecil
SliverList.builder / .separatedListView.builder / .separated
SliverGrid.count / SliverGrid.builderGridView.count / .builder
SliverToBoxAdapterPembungkus untuk widget biasa (Text, Card, dll.)
SliverPaddingPadding untuk sliver

Properti penting SliverAppBar: expandedHeight (tinggi saat terbuka penuh), pinned (bagian kecilnya tetap menempel di atas), floating (muncul lagi begitu pengguna menggulir sedikit ke atas), snap (bersama floating, langsung terbuka penuh), dan flexibleSpace (isi area yang membesar).

Contoh kecil

body: CustomScrollView(
  // Semua anak CustomScrollView harus berupa SLIVER
  slivers: [
    const SliverAppBar(title: Text('Beranda'), pinned: true),
    // Widget biasa dibungkus SliverToBoxAdapter
    const SliverToBoxAdapter(
      child: Padding(padding: EdgeInsets.all(16), child: Text('Halo!')),
    ),
    SliverList.builder(
      itemCount: 30,
      itemBuilder: (context, i) => ListTile(title: Text('Item $i')),
    ),
  ],
),
CustomScrollView dengan SliverAppBar, teks, dan SliverList

Contoh lengkap 1: profil universitas dengan gambar header

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: ProfilUniversitasScreen(),
    );
  }
}

class ProfilUniversitasScreen extends StatelessWidget {
  const ProfilUniversitasScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // CustomScrollView TIDAK memakai AppBar biasa: SliverAppBar sudah menjadi app bar-nya
    return Scaffold(
      body: CustomScrollView(
        slivers: [
          SliverAppBar(
            expandedHeight: 200.0,
            floating: false,
            pinned: true, // Judul tetap menempel di atas saat discroll
            backgroundColor: Colors.indigo,
            foregroundColor: Colors.white,
            flexibleSpace: FlexibleSpaceBar(
              title: const Text("Profil Universitas"),
              background: Image.network(
                "https://images.unsplash.com/photo-1541339907198-e08756dedf3f?w=600",
                fit: BoxFit.cover,
                // Cadangan jika gambar gagal dimuat (offline / URL mati)
                errorBuilder: (context, error, stackTrace) =>
                    Container(color: Colors.indigo.shade300),
              ),
            ),
          ),
          const SliverToBoxAdapter(
            child: Padding(
              padding: EdgeInsets.all(16),
              child: Text("Fakultas Teknologi Informasi memiliki 4 program studi unggulan..."),
            ),
          ),
          SliverList.builder(
            itemCount: 20,
            itemBuilder: (context, index) => ListTile(
              leading: const Icon(Icons.article_outlined),
              title: Text("Berita Kampus Ke-${index + 1}"),
            ),
          ),
        ],
      ),
    );
  }
}
Header gambar terbuka penuh
Setelah digulir: header mengecil menjadi app bar biasa
  • FlexibleSpaceBar mengatur judul yang mengecil dan gambar latar yang memudar.
  • errorBuilder pada Image.network menampilkan warna polos jika gambar gagal dimuat (misalnya saat offline).

Contoh lengkap 2: dashboard dengan grid dan list dalam satu gulir

Tanpa sliver, menaruh GridView dan ListView dalam satu halaman yang bisa digulir bersama cukup merepotkan. Dengan CustomScrollView, keduanya cukup ditumpuk sebagai sliver.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DashboardScreen(),
    );
  }
}

class DashboardScreen extends StatelessWidget {
  const DashboardScreen({super.key});

  static const _menu = [
    (Icons.edit_note, 'KRS'),
    (Icons.grading, 'KHS'),
    (Icons.calendar_month, 'Jadwal'),
    (Icons.fact_check, 'Presensi'),
    (Icons.receipt_long, 'Tagihan'),
    (Icons.local_library, 'Pustaka'),
  ];

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;

    return Scaffold(
      body: CustomScrollView(
        slivers: [
          // 1. App bar yang mengecil saat digulir
          SliverAppBar(
            expandedHeight: 180,
            pinned: true, // bagian kecilnya tetap menempel di atas
            backgroundColor: warna.primary,
            foregroundColor: warna.onPrimary,
            flexibleSpace: FlexibleSpaceBar(
              title: const Text('Halo, Nadia'),
              background: Container(
                decoration: BoxDecoration(
                  gradient: LinearGradient(
                    colors: [warna.primary, warna.tertiary],
                    begin: Alignment.topLeft,
                    end: Alignment.bottomRight,
                  ),
                ),
                alignment: Alignment.centerRight,
                padding: const EdgeInsets.only(right: 24),
                child: Icon(Icons.school, size: 96, color: warna.onPrimary.withValues(alpha: 0.3)),
              ),
            ),
          ),

          // 2. Widget biasa di antara sliver
          SliverToBoxAdapter(
            child: Padding(
              padding: const EdgeInsets.fromLTRB(16, 16, 16, 8),
              child: Text('Menu Cepat', style: Theme.of(context).textTheme.titleMedium),
            ),
          ),

          // 3. Grid di dalam CustomScrollView
          SliverPadding(
            padding: const EdgeInsets.symmetric(horizontal: 16),
            sliver: SliverGrid.count(
              crossAxisCount: 3,
              mainAxisSpacing: 8,
              crossAxisSpacing: 8,
              children: [
                for (final (ikon, label) in _menu)
                  Card(
                    child: Column(
                      mainAxisAlignment: MainAxisAlignment.center,
                      children: [Icon(ikon, size: 32), const SizedBox(height: 4), Text(label)],
                    ),
                  ),
              ],
            ),
          ),

          SliverToBoxAdapter(
            child: Padding(
              padding: const EdgeInsets.fromLTRB(16, 24, 16, 8),
              child: Text('Pengumuman Terbaru', style: Theme.of(context).textTheme.titleMedium),
            ),
          ),

          // 4. Daftar panjang di bawahnya: satu scroll untuk semuanya
          SliverList.separated(
            itemCount: 15,
            itemBuilder: (context, i) => ListTile(
              leading: const Icon(Icons.campaign_outlined),
              title: Text('Pengumuman ke-${i + 1}'),
              subtitle: const Text('Fakultas Teknik'),
            ),
            separatorBuilder: (context, i) => const Divider(height: 1),
          ),
        ],
      ),
    );
  }
}
Dashboard: header gradasi, grid menu, dan daftar pengumuman
Setelah digulir: header menempel, list berlanjut

Penjelasan kode:

  • Header memakai gradasi warna dari colorScheme, sehingga ikut berubah jika colorSchemeSeed diganti.
  • SliverPadding memberi jarak kiri-kanan untuk SliverGrid.count. Padding biasa tidak boleh membungkus sliver.
  • Judul bagian ("Menu Cepat", "Pengumuman Terbaru") adalah widget biasa sehingga dibungkus SliverToBoxAdapter.
  • SliverList.separated bekerja persis seperti ListView.separated, termasuk lazy loading.

⚠️ Kesalahan umum

  • Memasukkan widget biasa langsung ke slivers, misalnya Text atau ListView. Muncul error "A RenderViewport expected a child of type RenderSliver". Bungkus dengan SliverToBoxAdapter atau ganti dengan versi sliver-nya.
  • Memakai appBar: Scaffold sekaligus SliverAppBar. Hasilnya dua app bar bertumpuk.
  • Memakai snap: true tanpa floating: true. Terjadi error assertion; snap hanya berlaku bersama floating.
