Daftar data jarang langsung tersedia. Data harus dimuat dulu, bisa gagal, atau ternyata kosong. Aplikasi yang baik menampilkan tampilan yang jelas untuk setiap keadaan, bukan layar putih kosong.

Konsep: empat keadaan

KeadaanYang ditampilkan
LoadingCircularProgressIndicator + teks "Memuat..."
ErrorIkon, pesan yang dimengerti pengguna, tombol "Coba Lagi"
Kosong (empty state)Ikon, penjelasan kenapa kosong, ajakan bertindak
Ada dataListView / GridView

Contoh kecil: pola operator ternary

// Pola umum: periksa keadaan dari yang paling "awal"
return Scaffold(
  body: sedangMemuat
      ? const Center(child: CircularProgressIndicator())       // 1. loading
      : data.isEmpty
          ? const Center(child: Text('Belum ada data'))        // 2. kosong
          : ListView.builder(                                  // 3. ada data
              itemCount: data.length,
              itemBuilder: (context, i) => ListTile(title: Text(data[i])),
            ),
);
Keadaan loading: lingkaran berputar di tengah layar

Untuk dua atau tiga keadaan, ternary bersarang masih terbaca. Untuk empat keadaan atau lebih, lebih rapi memakai enum + switch seperti contoh berikut.

Contoh lengkap: enum StatusMuat

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DaftarTugasScreen(),
    );
  }
}

// Empat kemungkinan keadaan layar daftar
enum StatusMuat { loading, error, kosong, ada }

class DaftarTugasScreen extends StatefulWidget {
  const DaftarTugasScreen({super.key});

  @override
  State<DaftarTugasScreen> createState() => _DaftarTugasScreenState();
}

class _DaftarTugasScreenState extends State<DaftarTugasScreen> {
  StatusMuat _status = StatusMuat.loading;
  List<String> _tugas = [];
  int _percobaan = 0;

  @override
  void initState() {
    super.initState();
    _muatData();
  }

  // Simulasi mengambil data: percobaan ke-1 gagal, ke-2 kosong, ke-3 berhasil
  Future<void> _muatData() async {
    setState(() => _status = StatusMuat.loading);
    await Future.delayed(const Duration(seconds: 2));
    if (!mounted) return;

    _percobaan++;
    setState(() {
      if (_percobaan == 1) {
        _status = StatusMuat.error;
      } else if (_percobaan == 2) {
        _tugas = [];
        _status = StatusMuat.kosong;
      } else {
        _tugas = ['Laporan Praktikum 3', 'Kuis Dart', 'Proyek UI Login'];
        _status = StatusMuat.ada;
      }
    });
  }

  Widget _buildIsi() {
    switch (_status) {
      case StatusMuat.loading:
        return const Center(
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              CircularProgressIndicator(),
              SizedBox(height: 16),
              Text('Memuat tugas...'),
            ],
          ),
        );
      case StatusMuat.error:
        return _PesanStatus(
          ikon: Icons.wifi_off,
          judul: 'Gagal memuat data',
          keterangan: 'Periksa koneksi internet lalu coba lagi.',
          tombol: FilledButton.icon(
            onPressed: _muatData,
            icon: const Icon(Icons.refresh),
            label: const Text('Coba Lagi'),
          ),
        );
      case StatusMuat.kosong:
        return _PesanStatus(
          ikon: Icons.inbox_outlined,
          judul: 'Belum ada tugas',
          keterangan: 'Tugas dari dosen akan muncul di sini.',
          tombol: OutlinedButton(onPressed: _muatData, child: const Text('Muat Ulang')),
        );
      case StatusMuat.ada:
        return ListView.builder(
          itemCount: _tugas.length,
          itemBuilder: (context, i) => ListTile(
            leading: const Icon(Icons.assignment_outlined),
            title: Text(_tugas[i]),
          ),
        );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Tugas - status: ${_status.name}')),
      body: _buildIsi(),
    );
  }
}

// Widget kecil yang bisa dipakai ulang untuk empty state & error state
class _PesanStatus extends StatelessWidget {
  final IconData ikon;
  final String judul;
  final String keterangan;
  final Widget tombol;

  const _PesanStatus({
    required this.ikon,
    required this.judul,
    required this.keterangan,
    required this.tombol,
  });

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Padding(
        padding: const EdgeInsets.all(32),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Icon(ikon, size: 80, color: Colors.grey),
            const SizedBox(height: 16),
            Text(judul, style: Theme.of(context).textTheme.titleLarge),
            const SizedBox(height: 8),
            Text(keterangan, textAlign: TextAlign.center),
            const SizedBox(height: 24),
            tombol,
          ],
        ),
      ),
    );
  }
}
Loading saat pertama dibuka
Percobaan pertama gagal: error state
Setelah Coba Lagi: data kosong
Setelah Muat Ulang: data tampil

Penjelasan kode:

  • enum StatusMuat { loading, error, kosong, ada } membuat semua keadaan tertulis jelas.
  • switch (_status) di _buildIsi wajib menangani semua nilai enum. Jika kelak ditambah keadaan baru, compiler akan mengingatkan bagian yang belum ditangani.
  • Widget _PesanStatus dipakai ulang untuk error dan kosong, cukup berbeda ikon, teks, dan tombolnya.
  • _muatData selalu mengubah status ke loading dulu, lalu menunggu, lalu mengatur hasil. Pola ini juga akan dipakai di Modul 09 saat memanggil API.

⚠️ Kesalahan umum

  • Hanya memeriksa list.isEmpty. Saat masih loading, list juga kosong, sehingga pengguna sempat melihat tulisan "Belum ada data" padahal data sedang dimuat.
  • Pesan error teknis seperti "SocketException: Failed host lookup". Tampilkan bahasa manusia dan berikan tombol coba lagi.
  • Lupa if (!mounted) return; setelah await.
