Menarik daftar ke bawah untuk memuat ulang (pull to refresh) dibuat dengan membungkus widget gulir memakai RefreshIndicator.

Konsep

  • onRefresh harus berupa fungsi yang mengembalikan Future. Lingkaran loading terus berputar sampai Future selesai.
  • Anak RefreshIndicator harus widget yang bisa digulir (ListView, GridView, CustomScrollView).
  • Jika item sedikit dan tidak memenuhi layar, daftar tidak bisa ditarik. Tambahkan physics: const AlwaysScrollableScrollPhysics().

Contoh kecil

// onRefresh WAJIB mengembalikan Future: indikator berputar sampai Future selesai
Future<void> _muatUlang() async {
  await Future.delayed(const Duration(seconds: 1)); // pura-pura ambil dari server
  setState(() => _berita = ['Berita terbaru', ..._berita]);
}

@override
Widget build(BuildContext context) {
  return RefreshIndicator(
    onRefresh: _muatUlang,
    child: ListView.builder(
      // agar tetap bisa ditarik walau item sedikit
      physics: const AlwaysScrollableScrollPhysics(),
      itemCount: _berita.length,
      itemBuilder: (context, index) => ListTile(title: Text(_berita[index])),
    ),
  );
}
Daftar berita di dalam RefreshIndicator

Contoh lengkap: katalog mata kuliah dengan pull-to-refresh

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: DaftarMataKuliahScreen(),
    );
  }
}


class DaftarMataKuliahScreen extends StatefulWidget {
  const DaftarMataKuliahScreen({super.key});

  @override
  State<DaftarMataKuliahScreen> createState() => _DaftarMataKuliahScreenState();
}

class _DaftarMataKuliahScreenState extends State<DaftarMataKuliahScreen> {
  // Simulasi data dari database kampus
  final List<Map<String, dynamic>> _daftarMatkul = [
    {"kode": "IF101", "nama": "Algoritma & Pemrograman", "sks": 3, "dosen": "Dr. Bambang, M.Kom."},
    {"kode": "IF203", "nama": "Struktur Data & Graf", "sks": 3, "dosen": "Nadia Fitri, M.T."},
    {"kode": "IF305", "nama": "Pemrograman Mobile (Flutter)", "sks": 4, "dosen": "Irham Akbar, M.Cs."},
    {"kode": "IF401", "nama": "Kecerdasan Buatan (AI)", "sks": 3, "dosen": "Prof. Hartono"},
    {"kode": "IF408", "nama": "Keamanan Siber & Kriptografi", "sks": 3, "dosen": "Eko Prasetyo, Ph.D."},
  ];

  // Fungsi simulasi refresh data dari server
  Future<void> _refreshData() async {
    await Future.delayed(const Duration(seconds: 2));
    setState(() {
      _daftarMatkul.shuffle(); // Acak urutan sebagai tanda data baru
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text("Katalog Mata Kuliah"),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
      ),
      // RefreshIndicator menambahkan gestur tarik ke bawah untuk refresh
      body: RefreshIndicator(
        onRefresh: _refreshData,
        // AlwaysScrollableScrollPhysics: tarik-ke-bawah tetap bisa walau item sedikit
        child: ListView.separated(
          physics: const AlwaysScrollableScrollPhysics(),
          itemCount: _daftarMatkul.length,
          separatorBuilder: (context, index) => const Divider(height: 1, indent: 72),
          itemBuilder: (context, index) {
            final matkul = _daftarMatkul[index];
            return ListTile(
              leading: CircleAvatar(
                backgroundColor: Colors.indigo.shade100,
                child: Text(
                  "${matkul['sks']}",
                  style: const TextStyle(color: Colors.indigo, fontWeight: FontWeight.bold),
                ),
              ),
              title: Text(
                matkul['nama'],
                style: const TextStyle(fontWeight: FontWeight.w600),
              ),
              subtitle: Text("${matkul['kode']} • Dosen: ${matkul['dosen']}"),
              trailing: const Icon(Icons.arrow_forward_ios, size: 14, color: Colors.grey),
              onTap: () {
                // Aksi saat item baris ditekan
                ScaffoldMessenger.of(context).showSnackBar(
                  SnackBar(content: Text("Membuka ${matkul['nama']}")),
                );
              },
            );
          },
        ),
      ),
    );
  }
}
Katalog mata kuliah dengan ListView.separated. Tarik ke bawah untuk memuat ulang

Penjelasan kode:

  • _refreshData menunggu 2 detik (pura-pura mengambil data dari server), lalu mengacak urutan sebagai tanda data berubah.
  • ListView.separated dipakai agar setiap mata kuliah dipisah garis tipis.
  • CircleAvatar di leading menampilkan jumlah SKS.

💡 Tips

Pada Modul 09 (REST API), isi onRefresh akan diganti dengan pemanggilan http.get sungguhan. Polanya sama persis: await ambil data, lalu setState.

⚠️ Kesalahan umum

  • onRefresh tidak async / tidak mengembalikan Future. Indikator langsung hilang atau terjadi error tipe.
  • Lupa memeriksa mounted setelah await pada data sungguhan; jika pengguna sudah keluar halaman, setState akan error.
  • RefreshIndicator dibungkuskan ke Column. Ia harus langsung membungkus widget yang bisa digulir.
