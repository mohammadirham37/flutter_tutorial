Setiap GetxController punya siklus hidup: dibuat, dipakai, lalu dihapus dari memori. GetX memanggil method tertentu di setiap tahap, sehingga Anda tahu kapan harus memuat data dan kapan harus membersihkan sumber daya. Di section ini kita juga mengenal Bindings, tempat rapi untuk mendaftarkan banyak controller sekaligus.

Tiga method lifecycle

MethodKapan dipanggilDipakai untuk
onInit()Sekali, tepat setelah controller dibuat dan didaftarkanMemuat data awal, memulai timer, membuat worker (section 9), berlangganan stream
onReady()Sekali, satu frame setelah onInit (halaman sudah tampil)Aksi yang butuh UI sudah siap, misalnya menampilkan dialog sambutan dari View
onClose()Sekali, sebelum controller dihapus dari memoriMembatalkan Timer, StreamSubscription, worker, menutup TextEditingController milik controller

Jika Anda pernah memakai StatefulWidget, polanya mirip: onInit setara initState, dan onClose setara dispose. Bedanya, lifecycle ini milik controller, bukan milik widget.

Contoh kecil

import 'package:flutter/foundation.dart';
import 'package:get/get.dart';

class ContohController extends GetxController {
  ContohController() {
    debugPrint('1. constructor');
  }

  @override
  void onInit() {
    super.onInit(); // selalu panggil super lebih dulu
    debugPrint('2. onInit: muat data di sini');
  }

  @override
  void onReady() {
    super.onReady();
    debugPrint('3. onReady: halaman sudah tampil');
  }

  @override
  void onClose() {
    debugPrint('4. onClose: bersihkan sumber daya di sini');
    super.onClose();
  }
}

Kapan onClose dipanggil? Itu bergantung pada cara controller didaftarkan:

  • Didaftarkan dengan permanent: true atau di initialBinding: hidup selama aplikasi berjalan, onClose praktis tidak pernah dipanggil.
  • Didaftarkan lewat binding sebuah rute (atau Get.put di dalam halaman yang dibuka dengan Get.to/Get.toNamed): GetX mengikat controller ke rute tersebut. Saat halaman ditutup (Get.back atau tombol kembali), controller otomatis dihapus dan onClose dipanggil.
  • Dihapus manual dengan Get.delete<ContohController>().

Bindings: satu tempat untuk mendaftarkan controller

Di section 4 controller didaftarkan dengan Get.put di main() atau di View. Untuk aplikasi yang punya banyak controller, pendaftaran itu lebih rapi dikumpulkan dalam class turunan Bindings. Method dependencies() berisi semua Get.put/Get.lazyPut.

// 1. Binding global: dijalankan sekali saat aplikasi mulai
class AppBinding extends Bindings {
  @override
  void dependencies() {
    Get.put(TemaController(), permanent: true);
    Get.put(SesiController(), permanent: true);
    Get.lazyPut(() => FavoritController(), fenix: true);
  }
}

// 2. Binding per halaman: dijalankan saat rute dibuka
class BelajarBinding extends Bindings {
  @override
  void dependencies() {
    Get.lazyPut(() => BelajarController());
  }
}

// 3. Memasang binding
GetMaterialApp(
  initialBinding: AppBinding(),            // binding global
  initialRoute: '/',
  getPages: [
    GetPage(name: '/', page: () => const BerandaView()),
    GetPage(
      name: '/belajar',
      page: () => const BelajarView(),
      binding: BelajarBinding(),           // binding milik rute ini
    ),
  ],
);

// 4. Membuka rute bernama (boleh membawa arguments)
Get.toNamed('/belajar', arguments: 'Basis Data');

Untuk binding yang isinya hanya satu-dua baris, tidak perlu membuat class. Pakai BindingsBuilder:

GetPage(
  name: '/belajar',
  page: () => const BelajarView(),
  binding: BindingsBuilder(() {
    Get.lazyPut(() => BelajarController());
  }),
),

Jika Anda pernah melihat MultiProvider di package Provider, AppBinding inilah padanannya: semua controller global didaftarkan di satu tempat, tanpa widget yang bersarang.

Contoh lengkap: tiga controller global + satu controller per halaman

Aplikasi berikut punya TemaController, SesiController, dan FavoritController yang didaftarkan di AppBinding. Mengetuk nama mata kuliah membuka halaman Belajar yang punya BelajarController sendiri. Controller ini menjalankan Timer dan otomatis dihapus ketika halaman ditutup.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'dart:async';

import 'package:flutter/material.dart';
import 'package:get/get.dart';

// ================= CONTROLLER GLOBAL =================

// Controller 1: pengaturan tampilan
class TemaController extends GetxController {
  final _gelap = false.obs;
  bool get gelap => _gelap.value;

  void toggle() => _gelap.value = !_gelap.value;

  @override
  void onInit() {
    super.onInit();
    debugPrint('TemaController.onInit');
  }
}

// Controller 2: data pengguna yang sedang login
class SesiController extends GetxController {
  final _nama = RxnString(); // Rxn = observable yang boleh null
  String? get nama => _nama.value;
  bool get sudahLogin => _nama.value != null;

  void login(String nama) => _nama.value = nama;
  void logout() => _nama.value = null;

  @override
  void onInit() {
    super.onInit();
    debugPrint('SesiController.onInit');
  }
}

// Controller 3: daftar favorit
class FavoritController extends GetxController {
  final _items = <String>{}.obs; // RxSet
  int get jumlah => _items.length;
  bool isFavorit(String m) => _items.contains(m);

  void toggle(String m) {
    if (!_items.remove(m)) _items.add(m);
  }

  @override
  void onInit() {
    super.onInit();
    debugPrint('FavoritController.onInit');
  }
}

// ================= CONTROLLER PER HALAMAN =================

// Hidup hanya selama halaman Belajar terbuka
class BelajarController extends GetxController {
  final _detik = 0.obs;
  int get detik => _detik.value;

  Timer? _timer;

  @override
  void onInit() {
    super.onInit();
    debugPrint('BelajarController.onInit: timer dimulai');
    _timer = Timer.periodic(const Duration(seconds: 1), (_) => _detik.value++);
  }

  @override
  void onReady() {
    super.onReady();
    debugPrint('BelajarController.onReady: halaman sudah tampil');
  }

  @override
  void onClose() {
    _timer?.cancel(); // WAJIB: kalau lupa, timer tetap berjalan di latar
    debugPrint('BelajarController.onClose: timer dihentikan setelah $detik detik');
    super.onClose();
  }
}

class BerandaView extends StatelessWidget {
  const BerandaView({super.key});

  static const matkul = ['Pemrograman Mobile', 'Basis Data', 'Kecerdasan Buatan'];

  @override
  Widget build(BuildContext context) {
    final tema = Get.find<TemaController>();
    final sesi = Get.find<SesiController>();
    final favorit = Get.find<FavoritController>();

    return Scaffold(
      appBar: AppBar(
        title: Obx(() => Text(sesi.sudahLogin ? 'Halo, ${sesi.nama}' : 'Tamu')),
        actions: [
          IconButton(
            tooltip: 'Ganti tema',
            icon: const Icon(Icons.dark_mode),
            onPressed: () {
              tema.toggle(); // controller menyimpan state
              // View yang menerapkan state ke tampilan
              Get.changeThemeMode(tema.gelap ? ThemeMode.dark : ThemeMode.light);
            },
          ),
          Obx(
            () => IconButton(
              tooltip: sesi.sudahLogin ? 'Logout' : 'Login',
              icon: Icon(sesi.sudahLogin ? Icons.logout : Icons.login),
              onPressed: () => sesi.sudahLogin ? sesi.logout() : sesi.login('Andi'),
            ),
          ),
        ],
      ),
      body: ListView(
        children: [
          Obx(() => ListTile(title: Text('Favorit: ${favorit.jumlah} mata kuliah'))),
          const Divider(),
          for (final m in matkul)
            ListTile(
              title: Text(m),
              // ketuk baris untuk membuka halaman Belajar
              onTap: () => Get.toNamed('/belajar', arguments: m),
              trailing: Obx(
                () => IconButton(
                  tooltip: 'Favorit $m',
                  icon: Icon(
                    favorit.isFavorit(m) ? Icons.favorite : Icons.favorite_border,
                    color: favorit.isFavorit(m) ? Colors.red : null,
                  ),
                  onPressed: () => favorit.toggle(m),
                ),
              ),
            ),
        ],
      ),
    );
  }
}

Penjelasan:

  • initialBinding: AppBinding() menjalankan dependencies() sekali saat aplikasi mulai, sehingga tiga controller global langsung tersedia untuk Get.find di View mana pun.
  • Setiap controller kecil dan punya satu tanggung jawab. Hindari satu "GodController" berisi semua state.
  • BelajarBinding dipasang di GetPage. Controller baru dibuat ketika rute /belajar dibuka, dan dihapus ketika rute ditutup. Buka halaman itu lagi: hitungan mulai dari 0 karena controllernya baru.
  • onClose membatalkan Timer. Tanpa baris itu, timer tetap berdetak di latar dan terus mengubah observable milik controller yang sudah tidak dipakai (kebocoran memori).
  • BelajarView extends GetView<BelajarController>: GetView hanyalah StatelessWidget yang menyediakan getter controller berisi Get.find<BelajarController>().
  • Tema: TemaController hanya menyimpan nilai gelap. Yang memanggil Get.changeThemeMode adalah View, karena itu urusan tampilan (prinsip MVC dari section 2).
  • Get.arguments berisi nilai yang dikirim lewat Get.toNamed('/belajar', arguments: m).
  • Setiap Obx hanya membungkus bagian yang membaca observable: judul AppBar, ikon login, jumlah favorit, dan ikon hati per baris.

ℹ️ Get.put vs Get.lazyPut di binding

Get.put langsung membuat objek (dan menjalankan onInit) saat binding dijalankan. Get.lazyPut hanya mendaftarkan "resep"; objek baru dibuat saat pertama kali di-Get.find. Tambahkan fenix: true agar controller lazy bisa dibuat ulang setelah sempat dihapus.

⚠️ Kesalahan umum

  • Lupa memanggil super.onInit() / super.onClose(). Selalu panggil super.
  • Membuat Timer, StreamSubscription, atau worker di onInit tetapi tidak membatalkannya di onClose.
  • Memasang controller khusus satu halaman di AppBinding dengan permanent: true. Controller itu tidak pernah dihapus dan state lamanya muncul lagi saat halaman dibuka ulang.
  • Memakai Get.toNamed('/belajar') padahal rute itu tidak terdaftar di getPages, atau binding-nya lupa dipasang sehingga Get.find di View gagal dengan pesan "BelajarController" not found.
