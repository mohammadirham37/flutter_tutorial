GetX menyediakan tiga widget untuk menampilkan state controller: Obx, GetX<T>, dan GetBuilder<T>. Perbedaannya ada pada apa yang memicu rebuild. Memilih yang tepat membuat aplikasi benar sekaligus hemat rebuild.

Tiga cara menampilkan state

import 'package:flutter/material.dart';
import 'package:get/get.dart';

class ProfilController extends GetxController {
  final nama = 'Andi'.obs; // reaktif
  int bintang = 0; // biasa (non-reaktif)

  void tambahBintang() {
    bintang++;
    update(); // wajib untuk GetBuilder
  }
}

Widget contoh() {
  final c = Get.find<ProfilController>();
  return Column(
    children: [
      // 1) Obx: ambil controller sendiri, rebuild saat .obs yang dibaca berubah
      Obx(() => Text('Nama: ${c.nama.value}')),

      // 2) GetX<T>: sama-sama reaktif, controller diberikan lewat builder
      GetX<ProfilController>(
        builder: (ctrl) => Text('Nama: ${ctrl.nama.value}'),
      ),

      // 3) GetBuilder<T>: tidak memantau .obs, rebuild hanya saat update()
      GetBuilder<ProfilController>(
        builder: (ctrl) => Text('Bintang: ${ctrl.bintang}'),
      ),
    ],
  );
}
WidgetRebuild ketikaCara mendapat controllerState yang cocok
Obx(() => ...)Observable (.obs) yang dibaca di dalamnya berubahSendiri: Get.find atau controller dari GetViewReaktif (.obs)
GetX<T>(builder: ...)Sama seperti ObxDiberikan lewat parameter builder; bisa juga init: untuk membuatnyaReaktif (.obs)
GetBuilder<T>(builder: ...)Controller memanggil update() (atau update([id]))Diberikan lewat parameter builderField biasa (non-reaktif)

Hal penting: GetBuilder tidak memantau .obs, dan Obx/GetX tidak peduli pada update(). Keduanya adalah dua "jalur" yang terpisah.

Contoh lengkap: membuktikan perbedaan rebuild

Setiap kartu menampilkan berapa kali ia di-build. Tekan tombol dan amati angka mana yang naik.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Demo rebuild: angka "build ke-N" menunjukkan berapa kali tiap bagian di-build
import 'package:flutter/material.dart';
import 'package:get/get.dart';

class ProfilController extends GetxController {
  // Reaktif: dipantau oleh Obx / GetX
  final nama = 'Andi'.obs;
  final poin = 0.obs;

  // Non-reaktif: hanya diperbarui lewat update() untuk GetBuilder
  int bintang = 0;

  void tambahPoin() => poin.value++;

  void gantiNama() => nama.value = nama.value == 'Andi' ? 'Bunga' : 'Andi';

  void tambahBintang() {
    bintang++;
    update(); // beri tahu semua GetBuilder<ProfilController>
  }
}

// Penghitung build HANYA untuk keperluan demo (jangan ditiru di aplikasi nyata)
final Map<String, int> jumlahBuild = {};
int catatBuild(String nama) => jumlahBuild[nama] = (jumlahBuild[nama] ?? 0) + 1;

void main() {
  Get.put(ProfilController());
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepOrange),
      home: const DemoView(),
    );
  }
}

class DemoView extends GetView<ProfilController> {
  const DemoView({super.key});

  @override
  Widget build(BuildContext context) {
    // Halaman ini tidak membaca .value di luar Obx, jadi tidak ikut rebuild
    final n = catatBuild('halaman');
    return Scaffold(
      appBar: AppBar(title: Text('Obx vs GetX vs GetBuilder ($n)')),
      body: ListView(
        padding: const EdgeInsets.all(12),
        children: [
          const KartuObxSemua(),
          const KartuObxNama(),
          const KartuGetX(),
          const KartuGetBuilder(),
          const SizedBox(height: 12),
          Row(
            children: [
              Expanded(
                child: FilledButton(
                  onPressed: controller.tambahPoin,
                  child: const Text('Tambah Poin'),
                ),
              ),
              const SizedBox(width: 8),
              Expanded(
                child: OutlinedButton(
                  onPressed: controller.gantiNama,
                  child: const Text('Ganti Nama'),
                ),
              ),
            ],
          ),
          const SizedBox(height: 8),
          FilledButton.tonal(
            onPressed: controller.tambahBintang,
            child: const Text('Tambah Bintang'),
          ),
        ],
      ),
    );
  }
}

class KartuObxSemua extends GetView<ProfilController> {

  @override
  Widget build(BuildContext context) {
    return Card(

        final n = catatBuild('obx-semua');
        return ListTile(
          title: Text('Obx: ${controller.nama.value}, ${controller.poin.value} poin'),
          subtitle: Text('build ke-$n'),
        );
      }),
    );
  }
}

// 2) Obx yang hanya membaca nama: rebuild HANYA jika nama berubah
class KartuObxNama extends GetView<ProfilController> {
  const KartuObxNama({super.key});

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Obx(() {
        final n = catatBuild('obx-nama');
        return ListTile(
          title: Text('Obx(nama): ${controller.nama.value}'),
          subtitle: Text('build ke-$n'),
        );
      }),
    );
  }

// 3) GetX<T>: seperti Obx, tetapi controller diberikan lewat parameter builder
class KartuGetX extends StatelessWidget {
  const KartuGetX({super.key});

  @override
  Widget build(BuildContext context) {
    final nLuar = catatBuild('getx-luar');
    return Card(
      child: GetX<ProfilController>(
        builder: (c) {
          final nDalam = catatBuild('getx-dalam');
          return ListTile(
            title: Text('GetX(poin): ${c.poin.value}'),
            subtitle: Text('luar build ke-$nLuar, builder ke-$nDalam'),
          );
        },
      ),
    );
  }
}

// 4) GetBuilder: TIDAK memantau .obs, hanya bereaksi pada update()
class KartuGetBuilder extends StatelessWidget {
  const KartuGetBuilder({super.key});

  @override
  Widget build(BuildContext context) {
    return Card(
      child: GetBuilder<ProfilController>(
        builder: (c) {
          final n = catatBuild('getbuilder');
          return ListTile(
            title: Text('GetBuilder: ${c.bintang} bintang, ${c.poin.value} poin'),
            subtitle: Text('build ke-$n'),
          );
        },
      ),

Setelah 3x Tambah Poin: Obx(nama) dan GetBuilder tidak rebuild
Dari awal: 1x Ganti Nama lalu 2x Tambah Bintang

Penjelasan hasil:

  • Tambah Poin (gambar kiri): kartu Obx (membaca nama dan poin) serta GetX(poin) naik menjadi build ke-4. Kartu Obx(nama) tetap build ke-1 karena ia tidak membaca poin.
  • Kartu GetBuilder juga tetap build ke-1, bahkan menampilkan "0 poin" padahal poin sudah 3. Mengubah .obs tidak memicu GetBuilder, dan membaca .value di dalam GetBuilder tidak membuatnya reaktif.
  • Ganti Nama lalu Tambah Bintang (gambar kanan): Ganti Nama menaikkan kedua kartu Obx. Dua kali update() menaikkan GetBuilder menjadi build ke-3, sedangkan kartu GetX tetap build ke-1.
  • Angka "luar" pada kartu GetX tidak pernah naik. Seperti Obx, hanya isi builder yang dibangun ulang.
  • Angka di judul AppBar tetap (1): DemoView sendiri tidak pernah rebuild, karena tombol hanya memanggil method controller.

Membatasi rebuild

Prinsipnya sama untuk ketiga widget: bungkus sekecil mungkin bagian yang benar-benar berubah.

  1. Jangan membungkus satu halaman penuh dengan satu Obx besar. Pecah menjadi beberapa Obx kecil, misalnya satu untuk judul, satu untuk ringkasan, satu per baris list.
  2. Di dalam Obx, baca hanya observable yang dibutuhkan. Obx yang membaca nama saja tidak akan rebuild saat poin berubah.
  3. Di callback (onPressed, onTap) cukup panggil method controller. Tidak perlu Obx.
  4. Untuk GetBuilder, pakai id agar update hanya membangun ulang bagian tertentu.

Opsional: GetBuilder dengan id

import 'package:flutter/material.dart';
import 'package:get/get.dart';

class NilaiController extends GetxController {
  int uts = 0;
  int uas = 0;

  void tambahUts() {
    uts++;
    update(['uts']); // hanya GetBuilder dengan id 'uts' yang rebuild
  }

  void tambahUas() {
    uas++;
    update(['uas']);
  }
}

Widget kartuNilai() {
  return Column(
    children: [
      GetBuilder<NilaiController>(
        id: 'uts',
        builder: (c) => Text('UTS: ${c.uts}'),
      ),
      GetBuilder<NilaiController>(
        id: 'uas',
        builder: (c) => Text('UAS: ${c.uas}'),
      ),
    ],
  );
}

update(['uts']) hanya membangun ulang GetBuilder dengan id: 'uts'. Perhatikan juga kebalikannya: update() tanpa argumen hanya membangun ulang GetBuilder yang tidak memakai id.

Ringkasan & tips memilih

SituasiPilihan
Menampilkan state .obs (pilihan utama di kursus ini)Obx
Butuh controller langsung di builder, atau ingin membuatnya di tempat dengan init:GetX<T>
State berupa field biasa dan Anda ingin mengontrol sendiri kapan UI diperbaruiGetBuilder<T> + update()
Hanya memanggil method (tombol, gesture)Tanpa widget apa pun: controller.method()

💡 Cara memilih

  1. Default-nya pakai .obs + Obx. Sederhana dan otomatis.
  2. Pakai GetBuilder jika Anda sengaja tidak memakai .obs, misalnya data yang diubah berkali-kali lalu ditampilkan sekali di akhir proses.
  3. Jangan mencampur dua jalur untuk satu data. Jika poin sudah .obs, tampilkan dengan Obx, bukan GetBuilder.

⚠️ Kesalahan umum

  • Lupa update() setelah mengubah field biasa. Data berubah di memori, tetapi GetBuilder tidak pernah dibangun ulang.
  • Mengharapkan GetBuilder bereaksi pada .obs, seperti kartu GetBuilder pada demo di atas yang tetap "0 poin".
  • Satu Obx untuk seluruh halaman. Benar secara fungsi, tetapi setiap perubahan kecil membangun ulang semuanya. Pecah menjadi Obx kecil.
  • Memanggil update() di dalam builder. Widget diminta rebuild saat sedang dibangun, sehingga muncul error atau rebuild berulang. update() hanya dipanggil di method yang mengubah state.
