State reaktif adalah inti GetX: nilai yang dibungkus .obs akan "mengabari" siapa pun yang membacanya ketika berubah, dan widget Obx otomatis membangun ulang dirinya. Tidak ada setState, tidak ada panggilan "beri tahu" manual.

Tiga bahan utama

  1. GetxController: class tempat state dan logika disimpan (huruf C pada MVC).
  2. .obs: mengubah nilai biasa menjadi nilai yang bisa diamati (observable). 0.obs menghasilkan RxInt, 'Andi'.obs menghasilkan RxString, dan seterusnya.
  3. Obx(() => ...): widget yang membangun ulang isinya setiap kali observable yang dibaca di dalamnya berubah.

Jenis observable

DitulisTipeMembaca / mengubah

false.obsRxBoolx.value = true, x.toggle()
<String>[].obsRxList<String>Langsung seperti list: x.add(...), x.remove(...), x.length, x.assignAll(...)

Kunci yang sering terlupa: nilai aslinya ada di .value. RxList adalah pengecualian yang nyaman, karena method list (add, remove, length, []) bisa dipanggil langsung dan otomatis memberi tahu pendengarnya.

Contoh kecil: tanpa UI sama sekali

Sebelum menyentuh widget, lihat bahwa observable sudah bisa "didengarkan". Worker ever menjalankan callback setiap kali nilainya berubah. Jalankan dengan flutter run, lalu lihat tulisan di Debug Console (layar emulator akan kosong karena tidak ada runApp).

// lib/main.dart — contoh tanpa UI, hasilnya muncul di konsol (Debug Console)
import 'package:flutter/foundation.dart';
import 'package:get/get.dart';

class CounterController extends GetxController {
  final nilai = 0.obs; // RxInt: int yang bisa "diamati"

  void tambah() => nilai.value++;
}

void main() {
  final c = CounterController();

  // ever: jalankan callback SETIAP kali nilai berubah
  ever<int>(c.nilai, (baru) => debugPrint('Nilai berubah menjadi $baru'));

  c.tambah(); // Nilai berubah menjadi 1
  c.tambah(); // Nilai berubah menjadi 2
  c.nilai.value = 2; // TIDAK tercetak: nilainya sama dengan sebelumnya
  debugPrint('Nilai akhir: ${c.nilai.value}'); // Nilai akhir: 2
}
  • 0.obs membuat RxInt. Nilainya dibaca dan diubah lewat nilai.value.
  • ever(observable, callback) mendaftarkan fungsi yang dipanggil setiap kali nilai berubah. Kita akan memakai worker seperti ini lagi di section 9.
  • Mengisi nilai yang sama (2 menjadi 2) tidak memicu callback. GetX hanya memberi tahu jika nilainya benar-benar berubah, sehingga rebuild yang sia-sia dihindari.
  • Tidak ada pemanggilan "beri tahu pendengar" secara manual. Mengubah .value sudah cukup.

Contoh lengkap: absensi kelas dengan Obx

Contoh ini memakai kelima jenis observable sekaligus: RxString, RxInt, RxBool, RxList, dan RxnString.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: flutter pub add get
import 'package:flutter/material.dart';
import 'package:get/get.dart';

class AbsensiController extends GetxController {
  final kelas = 'Pemrograman Mobile A'.obs; // RxString
  final pertemuan = 1.obs; // RxInt
  final terkunci = false.obs; // RxBool
  final hadir = <String>[].obs; // RxList<String>
  final terakhir = RxnString(); // Rxn: boleh bernilai null

  final mahasiswa = const ['Andi', 'Bunga', 'Citra', 'Dodi', 'Eka'];

  void toggleHadir(String nama) {
    if (terkunci.value) return; // absensi dikunci, abaikan
    if (hadir.contains(nama)) {
      hadir.remove(nama); // RxList memberi tahu Obx otomatis
    } else {
      hadir.add(nama);
    }
    terakhir.value = nama;
  }

  void toggleKunci() => terkunci.toggle(); // sama dengan value = !value

  void pertemuanBerikutnya() {
    pertemuan.value++;
    hadir.clear();
    terakhir.value = null;
    terkunci.value = false;
  }
}

void main() {
  Get.put(AbsensiController());
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const AbsensiView(),
    );
  }
}

// StatelessWidget: tidak ada setState sama sekali
class AbsensiView extends StatelessWidget {
  const AbsensiView({super.key});

  @override
  Widget build(BuildContext context) {
    final c = Get.find<AbsensiController>();

    return Scaffold(
      appBar: AppBar(
        // Obx kecil 1: hanya membaca kelas dan pertemuan
        title: Obx(() => Text('${c.kelas.value} • P${c.pertemuan.value}')),
      ),
      body: ListView(
        children: [
          // Obx kecil 2: ringkasan
          Obx(
            () => Card(
              margin: const EdgeInsets.all(16),
              child: ListTile(
                leading: const Icon(Icons.how_to_reg),
                title: Text('Hadir: ${c.hadir.length} dari ${c.mahasiswa.length}'),
                subtitle: Text('Terakhir diubah: ${c.terakhir.value ?? '-'}'),
              ),
            ),
          ),
          // Obx kecil 3: saklar kunci
          Obx(
            () => SwitchListTile(
              title: const Text('Kunci absensi'),
              value: c.terkunci.value,
              onChanged: (_) => c.toggleKunci(),
            ),
          ),
          const Divider(),
          // Satu Obx per baris: baris lain tidak ikut dibangun ulang
          for (final nama in c.mahasiswa)
            Obx(
              () => CheckboxListTile(
                title: Text(nama),
                value: c.hadir.contains(nama),
                onChanged: c.terkunci.value ? null : (_) => c.toggleHadir(nama),
              ),
            ),
          Padding(
            padding: const EdgeInsets.all(16),
            child: OutlinedButton.icon(
              onPressed: c.pertemuanBerikutnya,
              icon: const Icon(Icons.skip_next),
              label: const Text('Pertemuan Berikutnya'),
            ),
          ),
        ],
      ),
    );
  }
}
Andi dan Citra dicentang, lalu absensi dikunci

Penjelasan:

  • AbsensiView adalah StatelessWidget, tetapi ringkasan, saklar, dan checkbox tetap berubah. Yang memicu rebuild adalah Obx, bukan setState.
  • Setiap Obx hanya mendengarkan observable yang dibaca di dalamnya. Obx di AppBar membaca kelas dan pertemuan, sehingga tidak ikut dibangun ulang saat checkbox dicentang.
  • Setiap baris mahasiswa punya Obx sendiri. Baris itu membaca hadir dan terkunci, jadi ketika kunci diaktifkan semua checkbox langsung menjadi abu-abu (nonaktif).
  • terakhir bertipe RxnString karena awalnya belum ada nama yang diubah (null). Di View kita tampilkan '-' dengan operator ??.
  • hadir.clear(), hadir.add(), dan hadir.remove() langsung memicu Obx karena hadir adalah RxList.

Bedanya dengan setState

AspeksetStateGetX (.obs + Obx)

⚠️ Kesalahan umum

  • Lupa .value. Text('${c.pertemuan}') memang menampilkan angka, tetapi biasakan menulis c.pertemuan.value agar jelas yang dibaca adalah isinya. Saat mengubah, c.pertemuan = 2 bahkan error; yang benar c.pertemuan.value = 2.
  • Obx yang tidak membaca observable apa pun. Misalnya Obx(() => Text(namaBiasa)). GetX akan melempar error "improper use of GetX" karena Obx tidak tahu harus mendengarkan apa.
  • Membaca .value di luar Obx, misalnya final n = c.pertemuan.value; di awal build lalu dipakai di Text biasa. Nilai itu dibaca sekali dan tidak pernah diperbarui.
  • Membuat .obs di dalam method build. Setiap rebuild membuat observable baru dan state hilang. Simpan observable di controller.
