Data dari internet atau database tidak datang seketika. Selama menunggu, View harus menampilkan loading; jika gagal, menampilkan error dengan tombol coba lagi; jika berhasil, menampilkan data. Pola tiga serangkai isLoading / error / data ini disimpan di controller dan akan dipakai ulang di Modul 09 (REST API) serta proyek CRUD Modul 13–14.

Pola di sisi View

// Di dalam Obx. Urutan pengecekan: loading -> error -> kosong -> data
Obx(() {
  if (controller.isLoading) return const CircularProgressIndicator();
  if (controller.error != null) return Text(controller.error!);
  if (controller.data.isEmpty) return const Text('Belum ada data');
  return ListView(children: [for (final d in controller.data) Text(d.nama)]);
})

Pola di sisi controller

  1. Set _isLoading.value = true dan kosongkan _error.value. Karena keduanya observable, Obx langsung menampilkan loading tanpa perlu memanggil method pemberi tahu apa pun.
  2. try: panggil service dan simpan hasilnya dengan _data.assignAll(...).
  3. catch: simpan pesan error.
  4. finally: set _isLoading.value = false. Bagian finally selalu dijalankan, sehingga loading tidak "macet".
  5. Panggil method pemuatan itu di onInit() agar data dimuat sekali saat controller dibuat (section 7).

📄 lib/controllers/mahasiswa_controller.dart

// lib/controllers/mahasiswa_controller.dart
import 'package:get/get.dart';

import '../models/mahasiswa.dart';
import '../services/mahasiswa_service.dart';

class MahasiswaController extends GetxController {
  MahasiswaController(this._service); // service disuntikkan lewat constructor

  final MahasiswaService _service;

  // Tiga serangkai state async, semuanya observable
  final _isLoading = false.obs;
  final _error = RxnString(); // null = tidak ada error
  final _data = <Mahasiswa>[].obs;

  bool get isLoading => _isLoading.value;
  String? get error => _error.value;
  List<Mahasiswa> get data => List.unmodifiable(_data);

  @override
  void onInit() {
    super.onInit();
    muatData(); // pemuatan awal: sekali saat controller dibuat
  }

  Future<void> muatData({bool simulasiGagal = false}) async {
    if (_isLoading.value) return; // cegah request ganda

    _isLoading.value = true; // Obx langsung menampilkan loading
    _error.value = null; // hapus error lama

    try {
      final hasil = await _service.ambilSemua(simulasiGagal: simulasiGagal);
      _data.assignAll(hasil); // ganti seluruh isi list sekaligus
    } catch (e) {
      _error.value = 'Gagal memuat data: ${e.toString().replaceFirst('Exception: ', '')}';
    } finally {
      _isLoading.value = false; // SELALU dimatikan, berhasil maupun gagal
    }
  }
}

// lib/views/mahasiswa_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/mahasiswa_controller.dart';

class MahasiswaView extends GetView<MahasiswaController> {
  const MahasiswaView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Data Mahasiswa'),
        actions: [
          IconButton(
            tooltip: 'Simulasi gagal',
            icon: const Icon(Icons.wifi_off),
            onPressed: () => controller.muatData(simulasiGagal: true),
          ),
        ],
      ),
      // Satu Obx untuk isi halaman: membaca isLoading, error, dan data
      body: Obx(() {
        // 1. Loading pertama kali (belum ada data sama sekali)
        if (controller.isLoading && controller.data.isEmpty) {
          return const Center(child: CircularProgressIndicator());
        }

        // 2. Error
        if (controller.error != null) {
          return _TampilanError(
            pesan: controller.error!,
            onCobaLagi: controller.muatData,
          );
        }

        // 3. Data kosong
        if (controller.data.isEmpty) {
          return const Center(child: Text('Belum ada data'));
        }

        // 4. Data tersedia (+ tarik ke bawah untuk memuat ulang)
        final data = controller.data;
        return RefreshIndicator(
          onRefresh: controller.muatData, // harus mengembalikan Future
          child: ListView.builder(
            itemCount: data.length,
            itemBuilder: (context, i) {
              final m = data[i];
              return ListTile(
                leading: CircleAvatar(child: Text(m.nama[0])),
                title: Text(m.nama),
                subtitle: Text(m.nim),
                trailing: Text('IPK ${m.ipk.toStringAsFixed(2)}'),
              );
            },
          ),
        );
      }),
    );
  }
}

class _TampilanError extends StatelessWidget {
  const _TampilanError({required this.pesan, required this.onCobaLagi});

  final String pesan;
  final VoidCallback onCobaLagi;

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            const Icon(Icons.error_outline, size: 64, color: Colors.red),
            const SizedBox(height: 12),
            Text(pesan, textAlign: TextAlign.center),
            const SizedBox(height: 12),
            FilledButton.icon(
              icon: const Icon(Icons.refresh),
              label: const Text('Coba Lagi'),
              onPressed: onCobaLagi,
            ),
          ],
        ),
      ),
    );
  }
}

Penjelasan:

  • Model (Mahasiswa) adalah Dart murni. Service hanya tahu cara mengambil data; ia tidak tahu apa pun soal GetX atau widget.
  • Controller menerima service lewat constructor (dependency injection). Saat testing (Modul 15), service ini bisa diganti dengan versi palsu tanpa mengubah controller.
  • onInit() memanggil muatData(). Tidak perlu initState atau addPostFrameCallback di View, karena controller sudah tahu kapan ia dibuat.
  • RxnString() adalah observable yang boleh bernilai null. null berarti "tidak ada error".
  • _data.assignAll(hasil) mengganti seluruh isi RxList dan memicu satu kali rebuild.
  • if (_isLoading.value) return; mencegah request ganda saat tombol ditekan berkali-kali.
  • View memakai satu Obx untuk isi halaman. Obx itu otomatis mendengarkan isLoading, error, dan data karena ketiganya dibaca di dalam builder.
  • Kondisi loading ditulis isLoading && data.isEmpty: saat refresh (data lama masih ada), daftar tetap tampil dan yang berputar adalah indikator RefreshIndicator.
  • onRefresh: controller.muatData bisa langsung dipakai karena muatData mengembalikan Future; indikator berhenti berputar saat Future selesai.
  • Tombol ikon wifi mensimulasikan kegagalan sehingga tampilan error bisa dicoba tanpa mematikan internet. Tekan Coba Lagi untuk memuat ulang dengan normal.

💡 Variasi: enum status

Sebagian tim memakai final status = Status.awal.obs; dengan enum Status { awal, loading, sukses, gagal } sebagai pengganti beberapa boolean. Keduanya sah; yang penting View selalu menangani semua kemungkinan. GetX juga punya StateMixin dengan obx(onLoading:, onError:), tetapi kursus ini memakai pola eksplisit di atas agar mudah dipindah ke state management lain.

⚠️ Kesalahan umum

  • Tidak memakai finally: jika terjadi error, isLoading tetap true selamanya dan View terjebak di loading.
  • Tidak mengosongkan _error.value saat mencoba lagi, sehingga pesan error lama tetap tampil walaupun request kedua berhasil.
  • Memanggil muatData() di build() View. Setiap rebuild memicu request baru, dan karena isLoading berubah, Obx rebuild lagi: request tidak pernah berhenti. Tempatnya di onInit.
  • Memanggil service langsung dari View. View hanya boleh bicara dengan controller.
