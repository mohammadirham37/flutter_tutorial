Studi kasus penutup: aplikasi Tugas Kuliah (todo) dengan fitur tambah, centang selesai, hapus (geser), filter, badge jumlah tugas aktif, dan halaman statistik. Satu TodoController dipakai bersama oleh tiga View, dan semuanya disusun dengan pola MVC.

Struktur folder

lib/
├── main.dart
├── models/todo.dart                  # M
├── controllers/todo_controller.dart  # C
└── views/                            # V
    ├── todo_list_view.dart
    ├── tambah_todo_view.dart
    └── statistik_view.dart

Data masih disimpan di memori, jadi belum ada folder services/. Saat todo disimpan ke penyimpanan lokal (Modul 10–11) atau Supabase (Modul 12), cukup tambahkan service dan suntikkan ke controller seperti di section 8. View tidak perlu diubah.

Langkah 1: model

📄 lib/models/todo.dart

// lib/models/todo.dart
class Todo {
  final String id;
  final String judul;
  final String matkul;
  final bool selesai;

  const Todo({
    required this.id,
    required this.judul,
    required this.matkul,
    this.selesai = false,
  });

  // Membuat salinan dengan sebagian field diubah (objek tetap immutable)
  Todo copyWith({String? judul, String? matkul, bool? selesai}) {
    return Todo(
      id: id,
      judul: judul ?? this.judul,
      matkul: matkul ?? this.matkul,
      selesai: selesai ?? this.selesai,
    );
  }
}

enum FilterTodo { semua, aktif, selesai }

copyWith membuat salinan objek dengan sebagian field diganti. Objek Todo tidak pernah diubah langsung; yang diganti adalah elemen di RxList, sehingga Obx pasti tahu ada perubahan (ingat kesalahan nomor 4 di section 11).

Langkah 2: controller

📄 lib/controllers/todo_controller.dart

// lib/controllers/todo_controller.dart
import 'package:get/get.dart';

import '../models/todo.dart';

class TodoController extends GetxController {
  final _todos = <Todo>[
    const Todo(id: '1', judul: 'Laporan praktikum Flutter', matkul: 'Pemrograman Mobile'),
    const Todo(id: '2', judul: 'Normalisasi tabel KRS', matkul: 'Basis Data', selesai: true),
  ].obs;
  final _filter = FilterTodo.semua.obs;

  // ---------- GETTER (data turunan dihitung, tidak disimpan) ----------
  FilterTodo get filter => _filter.value;
  int get jumlahTotal => _todos.length;
  int get jumlahSelesai => _todos.where((t) => t.selesai).length;
  int get jumlahAktif => jumlahTotal - jumlahSelesai;
  double get progres => jumlahTotal == 0 ? 0 : jumlahSelesai / jumlahTotal;

  List<Todo> get todosTampil {
    switch (_filter.value) {
      case FilterTodo.semua:
        return List.unmodifiable(_todos);
      case FilterTodo.aktif:
        return _todos.where((t) => !t.selesai).toList();
      case FilterTodo.selesai:
        return _todos.where((t) => t.selesai).toList();
    }
  }

  Todo? cariById(String id) => _todos.firstWhereOrNull((t) => t.id == id);

  // ---------- AKSI (cukup ubah observable, Obx otomatis rebuild) ----------
  void tambah(String judul, String matkul) {
    final id = DateTime.now().microsecondsSinceEpoch.toString();
    _todos.insert(0, Todo(id: id, judul: judul, matkul: matkul));
  }

  void toggle(String id) {
    final i = _todos.indexWhere((t) => t.id == id);
    if (i == -1) return;
    // ganti elemen dengan salinan baru, bukan mengubah field-nya
    _todos[i] = _todos[i].copyWith(selesai: !_todos[i].selesai);
  }

  void hapus(String id) => _todos.removeWhere((t) => t.id == id);

  void hapusYangSelesai() => _todos.removeWhere((t) => t.selesai);

  void ubahFilter(FilterTodo f) => _filter.value = f;
}
  • Hanya dua observable: _todos (RxList) dan _filter (Rx<FilterTodo>, dibuat dengan FilterTodo.semua.obs).
  • Data turunan (jumlahAktif, progres, todosTampil) berupa getter yang dihitung dari _todos, tidak disimpan terpisah, sehingga tidak mungkin "tidak sinkron". Obx yang memanggil getter ini tetap reaktif karena getter membaca observable di dalamnya.
  • Setiap aksi cukup mengubah observable. Tidak ada update() yang bisa terlupa seperti pada GetBuilder (section 5).
  • Controller hanya mengimpor package:get/get.dart dan model. Tidak ada material.dart.

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/todo_controller.dart';

void main() {
  runApp(const TodoApp());
}

class TodoApp extends StatelessWidget {
  const TodoApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'Tugas Kuliah',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      // Satu TodoController untuk seluruh aplikasi
      initialBinding: BindingsBuilder(() {
        Get.put(TodoController(), permanent: true);
      }),
      home: const TodoListView(),
    );
  }
}

Karena binding-nya hanya satu baris, dipakai BindingsBuilder (section 7) alih-alih membuat class AppBinding.

Langkah 4: halaman daftar

📄 lib/views/todo_list_view.dart

// lib/views/todo_list_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/todo_controller.dart';
import '../models/todo.dart';
import 'statistik_view.dart';
import 'tambah_todo_view.dart';

class TodoListView extends GetView<TodoController> {
  const TodoListView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Tugas Kuliah'),
        actions: [
          IconButton(
            tooltip: 'Statistik',
            // Obx kecil: hanya badge yang rebuild saat jumlah aktif berubah
            icon: Obx(
              () => Badge(
                label: Text('${controller.jumlahAktif}'),
                child: const Icon(Icons.insights),
              ),
            ),
            onPressed: () => Get.to(() => const StatistikView()),
          ),
        ],
      ),
      body: const Column(
        children: [
          _FilterBar(),
          Expanded(child: _DaftarTodo()),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        icon: const Icon(Icons.add),
        label: const Text('Tugas Baru'),
        onPressed: () => Get.to(() => const TambahTodoView()),
      ),
    );
  }
}

class _FilterBar extends GetView<TodoController> {
  const _FilterBar();

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(12),
      // Obx ini hanya membaca filter, tidak ikut rebuild saat todo dicentang
      child: Obx(
        () => SegmentedButton<FilterTodo>(
          segments: const [
            ButtonSegment(value: FilterTodo.semua, label: Text('Semua')),
            ButtonSegment(value: FilterTodo.aktif, label: Text('Aktif')),
            ButtonSegment(value: FilterTodo.selesai, label: Text('Selesai')),
          ],
          selected: {controller.filter},
          onSelectionChanged: (pilihan) => controller.ubahFilter(pilihan.first),
        ),
      ),
    );
  }
}

class _DaftarTodo extends GetView<TodoController> {
  const _DaftarTodo();

  @override
  Widget build(BuildContext context) {
    return Obx(() {
      final todos = controller.todosTampil;

      if (todos.isEmpty) {
        return const Center(child: Text('Tidak ada tugas di filter ini'));
      }

      return ListView.builder(
        itemCount: todos.length,
        itemBuilder: (context, i) {
          final t = todos[i];
          return Dismissible(
            key: ValueKey(t.id),
            direction: DismissDirection.endToStart,
            background: Container(
              color: Colors.red,
              alignment: Alignment.centerRight,
              padding: const EdgeInsets.only(right: 20),
              child: const Icon(Icons.delete, color: Colors.white),
            ),
            onDismissed: (_) {
              controller.hapus(t.id);
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('"${t.judul}" dihapus')),
              );
            },
            child: CheckboxListTile(
              value: t.selesai,
              onChanged: (_) => controller.toggle(t.id),
              title: Text(
                t.judul,
                style: TextStyle(
                  decoration: t.selesai ? TextDecoration.lineThrough : null,
                ),
              ),
              subtitle: Text(t.matkul),
            ),
          );
        },
      );
    });
  }
}

Langkah 5: halaman tambah

📄 lib/views/tambah_todo_view.dart

// lib/views/tambah_todo_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/todo_controller.dart';

// StatefulWidget: isi form (judul, matkul terpilih) adalah state LOKAL
class TambahTodoView extends StatefulWidget {
  const TambahTodoView({super.key});

  @override
  State<TambahTodoView> createState() => _TambahTodoViewState();
}

class _TambahTodoViewState extends State<TambahTodoView> {
  final _formKey = GlobalKey<FormState>();
  final _judulController = TextEditingController();
  String _matkul = 'Pemrograman Mobile';

  static const daftarMatkul = ['Pemrograman Mobile', 'Basis Data', 'Jaringan Komputer'];

  @override
  void dispose() {
    _judulController.dispose();
    super.dispose();
  }

  void _simpan() {
    if (!_formKey.currentState!.validate()) return;
    // Tidak perlu mengembalikan data lewat Get.back(result: ...): controller yang menyimpan
    Get.find<TodoController>().tambah(_judulController.text.trim(), _matkul);
    Get.back();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tugas Baru')),
      body: Form(
        key: _formKey,
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            TextFormField(
              controller: _judulController,
              decoration: const InputDecoration(
                labelText: 'Judul tugas',
                border: OutlineInputBorder(),
              ),
              validator: (v) =>
                  (v == null || v.trim().isEmpty) ? 'Judul wajib diisi' : null,
            ),
            const SizedBox(height: 16),
            DropdownButtonFormField<String>(
              initialValue: _matkul,
              decoration: const InputDecoration(
                labelText: 'Mata kuliah',
                border: OutlineInputBorder(),
              ),
              items: [
                for (final m in daftarMatkul) DropdownMenuItem(value: m, child: Text(m)),
              ],
              onChanged: (v) => setState(() => _matkul = v ?? _matkul),
            ),
            const SizedBox(height: 24),
            FilledButton(onPressed: _simpan, child: const Text('Simpan')),
          ],
        ),
      ),
    );
  }
}

// lib/views/statistik_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/todo_controller.dart';

class StatistikView extends GetView<TodoController> {
  const StatistikView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Statistik')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Obx(
          () => Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              Text(
                '${(controller.progres * 100).round()}% selesai',
                style: Theme.of(context).textTheme.headlineMedium,
              ),
              const SizedBox(height: 8),
              LinearProgressIndicator(value: controller.progres, minHeight: 10),
              const SizedBox(height: 16),
              Card(
                child: Column(
                  children: [
                    ListTile(
                      title: const Text('Total tugas'),
                      trailing: Text('${controller.jumlahTotal}'),
                    ),
                    ListTile(
                      title: const Text('Aktif'),
                      trailing: Text('${controller.jumlahAktif}'),
                    ),
                    ListTile(
                      title: const Text('Selesai'),
                      trailing: Text('${controller.jumlahSelesai}'),
                    ),
                  ],
                ),
              ),
              const SizedBox(height: 16),
              OutlinedButton.icon(
                icon: const Icon(Icons.cleaning_services),
                label: const Text('Hapus semua yang selesai'),
                onPressed: controller.jumlahSelesai == 0
                    ? null
                    : controller.hapusYangSelesai,
              ),
            ],
          ),
        ),
      ),
    );
  }
}

BagianTeknikAlasan

ℹ️ Bandingkan dengan Modul 07

Di studi kasus Modul 07, data KRS harus dioper lewat constructor dan callback, dan halaman tambah mengembalikan hasil lewat Navigator.pop. Di sini, ketiga View cukup mengambil TodoController dengan Get.find/GetView, dan setiap perubahan langsung terlihat di semua halaman berkat Obx. Pola yang sama dipakai di proyek CRUD Modul 13–14, dengan tambahan service, status loading/error dari section 8, dan auth gate dari section 10.
