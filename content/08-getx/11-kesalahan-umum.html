Bagian ini merangkum kesalahan GetX yang paling sering muncul di praktikum, lengkap dengan pesan error asli (diambil dari konsol flutter run dan flutter analyze) dan cara memperbaikinya.

1. Obx tanpa observable

class CounterController extends GetxController {
  int nilai = 0; // ❌ BUKAN observable
}

// di View
Obx(() => Text('Nilai: ${c.nilai}')) // ❌ tidak ada .obs yang dibaca

Begitu halaman dibuka, layar merah muncul dan konsol menampilkan:

══╡ EXCEPTION CAUGHT BY WIDGETS LIBRARY ╞════════════════════════
The following message was thrown building Obx(has builder, dirty, state: ObxState#33f31):
      [Get] the improper use of a GetX has been detected.
      You should only use GetX or Obx for the specific widget that will be updated.
      If you are seeing this error, you probably did not insert any observable variables into
GetX/Obx
      or insert them outside the scope that GetX considers suitable for an update
      (example: GetX => HeavyWidget => variableObservable).
      If you need to update a parent widget and a child widget, wrap each one in an Obx/GetX.

Perbaikan: jadikan field-nya observable (final nilai = 0.obs;), atau jika memang tidak perlu reaktif, buang Obx-nya. Error yang sama muncul bila observable dibaca di luar builder Obx, misalnya disimpan ke variabel lokal sebelum Obx(() => ...), atau dibaca di dalam widget lain yang punya method build sendiri.

// ❌ dibaca di luar Obx: Obx tidak melihat observable apa pun
final teks = c.nama.value;
return Obx(() => Text(teks));

// ✅ dibaca di DALAM builder Obx
return Obx(() => Text(c.nama.value));

2. Lupa .value atau tertukar antara Rx dan nilainya

Sebagian besar kasus ini ditangkap flutter analyze sebelum aplikasi dijalankan:

final isLoading = false.obs;   // RxBool
final nama = 'Andi'.obs;       // RxString
final count = 0.obs;           // RxInt

if (c.isLoading) {}            // ❌ error: Conditions must have a static type of 'bool'.
String n = c.nama;             // ❌ error: A value of type 'RxString' can't be assigned
                               //    to a variable of type 'String'.
Text(c.nama);                  // ❌ error: The argument type 'RxString' can't be assigned
                               //    to the parameter type 'String'.
c.count = 3;                   // ❌ error: 'count' can't be used as a setter because it's final.
if (5 == c.count) {}           // ⚠️ info: unrelated_type_equality_checks, dan hasilnya SELALU false

// ✅ BENAR
if (c.isLoading.value) {}
String n = c.nama.value;
Text(c.nama.value);
c.count.value = 3;
if (c.count.value == 5) {}

Kasus yang tidak tertangkap analyzer dan paling menjebak: field Rx dideklarasikan dengan var, lalu diganti dengan objek Rx baru.

var skor = 0.obs;

void reset() {
  skor = 0.obs; // ❌ Obx masih mendengarkan objek Rx LAMA, layar tidak berubah
}

// ✅ selalu deklarasikan Rx dengan final, ubah isinya lewat .value
final skor = 0.obs;
void reset() => skor.value = 0;

💡 Getter menyelamatkan Anda

Pola dari section 6 (field Rx privat + getter yang mengembalikan .value, misalnya bool get isLoading => _isLoading.value;) menghilangkan hampir semua kesalahan ini. View cukup menulis controller.isLoading tanpa memikirkan .value.

4. Mengubah field objek di dalam RxList

class Tugas {
  Tugas(this.judul);
  final String judul;
  bool selesai = false; // field mutable
}

final tugas = <Tugas>[Tugas('Laporan'), Tugas('Kuis')].obs;

void toggle(int i) {
  tugas[i].selesai = !tugas[i].selesai; // ❌ checkbox TIDAK berubah di layar
}

Tidak ada pesan error sama sekali, tetapi checkbox tidak tercentang. RxList hanya tahu ketika isi list berubah (tambah, hapus, ganti elemen). Mengubah field di dalam objek yang sama tidak terdeteksi. Dua perbaikan:

// ✅ Cara 1 (disarankan): model immutable + copyWith, lalu GANTI elemennya
_items[i] = _items[i].copyWith(selesai: !_items[i].selesai);

// ✅ Cara 2: tetap mutable, lalu beri tahu Obx secara manual
tugas[i].selesai = !tugas[i].selesai;
tugas.refresh();

Aturan yang sama berlaku untuk Rx<ObjekBiasa>: setelah mengubah field-nya, panggil .refresh() atau ganti seluruh objek lewat .value.

Contoh lengkap: semua perbaikan dalam satu aplikasi

Aplikasi Pengumuman berikut menerapkan perbaikan di atas: GetMaterialApp, controller per halaman lewat binding (dihapus otomatis), data dimuat di onInit, elemen RxList diganti dengan copyWith, dan halaman detail memakai controller yang sama lewat GetView.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Contoh BENAR: controller per halaman lewat binding, data dimuat di onInit,
// elemen RxList diganti (bukan diubah isinya), halaman detail memakai Get.find.
import 'package:flutter/material.dart';
import 'package:get/get.dart';

// ---------- MODEL (immutable) ----------
class Pengumuman {
  final String id;
  final String judul;
  final bool dibaca;

  const Pengumuman({required this.id, required this.judul, this.dibaca = false});

  Pengumuman copyWith({bool? dibaca}) =>
      Pengumuman(id: id, judul: judul, dibaca: dibaca ?? this.dibaca);
}

// ---------- CONTROLLER ----------
class PengumumanController extends GetxController {
  final _isLoading = false.obs;
  final _items = <Pengumuman>[].obs;

  bool get isLoading => _isLoading.value;
  List<Pengumuman> get items => List.unmodifiable(_items);

  Pengumuman? cari(String id) => _items.firstWhereOrNull((p) => p.id == id);

  @override
  void onInit() {
    super.onInit();
    muat(); // ✅ sekali, bukan di build
  }

  Future<void> muat() async {
    _isLoading.value = true;
    try {
      await Future.delayed(const Duration(seconds: 1));
      _items.assignAll(const [
        Pengumuman(id: '1', judul: 'Libur Dies Natalis'),
        Pengumuman(id: '2', judul: 'Jadwal UTS'),
        Pengumuman(id: '3', judul: 'Beasiswa PPA'),
      ]);
    } finally {
      _isLoading.value = false;
    }
  }

  void tandaiDibaca(String id) {
    final i = _items.indexWhere((p) => p.id == id);
    if (i == -1) return;
    // ✅ GANTI elemennya, RxList langsung memberi tahu Obx
    _items[i] = _items[i].copyWith(dibaca: true);
  }

  @override
  void onClose() {
    debugPrint('PengumumanController dihapus');
    super.onClose();
  }
}

// ---------- BINDING ----------
class PengumumanBinding extends Bindings {
  @override
  void dependencies() {
    Get.lazyPut(() => PengumumanController());
  }
}

// ---------- APP ----------
void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    // ✅ GetMaterialApp, bukan MaterialApp, karena memakai Get.to
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.blueGrey),
      home: const MenuView(),
    );
  }
}

class MenuView extends StatelessWidget {
  const MenuView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Menu')),
      body: Center(
        child: FilledButton(
          // ✅ controller dibuat oleh binding saat halaman dibuka,
          //    dan dihapus otomatis saat halaman ditutup
          onPressed: () => Get.to(
            () => const PengumumanView(),
            binding: PengumumanBinding(),
          ),
          child: const Text('Buka Pengumuman'),
        ),
      ),
    );
  }
}

class PengumumanView extends GetView<PengumumanController> {
  const PengumumanView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pengumuman')),
      body: Obx(() {
        if (controller.isLoading) {
          return const Center(child: CircularProgressIndicator());
        }
        return ListView(
          children: [
            for (final p in controller.items)
              ListTile(
                title: Text(p.judul),
                trailing: p.dibaca
                    ? const Icon(Icons.done_all, color: Colors.green)
                    : null,
                // ✅ cukup kirim id; detail mengambil controller yang SAMA
                onTap: () => Get.to(() => DetailPengumumanView(id: p.id)),
              ),
          ],
        );
      }),
    );
  }
}

class DetailPengumumanView extends GetView<PengumumanController> {
  const DetailPengumumanView({super.key, required this.id});

  final String id;

  @override
  Widget build(BuildContext context) {
    return Obx(() {
      final p = controller.cari(id);
      if (p == null) return const Scaffold(body: Center(child: Text('Tidak ditemukan')));
      return Scaffold(
        appBar: AppBar(title: Text(p.judul)),
        body: Center(
          child: FilledButton.icon(
            icon: Icon(p.dibaca ? Icons.done_all : Icons.mark_email_read),
            label: Text(p.dibaca ? 'Sudah dibaca' : 'Tandai sudah dibaca'),
            onPressed: p.dibaca ? null : () => controller.tandaiDibaca(id),
          ),
        ),
      );
    });
  }
}
Kembali ke daftar: tanda dibaca langsung muncul
Halaman detail memakai controller yang sama (Get.find)

Penjelasan:

  • PengumumanBinding dipasang di Get.to(..., binding: ...). Controller dibuat saat halaman Pengumuman dibuka; saat halaman ditutup, konsol mencetak PengumumanController dihapus.
  • muat() dipanggil sekali di onInit, dengan finally agar loading pasti berhenti.
  • Pengumuman immutable. tandaiDibaca mengganti elemen list dengan salinan baru, sehingga semua Obx yang membaca items rebuild.
  • DetailPengumumanView hanya menerima id, lalu mencari datanya di controller yang sama. Tidak ada objek yang dioper lewat constructor dan tidak ada yang perlu dikembalikan lewat Get.back(result: ...).
  • firstWhereOrNull berasal dari extension GetX (juga ada di package collection): mengembalikan null jika tidak ketemu, alih-alih melempar error.
