Sekarang kita gabungkan semua yang sudah dipelajari dalam satu contoh nyata yang dipecah menjadi beberapa file sesuai pola MVC: pengisian KRS dengan batas maksimal 24 SKS.

Struktur folder

lib/
├── main.dart                       # GetMaterialApp + pendaftaran controller
├── models/
│   └── mata_kuliah.dart            # M: bentuk data
├── controllers/
│   └── krs_controller.dart         # C: state reaktif + aturan 24 SKS
└── views/
    └── katalog_krs_view.dart       # V: katalog + ringkasan KRS

Pasang package terlebih dahulu jika belum: flutter pub add get. Lalu buat folder models, controllers, dan views di dalam lib/.

Langkah 1: Model

📄 lib/models/mata_kuliah.dart

// lib/models/mata_kuliah.dart
// MODEL: data murni, tanpa import Flutter maupun GetX
class MataKuliah {
  final String nama;
  final int sks;

  const MataKuliah(this.nama, this.sks);
}

Model hanya berisi data. Tidak ada import sama sekali, sehingga bisa dipakai di mana saja, termasuk di unit test.

Langkah 2: Controller

📄 lib/controllers/krs_controller.dart

// lib/controllers/krs_controller.dart
// CONTROLLER: state + aturan bisnis. Tidak mengimpor material.dart.
import 'package:get/get.dart';

import '../models/mata_kuliah.dart';

class KrsController extends GetxController {
  static const int batasMaksimalSks = 24;

  // Katalog (data statis). Di section 8 data seperti ini diambil lewat service.
  final List<MataKuliah> katalog = const [
    MataKuliah('Pemrograman Mobile', 4),
    MataKuliah('Basis Data Lanjut', 3),
    MataKuliah('Kecerdasan Buatan', 3),
    MataKuliah('Jaringan Komputer', 3),
    MataKuliah('Rekayasa Perangkat Lunak', 3),
    MataKuliah('Keamanan Siber', 3),
    MataKuliah('Etika Profesi', 2),
    MataKuliah('Kerja Praktik', 4),
  ];

  // State privat reaktif: hanya controller yang boleh mengubah
  final _matkulTerpilih = <MataKuliah>[].obs;

  // Getter publik read-only
  List<MataKuliah> get matkulTerpilih => List.unmodifiable(_matkulTerpilih);

  // Data turunan = getter, tidak disimpan terpisah
  int get totalSks => _matkulTerpilih.fold(0, (total, mk) => total + mk.sks);

  bool sudahDiambil(MataKuliah mk) => _matkulTerpilih.contains(mk);

  /// Mengembalikan false jika kuota terlampaui (atau matkul sudah diambil).
  /// Controller TIDAK menampilkan SnackBar; View yang memutuskan.
  bool tambahMatkul(MataKuliah mk) {
    if (sudahDiambil(mk)) return false;
    if (totalSks + mk.sks > batasMaksimalSks) return false;
    _matkulTerpilih.add(mk); // RxList otomatis memberi tahu Obx
    return true;
  }

  void hapusMatkul(int index) => _matkulTerpilih.removeAt(index);
}
  • _matkulTerpilih adalah RxList privat. Dari luar file ini, satu-satunya cara mengubahnya adalah lewat tambahMatkul dan hapusMatkul, sehingga aturan 24 SKS tidak bisa dilewati.
  • Getter matkulTerpilih mengembalikan List.unmodifiable. Jika View mencoba controller.matkulTerpilih.add(...), aplikasi langsung error dan kesalahan ketahuan sejak awal.
  • totalSks adalah getter (data turunan), bukan field terpisah. Nilainya selalu dihitung dari isi list, jadi tidak mungkin "tidak sinkron". Karena getter ini membaca _matkulTerpilih, Obx yang memanggil controller.totalSks otomatis ikut mendengarkan list tersebut.
  • tambahMatkul mengembalikan bool. Controller yang memutuskan boleh/tidaknya (aturan bisnis), sedangkan View yang menampilkan pesan.
  • Hanya package:get/get.dart yang diimpor, tanpa material.dart. Controller ini bisa diuji dengan unit test biasa.

Langkah 3: View

📄 lib/views/katalog_krs_view.dart

// lib/views/katalog_krs_view.dart
// VIEW: hanya menampilkan state dan meneruskan aksi ke controller
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/krs_controller.dart';

class KatalogKrsView extends GetView<KrsController> {
  const KatalogKrsView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pengisian KRS')),
      body: Column(
        children: [
          const RingkasanKrs(),
          Expanded(
            child: ListView.builder(
              itemCount: controller.katalog.length,
              itemBuilder: (context, index) {
                final mk = controller.katalog[index];
                return ListTile(
                  title: Text(mk.nama),
                  subtitle: Text('${mk.sks} SKS'),
                  // Obx kecil per baris: ikon berubah jika matkul sudah diambil
                  trailing: Obx(() {
                    final diambil = controller.sudahDiambil(mk);
                    return IconButton(
                      tooltip: 'Ambil ${mk.nama}',
                      icon: Icon(
                        diambil ? Icons.check_circle : Icons.add_circle,
                        color: diambil ? Colors.green : Colors.indigo,
                      ),
                      onPressed: diambil
                          ? null
                          : () {
                              final berhasil = controller.tambahMatkul(mk);
                              if (!berhasil) {
                                ScaffoldMessenger.of(context).showSnackBar(
                                  const SnackBar(
                                    content: Text('Kuota maksimal 24 SKS terlampaui!'),
                                    backgroundColor: Colors.red,
                                  ),
                                );
                              }
                            },
                    );
                  }),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

class RingkasanKrs extends GetView<KrsController> {
  const RingkasanKrs({super.key});

  @override
  Widget build(BuildContext context) {
    return Card(
      margin: const EdgeInsets.all(16),
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Obx(() {
          final total = controller.totalSks;
          const batas = KrsController.batasMaksimalSks;
          final terpilih = controller.matkulTerpilih;
          return Column(
            children: [
              Text('Total SKS Diambil: $total / $batas SKS'),
              const SizedBox(height: 8),
              LinearProgressIndicator(
                value: total / batas,
                color: total >= 20 ? Colors.orange : Colors.blue,
              ),
              const SizedBox(height: 8),
              Wrap(
                spacing: 6,
                children: [
                  for (var i = 0; i < terpilih.length; i++)
                    InputChip(
                      label: Text(terpilih[i].nama),
                      onDeleted: () => controller.hapusMatkul(i),
                    ),
                ],
              ),
            ],
          );
        }),
      ),
    );
  }
}

Langkah 4: Mendaftarkan controller di main.dart

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: (1) flutter pub add get, (2) membuat ketiga file di atas
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/krs_controller.dart';
import 'views/katalog_krs_view.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      // Dijalankan sekali sebelum halaman pertama dibangun
      initialBinding: BindingsBuilder(() {
        Get.put(KrsController());
      }),
      home: const KatalogKrsView(),
    );
  }
}
Setelah mengambil tiga mata kuliah: total 10 SKS, ikon berubah menjadi centang

initialBinding dijalankan sekali sebelum halaman pertama dibangun, sehingga KrsController sudah terdaftar ketika KatalogKrsView membaca controller. Cara lain yang sama-sama benar adalah mendaftarkannya di main():

void main() {
  Get.put(KrsController(), permanent: true);
  runApp(const MyApp());
}

Pilih salah satu saja. Bindings yang lebih rapi (class Bindings sendiri dan binding per halaman) dibahas di section 7.

Penjelasan:

  • KatalogKrsView tidak dibungkus Obx, sehingga daftar katalog tidak ikut dibangun ulang ketika SKS bertambah. Hanya ikon di setiap baris yang punya Obx kecil sendiri.
  • RingkasanKrs membungkus isinya dengan satu Obx, sehingga total SKS, progress bar, dan chip selalu sinkron.
  • InputChip.onDeleted memanggil controller.hapusMatkul(i). Ikon di katalog otomatis kembali menjadi tombol tambah karena Obx barisnya membaca sudahDiambil.
  • SnackBar ditampilkan di View dengan ScaffoldMessenger berdasarkan nilai bool dari controller. Controller tidak tahu apa-apa tentang SnackBar.
  • RingkasanKrs tidak menerima data apa pun lewat constructor. Bandingkan dengan contoh prop drilling di section 1.

⚠️ Kesalahan umum

  • Memeriksa batas SKS di View, bukan di controller. Jika ada dua tombol tambah di dua halaman, aturannya harus ditulis dua kali.
  • Mengembalikan _matkulTerpilih langsung dari getter, atau membuatnya publik. View bisa memanggil .add() dan melewati pengecekan kuota.
  • Menyimpan totalSks sebagai .obs terpisah lalu lupa memperbaruinya saat menghapus mata kuliah. Data turunan cukup ditulis sebagai getter.
  • Salah path import (misalnya import 'krs_controller.dart'; dari folder views/). Dari views/ gunakan '../controllers/krs_controller.dart', dari main.dart gunakan 'controllers/krs_controller.dart'.
