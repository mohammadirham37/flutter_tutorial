Dependency injection berarti sebuah objek (misalnya controller) dibuat dan disediakan oleh pihak luar, bukan dibuat sendiri oleh widget yang membutuhkannya. Di GetX, kita "menitipkan" controller ke sebuah wadah global dengan Get.put, lalu widget mana pun bisa mengambilnya dengan Get.find, tanpa constructor berantai.

Daftar API yang perlu dikenal

APIFungsinyaKapan dipakai
Get.put(X())Membuat objek sekarang juga lalu mendaftarkannyaController yang langsung dibutuhkan
Get.put(X(), permanent: true)Seperti di atas, tetapi tidak pernah dihapus otomatisController global (auth, tema, keranjang)
Get.lazyPut(() => X())Mendaftarkan "resep"; objek baru dibuat saat pertama kali di-findController yang belum tentu dipakai
Get.lazyPut(..., fenix: true)Resep tetap disimpan; jika objek pernah dihapus, ia dibuat ulang saat di-find lagiHalaman yang bisa dibuka-tutup berkali-kali
Get.find<X>()Mengambil objek yang sudah terdaftarDi View atau di controller lain
Get.delete<X>()Menghapus objek dan memanggil onClose()-nyaJarang dipanggil manual; GetX biasanya mengurusnya
GetView<X>StatelessWidget yang sudah punya getter controllerView yang memakai satu controller utama

Contoh kecil: mendaftarkan dan mengambil

import 'package:flutter/material.dart';
import 'package:get/get.dart';

class CounterController extends GetxController {
  final nilai = 0.obs;
}

class ProfilController extends GetxController {}

class KeranjangController extends GetxController {}

void daftarkan() {
  // 1) Get.put: objek dibuat SEKARANG lalu didaftarkan
  Get.put(CounterController());

  // 2) permanent: true → tidak pernah dihapus otomatis oleh GetX
  Get.put(ProfilController(), permanent: true);

  // 3) Get.lazyPut: yang didaftarkan "resep"-nya; objek baru dibuat
  //    saat pertama kali di-Get.find. fenix: true → dibuat ulang jika
  //    sebelumnya sudah dihapus.
  Get.lazyPut(() => KeranjangController(), fenix: true);
}

void ambil() {
  // 4) Get.find: ambil objek yang sudah terdaftar (error jika belum)
  final c = Get.find<CounterController>();
  c.nilai.value++;
}

Future<void> hapus() async {
  // 5) Get.delete: hapus dari memori, onClose() milik controller dipanggil
  await Get.delete<CounterController>();
}

// 6) GetView<T>: StatelessWidget dengan getter `controller` = Get.find<T>()
class NilaiView extends GetView<CounterController> {
  const NilaiView({super.key});

  @override
  Widget build(BuildContext context) {
    return Obx(() => Text('Nilai: ${controller.nilai.value}'));
  }
}
  • Tipe generik di Get.find<CounterController>() wajib ditulis. Tipe itulah "kunci" pencariannya.
  • Get.find sebelum ada Get.put/Get.lazyPut akan error dengan pesan "CounterController" not found. You need to call "Get.put(CounterController())" or "Get.lazyPut(()=>CounterController())".
  • GetView hanyalah jalan pintas: di dalamnya controller sama dengan Get.find<CounterController>(). Constructor-nya tetap boleh const.

ℹ️ Kapan controller dihapus otomatis?

Secara bawaan GetX menghapus controller yang dibuat ketika sebuah halaman dibuka (misalnya Get.put di dalam View halaman itu atau lewat binding halaman) begitu halaman tersebut ditutup dengan Get.back. Controller yang didaftarkan di main() sebelum runApp, terutama dengan permanent: true, tetap hidup selama aplikasi berjalan. Detail siklus hidup ini dibahas di section 7.

Contoh lengkap: satu controller, dua halaman

Halaman Dua dibuka dengan Get.to tanpa mengirim data apa pun, tetapi bisa membaca dan mengubah nilai yang sama dengan Halaman Satu.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: flutter pub add get
import 'package:flutter/material.dart';
import 'package:get/get.dart';

class CounterController extends GetxController {
  final nilai = 0.obs;

  void tambah() => nilai.value++;

  void kurang() {
    if (nilai.value == 0) return;
    nilai.value--;
  }
}

void main() {
  // Didaftarkan SEKALI untuk seluruh aplikasi
  Get.put(CounterController(), permanent: true);
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const HalamanSatuView(),
    );
  }
}

// GetView<T> menyediakan getter `controller` (= Get.find<T>())
class HalamanSatuView extends GetView<CounterController> {
  const HalamanSatuView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Halaman Satu')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Obx(
              () => Text(
                'Nilai: ${controller.nilai.value}',
                style: Theme.of(context).textTheme.headlineMedium,
              ),
            ),
            const SizedBox(height: 16),
            FilledButton(
              onPressed: controller.tambah,
              child: const Text('Tambah'),
            ),
            const SizedBox(height: 8),
            OutlinedButton(
              // Tidak ada data yang dikirim lewat constructor!
              onPressed: () => Get.to(() => const HalamanDuaView()),
              child: const Text('Buka Halaman Dua'),
            ),
          ],
        ),
      ),
    );
  }
}

class HalamanDuaView extends GetView<CounterController> {
  const HalamanDuaView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Halaman Dua')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Obx(
              () => Text(
                'Nilai yang sama: ${controller.nilai.value}',
                style: Theme.of(context).textTheme.headlineMedium,
              ),
            ),
            const SizedBox(height: 16),
            FilledButton.tonal(
              onPressed: controller.kurang,
              child: const Text('Kurangi dari Halaman Dua'),
            ),
            const SizedBox(height: 8),
            TextButton(
              onPressed: () => Get.back(),
              child: const Text('Kembali'),
            ),
          ],
        ),
      ),
    );
  }
}
Tiga kali Tambah di Halaman Satu, lalu satu kali Kurangi di Halaman Dua

Penjelasan:

  • Get.put(CounterController(), permanent: true) di main() membuat satu objek untuk seluruh aplikasi. Kedua halaman memakai objek yang sama, sehingga nilainya selalu sinkron.
  • Kedua View extends GetView<CounterController>, jadi cukup menulis controller.nilai tanpa Get.find.
  • Get.to(() => const HalamanDuaView()) membuka halaman baru tanpa BuildContext, dan Get.back() menutupnya. Keduanya butuh GetMaterialApp.
  • Saat menekan "Kurangi" di Halaman Dua lalu kembali, Halaman Satu sudah menampilkan nilai terbaru karena Obx di sana juga mendengarkan nilai yang sama.
  • Tombol "Tambah" langsung memakai controller.tambah (tanpa Obx). Memanggil method tidak perlu berlangganan perubahan; hanya bagian yang menampilkan state yang dibungkus Obx.

Alternatif: lazyPut

Jika controller belum tentu dipakai, ganti baris pendaftaran di main() menjadi:

Get.lazyPut(() => CounterController(), fenix: true);

Objek baru dibuat ketika controller pertama kali dibaca oleh HalamanSatuView. Dengan fenix: true, jika suatu saat objek itu dihapus, GetX membuatnya lagi saat dibutuhkan (nilainya kembali ke awal).

⚠️ Kesalahan umum

  • Get.find sebelum Get.put. Muncul error "... not found. You need to call "Get.put(...)" or "Get.lazyPut(...)". Pastikan controller didaftarkan di main(), di initialBinding, atau di binding halaman sebelum View membacanya.
  • Get.put di dalam method build berkali-kali dengan maksud membuat controller "baru". Get.put untuk tipe yang sudah terdaftar mengembalikan objek lama. Daftarkan sekali di tempat yang jelas.
  • Membuat objek controller sendiri di View, misalnya final c = CounterController();. Objek itu tidak terdaftar, sehingga halaman lain yang memakai Get.find mendapat objek yang berbeda dan nilainya tidak sinkron.
  • Lupa tipe generik: Get.find() tanpa <CounterController> (dan tanpa tipe variabel) membuat GetX tidak tahu objek mana yang dicari.
