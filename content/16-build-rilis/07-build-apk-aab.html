1. Membersihkan dan memeriksa sebelum build

# Pastikan kode bersih dan semua test lulus (Modul 15)
flutter analyze
flutter test

# Opsional: hapus hasil build lama jika ada perilaku aneh
flutter clean
flutter pub get

2. Build APK per arsitektur CPU

flutter build apk --split-per-abi --dart-define-from-file=config/prod.json

Contoh output asli untuk aplikasi yang memakai Supabase dan beberapa package lain:

Running Gradle task 'assembleRelease'...                           91.4s
✓ Built build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk (13.2MB)
✓ Built build/app/outputs/flutter-apk/app-arm64-v8a-release.apk (16.1MB)
✓ Built build/app/outputs/flutter-apk/app-x86_64-release.apk (17.6MB)

Bandingkan dengan flutter build apk tanpa --split-per-abi pada proyek yang sama, yang menghasilkan satu fat APK berisi kode untuk semua CPU:

✓ Built build/app/outputs/flutter-apk/app-release.apk (47.2MB)
FileUntuk perangkat
app-arm64-v8a-release.apkHampir semua HP Android modern (pilih ini jika ragu)
app-armeabi-v7a-release.apkHP Android lama/murah dengan CPU 32-bit
app-x86_64-release.apkEmulator di laptop Intel/AMD, Chromebook
app-release.apk (fat APK)Semua perangkat, tetapi ukurannya hampir tiga kali lipat

Flutter juga otomatis menambahkan 1000 × nomor ABI ke versionCode setiap APK split, sehingga ketiga APK tidak bentrok nomor versinya.

3. Obfuscation dan split-debug-info

Kode Dart di APK bisa dibongkar untuk melihat nama class dan fungsi. --obfuscate mengacak nama-nama tersebut, dan --split-debug-info memisahkan simbol debug ke folder di laptop Anda sehingga APK lebih kecil. Keduanya selalu dipakai bersamaan.

flutter build apk --split-per-abi \
  --obfuscate --split-debug-info=build/symbols \
  --dart-define-from-file=config/prod.json

Folder build/symbols/ berisi file simbol per arsitektur:

build/symbols/
├── app.android-arm.symbols
├── app.android-arm64.symbols
└── app.android-x64.symbols

Stack trace dari aplikasi yang di-obfuscate tidak bisa dibaca langsung. Simpan folder simbol untuk setiap versi yang dirilis, lalu terjemahkan stack trace dengan:

# stack_trace.txt = isi error yang disalin dari logcat/laporan crash
flutter symbolize -i stack_trace.txt -d build/symbols/app.android-arm64.symbols

⚠️ Efek samping obfuscation

Nama class ikut diacak, sehingga kode yang bergantung pada nama tipe akan berubah perilaku, misalnya runtimeType.toString() dan toString() pada enum. Jangan menyimpan atau membandingkan data berdasarkan nilai-nilai tersebut; gunakan string tetap yang Anda tulis sendiri.

4. Build App Bundle untuk Google Play

flutter build appbundle \
  --obfuscate --split-debug-info=build/symbols \
  --dart-define-from-file=config/prod.json
Running Gradle task 'bundleRelease'...                             19.8s
✓ Built build/app/outputs/bundle/release/app-release.aab (45.1MB)

Ukuran AAB terlihat besar karena berisi semua arsitektur. Pengguna Play Store hanya mengunduh bagian yang sesuai dengan HP-nya, sehingga ukuran unduhannya mirip APK split.

5. Menguji build rilis di HP sungguhan

Build rilis wajib diuji sebelum dikumpulkan, karena beberapa bug hanya muncul di mode release (permission INTERNET, konfigurasi kosong, kode di dalam assert).

# Cara 1: jalankan langsung dalam mode release (HP tersambung USB, USB debugging aktif)
flutter run --release --dart-define-from-file=config/prod.json

# Cara 2: pasang APK yang sudah di-build ke perangkat yang tersambung
flutter install --use-application-binary=build/app/outputs/flutter-apk/app-arm64-v8a-release.apk

# Cara 3: lewat adb
adb install -r build/app/outputs/flutter-apk/app-arm64-v8a-release.apk

# Melihat log aplikasi yang sedang berjalan
flutter logs

Cara 4: kirim file APK ke HP (Google Drive, Telegram, kabel USB), buka dari aplikasi File, lalu izinkan “Instal dari sumber tidak dikenal” bila diminta.

Daftar uji minimal untuk build rilis Catatan Kuliah:

  1. Aplikasi terbuka tanpa layar abu-abu; ikon, nama, dan splash sesuai.
  2. Register, login, dan logout berhasil (membuktikan INTERNET dan konfigurasi Supabase benar).
  3. Tambah, ubah, dan hapus catatan berhasil.
  4. Matikan internet (mode pesawat): catatan dari cache Hive tetap tampil.
  5. Tutup paksa lalu buka lagi: sesi login dan data cache masih ada.
  6. Putar layar dan ubah ukuran font sistem ke terbesar: tidak ada overflow.

⚠️ Kesalahan umum

  • Mengirim app-x86_64-release.apk ke teman yang memakai HP biasa. Aplikasi tidak bisa dipasang (“App not installed”). Kirim arm64-v8a.
  • Memasang APK rilis di atas aplikasi debug yang sudah terpasang. Tanda tangannya berbeda sehingga gagal; hapus dulu aplikasi lama.
  • Mengumpulkan APK debug (build/app/outputs/flutter-apk/app-debug.apk). Ukurannya besar, lambat, dan menampilkan pita DEBUG.
  • Membuang folder build/symbols dengan flutter clean sebelum menyalinnya. Simpan di luar folder build/ (misalnya symbols/1.2.0+7/, tetapi jangan di-commit).
