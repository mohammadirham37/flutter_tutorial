Versi aplikasi: version: x.y.z+build

Nomor versi diatur di satu tempat saja, yaitu baris version di pubspec.yaml:

📄 pubspec.yaml (potongan)

name: catatan_kuliah
description: "Aplikasi catatan kuliah dengan Supabase dan cache offline."
publish_to: 'none'

# format: versionName+versionCode
version: 1.2.0+7
BagianContohDi Android menjadiDilihat olehAturan
Nama versi (sebelum +)1.2.0versionNamePengguna (di Play Store dan pengaturan HP)Bebas, biasanya mengikuti semantic versioning
Nomor build (setelah +)7versionCodeSistem Android dan Play StoreBilangan bulat, wajib naik setiap unggahan baru

Semantic versioning (MAYOR.MINOR.PATCH) memudahkan pengguna dan tim memahami besarnya perubahan:

  • PATCH (1.2.0 → 1.2.1): perbaikan bug tanpa fitur baru.
  • MINOR (1.2.1 → 1.3.0): fitur baru, misalnya fitur pencarian catatan.
  • MAYOR (1.3.0 → 2.0.0): perubahan besar, misalnya struktur database berubah total.

Nilai versionCode dan versionName otomatis dibaca oleh Gradle dari pubspec.yaml. Di android/app/build.gradle.kts hasil flutter create sudah ada baris berikut, jadi jangan mengubah angka di sana:

📄 android/app/build.gradle.kts (potongan bawaan)

defaultConfig {
    applicationId = "id.ac.unsoed.catatan_kuliah"
    minSdk = flutter.minSdkVersion
    targetSdk = flutter.targetSdkVersion
    versionCode = flutter.versionCode
    versionName = flutter.versionName
}

Versi juga bisa ditimpa sekali jalan dari terminal, misalnya oleh CI:

flutter build apk --build-name=1.2.1 --build-number=8

Menampilkan versi di dalam aplikasi

Halaman “Tentang” atau footer halaman Profil biasanya menampilkan versi aplikasi. Ini membantu saat pengguna melapor bug (“saya pakai versi berapa?”). Gunakan package package_info_plus:

flutter pub add package_info_plus

📄 lib/utils/versi.dart

// lib/utils/versi.dart
import 'package:package_info_plus/package_info_plus.dart';

/// Contoh hasil: "1.2.0 (build 7)"
Future<String> versiAplikasi() async {
  final info = await PackageInfo.fromPlatform();
  return '${info.version} (build ${info.buildNumber})';
}

Panggil versiAplikasi() di initState halaman Profil lalu tampilkan hasilnya dengan FutureBuilder atau setState, seperti pola di Modul 09.

⚠️ Kesalahan umum

  • Mengunggah build baru ke Play Console dengan nomor build yang sama. Play Console menolak: “Version code 7 has already been used”. Naikkan angka setelah +.
  • Menurunkan nomor build. Android menolak memasang APK dengan versionCode lebih kecil di atas versi yang sudah terpasang.
  • Mengubah versionCode = 7 langsung di build.gradle.kts. Hapus angka manual itu; pubspec adalah satu-satunya sumber versi.
