Setiap aplikasi Android punya dua identitas: nama tampilan yang dilihat pengguna di bawah ikon, dan application ID (package id) yang unik di seluruh Play Store. Nama tampilan boleh diganti kapan saja; application ID tidak boleh berubah setelah aplikasi dipublikasikan.

1. Nama aplikasi (label)

Secara bawaan, nama aplikasi sama dengan nama proyek (catatan_kuliah), lengkap dengan garis bawah. Ganti atribut android:label:

📄 android/app/src/main/AndroidManifest.xml (potongan)

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application
        android:label="Catatan Kuliah"
        android:name="${applicationName}"
        android:icon="@mipmap/ic_launcher">
        ...
    </application>
</manifest>

Untuk iOS, ubah nilai CFBundleDisplayName:

📄 ios/Runner/Info.plist (potongan)

<key>CFBundleDisplayName</key>
<string>Catatan Kuliah</string>

Nama yang tampil di task switcher Android saat aplikasi berjalan diambil dari properti title pada MaterialApp, jadi samakan juga: MaterialApp(title: 'Catatan Kuliah', ...).

2. Application ID

Application ID ditulis seperti nama domain terbalik. Untuk tugas kuliah, gunakan pola id.ac.unsoed.<nim_atau_kelompok>.<nama_app> agar tidak bentrok dengan teman sekelas.

  • Hanya huruf kecil, angka, dan garis bawah; dipisah titik; minimal dua segmen.
  • Setiap segmen harus diawali huruf: id.ac.unsoed.h1d022001.catatan boleh, id.ac.unsoed.2022.catatan tidak.
  • Hindari com.example: Play Console menolak application ID yang diawali com.example.

Cara paling mudah adalah menentukannya saat membuat proyek dengan opsi --org:

flutter create --org id.ac.unsoed.h1d022001 catatan_kuliah
# hasil: applicationId = "id.ac.unsoed.h1d022001.catatan_kuliah"

Untuk proyek yang sudah terlanjur dibuat, ubah applicationId di Gradle:

📄 android/app/build.gradle.kts (potongan)

android {
    // namespace = package kode Kotlin/Java (lokasi MainActivity)
    namespace = "com.example.catatan_kuliah"

    defaultConfig {
        // applicationId = identitas unik di HP dan Play Store
        applicationId = "id.ac.unsoed.h1d022001.catatan_kuliah"
        // ...
    }
}

Jika Anda juga ingin mengubah namespace, sesuaikan baris package di MainActivity.kt dan pindahkan file tersebut ke folder yang cocok:

📄 android/app/src/main/kotlin/id/ac/unsoed/h1d022001/catatan_kuliah/MainActivity.kt

package id.ac.unsoed.h1d022001.catatan_kuliah

import io.flutter.embedding.android.FlutterActivity

class MainActivity : FlutterActivity()

Setelah mengubah application ID, lakukan flutter clean lalu jalankan ulang. Untuk iOS, bundle identifier diatur dari Xcode (Runner → Signing & Capabilities).

⚠️ Kesalahan umum

  • Mengubah namespace tanpa memindahkan MainActivity.kt. Build berhasil, tetapi aplikasi langsung tertutup dengan error ClassNotFoundException: ...MainActivity.
  • Mengubah application ID setelah aplikasi diunggah ke Play Console. Play Store akan menganggapnya aplikasi baru; pengguna lama tidak mendapat update.
  • Satu kelas memakai com.example.catatan_kuliah yang sama. Saat dosen memasang beberapa APK, APK berikutnya menimpa APK sebelumnya (atau gagal dipasang karena tanda tangan berbeda).
