Aplikasi profesional tidak boleh menampilkan ikon bawaan Flutter atau layar putih kosong saat pertama dibuka. Dua package generator membuat semua ukuran ikon dan splash screen untuk Android dan iOS secara otomatis dari satu gambar.

Menyiapkan aset gambar

catatan_kuliah/
├── assets/
│   ├── icon/
│   │   ├── icon.png              # 1024x1024, latar penuh (untuk iOS dan Android lama)
│   │   └── icon_foreground.png   # 1024x1024, latar TRANSPARAN, logo di tengah
│   └── splash/
│       └── logo.png              # logo transparan untuk splash
└── pubspec.yaml
  • Gunakan PNG persegi minimal 1024×1024 piksel. Jangan memberi sudut membulat sendiri; Android dan iOS akan memotongnya sesuai bentuk masing-masing.
  • Untuk adaptive icon Android, logo pada icon_foreground.png harus berada di area tengah (sekitar 66% bagian dalam), karena pinggirannya bisa terpotong menjadi lingkaran, kotak membulat, atau bentuk lain tergantung merek HP.

Langkah 1: ikon aplikasi dengan flutter_launcher_icons

flutter pub add dev:flutter_launcher_icons

Konfigurasi bisa ditulis di pubspec.yaml atau di file terpisah. File terpisah membuat pubspec.yaml tetap rapi:

📄 flutter_launcher_icons.yaml (di root proyek)

flutter_launcher_icons:
  # Android: ganti ikon bawaan (ic_launcher) dengan ikon baru
  android: true
  ios: true
  image_path: "assets/icon/icon.png"           # 1024x1024, tanpa sudut membulat
  min_sdk_android: 21
  # Adaptive icon (Android 8+): background warna + foreground transparan
  adaptive_icon_background: "#1E3A8A"
  adaptive_icon_foreground: "assets/icon/icon_foreground.png"
  adaptive_icon_monochrome: "assets/icon/icon_foreground.png" # ikon bertema Android 13+
  # iOS menolak ikon transparan di App Store
  remove_alpha_ios: true
  background_color_ios: "#1E3A8A"
dart run flutter_launcher_icons

Output yang diharapkan:

• Creating colors.xml file and adding it to your Android project
• Overwriting the default Android launcher icon with a new icon
• Creating mipmap xml file Android
• Overwriting default iOS launcher icon with new icon

✓ Successfully generated launcher icons
OpsiFungsi
android: trueTimpa ikon bawaan ic_launcher. Isi dengan nama lain (misalnya "launcher_icon") jika ingin membuat ikon baru tanpa menghapus yang lama.
image_pathGambar sumber untuk semua platform

Langkah 2: splash screen dengan flutter_native_splash

Splash screen native tampil sebelum Flutter selesai dimuat, menggantikan layar putih kosong.

flutter pub add dev:flutter_native_splash

📄 flutter_native_splash.yaml (di root proyek)

flutter_native_splash:
  # Android 11 ke bawah dan iOS
  color: "#1E3A8A"
  image: assets/splash/logo.png
  color_dark: "#0F172A"
  image_dark: assets/splash/logo.png

  # Android 12+ punya aturan splash sendiri
  android_12:
    color: "#1E3A8A"
    image: assets/splash/logo.png
    color_dark: "#0F172A"
    image_dark: assets/splash/logo.png

  android: true
  ios: true
  web: false
dart run flutter_native_splash:create

# Mengembalikan ke splash bawaan jika ingin membatalkan
dart run flutter_native_splash:remove

Kenapa ada blok android_12 terpisah? Mulai Android 12, sistem selalu menampilkan splash berupa ikon di tengah lingkaran di atas satu warna latar. Gambar penuh layar tidak didukung. Siapkan logo yang tetap terlihat baik jika dipotong menjadi lingkaran (sekitar 1152×1152 px dengan logo di dalam lingkaran berdiameter 768 px).

Langkah 3 (opsional): menahan splash selama inisialisasi

Aplikasi Catatan Kuliah perlu menginisialisasi Supabase dan Hive sebelum halaman pertama tampil. Splash bisa ditahan sampai proses itu selesai. Untuk fitur ini, package harus dipindah ke dependencies biasa (bukan dev), karena dipakai di kode aplikasi:

flutter pub remove flutter_native_splash
flutter pub add flutter_native_splash

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter_native_splash/flutter_native_splash.dart';

Future<void> main() async {
  final binding = WidgetsFlutterBinding.ensureInitialized();
  // Tahan splash selama inisialisasi (Supabase, Hive, dll.)
  FlutterNativeSplash.preserve(widgetsBinding: binding);

  await Future.delayed(const Duration(seconds: 1)); // ganti dengan inisialisasi asli

  FlutterNativeSplash.remove(); // splash hilang, frame pertama tampil
  runApp(const MaterialApp(home: Scaffold(body: Center(child: Text('Siap!')))));
}

preserve() menahan splash native, remove() menghilangkannya. Jangan lupa memanggil remove() juga pada jalur error (misalnya di blok catch), agar aplikasi tidak “macet” di splash selamanya.

Melihat hasilnya

Ikon dan splash adalah bagian native, jadi hot reload tidak cukup. Hentikan aplikasi, hapus aplikasi lama dari emulator (beberapa launcher menyimpan cache ikon), lalu jalankan ulang flutter run.

⚠️ Kesalahan umum

  • Logo foreground mengisi seluruh gambar 1024×1024, sehingga terpotong di HP dengan ikon berbentuk lingkaran.
  • Menulis konfigurasi di dua tempat (di pubspec.yaml dan file terpisah). Pilih salah satu.
  • Lupa menjalankan ulang perintah generator setelah mengganti gambar.
  • Memakai FlutterNativeSplash.preserve sementara package masih di dev_dependencies. flutter analyze memberi peringatan depend_on_referenced_packages.
