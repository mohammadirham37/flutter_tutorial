Bagian terakhir membahas tiga alat pelengkap: golden test untuk menjaga tampilan tidak berubah tanpa sengaja, integration test untuk menguji aplikasi utuh di perangkat, dan coverage untuk mengukur seberapa banyak kode yang sudah diuji.

1. Golden test (sekilas)

Golden test merender widget menjadi gambar PNG, lalu membandingkannya dengan gambar acuan (“golden file”) yang disimpan di repo. Jika ada satu pixel yang berbeda, test gagal. Cocok untuk widget yang tampilannya penting dan jarang berubah, seperti kartu atau komponen desain.

📄 lib/widgets/kartu_nilai.dart

// lib/widgets/kartu_nilai.dart
import 'package:flutter/material.dart';

class KartuNilai extends StatelessWidget {
  const KartuNilai({super.key, required this.matkul, required this.nilai});

  final String matkul;
  final String nilai;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: ListTile(
        leading: const Icon(Icons.school),
        title: Text(matkul),
        trailing: CircleAvatar(child: Text(nilai)),
      ),
    );
  }
}

📄 test/golden/kartu_nilai_golden_test.dart

// test/golden/kartu_nilai_golden_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:catatan_kuliah/widgets/kartu_nilai.dart';

void main() {
  testWidgets('tampilan KartuNilai sesuai golden', (tester) async {
    await tester.pumpWidget(
      const MaterialApp(
        debugShowCheckedModeBanner: false,
        home: Scaffold(
          body: Center(
            child: SizedBox(
              width: 300,
              child: KartuNilai(matkul: 'Pemrograman Mobile', nilai: 'A'),
            ),
          ),
        ),
      ),
    );

    await expectLater(
      find.byType(KartuNilai),
      matchesGoldenFile('goldens/kartu_nilai.png'),
    );
  });
}
# Pertama kali: buat gambar acuan (test/golden/goldens/kartu_nilai.png)
flutter test --update-goldens test/golden

# Selanjutnya: bandingkan dengan acuan
flutter test test/golden

Jika test golden gagal, Flutter menyimpan gambar perbedaan di folder test/golden/failures/. Lihat gambarnya: jika perubahan memang disengaja (misalnya Anda mengganti warna), jalankan lagi --update-goldens dan commit gambar barunya.

ℹ️ Catatan

Di lingkungan test, semua teks dirender dengan font khusus berbentuk kotak-kotak (Ahem) agar hasilnya sama di semua komputer. Jadi jangan kaget jika gambar golden tidak menampilkan huruf yang terbaca. Golden file juga bisa sedikit berbeda antara macOS, Windows, dan Linux, sehingga tim biasanya membuat golden di satu OS yang sama (misalnya di CI).

2. Integration test (pengenalan)

Unit dan widget test berjalan di lingkungan virtual. Integration test menjalankan aplikasi asli di emulator atau HP, termasuk plugin native (kamera, Hive, Supabase). Gunanya untuk menguji alur penting dari awal sampai akhir, misalnya “register → login → tambah catatan → logout”.

Tambahkan package integration_test (bagian dari Flutter SDK) sebagai dev dependency:

flutter pub add 'dev:integration_test:{"sdk":"flutter"}'

Hasilnya di pubspec.yaml:

dev_dependencies:
  flutter_test:
    sdk: flutter
  integration_test:
    sdk: flutter

Buat folder integration_test/ di root proyek (sejajar dengan lib/ dan test/):

📄 integration_test/app_test.dart

// integration_test/app_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';
import 'package:catatan_kuliah/main.dart' as app;

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('alur lengkap: buka aplikasi dan tekan tombol', (tester) async {
    app.main(); // jalankan aplikasi ASLI
    await tester.pumpAndSettle();

    expect(find.text('Diklik 0 kali'), findsOneWidget);

    await tester.tap(find.byIcon(Icons.add));
    await tester.pumpAndSettle();

    expect(find.text('Diklik 1 kali'), findsOneWidget);
  });
}
# Pastikan emulator menyala atau HP terhubung
flutter devices

# Jalankan integration test di perangkat
flutter test integration_test/app_test.dart

# Pilih perangkat tertentu
flutter test integration_test -d emulator-5554

Perhatikan perbedaannya dengan widget test:

  • IntegrationTestWidgetsFlutterBinding.ensureInitialized() wajib dipanggil di awal.
  • app.main() menjalankan fungsi main() asli, termasuk inisialisasi Supabase dan Hive. Karena memakai backend sungguhan, gunakan akun dan project Supabase khusus pengujian.
  • Integration test jauh lebih lambat (build APK + install), jadi tulis sedikit saja untuk alur yang paling penting.

3. Coverage: seberapa banyak kode yang diuji?

Coverage menghitung persentase baris kode di lib/ yang dijalankan oleh test.

# Jalankan semua test sambil merekam coverage
flutter test --coverage

# Hasilnya: coverage/lcov.info (format teks LCOV)
head coverage/lcov.info

Isi lcov.info berupa daftar file (SF:) dan jumlah eksekusi tiap baris (DA:nomor_baris,jumlah):

SF:lib/utils/ipk.dart
DA:2,2
DA:3,6
DA:4,1
DA:6,1
...

Agar mudah dibaca, ubah menjadi laporan HTML dengan genhtml dari paket lcov:

# macOS
brew install lcov
# Ubuntu/Debian
sudo apt install lcov

genhtml coverage/lcov.info -o coverage/html
open coverage/html/index.html        # macOS
xdg-open coverage/html/index.html    # Linux

Pengguna Windows atau yang tidak ingin memasang lcov bisa memakai ekstensi VS Code Coverage Gutters: ia membaca coverage/lcov.info dan mewarnai baris di editor (hijau = teruji, merah = belum).

💡 Tips

Jangan mengejar 100%. Target realistis untuk tugas besar: logika bisnis (utils/, data/, providers/) di atas 70%, ditambah widget test untuk halaman-halaman utama. Coverage tinggi dengan test yang tidak memeriksa apa-apa (tanpa expect) tidak ada artinya.

Ringkasan perintah

PerintahFungsi
flutter analyzeCek error dan lint tanpa menjalankan aplikasi
flutter testJalankan semua unit, widget, dan golden test
flutter test --update-goldensPerbarui gambar acuan golden
flutter test integration_testJalankan integration test di perangkat
flutter test --coverageRekam coverage ke coverage/lcov.info

⚠️ Kesalahan umum

  • Menaruh file integration test di folder test/. File tersebut akan ikut dijalankan oleh flutter test biasa dan gagal karena tidak ada perangkat.
  • Lupa meng-commit folder goldens/, sehingga test golden gagal di komputer teman satu kelompok.
  • Meng-commit folder coverage/. Folder ini hasil generate dan sudah ada di .gitignore bawaan Flutter.
