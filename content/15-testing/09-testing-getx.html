Di Modul 14, logika halaman catatan dipindahkan ke NotesController. Kabar baiknya: GetxController adalah class Dart biasa yang tidak mengimpor material.dart dan tidak memegang BuildContext, sehingga bisa diuji dengan unit test tanpa widget sama sekali. Setelah itu, kita uji View yang memakai controller tersebut dengan widget test.

ℹ️ Versi ringkas

Seperti bagian sebelumnya, NotesController di sini disederhanakan agar bisa dijalankan bersama NoteRepository dan test/mock/fakes.dart dari bagian 7. Polanya sama dengan controller proyek Modul 14: state privat .obs, getter publik, data dimuat di onInit(), dan repository diterima lewat konstruktor.

Controller yang akan diuji

📄 lib/controllers/notes_controller.dart

// lib/controllers/notes_controller.dart
import 'package:get/get.dart';

import '../data/note_repository.dart';
import '../models/note.dart';

class NotesController extends GetxController {
  NotesController(this._repository);

  final NoteRepository _repository;

  // State privat reaktif
  final _notes = <Note>[].obs;
  final _isLoading = false.obs;
  final _error = RxnString();
  final _isOffline = false.obs;
  final _kataKunci = ''.obs; // diketik pengguna di kolom cari
  final _filter = ''.obs; // kata kunci yang benar-benar dipakai (setelah debounce)
  late final Worker _cariWorker;

  // Getter publik read-only
  List<Note> get notes => List.unmodifiable(_notes);
  bool get isLoading => _isLoading.value;
  String? get error => _error.value;
  bool get isOffline => _isOffline.value;

  /// Catatan yang ditampilkan: semua, atau hanya yang judulnya cocok.
  List<Note> get tampil {
    final f = _filter.value.trim().toLowerCase();
    if (f.isEmpty) return notes;
    return _notes.where((n) => n.title.toLowerCase().contains(f)).toList();
  }

  @override
  void onInit() {
    super.onInit();
    // Worker: filter baru diterapkan 300 ms setelah pengguna berhenti mengetik
    _cariWorker = debounce<String>(
      _kataKunci,
      (q) => _filter.value = q,
      time: const Duration(milliseconds: 300),
    );
    loadNotes();
  }

  void cari(String kataKunci) => _kataKunci.value = kataKunci;

  Future<void> loadNotes() async {
    _isLoading.value = true;
    _error.value = null;
    try {
      _notes.assignAll(await _repository.getNotes());
      _isOffline.value = _repository.lastFromCache;
    } catch (e) {
      _error.value = 'Gagal memuat catatan';
    } finally {
      _isLoading.value = false;
    }
  }

  Future<bool> addNote(String title, String content) async {
    _error.value = null;
    try {
      final note = await _repository.addNote(title, content);
      _notes.insert(0, note);
      return true;
    } catch (e) {
      _error.value = 'Gagal menyimpan catatan';
      return false;
    }
  }

  @override
  void onClose() {
    _cariWorker.dispose();
    super.onClose();
  }
}

Yang membuat controller ini mudah diuji:

  • Repository masuk lewat konstruktor. Di test, kita isi dengan repository yang memakai data source palsu.
  • Hasil dikembalikan, bukan ditampilkan. addNote mengembalikan bool dan mengisi error; View yang memutuskan menampilkan SnackBar. Controller tidak pernah memanggil Get.snackbar atau Get.back, sehingga test tidak butuh layar.
  • Worker debounce menunda penerapan kata kunci pencarian sampai pengguna berhenti mengetik selama 300 ms, lalu dibatalkan di onClose().

Langkah 1: unit test untuk GetxController

Tiga hal wajib saat menguji controller GetX:

BarisFungsi
Get.testMode = trueMemberi tahu GetX bahwa kode berjalan di dalam test. Tanpa ini, pemanggilan navigasi GetX (Get.to, Get.back) di luar GetMaterialApp melempar error You are trying to use contextless navigation without a GetMaterialApp

📄 test/unit/notes_controller_test.dart

// test/unit/notes_controller_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';
import 'package:catatan_kuliah/controllers/notes_controller.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';

import '../mock/fakes.dart';

void main() {
  late FakeRemoteDataSource remote;
  late FakeLocalCache cache;

  setUp(() {
    Get.testMode = true;
    remote = FakeRemoteDataSource(
      awal: [
        const Note(id: 'n1', title: 'Pertemuan 1', content: 'Dart'),
        const Note(id: 'n2', title: 'Kuis 1', content: 'Bab 1-3'),
      ],
    );
    cache = FakeLocalCache();
  });

  // Hapus semua controller yang didaftarkan Get.put agar test terisolasi
  tearDown(Get.reset);

  /// Daftarkan controller SETELAH test mengatur remote/cache.
  /// Get.put langsung menjalankan onInit(), jadi loadNotes() ikut berjalan.
  NotesController buatController() {
    final repository = NoteRepository(remote: remote, cache: cache);
    return Get.put(NotesController(repository));
  }

  test('onInit memuat data: isLoading true lalu false', () async {
    final c = buatController();

    // onInit sudah memanggil loadNotes(), tetapi Future-nya belum selesai
    expect(c.isLoading, isTrue);

    await pumpEventQueue(); // tunggu semua Future fake selesai

    expect(c.isLoading, isFalse);
    expect(c.notes, hasLength(2));
    expect(c.error, isNull);
    expect(c.isOffline, isFalse);
  });

  test('offline dengan cache: data dari cache, isOffline true', () async {
    remote.shouldFail = true;
    cache.saved = [const Note(id: 'c1', title: 'Dari cache', content: '-')];

    final c = buatController();
    await pumpEventQueue();

    expect(c.notes.single.title, 'Dari cache');
    expect(c.isOffline, isTrue);
  });

  test('addNote menaruh catatan baru di urutan teratas', () async {
    final c = buatController();
    await pumpEventQueue();

    final berhasil = await c.addNote('Tugas Besar', 'Deadline minggu 16');

    expect(berhasil, isTrue);
    expect(c.notes.first.title, 'Tugas Besar');
    expect(c.notes, hasLength(3));
  });

  test('addNote gagal saat offline: false dan error terisi', () async {
    final c = buatController();
    await pumpEventQueue();
    remote.shouldFail = true;

    final berhasil = await c.addNote('Tugas Besar', 'Deadline minggu 16');

    expect(berhasil, isFalse);
    expect(c.error, 'Gagal menyimpan catatan');
    expect(c.notes, hasLength(2)); // daftar lama tidak berubah
  });

  test('worker debounce: filter baru berlaku setelah 300 ms', () async {
    final c = buatController();
    await pumpEventQueue();

    c.cari('kuis');
    expect(c.tampil, hasLength(2)); // belum 300 ms, filter belum diterapkan

    await Future<void>.delayed(const Duration(milliseconds: 350));
    expect(c.tampil.single.title, 'Kuis 1');
  });

  test('Get.find mengembalikan instance yang sama dengan Get.put', () {
    final c = buatController();

    expect(Get.find<NotesController>(), same(c));
  });
}
$ flutter test test/unit/notes_controller_test.dart
00:00 +6: All tests passed!

Teknik yang perlu diperhatikan:

  • buatController() dipanggil setelah skenario disiapkan. Karena onInit() langsung memanggil loadNotes(), nilai remote.shouldFail dan cache.saved harus diatur sebelum Get.put.
  • Menguji isLoading. Tepat setelah Get.put, Future belum selesai sehingga isLoading masih true. pumpEventQueue() (dari flutter_test) menunggu semua Future yang sudah siap, lalu kita periksa isLoading, notes, dan error.
  • Menguji worker. Tepat setelah cari('kuis'), daftar masih lengkap karena debounce belum lewat 300 ms. Setelah menunggu 350 ms, filter diterapkan. Dalam unit test biasa, waktu berjalan sungguhan, jadi test ini memang menunggu sekitar 0,35 detik.
  • Tidak perlu addListener. Getter seperti c.isLoading cukup dibaca langsung; .obs otomatis memberi tahu Obx di View, dan perilaku itu diuji terpisah dengan widget test.

Langkah 2: View yang memakai controller

📄 lib/views/notes_view.dart

// lib/views/notes_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/notes_controller.dart';

class NotesView extends GetView<NotesController> {
  const NotesView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Catatan Kuliah')),
      body: Obx(() {
        if (controller.isLoading) {
          return const Center(child: CircularProgressIndicator());
        }
        final error = controller.error;
        if (error != null && controller.notes.isEmpty) {
          return Center(child: Text(error));
        }
        final tampil = controller.tampil;
        return Column(
          children: [
            if (controller.isOffline)
              const MaterialBanner(
                content: Text('Mode offline: menampilkan data cache'),
                actions: [SizedBox.shrink()],
              ),
            Padding(
              padding: const EdgeInsets.all(12),
              child: TextField(
                onChanged: controller.cari,
                decoration: const InputDecoration(
                  prefixIcon: Icon(Icons.search),
                  hintText: 'Cari judul catatan',
                  border: OutlineInputBorder(),
                ),
              ),
            ),
            Expanded(
              child: tampil.isEmpty
                  ? Center(
                      child: Text(controller.notes.isEmpty
                          ? 'Belum ada catatan'
                          : 'Tidak ada catatan yang cocok'),
                    )
                  : ListView.builder(
                      itemCount: tampil.length,
                      itemBuilder: (context, index) {
                        final note = tampil[index];
                        return ListTile(
                          title: Text(note.title),
                          subtitle: Text(note.content),
                        );
                      },
                    ),
            ),
          ],
        );
      }),
    );
  }
}

NotesView meng-extend GetView<NotesController>, sehingga properti controller sama dengan Get.find<NotesController>(). Seluruh body dibungkus satu Obx yang membaca isLoading, error, notes, isOffline, dan tampil.

Mengetik “kuis”: setelah 300 ms hanya catatan kuis yang tampil
shouldFail = true: data cache dan banner mode offline

Screenshot di atas diambil dengan memanggil Get.put(NotesController(...)) berisi FakeRemoteDataSource dan FakeLocalCache di main(). Ini trik yang berguna untuk mendesain tampilan offline tanpa harus mematikan internet.

Langkah 3: widget test dengan GetMaterialApp

Pola kuncinya sama dengan main.dart: daftarkan controller (berisi dependensi palsu) dengan Get.put, lalu render View di dalam GetMaterialApp.

📄 test/widget/notes_view_test.dart

// test/widget/notes_view_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';
import 'package:catatan_kuliah/controllers/notes_controller.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';
import 'package:catatan_kuliah/views/notes_view.dart';

import '../mock/fakes.dart';

/// Remote yang sengaja lambat agar status loading sempat terlihat.
class RemoteLambat extends FakeRemoteDataSource {
  RemoteLambat({super.awal});

  @override
  Future<List<Note>> fetchNotes() async {
    await Future<void>.delayed(const Duration(milliseconds: 500));
    return super.fetchNotes();
  }
}

void main() {
  late FakeRemoteDataSource remote;
  late FakeLocalCache cache;

  setUp(() {
    Get.testMode = true;
    remote = FakeRemoteDataSource(
      awal: [
        const Note(id: 'n1', title: 'Pertemuan 1', content: 'Dart'),
        const Note(id: 'n2', title: 'Kuis 1', content: 'Bab 1-3'),
      ],
    );
    cache = FakeLocalCache();
  });

  tearDown(Get.reset);

  /// Daftarkan controller dengan fake, lalu render View di GetMaterialApp.
  Future<void> pasangApp(WidgetTester tester) async {
    Get.put(NotesController(NoteRepository(remote: remote, cache: cache)));
    await tester.pumpWidget(const GetMaterialApp(home: NotesView()));
  }

  testWidgets('menampilkan loading lalu daftar catatan', (tester) async {
    remote = RemoteLambat(awal: remote.notes);
    await pasangApp(tester);

    // Frame pertama: data belum datang (remote butuh 500 ms)
    expect(find.byType(CircularProgressIndicator), findsOneWidget);

    await tester.pumpAndSettle(); // majukan waktu sampai Future selesai

    expect(find.text('Pertemuan 1'), findsOneWidget);
    expect(find.byType(CircularProgressIndicator), findsNothing);
  });

  testWidgets('offline dengan cache: tampil banner mode offline',
      (tester) async {
    remote.shouldFail = true;
    cache.saved = [const Note(id: 'c1', title: 'Dari cache', content: '-')];

    await pasangApp(tester);
    await tester.pumpAndSettle();

    expect(find.text('Dari cache'), findsOneWidget);
    expect(find.textContaining('Mode offline'), findsOneWidget);
  });

  testWidgets('tanpa data sama sekali: tampil pesan kosong', (tester) async {
    remote.notes.clear();

    await pasangApp(tester);
    await tester.pumpAndSettle();

    expect(find.text('Belum ada catatan'), findsOneWidget);
  });

  testWidgets('catatan baru dari controller langsung tampil', (tester) async {
    await pasangApp(tester);
    await tester.pumpAndSettle();

    // Ambil controller yang sama dengan yang dipakai View
    final c = Get.find<NotesController>();
    await c.addNote('Tugas Besar', 'Deadline minggu 16');
    await tester.pump(); // Obx menggambar ulang

    expect(find.text('Tugas Besar'), findsOneWidget);
  });

  testWidgets('kolom cari menyaring daftar setelah debounce',
      (tester) async {
    await pasangApp(tester);
    await tester.pumpAndSettle();

    await tester.enterText(find.byType(TextField), 'kuis');
    await tester.pump(); // belum 300 ms: daftar masih lengkap
    expect(find.text('Pertemuan 1'), findsOneWidget);

    await tester.pump(const Duration(milliseconds: 300)); // majukan waktu
    expect(find.text('Pertemuan 1'), findsNothing);
    expect(find.text('Kuis 1'), findsOneWidget);
  });
}

  • RemoteLambat: fake remote biasa selesai hampir seketika, bahkan sebelum frame pertama selesai digambar, sehingga loading tidak pernah terlihat. Subclass kecil yang menunggu 500 ms membuat status loading bisa diperiksa. Di dalam testWidgets, waktu ini palsu: pumpAndSettle() memajukannya tanpa benar-benar menunggu.
  • pasangApp() dipanggil setelah test mengubah remote/cache, sehingga setiap test bisa menyiapkan skenario berbeda.
  • Memegang controller dari test: Get.find<NotesController>() mengembalikan instance yang sama dengan yang dipakai View. Setelah addNote, cukup pump() agar Obx menggambar ulang.
  • Menguji debounce di widget test: tester.pump(const Duration(milliseconds: 300)) memajukan jam palsu 300 ms sehingga timer debounce berjalan, tanpa membuat test lambat.

⚠️ Kesalahan umum

  • Lupa tearDown(Get.reset). Instance dari test sebelumnya masih terdaftar, dan Get.put untuk tipe yang sudah ada tidak menggantinya. Akibatnya test memakai controller lama: pada percobaan kami, test offline gagal dengan Found 0 widgets with text "Dari cache" karena controller yang dipakai masih berisi data online dari test pertama. Test lulus jika dijalankan sendiri, tetapi gagal jika dijalankan bersama.
  • Memanggil pumpWidget sebelum Get.put. View langsung memanggil Get.find dan gagal dengan pesan "NotesController" not found (lihat bagian 1).
  • Membuat controller yang di dalamnya langsung memanggil Supabase.instance.client atau Hive.box(). Controller seperti itu tidak bisa diuji; terima repository lewat konstruktor.
  • Menampilkan SnackBar atau bernavigasi dari controller. Unit test controller jadi butuh widget tree; kembalikan hasilnya dan biarkan View yang bereaksi.
  • Hanya menguji controller lewat UI. Unit test controller jauh lebih cepat dan pesan gagalnya lebih jelas; gunakan widget test untuk memastikan Obx bereaksi terhadap state.
