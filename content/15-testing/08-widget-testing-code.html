Widget test menjalankan widget di lingkungan virtual (tanpa emulator), lalu mensimulasikan interaksi pengguna: mengetik, menekan tombol, menggulir. Hasilnya diperiksa dengan cara yang sama seperti unit test, yaitu expect.

Kosakata dasar WidgetTester

PerintahFungsi
testWidgets('...', (tester) async { })Mendefinisikan widget test; tester adalah “robot” yang mengendalikan UI
await tester.pumpWidget(widget)Merender widget untuk pertama kali
find.text('...'), find.byKey(...), find.byType(...), find.byIcon(...)Mencari widget di layar (finder)
await tester.tap(finder)Menekan widget
await tester.enterText(finder, 'teks')Mengetik ke TextField/TextFormField
await tester.pump()Menggambar satu frame berikutnya (setelah setState)
await tester.pump(Duration)Memajukan waktu virtual lalu menggambar frame
await tester.pumpAndSettle()Terus menggambar frame sampai tidak ada animasi/timer yang tersisa
findsOneWidget, findsNothing, findsNWidgets(n), findsWidgetsMatcher jumlah widget yang ditemukan

Contoh 1: aplikasi penghitung klik

Kita mulai dari aplikasi paling sederhana. Simpan sebagai lib/main.dart:

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const KlikApp());
}

class KlikApp extends StatelessWidget {
  const KlikApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Klik App',
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const KlikPage(),
    );
  }
}

class KlikPage extends StatefulWidget {
  const KlikPage({super.key});

  @override
  State<KlikPage> createState() => _KlikPageState();
}

class _KlikPageState extends State<KlikPage> {
  int _jumlah = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Klik App')),
      body: Center(
        child: Text(
          'Diklik $_jumlah kali',
          style: Theme.of(context).textTheme.headlineSmall,
        ),
      ),
      floatingActionButton: FloatingActionButton(
        tooltip: 'Tambah',
        onPressed: () => setState(() => _jumlah++),
        child: const Icon(Icons.add),
      ),
    );
  }
}
Kondisi awal: “Diklik 0 kali”
Setelah tombol + ditekan tiga kali

Test berikut melakukan hal yang sama dengan yang Anda lakukan secara manual di emulator, tetapi otomatis:

📄 test/widget/klik_app_test.dart

// test/widget/klik_app_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:catatan_kuliah/main.dart';

void main() {
  testWidgets('angka bertambah saat tombol + ditekan', (tester) async {
    // 1. Render widget
    await tester.pumpWidget(const KlikApp());

    // 2. Periksa kondisi awal
    expect(find.text('Diklik 0 kali'), findsOneWidget);
    expect(find.text('Diklik 1 kali'), findsNothing);

    // 3. Tekan tombol, lalu minta Flutter menggambar frame baru
    await tester.tap(find.byIcon(Icons.add));
    await tester.pump();

    // 4. Periksa hasilnya
    expect(find.text('Diklik 1 kali'), findsOneWidget);
  });

  testWidgets('menekan tombol tiga kali', (tester) async {
    await tester.pumpWidget(const KlikApp());

    for (var i = 0; i < 3; i++) {
      await tester.tap(find.byTooltip('Tambah'));
    }
    await tester.pump();

    expect(find.text('Diklik 3 kali'), findsOneWidget);
  });
}

Poin penting:

  • tester.tap() hanya mengirim sentuhan. Layar belum berubah sampai Anda memanggil pump(). Ini kesalahan nomor satu pemula.
  • find.byTooltip('Tambah') mencari tombol lewat tooltip-nya. Ini sekaligus memastikan tombol punya label aksesibilitas.
  • Test dimulai dengan memeriksa kondisi awal. Tanpa itu, test bisa lulus walaupun teks awal sudah salah.

Contoh 2: berbagai cara mencari widget (finder)

📄 test/widget/finder_test.dart

// test/widget/finder_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  testWidgets('berbagai cara mencari widget', (tester) async {
    await tester.pumpWidget(
      MaterialApp(
        home: Scaffold(
          appBar: AppBar(title: const Text('Profil')),
          body: Column(
            children: [
              const Text('Budi Santoso', key: Key('nama')),
              const Icon(Icons.verified),
              ElevatedButton(onPressed: () {}, child: const Text('Edit')),
              const Text('Edit'),
            ],
          ),
        ),
      ),
    );

    expect(find.text('Profil'), findsOneWidget); // berdasarkan teks
    expect(find.byKey(const Key('nama')), findsOneWidget); // berdasarkan Key
    expect(find.byIcon(Icons.verified), findsOneWidget); // berdasarkan ikon
    expect(find.byType(ElevatedButton), findsOneWidget); // berdasarkan tipe
    expect(find.text('Edit'), findsNWidgets(2)); // ada 2 teks "Edit"
    // Teks "Edit" yang berada DI DALAM ElevatedButton saja
    expect(find.widgetWithText(ElevatedButton, 'Edit'), findsOneWidget);
    expect(find.text('Hapus'), findsNothing);

    // Membaca properti widget yang ditemukan
    final teksNama = tester.widget<Text>(find.byKey(const Key('nama')));
    expect(teksNama.data, 'Budi Santoso');
  });
}

Urutan prioritas memilih finder: find.byKey paling stabil (tidak terpengaruh perubahan teks), find.text paling mudah dibaca, find.byType jika hanya ada satu widget sejenis. tester.widget<T>(finder) mengambil objek widget-nya untuk memeriksa properti.

pump() vs pumpAndSettle()

pump()pumpAndSettle()
Jumlah frameTepat satuSebanyak yang dibutuhkan sampai tenang
Cocok untuksetState sederhana, memeriksa kondisi “di tengah” (loading)Navigasi, dialog, SnackBar, Future yang sudah selesai
BahayaAnimasi belum selesai saat diperiksaTimeout jika ada animasi tanpa akhir (misalnya CircularProgressIndicator yang terus berputar)

Contoh 3: menguji validasi form login (Modul 13)

Form login Catatan Kuliah adalah kandidat ideal untuk widget test: banyak aturan validasi, dan bug di sini membuat pengguna tidak bisa masuk sama sekali. Agar mudah diuji, proses login tidak dipanggil langsung di dalam halaman, melainkan diterima lewat parameter onLogin. Di aplikasi asli isinya context.read<AuthProvider>().signIn; di test isinya fungsi palsu.

📄 lib/pages/login_page.dart

// lib/pages/login_page.dart
import 'package:flutter/material.dart';

import '../utils/validators.dart';

class LoginPage extends StatefulWidget {
  const LoginPage({super.key, required this.onLogin});

  /// Dipanggil saat form valid. Di Modul 13 isinya AuthProvider.signIn.
  final Future<void> Function(String email, String password) onLogin;

  @override
  State<LoginPage> createState() => _LoginPageState();
}

class _LoginPageState extends State<LoginPage> {
  final _formKey = GlobalKey<FormState>();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  bool _loading = false;

  @override
  void dispose() {
    _emailController.dispose();
    _passwordController.dispose();
    super.dispose();
  }

  Future<void> _submit() async {
    if (!_formKey.currentState!.validate()) return;

    setState(() => _loading = true);
    try {
      await widget.onLogin(
        _emailController.text.trim(),
        _passwordController.text,
      );
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Login gagal, periksa email/password')),
      );
    } finally {
      if (mounted) setState(() => _loading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Masuk')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                key: const Key('field-email'),
                controller: _emailController,
                decoration: const InputDecoration(labelText: 'Email'),
                keyboardType: TextInputType.emailAddress,
                validator: validasiEmail,
              ),
              const SizedBox(height: 12),
              TextFormField(
                key: const Key('field-password'),
                controller: _passwordController,
                decoration: const InputDecoration(labelText: 'Password'),
                obscureText: true,
                validator: validasiPassword,
              ),
              const SizedBox(height: 24),
              SizedBox(
                width: double.infinity,
                child: FilledButton(
                  onPressed: _loading ? null : _submit,
                  child: _loading
                      ? const SizedBox(
                          width: 20,
                          height: 20,
                          child: CircularProgressIndicator(strokeWidth: 2),
                        )
                      : const Text('Masuk'),
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
Tombol Masuk ditekan saat form kosong
Email “budi” dan password “123”
Form valid tetapi onLogin melempar error: SnackBar muncul

Ketiga kondisi pada screenshot di atas kini kita uji secara otomatis, ditambah dua skenario lain:

📄 test/widget/login_page_test.dart

// test/widget/login_page_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:catatan_kuliah/pages/login_page.dart';

void main() {
  // Helper agar setiap test tidak menulis MaterialApp berulang kali
  Future<void> pumpLogin(
    WidgetTester tester, {
    Future<void> Function(String, String)? onLogin,
  }) async {
    await tester.pumpWidget(
      MaterialApp(
        home: LoginPage(onLogin: onLogin ?? (email, password) async {}),
      ),
    );
  }

  final fieldEmail = find.byKey(const Key('field-email'));
  final fieldPassword = find.byKey(const Key('field-password'));
  final tombolMasuk = find.widgetWithText(FilledButton, 'Masuk');

  testWidgets('form kosong menampilkan dua pesan error', (tester) async {
    await pumpLogin(tester);

    await tester.tap(tombolMasuk);
    await tester.pump();

    expect(find.text('Email wajib diisi'), findsOneWidget);
    expect(find.text('Password wajib diisi'), findsOneWidget);
  });

  testWidgets('email salah format dan password pendek', (tester) async {
    await pumpLogin(tester);

    await tester.enterText(fieldEmail, 'budi');
    await tester.enterText(fieldPassword, '123');
    await tester.tap(tombolMasuk);
    await tester.pump();

    expect(find.text('Format email tidak valid'), findsOneWidget);
    expect(find.text('Password minimal 8 karakter'), findsOneWidget);
  });

  testWidgets('form valid memanggil onLogin dengan data yang diketik',
      (tester) async {
    String? emailDikirim;
    String? passwordDikirim;

    await pumpLogin(
      tester,
      onLogin: (email, password) async {
        emailDikirim = email;
        passwordDikirim = password;
      },
    );

    await tester.enterText(fieldEmail, '  budi@mhs.unsoed.ac.id ');
    await tester.enterText(fieldPassword, 'rahasia123');
    await tester.tap(tombolMasuk);
    await tester.pumpAndSettle();

    expect(emailDikirim, 'budi@mhs.unsoed.ac.id'); // sudah di-trim
    expect(passwordDikirim, 'rahasia123');
    expect(find.text('Email wajib diisi'), findsNothing);
  });

  testWidgets('login gagal menampilkan SnackBar', (tester) async {
    await pumpLogin(
      tester,
      onLogin: (email, password) async => throw Exception('401'),
    );

    await tester.enterText(fieldEmail, 'budi@mhs.unsoed.ac.id');
    await tester.enterText(fieldPassword, 'salahsalah');
    await tester.tap(tombolMasuk);
    await tester.pumpAndSettle();

    expect(find.text('Login gagal, periksa email/password'), findsOneWidget);
  });

  testWidgets('tombol menampilkan loading selama proses login',
      (tester) async {
    await pumpLogin(
      tester,
      onLogin: (email, password) =>
          Future.delayed(const Duration(seconds: 2)),
    );

    await tester.enterText(fieldEmail, 'budi@mhs.unsoed.ac.id');
    await tester.enterText(fieldPassword, 'rahasia123');
    await tester.tap(tombolMasuk);
    await tester.pump(); // satu frame: setState(_loading = true) terlihat

    expect(find.byType(CircularProgressIndicator), findsOneWidget);

    await tester.pump(const Duration(seconds: 2)); // majukan waktu 2 detik
    await tester.pump(); // frame setelah loading selesai

    expect(find.byType(CircularProgressIndicator), findsNothing);
  });
}

Penjelasan bagian penting:

  • Helper pumpLogin: membungkus LoginPage dengan MaterialApp (wajib, karena Scaffold, TextFormField, dan SnackBar butuh tema dan ScaffoldMessenger).
  • Key('field-email'): diberikan di LoginPage agar test bisa menemukan field dengan pasti. Mencari lewat find.text('Email') rawan karena label bisa berubah.
  • find.widgetWithText(FilledButton, 'Masuk'): teks “Masuk” juga ada di judul AppBar, jadi kita batasi pencarian ke tombol saja.
  • Menangkap argumen: variabel emailDikirim diisi oleh fungsi palsu, lalu diperiksa. Ini cara sederhana memastikan form mengirim data yang benar (termasuk trim()).
  • Test loading: pump() sekali untuk melihat kondisi tengah (indikator loading tampil), lalu pump(Duration(seconds: 2)) memajukan waktu virtual. Test tetap selesai dalam milidetik walaupun “menunggu” 2 detik. Di sini pumpAndSettle() tidak bisa dipakai di tengah, karena indikator loading berputar terus.

Menggulir sampai widget terlihat

Jika widget berada di bawah layar dalam ListView, ia mungkin belum dibangun sehingga find tidak menemukannya. Gulir dulu:

// di dalam testWidgets, setelah pumpWidget sebuah ListView berisi 100 item
await tester.scrollUntilVisible(
  find.text('Catatan 80'),
  300, // jarak gulir per langkah (pixel)
  scrollable: find.byType(Scrollable).first,
);
expect(find.text('Catatan 80'), findsOneWidget);

⚠️ Kesalahan umum

  • Lupa await di depan tester.tap, tester.pump, atau tester.enterText.
  • Lupa memanggil pump() setelah tap(), lalu bingung kenapa teks belum berubah.
  • Memanggil pumpAndSettle() saat ada animasi tak berujung, sehingga test gagal dengan pesan pumpAndSettle timed out.
  • Me-render halaman tanpa MaterialApp, menghasilkan error No MediaQuery widget ancestor found atau No Material widget found.
  • Halaman langsung memanggil Supabase.instance.client. Di test, Supabase belum diinisialisasi sehingga test crash. Pisahkan aksi lewat parameter atau provider (bagian berikutnya).
