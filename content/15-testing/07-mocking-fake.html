Di Modul 14, NoteRepository mengambil catatan dari Supabase dan menyimpannya ke cache Hive. Bagaimana mengujinya tanpa internet, tanpa akun Supabase, dan tanpa mengotori database? Jawabannya: ganti sumber data asli dengan pengganti palsu yang kita kendalikan penuh.

ℹ️ Versi ringkas, bukan salinan kode proyek

Agar setiap contoh di modul ini bisa dijalankan sendiri, class Note, NoteRepository, dan data source di bawah sengaja dibuat lebih sederhana daripada kode proyek Modul 14 (nama method dan field bisa berbeda). Konsepnya sama persis. Test untuk kode proyek yang sesungguhnya ada di Modul 14 section Unit Test (test/note_repository_test.dart dan test/note_local_data_source_test.dart).

Kenapa butuh pengganti?

  • Cepat: tidak ada request jaringan, ratusan test selesai dalam hitungan detik.
  • Stabil: hasil test tidak bergantung pada koneksi atau isi database hari ini.
  • Bisa mensimulasikan kegagalan: kondisi “offline” sulit dibuat dengan server sungguhan, tetapi mudah dengan pengganti palsu.

Langkah 1: kode harus bergantung pada abstraksi

Pengganti hanya bisa dipasang jika repository tidak membuat koneksi Supabase/Hive sendiri, melainkan menerimanya dari luar lewat konstruktor (dependency injection). Berikut versi sederhana arsitektur Modul 14:

📄 lib/models/note.dart

// lib/models/note.dart
class Note {
  final String id;
  final String title;
  final String content;

  const Note({required this.id, required this.title, required this.content});
}

📄 lib/data/note_data_source.dart

// lib/data/note_data_source.dart
import '../models/note.dart';

/// Sumber data online (di Modul 14: tabel notes di Supabase).
abstract class NoteRemoteDataSource {
  Future<List<Note>> fetchNotes();
  Future<Note> createNote(String title, String content);
}

/// Cache offline (di Modul 14: box Hive).
abstract class NoteLocalCache {
  Future<void> saveNotes(List<Note> notes);
  Future<List<Note>> readNotes();
}

📄 lib/data/note_repository.dart

// lib/data/note_repository.dart
import '../models/note.dart';
import 'note_data_source.dart';

class NoteRepository {
  NoteRepository({required this.remote, required this.cache});

  final NoteRemoteDataSource remote;
  final NoteLocalCache cache;

  /// true jika data terakhir diambil dari cache (sedang offline).
  bool lastFromCache = false;

  Future<List<Note>> getNotes() async {
    try {
      final notes = await remote.fetchNotes();
      await cache.saveNotes(notes);
      lastFromCache = false;
      return notes;
    } catch (_) {
      lastFromCache = true;
      return cache.readNotes();
    }
  }

  Future<Note> addNote(String title, String content) async {
    if (title.trim().isEmpty) {
      throw ArgumentError('Judul tidak boleh kosong');
    }
    return remote.createNote(title.trim(), content);
  }
}

NoteRepository hanya mengenal NoteRemoteDataSource dan NoteLocalCache (abstract class). Di aplikasi asli, kita memasang implementasi Supabase dan Hive. Di test, kita memasang versi palsu.

Langkah 2: menulis fake class

Fake ditulis dengan implements, sehingga compiler memaksa kita mengisi semua method. Tambahkan “tombol” untuk mengatur perilaku (shouldFail) dan “penghitung” untuk diperiksa (fetchCount).

📄 test/mock/fakes.dart

// test/mock/fakes.dart
import 'package:catatan_kuliah/data/note_data_source.dart';
import 'package:catatan_kuliah/models/note.dart';

/// Pengganti Supabase: datanya disimpan di list biasa.
class FakeRemoteDataSource implements NoteRemoteDataSource {
  FakeRemoteDataSource({List<Note>? awal}) : notes = [...?awal];

  final List<Note> notes;
  bool shouldFail = false; // ubah ke true untuk mensimulasikan offline
  int fetchCount = 0; // berapa kali fetchNotes dipanggil

  @override
  Future<List<Note>> fetchNotes() async {
    fetchCount++;
    if (shouldFail) throw Exception('Tidak ada koneksi internet');
    return List.of(notes);
  }

  @override
  Future<Note> createNote(String title, String content) async {
    if (shouldFail) throw Exception('Tidak ada koneksi internet');
    final note = Note(id: 'n${notes.length + 1}', title: title, content: content);
    notes.add(note);
    return note;
  }
}

/// Pengganti Hive: cache disimpan di memori.
class FakeLocalCache implements NoteLocalCache {
  List<Note> saved = [];

  @override
  Future<void> saveNotes(List<Note> notes) async => saved = List.of(notes);

  @override
  Future<List<Note>> readNotes() async => List.of(saved);
}

File ini diletakkan di folder test/ karena hanya dipakai untuk pengujian. Namanya tidak diakhiri _test.dart, jadi tidak dijalankan sebagai test.

Langkah 3: menguji repository dengan fake

📄 test/mock/note_repository_test.dart

// test/mock/note_repository_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';

import 'fakes.dart';

void main() {
  late FakeRemoteDataSource remote;
  late FakeLocalCache cache;
  late NoteRepository repository;

  const catatan1 = Note(id: 'n1', title: 'Pertemuan 1', content: 'Pengenalan Dart');

  setUp(() {
    remote = FakeRemoteDataSource(awal: [catatan1]);
    cache = FakeLocalCache();
    repository = NoteRepository(remote: remote, cache: cache);
  });

  test('online: data diambil dari remote lalu disimpan ke cache', () async {
    final notes = await repository.getNotes();

    expect(notes, hasLength(1));
    expect(notes.first.title, 'Pertemuan 1');
    expect(cache.saved, hasLength(1)); // cache ikut terisi
    expect(repository.lastFromCache, isFalse);
  });

  test('offline: data diambil dari cache', () async {
    cache.saved = [catatan1];
    remote.shouldFail = true;

    final notes = await repository.getNotes();

    expect(notes.single.id, 'n1');
    expect(repository.lastFromCache, isTrue);
  });

  test('offline dan cache kosong: hasilnya list kosong, bukan crash', () async {
    remote.shouldFail = true;

    expect(await repository.getNotes(), isEmpty);
  });

  test('addNote menolak judul kosong tanpa memanggil remote', () async {
    await expectLater(repository.addNote('   ', 'isi'), throwsArgumentError);
    expect(remote.notes, hasLength(1)); // tidak bertambah
  });

  test('addNote merapikan spasi judul', () async {
    final note = await repository.addNote('  Kuis 1  ', 'Bab 1-3');

    expect(note.title, 'Kuis 1');
    expect(remote.notes, hasLength(2));
  });
}

Lima test ini mendokumentasikan perilaku penting repository: online menyimpan cache, offline membaca cache, offline tanpa cache tidak crash, dan validasi judul. Jika suatu hari ada yang mengubah getNotes() dan lupa menyimpan cache, test pertama langsung gagal.

Alternatif: mocktail

Menulis fake butuh waktu jika interface-nya besar. Package mocktail membuat mock tanpa menulis method satu per satu. Pasang sebagai dev dependency:

flutter pub add dev:mocktail

📄 test/mock/note_repository_mocktail_test.dart

// test/mock/note_repository_mocktail_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:mocktail/mocktail.dart';
import 'package:catatan_kuliah/data/note_data_source.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';

// Cukup satu baris per class, tanpa menulis method apa pun
class MockRemote extends Mock implements NoteRemoteDataSource {}

class MockCache extends Mock implements NoteLocalCache {}

void main() {
  late MockRemote remote;
  late MockCache cache;
  late NoteRepository repository;

  const catatan = Note(id: 'n1', title: 'UTS', content: 'Bab 1-6');

  setUp(() {
    remote = MockRemote();
    cache = MockCache();
    repository = NoteRepository(remote: remote, cache: cache);
  });

  test('online: hasil remote disimpan ke cache', () async {
    // Atur perilaku mock (stub)
    when(() => remote.fetchNotes()).thenAnswer((_) async => [catatan]);
    when(() => cache.saveNotes(any())).thenAnswer((_) async {});

    final notes = await repository.getNotes();

    expect(notes, [catatan]);
    // Pastikan saveNotes dipanggil tepat satu kali dengan data yang benar
    verify(() => cache.saveNotes([catatan])).called(1);
    verifyNever(() => cache.readNotes());
  });

  test('offline: remote melempar error, cache yang dibaca', () async {
    when(() => remote.fetchNotes()).thenThrow(Exception('offline'));
    when(() => cache.readNotes()).thenAnswer((_) async => [catatan]);

    final notes = await repository.getNotes();

    expect(notes, [catatan]);
    expect(repository.lastFromCache, isTrue);
    verifyNever(() => cache.saveNotes(any()));
  });
}
API mocktailFungsi

when(() => mock.f()).thenReturn(nilai)Method biasa mengembalikan nilai
when(() => mock.f()).thenAnswer((_) async => nilai)Method yang mengembalikan Future
when(() => mock.f()).thenThrow(error)Method melempar error
any()Argumen apa saja
verify(() => mock.f()).called(n)Memastikan method dipanggil n kali
verifyNever(() => mock.f())Memastikan method tidak pernah dipanggil

Jika memakai any() untuk argumen bertipe class buatan sendiri (misalnya Note), mocktail meminta Anda mendaftarkan nilai cadangan sekali di setUpAll(() => registerFallbackValue(const Note(id: '', title: '', content: '')));. Untuk List<Note> seperti contoh di atas, hal ini tidak diperlukan.

Fake atau mock?

  • Pakai fake jika pengganti yang sama dipakai di banyak file test (repository, provider, widget test). Contoh di modul ini memakai fake yang sama di tiga tempat.
  • Pakai mock jika Anda ingin memeriksa interaksi: method apa yang dipanggil, berapa kali, dengan argumen apa.

⚠️ Kesalahan umum

  • Membuat koneksi di dalam class (final client = Supabase.instance.client; di dalam repository). Class seperti ini tidak bisa diuji tanpa Supabase sungguhan. Terima dependensi lewat konstruktor.
  • Lupa melakukan stub: memanggil method mock yang belum diatur dengan when menghasilkan error type 'Null' is not a subtype of type 'Future<...>'.
  • Memakai thenReturn untuk method yang mengembalikan Future. Gunakan thenAnswer((_) async => ...).
  • Hanya menguji jalur sukses. Bagian paling berharga dari fake/mock justru kemampuannya mensimulasikan kegagalan.
