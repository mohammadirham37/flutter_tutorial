Di Modul 14, logika halaman catatan dipindahkan ke NotesProvider. Kabar baiknya: ChangeNotifier adalah class Dart biasa, sehingga bisa diuji dengan unit test tanpa widget sama sekali. Setelah itu, kita uji halaman yang memakai provider tersebut dengan widget test.

Provider yang akan diuji

📄 lib/providers/notes_provider.dart

// lib/providers/notes_provider.dart
import 'package:flutter/foundation.dart';

import '../data/note_repository.dart';
import '../models/note.dart';

enum NotesStatus { initial, loading, loaded, error }

class NotesProvider extends ChangeNotifier {
  NotesProvider(this._repository);

  final NoteRepository _repository;

  NotesStatus status = NotesStatus.initial;
  List<Note> notes = [];
  String? errorMessage;
  bool get isOffline => _repository.lastFromCache;

  Future<void> loadNotes() async {
    status = NotesStatus.loading;
    notifyListeners();
    try {
      notes = await _repository.getNotes();
      status = NotesStatus.loaded;
    } catch (e) {
      errorMessage = 'Gagal memuat catatan';
      status = NotesStatus.error;
    }
    notifyListeners();
  }

  Future<bool> addNote(String title, String content) async {
    try {
      final note = await _repository.addNote(title, content);
      notes = [note, ...notes];
      notifyListeners();
      return true;
    } catch (e) {
      errorMessage = 'Gagal menyimpan catatan';
      notifyListeners();
      return false;
    }
  }
}

Langkah 1: unit test untuk ChangeNotifier

Provider dibuat dengan repository sungguhan yang diberi data source palsu dari bagian sebelumnya (test/mock/fakes.dart). Dengan begitu kita sekaligus menguji kerja sama provider dan repository.

📄 test/unit/notes_provider_test.dart

// test/unit/notes_provider_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';
import 'package:catatan_kuliah/providers/notes_provider.dart';

import '../mock/fakes.dart';

void main() {
  late FakeRemoteDataSource remote;
  late NotesProvider provider;

  setUp(() {
    remote = FakeRemoteDataSource(
      awal: [const Note(id: 'n1', title: 'Pertemuan 1', content: 'Dart')],
    );
    final repository = NoteRepository(remote: remote, cache: FakeLocalCache());
    provider = NotesProvider(repository);
  });

  test('status awal initial dan list kosong', () {
    expect(provider.status, NotesStatus.initial);
    expect(provider.notes, isEmpty);
  });

  test('loadNotes: loading lalu loaded', () async {
    final riwayatStatus = <NotesStatus>[];
    provider.addListener(() => riwayatStatus.add(provider.status));

    await provider.loadNotes();

    expect(riwayatStatus, [NotesStatus.loading, NotesStatus.loaded]);
    expect(provider.notes, hasLength(1));
  });

  test('addNote menaruh catatan baru di urutan teratas', () async {
    await provider.loadNotes();

    final berhasil = await provider.addNote('Kuis', 'Bab 2');

    expect(berhasil, isTrue);
    expect(provider.notes.first.title, 'Kuis');
    expect(provider.notes, hasLength(2));
  });

  test('addNote gagal saat offline, errorMessage terisi', () async {
    remote.shouldFail = true;

    final berhasil = await provider.addNote('Kuis', 'Bab 2');

    expect(berhasil, isFalse);
    expect(provider.errorMessage, 'Gagal menyimpan catatan');
  });

  test('provider memanggil notifyListeners saat addNote', () async {
    var jumlahNotifikasi = 0;
    provider.addListener(() => jumlahNotifikasi++);

    await provider.addNote('Kuis', 'Bab 2');

    expect(jumlahNotifikasi, 1);
  });
}

Teknik yang perlu diperhatikan:

  • provider.addListener(...): inilah cara widget “mendengar” provider. Di test, kita memakainya untuk merekam urutan status (loading lalu loaded) dan menghitung berapa kali notifyListeners() dipanggil.
  • Menguji jumlah notifikasi mencegah dua bug yang sering terjadi: lupa memanggil notifyListeners() (UI tidak berubah) dan memanggilnya berlebihan (UI rebuild tanpa perlu).
  • remote.shouldFail = true: mensimulasikan kondisi offline cukup dengan satu baris.

Langkah 2: halaman yang memakai provider

📄 lib/pages/notes_page.dart

// lib/pages/notes_page.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import '../providers/notes_provider.dart';

class NotesPage extends StatelessWidget {
  const NotesPage({super.key});

  @override
  Widget build(BuildContext context) {
    final provider = context.watch<NotesProvider>();

    return Scaffold(
      appBar: AppBar(title: const Text('Catatan Kuliah')),
      body: switch (provider.status) {
        NotesStatus.initial ||
        NotesStatus.loading => const Center(child: CircularProgressIndicator()),
        NotesStatus.error => Center(child: Text(provider.errorMessage ?? 'Error')),
        NotesStatus.loaded => Column(
            children: [
              if (provider.isOffline)
                const MaterialBanner(
                  content: Text('Mode offline: menampilkan data cache'),
                  actions: [SizedBox.shrink()],
                ),
              Expanded(
                child: provider.notes.isEmpty
                    ? const Center(child: Text('Belum ada catatan'))
                    : ListView.builder(
                        itemCount: provider.notes.length,
                        itemBuilder: (context, index) {
                          final note = provider.notes[index];
                          return ListTile(
                            title: Text(note.title),
                            subtitle: Text(note.content),
                          );
                        },
                      ),
              ),
            ],
          ),
      },
    );
  }
}
Fake remote berhasil: daftar catatan tampil
shouldFail = true: data cache dan banner mode offline

Screenshot di atas diambil dengan memasang FakeRemoteDataSource dan FakeLocalCache di main(). Ini trik yang berguna untuk mendesain tampilan offline tanpa harus mematikan internet.

Langkah 3: widget test dengan ChangeNotifierProvider

Pola kuncinya: bungkus halaman dengan ChangeNotifierProvider yang berisi provider dengan dependensi palsu, di atas MaterialApp, persis seperti di main.dart.

📄 test/widget/notes_page_test.dart

// test/widget/notes_page_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:provider/provider.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:catatan_kuliah/models/note.dart';
import 'package:catatan_kuliah/pages/notes_page.dart';
import 'package:catatan_kuliah/providers/notes_provider.dart';

import '../mock/fakes.dart';

void main() {
  late FakeRemoteDataSource remote;
  late FakeLocalCache cache;

  setUp(() {
    remote = FakeRemoteDataSource(
      awal: [const Note(id: 'n1', title: 'Pertemuan 1', content: 'Dart')],
    );
    cache = FakeLocalCache();
  });

  Widget buatApp() {
    final repository = NoteRepository(remote: remote, cache: cache);
    return ChangeNotifierProvider(
      create: (_) => NotesProvider(repository)..loadNotes(),
      child: const MaterialApp(home: NotesPage()),
    );
  }

  testWidgets('menampilkan loading lalu daftar catatan', (tester) async {
    await tester.pumpWidget(buatApp());

    // Frame pertama: data belum datang
    expect(find.byType(CircularProgressIndicator), findsOneWidget);

    await tester.pumpAndSettle(); // tunggu Future selesai

    expect(find.text('Pertemuan 1'), findsOneWidget);
    expect(find.byType(CircularProgressIndicator), findsNothing);
  });

  testWidgets('offline dengan cache: tampil banner mode offline',
      (tester) async {
    remote.shouldFail = true;
    cache.saved = [const Note(id: 'c1', title: 'Dari cache', content: '-')];

    await tester.pumpWidget(buatApp());
    await tester.pumpAndSettle();

    expect(find.text('Dari cache'), findsOneWidget);
    expect(find.textContaining('Mode offline'), findsOneWidget);
  });

  testWidgets('tanpa data sama sekali: tampil pesan kosong', (tester) async {
    remote.notes.clear();

    await tester.pumpWidget(buatApp());
    await tester.pumpAndSettle();

    expect(find.text('Belum ada catatan'), findsOneWidget);
  });
}
  • NotesProvider(repository)..loadNotes(): operator kaskade (..) memanggil loadNotes() lalu mengembalikan provider-nya.
  • Frame pertama setelah pumpWidget menampilkan loading karena Future belum selesai. pumpAndSettle() menunggu Future fake selesai lalu menggambar ulang.
  • Fungsi buatApp() dipanggil setelah test mengubah remote/cache, sehingga setiap test bisa menyiapkan skenario berbeda.

Alternatif: memakai ChangeNotifierProvider.value

Jika test perlu memegang objek provider untuk dipanggil langsung, buat provider di luar lalu berikan dengan .value:

testWidgets('catatan baru langsung tampil di daftar', (tester) async {
  final provider = NotesProvider(
    NoteRepository(remote: FakeRemoteDataSource(), cache: FakeLocalCache()),
  );
  await provider.loadNotes();

  await tester.pumpWidget(
    ChangeNotifierProvider.value(
      value: provider,
      child: const MaterialApp(home: NotesPage()),
    ),
  );
  expect(find.text('Belum ada catatan'), findsOneWidget);

  await provider.addNote('Tugas Besar', 'Deadline minggu 16');
  await tester.pump();

  expect(find.text('Tugas Besar'), findsOneWidget);
});

⚠️ Kesalahan umum

  • Membuat provider yang di dalamnya langsung memanggil Supabase.instance.client atau Hive.box(). Provider seperti itu tidak bisa diuji; terima repository lewat konstruktor.
  • Meletakkan ChangeNotifierProvider di bawah MaterialApp di test, lalu test navigasi gagal dengan ProviderNotFoundException (lihat bagian 1).
  • Hanya menguji provider lewat UI. Unit test provider jauh lebih cepat dan pesan gagalnya lebih jelas; gunakan widget test untuk memastikan UI bereaksi terhadap state.
