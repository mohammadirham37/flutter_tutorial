Ada beberapa cara membaca provider. Perbedaannya ada pada kapan widget di-build ulang. Memilih cara yang tepat membuat aplikasi benar sekaligus hemat rebuild.

Ringkasan lima cara

// 1) watch: baca + langganan SEMUA perubahan (di dalam build)
final profil = context.watch<ProfilProvider>();

// 2) select: baca + langganan SATU nilai saja (di dalam build)
final nama = context.select((ProfilProvider p) => p.nama);

// 3) read: ambil objek tanpa langganan (di callback/event)
void onTekan() => context.read<ProfilProvider>().tambahPoin();

// 4) Consumer: langganan, tetapi hanya bagian builder yang rebuild
final widgetPoin = Consumer<ProfilProvider>(
  builder: (context, p, child) => Text('Poin: ${p.poin}'),
);

// 5) Selector: seperti Consumer + select
final widgetPoin2 = Selector<ProfilProvider, int>(
  selector: (context, p) => p.poin,
  builder: (context, poin, child) => Text('Poin: $poin'),
);
CaraRebuild ketikaDipakai di
context.watch<T>()Setiap notifyListeners()build()
context.select<T, R>(fn)Hanya jika nilai hasil fn berubahbuild()
context.read<T>()Tidak pernahCallback: onPressed, onTap, initState (lewat post-frame)
Consumer<T>Setiap notify, tetapi hanya isi builderDi tengah pohon widget
Selector<T, R>Hanya jika nilai selector berubah, hanya isi builderDi tengah pohon widget

Contoh lengkap: membuktikan perbedaan rebuild

Setiap kartu menampilkan berapa kali ia di-build. Tekan tombol dan amati angka mana yang naik.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Demo rebuild: angka "build ke-N" menunjukkan berapa kali tiap kartu di-build
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

class ProfilProvider extends ChangeNotifier {
  String _nama = 'Andi';
  int _poin = 0;

  String get nama => _nama;
  int get poin => _poin;

  void tambahPoin() {
    _poin++;
    notifyListeners();
  }

  void gantiNama() {
    _nama = _nama == 'Andi' ? 'Bunga' : 'Andi';
    notifyListeners();
  }
}

// Penghitung build HANYA untuk keperluan demo (jangan ditiru di aplikasi nyata)
final Map<String, int> jumlahBuild = {};
int catatBuild(String nama) => jumlahBuild[nama] = (jumlahBuild[nama] ?? 0) + 1;

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => ProfilProvider(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepOrange),
      home: const DemoPage(),
    );
  }
}

class DemoPage extends StatelessWidget {
  const DemoPage({super.key});

  @override
  Widget build(BuildContext context) {
    // Halaman ini TIDAK watch apa pun, jadi tidak ikut rebuild
    return Scaffold(
      appBar: AppBar(title: const Text('watch vs select vs Consumer')),
      body: ListView(
        padding: const EdgeInsets.all(12),
        children: [
          const KartuWatch(),
          const KartuSelectNama(),
          const KartuConsumer(),
          const KartuSelectorPoin(),
          const SizedBox(height: 12),
          Row(
            children: [
              Expanded(
                child: FilledButton(
                  onPressed: () => context.read<ProfilProvider>().tambahPoin(),
                  child: const Text('Tambah Poin'),
                ),
              ),
              const SizedBox(width: 8),
              Expanded(
                child: OutlinedButton(
                  onPressed: () => context.read<ProfilProvider>().gantiNama(),
                  child: const Text('Ganti Nama'),
                ),
              ),
            ],
          ),
        ],
      ),
    );
  }
}

// 1) watch: rebuild untuk SETIAP perubahan (nama maupun poin)
class KartuWatch extends StatelessWidget {
  const KartuWatch({super.key});

  @override
  Widget build(BuildContext context) {
    final p = context.watch<ProfilProvider>();
    final n = catatBuild('watch');
    return Card(
      child: ListTile(
        title: Text('watch: ${p.nama}, ${p.poin} poin'),
        subtitle: Text('build ke-$n'),
      ),
    );
  }
}

// 2) select: rebuild HANYA jika nama berubah
class KartuSelectNama extends StatelessWidget {
  const KartuSelectNama({super.key});

  @override
  Widget build(BuildContext context) {
    final nama = context.select((ProfilProvider p) => p.nama);
    final n = catatBuild('select');
    return Card(
      child: ListTile(
        title: Text('select(nama): $nama'),
        subtitle: Text('build ke-$n'),
      ),
    );
  }
}

// 3) Consumer: kartu luar tidak rebuild, hanya isi builder
class KartuConsumer extends StatelessWidget {
  const KartuConsumer({super.key});

  @override
  Widget build(BuildContext context) {
    final nLuar = catatBuild('consumer-luar');
    return Card(
      child: Consumer<ProfilProvider>(
        builder: (context, p, child) {
          final nDalam = catatBuild('consumer-dalam');
          return ListTile(
            title: Text('Consumer: ${p.poin} poin'),
            subtitle: Text('luar build ke-$nLuar, builder ke-$nDalam'),
          );
        },
      ),
    );
  }
}

// 4) Selector: builder rebuild HANYA jika poin berubah
class KartuSelectorPoin extends StatelessWidget {
  const KartuSelectorPoin({super.key});

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Selector<ProfilProvider, int>(
        selector: (context, p) => p.poin,
        builder: (context, poin, child) {
          final n = catatBuild('selector');
          return ListTile(
            title: Text('Selector(poin): $poin'),
            subtitle: Text('build ke-$n'),
          );
        },
      ),
    );
  }
}
Setelah 3x Tambah Poin: kartu select(nama) tidak rebuild
Setelah Ganti Nama: Selector(poin) tidak rebuild

Penjelasan hasil:

  • Tambah Poin: kartu watch, Consumer (builder), dan Selector naik. Kartu select(nama) tetap karena nama tidak berubah.
  • Ganti Nama: kartu watch, select(nama), dan Consumer (builder) naik. Selector(poin) tetap.
  • Angka "luar" pada kartu Consumer tidak pernah naik. Hanya bagian di dalam builder yang di-build ulang.
  • DemoPage sendiri tidak pernah rebuild karena hanya memakai read di tombol.

💡 Cara memilih

  1. Di callback? Pakai read.
  2. Di build dan butuh banyak field? Pakai watch.
  3. Di build dan butuh satu nilai saja? Pakai select.
  4. Widget besar tapi hanya sebagian kecil yang berubah? Bungkus bagian kecil itu dengan Consumer/Selector, atau pecah menjadi widget sendiri.

⚠️ Kesalahan umum

  • context.read di dalam build: layar tidak ter-update karena widget tidak berlangganan.
  • context.watch di dalam onPressed: error saat tombol ditekan.
  • select yang mengembalikan list baru setiap kali, misalnya select((p) => p.items.where(...).toList()). List baru selalu dianggap "berbeda", sehingga select tidak menghemat apa pun. Pilih nilai sederhana seperti int, bool, atau String.
