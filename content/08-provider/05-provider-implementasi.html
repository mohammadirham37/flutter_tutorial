Sekarang kita gabungkan tiga pilar Provider dalam satu contoh nyata: pengisian KRS dengan batas maksimal 24 SKS.

Untuk mengimplementasikan package provider (dari pub.dev), kita menggunakan 3 pilar utama:

  1. ChangeNotifier: tempat state dan logika bisnis.
  2. ChangeNotifierProvider: menyediakan state ke pohon widget.
  3. watch / read: membaca state dari widget.

Pasang package terlebih dahulu: flutter pub add provider.

Langkah 1: Membuat Model State dengan ChangeNotifier

Buat folder lib/providers/ lalu file krs_provider.dart:

📄 lib/providers/krs_provider.dart

// lib/providers/krs_provider.dart
import 'package:flutter/foundation.dart';

class MataKuliah {
  final String nama;
  final int sks;

  const MataKuliah(this.nama, this.sks);
}

class KrsProvider with ChangeNotifier {
  // Data privat di dalam store
  final List<MataKuliah> _matkulTerpilih = [];
  final int batasMaksimalSks = 24;

  // Getter publik (read-only agar tidak bisa diubah langsung dari luar)
  List<MataKuliah> get matkulTerpilih => List.unmodifiable(_matkulTerpilih);
  int get totalSks => _matkulTerpilih.fold(0, (total, mk) => total + mk.sks);

  // Logika bisnis untuk menambah mata kuliah
  bool tambahMatkul(MataKuliah matkul) {
    if (totalSks + matkul.sks > batasMaksimalSks) {
      return false; // Melebihi batas kuota SKS!
    }

    _matkulTerpilih.add(matkul);

    // SANGAT PENTING: Beritahu seluruh widget yang mendengarkan agar me-rebuild UI!
    notifyListeners();
    return true;
  }

  void hapusMatkul(int index) {
    _matkulTerpilih.removeAt(index);
    notifyListeners();
  }
}

Perhatikan bahwa tambahMatkul mengembalikan bool. Provider yang memutuskan boleh/tidaknya (aturan bisnis), sedangkan UI hanya menampilkan pesan.

Langkah 2: Mendaftarkan Provider di Root Aplikasi (main.dart)

// Potongan inti dari lib/main.dart (kode lengkap ada di Langkah 3)
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import 'providers/krs_provider.dart';

void main() {
  runApp(
    // Membungkus aplikasi dengan ChangeNotifierProvider
    ChangeNotifierProvider(
      create: (context) => KrsProvider(),
      child: const MyApp(),
    ),
  );
}

Langkah 3: Mengonsumsi State di Widget (context.watch vs context.read)

Metode Akses Tujuan & Sifat Reaktif Tempat Penggunaan
context.watch<T>() Membaca data DAN ikut me-render ulang widget setiap ada perubahan (notifyListeners). Di dalam method build() saat menampilkan teks/angka.
context.read<T>() Hanya membaca fungsi/method SATU KALI tanpa mendaftar untuk re-render. Di dalam event handler seperti tombol onPressed: () {}.

Kode lengkap lib/main.dart yang siap dijalankan (katalog mata kuliah + ringkasan SKS):

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: (1) flutter pub add provider, (2) membuat lib/providers/krs_provider.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import 'providers/krs_provider.dart';

void main() {
  runApp(
    // Membungkus aplikasi dengan ChangeNotifierProvider di root
    ChangeNotifierProvider(
      create: (context) => KrsProvider(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: KatalogKrsScreen(),
    );
  }
}

class KatalogKrsScreen extends StatelessWidget {
  const KatalogKrsScreen({super.key});

  static const List<MataKuliah> katalog = [
    MataKuliah("Pemrograman Mobile", 4),
    MataKuliah("Basis Data Lanjut", 3),
    MataKuliah("Kecerdasan Buatan", 3),
    MataKuliah("Jaringan Komputer", 3),
    MataKuliah("Rekayasa Perangkat Lunak", 3),
    MataKuliah("Keamanan Siber", 3),
    MataKuliah("Etika Profesi", 2),
    MataKuliah("Kerja Praktik", 4),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Pengisian KRS")),
      body: Column(
        children: [
          const RingkasanKrsWidget(),
          Expanded(
            child: ListView.builder(
              itemCount: katalog.length,
              itemBuilder: (context, index) {
                final mk = katalog[index];
                return ListTile(
                  title: Text(mk.nama),
                  subtitle: Text("${mk.sks} SKS"),
                  trailing: IconButton(
                    tooltip: "Ambil ${mk.nama}",
                    icon: const Icon(Icons.add_circle, color: Colors.indigo),
                    onPressed: () {
                      // 2. Di event handler gunakan read: hanya memanggil method, tanpa rebuild
                      final berhasil = context.read<KrsProvider>().tambahMatkul(mk);
                      if (!berhasil) {
                        ScaffoldMessenger.of(context).showSnackBar(
                          const SnackBar(
                            content: Text("Kuota maksimal 24 SKS terlampaui!"),
                            backgroundColor: Colors.red,
                          ),
                        );
                      }
                    },
                  ),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

// Contoh Widget Tampilan KRS Menggunakan Provider
class RingkasanKrsWidget extends StatelessWidget {
  const RingkasanKrsWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // 1. Menggunakan watch untuk mendengarkan perubahan angka SKS
    final krs = context.watch<KrsProvider>();

    return Card(
      margin: const EdgeInsets.all(16),
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            Text("Total SKS Diambil: ${krs.totalSks} / ${krs.batasMaksimalSks} SKS"),
            const SizedBox(height: 8),
            LinearProgressIndicator(
              value: krs.totalSks / krs.batasMaksimalSks,
              color: krs.totalSks >= 20 ? Colors.orange : Colors.blue,
            ),
            const SizedBox(height: 8),
            Wrap(
              spacing: 6,
              children: [
                for (var i = 0; i < krs.matkulTerpilih.length; i++)
                  InputChip(
                    label: Text(krs.matkulTerpilih[i].nama),
                    onDeleted: () => context.read<KrsProvider>().hapusMatkul(i),
                  ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
Ringkasan SKS ikut berubah saat mata kuliah diambil

Penjelasan:

  • KatalogKrsScreen tidak memakai watch, sehingga daftar katalog tidak ikut rebuild ketika SKS bertambah.
  • RingkasanKrsWidget memakai watch sehingga total SKS, progress bar, dan chip selalu sinkron.
  • InputChip.onDeleted memanggil hapusMatkul lewat read.
  • List.unmodifiable di getter mencegah UI menambah item langsung tanpa melewati tambahMatkul (yang memeriksa kuota).

⚠️ Kesalahan umum

  • Memeriksa batas SKS di UI, bukan di provider. Jika ada dua tombol tambah di dua halaman, aturannya harus ditulis dua kali.
  • Mengembalikan _matkulTerpilih langsung dari getter. UI bisa memanggil .add() dan melewati pengecekan kuota.
