Data dari internet atau database tidak datang seketika. Selama menunggu, UI harus menampilkan loading; jika gagal, menampilkan error dengan tombol coba lagi; jika berhasil, menampilkan data. Pola tiga serangkai isLoading / error / data ini akan dipakai ulang di Modul 09 (REST API) dan proyek CRUD Modul 13–14.

Pola di sisi UI

// Urutan pengecekan di UI: loading -> error -> kosong -> data
if (prov.isLoading) return const CircularProgressIndicator();
if (prov.error != null) return Text(prov.error!);
if (prov.data.isEmpty) return const Text('Belum ada data');
return ListView(children: [for (final d in prov.data) Text(d)]);

Pola di sisi provider

  1. Set _isLoading = true, kosongkan _error, lalu notifyListeners().
  2. try: panggil service dan simpan hasilnya.
  3. catch: simpan pesan error.
  4. finally: set _isLoading = false, lalu notifyListeners(). Bagian finally selalu dijalankan, sehingga loading tidak "macet".

// Service = satu-satunya tempat yang tahu cara MENGAMBIL data.
// Saat ini datanya palsu; di Modul 09 isi fungsi ini diganti dengan HTTP request.
import '../models/mahasiswa.dart';

class MahasiswaService {
  Future<List<Mahasiswa>> ambilSemua({bool simulasiGagal = false}) async {
    await Future.delayed(const Duration(seconds: 3)); // pura-pura menunggu server

    if (simulasiGagal) {
      throw Exception('Server tidak dapat dihubungi');
    }

    return const [
      Mahasiswa(nim: 'H1D023001', nama: 'Andi Pratama', ipk: 3.45),
      Mahasiswa(nim: 'H1D023002', nama: 'Bunga Lestari', ipk: 3.81),
      Mahasiswa(nim: 'H1D023003', nama: 'Citra Ayu', ipk: 3.12),
      Mahasiswa(nim: 'H1D023004', nama: 'Dimas Saputra', ipk: 3.67),
    ];
  }
}

📄 lib/providers/mahasiswa_provider.dart

// lib/providers/mahasiswa_provider.dart
import 'package:flutter/foundation.dart';

import '../models/mahasiswa.dart';
import '../services/mahasiswa_service.dart';

class MahasiswaProvider extends ChangeNotifier {
  MahasiswaProvider(this._service);

  final MahasiswaService _service;

  // Tiga serangkai state async
  bool _isLoading = false;
  String? _error;
  List<Mahasiswa> _data = [];

  bool get isLoading => _isLoading;
  String? get error => _error;
  List<Mahasiswa> get data => List.unmodifiable(_data);

  Future<void> muatData({bool simulasiGagal = false}) async {
    if (_isLoading) return; // cegah request ganda saat tombol ditekan berkali-kali

    _isLoading = true;
    _error = null;
    notifyListeners(); // UI menampilkan loading

    try {
      _data = await _service.ambilSemua(simulasiGagal: simulasiGagal);
    } catch (e) {
      _error = 'Gagal memuat data: $e';
    } finally {
      _isLoading = false;
      notifyListeners(); // UI menampilkan data ATAU error
    }
  }
}

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import 'providers/mahasiswa_provider.dart';
import 'services/mahasiswa_service.dart';

void main() {
  runApp(
    ChangeNotifierProvider(
      // ..muatData() langsung memulai pemuatan saat provider dibuat
      create: (_) => MahasiswaProvider(MahasiswaService())..muatData(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DaftarMahasiswaPage(),
    );
  }
}

class DaftarMahasiswaPage extends StatelessWidget {
  const DaftarMahasiswaPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Data Mahasiswa'),
        actions: [
          IconButton(
            tooltip: 'Simulasi gagal',
            icon: const Icon(Icons.wifi_off),
            onPressed: () =>
                context.read<MahasiswaProvider>().muatData(simulasiGagal: true),
          ),
        ],
      ),
      body: const _IsiHalaman(),
    );
  }
}

class _IsiHalaman extends StatelessWidget {
  const _IsiHalaman();

  @override
  Widget build(BuildContext context) {
    final prov = context.watch<MahasiswaProvider>();

    // 1. Loading pertama kali (belum ada data sama sekali)
    if (prov.isLoading && prov.data.isEmpty) {
      return const Center(child: CircularProgressIndicator());
    }

    // 2. Error
    if (prov.error != null) {
      return Center(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              const Icon(Icons.error_outline, size: 64, color: Colors.red),
              const SizedBox(height: 12),
              Text(prov.error!, textAlign: TextAlign.center),
              const SizedBox(height: 12),
              FilledButton.icon(
                icon: const Icon(Icons.refresh),
                label: const Text('Coba Lagi'),
                onPressed: () => context.read<MahasiswaProvider>().muatData(),
              ),
            ],
          ),
        ),
      );
    }

    // 3. Data kosong
    if (prov.data.isEmpty) {
      return const Center(child: Text('Belum ada data'));
    }

    // 4. Data tersedia (+ tarik ke bawah untuk memuat ulang)
    return RefreshIndicator(
      onRefresh: () => context.read<MahasiswaProvider>().muatData(),
      child: ListView.builder(
        itemCount: prov.data.length,
        itemBuilder: (context, i) {
          final m = prov.data[i];
          return ListTile(
            leading: CircleAvatar(child: Text(m.nama[0])),
            title: Text(m.nama),
            subtitle: Text(m.nim),
            trailing: Text('IPK ${m.ipk.toStringAsFixed(2)}'),
          );
        },
      ),
    );
  }
}

Penjelasan:

  • MahasiswaService hanya tahu cara mengambil data. Ia tidak tahu apa pun soal UI atau notifyListeners.
  • MahasiswaProvider menerima service lewat constructor (dependency injection). Saat testing (Modul 15), service ini bisa diganti dengan versi palsu.
  • create: (_) => MahasiswaProvider(MahasiswaService())..muatData(): operator cascade .. memanggil muatData() lalu tetap mengembalikan objek provider.
  • if (_isLoading) return; mencegah request ganda saat tombol ditekan berkali-kali.
  • Tombol ikon wifi mensimulasikan kegagalan sehingga tampilan error bisa dicoba tanpa mematikan internet.
  • Kondisi loading ditulis prov.isLoading && prov.data.isEmpty: saat refresh (data lama masih ada), list tetap tampil dan indikator RefreshIndicator yang berputar.

💡 Variasi: enum status

Sebagian tim memakai enum Status { awal, loading, sukses, gagal } sebagai pengganti beberapa boolean. Keduanya sah; yang penting UI selalu menangani semua kemungkinan.

⚠️ Kesalahan umum

  • Lupa notifyListeners() sebelum await, sehingga loading tidak pernah terlihat.
  • Tidak memakai finally: jika terjadi error, isLoading tetap true selamanya.
  • Tidak mengosongkan _error saat mencoba lagi, sehingga pesan error lama tetap tampil walaupun request kedua berhasil.
  • Memanggil service langsung dari widget (di build). Setiap rebuild akan memicu request baru.
