ChangeNotifierProvider dari package provider "menitipkan" sebuah ChangeNotifier di pohon widget. Semua widget di bawahnya bisa mengambil objek itu lewat context, tanpa constructor.

Instalasi

flutter pub add provider

Contoh kecil: mendaftarkan provider

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

class CounterModel extends ChangeNotifier {
  int _nilai = 0;
  int get nilai => _nilai;

  void tambah() {
    _nilai++;
    notifyListeners();
  }
}

void main() {
  runApp(
    // create dipanggil SEKALI; Provider juga otomatis memanggil dispose()
    ChangeNotifierProvider(
      create: (context) => CounterModel(),
      child: const MyApp(), // seluruh MyApp & turunannya bisa mengakses CounterModel
    ),
  );
}
  • create dipanggil sekali (secara lazy, saat pertama kali dibaca) untuk membuat objek.
  • Saat provider dibuang dari pohon widget, ia otomatis memanggil dispose() pada objek tersebut.
  • Provider di atas MaterialApp berarti tersedia di semua halaman, termasuk halaman yang dibuka dengan Navigator.push.

Contoh lengkap: satu state, dua halaman

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah: flutter pub add provider
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

class CounterModel extends ChangeNotifier {
  int _nilai = 0;
  int get nilai => _nilai;

  void tambah() {
    _nilai++;
    notifyListeners();
  }

  void kurang() {
    if (_nilai == 0) return;
    _nilai--;
    notifyListeners();
  }
}

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (context) => CounterModel(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const HalamanSatu(),
    );
  }
}

class HalamanSatu extends StatelessWidget {
  const HalamanSatu({super.key});

  @override
  Widget build(BuildContext context) {
    // watch: widget ini rebuild setiap CounterModel memanggil notifyListeners
    final nilai = context.watch<CounterModel>().nilai;

    return Scaffold(
      appBar: AppBar(title: const Text('Halaman Satu')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Nilai: $nilai', style: Theme.of(context).textTheme.headlineMedium),
            const SizedBox(height: 16),
            FilledButton(
              // read: hanya memanggil method, tidak berlangganan
              onPressed: () => context.read<CounterModel>().tambah(),
              child: const Text('Tambah'),
            ),
            const SizedBox(height: 8),
            OutlinedButton(
              // Tidak ada data yang dikirim lewat constructor!
              onPressed: () => Navigator.push(
                context,
                MaterialPageRoute(builder: (_) => const HalamanDua()),
              ),
              child: const Text('Buka Halaman Dua'),
            ),
          ],
        ),
      ),
    );
  }
}

class HalamanDua extends StatelessWidget {
  const HalamanDua({super.key});

  @override
  Widget build(BuildContext context) {
    final nilai = context.watch<CounterModel>().nilai;

    return Scaffold(
      appBar: AppBar(title: const Text('Halaman Dua')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Nilai yang sama: $nilai',
                style: Theme.of(context).textTheme.headlineMedium),
            const SizedBox(height: 16),
            FilledButton.tonal(
              onPressed: () => context.read<CounterModel>().kurang(),
              child: const Text('Kurangi dari Halaman Dua'),
            ),
          ],
        ),
      ),
    );
  }
}
Halaman Dua membaca dan mengubah state yang sama

Penjelasan:

  • HalamanDua dibuka tanpa mengirim data apa pun, tetapi bisa membaca dan mengubah nilai yang sama.
  • Saat menekan "Kurangi" di Halaman Dua lalu kembali, Halaman Satu sudah menampilkan nilai terbaru karena ia juga watch objek yang sama.
  • context.watch<CounterModel>() dipakai di build; context.read<CounterModel>() dipakai di onPressed. Bedanya dibahas di section berikutnya.

⚠️ Kesalahan umum

  • ProviderNotFoundException. Muncul jika widget mencari provider yang tidak ada di atasnya. Penyebab tersering: provider dipasang di dalam satu halaman, lalu halaman lain (hasil push) mencoba membacanya. Pasang provider di atas MaterialApp jika dipakai lintas halaman.
  • Lupa menulis tipe generik: context.watch() tanpa <CounterModel> membuat Dart tidak tahu provider mana yang dicari.
  • Memakai Provider biasa (bukan ChangeNotifierProvider) untuk ChangeNotifier. Hasilnya UI tidak pernah rebuild.
