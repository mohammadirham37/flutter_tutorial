Web tutorial ini adalah "buku ajar interaktif" mata kuliah. Setiap modul memiliki tiga tab di bagian atas halaman modul:

📖 Materi

Isi pelajaran yang dibagi menjadi beberapa section bernomor. Baca berurutan dari section 1. Gunakan daftar isi di samping untuk melompat ke section tertentu.

🛠️ Tugas Praktikum Mandiri

Sasaran, langkah kerja, luaran yang diharapkan, dan rubrik penilaian. Kerjakan setelah membaca semua materi modul, lalu kumpulkan ke repositori GitHub Anda.

✅ Kuis Pemahaman

Soal pilihan ganda dengan pembahasan. Kerjakan tanpa membuka materi untuk mengukur pemahaman, lalu baca pembahasan untuk soal yang salah.

Membaca komponen di dalam materi

KomponenArtinya
Label 📄 lib/main.dart di atas kodeKode adalah isi satu file utuh. Ganti seluruh isi file tersebut dengan kode contoh.
Kode tanpa labelPotongan (snippet) untuk dibaca atau disisipkan ke kode yang sudah ada, bukan program lengkap.
Kode bashPerintah yang diketik di terminal (Terminal macOS/Linux, PowerShell, atau terminal VS Code).
Kotak ℹ️ InfoPenjelasan tambahan atau latar belakang konsep.
Kotak 💡 TipsCara kerja yang lebih cepat atau lebih rapi.
Kotak ⚠️ PerhatianKesalahan yang sering terjadi. Baca dengan teliti, biasanya ini sumber error mahasiswa.

Contoh membaca label file

Jika Anda melihat dua blok berikut di satu section, artinya Anda harus membuat dua file di proyek:

📄 lib/main.dart                  -> ganti seluruh isi file bawaan
📄 lib/models/mahasiswa.dart      -> buat folder models/ dan file baru di dalamnya

💡 Progres belajar tersimpan otomatis

Status modul yang sudah Anda selesaikan disimpan di browser (localStorage). Gunakan browser dan perangkat yang sama agar progres tidak hilang. Mode gelap dan fitur pencarian materi tersedia di bagian atas halaman.
