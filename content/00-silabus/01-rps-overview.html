Selamat datang di mata kuliah Pemrograman Aplikasi Perangkat Bergerak (Mobile Application Development) berbasis Flutter & Dart untuk mahasiswa Program Studi S1 Informatika, Fakultas Teknik, Universitas Jenderal Soedirman (UNSOED). Kurikulum ini dirancang terstruktur dan komprehensif agar mahasiswa memiliki keterampilan siap industri (industry-ready) dalam membangun aplikasi Android dan iOS berkualitas tinggi dari satu basis kode (single codebase).

🎯 Tujuan Kompetensi Lulusan (CPMK)

Setelah menyelesaikan rangkaian modul ini, mahasiswa diharapkan mampu merancang arsitektur aplikasi mobile yang bersih, mengimplementasikan antarmuka reaktif yang responsif, mengelola status aplikasi (state management), mengintegrasikan layanan web API (RESTful), mengelola basis data lokal offline-first (SQLite dan Hive), membangun backend cloud dengan autentikasi (Supabase), serta mempublikasikan aplikasi ke format berkas rilis (.apk dan .aab).

Struktur Distribusi Materi Kuliah (17 Modul, 16 Pertemuan)

Seluruh materi dibagi menjadi 17 modul (M00 sampai M16) yang dikelompokkan ke dalam 6 fase. Setiap fase menghasilkan satu capaian nyata yang bisa Anda tunjukkan.

Fase Modul Fokus Utama Output Capaian
Fase 1 M00 - M02 Fondasi: Silabus, Setup Flutter, Bahasa Dart 3 Lingkungan dev siap, aplikasi "Halo Kampus" berjalan, logika Dart dikuasai
Fase 2 M03 - M06 UI: Widget & Lifecycle, Layouting Responsif, Form & Input, List & Scroll Halaman aplikasi kampus yang rapi dan interaktif
Fase 3 M07 - M08 Arsitektur Aplikasi: Navigasi & Routing, State Management Provider Aplikasi multi-halaman dengan state terpusat (materi UTS)
Fase 4 M09 - M12 Data: REST API, SharedPreferences & SQLite, Hive NoSQL, Supabase (Database, Auth, RLS) Aplikasi yang membaca/menyimpan data lokal dan cloud
Fase 5 M13 - M14 Proyek Tutorial Terpadu: Auth login/register Supabase, CRUD + cache offline Hive Satu aplikasi utuh siap pakai sebagai pola dasar capstone
Fase 6 M15 - M16 Kualitas & Rilis: Debugging, Testing, Build Rilis, Capstone Proyek portofolio teruji dan siap rilis (.apk / .aab)

Daftar Lengkap Modul

  1. M00 Silabus - RPS, kontrak kuliah, cara belajar, persiapan perangkat.
  2. M01 Pengenalan Flutter & Setup - instalasi, CLI, anatomi proyek, Hot Reload, aplikasi pertama.
  3. M02 Bahasa Dart 3 - variabel, null safety, fungsi, OOP, collection, async.
  4. M03 Widget Dasar & Lifecycle - Stateless vs Stateful, setState, siklus hidup.
  5. M04 Layouting & Responsif - Row, Column, Stack, Expanded, LayoutBuilder.
  6. M05 Form & Input - TextFormField, validasi, controller.
  7. M06 List & Scroll - ListView.builder, GridView, pencarian.
  8. M07 Navigasi & Routing - Navigator, kirim/terima data antar halaman.
  9. M08 State Management Provider - ChangeNotifier, Consumer, state global.
  10. M09 REST API - package http, JSON, model, FutureBuilder.
  11. M10 Local Storage - SharedPreferences dan SQLite.
  12. M11 Hive NoSQL Lokal - box, adapter, mini proyek CRUD catatan offline.
  13. M12 Supabase - database Postgres, Auth, Row Level Security (RLS).
  14. M13 Proyek Tutorial 1 - setup arsitektur + Auth login/register Supabase.
  15. M14 Proyek Tutorial 2 - CRUD Supabase + cache offline Hive.
  16. M15 Debugging & Testing - DevTools, unit test, widget test.
  17. M16 Build Rilis & Capstone - ikon, signing, build APK/AAB, presentasi proyek.
