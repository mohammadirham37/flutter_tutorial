Pemrograman tidak bisa dikuasai hanya dengan membaca. Gunakan siklus belajar berikut untuk setiap modul:

  1. Baca konsep - pahami dulu masalah apa yang diselesaikan materi ini.
  2. Ketik ulang contoh kode - jangan copy-paste di percobaan pertama. Mengetik membuat Anda memperhatikan setiap tanda kurung, koma, dan titik koma.
  3. Jalankan dan amati - cocokkan hasil di layar dengan penjelasan materi.
  4. Ubah sedikit - ganti teks, warna, angka, atau tambahkan satu widget. Tanyakan "apa yang terjadi jika ...?" lalu buktikan.
  5. Sengaja buat error - hapus satu kurung atau ganti tipe data, lalu baca pesan error-nya. Ini latihan paling berharga untuk debugging.
  6. Kerjakan praktikum dan kuis - lalu commit hasilnya ke GitHub.

Cara menjalankan contoh kode

Ada dua jenis contoh kode di web ini, dan cara menjalankannya berbeda.

1. Dart murni (terutama Modul 02). Tidak butuh Flutter maupun emulator. Buka dartpad.dev, tempel kode, lalu klik Run. Coba sekarang:

void main() {
  const nama = 'Mahasiswa UNSOED';
  final modul = ['Dart', 'Widget', 'Layout', 'Supabase'];

  print('Halo, $nama!');
  for (final m in modul) {
    print('Saya akan belajar $m');
  }
}

Hasil di panel Console:

Halo, Mahasiswa UNSOED!
Saya akan belajar Dart
Saya akan belajar Widget
Saya akan belajar Layout
Saya akan belajar Supabase

2. Aplikasi Flutter (Modul 01 dan seterusnya). Butuh proyek Flutter dan device (emulator, HP fisik, atau Chrome). Buat satu proyek "kelinci percobaan" khusus untuk mencoba contoh:

# Sekali saja: buat proyek latihan
flutter create latihan_flutter
cd latihan_flutter

# Setiap mencoba contoh berlabel lib/main.dart:
# 1. Ganti seluruh isi lib/main.dart dengan kode contoh
# 2. Jalankan aplikasi
flutter run

# Jika contoh memakai package, tambahkan dulu (contoh: package http)
flutter pub add http

Alur kerja Git untuk tiap praktikum

Simpan setiap praktikum sebagai commit di repositori yang dibuat pada Praktikum 0:

git add .
git commit -m "Praktikum 01: aplikasi Halo Kampus"
git push origin main

⚠️ Kesalahan umum saat mencoba contoh

  • Menempel kode di bawah kode lama sehingga ada dua fungsi main(). Hapus dulu seluruh isi file sebelum menempel.
  • Lupa flutter pub add sehingga muncul error Target of URI doesn't exist.
  • Hanya menekan Hot Reload setelah mengganti seluruh main.dart. Gunakan Hot Restart (R), penjelasannya ada di Modul 01.
  • Mengabaikan garis merah di editor. Jalankan flutter analyze dan perbaiki error sebelum flutter run.
