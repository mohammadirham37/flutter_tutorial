Model Note mewakili satu baris tabel notes. Model ini dipakai di tiga tempat: data dari Supabase, data dari cache Hive, dan data yang dikirim saat insert/update. Karena itu kita butuh tiga konversi.

File: lib/models/note.dart

📄 lib/models/note.dart

/// Model satu catatan kuliah. Satu objek Note = satu baris di tabel `notes`.
class Note {
  const Note({
    required this.id,
    required this.userId,
    required this.title,
    required this.content,
    required this.category,
    required this.createdAt,
    required this.updatedAt,
  });

  /// Pilihan kategori yang tersedia di form.
  static const List<String> categories = [
    'Kuliah',
    'Tugas',
    'Ujian',
    'Lainnya',
  ];

  final String id;
  final String userId;
  final String title;
  final String content;
  final String category;
  final DateTime createdAt;
  final DateTime updatedAt;

  /// Membuat Note dari Map. Dipakai untuk data dari Supabase
  /// (`Map<String, dynamic>`) maupun dari Hive (`Map<dynamic, dynamic>`).
  factory Note.fromJson(Map<dynamic, dynamic> json) {
    return Note(
      id: json['id'] as String,
      userId: json['user_id'] as String,
      title: json['title'] as String? ?? '',
      content: json['content'] as String? ?? '',
      category: json['category'] as String? ?? 'Lainnya',
      createdAt: DateTime.parse(json['created_at'] as String),
      updatedAt: DateTime.parse(json['updated_at'] as String),
    );
  }

  /// Seluruh kolom, dipakai untuk menyimpan cache di Hive.
  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'user_id': userId,
      'title': title,
      'content': content,
      'category': category,
      'created_at': createdAt.toIso8601String(),
      'updated_at': updatedAt.toIso8601String(),
    };
  }

  /// Hanya kolom yang boleh diisi/diubah aplikasi, dipakai untuk
  /// insert/update ke Supabase. id, user_id, created_at, dan updated_at
  /// diisi otomatis oleh database.
  Map<String, dynamic> toMap() {
    return {'title': title, 'content': content, 'category': category};
  }

  Note copyWith({
    String? title,
    String? content,
    String? category,
    DateTime? updatedAt,
  }) {
    return Note(
      id: id,
      userId: userId,
      title: title ?? this.title,
      content: content ?? this.content,
      category: category ?? this.category,
      createdAt: createdAt,
      updatedAt: updatedAt ?? this.updatedAt,
    );
  }
}

Tiga konversi, tiga tujuan

MethodArahDipakai olehIsi
Note.fromJson(map)Map → NoteRemote (Supabase) & Local (Hive)Semua kolom
toJson()Note → MapLocal (simpan ke Hive)Semua kolom, tanggal sebagai String ISO
toMap()Note → MapRemote (update ke Supabase)Hanya title, content, category

Hal-hal yang perlu diperhatikan

  • Parameter Map<dynamic, dynamic>: Supabase mengembalikan Map<String, dynamic>, sedangkan Hive mengembalikan Map<dynamic, dynamic> saat membaca Map yang disimpan. Dengan tipe parameter yang lebih umum, satu factory bisa melayani keduanya tanpa konversi tambahan.
  • json['title'] as String? ?? '': aman jika nilai null, tidak langsung crash.
  • DateTime.parse: Supabase mengirim timestamptz sebagai String ISO-8601 (misalnya 2026-10-28T07:15:00.123+00:00). Kita menyimpannya ke Hive dalam format yang sama, sehingga parsing-nya identik.
  • Kenapa toMap() tidak mengirim id, user_id, dan tanggal? Kolom itu milik database: id dan created_at diisi default, user_id dari auth.uid(), dan updated_at dari trigger. Mengirim lebih sedikit data berarti lebih sedikit peluang salah.
  • copyWith membuat salinan dengan beberapa nilai diganti. Ini dipakai form edit agar objek lama tidak diubah langsung (immutable).
  • static const categories menjadi satu sumber kebenaran untuk dropdown form dan chip filter, dan isinya harus sama dengan check di SQL.

final note = Note.fromJson({
  'id': 'a1',
  'user_id': 'u1',
  'title': 'Basis Data',
  'content': 'Normalisasi 3NF',
  'category': 'Kuliah',
  'created_at': '2026-10-28T07:00:00+00:00',
  'updated_at': '2026-10-28T07:00:00+00:00',
});
debugPrint(note.toMap()); // {title: Basis Data, content: Normalisasi 3NF, category: Kuliah}
debugPrint(Note.fromJson(note.toJson()).title); // Basis Data (bolak-balik aman)
