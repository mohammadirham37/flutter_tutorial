Logika paling penting di proyek ini adalah fallback offline di NoteRepository, cache Hive, dan state di NotesController (pencarian, filter, optimistic delete). Logika seperti ini sulit diuji secara manual (harus menyalakan/mematikan internet berulang kali), tetapi mudah diuji dengan unit test karena repository dan controller tidak bergantung pada widget.

Ide utama: ganti Supabase dengan "server palsu"

Kita membuat FakeRemoteDataSource yang implements NoteRemoteDataSource. Class ini menyimpan data di List biasa dan bisa diperintah untuk melempar error (misalnya SocketException) agar seolah-olah offline. Hive asli tetap dipakai, tetapi diarahkan ke folder sementara dengan Hive.init(path).

Karena fake ini dipakai oleh tiga file test, kita taruh di satu file bantu. File di folder test/ yang namanya tidak berakhiran _test.dart tidak dijalankan sebagai test, jadi aman dipakai untuk kode bantu.

import 'package:catatan_kuliah/data/note_remote_data_source.dart';
import 'package:catatan_kuliah/models/note.dart';

/// Membuat Note contoh untuk test. [hari] menentukan tanggal (urutan).
Note buatNote(
  String id, {
  String title = 'Judul',
  String category = 'Kuliah',
  int hari = 1,
}) {
  final waktu = DateTime.utc(2026, 10, hari);
  return Note(
    id: id,
    userId: 'user-1',
    title: title,
    content: 'Isi $title',
    category: category,
    createdAt: waktu,
    updatedAt: waktu,
  );
}

/// Pengganti Supabase untuk test. `implements` membuat kita wajib
/// menulis ulang semua method, sehingga tidak ada request jaringan sungguhan.
class FakeRemoteDataSource implements NoteRemoteDataSource {
  List<Note> serverNotes = [];
  Object? errorToThrow; // jika diisi, setiap method melempar error ini

  void _maybeThrow() {
    final error = errorToThrow;
    if (error != null) throw error;
  }

  @override
  Future<List<Note>> fetchNotes() async {
    _maybeThrow();
    return serverNotes;
  }

  @override
  Future<Note> createNote({
    required String title,
    required String content,
    required String category,
  }) async {
    _maybeThrow();
    final note = buatNote('baru', title: title, category: category);
    serverNotes.add(note);
    return note;
  }

  @override
  Future<Note> updateNote(Note note) async {
    _maybeThrow();
    return note;
  }

  @override
  Future<void> deleteNote(String id) async {
    _maybeThrow();
    serverNotes.removeWhere((n) => n.id == id);
  }
}

import 'dart:io';

import 'package:catatan_kuliah/data/note_local_data_source.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:hive_ce/hive_ce.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'helpers/fakes.dart';

void main() {
  late Directory tempDir;
  late NoteLocalDataSource local;
  late FakeRemoteDataSource remote;
  late NoteRepository repository;

  setUp(() async {
    tempDir = await Directory.systemTemp.createTemp('repo_test_');
    Hive.init(tempDir.path);
    local = await NoteLocalDataSource.open();
    remote = FakeRemoteDataSource();
    repository = NoteRepository(remote: remote, local: local);
  });

  tearDown(() async {
    await Hive.deleteFromDisk();
    await tempDir.delete(recursive: true);
  });

  test('online: data server dikembalikan dan disimpan ke cache', () async {
    remote.serverNotes = [buatNote('1'), buatNote('2')];

    final result = await repository.getNotes();

    expect(result.fromCache, isFalse);
    expect(result.notes, hasLength(2));
    expect(local.getNotes(), hasLength(2));
  });

  test('offline: jika jaringan gagal, data diambil dari cache', () async {
    await local.saveNotes([buatNote('cache-1', title: 'Dari Hive')]);
    remote.errorToThrow = const SocketException('Tidak ada internet');

    final result = await repository.getNotes();

    expect(result.fromCache, isTrue);
    expect(result.notes.single.title, 'Dari Hive');
  });

  test('error dari server (PostgrestException) tidak disembunyikan', () async {
    remote.errorToThrow = const PostgrestException(
      message: 'permission denied',
      code: '42501',
    );

    expect(repository.getNotes(), throwsA(isA<PostgrestException>()));
  });

  test('addNote dan deleteNote ikut memperbarui cache', () async {
    final note = await repository.addNote(
      title: 'Basis Data',
      content: 'Normalisasi',
      category: 'Kuliah',
    );
    expect(local.getNotes().single.id, note.id);

    await repository.deleteNote(note.id);
    expect(local.getNotes(), isEmpty);
  });

  test('deleteNote gagal: cache tidak berubah', () async {
    await local.saveNotes([buatNote('1')]);
    remote.errorToThrow = const SocketException('offline');

    await expectLater(
      repository.deleteNote('1'),
      throwsA(isA<SocketException>()),
    );
    expect(local.getNotes(), hasLength(1));
  });
}

File: test/notes_controller_test.dart

Inilah keuntungan controller yang tidak menyentuh UI: NotesController bisa diuji seperti class Dart biasa. Kita hanya perlu mengaktifkan mode test GetX dan membersihkan semua instance setelah setiap test.

📄 test/notes_controller_test.dart

import 'dart:io';

import 'package:catatan_kuliah/controllers/notes_controller.dart';
import 'package:catatan_kuliah/data/note_local_data_source.dart';
import 'package:catatan_kuliah/data/note_repository.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';
import 'package:hive_ce/hive_ce.dart';

import 'helpers/fakes.dart';

void main() {
  late Directory tempDir;
  late FakeRemoteDataSource remote;
  late NotesController controller;

  setUp(() async {
    Get.testMode = true;
    tempDir = await Directory.systemTemp.createTemp('controller_test_');
    Hive.init(tempDir.path);
    remote = FakeRemoteDataSource()
      ..serverNotes = [
        buatNote('1', title: 'Basis Data', hari: 3),
        buatNote('2', title: 'Tugas Mobile', category: 'Tugas', hari: 2),
        buatNote('3', title: 'Kisi-kisi UTS', category: 'Ujian', hari: 1),
      ];
    final repository = NoteRepository(
      remote: remote,
      local: await NoteLocalDataSource.open(),
    );
    controller = Get.put(NotesController(repository));
  });

  tearDown(() async {
    Get.reset(); // hapus semua controller agar setiap test terisolasi
    await Hive.deleteFromDisk();
    await tempDir.delete(recursive: true);
  });

  test('loadNotes mengisi daftar dan mematikan loading', () async {
    final future = controller.loadNotes();
    expect(controller.isLoading, isTrue);

    await future;

    expect(controller.isLoading, isFalse);
    expect(controller.isOffline, isFalse);
    expect(controller.visibleNotes, hasLength(3));
  });

  test('loadNotes offline: data cache dipakai dan isOffline true', () async {
    await controller.loadNotes(); // online dulu, cache terisi
    remote.errorToThrow = const SocketException('offline');

    await controller.loadNotes();

    expect(controller.isOffline, isTrue);
    expect(controller.visibleNotes, hasLength(3));
  });

  test('setQuery dan setCategoryFilter menyaring visibleNotes', () async {
    await controller.loadNotes();

    controller.setQuery('mobile');
    expect(controller.visibleNotes.single.id, '2');

    controller.setQuery('');
    controller.setCategoryFilter('Ujian');
    expect(controller.visibleNotes.single.id, '3');

    controller.setCategoryFilter(null);
    expect(controller.visibleNotes, hasLength(3));
  });

  test('deleteNote gagal: catatan dikembalikan ke posisi semula', () async {
    await controller.loadNotes();
    final note = controller.findById('2')!;
    remote.errorToThrow = const SocketException('offline');

    final future = controller.deleteNote(note);
    // Optimistic: sebelum server menjawab, catatan sudah hilang.
    expect(controller.findById('2'), isNull);

    final error = await future;

    expect(error, isNotNull);
    expect(controller.visibleNotes.map((n) => n.id), ['1', '2', '3']);
  });
}

Penjelasan

  • setUp/tearDown dijalankan sebelum/sesudah setiap test: buat folder sementara, Hive.init, buka box, lalu hapus semuanya. Setiap test mulai dari kondisi bersih.
  • Hive.init(tempDir.path) dipakai, bukan Hive.initFlutter(), karena di unit test tidak ada plugin path_provider.
  • Test "offline" adalah inti modul ini: cache diisi, server dibuat gagal dengan SocketException, lalu kita pastikan fromCache bernilai true dan data cache yang dikembalikan.
  • Test PostgrestException memastikan error RLS tidak disembunyikan oleh cache.
  • expectLater(future, throwsA(...)) menunggu Future selesai lalu memeriksa exception-nya.
  • Get.testMode = true memberi tahu GetX bahwa kode berjalan di lingkungan test (tanpa GetMaterialApp), sehingga fitur yang butuh navigator tidak membuat test gagal.
  • Get.put(NotesController(repository)) mendaftarkan controller seperti di main(), tetapi dengan repository yang memakai fake data source. Get.reset() di tearDown menghapus semua instance agar setiap test mulai dari controller baru.
  • Membaca getter langsung: controller.isLoading, controller.visibleNotes, dan seterusnya bisa dibaca tanpa Obx. Test loadNotes bahkan memeriksa isLoading bernilai true sebelum await, lalu false sesudahnya.
  • Test optimistic delete memastikan dua hal: catatan langsung hilang sebelum server menjawab, lalu kembali ke posisi semula (urutan ['1', '2', '3']) ketika server gagal.
