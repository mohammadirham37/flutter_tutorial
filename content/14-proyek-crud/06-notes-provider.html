NotesProvider memegang semua state halaman catatan: daftar catatan, status loading, mode offline, pesan error, kata kunci pencarian, dan filter kategori.

import 'dart:async';

import 'package:flutter/foundation.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import '../data/note_repository.dart';
import '../models/note.dart';

class NotesProvider extends ChangeNotifier {
  NotesProvider(this._repository);

  final NoteRepository _repository;

  List<Note> _notes = [];
  bool _isLoading = false;
  bool _isOffline = false;
  String? _errorMessage;
  String _query = '';
  String? _categoryFilter; // null = semua kategori

  bool get isLoading => _isLoading;
  bool get isOffline => _isOffline;
  String? get errorMessage => _errorMessage;
  String get query => _query;
  String? get categoryFilter => _categoryFilter;
  bool get hasNotes => _notes.isNotEmpty;

  /// Daftar yang ditampilkan di layar setelah difilter pencarian & kategori.
  List<Note> get visibleNotes {
    final q = _query.toLowerCase();
    return _notes.where((note) {
      final cocokKategori =
          _categoryFilter == null || note.category == _categoryFilter;
      final cocokCari =
          q.isEmpty ||
          note.title.toLowerCase().contains(q) ||
          note.content.toLowerCase().contains(q);
      return cocokKategori && cocokCari;
    }).toList();
  }

  Note? findById(String id) {
    for (final note in _notes) {
      if (note.id == id) return note;
    }
    return null;
  }

  /// Memuat catatan (dipanggil saat HomeScreen dibuka & saat pull-to-refresh).
  Future<void> loadNotes() async {
    _isLoading = true;
    _errorMessage = null;
    notifyListeners();

    try {
      final result = await _repository.getNotes();
      _notes = result.notes;
      _isOffline = result.fromCache;
    } catch (e) {
      _errorMessage = _friendlyError(e);
    } finally {
      _isLoading = false;
      notifyListeners();
    }
  }

  /// Mengembalikan null jika berhasil, atau pesan error jika gagal.
  Future<String?> addNote({
    required String title,
    required String content,
    required String category,
  }) async {
    try {
      final note = await _repository.addNote(
        title: title,
        content: content,
        category: category,
      );
      _notes.insert(0, note);
      _isOffline = false;
      notifyListeners();
      return null;
    } catch (e) {
      return _friendlyError(e);
    }
  }

  Future<String?> updateNote(Note note) async {
    try {
      final updated = await _repository.updateNote(note);
      _notes.removeWhere((n) => n.id == updated.id);
      _notes.insert(0, updated); // yang baru diubah naik ke atas
      _isOffline = false;
      notifyListeners();
      return null;
    } catch (e) {
      return _friendlyError(e);
    }
  }

  /// Optimistic delete: hapus dari layar dulu, baru kirim ke server.
  /// Jika server gagal, catatan dikembalikan ke posisi semula (rollback).
  Future<String?> deleteNote(Note note) async {
    final index = _notes.indexWhere((n) => n.id == note.id);
    if (index == -1) return null;

    _notes.removeAt(index);
    notifyListeners();

    try {
      await _repository.deleteNote(note.id);
      return null;
    } catch (e) {
      _notes.insert(index, note);
      notifyListeners();
      return _friendlyError(e);
    }
  }

  void setQuery(String value) {
    _query = value;
    notifyListeners();
  }

  void setCategoryFilter(String? category) {
    _categoryFilter = category;
    notifyListeners();
  }

  /// Dipanggil saat logout: kosongkan state dan cache Hive.
  Future<void> clear() async {
    _notes = [];
    _query = '';
    _categoryFilter = null;
    _errorMessage = null;
    _isOffline = false;
    await _repository.clearCache();
    notifyListeners();
  }

  String _friendlyError(Object e) {
    if (e is PostgrestException) {
      if (e.code == '42501') {
        return 'Akses ditolak oleh Row Level Security. Periksa policy tabel notes.';
      }
      if (e.code == '42P01' || e.code == 'PGRST205') {
        return 'Tabel notes belum dibuat. Jalankan SQL di Supabase.';
      }
      return 'Kesalahan database: ${e.message}';
    }
    if (e is TimeoutException) {
      return 'Server terlalu lama merespons. Coba lagi.';
    }
    return 'Tidak dapat terhubung ke server. Periksa koneksi internet.';
  }
}

State yang dikelola

FieldKegunaan di UI
_notesSemua catatan milik user (sumber data)
visibleNotesGetter: _notes setelah difilter pencarian + kategori. Inilah yang ditampilkan ListView
isLoadingSpinner saat pertama kali memuat
isOfflineMenampilkan OfflineBanner
errorMessageTampilan error + tombol "Coba lagi"
query, categoryFilterIsi kolom pencarian dan chip yang terpilih

Pencarian dan filter tanpa query ulang

visibleNotes dihitung dari data di memori. Mengetik di kolom pencarian tidak mengirim request ke server, sehingga hasilnya instan dan tetap berfungsi saat offline. Untuk ratusan catatan cara ini lebih dari cukup. Untuk data sangat besar, gunakan .ilike() di server (Modul 12).

Optimistic delete dengan rollback

user geser catatan ──▶ konfirmasi "Hapus"
                         │
                         ▼
   1. simpan index, hapus dari _notes, notifyListeners()   ← UI langsung hilang (terasa cepat)
                         │
   2. await repository.deleteNote(id)
            │                         │
         sukses                     gagal (offline / RLS)
            │                         │
         selesai          3. _notes.insert(index, note)   ← kembalikan ke posisi semula
                             notifyListeners()            ← catatan muncul lagi
                             return pesan error           ← SnackBar

Disebut optimistic karena kita "optimis" server akan berhasil, sehingga UI diperbarui duluan. Keuntungannya, aplikasi terasa instan. Konsekuensinya, kita wajib menyediakan rollback jika ternyata gagal.

Untuk tambah dan edit kita memakai cara sebaliknya (pessimistic): tunggu server, baru perbarui list. Alasannya, id dan tanggal catatan baru berasal dari database.

Kontrak nilai kembali: Future<String?>

addNote, updateNote, dan deleteNote mengembalikan null jika sukses atau String pesan error jika gagal. UI cukup menulis:

final error = await provider.addNote(
  title: 'Basis Data',
  content: 'Normalisasi sampai 3NF',
  category: 'Kuliah',
);
if (error == null) {
  // sukses
} else {
  // tampilkan error di SnackBar
}

Menerjemahkan error

_friendlyError mengubah exception menjadi kalimat untuk user: 42501 (RLS menolak), 42P01/PGRST205 (tabel belum dibuat), TimeoutException, dan selain itu dianggap masalah koneksi.

⚠️ Kesalahan umum

  • Mengembalikan _notes langsung lewat getter: UI bisa mengubah list tanpa notifyListeners. Di sini UI hanya menerima visibleNotes, yaitu list baru hasil where().toList().
  • Lupa notifyListeners() setelah rollback: catatan "hilang" di layar padahal masih ada di server.
  • Memanggil loadNotes() langsung di initState: notifyListeners terpanggil saat build pertama dan memicu error setState() or markNeedsBuild() called during build. Solusinya ada di HomeScreen (section 7).
