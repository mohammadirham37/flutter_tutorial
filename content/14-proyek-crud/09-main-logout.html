📄 lib/main.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'config/env.dart';
import 'controllers/auth_controller.dart';
import 'controllers/notes_controller.dart';
import 'data/note_local_data_source.dart';
import 'data/note_remote_data_source.dart';
import 'data/note_repository.dart';
import 'services/auth_service.dart';
import 'views/auth_gate.dart';

Future<void> main() async {
  // Wajib sebelum memanggil kode async/plugin sebelum runApp.
  WidgetsFlutterBinding.ensureInitialized();

  if (!Env.isConfigured) {
    runApp(const ConfigErrorApp());
    return;
  }

  // 1. Hive (cache lokal)
  await Hive.initFlutter();
  final localDataSource = await NoteLocalDataSource.open();

  // 2. Supabase (backend)
  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabasePublishableKey,
  );
  final client = Supabase.instance.client;

  // 3. Rakit lapisan data: Service/DataSource -> Repository
  final authService = AuthService(client);
  final repository = NoteRepository(
    remote: NoteRemoteDataSource(client),
    local: localDataSource,
  );

  // 4. Daftarkan controller global. permanent: true agar tidak pernah
  //    dihapus otomatis oleh GetX selama aplikasi berjalan.
  Get.put(AuthController(authService), permanent: true);
  Get.put(NotesController(repository), permanent: true);

  runApp(const CatatanKuliahApp());
}

class CatatanKuliahApp extends StatelessWidget {
  const CatatanKuliahApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'Catatan Kuliah',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
      ),
      home: const AuthGate(),
    );
  }
}

Urutan perakitan (dependency graph)

Hive.initFlutter()          Supabase.initialize()
        │                           │
NoteLocalDataSource.open()   SupabaseClient ─────────────┐
        │                           │                    │
        └──────────┬────────────────┘                    │
                   ▼                                     ▼
            NoteRepository                         AuthService
                   │                                     │
           NotesController                      AuthController
                   └─── Get.put(..., permanent: true) ───┘
                                      │
                  runApp(CatatanKuliahApp) → GetMaterialApp → AuthGate
  • Objek dibuat sekali di main() lalu disuntikkan lewat constructor. Tidak ada class yang memanggil Supabase.instance atau Hive.openBox sendiri.
  • Get.put(..., permanent: true) (Modul 08) mendaftarkan controller ke "gudang" dependency GetX sebelum runApp. Setelah itu View mana pun bisa mengambilnya dengan Get.find atau GetView. permanent: true mencegah GetX menghapus controller saat halaman ditutup, karena kedua controller ini dipakai selama aplikasi hidup.
  • GetMaterialApp menggantikan MaterialApp agar Get.to, Get.back, dan fitur GetX lain bisa bekerja. Parameternya sama (title, theme, home, ...).
  • Dibanding versi Modul 13, yang bertambah hanya bagian Hive, repository, dan NotesController. Bagian auth tidak berubah sama sekali, dan itulah manfaat arsitektur berlapis.

Alur logout yang aman

ikon logout ─▶ dialog "Keluar?" ─▶ NotesController.clear()
                                       ├─ _notes.clear(), filter direset
                                       └─ repository.clearCache() → Hive box dikosongkan
                                   ─▶ AuthController.signOut()
                                       └─ onAuthStateChange: signedOut
                                           └─ _session.value = null
                                               └─ Obx di AuthGate → LoginView

Urutannya penting: cache dibersihkan sebelum sesi dihapus. Jika urutannya dibalik, AuthGate langsung membuang HomeView, sedangkan NotesController (yang permanent, jadi tidak ikut dihapus) masih berisi catatan user lama sampai user berikutnya login.

Uji mode offline

  1. Login dan pastikan catatan tampil (data sudah tersimpan di cache).
  2. Aktifkan mode pesawat di emulator.
  3. Tarik ke bawah (pull-to-refresh). Setelah request gagal, banner "Mode offline" muncul dan catatan tetap tampil dari Hive.
  4. Coba tambah catatan. Muncul SnackBar error koneksi dan list tidak berubah.
  5. Coba hapus catatan (geser). Catatan hilang sebentar lalu muncul kembali (rollback) dengan SnackBar.
  6. Matikan mode pesawat dan tekan Coba lagi di banner. Banner hilang.
