Kita memakai Hive (Modul 11) sebagai cache: salinan terakhir catatan dari server yang disimpan di HP. Jika server tidak bisa dihubungi, aplikasi tetap bisa menampilkan catatan dari cache.

Kenapa menyimpan sebagai Map, bukan TypeAdapter?

Di Modul 11 Anda belajar dua cara: menyimpan Map biasa atau membuat TypeAdapter. Untuk cache, Map lebih sederhana: model Note sudah punya toJson()/fromJson(), tidak perlu registerAdapter, tidak ada typeId yang harus dijaga, dan tidak perlu code generation.

Box<Map> "notes_cache"
┌──────────────────────────────────────┬─────────────────────────────────────────┐
│ key (id catatan)                     │ value (Map hasil note.toJson())         │
├──────────────────────────────────────┼─────────────────────────────────────────┤
│ "3f6c2a9e-8b1d-4c7a-9e21-..."        │ {id: ..., title: "Basis Data", ...}     │
│ "a71d0c44-52be-4f0e-8d3a-..."        │ {id: ..., title: "Tugas Mobile", ...}   │
└──────────────────────────────────────┴─────────────────────────────────────────┘

Memakai id catatan sebagai key membuat update dan delete satu catatan menjadi operasi langsung (put(id)/delete(id)), tanpa perlu mencari indeks.

File: lib/data/note_local_data_source.dart

📄 lib/data/note_local_data_source.dart

import 'package:hive_ce/hive_ce.dart';

import '../models/note.dart';

/// Cache catatan di Hive. Setiap catatan disimpan sebagai Map
/// dengan key = id catatan, sehingga tidak perlu TypeAdapter/codegen.
class NoteLocalDataSource {
  NoteLocalDataSource(this._box);

  static const String boxName = 'notes_cache';

  final Box<Map> _box;

  /// Membuka box. Panggil setelah Hive.initFlutter() (atau Hive.init()).
  static Future<NoteLocalDataSource> open() async {
    final box = await Hive.openBox<Map>(boxName);
    return NoteLocalDataSource(box);
  }

  /// Semua catatan di cache, urut dari yang terakhir diubah.
  List<Note> getNotes() {
    final notes = _box.values.map(Note.fromJson).toList();
    notes.sort((a, b) => b.updatedAt.compareTo(a.updatedAt));
    return notes;
  }

  /// Mengganti seluruh isi cache dengan data terbaru dari server.
  Future<void> saveNotes(List<Note> notes) async {
    await _box.clear();
    await _box.putAll({for (final note in notes) note.id: note.toJson()});
  }

  Future<void> saveNote(Note note) => _box.put(note.id, note.toJson());

  Future<void> deleteNote(String id) => _box.delete(id);

  /// Dipanggil saat logout agar data user lain tidak tertinggal.
  Future<void> clear() => _box.clear();
}

Penjelasan

  • import 'package:hive_ce/hive_ce.dart': file ini cukup memakai Hive inti, tanpa Flutter. Karena itu ia bisa diuji dengan Hive.init(folderSementara) di unit test (section 10).
  • static Future<NoteLocalDataSource> open(): membuka box bersifat async, sedangkan constructor tidak boleh async. Solusinya adalah factory method statis yang membuka box lalu membuat objek.
  • getNotes() bersifat sinkron karena Hive membaca dari memori setelah box dibuka. Hasilnya diurutkan updatedAt terbaru, sama dengan urutan dari server.
  • saveNotes() mengosongkan box lalu putAll. Catatan yang sudah dihapus di server (misalnya dari HP lain) ikut hilang dari cache.
  • clear() dipanggil saat logout. Tanpa ini, user B yang login di HP yang sama bisa sempat melihat catatan user A ketika offline.

Inisialisasi di main()

Box harus dibuka sebelum dipakai. Potongan ini akan menjadi bagian dari main.dart final di section 9:

await Hive.initFlutter();                 // folder penyimpanan di HP
final localDataSource = await NoteLocalDataSource.open(); // buka box
