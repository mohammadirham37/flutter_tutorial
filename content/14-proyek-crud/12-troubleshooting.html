Ringkasan Modul 14

  • Tabel notes dilindungi empat policy RLS berbasis auth.uid(), dengan user_id default auth.uid() dan trigger updated_at.
  • Lapisan data: Remote (Supabase CRUD), Local (Hive Map dengan key id), dan Repository (network first, cache fallback, PostgrestException tidak disembunyikan).
  • NotesProvider: loading/error/offline, pencarian dan filter di memori, optimistic delete dengan rollback.
  • UI: RefreshIndicator, empty/loading/error state, Dismissible + konfirmasi, satu form untuk tambah & edit, detail reaktif dengan context.select.
  • Logout membersihkan state dan cache sebelum sesi dihapus.
  • Logika offline diuji dengan unit test memakai fake data source dan Hive di folder sementara.
