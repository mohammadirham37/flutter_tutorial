Dua halaman baru: login dan register. Keduanya GetView<AuthController> yang tipis. View hanya menampilkan field dan meneruskan tombol ke controller, persis seperti MahasiswaFormView di Modul 11B.

1. LoginView

Buat file lib/views/login_view.dart:

📄 lib/views/login_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/auth_controller.dart';

/// VIEW: halaman login.
class LoginView extends GetView<AuthController> {
  const LoginView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: Form(
          key: controller.loginFormKey,
          autovalidateMode: AutovalidateMode.onUserInteraction,
          child: ListView(
            padding: const EdgeInsets.all(24),
            children: [
              const SizedBox(height: 40),
              const Icon(Icons.school, size: 72, color: Colors.indigo),
              const SizedBox(height: 12),
              Text(
                'CRUD Mahasiswa',
                textAlign: TextAlign.center,
                style: Theme.of(context).textTheme.headlineSmall,
              ),
              const Text(
                'Masuk untuk mengelola data',
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 32),
              TextFormField(
                controller: controller.emailC,
                keyboardType: TextInputType.emailAddress,
                validator: controller.validateEmail,
                decoration: const InputDecoration(
                  labelText: 'Email',
                  prefixIcon: Icon(Icons.email),
                  border: OutlineInputBorder(),
                ),
              ),
              const SizedBox(height: 16),
              Obx(
                () => TextFormField(
                  controller: controller.passwordC,
                  obscureText: controller.hidePassword.value,
                  validator: controller.validatePassword,
                  decoration: InputDecoration(
                    labelText: 'Password',
                    prefixIcon: const Icon(Icons.lock),
                    border: const OutlineInputBorder(),
                    suffixIcon: IconButton(
                      icon: Icon(
                        controller.hidePassword.value
                            ? Icons.visibility
                            : Icons.visibility_off,
                      ),
                      onPressed: controller.hidePassword.toggle,
                    ),
                  ),
                ),
              ),
              const SizedBox(height: 24),
              Obx(
                () => FilledButton(
                  // null = tombol nonaktif selama proses login
                  onPressed: controller.isLoading.value
                      ? null
                      : controller.login,
                  style: FilledButton.styleFrom(
                    padding: const EdgeInsets.symmetric(vertical: 16),
                  ),
                  child: controller.isLoading.value
                      ? const SizedBox(
                          height: 20,
                          width: 20,
                          child: CircularProgressIndicator(strokeWidth: 2),
                        )
                      : const Text('Masuk'),
                ),
              ),
              const SizedBox(height: 8),
              TextButton(
                onPressed: controller.openRegister,
                child: const Text('Belum punya akun? Daftar'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
Tombol Masuk ditekan dengan form kosong
Akun belum terdaftar: Supabase menolak

Penjelasan

  • Form(key: controller.loginFormKey): memakai key milik controller, sehingga login() bisa memanggil validate().
  • Password dengan ikon mata: obscureText membaca hidePassword.value di dalam Obx. Ikon memanggil controller.hidePassword.toggle, method bawaan RxBool yang membalik nilai true/false.
  • Tombol loading: onPressed diisi null saat isLoading bernilai true. Di Flutter, tombol dengan onPressed: null otomatis nonaktif (abu-abu). Isi tombol juga berganti menjadi CircularProgressIndicator kecil.
  • Dua Obx kecil: hanya field password dan tombol yang dibungkus Obx, karena hanya keduanya yang berubah. Bagian lain tidak ikut dibangun ulang.

2. RegisterView

Buat file lib/views/register_view.dart:

📄 lib/views/register_view.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/auth_controller.dart';

/// VIEW: halaman daftar akun baru.
class RegisterView extends GetView<AuthController> {
  const RegisterView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Daftar Akun')),
      body: Form(
        key: controller.registerFormKey,
        autovalidateMode: AutovalidateMode.onUserInteraction,
        child: ListView(
          padding: const EdgeInsets.all(24),
          children: [
            TextFormField(
              controller: controller.regEmailC,
              keyboardType: TextInputType.emailAddress,
              validator: controller.validateEmail,
              decoration: const InputDecoration(
                labelText: 'Email',
                prefixIcon: Icon(Icons.email),
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            Obx(
              () => TextFormField(
                controller: controller.regPasswordC,
                obscureText: controller.hidePassword.value,
                validator: controller.validatePassword,
                decoration: InputDecoration(
                  labelText: 'Password',
                  prefixIcon: const Icon(Icons.lock),
                  border: const OutlineInputBorder(),
                  suffixIcon: IconButton(
                    icon: Icon(
                      controller.hidePassword.value
                          ? Icons.visibility
                          : Icons.visibility_off,
                    ),
                    onPressed: controller.hidePassword.toggle,
                  ),
                ),
              ),
            ),
            const SizedBox(height: 16),
            Obx(
              () => TextFormField(
                controller: controller.regKonfirmasiC,
                obscureText: controller.hidePassword.value,
                validator: controller.validateKonfirmasi,
                decoration: const InputDecoration(
                  labelText: 'Ulangi Password',
                  prefixIcon: Icon(Icons.lock_outline),
                  border: OutlineInputBorder(),
                ),
              ),
            ),
            const SizedBox(height: 24),
            Obx(
              () => FilledButton(
                onPressed: controller.isLoading.value
                    ? null
                    : controller.register,
                style: FilledButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 16),
                ),
                child: controller.isLoading.value
                    ? const SizedBox(
                        height: 20,
                        width: 20,
                        child: CircularProgressIndicator(strokeWidth: 2),
                      )
                    : const Text('Daftar'),
              ),
            ),
          ],
        ),
      ),
    );
  }
}
Validasi form register kosong
Ulangi Password tidak sama
Register berhasil, langsung masuk
  • Strukturnya sama dengan LoginView, ditambah field Ulangi Password dengan validator validateKonfirmasi.
  • Ada AppBar sehingga muncul tombol kembali ke halaman login.
  • Ketiga field password berbagi satu state hidePassword, jadi menekan ikon mata menampilkan atau menyembunyikan keduanya sekaligus.

💡 Email untuk percobaan

Untuk praktikum, Anda bisa memakai alamat dengan domain buatan seperti budi@kampus.test (dipakai saat membuat screenshot modul ini), atau email Anda sendiri. Jika Supabase menolak suatu alamat, aplikasi menampilkan "Alamat email ditolak server.", jadi coba domain lain. Selama Confirm email dimatikan, tidak ada email yang benar-benar dikirim.
