Kita lanjutkan proyek crud_mahasiswa dari Modul 11B. Di section ini kita mengganti package Hive dengan Supabase, membuang file yang tidak dipakai lagi, dan menyimpan URL serta key Supabase dengan aman.

💡 Simpan dulu versi Hive

Sebelum mengubah apa pun, simpan hasil Modul 11B, misalnya dengan git commit -am "Versi Hive selesai" atau dengan menyalin folder proyek menjadi crud_mahasiswa_hive. Dengan begitu Anda bisa membandingkan kedua versi.

1. Ganti package

Buka terminal di folder proyek crud_mahasiswa:

flutter pub remove hive_ce hive_ce_flutter
flutter pub add supabase_flutter

Package get sudah terpasang sejak Modul 11B. Jika Anda memulai dari proyek kosong, jalankan flutter pub add get supabase_flutter.

PackageKegunaan di proyek ini
getState reaktif, dependency injection, named route, middleware, snackbar, dan dialog
supabase_flutterKoneksi ke Supabase: Auth (register, login, logout, menyimpan sesi) dan database (select, insert, update, delete)

Bagian dependencies di pubspec.yaml kira-kira menjadi seperti ini (nomor versi di laptop Anda boleh lebih baru):

📄 pubspec.yaml (bagian dependencies)

dependencies:
  flutter:
    sdk: flutter

  cupertino_icons: ^1.0.8
  get: ^4.7.3
  supabase_flutter: ^2.18.3

2. Hapus file Hive dan siapkan folder baru

# macOS / Linux / Git Bash
rm lib/models/mahasiswa_adapter.dart lib/services/hive_service.dart
rm -f test/hive_service_test.dart test/crud_flow_test.dart
mkdir -p lib/config lib/middlewares supabase test/helpers

# Windows PowerShell
Remove-Item lib/models/mahasiswa_adapter.dart, lib/services/hive_service.dart
Remove-Item test/hive_service_test.dart, test/crud_flow_test.dart -ErrorAction SilentlyContinue
mkdir lib/config, lib/middlewares, supabase, test/helpers

Setelah langkah ini editor akan menampilkan banyak garis merah, misalnya di main.dart dan mahasiswa_controller.dart, karena keduanya masih mengimpor file Hive yang baru dihapus. Ini normal. Semua error hilang setelah file-file diperbarui di section berikutnya.

3. Simpan URL dan key di env.json

URL dan key Supabase tidak ditulis langsung di kode Dart, supaya tidak ikut ter-upload ke GitHub. Buat file env.json di root proyek (sejajar dengan pubspec.yaml) dan isi dengan nilai dari section 2:

📄 env.json

{
  "SUPABASE_URL": "https://YOUR-PROJECT-REF.supabase.co",
  "SUPABASE_PUBLISHABLE_KEY": "sb_publishable_YOUR_KEY"
}

Tambahkan baris berikut di bagian paling bawah .gitignore:

📄 .gitignore (tambahan)

# Kunci Supabase
env.json

4. Kelas Env untuk membaca konfigurasi

📄 lib/config/env.dart

/// Konfigurasi Supabase yang dibaca saat build lewat --dart-define.
///
/// Jalankan aplikasi dengan:
///   flutter run --dart-define-from-file=env.json
class Env {
  static const String supabaseUrl = String.fromEnvironment('SUPABASE_URL');
  static const String supabaseKey = String.fromEnvironment(
    'SUPABASE_PUBLISHABLE_KEY',
  );

  /// true jika kedua nilai sudah diisi.
  static bool get isConfigured =>
      supabaseUrl.isNotEmpty && supabaseKey.isNotEmpty;
}
  • String.fromEnvironment('SUPABASE_URL') membaca nilai yang dikirim saat build lewat --dart-define-from-file=env.json. Nilainya ditanam ke aplikasi saat kompilasi, bukan dibaca dari file saat aplikasi berjalan.
  • Jika aplikasi dijalankan tanpa flag tersebut, nilainya string kosong. isConfigured dipakai di main.dart untuk menampilkan pesan yang jelas, bukan error yang membingungkan.

5. Izin internet (Android)

Mode debug otomatis punya izin internet, tetapi APK rilis tidak. Buka android/app/src/main/AndroidManifest.xml dan tambahkan baris ini tepat di atas tag <application:

<uses-permission android:name="android.permission.INTERNET"/>

⚠️ Lupa izin internet = aplikasi rilis selalu "Tidak dapat terhubung"

Kesalahan ini sering baru ketahuan setelah APK dibagikan ke teman, karena saat flutter run semuanya lancar. Tambahkan izinnya sekarang.
