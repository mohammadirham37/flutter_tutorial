Model Mahasiswa tetap menjadi bentuk data di seluruh aplikasi. Supabase mengirim dan menerima data dalam bentuk JSON (di Dart menjadi Map<String, dynamic>), jadi model perlu bisa diubah dari dan ke Map. Pengubah biner (TypeAdapter) dari Modul 11B tidak dipakai lagi.

Ganti seluruh isi lib/models/mahasiswa_model.dart:

📄 lib/models/mahasiswa_model.dart

/// MODEL: representasi data Mahasiswa.
/// Class ini murni berisi data (tidak tahu soal UI maupun GetX).
class Mahasiswa {
  /// null  -> data baru, belum tersimpan di Supabase.
  /// berisi -> uuid yang dibuat otomatis oleh Postgres.
  final String? id;
  final String nim;
  final String nama;
  final String prodi;
  final int semester;

  Mahasiswa({
    this.id,
    required this.nim,
    required this.nama,
    required this.prodi,
    required this.semester,
  });

  /// Map dari Supabase (satu baris tabel) -> objek Mahasiswa.
  factory Mahasiswa.fromJson(Map<String, dynamic> json) {
    return Mahasiswa(
      id: json['id'] as String,
      nim: json['nim'] as String,
      nama: json['nama'] as String,
      prodi: json['prodi'] as String,
      semester: json['semester'] as int,
    );
  }

  /// Objek Mahasiswa -> Map untuk insert / update.
  /// id dan user_id TIDAK dikirim: keduanya diisi otomatis oleh database.
  Map<String, dynamic> toJson() {
    return {'nim': nim, 'nama': nama, 'prodi': prodi, 'semester': semester};
  }

  /// Membuat salinan objek dengan sebagian field yang diubah.
  Mahasiswa copyWith({
    String? nim,
    String? nama,
    String? prodi,
    int? semester,
  }) {
    return Mahasiswa(
      id: id,
      nim: nim ?? this.nim,
      nama: nama ?? this.nama,
      prodi: prodi ?? this.prodi,
      semester: semester ?? this.semester,
    );
  }
}

Perubahan 1: id menjadi nullable (String?)

Di versi Hive, id dibuat oleh aplikasi sebelum data disimpan. Sekarang id dibuat oleh database (gen_random_uuid()), sehingga objek yang baru diisi di form belum punya id:

KapanNilai id
Objek dibuat dari form (belum disimpan)null
Objek dibaca dari Supabase lewat fromJsonuuid, misalnya "3f2b9c1e-8d1a-4c55-..."

Karena itu di constructor ditulis this.id tanpa required.

Perubahan 2: fromJson (Map → objek)

Satu baris tabel yang dikirim Supabase berbentuk seperti ini:

{
  "id": "3f2b9c1e-8d1a-4c55-9a0e-6c1f0f8f2a10",
  "user_id": "9b7e...",
  "nim": "220101001",
  "nama": "Budi Santoso",
  "prodi": "Informatika",
  "semester": 5,
  "created_at": "2026-11-23T08:00:00+00:00"
}

fromJson mengambil kolom yang kita perlukan saja. Kolom user_id dan created_at diabaikan karena tidak ditampilkan. Tanda as String dan as int memberi tahu Dart tipe setiap nilai. Kolom semester bertipe int di Postgres, sehingga di JSON pun sudah berupa angka.

Kata kunci factory berarti constructor ini boleh menjalankan logika lalu mengembalikan objek. Cara memakainya: Mahasiswa.fromJson(map).

Perubahan 3: toJson (objek → Map)

Dipakai saat insert dan update. Hanya empat kolom yang dikirim. id dan user_id sengaja tidak dikirim:

  • id diisi database saat insert, dan tidak boleh diubah saat update.
  • user_id diisi otomatis oleh default auth.uid(). Jika aplikasi boleh mengirim user_id sendiri, policy with check tetap akan menolak nilai yang bukan milik user tersebut.

⚠️ Nama key harus sama persis dengan nama kolom

'nama' di toJson harus sama dengan kolom nama di tabel, termasuk huruf besar dan kecilnya. Jika Anda menulis 'Nama', Supabase menolak dengan error Could not find the 'Nama' column.

Coba jalankan: model tanpa Supabase

Model adalah kelas Dart biasa, jadi bisa dicoba tanpa internet dan tanpa env.json. Ganti seluruh isi lib/main.dart dengan:

📄 lib/main.dart (sementara)

// lib/main.dart (SEMENTARA) — mencoba model Mahasiswa tanpa Supabase.
// Jalankan: flutter run
import 'dart:convert';

import 'package:flutter/material.dart';

import 'models/mahasiswa_model.dart';

void main() => runApp(const CobaModelApp());

class CobaModelApp extends StatelessWidget {
  const CobaModelApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo, useMaterial3: true),
      home: const CobaModelPage(),
    );
  }
}

class CobaModelPage extends StatelessWidget {
  const CobaModelPage({super.key});

  @override
  Widget build(BuildContext context) {
    // 1. Pura-pura menerima satu baris dari Supabase
    final baris = <String, dynamic>{
      'id': '3f2b9c1e-8d1a-4c55-9a0e-6c1f0f8f2a10',
      'user_id': '9b7e0000-0000-0000-0000-000000000000',
      'nim': '220101001',
      'nama': 'Budi Santoso',
      'prodi': 'Informatika',
      'semester': 5,
      'created_at': '2026-11-23T08:00:00+00:00',
    };

    // 2. Map -> objek
    final budi = Mahasiswa.fromJson(baris);

    // 3. Objek -> Map (yang akan dikirim saat insert/update)
    final dikirim = budi.toJson();

    // 4. copyWith: naik semester tanpa mengubah objek asli
    final budiNaik = budi.copyWith(semester: budi.semester + 1);

    // 5. Objek baru dari form: id masih null
    final baru = Mahasiswa(
      nim: '220101002',
      nama: 'Siti Aminah',
      prodi: 'Sistem Informasi',
      semester: 3,
    );

    const encoder = JsonEncoder.withIndent('  ');

    return Scaffold(
      appBar: AppBar(title: const Text('Coba Model Mahasiswa')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          _Kartu(
            judul: 'fromJson',
            isi:
                'id: ${budi.id}\nnama: ${budi.nama}\n'
                'prodi: ${budi.prodi}\nsemester: ${budi.semester}',
          ),
          _Kartu(
            judul: 'toJson (tanpa id & user_id)',
            isi: encoder.convert(dikirim),
          ),
          _Kartu(
            judul: 'copyWith(semester: 6)',
            isi:
                'asli: semester ${budi.semester}\n'
                'salinan: semester ${budiNaik.semester}\n'
                'id tetap sama: ${budiNaik.id == budi.id}',
          ),
          _Kartu(
            judul: 'Objek baru dari form',
            isi: 'id: ${baru.id}\nnama: ${baru.nama}',
          ),
        ],
      ),
    );
  }
}

class _Kartu extends StatelessWidget {
  const _Kartu({required this.judul, required this.isi});

  final String judul;
  final String isi;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(judul, style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 8),
            Text(isi, style: const TextStyle(fontFamily: 'monospace')),
          ],
        ),
      ),
    );
  }
}
Hasil fromJson, toJson, copyWith, dan objek baru dari form
  • fromJson: Map yang meniru satu baris tabel (lengkap dengan user_id dan created_at) diubah menjadi objek. Kolom yang tidak dipakai diabaikan.
  • toJson: hanya berisi nim, nama, prodi, dan semester. id dan user_id tidak ikut, sesuai penjelasan di atas.
  • copyWith: menghasilkan objek baru dengan semester 6, sedangkan objek asli tetap semester 5. id ikut tersalin.
  • Objek baru dari form: id bernilai null karena belum pernah disimpan ke database.
  • JsonEncoder.withIndent(' ') dari dart:convert hanya dipakai agar Map tampil rapi berjajar.
