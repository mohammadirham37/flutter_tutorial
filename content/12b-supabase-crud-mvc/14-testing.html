Test di Modul 11B memakai Hive di folder sementara. Kali ini kita tidak bisa menguji dengan Supabase sungguhan setiap kali menjalankan flutter test, karena butuh internet, lambat, dan bisa mengotori data. Solusinya: buat service palsu (fake) yang menyimpan data di memori, lalu suntikkan ke aplikasi sebagai pengganti service asli.

Kenapa ini bisa dilakukan?

Karena sejak awal controller tidak membuat service sendiri, tetapi mengambilnya dari Get.find(), dan service menerima client Supabase lewat constructor. Saat test, kita cukup memanggil Get.put dengan objek palsu sebelum aplikasi dijalankan. Controller tidak tahu bedanya.

Aplikasi asli:  AuthController ──► AuthService      ──► Supabase Auth (internet)
Saat test:      AuthController ──► FakeAuthService  ──► variabel di memori

1. Service palsu

Buat file test/helpers/fakes.dart:

📄 test/helpers/fakes.dart

import 'dart:async';

import 'package:crud_mahasiswa/models/mahasiswa_model.dart';
import 'package:crud_mahasiswa/services/auth_service.dart';
import 'package:crud_mahasiswa/services/mahasiswa_service.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

/// AuthService palsu: tidak menghubungi Supabase sama sekali.
/// Hanya satu akun yang dianggap benar: budi@kampus.ac.id / rahasia123.
class FakeAuthService implements AuthService {
  FakeAuthService({bool sudahLogin = false}) {
    if (sudahLogin) _user = _buatUser('budi@kampus.ac.id');
  }

  final _events = StreamController<AuthState>.broadcast();
  User? _user;

  User _buatUser(String email) => User(
    id: 'user-1',
    appMetadata: const {},
    userMetadata: const {},
    aud: 'authenticated',
    email: email,
    createdAt: DateTime.now().toIso8601String(),
  );

  @override
  User? get currentUser => _user;

  @override
  Stream<AuthState> get authStateChanges => _events.stream;

  @override
  Future<AuthResponse> signIn({
    required String email,
    required String password,
  }) async {
    if (email != 'budi@kampus.ac.id' || password != 'rahasia123') {
      throw const AuthApiException(
        'Invalid login credentials',
        code: 'invalid_credentials',
        statusCode: '400',
      );
    }
    _user = _buatUser(email);
    final session = Session(
      accessToken: 'token',
      tokenType: 'bearer',
      user: _user!,
    );
    _events.add(AuthState(AuthChangeEvent.signedIn, session));
    return AuthResponse(session: session);
  }

  @override
  Future<AuthResponse> signUp({
    required String email,
    required String password,
  }) async {
    _user = _buatUser(email);
    final session = Session(
      accessToken: 'token',
      tokenType: 'bearer',
      user: _user!,
    );
    return AuthResponse(session: session);
  }

  @override
  Future<void> signOut() async {
    _user = null;
    _events.add(const AuthState(AuthChangeEvent.signedOut, null));
  }
}

/// MahasiswaService palsu: data disimpan di List biasa (memori).
class FakeMahasiswaService implements MahasiswaService {
  final List<Mahasiswa> _data = [];
  int _nextId = 1;

  @override
  Future<List<Mahasiswa>> getAll() async {
    final hasil = [..._data]..sort((a, b) => a.nama.compareTo(b.nama));
    return hasil;
  }

  @override
  Future<void> create(Mahasiswa mhs) async {
    if (_data.any((m) => m.nim == mhs.nim)) {
      // tiru error unique constraint dari Postgres
      throw const PostgrestException(message: 'duplicate', code: '23505');
    }
    _data.add(
      Mahasiswa(
        id: '${_nextId++}',
        nim: mhs.nim,
        nama: mhs.nama,
        prodi: mhs.prodi,
        semester: mhs.semester,
      ),
    );
  }

  @override
  Future<void> update(String id, Mahasiswa mhs) async {
    final i = _data.indexWhere((m) => m.id == id);
    _data[i] = Mahasiswa(
      id: id,
      nim: mhs.nim,
      nama: mhs.nama,
      prodi: mhs.prodi,
      semester: mhs.semester,
    );
  }

  @override
  Future<void> delete(String id) async {
    _data.removeWhere((m) => m.id == id);
  }
}
  • implements AuthService: kelas palsu berjanji punya semua method yang sama dengan AuthService, sehingga bisa dipakai di tempat mana pun yang meminta AuthService. Kata kunci @override menandai method yang menggantikan versi aslinya.
  • FakeAuthService hanya menerima satu akun: budi@kampus.ac.id / rahasia123. Untuk akun lain ia melempar AuthApiException dengan kode invalid_credentials, sama seperti Supabase asli.
  • StreamController.broadcast() dipakai untuk memancarkan event signedIn/signedOut seperti onAuthStateChange.
  • FakeMahasiswaService menyimpan data di List biasa dan meniru error 23505 jika NIM ganda.

2. Unit test model

📄 test/mahasiswa_model_test.dart

import 'package:crud_mahasiswa/models/mahasiswa_model.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  test('fromJson membaca satu baris dari Supabase', () {
    final mhs = Mahasiswa.fromJson({
      'id': 'a1b2',
      'user_id': 'u1',
      'nim': '220101001',
      'nama': 'Budi',
      'prodi': 'Informatika',
      'semester': 5,
      'created_at': '2026-11-23T08:00:00+00:00',
    });

    expect(mhs.id, 'a1b2');
    expect(mhs.nama, 'Budi');
    expect(mhs.semester, 5);
  });

  test('toJson tidak mengirim id dan user_id', () {
    final json = Mahasiswa(
      nim: '220101001',
      nama: 'Budi',
      prodi: 'Informatika',
      semester: 5,
    ).toJson();

    expect(json.containsKey('id'), isFalse);
    expect(json.containsKey('user_id'), isFalse);
    expect(json['nim'], '220101001');
  });
}

Test ini memastikan fromJson membaca kolom dengan benar, dan bahwa toJson tidak mengirim id maupun user_id.

3. Widget test alur login

📄 test/auth_flow_test.dart

import 'package:crud_mahasiswa/controllers/auth_controller.dart';
import 'package:crud_mahasiswa/main.dart';
import 'package:crud_mahasiswa/services/auth_service.dart';
import 'package:crud_mahasiswa/services/mahasiswa_service.dart';
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';

import 'helpers/fakes.dart';

void main() {
  setUp(() {
    // Sama seperti main(), tetapi memakai service palsu.
    final auth = FakeAuthService();
    Get.put<AuthService>(auth, permanent: true);
    Get.put<MahasiswaService>(FakeMahasiswaService(), permanent: true);
    Get.put(AuthController(auth), permanent: true);
  });

  tearDown(Get.reset);

  testWidgets('Belum login: diarahkan ke halaman login', (tester) async {
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();
    expect(find.text('Masuk'), findsOneWidget);
    expect(find.text('Data Mahasiswa'), findsNothing);
  });

  testWidgets('Validasi form login', (tester) async {
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();
    await tester.tap(find.text('Masuk'));
    await tester.pump();
    expect(find.text('Email wajib diisi'), findsOneWidget);
    expect(find.text('Password wajib diisi'), findsOneWidget);
  });

  testWidgets('Login salah, login benar, lalu logout', (tester) async {
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();

    // Password salah
    await tester.enterText(
      find.widgetWithText(TextFormField, 'Email'),
      'budi@kampus.ac.id',
    );
    await tester.enterText(
      find.widgetWithText(TextFormField, 'Password'),
      'salah123',
    );
    await tester.tap(find.text('Masuk'));
    await tester.pump(); // proses login (palsu) selesai
    await tester.pump(const Duration(seconds: 1)); // snackbar muncul
    expect(find.text('Email atau password salah.'), findsOneWidget);
    await tester.pumpAndSettle(const Duration(seconds: 4)); // tunggu hilang
    expect(find.text('Data Mahasiswa'), findsNothing);

    // Password benar
    await tester.enterText(
      find.widgetWithText(TextFormField, 'Password'),
      'rahasia123',
    );
    await tester.tap(find.text('Masuk'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Data Mahasiswa'), findsOneWidget);
    expect(find.text('Masuk sebagai budi@kampus.ac.id'), findsOneWidget);

    // Logout
    await tester.tap(find.byIcon(Icons.logout));
    await tester.pumpAndSettle();
    await tester.tap(find.widgetWithText(FilledButton, 'Keluar'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Masuk'), findsOneWidget);
    expect(find.text('Data Mahasiswa'), findsNothing);
  });
}
  • setUp meniru isi main(), tetapi memakai service palsu. Bagian ini dijalankan sebelum setiap test.
  • tearDown(Get.reset) menghapus semua yang didaftarkan ke GetX setelah setiap test, sehingga test berikutnya mulai dari keadaan bersih.
  • Test pertama membuktikan bahwa AuthMiddleware mengalihkan ke halaman login.
  • Test ketiga menguji alur lengkap: login salah, login benar, lalu logout. Perhatikan bahwa snackbar dicek setelah pump(Duration(seconds: 1)). Snackbar GetX hilang setelah 3 detik, jadi jika kita langsung menunggu dengan pumpAndSettle(Duration(seconds: 4)), snackbar sudah lenyap sebelum dicek.

4. Widget test alur CRUD

📄 test/crud_flow_test.dart

import 'package:crud_mahasiswa/controllers/auth_controller.dart';
import 'package:crud_mahasiswa/main.dart';
import 'package:crud_mahasiswa/services/auth_service.dart';
import 'package:crud_mahasiswa/services/mahasiswa_service.dart';
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:get/get.dart';

import 'helpers/fakes.dart';

void main() {
  setUp(() {
    // Anggap user sudah login sehingga aplikasi langsung ke halaman daftar.
    final auth = FakeAuthService(sudahLogin: true);
    Get.put<AuthService>(auth, permanent: true);
    Get.put<MahasiswaService>(FakeMahasiswaService(), permanent: true);
    Get.put(AuthController(auth), permanent: true);
  });

  tearDown(Get.reset);

  testWidgets('Alur CRUD lewat UI', (tester) async {
    await tester.pumpWidget(const MyApp());
    await tester.pumpAndSettle();
    expect(find.text('Belum ada data mahasiswa'), findsOneWidget);

    // CREATE
    await tester.tap(find.text('Tambah'));
    await tester.pumpAndSettle();
    await tester.enterText(
      find.widgetWithText(TextFormField, 'NIM'),
      '22010100',
    );
    await tester.enterText(
      find.widgetWithText(TextFormField, 'Nama Lengkap'),
      'Siti',
    );
    await tester.enterText(find.widgetWithText(TextFormField, 'Semester'), '3');
    await tester.tap(find.text('Simpan'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Siti'), findsOneWidget);

    // UPDATE
    await tester.tap(find.byIcon(Icons.edit));
    await tester.pumpAndSettle();
    await tester.enterText(
      find.widgetWithText(TextFormField, 'Nama Lengkap'),
      'Siti Aminah',
    );
    await tester.tap(find.text('Perbarui'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Siti Aminah'), findsOneWidget);

    // DELETE
    await tester.tap(find.byIcon(Icons.delete));
    await tester.pumpAndSettle();
    await tester.tap(find.text('Hapus'));
    await tester.pumpAndSettle(const Duration(seconds: 4));
    expect(find.text('Belum ada data mahasiswa'), findsOneWidget);
  });
}

Isinya hampir sama dengan test di Modul 11B. Bedanya, FakeAuthService(sudahLogin: true) membuat aplikasi langsung membuka halaman daftar, dan data disimpan di FakeMahasiswaService, bukan di Hive.
