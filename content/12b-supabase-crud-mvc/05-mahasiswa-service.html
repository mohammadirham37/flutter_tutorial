MahasiswaService menggantikan HiveService. Tugasnya tetap sama: menjadi satu-satunya kelas yang berbicara dengan database. Bedanya, sekarang databasenya ada di internet sehingga semua method bersifat async.

Buat file lib/services/mahasiswa_service.dart:

📄 lib/services/mahasiswa_service.dart

import 'package:supabase_flutter/supabase_flutter.dart';

import '../models/mahasiswa_model.dart';

/// Lapisan akses data (bagian dari MODEL pada MVC).
/// Pengganti HiveService: semua operasi CRUD ke tabel `mahasiswa`
/// di Supabase dikumpulkan di sini.
class MahasiswaService {
  MahasiswaService(this._client);

  final SupabaseClient _client;

  static const String table = 'mahasiswa';

  // READ: RLS otomatis membatasi hanya data milik user yang login.
  Future<List<Mahasiswa>> getAll() async {
    final rows = await _client
        .from(table)
        .select()
        .order('nama', ascending: true);
    return rows.map(Mahasiswa.fromJson).toList();
  }

  // CREATE: id dan user_id diisi otomatis oleh database.
  Future<void> create(Mahasiswa mhs) async {
    await _client.from(table).insert(mhs.toJson());
  }

  // UPDATE: ubah baris dengan id tertentu.
  Future<void> update(String id, Mahasiswa mhs) async {
    await _client.from(table).update(mhs.toJson()).eq('id', id);
  }

  // DELETE
  Future<void> delete(String id) async {
    await _client.from(table).delete().eq('id', id);
  }
}

Membandingkan dengan HiveService

OperasiHiveService (Modul 11B)MahasiswaService (Supabase)
Read_box.values.toList() (langsung, tanpa await)await _client.from('mahasiswa').select().order('nama', ascending: true)
Create_box.put(mhs.id, mhs)insert(mhs.toJson())
Update_box.put(mhs.id, mhs) (menimpa key yang sama)update(mhs.toJson()).eq('id', id)
Delete_box.delete(id)delete().eq('id', id)
Tipe kembalian ReadList<Mahasiswa>Future<List<Mahasiswa>>

Penjelasan baris penting

  • MahasiswaService(this._client): client Supabase diterima lewat constructor, tidak diambil sendiri dari Supabase.instance. Teknik ini disebut dependency injection. Manfaatnya terlihat di section 14: saat testing kita bisa memakai service palsu tanpa internet.
  • _client.from(table): memilih tabel, mirip Hive.box().
  • .select(): mengambil semua kolom. Hasilnya List<Map<String, dynamic>>, lalu setiap Map diubah menjadi objek dengan rows.map(Mahasiswa.fromJson).toList().
  • .order('nama', ascending: true): data diurutkan oleh database berdasarkan nama, A ke Z.
  • .eq('id', id): filter "kolom id sama dengan ...". Artinya sama dengan WHERE id = '...' di SQL.

⚠️ Jebakan: order() defaultnya Z ke A

Di supabase_flutter, parameter ascending pada order() bernilai false secara bawaan. Jika Anda hanya menulis .order('nama'), daftar justru tampil terbalik (Siti, Budi, Andi). Kesalahan ini kami temukan sendiri saat menguji modul ini, jadi selalu tulis ascending: true secara eksplisit.

⚠️ Update/delete tanpa .eq()

Jangan pernah memanggil update(...) atau delete() tanpa filter. Supabase menolak update/delete tanpa filter, dan seandainya diizinkan, perintah itu akan mengenai semua baris milik user tersebut.

ℹ️ Tidak ada filter user_id

Perhatikan bahwa getAll() tidak memfilter user_id, tetapi Budi tetap hanya mendapat datanya sendiri. Penyaringan ini dilakukan RLS di server (section 2), dan inilah alasan RLS wajib diaktifkan.

Coba jalankan: service sebelum login

Kita belum punya fitur login, tetapi service sudah bisa dicoba. Hasilnya justru memperlihatkan RLS sedang bekerja. Ganti seluruh isi lib/main.dart dengan:

📄 lib/main.dart (sementara)

// lib/main.dart (SEMENTARA) — mencoba MahasiswaService SEBELUM login.
// Jalankan: flutter run --dart-define-from-file=env.json
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'config/env.dart';
import 'models/mahasiswa_model.dart';
import 'services/mahasiswa_service.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabaseKey,
  );
  runApp(const CobaServiceApp());
}

class CobaServiceApp extends StatelessWidget {
  const CobaServiceApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo, useMaterial3: true),
      home: const CobaServicePage(),
    );
  }
}

class CobaServicePage extends StatefulWidget {
  const CobaServicePage({super.key});

  @override
  State<CobaServicePage> createState() => _CobaServicePageState();
}

class _CobaServicePageState extends State<CobaServicePage> {
  // Service menerima client lewat constructor (dependency injection).
  final _service = MahasiswaService(Supabase.instance.client);
  String _log = '';

  void _tulis(String baris) => setState(() => _log = '$baris\n\n$_log');

  Future<void> _getAll() async {
    try {
      final data = await _service.getAll();
      _tulis(
        'getAll(): ${data.length} data\n'
        '${data.map((m) => '- ${m.nama}').join('\n')}',
      );
    } catch (e) {
      _tulis('getAll() gagal: $e');
    }
  }

  Future<void> _create() async {
    try {
      await _service.create(
        Mahasiswa(
          nim: '220101001',
          nama: 'Budi Santoso',
          prodi: 'Informatika',
          semester: 5,
        ),
      );
      _tulis('create(): berhasil');
    } on PostgrestException catch (e) {
      _tulis('create() ditolak\ncode: ${e.code}\nmessage: ${e.message}');
    } catch (e) {
      _tulis('create() gagal: $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    final user = Supabase.instance.client.auth.currentUser;
    return Scaffold(
      appBar: AppBar(title: const Text('Coba MahasiswaService')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            Text(
              'Status: ${user == null ? 'BELUM login' : 'login sebagai ${user.email}'}',
            ),
            const SizedBox(height: 12),
            Row(
              children: [
                Expanded(
                  child: FilledButton(
                    onPressed: _getAll,
                    child: const Text('getAll()'),
                  ),
                ),
                const SizedBox(width: 12),
                Expanded(
                  child: FilledButton.tonal(
                    onPressed: _create,
                    child: const Text('create()'),
                  ),
                ),
              ],
            ),
            const Divider(height: 32),
            Expanded(
              child: SingleChildScrollView(
                child: Text(
                  _log.isEmpty ? 'Hasil akan tampil di sini.' : _log,
                  style: const TextStyle(fontFamily: 'monospace'),
                ),
              ),
            ),
          ],
        ),
      ),
    );
  }
}
Belum login: 0 data dan insert ditolak RLS (42501)

Jalankan dengan flutter run --dart-define-from-file=env.json, lalu tekan kedua tombol:

TombolHasil saat belum loginPenyebab
getAll()getAll(): 0 dataPolicy SELECT hanya meloloskan baris dengan user_id = auth.uid(). Tanpa login, auth.uid() bernilai null, jadi tidak ada baris yang cocok. Perhatikan bahwa hasilnya daftar kosong, bukan error.
create()Ditolak, code: 42501 (new row violates row-level security policy)Pengguna tanpa login tidak boleh menambah data, sehingga insert ditolak RLS.
  • MahasiswaService(Supabase.instance.client): service dibuat dengan memberikan client lewat constructor. Di aplikasi final, pekerjaan ini dilakukan Get.put di main.dart.
  • on PostgrestException catch (e) menampilkan e.code. Kode 42501 inilah yang nanti diterjemahkan MahasiswaController menjadi "Akses ditolak. Silakan login ulang."
  • _tulis menaruh hasil terbaru di paling atas log, supaya urutan percobaan mudah dibaca.

💡 Kesimpulan percobaan

Tanpa login, aplikasi tidak bisa membaca maupun menulis data. Section berikutnya menambahkan AuthService, lalu percobaan yang sama diulang setelah login.
