File terakhir. main.dart sekarang menyalakan Supabase (bukan Hive), mendaftarkan service dan AuthController ke GetX, lalu menjalankan aplikasi.

Hapus seluruh isi lib/main.dart, lalu ganti dengan:

📄 lib/main.dart

import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'config/env.dart';
import 'controllers/auth_controller.dart';
import 'routes/app_pages.dart';
import 'routes/app_routes.dart';
import 'services/auth_service.dart';
import 'services/mahasiswa_service.dart';

Future<void> main() async {
  // 1. Pastikan binding Flutter siap sebelum memanggil kode async
  WidgetsFlutterBinding.ensureInitialized();

  // 2. Cek konfigurasi: lupa --dart-define-from-file=env.json?
  if (!Env.isConfigured) {
    runApp(const KonfigurasiKosongApp());
    return;
  }

  // 3. Inisialisasi Supabase (sesi login lama otomatis dipulihkan)
  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabaseKey,
  );
  final client = Supabase.instance.client;

  // 4. Daftarkan service & AuthController sekali untuk seluruh aplikasi
  Get.put(AuthService(client), permanent: true);
  Get.put(MahasiswaService(client), permanent: true);
  Get.put(AuthController(Get.find()), permanent: true);

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'CRUD Mahasiswa',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo, useMaterial3: true),
      // Selalu menuju home. Jika belum login, AuthMiddleware
      // mengalihkan ke halaman login.
      initialRoute: AppRoutes.home,
      getPages: AppPages.pages,
    );
  }
}

Langkah di dalam main()

  1. WidgetsFlutterBinding.ensureInitialized(): sama seperti Modul 11B, wajib ada karena main() memanggil plugin sebelum runApp.
  2. Cek konfigurasi: jika aplikasi dijalankan tanpa --dart-define-from-file=env.json, tampilkan layar berisi petunjuk lalu berhenti (return).
  3. await Supabase.initialize(...): menyambungkan aplikasi ke project Supabase. Fungsi ini juga memulihkan sesi login yang tersimpan, sehingga setelah baris ini currentUser sudah terisi jika pengguna pernah login.
  4. Tiga Get.put(..., permanent: true): mendaftarkan AuthService, MahasiswaService, dan AuthController. permanent: true berarti objek tidak pernah dihapus GetX selama aplikasi berjalan, karena ketiganya dibutuhkan di semua halaman.

Pembanding dengan Modul 11B

Modul 11BSekarang
await Hive.initFlutter();await Supabase.initialize(url: ..., publishableKey: ...);
Hive.registerAdapter(MahasiswaAdapter());Tidak perlu

-Get.put(AuthService(...)), Get.put(MahasiswaService(...)), Get.put(AuthController(...))
initialRoute: AppRoutes.homeSama. Middleware yang memutuskan login atau tidak.

Urutan Get.put itu penting

AuthController(Get.find()) mencari AuthService, jadi AuthService harus didaftarkan lebih dulu. Jika urutannya dibalik, muncul error "AuthService" not found. You need to call "Get.put(AuthService())".

Menjalankan aplikasi

Mulai sekarang, aplikasi selalu dijalankan dengan flag berikut:

flutter analyze
flutter run --dart-define-from-file=env.json

💡 Supaya tidak lupa flag-nya (VS Code)

Buat file .vscode/launch.json berikut, lalu jalankan aplikasi dengan menekan F5:

{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "crud_mahasiswa",
      "request": "launch",
      "type": "dart",
      "args": ["--dart-define-from-file=env.json"]
    }
  ]
}

Di Android Studio: Run → Edit Configurations → Additional run args, lalu isi --dart-define-from-file=env.json.

⚠️ Hot reload tidak membaca ulang env.json

Nilai dari env.json ditanam saat kompilasi. Jika Anda mengubah isi env.json, hentikan aplikasi lalu jalankan ulang flutter run. Hot reload saja tidak cukup.
