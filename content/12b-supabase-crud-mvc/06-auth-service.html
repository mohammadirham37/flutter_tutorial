AuthService adalah pasangan MahasiswaService untuk urusan akun. Kelas ini satu-satunya yang memanggil Supabase Auth, sehingga controller tidak perlu tahu detail Supabase.

Buat file lib/services/auth_service.dart:

📄 lib/services/auth_service.dart

import 'package:supabase_flutter/supabase_flutter.dart';

/// Lapisan akses Supabase Auth (bagian dari MODEL pada MVC).
/// Hanya class ini yang berbicara langsung dengan Supabase Auth.
class AuthService {
  AuthService(this._client);

  final SupabaseClient _client;

  GoTrueClient get _auth => _client.auth;

  /// User yang sedang login, atau null jika belum login.
  User? get currentUser => _auth.currentUser;

  /// Stream yang memancarkan event setiap status login berubah
  /// (signedIn, signedOut, tokenRefreshed, ...).
  Stream<AuthState> get authStateChanges => _auth.onAuthStateChange;

  Future<AuthResponse> signUp({
    required String email,
    required String password,
  }) {
    return _auth.signUp(email: email, password: password);
  }

  Future<AuthResponse> signIn({
    required String email,
    required String password,
  }) {
    return _auth.signInWithPassword(email: email, password: password);
  }

  Future<void> signOut() => _auth.signOut();
}

Isi kelas

AnggotaKegunaan
currentUserData user yang sedang login (id, email, ...), atau null jika belum login. Dipakai AuthMiddleware untuk memutuskan boleh masuk atau tidak.
authStateChangesStream yang memancarkan event setiap kali status login berubah: signedIn, signedOut, tokenRefreshed, dan lainnya.
signUp(email, password)Membuat akun baru di tabel auth.users.
signIn(email, password)Login dengan email dan password. Jika salah, melempar AuthException.
signOut()Logout dan menghapus sesi yang tersimpan di HP.

Apa itu "sesi" dan di mana disimpan?

Setelah login berhasil, Supabase memberi aplikasi sebuah sesi: berisi access token (berlaku sekitar 1 jam) dan refresh token (untuk meminta token baru). supabase_flutter menyimpan sesi ini di penyimpanan HP secara otomatis dan memperbaruinya sebelum kedaluwarsa. Akibatnya:

  • Setelah aplikasi ditutup lalu dibuka lagi, pengguna tidak perlu login ulang. currentUser langsung terisi.
  • Setiap query ke tabel mahasiswa otomatis membawa token ini. Dari token itulah auth.uid() di policy RLS mengetahui siapa yang meminta data.

💡 Kenapa dibungkus lagi, padahal bisa langsung Supabase.instance.client.auth?

Supaya hanya ada satu pintu menuju Supabase Auth. Jika suatu saat Anda pindah ke Firebase Auth, cukup kelas ini yang diganti. Alasan kedua, kelas ini bisa diganti dengan versi palsu saat testing.

Coba jalankan: login lalu akses data

Sekarang kita gabungkan AuthService dan MahasiswaService dalam satu halaman percobaan. Ganti seluruh isi lib/main.dart dengan:

📄 lib/main.dart (sementara)

// lib/main.dart (SEMENTARA) — mencoba AuthService + MahasiswaService.
// Jalankan: flutter run --dart-define-from-file=env.json
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'config/env.dart';
import 'models/mahasiswa_model.dart';
import 'services/auth_service.dart';
import 'services/mahasiswa_service.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Supabase.initialize(
    url: Env.supabaseUrl,
    publishableKey: Env.supabaseKey,
  );
  runApp(const CobaAuthApp());
}

class CobaAuthApp extends StatelessWidget {
  const CobaAuthApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo, useMaterial3: true),
      home: const CobaAuthPage(),
    );
  }
}

class CobaAuthPage extends StatefulWidget {
  const CobaAuthPage({super.key});

  @override
  State<CobaAuthPage> createState() => _CobaAuthPageState();
}

class _CobaAuthPageState extends State<CobaAuthPage> {
  final _auth = AuthService(Supabase.instance.client);
  final _service = MahasiswaService(Supabase.instance.client);

  final _emailC = TextEditingController();
  final _passwordC = TextEditingController();
  String _log = '';

  void _tulis(String baris) => setState(() => _log = '$baris\n\n$_log');

  /// Menjalankan [aksi] dan mencatat error-nya (jika ada) ke log.
  Future<void> _jalankan(String nama, Future<void> Function() aksi) async {
    try {
      await aksi();
    } on AuthException catch (e) {
      _tulis('$nama gagal (AuthException)\ncode: ${e.code}\n${e.message}');
    } on PostgrestException catch (e) {
      _tulis('$nama gagal (PostgrestException)\ncode: ${e.code}\n${e.message}');
    } catch (e) {
      _tulis('$nama gagal: $e');
    }
  }

  Future<void> _signUp() => _jalankan('signUp', () async {
    final res = await _auth.signUp(
      email: _emailC.text.trim(),
      password: _passwordC.text,
    );
    _tulis(
      res.session != null
          ? 'signUp: akun dibuat dan langsung login'
          : 'signUp: akun dibuat, cek email untuk verifikasi',
    );
  });

  Future<void> _signIn() => _jalankan('signIn', () async {
    await _auth.signIn(email: _emailC.text.trim(), password: _passwordC.text);
    _tulis('signIn: berhasil');
  });

  Future<void> _signOut() => _jalankan('signOut', () async {
    await _auth.signOut();
    _tulis('signOut: berhasil');
  });

  Future<void> _getAll() => _jalankan('getAll', () async {
    final data = await _service.getAll();
    _tulis(
      'getAll(): ${data.length} data\n'
      '${data.map((m) => '- ${m.nim} ${m.nama}').join('\n')}',
    );
  });

  Future<void> _create() => _jalankan('create', () async {
    // NIM acak agar tidak bentrok dengan aturan unique
    final nim = '2201${DateTime.now().millisecondsSinceEpoch % 100000}';
    await _service.create(
      Mahasiswa(
        nim: nim,
        nama: 'Mahasiswa $nim',
        prodi: 'Informatika',
        semester: 1,
      ),
    );
    _tulis('create(): $nim ditambahkan');
  });

  @override
  void dispose() {
    _emailC.dispose();
    _passwordC.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Coba AuthService')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // StreamBuilder: ikut berubah setiap event login/logout
          StreamBuilder<AuthState>(
            stream: _auth.authStateChanges,
            builder: (context, snapshot) {
              final user = _auth.currentUser;
              final event = snapshot.data?.event.name ?? '-';
              return Text(
                'Status: ${user == null ? 'BELUM login' : user.email}\n'
                'Event terakhir: $event',
              );
            },
          ),
          const SizedBox(height: 12),
          TextField(
            controller: _emailC,
            keyboardType: TextInputType.emailAddress,
            decoration: const InputDecoration(
              labelText: 'Email',
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 8),
          TextField(
            controller: _passwordC,
            obscureText: true,
            decoration: const InputDecoration(
              labelText: 'Password (min. 6 karakter)',
              border: OutlineInputBorder(),
            ),
          ),
          const SizedBox(height: 8),
          Wrap(
            spacing: 8,
            children: [
              FilledButton(onPressed: _signUp, child: const Text('Daftar')),
              FilledButton(onPressed: _signIn, child: const Text('Masuk')),
              OutlinedButton(onPressed: _signOut, child: const Text('Keluar')),
              FilledButton.tonal(
                onPressed: _getAll,
                child: const Text('getAll()'),
              ),
              FilledButton.tonal(
                onPressed: _create,
                child: const Text('create()'),
              ),
            ],
          ),
          const Divider(height: 32),
          Text(
            _log.isEmpty ? 'Hasil akan tampil di sini.' : _log,
            style: const TextStyle(fontFamily: 'monospace'),
          ),
        ],
      ),
    );
  }
}
Setelah Daftar: create() dan getAll() berhasil
Setelah Keluar: data disembunyikan RLS

Jalankan dengan flutter run --dart-define-from-file=env.json, lalu coba urutan berikut:

  1. Tekan getAll() dan create() saat status masih "BELUM login". Hasilnya sama dengan section 5: 0 data dan insert ditolak (42501).
  2. Isi email (misalnya budi@kampus.test) dan password minimal 6 karakter, lalu tekan Daftar. Karena Confirm email dimatikan (section 2), log menampilkan "akun dibuat dan langsung login", dan status berubah menjadi email Anda.
  3. Tekan create() dua kali, lalu getAll(). Sekarang data berhasil disimpan dan terbaca.
  4. Tekan Keluar, lalu getAll() lagi. Hasilnya kembali 0 data: datanya masih ada di database, tetapi RLS menyembunyikannya.
  5. Tekan Masuk dengan email dan password yang sama. Data muncul kembali.
  6. Tekan Masuk dengan password salah. Log menampilkan AuthException dengan code: invalid_credentials.
  7. Tutup aplikasi saat masih login, lalu jalankan lagi. Status langsung menampilkan email Anda karena sesi tersimpan di HP.
  • StreamBuilder<AuthState> mendengarkan authStateChanges. Setiap kali ada event (signedIn, signedOut, ...), teks status dibangun ulang. Pola mendengarkan stream ini nanti dipakai AuthController.
  • _jalankan membungkus setiap aksi dengan try/catch dan membedakan AuthException (error login) dari PostgrestException (error database).
  • NIM pada create() dibuat dari jam saat itu agar tidak bentrok dengan constraint unique (user_id, nim) saat tombol ditekan berkali-kali.

ℹ️ Kenapa halaman ini memakai StatefulWidget, bukan GetX?

Halaman ini hanya alat uji untuk dua service. Setelah keduanya terbukti bekerja, section 7 dan 8 memindahkan logika ke controller GetX, sama seperti pola MVC di Modul 11B.
