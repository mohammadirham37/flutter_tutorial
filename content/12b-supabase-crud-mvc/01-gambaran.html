Di Modul 11B kita sudah membuat aplikasi CRUD Data Mahasiswa yang menyimpan data di Hive, jadi datanya hanya ada di satu HP. Di modul ini aplikasi yang sama kita pindahkan ke Supabase (database cloud), lalu kita tambahkan login dan register supaya setiap pengguna hanya melihat datanya sendiri. Polanya tetap MVC + GetX, dan sebagian besar file dari Modul 11B tetap dipakai.

Perhatikan bahwa View daftar dan form hampir tidak berubah. Inilah keuntungan MVC: karena View tidak pernah menyentuh Hive secara langsung, mengganti database cukup dilakukan di lapisan Model (service) dan sedikit di Controller.

AuthMiddleware: sebelum membuka halaman Daftar/Form,
cek AuthController.isLoggedIn. Belum login -> ke /login.

Alur yang dilalui pengguna

  1. Aplikasi dibuka dan selalu menuju route / (daftar mahasiswa).
  2. AuthMiddleware memeriksa apakah ada user yang login. Jika belum, pengguna dialihkan ke /login. Jika sudah (sesi tersimpan dari pembukaan sebelumnya), halaman daftar langsung tampil.
  3. Di halaman login, pengguna bisa masuk atau membuka halaman register.
  4. Setelah login berhasil, Get.offAllNamed('/') membuka halaman daftar dan menghapus halaman login dari tumpukan, sehingga tombol Back tidak kembali ke login.
  5. Di halaman daftar, pengguna melakukan CRUD seperti di Modul 11B. Bedanya, setiap operasi dikirim ke Supabase.
  6. Saat logout, Supabase memancarkan event signedOut, lalu AuthController membuka halaman login.

💡 Cara mengikuti modul ini

Kerjakan section 2 sampai 12 berurutan. Urutannya sama seperti Modul 11B: siapkan database dulu, lalu tulis kode dari lapisan paling bawah (model dan service), naik ke controller, route, view, dan terakhir main.dart. Garis merah di editor karena file yang diimpor belum dibuat akan hilang sendiri setelah file tersebut ditulis. Jika ingin langsung jadi, salin semua file dari section 15 (Listing Lengkap).

Anda sudah menyelesaikan proyek crud_mahasiswa di Modul 11B, dan sudah membaca Modul 12 (membuat project Supabase, SQL Editor, dan Row Level Security). Jika proyek Modul 11B belum ada, buat dulu dengan flutter create crud_mahasiswa. Semua file yang dibutuhkan tetap ditulis lengkap di modul ini.
