local_auth memakai komponen native yang perlu sedikit persiapan. Jika langkah ini terlewat, dialog biometrik tidak akan muncul dan aplikasi melempar error uiUnavailable. Kerjakan semua langkah berikut sebelum menulis kode Dart.

Langkah 1: Pasang package

flutter pub add local_auth flutter_secure_storage get permission_handler

Versi terbaru local_auth mendukung Android API 24 (Android 7.0) ke atas dan iOS 13 ke atas. Proyek Flutter baru sudah memakai minSdk = flutter.minSdkVersion yang bernilai 24, jadi tidak perlu diubah.

Langkah 2: MainActivity menjadi FlutterFragmentActivity

Dialog BiometricPrompt di Android adalah sebuah Fragment, sehingga Activity yang menampungnya harus turunan FragmentActivity. Buka file Kotlin MainActivity.kt (lokasinya mengikuti nama paket, misalnya android/app/src/main/kotlin/id/ac/kampus/catatan_kuliah/) lalu ubah menjadi:

📄 android/app/src/main/kotlin/.../MainActivity.kt

package id.ac.kampus.catatan_kuliah

import io.flutter.embedding.android.FlutterFragmentActivity

class MainActivity : FlutterFragmentActivity()

Baris package biarkan sesuai proyek Anda. Yang diganti hanya import dan kelas induknya: FlutterActivity menjadi FlutterFragmentActivity.

Langkah 3: Izin USE_BIOMETRIC

Tambahkan satu baris di atas tag <application>:

📄 android/app/src/main/AndroidManifest.xml

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.USE_BIOMETRIC" />

    <application
        android:label="catatan_kuliah"
        ...

USE_BIOMETRIC adalah izin kategori normal: otomatis diberikan saat aplikasi dipasang, tidak memunculkan dialog izin seperti kamera atau lokasi (Modul 17). Jadi di Android tidak ada skenario "izin biometrik ditolak". Yang mungkin terjadi adalah pengguna belum mendaftarkan sidik jari, dan itu ditangani di section 5.

Langkah 4: Tema AppCompat

README local_auth_android meminta LaunchTheme memakai turunan Theme.AppCompat agar dialog tidak crash di Android 8 ke bawah. Ubah atribut parent di dua file tema:

📄 android/app/src/main/res/values/styles.xml

<style name="LaunchTheme" parent="Theme.AppCompat.DayNight">
    <item name="android:windowBackground">@drawable/launch_background</item>
</style>

Lakukan hal yang sama untuk LaunchTheme di res/values-night/styles.xml. Isi <item> lain dan NormalTheme tidak perlu diubah.

Langkah 5: compileSdk untuk permission_handler

Versi terbaru permission_handler dikompilasi dengan Android SDK 37. Jika build gagal dengan pesan "plugin(s) require to be compiled against a higher Android SDK version", ubah compileSdk (bukan minSdk):

📄 android/app/build.gradle.kts

android {
    namespace = "id.ac.kampus.catatan_kuliah"
    compileSdk = 37 // sebelumnya: flutter.compileSdkVersion
    ...
}

Langkah 6: iOS, alasan pemakaian Face ID

Tanpa kunci ini, aplikasi di iPhone dengan Face ID akan ditolak sistem saat meminta autentikasi. Tambahkan di dalam <dict>:

📄 ios/Runner/Info.plist

<key>NSFaceIDUsageDescription</key>
<string>Face ID dipakai untuk membuka kunci Catatan Kuliah Anda.</string>

Teks ini muncul di dialog izin iOS, jadi tulis alasan yang jujur dan jelas dalam bahasa pengguna. Touch ID tidak memerlukan kunci ini.

⚠️ Perhatian

  • Perubahan di folder android/ dan ios/ tidak ikut terbawa oleh Hot Reload maupun Hot Restart. Hentikan aplikasi lalu jalankan ulang dengan flutter run.
  • Jika MainActivity.kt tidak ditemukan, cari dengan nama berkas di folder android/app/src/main/. Proyek lama kadang memakai MainActivity.java; ganti induknya menjadi io.flutter.embedding.android.FlutterFragmentActivity dengan cara yang sama.
