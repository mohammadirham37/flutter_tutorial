Sekarang semua potongan kita susun dengan pola MVC GetX seperti di Modul 08: Service yang membungkus plugin, Controller yang menyimpan state reaktif dan aturan "kapan terkunci", dan View yang hanya menampilkan state lewat Obx.

File 1: BiometricService

📄 lib/services/biometric_service.dart

// lib/services/biometric_service.dart
import 'package:flutter/services.dart';
import 'package:local_auth/local_auth.dart';
import 'package:permission_handler/permission_handler.dart';

import '../utils/pesan_biometrik.dart';

/// Satu-satunya kelas yang menyentuh plugin local_auth.
/// Controller dan view cukup memakai method di sini.
class BiometricService {
  BiometricService({LocalAuthentication? auth})
    : _auth = auth ?? LocalAuthentication();

  final LocalAuthentication _auth;

  /// true jika perangkat punya biometrik ATAU kunci layar (PIN/pola/sandi).
  Future<bool> perangkatMendukung() async {
    try {
      return await _auth.isDeviceSupported();
    } on PlatformException {
      return false;
    }
  }

  /// Daftar biometrik yang sudah didaftarkan dan boleh dipakai aplikasi.
  Future<List<BiometricType>> daftarBiometrik() async {
    try {
      return await _auth.getAvailableBiometrics();
    } on PlatformException {
      return const [];
    }
  }

  /// Menampilkan dialog sistem. Data sidik jari/wajah TIDAK pernah
  /// sampai ke aplikasi; kita hanya menerima hasil berhasil/gagal.
  Future<HasilBiometrik> autentikasi({
    required String alasan,
    bool hanyaBiometrik = false,
  }) async {
    try {
      final berhasil = await _auth.authenticate(
        localizedReason: alasan,
        biometricOnly: hanyaBiometrik,
        persistAcrossBackgrounding: true,
      );
      return berhasil
          ? const HasilBiometrik(StatusBiometrik.berhasil, 'Berhasil.')
          : const HasilBiometrik(
              StatusBiometrik.gagal,
              'Sidik jari atau wajah tidak dikenali.',
            );
    } on LocalAuthException catch (e) {
      return hasilDariKode(e.code);
    } on PlatformException catch (e) {
      return HasilBiometrik(StatusBiometrik.gagal, 'Kesalahan: ${e.code}');
    }
  }

  /// Membuka halaman pengaturan aplikasi (berguna di iOS jika
  /// izin Face ID pernah ditolak).
  Future<bool> bukaPengaturan() => openAppSettings();
}
  • Hanya file ini yang mengimpor local_auth dan permission_handler. Jika suatu saat plugin diganti, controller dan view tidak perlu diubah.
  • autentikasi() tidak pernah melempar exception. Semua kemungkinan diubah menjadi HasilBiometrik lewat hasilDariKode dari section 5, sehingga controller cukup memakai switch.
  • persistAcrossBackgrounding: true: jika pengguna menerima telepon saat dialog tampil, autentikasi diulang otomatis saat kembali, bukan gagal dengan systemCanceled.
  • Konstruktor menerima LocalAuthentication? opsional. Saat unit test (Modul 15), kita bisa memasukkan objek tiruan.

File 2: LockController

Controller ini memerlukan SesiController (status login), yang kodenya ada di studi kasus section 8. Yang dipakai dari sana hanya getter sudahLogin, tokenRx, dan method logout().

📄 lib/controllers/lock_controller.dart

// lib/controllers/lock_controller.dart
import 'package:flutter/widgets.dart' show AppLifecycleListener, FocusManager;
import 'package:get/get.dart';

import '../services/biometric_service.dart';
import '../services/sesi_service.dart';
import '../utils/pesan_biometrik.dart';
import 'sesi_controller.dart';

class LockController extends GetxController {
  LockController(
    this._biometrik,
    this._sesiService,
    SesiController sesi, {
    bool kunciAktifAwal = false,
  }) : _sesi = sesi,
       _kunciAktif = kunciAktifAwal.obs,
       // Saat aplikasi dibuka: kunci jika fitur aktif dan sudah login.
       _terkunci = (kunciAktifAwal && sesi.sudahLogin).obs;

  /// Kembali dari background lebih cepat dari ini tidak perlu buka kunci lagi.
  static const masaTenggang = Duration(seconds: 30);

  /// Setelah gagal sebanyak ini, tombol "Masuk ulang" ditonjolkan.
  static const batasGagal = 3;

  final BiometricService _biometrik;
  final SesiService _sesiService;
  final SesiController _sesi;

  final RxBool _kunciAktif;
  final RxBool _terkunci;
  final _sedangMemproses = false.obs;
  final _pesan = RxnString();
  final _jumlahGagal = 0.obs;
  final _perluPengaturan = false.obs;

  AppLifecycleListener? _lifecycle;
  final _workers = <Worker>[];
  DateTime? _waktuKeBackground;

  bool get kunciAktif => _kunciAktif.value;
  bool get terkunci => _terkunci.value;
  bool get sedangMemproses => _sedangMemproses.value;
  String? get pesan => _pesan.value;
  bool get sarankanLoginUlang => _jumlahGagal.value >= batasGagal;
  bool get perluPengaturan => _perluPengaturan.value;

  @override
  void onInit() {
    super.onInit();
    _lifecycle = AppLifecycleListener(
      onPause: _saatKeBackground,
      onResume: _saatKembali,
    );
    // Logout dari mana pun: reset semua state kunci.
    _workers.add(
      ever<String?>(_sesi.tokenRx, (token) {
        if (token == null) {
          _kunciAktif.value = false;
          _terkunci.value = false;
          _resetStatus();
        }
      }),
    );
  }

  @override
  void onReady() {
    super.onReady();
    // onReady dipanggil setelah frame pertama, Activity sudah siap.
    if (terkunci) bukaKunci();
  }

  @override
  void onClose() {
    _lifecycle?.dispose();
    for (final worker in _workers) {
      worker.dispose();
    }
    super.onClose();
  }

  void _saatKeBackground() {
    // Dialog biometrik bisa memicu pause; abaikan agar tidak terkunci ulang.
    if (_sedangMemproses.value) return;
    _waktuKeBackground = DateTime.now();
  }

  void _saatKembali() {
    final sejak = _waktuKeBackground;
    _waktuKeBackground = null;
    if (sejak == null || !kunciAktif || !_sesi.sudahLogin || terkunci) return;

    if (DateTime.now().difference(sejak) >= masaTenggang) {
      // Tutup keyboard agar isi form di bawah layar kunci tidak terlihat.
      FocusManager.instance.primaryFocus?.unfocus();
      _terkunci.value = true;
      bukaKunci();
    }
  }

  Future<void> bukaKunci() async {
    if (_sedangMemproses.value) return; // cegah dialog ganda
    _sedangMemproses.value = true;
    _pesan.value = null;

    final hasil = await _biometrik.autentikasi(
      alasan: 'Buka kunci Catatan Kuliah',
    );
    _sedangMemproses.value = false;

    switch (hasil.status) {
      case StatusBiometrik.berhasil:
        _resetStatus();
        _terkunci.value = false;
      case StatusBiometrik.dibatalkan:
        _pesan.value = hasil.pesan; // tidak dihitung sebagai gagal
      case StatusBiometrik.gagal:
        _jumlahGagal.value++;
        _pesan.value = hasil.pesan;
      case StatusBiometrik.belumTerdaftar:
      case StatusBiometrik.tidakTersedia:
        _perluPengaturan.value = true;
        _jumlahGagal.value = batasGagal;
        _pesan.value = hasil.pesan;
      case StatusBiometrik.terkunciSementara:
      case StatusBiometrik.terkunciPermanen:
        _jumlahGagal.value = batasGagal;
        _pesan.value = hasil.pesan;
    }
  }

  /// Mengaktifkan/mematikan kunci. Mengembalikan pesan error, atau null jika sukses.
  Future<String?> aturKunci(bool aktif) async {
    if (aktif) {
      if (!await _biometrik.perangkatMendukung()) {
        return 'Aktifkan dulu kunci layar atau sidik jari di pengaturan HP.';
      }
      // Minta konfirmasi agar pengguna yakin biometriknya berfungsi.
      _sedangMemproses.value = true;
      final hasil = await _biometrik.autentikasi(
        alasan: 'Konfirmasi untuk mengaktifkan kunci aplikasi',
      );
      _sedangMemproses.value = false;
      if (!hasil.berhasil) return hasil.pesan;
    }
    await _sesiService.aturKunciBiometrik(aktif);
    _kunciAktif.value = aktif;
    return null;
  }

  /// Jalan keluar terakhir: hapus sesi lalu login ulang dengan email.
  Future<void> loginUlang() async {
    // Tutup halaman yang mungkin terbuka (misalnya Pengaturan) agar
    // AppGate di halaman pertama terlihat dan menampilkan LoginView.
    Get.until((route) => route.isFirst);
    await _sesi.logout();
  }

  Future<void> bukaPengaturan() => _biometrik.bukaPengaturan();

  void _resetStatus() {
    _pesan.value = null;
    _jumlahGagal.value = 0;
    _perluPengaturan.value = false;
  }
}

Penjelasan baris penting:

  • Initializer list (: _sesi = sesi, ...) menentukan state awal: aplikasi langsung terkunci jika fitur aktif dan pengguna sudah login. Nilai ini dibaca di main() sebelum runApp, sehingga isi catatan tidak sempat terlihat sekejap.
  • AppLifecycleListener dibuat di onInit dan di-dispose di onClose, sama seperti StreamSubscription. Controller hanya mengimpor flutter/widgets.dart untuk dua kelas ini (bukan material.dart).
  • onReady dipanggil GetX setelah frame pertama. Itulah saat yang aman untuk memunculkan dialog biometrik pertama (menghindari uiUnavailable).
  • _saatKeBackground mengabaikan event selama _sedangMemproses, sesuai peringatan di section 6.
  • bukaKunci() keluar lebih awal jika dialog masih tampil, mencegah authInProgress. switch atas StatusBiometrik menentukan reaksi: batal tidak dihitung gagal, sedangkan lockout atau sensor tidak tersedia langsung menonjolkan tombol login ulang.
  • aturKunci(true) meminta autentikasi dulu sebelum menyimpan. Pengguna tidak bisa mengaktifkan kunci yang ternyata tidak bisa ia buka.
  • Worker ever pada tokenRx mereset semua state kunci setiap kali pengguna logout dari mana pun (Modul 08, section antar controller). Worker disimpan di list dan di-dispose di onClose.
  • loginUlang() memanggil Get.until untuk menutup halaman yang mungkin sedang terbuka, lalu logout.

File 3: LockView

📄 lib/views/lock_view.dart

// lib/views/lock_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/lock_controller.dart';

/// Ditampilkan di ATAS Navigator (lewat GetMaterialApp.builder), sehingga
/// halaman ini tidak boleh memakai showDialog atau Navigator.
class LockView extends GetView<LockController> {
  const LockView({super.key});

  @override
  Widget build(BuildContext context) {
    final skema = Theme.of(context).colorScheme;

    return Scaffold(
      body: SafeArea(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Obx(() {
            final pesan = controller.pesan;
            return Column(
              mainAxisAlignment: MainAxisAlignment.center,
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                Icon(Icons.lock_outline, size: 72, color: skema.primary),
                const SizedBox(height: 16),
                Text(
                  'Catatan Kuliah Terkunci',
                  textAlign: TextAlign.center,
                  style: Theme.of(context).textTheme.headlineSmall,
                ),
                const SizedBox(height: 8),
                const Text(
                  'Gunakan sidik jari, wajah, atau PIN HP untuk membuka.',
                  textAlign: TextAlign.center,
                ),
                const SizedBox(height: 24),
                if (pesan != null)
                  Card(
                    color: skema.errorContainer,
                    child: Padding(
                      padding: const EdgeInsets.all(12),
                      child: Text(
                        pesan,
                        style: TextStyle(color: skema.onErrorContainer),
                      ),
                    ),
                  ),
                const SizedBox(height: 16),
                FilledButton.icon(
                  onPressed: controller.sedangMemproses
                      ? null
                      : controller.bukaKunci,
                  icon: const Icon(Icons.fingerprint),
                  label: Text(
                    controller.sedangMemproses ? 'Menunggu...' : 'Buka Kunci',
                  ),
                ),
                if (controller.perluPengaturan) ...[
                  const SizedBox(height: 8),
                  OutlinedButton.icon(
                    onPressed: controller.bukaPengaturan,
                    icon: const Icon(Icons.settings),
                    label: const Text('Buka Pengaturan'),
                  ),
                ],
                const SizedBox(height: 8),
                // Fallback terakhir: selalu ada, ditonjolkan setelah gagal berkali-kali.
                controller.sarankanLoginUlang
                    ? FilledButton.tonal(
                        onPressed: controller.loginUlang,
                        child: const Text('Keluar & masuk ulang dengan email'),
                      )
                    : TextButton(
                        onPressed: controller.loginUlang,
                        child: const Text(
                          'Tidak bisa? Masuk ulang dengan email',
                        ),
                      ),
              ],
            );
          }),
        ),
      ),
    );
  }
}
  • GetView<LockController> menyediakan getter controller. Seluruh isi dibungkus satu Obx karena hampir semua bagian bergantung pada state controller.
  • Tombol Buka Kunci dinonaktifkan (onPressed: null) selama dialog tampil.
  • Tombol "Buka Pengaturan" hanya muncul jika sensor tidak tersedia atau belum ada biometrik terdaftar.
  • Tombol login ulang selalu ada: berupa TextButton kecil dalam kondisi normal, lalu berubah menjadi FilledButton.tonal yang menonjol setelah batasGagal tercapai.
  • View ini akan ditampilkan di atas Navigator (section 8), sehingga sengaja tidak memakai showDialog, yang membutuhkan Navigator di atasnya.

💡 Tips

Saat mencoba di emulator, ubah sementara masaTenggang menjadi Duration.zero agar aplikasi langsung terkunci begitu kembali dari background. Kembalikan ke 30 detik sebelum dikumpulkan.
