Autentikasi biometrik punya banyak cara untuk "tidak berhasil", dan masing-masing butuh reaksi berbeda. Pengguna yang menekan Batal cukup diberi tombol coba lagi. Pengguna yang sensornya terkunci perlu diarahkan ke PIN. Pengguna yang belum mendaftarkan sidik jari perlu diarahkan ke pengaturan. Semua informasi ini ada di LocalAuthException.code.

ℹ️ Enum ini bisa bertambah

Dokumentasi local_auth menyebut bahwa nilai baru bisa ditambahkan ke LocalAuthExceptionCode tanpa dianggap perubahan besar. Jadi setiap switch atas kode ini wajib punya cabang default atau wildcard _.

Menerjemahkan kode menjadi status dan pesan

Daripada menyebar if (e.code == ...) di banyak tempat, kita kumpulkan semuanya dalam satu file. Hasilnya berupa StatusBiometrik (untuk logika) dan pesan Bahasa Indonesia (untuk ditampilkan). File ini dipakai lagi di section 7 dan studi kasus.

📄 lib/utils/pesan_biometrik.dart

// lib/utils/pesan_biometrik.dart
import 'package:local_auth/local_auth.dart';

/// Ringkasan hasil autentikasi yang mudah dipakai controller dan view.
enum StatusBiometrik {
  berhasil,
  gagal, // wajah/jari tidak cocok (iOS) atau error tak dikenal
  dibatalkan, // pengguna/sistem membatalkan dialog
  belumTerdaftar, // belum ada sidik jari/wajah/PIN di perangkat
  tidakTersedia, // tidak ada sensor, sensor sibuk, atau izin Face ID ditolak
  terkunciSementara, // terlalu banyak percobaan, tunggu sebentar
  terkunciPermanen, // biometrik dikunci sampai pengguna memakai PIN/pola
}

class HasilBiometrik {
  const HasilBiometrik(this.status, this.pesan);

  final StatusBiometrik status;
  final String pesan;

  bool get berhasil => status == StatusBiometrik.berhasil;
}

/// Menerjemahkan kode error local_auth menjadi status + pesan Indonesia.
HasilBiometrik hasilDariKode(LocalAuthExceptionCode kode) {
  return switch (kode) {
    LocalAuthExceptionCode.userCanceled ||
    LocalAuthExceptionCode.systemCanceled ||
    LocalAuthExceptionCode.timeout => const HasilBiometrik(
      StatusBiometrik.dibatalkan,
      'Autentikasi dibatalkan. Coba lagi.',
    ),
    LocalAuthExceptionCode.userRequestedFallback => const HasilBiometrik(
      StatusBiometrik.dibatalkan,
      'Pilih "Masuk ulang" untuk login dengan email dan kata sandi.',
    ),
    LocalAuthExceptionCode.noBiometricsEnrolled => const HasilBiometrik(
      StatusBiometrik.belumTerdaftar,
      'Belum ada sidik jari atau wajah yang terdaftar di perangkat ini.',
    ),
    LocalAuthExceptionCode.noCredentialsSet => const HasilBiometrik(
      StatusBiometrik.belumTerdaftar,
      'Perangkat belum memakai kunci layar (PIN, pola, atau sandi).',
    ),
    LocalAuthExceptionCode.noBiometricHardware ||
    LocalAuthExceptionCode.biometricHardwareTemporarilyUnavailable =>
      const HasilBiometrik(
        StatusBiometrik.tidakTersedia,
        'Sensor biometrik tidak tersedia atau izinnya ditolak.',
      ),
    LocalAuthExceptionCode.temporaryLockout => const HasilBiometrik(
      StatusBiometrik.terkunciSementara,
      'Terlalu banyak percobaan. Tunggu sekitar 30 detik.',
    ),
    LocalAuthExceptionCode.biometricLockout => const HasilBiometrik(
      StatusBiometrik.terkunciPermanen,
      'Biometrik terkunci. Buka kunci layar HP dengan PIN/pola dulu.',
    ),
    LocalAuthExceptionCode.authInProgress => const HasilBiometrik(
      StatusBiometrik.dibatalkan,
      'Autentikasi sebelumnya masih berjalan.',
    ),
    // Wildcard wajib: enum ini bisa bertambah di versi package berikutnya.
    _ => HasilBiometrik(
      StatusBiometrik.gagal,
      'Terjadi kesalahan (${kode.name}).',
    ),
  };
}

Penjelasan:

  • StatusBiometrik mengelompokkan belasan kode menjadi tujuh kategori yang benar-benar berbeda reaksinya. Controller cukup memeriksa kategori ini.
  • Ekspresi switch Dart 3 dengan pola a || b menggabungkan beberapa kode dalam satu cabang.
  • Cabang _ menangkap deviceError, unknownError, uiUnavailable, dan kode baru di masa depan.

Alur lengkap: berhasil, gagal, ditolak, ke pengaturan

Biometrik tidak memakai dialog izin runtime seperti kamera, tetapi alurnya mirip dengan alur izin di Modul 17:

SituasiAndroidiOS

Fungsi berikut memperlihatkan cara bereaksi terhadap tiap status. Tombol "Pengaturan" pada SnackBar memakai openAppSettings() dari permission_handler (Modul 17).

import 'package:flutter/material.dart';
import 'package:local_auth/local_auth.dart';
import 'package:permission_handler/permission_handler.dart';

import '../utils/pesan_biometrik.dart';

final _auth = LocalAuthentication();

Future<void> bukaFiturRahasia(BuildContext context) async {
  HasilBiometrik hasil;
  try {
    final ok = await _auth.authenticate(
      localizedReason: 'Verifikasi untuk membuka fitur ini',
    );
    hasil = ok
        ? const HasilBiometrik(StatusBiometrik.berhasil, 'Berhasil.')
        : const HasilBiometrik(StatusBiometrik.gagal, 'Tidak dikenali.');
  } on LocalAuthException catch (e) {
    hasil = hasilDariKode(e.code);
  }

  if (!context.mounted) return;
  final messenger = ScaffoldMessenger.of(context);

  switch (hasil.status) {
    case StatusBiometrik.berhasil:
      messenger.showSnackBar(const SnackBar(content: Text('Terbuka!')));
    case StatusBiometrik.belumTerdaftar:
    case StatusBiometrik.tidakTersedia:
      // Arahkan ke pengaturan (iOS: izin Face ID untuk aplikasi ini).
      messenger.showSnackBar(
        SnackBar(
          content: Text(hasil.pesan),
          action: SnackBarAction(
            label: 'Pengaturan',
            onPressed: openAppSettings,
          ),
        ),
      );
    default:
      messenger.showSnackBar(SnackBar(content: Text(hasil.pesan)));
  }
}
  • if (!context.mounted) return; diletakkan setelah await, sebelum ScaffoldMessenger.of(context).
  • openAppSettings di iOS membuka halaman aplikasi tempat sakelar Face ID berada. Di Android, halaman itu tidak berisi pengaturan sidik jari, sehingga pesan untuk pengguna Android sebaiknya menyebut jalurnya secara manual: Settings → Security → Fingerprint.

⚠️ Selalu sediakan jalan keluar

Jangan pernah membuat kondisi di mana pengguna terkunci dari datanya sendiri. Sensor bisa rusak, jari bisa terluka, dan Face ID tidak bekerja saat memakai masker tertentu. Untuk kunci aplikasi, sediakan minimal satu dari dua fallback: izinkan PIN/pola HP (biometricOnly: false) dan/atau tombol login ulang dengan email dan kata sandi.
