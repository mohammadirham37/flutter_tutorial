Aplikasi yang memakai internet (REST API di Modul 09, Supabase di Modul 12) harus tahu kapan HP sedang offline, supaya bisa menampilkan pesan yang jelas alih-alih loading tanpa akhir. Package connectivity_plus memberi tahu jenis koneksi yang aktif dan mengabari setiap kali berubah.

Instalasi

flutter pub add connectivity_plus

Di Android, package ini sudah membawa izin ACCESS_NETWORK_STATE di manifest miliknya sendiri, jadi tidak ada konfigurasi tambahan. iOS juga tidak butuh kunci di Info.plist. Izin internet (android.permission.INTERNET) tetap diperlukan untuk request ke server, seperti yang sudah dibahas di Modul 09 dan Modul 16.

Dua API utama

final connectivity = Connectivity();

// 1. Sekali cek: hasilnya List, bukan satu nilai
final List<ConnectivityResult> hasil = await connectivity.checkConnectivity();
if (hasil.contains(ConnectivityResult.none)) {
  // tidak ada jaringan sama sekali
}

// 2. Stream: dipanggil setiap jenis koneksi berubah
final sub = connectivity.onConnectivityChanged.listen((hasil) {
  // contoh isi: [ConnectivityResult.wifi] atau
  // [ConnectivityResult.wifi, ConnectivityResult.vpn]
});
// ... saat tidak dipakai lagi (misalnya di dispose):
await sub.cancel();

Kenapa List? HP bisa memakai beberapa antarmuka sekaligus, misalnya WiFi dan VPN. Daftar ini tidak pernah kosong. Jika tidak ada jaringan sama sekali, isinya tepat satu elemen ConnectivityResult.none, dan itu satu-satunya keadaan saat none muncul. Nilai lain yang mungkin: wifi, mobile, ethernet, vpn, bluetooth, satellite, dan other.

⚠️ Kode lama: result == ConnectivityResult.wifi

Tutorial lama (sebelum package ini mengembalikan List) menulis if (result == ConnectivityResult.none). Di versi sekarang, perbandingan itu membandingkan List dengan enum sehingga hasilnya selalu false: aplikasi tidak pernah merasa offline. Selalu gunakan hasil.contains(...).

"Terhubung WiFi" belum tentu "ada internet"

connectivity_plus hanya melihat status radio. Dokumentasinya sendiri mengingatkan: jangan memakai hasil ini untuk memutuskan apakah request jaringan pasti berhasil. Contoh keadaan yang membuatnya "berbohong":

  • WiFi kampus yang belum login ke portal (captive portal): status wifi, tetapi semua request diarahkan ke halaman login.
  • Router menyala tetapi kabel internet dari penyedia layanan putus.
  • Kuota data habis: status mobile, tetapi tidak ada data yang lewat.

Karena itu, setelah status berubah menjadi "ada jaringan", kita lakukan cek internet ringan: lookup DNS ke sebuah domain dengan batas waktu. Lookup tidak mengunduh halaman, sehingga hemat kuota.

/// Mengecek apakah internet benar-benar bisa dipakai.
/// Lookup DNS ringan dengan batas waktu 5 detik.
Future<bool> cekInternet() async {
  try {
    final hasil = await InternetAddress.lookup('example.com')
        .timeout(const Duration(seconds: 5));
    return hasil.isNotEmpty && hasil.first.rawAddress.isNotEmpty;
  } on SocketException {
    return false;
  } on TimeoutException {
    return false;
  }
}

Di proyek sungguhan, ganti example.com dengan domain server Anda sendiri (misalnya domain proyek Supabase). Yang penting bagi pengguna adalah "server saya bisa dihubungi", bukan "internet secara umum hidup".

Contoh lengkap: halaman status jaringan

📄 lib/main.dart

import 'dart:async';
import 'dart:io';

import 'package:connectivity_plus/connectivity_plus.dart';
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const StatusJaringanPage(),
    );
  }
}

class StatusJaringanPage extends StatefulWidget {
  const StatusJaringanPage({super.key});

  @override
  State<StatusJaringanPage> createState() => _StatusJaringanPageState();
}

class _StatusJaringanPageState extends State<StatusJaringanPage> {
  final Connectivity _connectivity = Connectivity();
  StreamSubscription<List<ConnectivityResult>>? _subscription;

  List<ConnectivityResult> _jenis = [ConnectivityResult.none];
  bool? _adaInternet; // null = belum dicek
  bool _sedangCek = false;

  @override
  void initState() {
    super.initState();
    _muatAwal();
    // Dengarkan setiap perubahan (WiFi mati, data seluler nyala, dll.)
    _subscription = _connectivity.onConnectivityChanged.listen(_saatBerubah);
  }

  Future<void> _muatAwal() async {
    final hasil = await _connectivity.checkConnectivity();
    if (!mounted) return;
    await _saatBerubah(hasil);
  }

  Future<void> _saatBerubah(List<ConnectivityResult> hasil) async {
    setState(() {
      _jenis = hasil;
      _sedangCek = true;
    });
    final internet = hasil.contains(ConnectivityResult.none)
        ? false
        : await cekInternet();
    if (!mounted) return;
    setState(() {
      _adaInternet = internet;
      _sedangCek = false;
    });
  }

  @override
  void dispose() {
    _subscription?.cancel(); // wajib: hentikan stream saat halaman ditutup
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final skema = Theme.of(context).colorScheme;
    final online = _adaInternet ?? false;

    return Scaffold(
      appBar: AppBar(title: const Text('Status Jaringan')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Card(
            color: online
                ? skema.primaryContainer
                : skema.errorContainer.withValues(alpha: 0.8),
            child: ListTile(
              leading: Icon(online ? Icons.cloud_done : Icons.cloud_off),
              title: Text(
                _sedangCek
                    ? 'Memeriksa internet...'
                    : online
                    ? 'Internet tersedia'
                    : 'Tidak ada internet',
              ),
              subtitle: Text('Jenis koneksi: ${_jenis.map(_label).join(', ')}'),
            ),
          ),
          const SizedBox(height: 12),
          FilledButton.icon(
            onPressed: _sedangCek ? null : _muatAwal,
            icon: const Icon(Icons.refresh),
            label: const Text('Periksa ulang'),
          ),
        ],
      ),
    );
  }

  String _label(ConnectivityResult r) {
    return switch (r) {
      ConnectivityResult.wifi => 'WiFi',
      ConnectivityResult.mobile => 'Data seluler',
      ConnectivityResult.ethernet => 'Ethernet',
      ConnectivityResult.vpn => 'VPN',
      ConnectivityResult.bluetooth => 'Bluetooth',
      ConnectivityResult.satellite => 'Satelit',
      ConnectivityResult.other => 'Lainnya',
      ConnectivityResult.none => 'Tidak ada',
    };
  }
}

/// Mengecek apakah internet benar-benar bisa dipakai.
/// Lookup DNS ringan dengan batas waktu 5 detik.
Future<bool> cekInternet() async {
  try {
    final hasil = await InternetAddress.lookup('example.com')
        .timeout(const Duration(seconds: 5));
    return hasil.isNotEmpty && hasil.first.rawAddress.isNotEmpty;
  } on SocketException {
    return false;
  } on TimeoutException {
    return false;
  }
}

Penjelasan baris penting

  • StreamSubscription<List<ConnectivityResult>>? _subscription disimpan agar bisa dibatalkan di dispose(). Tanpa cancel(), listener tetap hidup setelah halaman ditutup dan memanggil setState pada State yang sudah dibuang.
  • _muatAwal() memanggil checkConnectivity() sekali di awal, karena stream belum tentu langsung memancarkan nilai saat halaman dibuka.
  • if (!mounted) return; muncul setelah setiap await. Cek internet bisa makan waktu sampai 5 detik. Kalau pengguna sudah keluar dari halaman, setState tidak boleh dipanggil.
  • hasil.contains(ConnectivityResult.none) ? false : await cekInternet(): jika radio saja sudah mati, tidak perlu lookup.
  • switch pada enum tanpa default: jika suatu hari package menambah nilai baru, analyzer akan memperingatkan bahwa switch belum lengkap.

Mencoba di emulator

Bagian ini bisa diuji di Android Emulator. Jalankan aplikasi, lalu tarik panel notifikasi emulator dan nyalakan Airplane mode: kartu berubah menjadi "Tidak ada internet". Matikan lagi, dan setelah beberapa detik kartu kembali hijau. Di Extended Controls (tombol ...) bagian Cellular, Anda juga bisa mengubah Data status untuk mensimulasikan data seluler terputus.

💡 Kapan memakai connectivity_plus?

Pakai status konektivitas untuk UX: menampilkan banner offline, menonaktifkan tombol yang butuh internet, dan memicu muat ulang saat online kembali. Untuk kebenaran data, tetap andalkan hasil request itu sendiri (berhasil, gagal, atau timeout), seperti pola network first, cache fallback di Modul 14.
