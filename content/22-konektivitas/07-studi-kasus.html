Laboratorium jurusan punya beberapa sensor BLE (termometer ruang, papan ESP32 praktikum, gelang detak jantung). Asisten lab ingin aplikasi sederhana untuk memindai perangkat di sekitar, melihat kekuatan sinyalnya, menghubungkan salah satu perangkat, melihat daftar service dan characteristic-nya, dan membaca level baterai (characteristic 0x2A19) bila perangkat menyediakannya. Aplikasi juga menampilkan banner saat HP offline. Kita bangun dengan pola GetX MVC.

Fitur

  • Meminta izin sesuai versi Android, dengan penanganan ditolak dan ditolak permanen (tombol ke Pengaturan).
  • Memantau status adapter Bluetooth dan menawarkan tombol "Nyalakan" (Android).
  • Scan 10 detik, daftar diurutkan dari sinyal terkuat, filter "hanya yang bernama".
  • Halaman detail: connect, discover services, baca baterai, berlangganan notify baterai, dan otomatis disconnect saat halaman ditutup.
  • Banner offline dari bagian 6.

/// Perangkat hasil scan. Model murni, tidak bergantung pada plugin.
class PerangkatBle {
  const PerangkatBle({
    required this.id,
    required this.nama,
    required this.rssi,
    required this.bisaDihubungkan,
  });

  final String id; // MAC (Android) atau UUID acak (iOS)
  final String nama;
  final int rssi; // dBm, makin mendekati 0 makin dekat
  final bool bisaDihubungkan;

  bool get punyaNama => nama.isNotEmpty;

  /// Perkiraan kasar kekuatan sinyal untuk ditampilkan ke pengguna.
  String get labelSinyal {
    if (rssi >= -60) return 'Sangat dekat';
    if (rssi >= -75) return 'Dekat';
    if (rssi >= -90) return 'Jauh';
    return 'Sangat jauh';
  }
}

class KarakteristikBle {
  const KarakteristikBle({
    required this.uuid,
    required this.bisaBaca,
    required this.bisaTulis,
    required this.bisaNotify,
  });

  final String uuid;
  final bool bisaBaca;
  final bool bisaTulis;
  final bool bisaNotify;

import 'dart:io';

import 'package:device_info_plus/device_info_plus.dart';
import 'package:permission_handler/permission_handler.dart';

enum HasilIzin { diberikan, ditolak, ditolakPermanen }

class IzinBluetoothService {
  Future<HasilIzin> minta() async {
    // iOS: dialog izin muncul otomatis, status ditolak terbaca dari adapterState
    if (!Platform.isAndroid) return HasilIzin.diberikan;

    final android = await DeviceInfoPlugin().androidInfo;
    final daftarIzin = android.version.sdkInt >= 31
        ? [Permission.bluetoothScan, Permission.bluetoothConnect]
        : [Permission.locationWhenInUse];

    final hasil = await daftarIzin.request();
    final semuaStatus = hasil.values;
    if (semuaStatus.every((s) => s.isGranted)) return HasilIzin.diberikan;
    if (semuaStatus.any((s) => s.isPermanentlyDenied)) {
      return HasilIzin.ditolakPermanen;
    }
    return HasilIzin.ditolak;
  }

  Future<bool> bukaPengaturan() => openAppSettings();
}

Service BLE

📄 lib/services/ble_service.dart

import 'dart:io';

import 'package:flutter_blue_plus/flutter_blue_plus.dart';

import '../models/perangkat_ble.dart';

enum StatusAdapter { nyala, mati, tidakDiizinkan, tidakTersedia, menunggu }

/// Satu-satunya kelas yang menyentuh flutter_blue_plus.
class BleService {
  static final Guid _batteryService = Guid('180F');
  static final Guid _batteryLevel = Guid('2A19');

  Future<bool> get didukung => FlutterBluePlus.isSupported;

  Stream<StatusAdapter> get statusAdapter => FlutterBluePlus.adapterState.map(
    (s) => switch (s) {
      BluetoothAdapterState.on => StatusAdapter.nyala,
      BluetoothAdapterState.off ||
      BluetoothAdapterState.turningOff => StatusAdapter.mati,
      BluetoothAdapterState.unauthorized => StatusAdapter.tidakDiizinkan,
      BluetoothAdapterState.unavailable => StatusAdapter.tidakTersedia,
      BluetoothAdapterState.unknown ||
      BluetoothAdapterState.turningOn => StatusAdapter.menunggu,
    },
  );

  /// Hanya Android. Di iOS pengguna harus menyalakan sendiri.
  Future<void> nyalakan() async {
    if (Platform.isAndroid) await FlutterBluePlus.turnOn();
  }

  Stream<bool> get sedangScan => FlutterBluePlus.isScanning;

  Stream<List<PerangkatBle>> get hasilScan => FlutterBluePlus.scanResults.map(
    (daftar) => daftar
        .map(
          (r) => PerangkatBle(
            id: r.device.remoteId.str,
            nama: r.advertisementData.advName.isNotEmpty
                ? r.advertisementData.advName
                : r.device.platformName,
            rssi: r.rssi,
            bisaDihubungkan: r.advertisementData.connectable,
          ),
        )
        .toList(),
  );

  Future<void> mulaiScan(Duration durasi) =>
      FlutterBluePlus.startScan(timeout: durasi);

  Future<void> hentikanScan() => FlutterBluePlus.stopScan();

  Stream<bool> terhubung(String id) =>
      BluetoothDevice.fromId(id).connectionState
          .map((s) => s == BluetoothConnectionState.connected);

  Future<void> hubungkan(String id) async {
    await FlutterBluePlus.stopScan();
    await BluetoothDevice.fromId(id).connect(
      license: License.nonprofit, // penggunaan pendidikan (lihat bagian 4)
      timeout: const Duration(seconds: 15),
    );
  }

  Future<List<LayananBle>> jelajahi(String id) async {
    final services = await BluetoothDevice.fromId(id).discoverServices();
    return services
        .map(
          (s) => LayananBle(
            uuid: s.uuid.str,
            karakteristik: s.characteristics
                .map(
                  (c) => KarakteristikBle(
                    uuid: c.uuid.str,
                    bisaBaca: c.properties.read,
                    bisaTulis:
                        c.properties.write || c.properties.writeWithoutResponse,
                    bisaNotify: c.properties.notify || c.properties.indicate,
                  ),
                )
                .toList(),
          ),
        )
        .toList();
  }

  /// Characteristic Battery Level, atau null jika perangkat tidak punya.
  /// Harus dipanggil setelah [jelajahi].
  BluetoothCharacteristic? _karakteristikBaterai(String id) {
    for (final s in BluetoothDevice.fromId(id).servicesList) {
      if (s.uuid != _batteryService) continue;
      for (final c in s.characteristics) {
        if (c.uuid == _batteryLevel) return c;
      }
    }
    return null;
  }

  bool punyaBaterai(String id) => _karakteristikBaterai(id) != null;

  Future<int?> bacaBaterai(String id) async {
    final c = _karakteristikBaterai(id);
    if (c == null || !c.properties.read) return null;
    final nilai = await c.read();
    return nilai.isEmpty ? null : nilai.first; // 1 byte: 0..100
  }

  /// Stream persen baterai dari notifikasi, atau null jika tidak didukung.
  Future<Stream<int>?> pantauBaterai(String id) async {
    final c = _karakteristikBaterai(id);
    if (c == null || !c.properties.notify) return null;
    await c.setNotifyValue(true);
    return c.onValueReceived.where((v) => v.isNotEmpty).map((v) => v.first);
  }

  Future<void> putuskan(String id) => BluetoothDevice.fromId(id).disconnect();
}
  • StatusAdapter menerjemahkan tujuh nilai BluetoothAdapterState menjadi lima keadaan yang relevan bagi UI. switch expression tanpa default memaksa semua nilai ditangani.
  • BluetoothDevice.fromId(id) membuat objek perangkat dari remoteId. Service cukup menyimpan id (String), bukan objek plugin.
  • hasilScan memakai advName, atau platformName sebagai cadangan (nama yang diingat sistem, misalnya dari pairing sebelumnya).
  • _karakteristikBaterai mencari di servicesList, yaitu hasil discoverServices() terakhir. Karena itu jelajahi() harus dipanggil lebih dulu.
  • pantauBaterai mengembalikan null jika characteristic tidak mendukung notify. Banyak perangkat hanya mendukung READ untuk baterai.

Controller pemindai

📄 lib/controllers/ble_controller.dart

import 'dart:async';

import 'package:get/get.dart';

import '../models/perangkat_ble.dart';
import '../services/ble_service.dart';
import '../services/izin_bluetooth_service.dart';

class BleController extends GetxController {
  BleController(this._ble, this._izin);

  final BleService _ble;
  final IzinBluetoothService _izin;

  final _adapter = StatusAdapter.menunggu.obs;
  final _sedangScan = false.obs;
  final _hasil = <PerangkatBle>[].obs;
  final _hanyaBernama = true.obs;
  final _pesan = RxnString();
  final _izinDitolakPermanen = false.obs;
  final _didukung = true.obs;

  StatusAdapter get adapter => _adapter.value;
  bool get sedangScan => _sedangScan.value;
  bool get hanyaBernama => _hanyaBernama.value;
  String? get pesan => _pesan.value;
  bool get izinDitolakPermanen => _izinDitolakPermanen.value;
  bool get didukung => _didukung.value;

  /// Daftar yang tampil: difilter lalu diurutkan dari sinyal terkuat.
  List<PerangkatBle> get perangkat {
    final daftar = _hasil
        .where((p) => !_hanyaBernama.value || p.punyaNama)
        .toList();
    daftar.sort((a, b) => b.rssi.compareTo(a.rssi));
    return daftar;
  }

  final List<StreamSubscription<dynamic>> _subs = [];

  @override
  void onInit() {
    super.onInit();
    _cekDukungan();
    _subs.add(_ble.statusAdapter.listen((s) => _adapter.value = s));
    _subs.add(_ble.sedangScan.listen((s) => _sedangScan.value = s));
    _subs.add(_ble.hasilScan.listen(_hasil.assignAll));
  }

  Future<void> _cekDukungan() async {
    _didukung.value = await _ble.didukung;
    if (!_didukung.value) {
      _pesan.value =
          'HP ini tidak mendukung Bluetooth LE. '
          'Emulator juga tidak punya Bluetooth: pakai HP fisik.';
    }
  }

  void setHanyaBernama(bool nilai) => _hanyaBernama.value = nilai;

  Future<void> mulaiScan() async {
    _pesan.value = null;
    _izinDitolakPermanen.value = false;

    // 1. Izin
    final izin = await _izin.minta();
    if (izin == HasilIzin.ditolakPermanen) {
      _izinDitolakPermanen.value = true;
      _pesan.value =
          'Izin Perangkat di sekitar ditolak permanen. '
          'Aktifkan lewat pengaturan aplikasi.';
      return;
    }
    if (izin == HasilIzin.ditolak) {
      _pesan.value = 'Izin dibutuhkan untuk memindai perangkat di lab.';
      return;
    }

    // 2. Adapter harus menyala
    if (_adapter.value != StatusAdapter.nyala) {
      _pesan.value = 'Nyalakan Bluetooth terlebih dahulu.';
      return;
    }

    // 3. Scan dengan batas waktu agar baterai tidak terkuras
    try {
      await _ble.mulaiScan(const Duration(seconds: 10));
    } catch (e) {
      _pesan.value = 'Gagal memulai scan: $e';
    }
  }

  Future<void> hentikanScan() => _ble.hentikanScan();

  Future<void> nyalakanBluetooth() async {
    try {
      await _ble.nyalakan();
    } catch (_) {
      _pesan.value = 'Bluetooth tidak dinyalakan.';
    }
  }

  Future<void> bukaPengaturan() => _izin.bukaPengaturan();

  @override
  void onClose() {
    for (final s in _subs) {
      s.cancel();
    }
    _ble.hentikanScan();
    super.onClose();
  }
}
  • Urutan di mulaiScan(): izin → adapter → scan. Setiap kegagalan menghasilkan pesan yang jelas, bukan scan yang diam-diam tidak menemukan apa-apa.
  • _subs mengumpulkan tiga StreamSubscription agar mudah dibatalkan bersamaan di onClose().
  • perangkat adalah getter turunan: filter dan urutan dihitung dari _hasil dan _hanyaBernama. Obx yang membacanya otomatis dibangun ulang saat salah satu berubah.
  • Controller tidak mengimpor material.dart maupun flutter_blue_plus.

Controller detail perangkat

📄 lib/controllers/detail_perangkat_controller.dart

import 'dart:async';

import 'package:get/get.dart';

import '../models/perangkat_ble.dart';
import '../services/ble_service.dart';

enum StatusKoneksi { menghubungkan, terhubung, terputus, gagal }

class DetailPerangkatController extends GetxController {
  DetailPerangkatController(this._ble, this.perangkat);

  final BleService _ble;
  final PerangkatBle perangkat;

  final _status = StatusKoneksi.menghubungkan.obs;
  final _layanan = <LayananBle>[].obs;
  final _baterai = RxnInt();
  final _punyaBaterai = false.obs;
  final _pesan = RxnString();

  StatusKoneksi get status => _status.value;
  List<LayananBle> get layanan => _layanan;
  int? get baterai => _baterai.value;
  bool get punyaBaterai => _punyaBaterai.value;
  String? get pesan => _pesan.value;

  StreamSubscription<bool>? _koneksiSub;
  StreamSubscription<int>? _bateraiSub;

  @override
  void onInit() {
    super.onInit();
    _koneksiSub = _ble.terhubung(perangkat.id).listen((ya) {
      if (!ya && _status.value == StatusKoneksi.terhubung) {
        _status.value = StatusKoneksi.terputus;
        _bateraiSub?.cancel();
      }
    });
    hubungkan();
  }

  Future<void> hubungkan() async {
    _status.value = StatusKoneksi.menghubungkan;
    _pesan.value = null;
    try {
      await _ble.hubungkan(perangkat.id);
      _layanan.assignAll(await _ble.jelajahi(perangkat.id));
      _status.value = StatusKoneksi.terhubung;
      _punyaBaterai.value = _ble.punyaBaterai(perangkat.id);
      if (_punyaBaterai.value) await _siapkanBaterai();
    } catch (e) {
      _status.value = StatusKoneksi.gagal;
      _pesan.value = 'Gagal terhubung: $e';
    }
  }

  Future<void> _siapkanBaterai() async {
    _baterai.value = await _ble.bacaBaterai(perangkat.id);
    final stream = await _ble.pantauBaterai(perangkat.id);
    await _bateraiSub?.cancel();
    _bateraiSub = stream?.listen((persen) => _baterai.value = persen);
  }

  Future<void> bacaUlangBaterai() async {
    try {
      _baterai.value = await _ble.bacaBaterai(perangkat.id);
    } catch (e) {
      _pesan.value = 'Gagal membaca baterai: $e';
    }
  }

  @override
  void onClose() {
    _koneksiSub?.cancel();
    _bateraiSub?.cancel();
    _ble.putuskan(perangkat.id); // selalu putuskan saat halaman ditutup
    super.onClose();
  }
}
  • Satu controller per halaman detail. Controller didaftarkan lewat binding saat Get.to (Modul 08), sehingga GetX menghapusnya saat halaman ditutup dan onClose() terpanggil. Di sanalah putuskan() dijalankan. Pengguna tidak perlu menekan tombol disconnect, dan koneksi tidak tertinggal.
  • _koneksiSub mendeteksi perangkat yang terputus sendiri (keluar jangkauan, dimatikan) dan mengubah status menjadi terputus, sehingga View menampilkan tombol "Hubungkan lagi".
  • _siapkanBaterai() membaca sekali (agar langsung tampil), lalu berlangganan notify bila didukung. Subscription lama dibatalkan dulu agar tidak dobel saat menyambung ulang.

import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/ble_controller.dart';
import '../controllers/detail_perangkat_controller.dart';
import '../models/perangkat_ble.dart';

class PemindaiView extends GetView<BleController> {
  const PemindaiView({super.key});

  void _buka(PerangkatBle p) {
    Get.to(
      () => const DetailPerangkatView(),
      binding: BindingsBuilder(() {
        Get.put(DetailPerangkatController(Get.find<BleService>(), p));
      }),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Pemindai BLE Lab'),
        actions: [
          Obx(
            () => Switch(
              value: controller.hanyaBernama,
              onChanged: controller.setHanyaBernama,
            ),
          ),
          const Padding(
            padding: EdgeInsets.only(right: 12),
            child: Center(child: Text('Bernama')),
          ),
        ],
      ),
      body: Column(
        children: [
          const BannerOffline(),
          Obx(() => _bannerAdapter(context)),
          Obx(() => _bannerPesan(context)),
          Obx(
            () => controller.sedangScan
                ? const LinearProgressIndicator()
                : const SizedBox(height: 4),
          ),
          Expanded(
            child: Obx(() {
              final daftar = controller.perangkat;
              if (daftar.isEmpty) {
                return const Center(
                  child: Text('Tekan "Scan" untuk mencari perangkat di lab'),
                );
              }
              return ListView.separated(
                itemCount: daftar.length,
                separatorBuilder: (_, _) => const Divider(height: 1),
                itemBuilder: (context, i) => _ItemPerangkat(
                  perangkat: daftar[i],
                  onTap: daftar[i].bisaDihubungkan
                      ? () => _buka(daftar[i])
                      : null,
                ),
              );
            }),
          ),
        ],
      ),
      floatingActionButton: Obx(
        () => FloatingActionButton.extended(
          onPressed: !controller.didukung
              ? null
              : controller.sedangScan
              ? controller.hentikanScan
              : controller.mulaiScan,
          icon: Icon(controller.sedangScan ? Icons.stop : Icons.radar),
          label: Text(controller.sedangScan ? 'Berhenti' : 'Scan'),
        ),
      ),
    );
  }

  Widget _bannerAdapter(BuildContext context) {
    if (controller.adapter == StatusAdapter.nyala) {
      return const SizedBox.shrink();
    }
    final teks = switch (controller.adapter) {
      StatusAdapter.mati => 'Bluetooth mati.',
      StatusAdapter.tidakDiizinkan =>
        'Aplikasi belum diizinkan memakai Bluetooth.',
      StatusAdapter.tidakTersedia =>
        'Bluetooth tidak tersedia di perangkat ini.',
      _ => 'Memeriksa Bluetooth...',
    };
    return MaterialBanner(
      leading: const Icon(Icons.bluetooth_disabled),
      content: Text(teks),
      actions: [
        if (controller.adapter == StatusAdapter.mati)
          TextButton(
            onPressed: controller.nyalakanBluetooth,
            child: const Text('Nyalakan'),
          )
        else
          const SizedBox.shrink(),
      ],
    );
  }

  Widget _bannerPesan(BuildContext context) {
    final pesan = controller.pesan;
    if (pesan == null) return const SizedBox.shrink();
    return ListTile(
      leading: const Icon(Icons.info_outline),
      title: Text(pesan),
      trailing: controller.izinDitolakPermanen
          ? TextButton(
              onPressed: controller.bukaPengaturan,
              child: const Text('Pengaturan'),
            )
          : null,
    );
  }
}

class _ItemPerangkat extends StatelessWidget {
  const _ItemPerangkat({required this.perangkat, this.onTap});

  final VoidCallback? onTap;

  @override
  Widget build(BuildContext context) {
    final skema = Theme.of(context).colorScheme;
    return ListTile(
      enabled: onTap != null,
      onTap: onTap,
      leading: CircleAvatar(

        child: const Icon(Icons.bluetooth),

      title: Text(perangkat.punyaNama ? perangkat.nama : '(tanpa nama)'),

      isThreeLine: true,
      trailing: Text(
        '${perangkat.rssi} dBm',
        style: Theme.of(context).textTheme.labelLarge,
      ),
    );
  }
}

                ? IconButton(
                    icon: const Icon(Icons.refresh),
                    onPressed: controller.bacaUlangBaterai,
                  )
                : null,
          ),
        ),
        const SizedBox(height: 12),
        Text('Service & characteristic', style: teks.titleMedium),
        for (final s in controller.layanan)
          ExpansionTile(
            title: Text('Service ${s.uuid}'),
            children: [
              for (final c in s.karakteristik)
                ListTile(
                  dense: true,
                  title: Text(c.uuid),
                  subtitle: Text(
                    [
                      if (c.bisaBaca) 'READ',
                      if (c.bisaTulis) 'WRITE',
                      if (c.bisaNotify) 'NOTIFY',
                    ].join(' · '),
                  ),
                ),
            ],
          ),
      ],
    );
  }
}

void main() {
  WidgetsFlutterBinding.ensureInitialized();

  // Service (lapisan paling bawah)
  final bleService = Get.put(BleService(), permanent: true);

  // Controller global
  Get.put(NetworkController(ConnectivityService()), permanent: true);
  Get.put(BleController(bleService, IzinBluetoothService()), permanent: true);

  runApp(const PemindaiLabApp());
}

class PemindaiLabApp extends StatelessWidget {

}

BleService didaftarkan ke GetX dengan Get.put agar binding halaman detail bisa mengambilnya dengan Get.find<BleService>(). Semua dependensi dibuat dari lapisan bawah ke atas: service dulu, baru controller.

Alur uji di lab

  1. Jalankan di HP fisik dengan flutter run. Tekan Scan: dialog "Perangkat di sekitar" muncul. Pilih Izinkan.
  2. Matikan Bluetooth dari panel cepat: banner "Bluetooth mati" muncul dengan tombol Nyalakan.
  3. Siapkan HP kedua dengan nRF Connect sebagai peripheral yang punya Battery Service (lihat bagian 8). Perangkat tersebut muncul di daftar beserta RSSI-nya. Dekatkan dan jauhkan HP, lalu scan ulang untuk melihat RSSI berubah.
  4. Ketuk perangkat: status "menghubungkan", lalu daftar service tampil dan kartu Battery Level menunjukkan persen. Ubah nilai baterai di nRF Connect: jika notify aktif, angka di aplikasi ikut berubah.
  5. Tekan tombol kembali, lalu periksa di nRF Connect bahwa koneksi sudah terputus.
  6. Tolak izin dua kali (atau pilih "Jangan izinkan" lalu ulangi): pesan ditolak permanen dan tombol Pengaturan muncul.
  7. Nyalakan mode pesawat: banner offline muncul. Bluetooth bisa tetap dinyalakan saat mode pesawat, jadi scan masih berjalan. Ini bukti bahwa BLE tidak butuh internet.
