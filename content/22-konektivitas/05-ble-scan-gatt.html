Dengan izin dan adapter siap, alur kerja BLE selalu sama: scan → pilih perangkat → connect → discoverServices → read / write / notify characteristic → disconnect. Di section ini kita mencoba setiap langkah, mulai dari layar scan sederhana.

Scan: menemukan perangkat di sekitar

// Hasil scan (daftar lengkap, diperbarui terus selama scan)
final hasilSub = FlutterBluePlus.scanResults.listen((hasil) {
  for (final r in hasil) {
    debugPrint(
      '${r.device.remoteId} "${r.advertisementData.advName}" ${r.rssi}',
    );
  }
});

// Apakah sedang scan? (untuk menampilkan progress bar)
final scanningSub = FlutterBluePlus.isScanning.listen((sedang) {
  debugPrint('Sedang scan: $sedang');
});

// Mulai scan selama 10 detik, lalu berhenti sendiri
await FlutterBluePlus.startScan(timeout: const Duration(seconds: 10));

// Atau berhenti lebih awal
await FlutterBluePlus.stopScan();

// Saat halaman/controller ditutup
await hasilSub.cancel();
await scanningSub.cancel();

Setiap ScanResult berisi:

FieldIsi
device.remoteIdIdentitas perangkat. Di Android berupa alamat MAC, di iOS berupa UUID acak yang berbeda di setiap HP.
advertisementData.advNameNama yang disiarkan perangkat. Bisa kosong, karena tidak semua perangkat menyiarkan nama.
rssiKekuatan sinyal dalam dBm, selalu negatif. -50 berarti sangat dekat, -90 berarti jauh. Nilainya naik-turun karena pantulan dan halangan, jadi hanya perkiraan kasar jarak.
advertisementData.connectablefalse untuk perangkat yang hanya menyiarkan (misalnya beacon). Perangkat seperti ini tidak bisa di-connect.
advertisementData.serviceUuidsDaftar service yang diiklankan. Bisa dipakai untuk menyaring scan dengan startScan(withServices: [Guid('180F')]).

ℹ️ scanResults atau onScanResults?

scanResults langsung memancarkan hasil scan terakhir saat didengarkan, jadi cocok untuk layar daftar yang bisa dibuka-tutup. onScanResults hanya memancarkan hasil dari scan yang sedang berjalan, cocok untuk logika "tunggu sampai perangkat X ditemukan". Di modul ini kita memakai scanResults.

Contoh lengkap: layar scan

Pasang izin dan konfigurasi dari bagian 4 terlebih dahulu. Supaya contoh tetap pendek, izin di contoh ini diberikan manual: buka Setelan → Aplikasi → nama aplikasi → Izin → Perangkat di sekitar → Izinkan. Studi kasus di bagian 7 sudah meminta izin secara otomatis.

📄 lib/main.dart

import 'dart:async';

import 'package:flutter/material.dart';
import 'package:flutter_blue_plus/flutter_blue_plus.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const ScanPage(),
    );
  }
}

class ScanPage extends StatefulWidget {
  const ScanPage({super.key});

  @override
  State<ScanPage> createState() => _ScanPageState();
}

class _ScanPageState extends State<ScanPage> {
  StreamSubscription<BluetoothAdapterState>? _adapterSub;
  StreamSubscription<List<ScanResult>>? _hasilSub;
  StreamSubscription<bool>? _scanningSub;

  BluetoothAdapterState _adapter = BluetoothAdapterState.unknown;
  List<ScanResult> _hasil = [];
  bool _sedangScan = false;

  @override
  void initState() {
    super.initState();
    _adapterSub = FlutterBluePlus.adapterState.listen((state) {
      if (mounted) setState(() => _adapter = state);
    });
    _hasilSub = FlutterBluePlus.scanResults.listen((daftar) {
      // Urutkan dari sinyal terkuat (RSSI paling besar)
      final urut = [...daftar]..sort((a, b) => b.rssi.compareTo(a.rssi));
      if (mounted) setState(() => _hasil = urut);
    });
    _scanningSub = FlutterBluePlus.isScanning.listen((nilai) {
      if (mounted) setState(() => _sedangScan = nilai);
    });
  }

  Future<void> _mulaiScan() async {
    // Ingat: izin sudah harus diminta sebelum baris ini (lihat bagian 4)
    try {
      await FlutterBluePlus.startScan(timeout: const Duration(seconds: 10));
    } on FlutterBluePlusException catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(
        context,
      ).showSnackBar(SnackBar(content: Text('Gagal scan: ${e.description}')));
    }
  }

  @override
  void dispose() {
    _adapterSub?.cancel();
    _hasilSub?.cancel();
    _scanningSub?.cancel();
    FlutterBluePlus.stopScan();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final adapterNyala = _adapter == BluetoothAdapterState.on;

    return Scaffold(
      appBar: AppBar(title: const Text('Scan BLE')),
      body: Column(
        children: [
          if (!adapterNyala)
            MaterialBanner(
              content: Text('Bluetooth belum aktif (status: ${_adapter.name})'),
              actions: [
                TextButton(
                  onPressed: () async {
                    try {
                      await FlutterBluePlus.turnOn(); // Android saja
                    } on FlutterBluePlusException {
                      // pengguna menolak atau platform tidak mendukung
                    }
                  },
                  child: const Text('Nyalakan'),
                ),
              ],
            ),
          if (_sedangScan) const LinearProgressIndicator(),
          Expanded(
            child: _hasil.isEmpty
                ? const Center(child: Text('Belum ada perangkat ditemukan'))
                : ListView.builder(
                    itemCount: _hasil.length,
                    itemBuilder: (context, i) {
                      final r = _hasil[i];
                      final nama = r.advertisementData.advName.isNotEmpty
                          ? r.advertisementData.advName
                          : '(tanpa nama)';
                      return ListTile(
                        leading: const Icon(Icons.bluetooth),
                        title: Text(nama),
                        subtitle: Text(r.device.remoteId.str),
                        trailing: Text('${r.rssi} dBm'),
                      );
                    },
                  ),
          ),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: adapterNyala && !_sedangScan ? _mulaiScan : null,
        icon: const Icon(Icons.radar),
        label: Text(_sedangScan ? 'Memindai...' : 'Scan 10 detik'),
      ),
    );
  }
}
  • Tiga stream, tiga subscription, semuanya dibatalkan di dispose(). stopScan() juga dipanggil agar scan tidak berjalan terus setelah halaman ditutup.
  • timeout: const Duration(seconds: 10): scan menguras baterai dan Android membatasi aplikasi memanggil startScan paling banyak 5 kali per 30 detik. Selalu beri batas waktu dan jangan memanggil scan berulang dalam loop.
  • Hasil diurutkan berdasarkan RSSI agar perangkat terdekat muncul paling atas. Di lab yang penuh perangkat, ini sangat membantu.
  • MaterialBanner muncul jika adapter tidak on, dengan tombol yang memanggil turnOn().

Connect, discover, read, write, notify, disconnect

Potongan berikut memperlihatkan setiap operasi GATT pada sebuah BluetoothDevice (misalnya hasil.device dari scan). Contoh characteristic yang dipakai adalah Battery Level (UUID 2A19) di dalam Battery Service (180F), karena keduanya standar resmi Bluetooth SIG dan mudah disimulasikan.

import 'dart:async';

import 'package:flutter/foundation.dart';
import 'package:flutter_blue_plus/flutter_blue_plus.dart';

final Guid uuidBatteryService = Guid('180F');
final Guid uuidBatteryLevel = Guid('2A19');

Future<void> contohGatt(BluetoothDevice device) async {
  // 1. Pantau status koneksi
  final StreamSubscription<BluetoothConnectionState> koneksiSub = device
      .connectionState
      .listen((state) {
        debugPrint('Koneksi ${device.remoteId}: $state');
      });
  device.cancelWhenDisconnected(koneksiSub, delayed: true, next: true);

  // 2. Hubungkan (license wajib diisi sejak flutter_blue_plus 2.x)
  await FlutterBluePlus.stopScan(); // hentikan scan sebelum connect
  await device.connect(
    license: License.nonprofit,
    timeout: const Duration(seconds: 15),
  );

  // 3. Cari semua service dan characteristic
  final List<BluetoothService> services = await device.discoverServices();
  for (final s in services) {
    debugPrint('Service ${s.uuid}');
    for (final c in s.characteristics) {
      final p = c.properties;
      debugPrint(
        '  Char ${c.uuid} read=${p.read} write=${p.write} '
        'notify=${p.notify}',
      );
    }
  }

  // 4. Cari characteristic Battery Level (0x2A19)
  BluetoothCharacteristic? baterai;
  for (final s in services) {
    if (s.uuid != uuidBatteryService) continue;
    for (final c in s.characteristics) {
      if (c.uuid == uuidBatteryLevel) baterai = c;
    }
  }
  if (baterai == null) {
    debugPrint('Perangkat tidak punya Battery Service');
  } else {
    // 5. READ: hasilnya List<int> (byte). Battery level = 1 byte 0..100
    final List<int> nilai = await baterai.read();
    debugPrint('Baterai: ${nilai.isEmpty ? '-' : nilai.first}%');

    // 6. NOTIFY: berlangganan perubahan nilai
    if (baterai.properties.notify) {
      final StreamSubscription<List<int>> notifSub = baterai.onValueReceived
          .listen((v) {
            debugPrint('Notifikasi baterai: ${v.first}%');
          });
      device.cancelWhenDisconnected(notifSub); // dibatalkan otomatis
      await baterai.setNotifyValue(true);
    }
  }
}

Future<void> contohTulis(BluetoothCharacteristic c) async {
  // 7. WRITE: kirim byte. Cek dulu properti characteristic-nya.
  if (c.properties.write) {
    await c.write([0x01]); // dengan response (dikonfirmasi peripheral)
  } else if (c.properties.writeWithoutResponse) {
    await c.write([0x01], withoutResponse: true); // lebih cepat, tanpa ack
  }
}

Future<void> contohPutus(BluetoothDevice device) async {
  // 8. Putuskan koneksi saat selesai (hemat baterai kedua perangkat)
  await device.disconnect();
}

Penjelasan langkah demi langkah

  1. connectionState memberi tahu saat perangkat terputus (keluar jangkauan, baterai habis, atau dimatikan). cancelWhenDisconnected(sub, delayed: true, next: true) adalah bantuan dari package: subscription dibatalkan otomatis pada pemutusan berikutnya, sehingga tidak terjadi listener ganda saat menyambung ulang.
  2. connect(license: License.nonprofit, timeout: ...). Hentikan scan sebelum connect, karena sebagian HP gagal connect saat masih scan. Secara default package juga meminta MTU besar (512) setelah terhubung di Android, sehingga paket data bisa lebih panjang dari 20 byte.
  3. discoverServices() wajib dipanggil setelah setiap connect. Sebelum itu, daftar service kosong. Setelah dipanggil, hasilnya juga tersedia lewat device.servicesList.
  4. Membandingkan UUID dengan Guid: Guid('2A19') sama dengan Guid('00002a19-0000-1000-8000-00805f9b34fb'), jadi bentuk pendek aman dipakai. Jangan membandingkan toString() karena format huruf dan panjangnya bisa berbeda.
  5. read() mengembalikan List<int> berisi byte. Battery Level adalah 1 byte bernilai 0–100. Data lain perlu diterjemahkan sesuai spesifikasinya, misalnya suhu 2 byte little-endian dalam satuan 0,01 °C.
  6. onValueReceived + setNotifyValue(true): pasang listener dulu, baru nyalakan notify, supaya nilai pertama tidak terlewat. Package menulis descriptor CCCD (0x2902) untuk kita.
  7. write(): periksa properties dulu. Menulis ke characteristic yang hanya READ akan gagal. withoutResponse: true lebih cepat tetapi tidak ada konfirmasi.
  8. disconnect() saat selesai. Koneksi BLE yang dibiarkan menggantung menguras baterai kedua perangkat dan membuat perangkat itu tidak bisa dihubungi HP lain (banyak peripheral hanya menerima satu koneksi).

⚠️ Kesalahan umum

  • Memanggil read() sebelum discoverServices(): characteristic belum dikenal, muncul error. Setiap kali connect ulang, discover ulang.
  • Menyimpan objek BluetoothCharacteristic lama setelah reconnect: objek itu milik koneksi sebelumnya. Ambil ulang dari hasil discoverServices() yang baru.
  • Listener notify dipasang berkali-kali setiap kali tombol ditekan: nilai muncul dobel. Simpan subscription dan batalkan yang lama, atau pakai cancelWhenDisconnected.
  • Menganggap nama perangkat selalu ada: banyak perangkat tidak menyiarkan nama. Tampilkan remoteId sebagai cadangan.
