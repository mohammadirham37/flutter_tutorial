Named routes memberi setiap halaman sebuah nama seperti URL ('/detail'). Navigasi cukup menyebut nama, tanpa perlu meng-import class halaman tujuan di setiap file.

Cara 1: tabel routes (paling sederhana)

return MaterialApp(
  initialRoute: '/',
  routes: {
    '/': (context) => const BerandaScreen(),
    '/tentang': (context) => const TentangScreen(),
  },
);


// Di halaman mana pun:
onPressed: () => Navigator.pushNamed(context, '/tentang'),

Tabel routes cocok untuk halaman tanpa argumen. Kelemahannya: jika halaman butuh data, kita harus membaca ModalRoute.of(context)!.settings.arguments di dalam halaman, dan tidak ada penanganan nama rute yang salah.

Cara 2: onGenerateRoute (lebih aman)

onGenerateRoute adalah satu fungsi pusat yang dipanggil setiap kali pushNamed dijalankan. Di sana kita bisa memeriksa argumen dan membuat halaman error jika rute tidak dikenal.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class Mahasiswa {
  final String nim;
  final String nama;

  const Mahasiswa(this.nim, this.nama);
}

// Kumpulkan semua nama rute di satu tempat agar tidak salah ketik
class Rute {
  static const beranda = '/';
  static const detail = '/detail';
  static const tentang = '/tentang';
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      initialRoute: Rute.beranda,
      onGenerateRoute: generateRoute, // dipanggil setiap pushNamed
    );
  }
}

// Satu fungsi pusat yang menerjemahkan NAMA rute menjadi HALAMAN
Route<dynamic> generateRoute(RouteSettings settings) {
  switch (settings.name) {
    case Rute.beranda:
      return MaterialPageRoute(builder: (_) => const BerandaScreen());

    case Rute.detail:
      // arguments bertipe Object?, jadi WAJIB dicek tipenya
      final args = settings.arguments;
      if (args is Mahasiswa) {
        return MaterialPageRoute(
          settings: settings,
          builder: (_) => DetailScreen(mahasiswa: args),
        );
      }
      return _halamanError('Argumen untuk ${settings.name} tidak valid');

    case Rute.tentang:
      return MaterialPageRoute(builder: (_) => const TentangScreen());

    default:
      return _halamanError('Rute "${settings.name}" tidak ditemukan');
  }
}

// Halaman cadangan agar aplikasi tidak crash ketika rute salah
MaterialPageRoute<dynamic> _halamanError(String pesan) {
  return MaterialPageRoute(
    builder: (_) => Scaffold(
      appBar: AppBar(title: const Text('Oops')),
      body: Center(child: Text(pesan)),
    ),
  );
}

class BerandaScreen extends StatelessWidget {
  const BerandaScreen({super.key});

  static const data = [
    Mahasiswa('H1D023001', 'Andi Pratama'),
    Mahasiswa('H1D023002', 'Bunga Lestari'),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Beranda'),
        actions: [
          IconButton(
            icon: const Icon(Icons.info_outline),
            onPressed: () => Navigator.pushNamed(context, Rute.tentang),
          ),
        ],
      ),
      body: ListView(
        children: [
          for (final m in data)
            ListTile(
              title: Text(m.nama),
              subtitle: Text(m.nim),
              // Kirim argumen lewat parameter "arguments"
              onTap: () => Navigator.pushNamed(context, Rute.detail, arguments: m),
            ),
          ListTile(
            title: const Text('Coba rute yang salah'),
            textColor: Colors.red,
            onTap: () => Navigator.pushNamed(context, '/tidak-ada'),
          ),
        ],
      ),
    );
  }
}

class DetailScreen extends StatelessWidget {
  final Mahasiswa mahasiswa;

  const DetailScreen({super.key, required this.mahasiswa});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(mahasiswa.nama)),
      body: Center(child: Text('NIM: ${mahasiswa.nim}')),
    );
  }
}

class TentangScreen extends StatelessWidget {
  const TentangScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tentang')),
      body: const Center(child: Text('Contoh Named Routes + onGenerateRoute')),
    );
  }
}

Penjelasan:

  • Class Rute berisi konstanta nama rute. Salah ketik Rute.detial akan langsung ditandai merah oleh editor, sedangkan salah ketik string '/detial' baru ketahuan saat aplikasi jalan.
  • Navigator.pushNamed(context, Rute.detail, arguments: m) mengirim objek lewat settings.arguments.
  • Di generateRoute, if (args is Mahasiswa) memeriksa tipe sekaligus melakukan type promotion, sehingga args bisa langsung dipakai sebagai Mahasiswa.
  • Cabang default mengembalikan halaman error yang ramah, bukan crash.
  • Varian lain: pushReplacementNamed dan pushNamedAndRemoveUntil bekerja sama seperti versi tanpa nama.

💡 Named routes atau go_router?

Tim Flutter tidak lagi merekomendasikan named routes untuk aplikasi baru yang butuh deep link (membuka halaman tertentu dari URL/notifikasi). Untuk kebutuhan itu gunakan go_router (section 11). Namun named routes tetap penting dipahami karena banyak proyek lama memakainya.

⚠️ Kesalahan umum

  • Melakukan cast paksa settings.arguments as Mahasiswa tanpa cek. Jika argumen lupa dikirim, aplikasi crash.
  • Mengisi home sekaligus rute '/' di tabel routes. Flutter akan memberi error karena keduanya mendefinisikan halaman awal.
  • Lupa meneruskan settings ke MaterialPageRoute sehingga ModalRoute.of(context)?.settings.name bernilai null.
