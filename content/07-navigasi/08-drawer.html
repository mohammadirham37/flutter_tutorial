Drawer adalah panel menu yang muncul dari sisi kiri layar. Cocok untuk menu sekunder yang jumlahnya banyak (Jadwal, Transkrip, Pengaturan, Bantuan) dan tidak muat di NavigationBar.

Konsep

  • Pasang drawer di parameter drawer: milik Scaffold. AppBar otomatis menampilkan ikon hamburger (≡).
  • Drawer yang terbuka sebenarnya juga sebuah route di tumpukan. Karena itu, menutupnya cukup dengan Navigator.pop(context).
  • Saat memilih menu yang membuka halaman baru: tutup drawer dulu, baru push. Jika tidak, saat pengguna kembali, drawer masih terbuka.

Contoh lengkap: Drawer dengan header akun

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DashboardScreen(),
    );
  }
}

class DashboardScreen extends StatelessWidget {
  const DashboardScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // Ikon hamburger (≡) muncul otomatis di AppBar karena ada drawer
      appBar: AppBar(title: const Text('Dashboard')),
      drawer: const MenuDrawer(),
      body: const Center(child: Text('Geser dari kiri atau tekan ikon ≡')),
    );
  }
}

class MenuDrawer extends StatelessWidget {
  const MenuDrawer({super.key});

  // Tutup drawer DULU, baru buka halaman baru
  void _buka(BuildContext context, Widget halaman) {
    Navigator.pop(context); // menutup drawer (drawer juga sebuah rute!)
    Navigator.push(context, MaterialPageRoute(builder: (_) => halaman));
  }

  @override
  Widget build(BuildContext context) {
    return Drawer(
      child: ListView(
        padding: EdgeInsets.zero,
        children: [
          const UserAccountsDrawerHeader(
            accountName: Text('Rizky Maulana'),
            accountEmail: Text('rizky@mhs.unsoed.ac.id'),
            currentAccountPicture: CircleAvatar(child: Text('RM')),
          ),
          ListTile(
            leading: const Icon(Icons.schedule),
            title: const Text('Jadwal Kuliah'),
            onTap: () => _buka(context, const HalamanMenu(judul: 'Jadwal Kuliah')),
          ),
          ListTile(
            leading: const Icon(Icons.grade),
            title: const Text('Transkrip Nilai'),
            onTap: () => _buka(context, const HalamanMenu(judul: 'Transkrip Nilai')),
          ),
          const Divider(),
          ListTile(
            leading: const Icon(Icons.settings),
            title: const Text('Pengaturan'),
            onTap: () => _buka(context, const HalamanMenu(judul: 'Pengaturan')),
          ),
        ],
      ),
    );
  }
}

class HalamanMenu extends StatelessWidget {
  final String judul;

  const HalamanMenu({super.key, required this.judul});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(judul)),
      body: Center(child: Text('Isi halaman $judul')),
    );
  }
}
Drawer terbuka dengan header akun
Drawer ditutup lalu halaman baru di-push

Penjelasan:

  • UserAccountsDrawerHeader adalah header siap pakai dengan nama, email, dan foto profil.
  • ListView dengan padding: EdgeInsets.zero agar header menempel sampai atas layar.
  • Fungsi _buka memanggil pop (menutup drawer) lalu push halaman tujuan.

Alternatif Material 3: NavigationDrawer

Jika menu drawer dipakai untuk berganti "halaman utama" (seperti tab), gunakan NavigationDrawer yang punya penanda menu aktif bawaan:

// Alternatif Material 3: NavigationDrawer
drawer: NavigationDrawer(
  selectedIndex: _menu,
  onDestinationSelected: (i) {
    setState(() => _menu = i);
    Navigator.pop(context); // tutup drawer
  },
  children: const [
    Padding(
      padding: EdgeInsets.fromLTRB(28, 16, 16, 10),
      child: Text('Portal Akademik'),
    ),
    NavigationDrawerDestination(icon: Icon(Icons.home), label: Text('Beranda')),
    NavigationDrawerDestination(icon: Icon(Icons.grade), label: Text('Nilai')),
  ],
),

💡 Kapan pakai apa?

NavigationBar untuk 3–5 menu utama yang sering dipakai. Drawer untuk menu tambahan. Keduanya boleh dipakai bersamaan dalam satu Scaffold.

⚠️ Kesalahan umum

  • Menulis Scaffold.of(context).openDrawer() dengan context milik widget yang membuat Scaffold itu sendiri. Context tersebut berada di atas Scaffold, sehingga error. Bungkus tombol dengan Builder atau pisahkan menjadi widget sendiri.
  • Lupa menutup drawer sebelum push.
