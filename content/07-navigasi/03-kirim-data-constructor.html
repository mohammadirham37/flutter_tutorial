Cara paling sederhana dan paling aman untuk mengirim data ke halaman baru adalah lewat constructor. Halaman tujuan hanyalah sebuah class Dart, jadi data cukup dikirim sebagai argumen.

Pola dasarnya

// Halaman ASAL: kirim data lewat argumen constructor
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => const ProfilScreen(nama: 'Sinta', angkatan: 2023),
  ),
);


// Halaman TUJUAN: deklarasikan field final + parameter required
class ProfilScreen extends StatelessWidget {
  final String nama;
  final int angkatan;

  const ProfilScreen({super.key, required this.nama, required this.angkatan});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(nama)),
      body: Center(child: Text('Angkatan $angkatan')),
    );
  }
}
  • Field di halaman tujuan dibuat final karena data kiriman tidak berubah selama halaman tampil.
  • Parameter required membuat compiler protes jika kita lupa mengirim datanya. Kesalahan ketahuan sebelum aplikasi dijalankan.
  • Jika halaman tujuan berupa StatefulWidget, data dibaca di class State dengan widget.nama.

Contoh lengkap: daftar mata kuliah ke halaman detail

Daripada mengirim kode, nama, sks satu per satu, kirim satu objek model utuh.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

// Model data sederhana (idealnya di lib/models/mata_kuliah.dart)
class MataKuliah {
  final String kode;
  final String nama;
  final int sks;
  final String dosen;

  const MataKuliah({
    required this.kode,
    required this.nama,
    required this.sks,
    required this.dosen,
  });
}

const daftarMatkul = [
  MataKuliah(kode: 'IF201', nama: 'Pemrograman Mobile', sks: 3, dosen: 'Dr. Rina'),
  MataKuliah(kode: 'IF202', nama: 'Basis Data', sks: 3, dosen: 'Budi, M.Kom.'),
  MataKuliah(kode: 'IF203', nama: 'Jaringan Komputer', sks: 2, dosen: 'Sari, M.T.'),
  MataKuliah(kode: 'IF204', nama: 'Kecerdasan Buatan', sks: 3, dosen: 'Dr. Agus'),
];

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const DaftarMatkulScreen(),
    );
  }
}

class DaftarMatkulScreen extends StatelessWidget {
  const DaftarMatkulScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Mata Kuliah Semester 3')),
      body: ListView.builder(
        itemCount: daftarMatkul.length,
        itemBuilder: (context, index) {
          final mk = daftarMatkul[index];
          return ListTile(
            leading: CircleAvatar(child: Text('${mk.sks}')),
            title: Text(mk.nama),
            subtitle: Text(mk.kode),
            trailing: const Icon(Icons.chevron_right),
            onTap: () {
              // Kirim SATU objek utuh, bukan field satu per satu
              Navigator.push(
                context,
                MaterialPageRoute(
                  builder: (context) => DetailMatkulScreen(matkul: mk),
                ),
              );
            },
          );
        },
      ),
    );
  }
}

class DetailMatkulScreen extends StatelessWidget {
  // Data yang diterima dari halaman sebelumnya
  final MataKuliah matkul;

  const DetailMatkulScreen({super.key, required this.matkul});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(matkul.kode)),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(matkul.nama, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 8),
            Text('Bobot: ${matkul.sks} SKS'),
            Text('Dosen pengampu: ${matkul.dosen}'),
          ],
        ),
      ),
    );
  }
}

Penjelasan:

  • Class MataKuliah adalah model data. Di proyek nyata letakkan di lib/models/.
  • Di onTap, objek mk dikirim ke DetailMatkulScreen(matkul: mk).
  • Halaman detail tidak perlu tahu dari mana datanya berasal. Ia hanya menampilkan matkul yang diterima. Pemisahan ini membuat halaman mudah dipakai ulang dan diuji.

ℹ️ Constructor vs arguments

Selain constructor, Flutter juga punya RouteSettings.arguments (dipakai di named routes, section 6). Constructor lebih disarankan karena tipe datanya diperiksa compiler, sedangkan arguments bertipe Object? dan harus dicek manual.

⚠️ Kesalahan umum

  • Menyimpan data kiriman di variabel global agar "bisa diakses dari halaman lain". Ini membuat data sulit dilacak. Kirim lewat constructor, atau pakai Provider (Modul 08) untuk data yang dipakai banyak halaman.
  • Lupa menulis widget. saat membaca field di State: tulis widget.matkul.nama, bukan matkul.nama.
