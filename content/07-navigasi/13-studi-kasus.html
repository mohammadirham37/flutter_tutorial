Saatnya menggabungkan semua materi menjadi satu aplikasi Portal Akademik multi-halaman: login dengan pushReplacement, tab utama dengan NavigationBar + IndexedStack, detail mata kuliah yang menerima data lewat constructor dan mengembalikan hasil, dialog logout, pushAndRemoveUntil, serta PopScope.

Struktur folder

lib/
├── main.dart
├── models/
│   └── matkul.dart
├── data/
│   └── dummy_data.dart
└── screens/
    ├── login_screen.dart
    ├── main_screen.dart
    └── detail_matkul_screen.dart

Peta navigasi

LoginScreen --pushReplacement--> MainScreen (tab: Beranda | Mata Kuliah | Profil)
MainScreen  --push<bool>------> DetailMatkulScreen --pop(true)--> MainScreen
MainScreen  --showDialog<bool>--> konfirmasi --pushAndRemoveUntil--> LoginScreen

📄 lib/screens/login_screen.dart

// lib/screens/login_screen.dart
import 'package:flutter/material.dart';

import 'main_screen.dart';

class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State<LoginScreen> createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final _nimController = TextEditingController();

  @override
  void dispose() {
    _nimController.dispose();
    super.dispose();
  }

  void _login() {
    final nim = _nimController.text.trim();
    if (nim.isEmpty) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('NIM wajib diisi')),
      );
      return;
    }
    // Login sukses: ganti Login dengan MainScreen (tidak bisa back ke login)
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(builder: (_) => MainScreen(nim: nim)),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              const Icon(Icons.school, size: 80),
              const SizedBox(height: 16),
              Text('Portal Akademik', style: Theme.of(context).textTheme.headlineMedium),
              const SizedBox(height: 24),
              TextField(
                controller: _nimController,
                decoration: const InputDecoration(
                  labelText: 'NIM',
                  border: OutlineInputBorder(),
                ),
              ),
              const SizedBox(height: 16),
              SizedBox(
                width: double.infinity,
                child: FilledButton(onPressed: _login, child: const Text('Masuk')),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Langkah 4: halaman utama dengan tab

📄 lib/screens/main_screen.dart

// lib/screens/main_screen.dart
import 'package:flutter/material.dart';

import '../data/dummy_data.dart';
import '../models/matkul.dart';
import 'detail_matkul_screen.dart';
import 'login_screen.dart';

class MainScreen extends StatefulWidget {
  final String nim;

  const MainScreen({super.key, required this.nim});

  @override
  State<MainScreen> createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _tab = 0;
  final List<Matkul> _diambil = [];

  int get _totalSks => _diambil.fold(0, (total, m) => total + m.sks);

  // Buka detail, tunggu jawaban "ambil" (true) atau tidak
  Future<void> _bukaDetail(Matkul matkul) async {
    final ambil = await Navigator.push<bool>(
      context,
      MaterialPageRoute(
        builder: (_) => DetailMatkulScreen(
          matkul: matkul,
          sudahDiambil: _diambil.contains(matkul),
        ),
      ),
    );
    if (ambil != true || !mounted) return;
    setState(() => _diambil.add(matkul));
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        backgroundColor: Colors.green,
        content: Text('${matkul.nama} masuk KRS'),
      ),
    );
  }

  Future<void> _logout() async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Keluar dari akun?'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Logout'),
          ),
        ],
      ),
    );
    if (yakin != true || !mounted) return;
    // Bersihkan SELURUH tumpukan, sisakan Login saja
    Navigator.pushAndRemoveUntil(
      context,
      MaterialPageRoute(builder: (_) => const LoginScreen()),
      (route) => false,
    );
  }

  @override
  Widget build(BuildContext context) {
    final tabs = [
      _BerandaTab(nim: widget.nim, totalSks: _totalSks),
      _MatkulTab(diambil: _diambil, onTap: _bukaDetail),
      _ProfilTab(nim: widget.nim, onLogout: _logout),
    ];

    return PopScope(
      // Jika bukan di tab Beranda, tombol back kembali ke Beranda dulu
      canPop: _tab == 0,
      onPopInvokedWithResult: (didPop, result) {
        if (!didPop) setState(() => _tab = 0);
      },
      child: Scaffold(
        appBar: AppBar(title: const Text('Portal Akademik')),
        body: IndexedStack(index: _tab, children: tabs),
        bottomNavigationBar: NavigationBar(
          selectedIndex: _tab,
          onDestinationSelected: (i) => setState(() => _tab = i),
          destinations: [
            const NavigationDestination(icon: Icon(Icons.home), label: 'Beranda'),
            NavigationDestination(
              icon: Badge(
                isLabelVisible: _diambil.isNotEmpty,
                label: Text('${_diambil.length}'),
                child: const Icon(Icons.book),
              ),
              label: 'Mata Kuliah',
            ),
            const NavigationDestination(icon: Icon(Icons.person), label: 'Profil'),
          ],
        ),
      ),
    );
  }
}

class _BerandaTab extends StatelessWidget {
  final String nim;
  final int totalSks;

  const _BerandaTab({required this.nim, required this.totalSks});

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Text('Selamat datang, $nim'),
          const SizedBox(height: 8),
          Text('Total SKS diambil: $totalSks',
              style: Theme.of(context).textTheme.headlineSmall),
        ],
      ),
    );
  }
}

class _MatkulTab extends StatelessWidget {
  final List<Matkul> diambil;
  final ValueChanged<Matkul> onTap;

  const _MatkulTab({required this.diambil, required this.onTap});

  @override
  Widget build(BuildContext context) {
    return ListView(
      children: [
        for (final m in semuaMatkul)
          ListTile(
            title: Text(m.nama),
            subtitle: Text('${m.kode} • ${m.sks} SKS'),
            trailing: diambil.contains(m)
                ? const Icon(Icons.check_circle, color: Colors.green)
                : const Icon(Icons.chevron_right),
            onTap: () => onTap(m),
          ),
      ],
    );
  }
}

class _ProfilTab extends StatelessWidget {
  final String nim;
  final VoidCallback onLogout;

  const _ProfilTab({required this.nim, required this.onLogout});

  @override
  Widget build(BuildContext context) {
    return ListView(
      children: [
        ListTile(leading: const Icon(Icons.badge), title: const Text('NIM'), subtitle: Text(nim)),
        ListTile(
          leading: const Icon(Icons.logout, color: Colors.red),
          title: const Text('Logout'),
          onTap: onLogout,
        ),
      ],
    );
  }
}

// lib/screens/detail_matkul_screen.dart
import 'package:flutter/material.dart';

import '../models/matkul.dart';

class DetailMatkulScreen extends StatelessWidget {
  final Matkul matkul;
  final bool sudahDiambil;

  const DetailMatkulScreen({
    super.key,
    required this.matkul,
    required this.sudahDiambil,
  });

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(matkul.kode)),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(matkul.nama, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 8),
            Text('${matkul.sks} SKS • ${matkul.dosen}'),
            const SizedBox(height: 16),
            Text(matkul.deskripsi),
            const Spacer(),
            SizedBox(
              width: double.infinity,
              child: FilledButton.icon(
                icon: const Icon(Icons.add_task),
                label: Text(sudahDiambil ? 'Sudah di KRS' : 'Daftar Matkul Ini'),
                // null = tombol nonaktif
                onPressed: sudahDiambil ? null : () => Navigator.pop(context, true),
              ),
            ),
          ],
        ),
      ),
    );
  }
}

Penjelasan:

  • Login memakai pushReplacement, jadi tombol back di MainScreen tidak kembali ke login. NIM dikirim ke MainScreen lewat constructor.
  • MainScreen menyimpan daftar _diambil dan mengoper data serta callback ke tiap tab lewat constructor (_MatkulTab(diambil: ..., onTap: ...)).
  • Detail mengembalikan true saat tombol "Daftar Matkul Ini" ditekan. MainScreen menunggu hasil itu dengan await Navigator.push<bool>.
  • PopScope di MainScreen: jika pengguna sedang di tab selain Beranda, tombol back memindahkan ke Beranda dulu, bukan menutup aplikasi.
  • Logout meminta konfirmasi lewat dialog, lalu membersihkan tumpukan dengan pushAndRemoveUntil.

ℹ️ Menuju Modul 08

Perhatikan bahwa _diambil harus dioper dari MainScreen ke tab-tabnya lewat constructor dan callback. Bayangkan jika halaman detail, halaman ringkasan KRS, dan badge di AppBar semuanya butuh data yang sama: constructor akan penuh dengan parameter "titipan". Masalah ini disebut prop drilling, dan diselesaikan dengan Provider di modul berikutnya.

💡 Tantangan tambahan

  • Tambahkan tombol "Batalkan" di halaman detail jika mata kuliah sudah diambil, lalu kembalikan nilai false untuk menghapusnya dari _diambil.
  • Tambahkan Drawer berisi menu Tentang Aplikasi.
  • Ubah navigasi aplikasi ini menjadi go_router dengan rute /login, /, dan /matkul/:kode.
