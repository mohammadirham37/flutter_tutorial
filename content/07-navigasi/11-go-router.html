go_router adalah package routing resmi dari tim Flutter. Halaman diidentifikasi dengan URL (misalnya /matkul/IF201), sehingga mendukung deep link, tombol back browser di Flutter Web, dan auth guard terpusat.

Instalasi

flutter pub add go_router

Contoh kecil: rute dan path parameter

import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';

// 1) Definisikan semua rute di SATU objek GoRouter
final GoRouter router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const BerandaScreen(),
    ),
    GoRoute(
      path: '/mahasiswa/:nim', // :nim = path parameter
      builder: (context, state) {
        final nim = state.pathParameters['nim']!;
        return ProfilScreen(nim: nim);
      },
    ),
  ],
);

// 2) Pakai MaterialApp.router, bukan MaterialApp biasa
void main() => runApp(MaterialApp.router(routerConfig: router));


// 3) Pindah halaman dengan URL
onPressed: () => context.push('/mahasiswa/H1D023001'),
  • Semua rute didaftarkan sekali di GoRouter(routes: [...]).
  • :nim pada path adalah path parameter. Nilainya dibaca dengan state.pathParameters['nim']. Nilainya selalu String.
  • MaterialApp.router(routerConfig: router) menggantikan MaterialApp(home: ...).

context.go vs context.push

MetodePerilakuCocok untuk
context.go('/x')Pindah ke lokasi /x. Tumpukan disusun ulang mengikuti struktur rute (sub-rute berada di atas induknya).Pindah menu utama, setelah login/logout
context.push('/x')Menumpuk /x di atas halaman saat ini, seperti Navigator.push.Membuka detail, lalu kembali
context.pop()Kembali satu halaman (bisa membawa hasil).Tombol kembali/batal

Redirect sebagai auth guard

Fungsi redirect dipanggil sebelum setiap perpindahan halaman. Kembalikan path lain untuk membelokkan pengguna, atau null untuk membiarkan. Dengan refreshListenable, redirect juga dievaluasi ulang setiap kali status login berubah.

Contoh lengkap: login, sub-rute, path & query parameter

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
// Pastikan sudah menjalankan: flutter pub add go_router
import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';

void main() {
  runApp(const MyApp());
}

// Penanda status login sederhana. ChangeNotifier dibahas tuntas di Modul 08;
// di sini cukup tahu bahwa notifyListeners() memberi kabar ke GoRouter.
class AuthState extends ChangeNotifier {
  bool _sudahLogin = false;
  bool get sudahLogin => _sudahLogin;

  void login() {
    _sudahLogin = true;
    notifyListeners();
  }

  void logout() {
    _sudahLogin = false;
    notifyListeners();
  }
}

final authState = AuthState();

final GoRouter router = GoRouter(
  initialLocation: '/',
  // Router mengevaluasi ulang redirect setiap kali authState berubah
  refreshListenable: authState,
  // AUTH GUARD: dipanggil sebelum setiap perpindahan halaman
  redirect: (context, state) {
    final sedangDiLogin = state.matchedLocation == '/login';
    if (!authState.sudahLogin && !sedangDiLogin) return '/login'; // belum login
    if (authState.sudahLogin && sedangDiLogin) return '/'; // sudah login
    return null; // null = boleh lanjut ke tujuan semula
  },
  routes: [
    GoRoute(
      path: '/login',
      builder: (context, state) => const LoginScreen(),
    ),
    GoRoute(
      path: '/',
      builder: (context, state) => const BerandaScreen(),
      routes: [
        // Sub-rute: URL lengkapnya menjadi /matkul/IF201
        GoRoute(
          path: 'matkul/:kode',
          builder: (context, state) {
            final kode = state.pathParameters['kode']!;
            // Query parameter opsional: /matkul/IF201?tab=nilai
            final tab = state.uri.queryParameters['tab'] ?? 'info';
            return DetailMatkulScreen(kode: kode, tab: tab);
          },
        ),
        GoRoute(
          path: 'tentang',
          builder: (context, state) => const TentangScreen(),
        ),
      ],
    ),
  ],
  // Halaman jika URL tidak dikenal
  errorBuilder: (context, state) => Scaffold(
    body: Center(child: Text('Halaman ${state.uri} tidak ditemukan')),
  ),
);

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp.router(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      routerConfig: router,
    );
  }
}

class LoginScreen extends StatelessWidget {
  const LoginScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Login')),
      body: Center(
        child: FilledButton(
          // Tidak perlu context.go('/'): redirect otomatis memindahkan
          // pengguna ke '/' setelah authState berubah.
          onPressed: authState.login,
          child: const Text('Masuk'),
        ),
      ),
    );
  }
}

class BerandaScreen extends StatelessWidget {
  const BerandaScreen({super.key});

  static const kodeMatkul = ['IF201', 'IF202', 'IF203'];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Beranda'),
        actions: [
          IconButton(
            icon: const Icon(Icons.logout),
            onPressed: authState.logout, // redirect akan membawa ke /login
          ),
        ],
      ),
      body: ListView(
        children: [
          for (final kode in kodeMatkul)
            ListTile(
              title: Text('Mata kuliah $kode'),
              // push: tumpuk di atas Beranda (ada tombol back)
              onTap: () => context.push('/matkul/$kode'),
            ),
          ListTile(
            title: const Text('Buka nilai IF201 (query parameter)'),
            onTap: () => context.push('/matkul/IF201?tab=nilai'),
          ),
          ListTile(
            title: const Text('Tentang (pakai context.go)'),
            // go: pindah ke lokasi /tentang; tumpukan disusun ulang
            // sesuai struktur rute -> [Beranda, Tentang]
            onTap: () => context.go('/tentang'),
          ),
        ],
      ),
    );
  }
}

class DetailMatkulScreen extends StatelessWidget {
  final String kode;
  final String tab;

  const DetailMatkulScreen({super.key, required this.kode, required this.tab});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(kode)),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Tab aktif: $tab'),
            const SizedBox(height: 12),
            FilledButton(
              onPressed: () => context.pop(), // sama seperti Navigator.pop
              child: const Text('Kembali'),
            ),
          ],
        ),
      ),
    );
  }
}

class TentangScreen extends StatelessWidget {
  const TentangScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tentang')),
      body: const Center(child: Text('Contoh go_router')),
    );
  }
}
Belum login: redirect ke /login
Path parameter dan query parameter terbaca

Penjelasan:

  • Saat aplikasi dibuka, initialLocation adalah /, tetapi redirect melihat pengguna belum login dan membelokkan ke /login.
  • Tombol Masuk hanya mengubah authState. Karena refreshListenable: authState, router menjalankan redirect lagi dan memindahkan pengguna ke /. Logout bekerja dengan cara yang sama.
  • matkul/:kode ditulis tanpa garis miring awal karena merupakan sub-rute dari /. URL lengkapnya /matkul/IF201.
  • state.uri.queryParameters['tab'] membaca bagian ?tab=nilai. Query parameter cocok untuk data opsional.
  • errorBuilder menampilkan halaman ketika URL tidak cocok dengan rute mana pun.

ℹ️ Hubungan dengan Modul 08 dan 13–14

Pada contoh ini authState adalah variabel global agar contoh tetap singkat. Setelah mempelajari Provider, status login akan disimpan di AuthProvider. Proyek CRUD + Auth memakai pola yang setara: sebuah auth gate yang menampilkan Login atau Home berdasarkan sesi.

⚠️ Kesalahan umum

  • Menulis sub-rute dengan garis miring awal ('/matkul/:kode' di dalam routes milik rute lain). go_router akan menolak konfigurasi tersebut.
  • Redirect yang tidak pernah mengembalikan null, misalnya selalu return '/login', menyebabkan redirect loop.
  • Mencampur MaterialApp(home: ...) dengan routerConfig. Gunakan MaterialApp.router.
  • Membuat objek GoRouter di dalam build(). Setiap rebuild akan membuat router baru dan posisi halaman hilang. Buat sekali saja (variabel top-level atau di State).
