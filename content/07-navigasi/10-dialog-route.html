Dialog, bottom sheet, dan date picker ternyata juga route. showDialog melakukan push sebuah DialogRoute ke tumpukan Navigator. Karena itu dialog ditutup dengan Navigator.pop, dan bisa mengembalikan nilai persis seperti halaman biasa.

Contoh kecil: dialog konfirmasi yang mengembalikan bool

// showDialog juga melakukan PUSH sebuah rute (DialogRoute)
final bool? yakin = await showDialog<bool>(
  context: context,
  builder: (dialogContext) => AlertDialog(
    title: const Text('Hapus data?'),
    actions: [
      TextButton(
        onPressed: () => Navigator.pop(dialogContext, false),
        child: const Text('Batal'),
      ),
      FilledButton(
        onPressed: () => Navigator.pop(dialogContext, true),
        child: const Text('Hapus'),
      ),
    ],
  ),
);
// yakin bisa true, false, atau null (ditutup dengan tap di luar dialog)
if (yakin == true) debugPrint('Data dihapus');
  • showDialog<bool> mengembalikan Future<bool?>.
  • Nilai null muncul ketika pengguna menutup dialog dengan tap di luar dialog atau tombol back.
  • Builder dialog memberi dialogContext sendiri. Gunakan context ini untuk pop agar yang tertutup pasti dialognya.

Contoh lengkap: AlertDialog, bottom sheet, dan date picker

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.cyan),
      home: const DialogDemoScreen(),
    );
  }
}

class DialogDemoScreen extends StatefulWidget {
  const DialogDemoScreen({super.key});

  @override
  State<DialogDemoScreen> createState() => _DialogDemoScreenState();
}

class _DialogDemoScreenState extends State<DialogDemoScreen> {
  final List<String> _tugas = ['Laporan Praktikum 1', 'Kuis Basis Data', 'UTS Mobile'];
  String _prioritas = 'Sedang';
  DateTime? _deadline;

  // 1) AlertDialog yang mengembalikan bool
  Future<void> _hapus(int index) async {
    final yakin = await showDialog<bool>(
      context: context,
      barrierDismissible: false, // wajib pilih tombol, tap di luar tidak menutup
      builder: (dialogContext) => AlertDialog(
        icon: const Icon(Icons.delete_forever),
        title: const Text('Hapus tugas?'),
        content: Text('"${_tugas[index]}" akan dihapus permanen.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    if (yakin != true || !mounted) return;
    setState(() => _tugas.removeAt(index));
  }

  // 2) Bottom sheet yang mengembalikan String
  Future<void> _pilihPrioritas() async {
    final pilihan = await showModalBottomSheet<String>(
      context: context,
      builder: (sheetContext) => SafeArea(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            for (final p in ['Rendah', 'Sedang', 'Tinggi'])
              ListTile(
                title: Text(p),
                trailing: p == _prioritas ? const Icon(Icons.check) : null,
                onTap: () => Navigator.pop(sheetContext, p),
              ),
          ],
        ),
      ),
    );
    if (pilihan == null || !mounted) return;
    setState(() => _prioritas = pilihan);
  }

  // 3) Date picker bawaan yang mengembalikan DateTime?
  Future<void> _pilihTanggal() async {
    final sekarang = DateTime.now();
    final tanggal = await showDatePicker(
      context: context,
      firstDate: sekarang,
      lastDate: DateTime(sekarang.year + 1),
      initialDate: _deadline ?? sekarang,
    );
    if (tanggal == null || !mounted) return;
    setState(() => _deadline = tanggal);
  }

  @override
  Widget build(BuildContext context) {
    final teksDeadline = _deadline == null
        ? 'Belum diatur'
        : '${_deadline!.day}/${_deadline!.month}/${_deadline!.year}';

    return Scaffold(
      appBar: AppBar(title: const Text('Dialog & Bottom Sheet')),
      body: ListView(
        children: [
          ListTile(
            leading: const Icon(Icons.flag),
            title: const Text('Prioritas'),
            subtitle: Text(_prioritas),
            onTap: _pilihPrioritas,
          ),
          ListTile(
            leading: const Icon(Icons.event),
            title: const Text('Deadline'),
            subtitle: Text(teksDeadline),
            onTap: _pilihTanggal,
          ),
          const Divider(),
          for (var i = 0; i < _tugas.length; i++)
            ListTile(
              title: Text(_tugas[i]),
              trailing: IconButton(
                tooltip: 'Hapus tugas',
                icon: const Icon(Icons.delete_outline),
                onPressed: () => _hapus(i),
              ),
            ),
        ],
      ),
    );
  }
}

Penjelasan:

FungsiTipe hasilDitutup dengan
showDialog<bool>bool?Navigator.pop(dialogContext, true)
showModalBottomSheet<String>String?Navigator.pop(sheetContext, p)
showDatePickerDateTime?Otomatis oleh tombol OK/Cancel
  • barrierDismissible: false memaksa pengguna memilih tombol.
  • Setiap fungsi memeriksa !mounted setelah await sebelum memanggil setState.
  • yakin != true menangani dua kasus sekaligus: false dan null.

⚠️ Kesalahan umum

  • Menulis if (yakin) padahal tipenya bool?. Dart menolak karena bisa null. Tulis if (yakin == true).
  • Memanggil Navigator.pop(context) dua kali (sekali untuk dialog, sekali "untuk jaga-jaga"), sehingga halaman di bawahnya ikut tertutup.
  • Menampilkan SnackBar dengan dialogContext setelah dialog tertutup. Gunakan context halaman.
