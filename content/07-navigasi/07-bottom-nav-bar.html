Aplikasi kampus biasanya punya 3–5 menu utama yang selalu terlihat di bawah layar. Di Material 3, komponennya adalah NavigationBar (pengganti BottomNavigationBar versi lama).

Konsep

  • NavigationBar bukan Navigator. Berpindah tab tidak melakukan push; kita hanya mengganti widget yang ditampilkan di body berdasarkan indeks.
  • Indeks tab aktif disimpan di State dan diubah dengan setState di onDestinationSelected.
  • Setiap item adalah NavigationDestination dengan icon, selectedIcon (opsional), dan label.

Contoh lengkap 1: NavigationBar dasar

Struktur aplikasi standar kampus biasanya menggunakan menu tab bawah untuk berpindah antar fitur utama:

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const MainWrapperScreen(),
    );
  }
}

class MainWrapperScreen extends StatefulWidget {
  const MainWrapperScreen({super.key});

  @override
  State<MainWrapperScreen> createState() => _MainWrapperScreenState();
}

class _MainWrapperScreenState extends State<MainWrapperScreen> {
  int _currentIndex = 0;

  // Daftar layar untuk masing-masing tab (urutannya = urutan destinations)
  final List<Widget> _pages = const [
    HalamanTab(judul: "Beranda", ikon: Icons.home),
    HalamanTab(judul: "Jadwal Kuliah", ikon: Icons.calendar_month),
    HalamanTab(judul: "Kartu Rencana Studi", ikon: Icons.assignment),
    HalamanTab(judul: "Profil Mahasiswa", ikon: Icons.person),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Portal Akademik")),
      body: _pages[_currentIndex], // Menampilkan halaman sesuai tab aktif
      bottomNavigationBar: NavigationBar( // Komponen NavigationBar Material 3
        selectedIndex: _currentIndex,
        onDestinationSelected: (index) {
          setState(() => _currentIndex = index);
        },
        destinations: const [
          NavigationDestination(icon: Icon(Icons.home_outlined), selectedIcon: Icon(Icons.home), label: "Beranda"),
          NavigationDestination(icon: Icon(Icons.calendar_month_outlined), selectedIcon: Icon(Icons.calendar_month), label: "Jadwal"),
          NavigationDestination(icon: Icon(Icons.assignment_outlined), selectedIcon: Icon(Icons.assignment), label: "KRS"),
          NavigationDestination(icon: Icon(Icons.person_outline), selectedIcon: Icon(Icons.person), label: "Profil"),
        ],
      ),
    );
  }
}

// Halaman sederhana untuk tiap tab. Pada proyek nyata, ganti dengan
// BerandaScreen, JadwalScreen, dst. di file terpisah.
class HalamanTab extends StatelessWidget {
  final String judul;
  final IconData ikon;

  const HalamanTab({super.key, required this.judul, required this.ikon});

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(ikon, size: 72, color: Colors.indigo),
          const SizedBox(height: 12),
          Text(judul, style: const TextStyle(fontSize: 22, fontWeight: FontWeight.bold)),
        ],
      ),
    );
  }
}
NavigationBar Material 3 dengan tab Jadwal aktif

Masalah: state tab hilang saat berpindah

Pada contoh di atas, body: _pages[_currentIndex] hanya memasang halaman aktif. Saat pindah tab, halaman lama dibuang dari pohon widget. Akibatnya isian form, posisi scroll, dan nilai di State tab tersebut hilang. Solusinya adalah IndexedStack:

// SEBELUM: hanya halaman aktif yang ada di pohon widget
// body: _pages[_currentIndex],

// SESUDAH: semua halaman tetap hidup, hanya satu yang terlihat
body: IndexedStack(
  index: _currentIndex,
  children: _pages,
),

IndexedStack membangun semua anaknya sekali, lalu hanya menampilkan anak pada posisi index. Anak yang tersembunyi tetap hidup beserta State-nya.

Contoh lengkap 2: IndexedStack menjaga state tab

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: const MainScreen(),
    );
  }
}

class MainScreen extends StatefulWidget {
  const MainScreen({super.key});

  @override
  State<MainScreen> createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _index = 0;

  static const _judul = ['Presensi', 'Pengumuman', 'Akun'];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(_judul[_index])),
      // IndexedStack menjaga state setiap tab:
      // angka presensi & posisi scroll tidak hilang saat pindah tab
      body: IndexedStack(
        index: _index,
        children: const [
          PresensiTab(),
          PengumumanTab(),
          Center(child: Text('Halaman Akun')),
        ],
      ),
      bottomNavigationBar: NavigationBar(
        selectedIndex: _index,
        onDestinationSelected: (i) => setState(() => _index = i),
        destinations: const [
          NavigationDestination(
            icon: Icon(Icons.how_to_reg_outlined),
            selectedIcon: Icon(Icons.how_to_reg),
            label: 'Presensi',
          ),
          NavigationDestination(
            icon: Badge(label: Text('3'), child: Icon(Icons.campaign_outlined)),
            selectedIcon: Badge(label: Text('3'), child: Icon(Icons.campaign)),
            label: 'Pengumuman',
          ),
          NavigationDestination(
            icon: Icon(Icons.person_outline),
            selectedIcon: Icon(Icons.person),
            label: 'Akun',
          ),
        ],
      ),
    );
  }
}

// Tab 1: punya state lokal (jumlah kehadiran)
class PresensiTab extends StatefulWidget {
  const PresensiTab({super.key});

  @override
  State<PresensiTab> createState() => _PresensiTabState();
}

class _PresensiTabState extends State<PresensiTab> {
  int _hadir = 0;

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Text('Hadir: $_hadir pertemuan',
              style: Theme.of(context).textTheme.headlineSmall),
          const SizedBox(height: 12),
          FilledButton(
            onPressed: () => setState(() => _hadir++),
            child: const Text('Presensi Hari Ini'),
          ),
          const SizedBox(height: 8),
          const Text('Tambah angka, pindah tab, lalu kembali ke sini.'),
        ],
      ),
    );
  }
}

// Tab 2: list panjang (posisi scroll ikut tersimpan)
class PengumumanTab extends StatelessWidget {
  const PengumumanTab({super.key});

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      itemCount: 50,
      itemBuilder: (context, i) => ListTile(
        leading: const Icon(Icons.campaign),
        title: Text('Pengumuman ke-${i + 1}'),
      ),
    );
  }
}
Tab Presensi setelah tombol ditekan 3 kali
Pindah ke tab Akun lalu kembali: angka tetap 3

Penjelasan:

  • PresensiTab adalah StatefulWidget dengan variabel _hadir. Berkat IndexedStack, angkanya tidak kembali ke 0 setelah pindah tab.
  • PengumumanTab berisi 50 item. Gulir ke bawah, pindah tab, lalu kembali: posisi scroll tetap.
  • Badge menampilkan angka kecil di atas ikon, berguna untuk notifikasi belum dibaca.
  • Judul AppBar diambil dari list _judul sesuai tab aktif.
PendekatanKelebihanKekurangan
_pages[index]Hemat memori, tab dibangun saat dibukaState tab hilang setiap pindah
IndexedStackState tab terjagaSemua tab dibangun di awal (hati-hati jika tiap tab memanggil API berat)

⚠️ Kesalahan umum

  • Jumlah destinations kurang dari 2. NavigationBar butuh minimal dua item.
  • Membuat list halaman di dalam build() tanpa const, lalu heran halaman ter-rebuild. Gunakan const jika halaman tidak butuh parameter.
  • Memakai Navigator.push untuk berpindah tab. Tab bukan tumpukan; cukup ubah indeks.
  • Masih memakai BottomNavigationBar lama di proyek baru. Untuk tampilan Material 3, pakai NavigationBar.
