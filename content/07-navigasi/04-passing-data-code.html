Navigasi bisa dua arah. Navigator.push mengembalikan sebuah Future yang selesai ketika halaman tujuan ditutup. Nilai yang dikirim lewat Navigator.pop(context, nilai) akan menjadi hasil Future tersebut.

Pola dasarnya

// Halaman ASAL: tunggu hasil dengan await
onPressed: () async {
  final String? kelas = await Navigator.push<String>(
    context,
    MaterialPageRoute(builder: (context) => const PilihKelasScreen()),
  );
  if (kelas == null) return; // pengguna menekan tombol back
  debugPrint('Kelas dipilih: $kelas');
},


// Halaman TUJUAN: tutup sambil membawa nilai
onTap: () => Navigator.pop(context, 'Kelas A'),
  • push<String> memberi tahu Dart bahwa hasilnya bertipe String?. Tanda tanya muncul karena pengguna bisa menekan back tanpa memilih apa pun, sehingga hasilnya null.
  • await membuat kode "menunggu" sampai halaman tujuan di-pop. Karena itu fungsi onPressed harus async.

Contoh lengkap 1: verifikasi data mahasiswa

Mari pelajari cara mengirim data objek Mahasiswa ke halaman detail, dan menerima konfirmasi status kembali:

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: DaftarMahasiswaScreen(),
    );
  }
}

// --- HALAMAN 1: DAFTAR MAHASISWA ---
class DaftarMahasiswaScreen extends StatelessWidget {
  const DaftarMahasiswaScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Daftar Mahasiswa")),
      body: Center(
        child: ElevatedButton(
          onPressed: () async {
            // 1. Mengirim data ke DetailMahasiswaScreen dan MENUNGGU hasil balik (await)
            //    <String> = tipe data yang diharapkan dikirim balik oleh Navigator.pop
            final hasilBalik = await Navigator.push<String>(
              context,
              MaterialPageRoute(
                builder: (context) => const DetailMahasiswaScreen(
                  nama: "Fikri Ramadhan",
                  nim: "21102045",
                ),
              ),
            );

            // 2. Menerima data yang dikirim balik dari Halaman 2.
            //    Cek context.mounted karena ada jeda (await) sebelum memakai context lagi.
            if (hasilBalik != null && context.mounted) {
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text("Feedback dari halaman detail: $hasilBalik")),
              );
            }
          },
          child: const Text("Lihat Detail Mahasiswa"),
        ),
      ),
    );
  }
}

// --- HALAMAN 2: DETAIL MAHASISWA ---
class DetailMahasiswaScreen extends StatelessWidget {
  final String nama;
  final String nim;

  const DetailMahasiswaScreen({super.key, required this.nama, required this.nim});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text("Profil $nama")),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text("NIM: $nim", style: const TextStyle(fontSize: 18)),
            const SizedBox(height: 20),
            ElevatedButton(
              onPressed: () {
                // Menutup layar DAN mengembalikan data String ke halaman sebelumnya
                Navigator.pop(context, "Data Telah Diverifikasi!");
              },
              child: const Text("Verifikasi & Kembali"),
            ),
          ],
        ),
      ),
    );
  }
}
Hasil balik dari pop tampil di SnackBar

Contoh lengkap 2: form tambah catatan yang mengembalikan objek

Pola ini sangat sering dipakai: halaman daftar membuka halaman form, form mengembalikan objek baru, lalu daftar menambahkannya dengan setState.

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class Catatan {
  final String judul;
  final bool penting;

  const Catatan({required this.judul, required this.penting});
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepPurple),
      home: const DaftarCatatanScreen(),
    );
  }
}

// Halaman daftar perlu StatefulWidget karena isinya berubah
class DaftarCatatanScreen extends StatefulWidget {
  const DaftarCatatanScreen({super.key});

  @override
  State<DaftarCatatanScreen> createState() => _DaftarCatatanScreenState();
}

class _DaftarCatatanScreenState extends State<DaftarCatatanScreen> {
  final List<Catatan> _catatan = [];

  Future<void> _bukaForm() async {
    // 1. Buka form dan TUNGGU sampai form ditutup
    final hasil = await Navigator.push<Catatan>(
      context,
      MaterialPageRoute(builder: (context) => const FormCatatanScreen()),
    );

    // 2. hasil == null berarti pengguna batal (tekan back)
    if (hasil == null) return;

    // 3. Setelah await, pastikan State masih terpasang sebelum setState/context
    if (!mounted) return;
    setState(() => _catatan.add(hasil));
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Catatan "${hasil.judul}" ditambahkan')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Catatan Kuliah')),
      body: _catatan.isEmpty
          ? const Center(child: Text('Belum ada catatan. Tekan tombol +'))
          : ListView.builder(
              itemCount: _catatan.length,
              itemBuilder: (context, index) {
                final c = _catatan[index];
                return ListTile(
                  leading: Icon(
                    c.penting ? Icons.star : Icons.notes,
                    color: c.penting ? Colors.amber : null,
                  ),
                  title: Text(c.judul),
                );
              },
            ),
      floatingActionButton: FloatingActionButton(
        tooltip: 'Tambah catatan',
        onPressed: _bukaForm,
        child: const Icon(Icons.add),
      ),
    );
  }
}

class FormCatatanScreen extends StatefulWidget {
  const FormCatatanScreen({super.key});

  @override
  State<FormCatatanScreen> createState() => _FormCatatanScreenState();
}

class _FormCatatanScreenState extends State<FormCatatanScreen> {
  final _judulController = TextEditingController();
  bool _penting = false;

  @override
  void dispose() {
    _judulController.dispose();
    super.dispose();
  }

  void _simpan() {
    final judul = _judulController.text.trim();
    if (judul.isEmpty) return;
    // Tutup halaman sambil MENGIRIM objek Catatan ke halaman sebelumnya
    Navigator.pop(context, Catatan(judul: judul, penting: _penting));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Catatan Baru')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            TextField(
              controller: _judulController,
              autofocus: true,
              decoration: const InputDecoration(
                labelText: 'Judul catatan',
                border: OutlineInputBorder(),
              ),
            ),
            SwitchListTile(
              title: const Text('Tandai penting'),
              value: _penting,
              onChanged: (v) => setState(() => _penting = v),
            ),
            const SizedBox(height: 12),
            SizedBox(
              width: double.infinity,
              child: FilledButton(onPressed: _simpan, child: const Text('Simpan')),
            ),
          ],
        ),
      ),
    );
  }
}
Objek Catatan dikembalikan dan ditambahkan ke daftar

Penjelasan:

  • _bukaForm() menunggu hasil bertipe Catatan?. Jika null, berarti pengguna batal sehingga fungsi langsung berhenti.
  • if (!mounted) return; wajib ada setelah await. Selama menunggu, halaman daftar bisa saja sudah ditutup. Memanggil setState pada State yang sudah dilepas akan menimbulkan error.
  • Di form, Navigator.pop(context, Catatan(...)) sekaligus menutup halaman dan mengirim objek.
  • Di dalam State gunakan mounted; di dalam fungsi yang hanya punya BuildContext (seperti contoh 1) gunakan context.mounted.

⚠️ Kesalahan umum

  • Lupa await: kode setelah push langsung jalan sebelum pengguna memilih apa pun, dan hasilnya selalu berupa Future, bukan nilai.
  • Tidak menangani null. Pengguna selalu bisa menekan tombol back, jadi hasil pasti bisa null.
  • Tipe hasil tidak cocok, misalnya push<String> tetapi halaman tujuan memanggil pop(context, 123). Ini menimbulkan error tipe saat runtime.
  • Memakai context setelah await tanpa cek mounted. Analyzer akan memberi peringatan use_build_context_synchronously.
