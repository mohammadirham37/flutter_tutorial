Kadang tombol back perlu "dicegat", misalnya ketika form sudah diisi tetapi belum disimpan. Widget yang dipakai adalah PopScope (pengganti WillPopScope yang sudah dihapus dari Flutter).

Dua parameter penting

  • canPop: true berarti back boleh langsung menutup halaman. false berarti back diblokir.
  • onPopInvokedWithResult: (didPop, result): dipanggil setiap kali ada upaya kembali. didPop bernilai true jika halaman sudah tertutup, false jika diblokir.

Contoh kecil

return PopScope(
  canPop: false, // blokir tombol/gestur back
  onPopInvokedWithResult: (bool didPop, Object? result) {
    if (didPop) return; // sudah keluar, tidak perlu apa-apa
    // Di sini: tampilkan dialog konfirmasi, simpan draf, dll.
    debugPrint('Back ditekan tapi diblokir');
  },
  child: const Scaffold(body: Center(child: Text('Form'))),
);

Contoh lengkap: konfirmasi sebelum membuang isian form

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.brown),
      home: const BerandaScreen(),
    );
  }
}

class BerandaScreen extends StatelessWidget {
  const BerandaScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Beranda')),
      body: Center(
        child: FilledButton(
          onPressed: () => Navigator.push(
            context,
            MaterialPageRoute(builder: (_) => const FormIzinScreen()),
          ),
          child: const Text('Ajukan Izin Kuliah'),
        ),
      ),
    );
  }
}

class FormIzinScreen extends StatefulWidget {
  const FormIzinScreen({super.key});

  @override
  State<FormIzinScreen> createState() => _FormIzinScreenState();
}

class _FormIzinScreenState extends State<FormIzinScreen> {
  final _alasanController = TextEditingController();
  bool _adaPerubahan = false;

  @override
  void dispose() {
    _alasanController.dispose();
    super.dispose();
  }

  Future<bool> _konfirmasiKeluar() async {
    final keluar = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Buang perubahan?'),
        content: const Text('Isian form belum dikirim dan akan hilang.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Tetap di sini'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Buang'),
          ),
        ],
      ),
    );
    return keluar ?? false;
  }

  void _kirim() {
    // Setelah terkirim, form boleh ditutup tanpa konfirmasi
    setState(() => _adaPerubahan = false);
    Navigator.pop(context);
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Pengajuan izin terkirim')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return PopScope(
      // Jika tidak ada perubahan -> boleh langsung kembali
      canPop: !_adaPerubahan,
      onPopInvokedWithResult: (didPop, result) async {
        if (didPop) return;
        final keluar = await _konfirmasiKeluar();
        // Pakai context milik State, cek mounted setelah await
        if (keluar && context.mounted) {
          Navigator.pop(context);
        }
      },
      child: Scaffold(
        appBar: AppBar(title: const Text('Form Izin')),
        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            children: [
              TextField(
                controller: _alasanController,
                maxLines: 4,
                decoration: const InputDecoration(
                  labelText: 'Alasan izin',
                  border: OutlineInputBorder(),
                ),
                onChanged: (teks) {
                  final berubah = teks.trim().isNotEmpty;
                  if (berubah != _adaPerubahan) {
                    setState(() => _adaPerubahan = berubah);
                  }
                },
              ),
              const SizedBox(height: 12),
              Text(_adaPerubahan
                  ? 'Ada perubahan: tombol back akan meminta konfirmasi'
                  : 'Belum ada perubahan: tombol back langsung kembali'),
              const Spacer(),
              SizedBox(
                width: double.infinity,
                child: FilledButton(onPressed: _kirim, child: const Text('Kirim')),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
Tombol back memicu dialog konfirmasi

Penjelasan:

  1. canPop: !_adaPerubahan: jika form masih kosong, back berjalan normal.
  2. Begitu pengguna mengetik, _adaPerubahan menjadi true, sehingga canPop menjadi false.
  3. Saat back ditekan, onPopInvokedWithResult dipanggil dengan didPop == false, lalu dialog konfirmasi ditampilkan.
  4. Jika pengguna memilih "Buang", kita menutup halaman sendiri dengan Navigator.pop(context). Pemanggilan pop secara langsung dari kode tetap berjalan walaupun canPop bernilai false.
  5. Tombol panah di AppBar, tombol back Android, dan gestur back semuanya melewati PopScope.

⚠️ Kesalahan umum

  • Memakai WillPopScope atau parameter onPopInvoked dari tutorial lama. Keduanya sudah usang; gunakan PopScope + onPopInvokedWithResult.
  • Tidak mengecek didPop. Jika halaman sudah tertutup lalu kita memanggil Navigator.pop lagi, halaman di bawahnya ikut tertutup.
  • Membuat canPop: false permanen tanpa memberi jalan keluar. Pengguna akan "terjebak" di halaman itu.
