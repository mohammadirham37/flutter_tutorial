TabBar menampilkan deretan tab di bawah AppBar, dan TabBarView menampilkan isi tab yang bisa digeser kiri-kanan. Cocok untuk mengelompokkan data sejenis, misalnya jadwal per hari atau nilai per semester.

Tiga komponen yang harus selaras

  1. DefaultTabController(length: n): pengatur tab aktif.
  2. TabBar(tabs: [...]): deretan judul tab, biasanya di AppBar.bottom.
  3. TabBarView(children: [...]): isi setiap tab.

Contoh kecil

return DefaultTabController(
  length: 2, // HARUS sama dengan jumlah Tab dan jumlah anak TabBarView
  child: Scaffold(
    appBar: AppBar(
      title: const Text('Nilai'),
      bottom: const TabBar(
        tabs: [Tab(text: 'Semester Ganjil'), Tab(text: 'Semester Genap')],
      ),
    ),
    body: const TabBarView(
      children: [
        Center(child: Text('Nilai ganjil')),
        Center(child: Text('Nilai genap')),
      ],
    ),
  ),
);

Contoh lengkap: jadwal kuliah per hari

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.pink),
      home: const JadwalScreen(),
    );
  }
}

class Jadwal {
  final String jam;
  final String matkul;
  final String ruang;

  const Jadwal(this.jam, this.matkul, this.ruang);
}

const jadwalPerHari = {
  'Senin': [
    Jadwal('07.30', 'Pemrograman Mobile', 'Lab 1'),
    Jadwal('10.00', 'Basis Data', 'R. 201'),
  ],
  'Selasa': [Jadwal('08.00', 'Jaringan Komputer', 'Lab 3')],
  'Rabu': <Jadwal>[],
  'Kamis': [Jadwal('13.00', 'Kecerdasan Buatan', 'R. 305')],
  'Jumat': [Jadwal('07.30', 'Etika Profesi', 'Aula')],
};

class JadwalScreen extends StatelessWidget {
  const JadwalScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final hari = jadwalPerHari.keys.toList();

    return DefaultTabController(
      length: hari.length,
      child: Scaffold(
        appBar: AppBar(
          title: const Text('Jadwal Kuliah'),
          bottom: TabBar(
            isScrollable: true, // tab bisa digeser jika banyak
            tabAlignment: TabAlignment.start,
            tabs: [for (final h in hari) Tab(text: h)],
          ),
        ),
        body: TabBarView(
          children: [
            for (final h in hari) DaftarJadwal(items: jadwalPerHari[h]!),
          ],
        ),
      ),
    );
  }
}

class DaftarJadwal extends StatelessWidget {
  final List<Jadwal> items;

  const DaftarJadwal({super.key, required this.items});

  @override
  Widget build(BuildContext context) {
    if (items.isEmpty) {
      return const Center(child: Text('Tidak ada kuliah. Waktunya belajar mandiri!'));
    }
    return ListView.separated(
      itemCount: items.length,
      separatorBuilder: (context, i) => const Divider(height: 1),
      itemBuilder: (context, i) {
        final j = items[i];
        return ListTile(
          leading: Text(j.jam, style: const TextStyle(fontWeight: FontWeight.bold)),
          title: Text(j.matkul),
          subtitle: Text(j.ruang),
        );
      },
    );
  }
}

Penjelasan:

  • Daftar hari diambil dari jadwalPerHari.keys, sehingga length, jumlah Tab, dan jumlah anak TabBarView selalu sama.
  • isScrollable: true + tabAlignment: TabAlignment.start membuat tab bisa digulir dan rata kiri saat jumlahnya banyak.
  • Widget DaftarJadwal dipakai ulang untuk setiap hari, dengan tampilan khusus jika list kosong.

⚠️ Kesalahan umum

  • length tidak sama dengan jumlah tab atau isi, menghasilkan error "Controller's length property does not match".
  • Lupa membungkus dengan DefaultTabController, menghasilkan error "No TabController for TabBar".
  • Memakai TabBarView di dalam Column tanpa Expanded, sehingga tingginya tidak terbatas.
