Tidak semua halaman boleh "dikembalikan" dengan tombol back. Setelah login, pengguna tidak seharusnya kembali ke form login. Setelah logout, pengguna tidak boleh kembali ke halaman berisi data pribadi. Untuk kasus ini kita memakai pushReplacement dan pushAndRemoveUntil.

MetodeTumpukan sebelumTumpukan sesudahKasus
push(Home)[Login][Login, Home]Halaman detail biasa
pushReplacement(Home)[Login][Home]Splash → Login, Login → Home
pushAndRemoveUntil(Login, (r) => false)[Home, Pengaturan][Login]Logout
popUntil((r) => r.isFirst)[Home, A, B][Home]Tombol "Kembali ke Beranda"

Contoh kecil

// 1) Ganti halaman saat ini: [Login] menjadi [Home]
Navigator.pushReplacement(
  context,
  MaterialPageRoute(builder: (context) => const HomeScreen()),
);


// 2) Push Login lalu hapus SEMUA rute di bawahnya
//    (route) => false artinya "jangan sisakan satu rute pun"
Navigator.pushAndRemoveUntil(
  context,
  MaterialPageRoute(builder: (context) => const LoginScreen()),
  (route) => false,
);

// 3) Kembali terus sampai ke rute pertama (tanpa push baru)
Navigator.popUntil(context, (route) => route.isFirst);

Parameter ketiga pushAndRemoveUntil adalah predicate: fungsi yang dipanggil untuk setiap route lama, dari atas ke bawah. Route dibuang selama fungsi mengembalikan false. Dengan (route) => false, semua route lama dibuang.

Contoh lengkap: Splash → Login → Home → Pengaturan → Logout

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.blue),
      home: const SplashScreen(),
    );
  }
}

// ---------------- SPLASH ----------------
class SplashScreen extends StatefulWidget {
  const SplashScreen({super.key});

  @override
  State<SplashScreen> createState() => _SplashScreenState();
}

class _SplashScreenState extends State<SplashScreen> {
  @override
  void initState() {
    super.initState();
    _lanjutKeLogin();
  }

  Future<void> _lanjutKeLogin() async {
    await Future.delayed(const Duration(seconds: 2));
    if (!mounted) return; // halaman bisa saja sudah ditutup selama menunggu
    // Splash diganti Login -> tombol back tidak akan kembali ke splash
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(builder: (context) => const LoginScreen()),
    );
  }

  @override
  Widget build(BuildContext context) {
    return const Scaffold(
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            FlutterLogo(size: 96),
            SizedBox(height: 16),
            CircularProgressIndicator(),
          ],
        ),
      ),
    );
  }
}

// ---------------- LOGIN ----------------
class LoginScreen extends StatelessWidget {
  const LoginScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Login')),
      body: Center(
        child: FilledButton(
          onPressed: () {
            // Login sukses: GANTI halaman login dengan Home
            Navigator.pushReplacement(
              context,
              MaterialPageRoute(builder: (context) => const HomeScreen()),
            );
          },
          child: const Text('Masuk'),
        ),
      ),
    );
  }
}

// ---------------- HOME ----------------
class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // Tidak ada panah back di sini karena Home adalah satu-satunya rute
      appBar: AppBar(title: const Text('Home')),
      body: Center(
        child: FilledButton.tonal(
          onPressed: () {
            Navigator.push(
              context,
              MaterialPageRoute(builder: (context) => const PengaturanScreen()),
            );
          },
          child: const Text('Buka Pengaturan'),
        ),
      ),
    );
  }
}

// ---------------- PENGATURAN ----------------
class PengaturanScreen extends StatelessWidget {
  const PengaturanScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pengaturan')),
      body: Center(
        child: FilledButton.icon(
          style: FilledButton.styleFrom(backgroundColor: Colors.red),
          icon: const Icon(Icons.logout),
          label: const Text('Logout'),
          onPressed: () {
            // Stack saat ini: [Home, Pengaturan]
            // Setelah ini  : [Login]  (Home & Pengaturan dibuang semua)
            Navigator.pushAndRemoveUntil(
              context,
              MaterialPageRoute(builder: (context) => const LoginScreen()),
              (route) => false,
            );
          },
        ),
      ),
    );
  }
}
Splash sudah diganti Login (tanpa panah kembali)
Setelah logout: tumpukan hanya [Login]

Penjelasan alur tumpukan:

  1. Aplikasi mulai: [Splash]. Setelah 2 detik, pushReplacement → [Login].
  2. Tekan Masuk: pushReplacement → [Home]. Perhatikan AppBar Home tidak punya panah kembali.
  3. Buka Pengaturan: push → [Home, Pengaturan].
  4. Logout: pushAndRemoveUntil → [Login]. Tekan back di Android, aplikasi tertutup karena tidak ada halaman lain.

ℹ️ Hubungan dengan Modul 13–14

Di proyek CRUD + Auth nanti, perpindahan login/home tidak lagi memakai pushReplacement manual, melainkan sebuah auth gate: widget yang memilih menampilkan Login atau Home berdasarkan status sesi di Provider. Konsepnya sama: halaman login tidak boleh tersisa di tumpukan setelah login.

⚠️ Kesalahan umum

  • Memakai push biasa setelah login sehingga tombol back membawa pengguna kembali ke form login.
  • Logout dengan pushReplacement: hanya halaman teratas yang diganti, halaman Home masih tersisa di bawah.
  • Navigasi di initState setelah Future.delayed tanpa cek mounted.
