Navigasi di Flutter bekerja seperti Tumpukan Piring (Stack - LIFO). Saat pengguna membuka halaman baru, halaman tersebut diletakkan di atas tumpukan (push). Saat tombol kembali ditekan, halaman paling atas diambil dan disingkirkan (pop).

Yang mengatur tumpukan ini adalah widget Navigator. Kita tidak perlu membuatnya sendiri: MaterialApp sudah menyediakan satu Navigator untuk seluruh aplikasi. Setiap "halaman" di dalam tumpukan disebut route (rute).

Operasi Metode Flutter Efek pada Tumpukan
Masuk Halaman Baru Navigator.push(context, route) Menambahkan halaman baru di puncak stack. Layar sebelumnya masih hidup di bawahnya.
Kembali Navigator.pop(context, [result]) Menghapus halaman paling atas. Mengembalikan kontrol ke layar di bawahnya.
Ganti Halaman (Replace) Navigator.pushReplacement(context, route) Menghancurkan halaman saat ini dan menggantinya dengan yang baru (Contoh: dari Layar Login ke Layar Utama).
Bersihkan Seluruh Stack Navigator.pushAndRemoveUntil(...) Menghapus seluruh riwayat layar masa lalu (Contoh: Logout kembali ke Login).

Ilustrasi tumpukan

Awal aplikasi        Setelah push(Tentang)     Setelah pop()
+-----------+        +-----------+             +-----------+
|  Beranda  |        |  Tentang  |  <- atas    |  Beranda  |
+-----------+        +-----------+             +-----------+
                     |  Beranda  |
                     +-----------+

Contoh kecil: push dan pop

Dua baris ini adalah inti navigasi. Baris pertama dipanggil di halaman asal, baris kedua di halaman tujuan.

// MASUK ke halaman baru (push = taruh di atas tumpukan)
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const HalamanB()),
);

// KEMBALI ke halaman sebelumnya (pop = ambil halaman teratas)
Navigator.pop(context);
  • context dipakai untuk mencari Navigator terdekat di atas widget ini.
  • MaterialPageRoute membungkus halaman tujuan dan memberi animasi transisi standar (dibahas di section berikutnya).
  • Navigator.pop(context) tidak perlu tahu halaman mana yang ada di bawahnya. Ia cukup membuang halaman teratas.

Contoh lengkap: Beranda dan Tentang

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const BerandaScreen(),
    );
  }
}

// --- HALAMAN 1 (paling bawah di tumpukan) ---
class BerandaScreen extends StatelessWidget {
  const BerandaScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Beranda')),
      body: Center(
        child: FilledButton.icon(
          icon: const Icon(Icons.info_outline),
          label: const Text('Buka Halaman Tentang'),
          onPressed: () {
            // push: TentangScreen diletakkan DI ATAS BerandaScreen
            Navigator.push(
              context,
              MaterialPageRoute(builder: (context) => const TentangScreen()),
            );
          },
        ),
      ),
    );
  }
}

// --- HALAMAN 2 ---
class TentangScreen extends StatelessWidget {
  const TentangScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // AppBar otomatis menampilkan tombol panah kembali (←)
      // karena ada halaman lain di bawah tumpukan.
      appBar: AppBar(title: const Text('Tentang Aplikasi')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            const Text('Portal Akademik v1.0'),
            const SizedBox(height: 16),
            OutlinedButton(
              // pop: buang halaman teratas, kembali ke Beranda
              onPressed: () => Navigator.pop(context),
              child: const Text('Kembali ke Beranda'),
            ),
            const SizedBox(height: 8),
            TextButton(
              // push lagi: tumpukan menjadi Beranda -> Tentang -> Tentang
              onPressed: () {
                Navigator.push(
                  context,
                  MaterialPageRoute(builder: (context) => const TentangScreen()),
                );
              },
              child: const Text('Push Tentang sekali lagi'),
            ),
          ],
        ),
      ),
    );
  }
}
Halaman pertama: Beranda
Setelah push: Tentang di atas Beranda (ada panah kembali)

Penjelasan:

  • home: const BerandaScreen() menjadi route pertama (paling bawah) di tumpukan.
  • Di TentangScreen, AppBar otomatis menampilkan tombol panah kembali. Tombol itu memanggil Navigator.maybePop untuk kita.
  • Tombol "Push Tentang sekali lagi" sengaja dibuat untuk membuktikan bahwa halaman yang sama boleh ada dua kali di tumpukan. Tekan back dua kali untuk kembali ke Beranda.
  • Tombol back fisik/gestur di Android juga melakukan pop.

⚠️ Kesalahan umum

  • Memanggil pop di halaman pertama. Jika tumpukan tinggal satu route, Navigator.pop membuat layar hitam (tidak ada halaman tersisa). Gunakan Navigator.canPop(context) untuk mengecek, atau Navigator.maybePop(context) yang aman.
  • Memanggil Navigator.push langsung di dalam build(). Navigasi harus dipicu oleh aksi (tombol, timer, hasil login), bukan setiap kali widget di-render.
  • Memakai context milik MyApp (di atas MaterialApp). Context tersebut belum punya Navigator, sehingga muncul error "Navigator operation requested with a context that does not include a Navigator". Lakukan navigasi dari widget halaman (di bawah MaterialApp).
