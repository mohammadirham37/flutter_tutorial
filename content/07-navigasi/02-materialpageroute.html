MaterialPageRoute adalah "bungkus" untuk halaman tujuan. Ia menentukan bagaimana halaman muncul: animasi transisi, apakah berupa dialog layar penuh, dan nama rutenya.

Parameter penting

MaterialPageRoute(
  builder: (context) => const FormScreen(), // WAJIB: membangun halaman tujuan
  settings: const RouteSettings(name: '/form'), // opsional: nama rute (untuk debug/analytics)
  fullscreenDialog: true, // opsional: animasi dari bawah + tombol X
  maintainState: true, // default true: halaman tetap hidup saat tertutup halaman lain
);
ParameterFungsi
builderFungsi yang mengembalikan widget halaman. Dipanggil saat route dibangun.
settingsBerisi name dan arguments. Berguna untuk named routes dan debugging.
fullscreenDialogJika true, halaman masuk dari bawah dan tombol back menjadi ikon X. Cocok untuk form "Tambah ...".
maintainStateJika true (default), halaman di bawah tetap disimpan di memori sehingga isian form dan posisi scroll tidak hilang.

Contoh lengkap: tiga gaya transisi

Contoh berikut membandingkan rute biasa, fullscreenDialog, dan PageRouteBuilder untuk animasi kustom (fade).

📄 lib/main.dart

// lib/main.dart — salin SELURUH kode ini untuk menggantikan isi lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.teal),
      home: const PengumumanScreen(),
    );
  }
}

class PengumumanScreen extends StatelessWidget {
  const PengumumanScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pengumuman')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          // 1. Rute biasa: animasi geser standar platform
          FilledButton(
            onPressed: () {
              Navigator.push(
                context,
                MaterialPageRoute(
                  settings: const RouteSettings(name: '/detail'),
                  builder: (context) => const DetailPengumumanScreen(),
                ),
              );
            },
            child: const Text('Rute biasa (geser)'),
          ),
          const SizedBox(height: 12),
          // 2. fullscreenDialog: muncul dari bawah, tombol kembali berubah jadi X
          FilledButton.tonal(
            onPressed: () {
              Navigator.push(
                context,
                MaterialPageRoute(
                  fullscreenDialog: true,
                  builder: (context) => const TulisPengumumanScreen(),
                ),
              );
            },
            child: const Text('fullscreenDialog (dari bawah)'),
          ),
          const SizedBox(height: 12),
          // 3. PageRouteBuilder: animasi kustom (fade)
          OutlinedButton(
            onPressed: () {
              Navigator.push(
                context,
                PageRouteBuilder(
                  transitionDuration: const Duration(milliseconds: 400),
                  pageBuilder: (context, animation, secondaryAnimation) =>
                      const DetailPengumumanScreen(),
                  transitionsBuilder:
                      (context, animation, secondaryAnimation, child) {
                    return FadeTransition(opacity: animation, child: child);
                  },
                ),
              );
            },
            child: const Text('PageRouteBuilder (fade)'),
          ),
        ],
      ),
    );
  }
}

class DetailPengumumanScreen extends StatelessWidget {
  const DetailPengumumanScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // ModalRoute.of(context) memberi akses ke rute yang sedang aktif
    final namaRute = ModalRoute.of(context)?.settings.name ?? '(tanpa nama)';
    return Scaffold(
      appBar: AppBar(title: const Text('Detail Pengumuman')),
      body: Center(child: Text('Nama rute: $namaRute')),
    );
  }
}

class TulisPengumumanScreen extends StatelessWidget {
  const TulisPengumumanScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tulis Pengumuman')),
      body: const Padding(
        padding: EdgeInsets.all(16),
        child: TextField(
          maxLines: 5,
          decoration: InputDecoration(
            border: OutlineInputBorder(),
            hintText: 'Isi pengumuman...',
          ),
        ),
      ),
    );
  }
}
Tiga tombol untuk tiga jenis rute
Rute biasa: nama rute terbaca dari settings
fullscreenDialog: tombol kembali berupa ikon X

Penjelasan:

  • MaterialPageRoute otomatis menyesuaikan animasi dengan platform (Android: zoom/geser, iOS: geser dari kanan).
  • ModalRoute.of(context)?.settings.name membaca nama rute dari dalam halaman tujuan. Rute ketiga tidak diberi settings, jadi namanya null.
  • PageRouteBuilder memberi kendali penuh: pageBuilder membangun halaman, transitionsBuilder membungkusnya dengan animasi. Nilai animation bergerak dari 0.0 ke 1.0.

💡 Tips

Untuk aplikasi kuliah, MaterialPageRoute sudah cukup di 95% kasus. Pakai PageRouteBuilder hanya jika desain memang meminta animasi khusus.

⚠️ Kesalahan umum

  • Menulis builder: (context) => HalamanB (tanpa tanda kurung). Yang benar adalah memanggil constructor: HalamanB().
  • Mengira fullscreenDialog sama dengan showDialog. fullscreenDialog tetap halaman penuh, hanya gaya animasinya yang berbeda.
