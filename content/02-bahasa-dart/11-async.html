Aplikasi mobile sering harus menunggu: mengambil data dari internet, membaca database, atau menunggu input. Jika program "diam menunggu", layar akan membeku. Dart memakai model single-threaded event loop dengan Future dan Stream agar pekerjaan yang lama berjalan tanpa memblokir tampilan.

Kode sinkron vs asinkron

void main() {
  print('1. Mulai');
  Future.delayed(const Duration(seconds: 1), () {
    print('3. Data selesai diambil (setelah 1 detik)');
  });
  print('2. Lanjut mengerjakan hal lain');
  // Output:
  // 1. Mulai
  // 2. Lanjut mengerjakan hal lain
  // 3. Data selesai diambil (setelah 1 detik)
}

Future.delayed "menjadwalkan" pekerjaan untuk nanti, lalu Dart langsung lanjut ke baris berikutnya. Itulah sebabnya baris 2 tercetak sebelum baris 3. Future adalah janji bahwa sebuah nilai (atau error) akan tersedia di masa depan.

async dan await

Future<String> ambilNamaMahasiswa(String nim) async {
  await Future.delayed(const Duration(milliseconds: 500)); // simulasi jaringan
  return 'Ayu Lestari';
}

Future<void> main() async {
  print('Mengambil data...');
  String nama = await ambilNamaMahasiswa('H1D023001');
  print('Nama: $nama');
  print('Selesai');
  // Output:
  // Mengambil data...
  // Nama: Ayu Lestari
  // Selesai
}
  • async menandai fungsi asinkron. Tipe kembaliannya dibungkus Future: return 'Ayu' menjadi Future<String>.
  • await menunggu Future selesai lalu mengambil nilainya. await hanya boleh dipakai di dalam fungsi async.
  • Selama menunggu, event loop bebas mengerjakan hal lain, misalnya menggambar ulang layar di Flutter.

then() vs await

Future<int> ambilJumlahSks() {
  return Future.delayed(const Duration(milliseconds: 300), () => 21);
}

Future<void> main() async {
  // Gaya 1: callback then()
  await ambilJumlahSks().then((sks) => print('then(): $sks SKS'));

  // Gaya 2: async/await (lebih mudah dibaca)
  final sks = await ambilJumlahSks();
  print('await: $sks SKS');
  // Output:
  // then(): 21 SKS
  // await: 21 SKS
}

Keduanya setara. async/await lebih disarankan karena kode terbaca berurutan dari atas ke bawah, terutama jika ada beberapa langkah yang saling bergantung.

Menangani error pada kode async

import 'dart:async';

Future<double> ambilIpk(String nim) async {
  await Future.delayed(const Duration(milliseconds: 300));
  if (!nim.startsWith('H1D')) {
    throw Exception('NIM $nim tidak ditemukan');
  }
  return 3.67;
}

Future<void> main() async {
  for (final nim in ['H1D023001', 'X999']) {
    try {
      final ipk = await ambilIpk(nim);
      print('$nim: IPK $ipk');
    } catch (e) {
      print('Gagal: $e');
    }
  }

  // Membatasi waktu tunggu
  try {
    await ambilIpk('H1D023001').timeout(const Duration(milliseconds: 100));
  } on TimeoutException {
    print('Server terlalu lama merespons');
  }
  // Output:
  // H1D023001: IPK 3.67
  // Gagal: Exception: NIM X999 tidak ditemukan
  // Server terlalu lama merespons
}

Dengan await, error dari Future bisa ditangkap memakai try/catch biasa, persis seperti kode sinkron. .timeout() melempar TimeoutException (dari dart:async) jika Future tidak selesai dalam batas waktu.

Menjalankan beberapa Future secara paralel

Jika beberapa permintaan tidak saling bergantung, jangan di-await satu per satu. Jalankan bersamaan dengan Future.wait.

Future<int> ambilNilai(String matkul) async {
  await Future.delayed(const Duration(milliseconds: 400));
  return switch (matkul) {
    'Mobile' => 88,
    'Web' => 79,
    _ => 70,
  };
}

Future<void> main() async {
  final nilai = await Future.wait([
    ambilNilai('Mobile'),
    ambilNilai('Web'),
    ambilNilai('AI'),
  ]);
  print(nilai); // Output: [88, 79, 70]
}

Ketiga permintaan berjalan bersamaan sehingga total waktunya sekitar 0,4 detik, bukan 1,2 detik. Urutan hasil selalu sama dengan urutan Future di dalam list.

Jika tipe hasilnya berbeda-beda, Dart 3 menyediakan .wait pada record:

Future<String> ambilProfil() async {
  await Future.delayed(const Duration(milliseconds: 500));
  return 'Profil Ayu';
}

Future<List<String>> ambilJadwal() async {
  await Future.delayed(const Duration(milliseconds: 500));
  return ['Mobile', 'Web'];
}

Future<int> ambilNotifikasi() async {
  await Future.delayed(const Duration(milliseconds: 500));
  return 3;
}

Future<void> main() async {
  final stopwatch = Stopwatch()..start();

  // Berurutan: total sekitar 1,5 detik
  final profil = await ambilProfil();
  final jadwal = await ambilJadwal();
  final notif = await ambilNotifikasi();
  print('Berurutan: $profil, $jadwal, $notif notifikasi');
  print('Lebih dari 1,4 detik? ${stopwatch.elapsedMilliseconds > 1400}');

  stopwatch.reset();

  // Paralel dengan record .wait: total sekitar 0,5 detik
  final (p, j, n) = await (ambilProfil(), ambilJadwal(), ambilNotifikasi()).wait;
  print('Paralel: $p, $j, $n notifikasi');
  print('Kurang dari 1 detik? ${stopwatch.elapsedMilliseconds < 1000}');
  // Output:
  // Berurutan: Profil Ayu, [Mobile, Web], 3 notifikasi
  // Lebih dari 1,4 detik? true
  // Paralel: Profil Ayu, [Mobile, Web], 3 notifikasi
  // Kurang dari 1 detik? true
}

Stream: rangkaian data dari waktu ke waktu

Jika Future menghasilkan satu nilai, Stream menghasilkan banyak nilai yang datang bergantian, misalnya pesan chat, posisi GPS, atau perubahan data realtime dari Supabase (Modul 12).

Future<void> main() async {
  final stream = Stream.fromIterable(['Ayu', 'Bima', 'Citra']);

  await for (final nama in stream) {
    print('Hadir: $nama');
  }
  print('Absensi selesai');
  // Output:
  // Hadir: Ayu
  // Hadir: Bima
  // Hadir: Citra
  // Absensi selesai
}

await for menunggu setiap data yang datang, lalu keluar dari perulangan ketika stream selesai.

Membuat Stream dengan async* dan yield

Stream<int> hitungMundur(int dari) async* {
  for (var i = dari; i >= 1; i--) {
    await Future.delayed(const Duration(milliseconds: 300));
    yield i; // kirim satu nilai ke pendengar
  }
}

Future<void> main() async {
  await for (final detik in hitungMundur(3)) {
    print('$detik...');
  }
  print('Ujian dimulai!');

  // Stream juga punya where, map, take, toList seperti List
  final hasil = await Stream.fromIterable([1, 2, 3, 4, 5, 6])
      .where((n) => n.isEven)
      .map((n) => n * 10)
      .toList();
  print(hasil);
  // Output:
  // 3...
  // 2...
  // 1...
  // Ujian dimulai!
  // [20, 40, 60]
}

Fungsi async* mengembalikan Stream. Setiap yield mengirim satu nilai tanpa mengakhiri fungsi, berbeda dengan return yang mengakhiri fungsi.

listen() dan StreamController

StreamController dipakai ketika kita ingin "mengirim" data ke stream secara manual, misalnya setiap kali isi keranjang belanja berubah.

import 'dart:async';

class Keranjang {
  final _controller = StreamController<int>();
  int _jumlah = 0;

  Stream<int> get jumlahStream => _controller.stream;

  void tambah() {
    _jumlah++;
    _controller.add(_jumlah); // kirim data baru ke stream
  }

  Future<void> tutup() => _controller.close();
}

Future<void> main() async {
  final keranjang = Keranjang();

  keranjang.jumlahStream.listen(
    (jumlah) => print('Isi keranjang: $jumlah'),
    onDone: () => print('Stream ditutup'),
  );

  keranjang.tambah();
  keranjang.tambah();
  keranjang.tambah();
  await keranjang.tutup(); // tunggu sampai semua data terkirim
  // Output:
  // Isi keranjang: 1
  // Isi keranjang: 2
  // Isi keranjang: 3
  // Stream ditutup
}

listen() mendaftarkan fungsi yang dipanggil setiap ada data baru. Secara default, stream hanya boleh punya satu pendengar; gunakan StreamController.broadcast() jika butuh banyak pendengar. Di Flutter, StreamBuilder melakukan listen secara otomatis dan membangun ulang widget setiap kali data baru datang.

⚠️ Kesalahan umum

  • Lupa await: variabel berisi Instance of 'Future<String>', bukan datanya.
  • Memakai await di fungsi yang tidak ditandai async, sehingga terjadi error compile.
  • Meng-await satu per satu permintaan yang sebenarnya bisa paralel. Gunakan Future.wait atau record .wait.
  • Lupa menutup StreamController atau membatalkan StreamSubscription (di Flutter, lakukan di dispose()), sehingga terjadi kebocoran memori.
