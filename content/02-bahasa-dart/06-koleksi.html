Koleksi menyimpan banyak nilai dalam satu variabel. Dart punya tiga koleksi utama: List (berurutan, boleh duplikat), Set (unik), dan Map (pasangan kunci-nilai). Hampir semua data di aplikasi, mulai dari daftar produk sampai respon JSON dari API, disimpan dalam koleksi.

List: dasar-dasar

void main() {
  List<String> buah = ['apel', 'jeruk'];
  buah.add('mangga'); // tambah di akhir
  buah.addAll(['salak', 'durian']); // tambah banyak sekaligus
  buah.insert(0, 'pisang'); // sisipkan di indeks 0

  print(buah); // Output: [pisang, apel, jeruk, mangga, salak, durian]
  print(buah.length); // Output: 6
  print(buah[1]); // Output: apel
  print(buah.first); // Output: pisang
  print(buah.last); // Output: durian
  print(buah.indexOf('mangga')); // Output: 3
  print(buah.contains('nanas')); // Output: false

  buah[1] = 'anggur'; // ubah elemen
  buah.remove('jeruk'); // hapus berdasarkan nilai
  buah.removeAt(0); // hapus berdasarkan indeks
  print(buah); // Output: [anggur, mangga, salak, durian]
  print(buah.sublist(1, 3)); // Output: [mangga, salak]
  print(buah.reversed.toList()); // Output: [durian, salak, mangga, anggur]
  print(buah.isEmpty); // Output: false
}

Indeks List dimulai dari 0. Mengakses indeks di luar jangkauan (misalnya buah[10]) menyebabkan RangeError. Tipe di dalam < > disebut generic: List<String> berarti list yang isinya hanya boleh String.

Membuat List secara otomatis

void main() {
  var kuadrat = List.generate(5, (i) => i * i);
  print(kuadrat); // Output: [0, 1, 4, 9, 16]

  var kursi = List.filled(3, 'kosong');
  print(kursi); // Output: [kosong, kosong, kosong]

  var kosong = <int>[]; // list kosong bertipe int
  print(kosong.length); // Output: 0
}

Set: koleksi tanpa duplikat

void main() {
  Set<String> hobi = {'coding', 'futsal', 'membaca'};
  hobi.add('coding'); // diabaikan karena sudah ada
  print(hobi); // Output: {coding, futsal, membaca}
  print(hobi.length); // Output: 3
  print(hobi.contains('membaca')); // Output: true

  var kelasA = {'Ayu', 'Bima', 'Citra'};
  var kelasB = {'Bima', 'Dodi', 'Citra'};
  print(kelasA.union(kelasB)); // Output: {Ayu, Bima, Citra, Dodi}
  print(kelasA.intersection(kelasB)); // Output: {Bima, Citra}
  print(kelasA.difference(kelasB)); // Output: {Ayu}

  // Trik populer: buang duplikat dari List
  var presensi = ['01', '02', '01', '03', '02'];
  print(presensi.toSet().toList()); // Output: [01, 02, 03]
}

⚠️ {} kosong adalah Map

var x = {}; menghasilkan Map, bukan Set. Untuk Set kosong tulis <String>{} atau Set<String> x = {};.

Map: pasangan kunci-nilai

void main() {
  Map<String, int> stok = {
    'pulpen': 20,
    'buku': 15,
  };

  stok['penggaris'] = 8; // tambah pasangan baru
  stok['buku'] = 12; // ubah nilai
  print(stok); // Output: {pulpen: 20, buku: 12, penggaris: 8}
  print(stok['pulpen']); // Output: 20
  print(stok['penghapus']); // Output: null
  print(stok.containsKey('buku')); // Output: true
  print(stok.keys); // Output: (pulpen, buku, penggaris)
  print(stok.values.toList()); // Output: [20, 12, 8]

  stok.remove('pulpen');
  stok.update('buku', (lama) => lama + 5);
  stok.putIfAbsent('spidol', () => 10);
  print(stok); // Output: {buku: 17, penggaris: 8, spidol: 10}

  for (final entry in stok.entries) {
    print('${entry.key} -> ${entry.value}');
  }
  // Output:
  // buku -> 17
  // penggaris -> 8
  // spidol -> 10
}

Mengakses kunci yang tidak ada menghasilkan null, bukan error. Karena itu tipe stok['x'] adalah int? (nullable).

Map<String, dynamic>: bentuk data JSON

Data JSON dari API (Modul 09) akan berbentuk Map<String, dynamic> karena nilainya bisa bermacam-macam tipe.

void main() {
  Map<String, dynamic> mahasiswa = {
    'nama': 'Nadia',
    'nim': 'H1D023005',
    'ipk': 3.75,
    'aktif': true,
    'matkul': ['Mobile', 'Web'],
  };

  String nama = mahasiswa['nama'] as String;
  double ipk = mahasiswa['ipk'] as double;
  List matkul = mahasiswa['matkul'] as List;

  print('$nama, IPK $ipk, ambil ${matkul.length} matkul'); // Output: Nadia, IPK 3.75, ambil 2 matkul
}

Method fungsional: map, where, fold, reduce, any, every

Method berikut menerima fungsi sebagai argumen (ingat higher-order function di section sebelumnya) dan membuat kode pengolahan data jauh lebih ringkas daripada perulangan manual.

void main() {
  List<int> nilai = [78, 92, 55, 64, 88, 40];

  var lulus = nilai.where((n) => n >= 60).toList();
  print(lulus); // Output: [78, 92, 64, 88]

  var plusBonus = nilai.map((n) => n + 5).toList();
  print(plusBonus); // Output: [83, 97, 60, 69, 93, 45]

  int total = nilai.fold(0, (jumlah, n) => jumlah + n);
  print(total); // Output: 417
  print(total / nilai.length); // Output: 69.5

  int tertinggi = nilai.reduce((a, b) => a > b ? a : b);
  print(tertinggi); // Output: 92

  print(nilai.any((n) => n < 50)); // Output: true
  print(nilai.every((n) => n >= 40)); // Output: true
  print(nilai.firstWhere((n) => n > 80)); // Output: 92
  print(nilai.take(2).toList()); // Output: [78, 92]
  print(nilai.skip(4).toList()); // Output: [88, 40]
  print(nilai.join(' | ')); // Output: 78 | 92 | 55 | 64 | 88 | 40
}
MethodFungsiHasil
whereMenyaring elemen yang memenuhi syaratIterable
mapMengubah setiap elemenIterable
foldMengakumulasi dengan nilai awalSatu nilai
reduceMengakumulasi tanpa nilai awal (list tidak boleh kosong)Satu nilai
any / everyAda yang memenuhi / semua memenuhibool
firstWhereElemen pertama yang memenuhi syaratSatu elemen

where dan map menghasilkan Iterable yang bersifat lazy (baru diproses ketika dibutuhkan). Tambahkan .toList() jika Anda butuh List sungguhan.

Mengurutkan dengan sort

void main() {
  var angka = [5, 2, 9, 1];
  angka.sort(); // naik (ascending)
  print(angka); // Output: [1, 2, 5, 9]
  angka.sort((a, b) => b.compareTo(a)); // turun (descending)
  print(angka); // Output: [9, 5, 2, 1]

  var nama = ['Citra', 'ayu', 'Bima'];
  nama.sort(); // huruf besar diurutkan lebih dulu
  print(nama); // Output: [Bima, Citra, ayu]
  nama.sort((a, b) => a.toLowerCase().compareTo(b.toLowerCase()));
  print(nama); // Output: [ayu, Bima, Citra]

  var mhs = [
    {'nama': 'Ayu', 'ipk': 3.4},
    {'nama': 'Bima', 'ipk': 3.9},
    {'nama': 'Citra', 'ipk': 3.6},
  ];
  mhs.sort((a, b) => (b['ipk'] as double).compareTo(a['ipk'] as double));
  print(mhs.map((m) => m['nama']).toList()); // Output: [Bima, Citra, Ayu]
}

Fungsi pembanding mengembalikan angka negatif jika a harus di depan, positif jika b di depan, dan 0 jika setara. compareTo sudah melakukan itu untuk kita. Perhatikan bahwa sort() mengubah list aslinya dan tidak mengembalikan nilai.

Spread, collection-if, dan collection-for

List<String>? ambilMatkulTambahan() => null; // anggap belum ada data

void main() {
  var wajib = ['Algoritma', 'Basis Data'];
  var pilihan = ['Pemrograman Mobile'];
  var tambahan = ambilMatkulTambahan();
  bool ambilMagang = true;

  var krs = [
    ...wajib, // sebar isi list wajib
    ...pilihan,
    ...?tambahan, // sebar hanya jika tidak null
    if (ambilMagang) 'Magang Industri',
    for (var i = 1; i <= 2; i++) 'Seminar $i',
  ];
  print(krs);
  // Output:
  // [Algoritma, Basis Data, Pemrograman Mobile, Magang Industri, Seminar 1, Seminar 2]

  var nilai = {'Ayu': 90, 'Bima': 55};
  var label = [
    for (final e in nilai.entries) '${e.key}: ${e.value >= 60 ? 'Lulus' : 'Gagal'}',
  ];
  print(label); // Output: [Ayu: Lulus, Bima: Gagal]
}

Fitur ini sangat sering dipakai di Flutter untuk menyusun children sebuah Column, misalnya children: [const Header(), if (isLogin) const Profil(), ...daftarMenu].

Merangkai method (chaining)

void main() {
  final belanja = [
    {'nama': 'Kopi', 'harga': 15000, 'kategori': 'minuman'},
    {'nama': 'Mendoan', 'harga': 10000, 'kategori': 'makanan'},
    {'nama': 'Es Teh', 'harga': 5000, 'kategori': 'minuman'},
    {'nama': 'Nasi Rames', 'harga': 18000, 'kategori': 'makanan'},
  ];

  final totalMinuman = belanja
      .where((b) => b['kategori'] == 'minuman')
      .map((b) => b['harga'] as int)
      .fold(0, (a, b) => a + b);
  print('Total minuman: Rp$totalMinuman'); // Output: Total minuman: Rp20000

  final namaMahal = belanja
      .where((b) => (b['harga'] as int) >= 15000)
      .map((b) => (b['nama'] as String).toUpperCase())
      .toList();
  print(namaMahal); // Output: [KOPI, NASI RAMES]
}

Baca rantai dari atas ke bawah: saring yang kategori minuman, ambil harganya, lalu jumlahkan. Gaya ini lebih mudah dibaca daripada for dengan banyak variabel sementara.

⚠️ Kesalahan umum

  • Lupa .toList() setelah map/where, lalu bingung kenapa tercetak (...) bukan [...].
  • Memanggil reduce atau first pada list kosong, sehingga muncul StateError: No element. Gunakan fold atau cek isEmpty dulu.
  • Menulis var hasil = list.sort();. sort() bertipe void, list aslinya yang terurut.
