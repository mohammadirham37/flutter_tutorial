Control flow menentukan baris mana yang dijalankan dan berapa kali. Ada dua kelompok besar: percabangan (if, switch) dan perulangan (for, while).

if, else if, else

void main() {
  double nilai = 78.5;

  if (nilai >= 85) {
    print('A');
  } else if (nilai >= 70) {
    print('B');
  } else if (nilai >= 55) {
    print('C');
  } else {
    print('D/E');
  }
  // Output: B
}

Kondisi diperiksa dari atas ke bawah, dan hanya blok pertama yang kondisinya benar yang dijalankan. Nilai 78.5 tidak memenuhi >= 85, tetapi memenuhi >= 70, sehingga pengecekan berhenti di situ. Kondisi di Dart harus bertipe bool; menulis if (1) seperti di C adalah error.

switch statement

void main() {
  String hari = 'Sabtu';

  switch (hari) {
    case 'Sabtu':
    case 'Minggu':
      print('Libur kuliah');
    case 'Jumat':
      print('Kuliah sampai jam 11');
    default:
      print('Kuliah seperti biasa');
  }
  // Output: Libur kuliah
}

Sejak Dart 3, break tidak wajib lagi: case yang berisi kode otomatis berhenti di akhir case-nya. Case yang kosong (seperti 'Sabtu') "jatuh" ke case berikutnya, sehingga Sabtu dan Minggu berbagi kode yang sama.

switch expression (Dart 3)

Switch expression adalah switch yang menghasilkan nilai. Bentuknya lebih ringkas: tidak ada case, tidak ada break, setiap cabang ditulis pola => nilai, dan _ berarti "selain itu".

void main() {
  String nilaiHuruf = 'B';
  int bobot = switch (nilaiHuruf) {
    'A' => 4,
    'B' => 3,
    'C' => 2,
    'D' => 1,
    _ => 0,
  };
  print('Bobot nilai $nilaiHuruf = $bobot'); // Output: Bobot nilai B = 3

  int nomorHari = 6;
  String jenisHari = switch (nomorHari) {
    6 || 7 => 'Akhir pekan',
    >= 1 && <= 5 => 'Hari kerja',
    _ => 'Nomor hari tidak valid',
  };
  print(jenisHari); // Output: Akhir pekan
}

6 || 7 berarti "6 atau 7", dan >= 1 && <= 5 berarti "di antara 1 sampai 5". Ini adalah pattern yang akan dibahas lebih dalam di section Fitur Modern Dart 3.

Perulangan for

void main() {
  for (int i = 1; i <= 3; i++) {
    print('Pertemuan ke-$i');
  }
  // Output:
  // Pertemuan ke-1
  // Pertemuan ke-2
  // Pertemuan ke-3

  // Perulangan bersarang (nested): tabel perkalian 3 x 3
  for (int baris = 1; baris <= 3; baris++) {
    String isi = '';
    for (int kolom = 1; kolom <= 3; kolom++) {
      isi += '${baris * kolom}'.padLeft(4);
    }
    print(isi);
  }
  // Output:
  //    1   2   3
  //    2   4   6
  //    3   6   9
}

Bagian for (inisialisasi; kondisi; perubahan): i mulai dari 1, perulangan berjalan selama i <= 3, dan setelah tiap putaran i bertambah 1.

for-in dan forEach

void main() {
  List<String> matkul = ['Pemrograman Mobile', 'Basis Data', 'Jaringan Komputer'];

  // for-in: ambil setiap elemen tanpa indeks
  for (final mk in matkul) {
    print('- $mk');
  }
  // Output:
  // - Pemrograman Mobile
  // - Basis Data
  // - Jaringan Komputer

  // for biasa jika butuh nomor urut
  for (int i = 0; i < matkul.length; i++) {
    print('${i + 1}. ${matkul[i]}');
  }
  // Output:
  // 1. Pemrograman Mobile
  // 2. Basis Data
  // 3. Jaringan Komputer

  // forEach dengan fungsi
  matkul.forEach((mk) => print(mk.toUpperCase()));
  // Output:
  // PEMROGRAMAN MOBILE
  // BASIS DATA
  // JARINGAN KOMPUTER
}

while dan do-while

void main() {
  int saldo = 100000;
  int hari = 0;
  while (saldo >= 25000) {
    saldo -= 25000;
    hari++;
  }
  print('Uang jajan cukup untuk $hari hari, sisa $saldo'); // Output: Uang jajan cukup untuk 4 hari, sisa 0

  int percobaan = 0;
  do {
    percobaan++;
    print('Percobaan login ke-$percobaan');
  } while (percobaan < 2);
  // Output:
  // Percobaan login ke-1
  // Percobaan login ke-2
}

while mengecek kondisi sebelum menjalankan isi perulangan, sedangkan do-while menjalankan isi minimal satu kali, baru mengecek kondisi di akhir. Gunakan while jika jumlah putaran tidak diketahui sejak awal.

break dan continue

void main() {
  List<int> daftarNilai = [80, 45, 90, -1, 70];

  for (final n in daftarNilai) {
    if (n < 0) {
      print('Data tidak valid, berhenti.');
      break; // keluar dari perulangan sepenuhnya
    }
    if (n < 60) {
      print('$n dilewati');
      continue; // lompat ke elemen berikutnya
    }
    print('$n lulus');
  }
  // Output:
  // 80 lulus
  // 45 dilewati
  // 90 lulus
  // Data tidak valid, berhenti.
}

Nilai 70 tidak pernah diproses karena break sudah menghentikan perulangan saat bertemu -1.

⚠️ Kesalahan umum

  • Infinite loop: lupa mengubah variabel kondisi di dalam while (misalnya lupa hari++), sehingga program tidak pernah berhenti.
  • Off-by-one: memakai i <= list.length padahal indeks terakhir adalah length - 1. Akibatnya muncul RangeError.
  • Lupa cabang _ pada switch expression untuk tipe int/String. Compiler akan menolak karena tidak semua kemungkinan tertangani.
