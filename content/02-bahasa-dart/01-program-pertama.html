Sebelum menulis aplikasi Flutter, kita perlu akrab dulu dengan bahasa yang menggerakkannya: Dart. Di modul ini semua contoh adalah program Dart murni (tanpa Flutter), jadi bisa dijalankan langsung di terminal atau di DartPad.

Di mana menjalankan kode Dart?

  • DartPad (dartpad.dev): cukup buka browser, tempel kode, klik Run. Cocok untuk mencoba potongan kode kecil.
  • Terminal: Dart SDK sudah ikut terpasang bersama Flutter (Modul 01). Simpan kode sebagai file .dart, lalu jalankan dengan dart run.
# Cek versi Dart (harus 3.x)
dart --version

# Cara 1: jalankan satu file
dart run halo.dart

# Cara 2: buat proyek console lengkap
dart create -t console belajar_dart
cd belajar_dart
dart run

Program pertama

Setiap program Dart dimulai dari fungsi main(). Saat program dijalankan, Dart mencari fungsi ini dan mengeksekusi isinya baris demi baris dari atas ke bawah.

📄 halo.dart

void main() {
  print('Halo, Dart!');
  print('Selamat datang di Praktikum Pemrograman Mobile');
}

// Output:
// Halo, Dart!
// Selamat datang di Praktikum Pemrograman Mobile
  • void artinya fungsi main tidak mengembalikan nilai apa pun.
  • print() menampilkan teks ke konsol, lalu pindah ke baris baru.
  • Setiap pernyataan (statement) diakhiri titik koma ;. Lupa titik koma adalah error paling sering bagi pemula.
  • Teks (String) ditulis di antara tanda kutip, boleh kutip satu '...' atau kutip dua "...".

ℹ️ Tentang komentar // Output:

Di seluruh modul ini, hasil yang muncul di konsol ditulis sebagai komentar // Output: .... Komentar tidak ikut dijalankan, jadi kode tetap bisa langsung disalin dan dijalankan.

Komentar

Komentar adalah catatan untuk manusia dan diabaikan oleh compiler. Dart punya tiga jenis komentar:

// Komentar satu baris: diabaikan oleh compiler.

/*
  Komentar banyak baris.
  Cocok untuk menonaktifkan sementara beberapa baris kode.
*/

/// Komentar dokumentasi (tiga garis miring).
/// Muncul sebagai tooltip saat kursor diarahkan ke nama fungsi di VS Code.
void sapa(String nama) {
  print('Halo, $nama!');
}

void main() {
  sapa('Rani'); // Output: Halo, Rani!
  // sapa('Budi'); baris ini tidak dijalankan karena dikomentari
}

Gunakan /// di atas class atau fungsi yang penting. Editor akan menampilkannya sebagai dokumentasi, sama seperti dokumentasi widget Flutter yang muncul saat Anda mengarahkan kursor ke Text atau Column.

Struktur file Dart

Sebuah file Dart biasanya berisi (berurutan): import, deklarasi tingkat atas (variabel, fungsi, class), dan fungsi main(). Urutan fungsi dan class di dalam file tidak berpengaruh, karena Dart membaca seluruh file terlebih dahulu.

import 'dart:math'; // 1. import library bawaan (opsional)

const namaKampus = 'UNSOED'; // 2. variabel tingkat atas (top-level)

int kuadrat(int x) {
  // 3. fungsi tingkat atas
  return x * x;
}

void main() {
  // 4. titik masuk program
  print(namaKampus); // Output: UNSOED
  print(kuadrat(7)); // Output: 49
  print(max(3, 9)); // Output: 9
}

Fungsi max() tidak kita tulis sendiri, melainkan berasal dari library dart:math yang di-import di baris pertama. Library bawaan lain yang sering dipakai: dart:async (Future dan Stream), dart:convert (JSON), dan dart:io (file dan terminal, tidak tersedia di web).

Argumen dari terminal

main() boleh menerima parameter List<String> berisi argumen yang diketik setelah nama file. Di Flutter, bentuk ini jarang dipakai, tetapi berguna untuk program console.

void main(List<String> args) {
  print('Jumlah argumen: ${args.length}');
  print('Isi argumen: $args');
}

// Output:
// Jumlah argumen: 0
// Isi argumen: []

Jika dijalankan dengan dart run argumen.dart halo dunia, hasilnya menjadi Jumlah argumen: 2 dan Isi argumen: [halo, dunia].

⚠️ Kesalahan umum pemula

  • Lupa titik koma ; di akhir statement.
  • Menulis Main() atau Print(). Dart membedakan huruf besar dan kecil (case-sensitive).
  • Kurung kurawal { } tidak berpasangan. Gunakan fitur Format Document (Shift+Alt+F) di VS Code agar indentasi rapi dan kesalahan mudah terlihat.
