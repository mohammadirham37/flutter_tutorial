Fungsi membungkus sekumpulan perintah agar bisa dipakai berulang kali dengan nama. Di Flutter, fungsi ada di mana-mana: build(), onPressed, itemBuilder, semuanya adalah fungsi. Memahami parameter bernama dan fungsi sebagai nilai adalah kunci membaca kode Flutter.

Fungsi dasar: parameter dan nilai kembali

double hitungLuas(double panjang, double lebar) {
  return panjang * lebar;
}

void sapa(String nama) {
  print('Halo, $nama!');
}

void main() {
  double luas = hitungLuas(4, 2.5);
  print(luas); // Output: 10.0
  sapa('Dimas'); // Output: Halo, Dimas!
}

Format umum: TipeKembali namaFungsi(TipeParam param) { ... }. Fungsi void tidak mengembalikan nilai. Fungsi yang punya tipe kembali wajib mengakhiri setiap jalurnya dengan return.

Arrow function =>

Jika isi fungsi hanya satu ekspresi, tulis dengan panah. => ekspresi sama dengan { return ekspresi; }.

int kuadrat(int x) => x * x;
bool isGenap(int x) => x % 2 == 0;
String salam(String nama) => 'Selamat pagi, $nama';

// Fungsi rekursif (memanggil dirinya sendiri)
int faktorial(int n) => n <= 1 ? 1 : n * faktorial(n - 1);

void main() {
  print(kuadrat(9)); // Output: 81
  print(isGenap(7)); // Output: false
  print(salam('Ayu')); // Output: Selamat pagi, Ayu
  print(faktorial(5)); // Output: 120
}

Parameter posisi opsional [ ]

String perkenalan(String nama, [String asal = 'Purwokerto', int? umur]) {
  var teks = 'Saya $nama dari $asal';
  if (umur != null) {
    teks += ', umur $umur tahun';
  }
  return teks;
}

void main() {
  print(perkenalan('Rani')); // Output: Saya Rani dari Purwokerto
  print(perkenalan('Bayu', 'Cilacap')); // Output: Saya Bayu dari Cilacap
  print(perkenalan('Sari', 'Banyumas', 19)); // Output: Saya Sari dari Banyumas, umur 19 tahun
}

Parameter di dalam [ ] boleh tidak diisi. Isinya bisa diberi nilai default (asal = 'Purwokerto') atau bertipe nullable (int? umur) yang otomatis bernilai null. Kelemahannya: urutan argumen harus diingat.

Named parameter { }, required, dan default

Named parameter dipanggil dengan menyebut namanya, sehingga urutan bebas dan kode mudah dibaca. Gaya inilah yang dipakai hampir semua widget Flutter, misalnya Text('Halo', style: ..., maxLines: 2).

void daftarMahasiswa({
  required String nama,
  required String nim,
  String prodi = 'Informatika',
  int? semester,
}) {
  print('$nim - $nama ($prodi), semester: ${semester ?? '-'}');
}

void main() {
  daftarMahasiswa(nama: 'Ayu', nim: 'H1D023010');
  daftarMahasiswa(
    nim: 'H1D023011',
    nama: 'Bima',
    semester: 3,
    prodi: 'Teknik Elektro',
  );
  // daftarMahasiswa(nama: 'Cici'); // ERROR: parameter nim wajib diisi

  // Output:
  // H1D023010 - Ayu (Informatika), semester: -
  // H1D023011 - Bima (Teknik Elektro), semester: 3
}

Posisi wajibf(int a)f(1)
Posisi opsionalf([int a = 0])f() atau f(1)
Named opsionalf({int a = 0}) / f({int? a})f() atau f(a: 1)

Parameter posisi dan named boleh digabung, asalkan yang posisi ditulis lebih dulu, misalnya void kirim(String tujuan, {bool penting = false}).

Fungsi sebagai nilai dan fungsi anonim

Di Dart, fungsi adalah objek: bisa disimpan di variabel, dikirim sebagai argumen, dan dikembalikan dari fungsi lain. Fungsi tanpa nama disebut fungsi anonim (lambda).

void main() {
  // Fungsi anonim disimpan dalam variabel bertipe fungsi
  int Function(int, int) tambah = (a, b) => a + b;
  print(tambah(2, 3)); // Output: 5

  // Fungsi anonim dengan body blok
  var cetakBintang = (int n) {
    print('*' * n);
  };
  cetakBintang(5); // Output: *****

  // Fungsi anonim langsung dipakai sebagai argumen
  var angka = [3, 1, 2];
  angka.forEach((n) {
    print('angka $n');
  });
  // Output:
  // angka 3
  // angka 1
  // angka 2
}

Bentuk (n) { ... } dan (n) => ... inilah yang Anda tulis di Flutter, misalnya onPressed: () { ... }.

Closure: fungsi yang "mengingat" variabel

int Function() buatPenghitung() {
  int hitung = 0;
  return () {
    hitung++;
    return hitung;
  };
}

void main() {
  var klikTombolA = buatPenghitung();
  var klikTombolB = buatPenghitung();

  print(klikTombolA()); // Output: 1
  print(klikTombolA()); // Output: 2
  print(klikTombolA()); // Output: 3
  print(klikTombolB()); // Output: 1
}

Fungsi yang dikembalikan tetap bisa mengakses variabel hitung walaupun buatPenghitung() sudah selesai dijalankan. Setiap pemanggilan buatPenghitung() membuat variabel hitung sendiri, sehingga penghitung A dan B tidak saling mengganggu.

Higher-order function

Fungsi yang menerima fungsi lain sebagai parameter, atau mengembalikan fungsi, disebut higher-order function.

int hitung(int a, int b, int Function(int, int) operasi) {
  return operasi(a, b);
}

int Function(int) pengali(int faktor) {
  return (x) => x * faktor;
}

int kuadrat(int x) => x * x;

void main() {
  print(hitung(10, 4, (a, b) => a + b)); // Output: 14
  print(hitung(10, 4, (a, b) => a * b)); // Output: 40

  final kaliDua = pengali(2);
  final kaliTiga = pengali(3);
  print(kaliDua(5)); // Output: 10
  print(kaliTiga(5)); // Output: 15

  // Mengirim fungsi yang sudah ada tanpa tanda kurung (tear-off)
  print([1, 2, 3].map(kuadrat).toList()); // Output: [1, 4, 9]
}

typedef dan callback

typedef memberi nama untuk tipe fungsi agar mudah dibaca. Flutter memakai pola ini, misalnya VoidCallback dan ValueChanged<T>.

typedef SaatDitekan = void Function(String namaTombol);

void buatTombol(String label, {required SaatDitekan onPressed}) {
  print('[Tombol $label dibuat]');
  onPressed(label); // simulasi pengguna menekan tombol
}

void main() {
  buatTombol('Simpan', onPressed: (nama) {
    print('Tombol $nama ditekan, data disimpan.');
  });
  // Output:
  // [Tombol Simpan dibuat]
  // Tombol Simpan ditekan, data disimpan.
}

Pola ini sama persis dengan ElevatedButton(onPressed: () { ... }): kita "menitipkan" fungsi, lalu widget yang memanggilnya ketika tombol benar-benar ditekan.

⚠️ Kesalahan umum

  • onPressed: simpan() memanggil fungsi saat itu juga dan mengirim hasilnya. Yang benar onPressed: simpan (tear-off) atau onPressed: () => simpan().
  • Lupa return pada fungsi blok yang punya tipe kembali.
  • Menulis arrow function dengan blok: () => { ... }. Di Dart, ini bukan blok, melainkan Set literal. Gunakan () { ... }.
