Dart 3 menambahkan fitur yang membuat kode lebih ringkas dan lebih aman: records (mengelompokkan beberapa nilai tanpa membuat class), patterns (membongkar dan mencocokkan bentuk data), serta sealed class (switch yang dijamin lengkap oleh compiler).

Records

Record adalah kumpulan beberapa nilai yang dibungkus jadi satu, ditulis dengan tanda kurung. Field-nya bisa berdasarkan posisi (diakses dengan $1, $2, ...) atau bernama.

void main() {
  var mhs = ('Ayu', 3.75); // record posisi
  print(mhs.$1); // Output: Ayu
  print(mhs.$2); // Output: 3.75

  ({String nama, int sks}) matkul = (nama: 'Pemrograman Mobile', sks: 3);
  print(matkul.nama); // Output: Pemrograman Mobile
  print(matkul); // Output: (nama: Pemrograman Mobile, sks: 3)

  var campur = ('H1D023001', nama: 'Ayu', aktif: true); // posisi + bernama
  print(campur.$1); // Output: H1D023001
  print(campur.aktif); // Output: true

  // Record dibandingkan berdasarkan isinya
  print(('Ayu', 20) == ('Ayu', 20)); // Output: true
}

Fungsi yang mengembalikan beberapa nilai

Sebelum Dart 3, mengembalikan lebih dari satu nilai harus memakai List, Map, atau class khusus. Dengan record, cukup tulis tipe kembalian sebagai record.

({double rataRata, int tertinggi, int terendah}) hitungStatistik(List<int> nilai) {
  final urut = [...nilai]..sort();
  final total = nilai.fold(0, (a, b) => a + b);
  return (
    rataRata: total / nilai.length,
    tertinggi: urut.last,
    terendah: urut.first,
  );
}

void main() {
  final s = hitungStatistik([80, 65, 90, 75]);
  print('Rata-rata: ${s.rataRata}'); // Output: Rata-rata: 77.5
  print('Tertinggi: ${s.tertinggi}'); // Output: Tertinggi: 90
  print('Terendah: ${s.terendah}'); // Output: Terendah: 65

  // Langsung dibongkar (destructuring) ke variabel
  final (:rataRata, :tertinggi, :terendah) = hitungStatistik([60, 70]);
  print('$rataRata $tertinggi $terendah'); // Output: 65.0 70 60
}

[...nilai]..sort() menyalin list dulu sebelum diurutkan agar list asli tidak berubah. :rataRata adalah singkatan dari rataRata: rataRata.

Destructuring

Destructuring berarti membongkar isi record, List, atau Map langsung ke beberapa variabel.

void main() {
  var (nama, ipk) = ('Bima', 3.6);
  print('$nama: $ipk'); // Output: Bima: 3.6

  // Menukar dua variabel tanpa variabel bantu
  var a = 1;
  var b = 2;
  (a, b) = (b, a);
  print('a=$a, b=$b'); // Output: a=2, b=1

  // List pattern dengan rest element (...)
  var [pertama, kedua, ...sisa] = [10, 20, 30, 40];
  print('$pertama $kedua $sisa'); // Output: 10 20 [30, 40]

  // Destructuring di for-in: Map entries
  final nilai = {'Ayu': 90, 'Bima': 78};
  for (final MapEntry(:key, :value) in nilai.entries) {
    print('$key mendapat $value');
  }
  // Output:
  // Ayu mendapat 90
  // Bima mendapat 78

  // .indexed menghasilkan record (indeks, elemen)
  for (final (i, mk) in ['Mobile', 'Web'].indexed) {
    print('${i + 1}. $mk');
  }
  // Output:
  // 1. Mobile
  // 2. Web
}

Pattern matching di switch

Pattern di switch bisa mencocokkan rentang nilai (relational pattern), tipe, bentuk List, dan record, ditambah syarat tambahan dengan when (guard).

String kategoriNilai(int nilai) => switch (nilai) {
      >= 85 && <= 100 => 'Sangat baik',
      >= 70 && < 85 => 'Baik',
      >= 60 && < 70 => 'Cukup',
      >= 0 && < 60 => 'Kurang',
      _ => 'Nilai tidak valid',
    };

void main() {
  print(kategoriNilai(91)); // Output: Sangat baik
  print(kategoriNilai(70)); // Output: Baik
  print(kategoriNilai(59)); // Output: Kurang
  print(kategoriNilai(120)); // Output: Nilai tidak valid
}

String jelaskan(Object data) => switch (data) {
      int n when n < 0 => 'Bilangan negatif $n',
      int n => 'Bilangan bulat $n',
      double d => 'Desimal ${d.toStringAsFixed(1)}',
      String s when s.isEmpty => 'Teks kosong',
      String s => 'Teks "$s" (${s.length} huruf)',
      [] => 'List kosong',
      [var x] => 'List berisi satu: $x',
      [var x, ...] => 'List diawali $x',
      (String nama, int umur) => 'Record: $nama umur $umur',
      _ => 'Tipe lain: ${data.runtimeType}',
    };

void main() {
  print(jelaskan(-5)); // Output: Bilangan negatif -5
  print(jelaskan(42)); // Output: Bilangan bulat 42
  print(jelaskan(3.14159)); // Output: Desimal 3.1
  print(jelaskan('')); // Output: Teks kosong
  print(jelaskan('Dart')); // Output: Teks "Dart" (4 huruf)
  print(jelaskan([])); // Output: List kosong
  print(jelaskan([7])); // Output: List berisi satu: 7
  print(jelaskan([1, 2, 3])); // Output: List diawali 1
  print(jelaskan(('Ayu', 20))); // Output: Record: Ayu umur 20
  print(jelaskan(true)); // Output: Tipe lain: bool
}

Cabang dicek dari atas ke bawah. int n when n < 0 artinya "jika data bertipe int, simpan sebagai n, dan nilainya negatif". Karena itu cabang yang lebih spesifik harus ditulis lebih dulu.

if-case: validasi bentuk data

Pattern juga bisa dipakai di if dengan kata kunci case. Ini sangat praktis untuk memeriksa JSON: cek kunci yang wajib ada sekaligus tipenya, lalu langsung ambil nilainya.

void prosesJson(Map<String, dynamic> json) {
  if (json case {'nama': String nama, 'ipk': double ipk}) {
    print('Valid: $nama, IPK $ipk');
  } else {
    print('Format JSON tidak sesuai: $json');
  }
}

void main() {
  prosesJson({'nama': 'Ayu', 'ipk': 3.8}); // Output: Valid: Ayu, IPK 3.8
  prosesJson({'nama': 'Bima'}); // Output: Format JSON tidak sesuai: {nama: Bima}
  prosesJson({'nama': 'Citra', 'ipk': '3.5'}); // Output: Format JSON tidak sesuai: {nama: Citra, ipk: 3.5}
}

Data ketiga ditolak karena '3.5' adalah String, bukan double. Tanpa pattern, kita harus menulis beberapa if dan is secara manual.

Object pattern

Object pattern mencocokkan objek berdasarkan nilai getter/field-nya.

class Mahasiswa {
  final String nama;
  final int semester;
  final double ipk;
  const Mahasiswa(this.nama, this.semester, this.ipk);
}

String evaluasi(Mahasiswa m) => switch (m) {
      Mahasiswa(semester: > 14) => '${m.nama}: melewati batas masa studi',
      Mahasiswa(:var nama, ipk: >= 3.5) => '$nama: kandidat cumlaude',
      Mahasiswa(:var nama, :var ipk) when ipk < 2.0 => '$nama: peringatan akademik',
      Mahasiswa(:var nama) => '$nama: normal',
    };

void main() {
  print(evaluasi(const Mahasiswa('Ayu', 5, 3.8))); // Output: Ayu: kandidat cumlaude
  print(evaluasi(const Mahasiswa('Bima', 15, 3.0))); // Output: Bima: melewati batas masa studi
  print(evaluasi(const Mahasiswa('Citra', 4, 1.9))); // Output: Citra: peringatan akademik
  print(evaluasi(const Mahasiswa('Dodi', 6, 3.1))); // Output: Dodi: normal
}

Sealed class dan exhaustive switch

sealed class adalah abstract class yang turunannya hanya boleh ditulis di file yang sama. Karena compiler tahu semua turunannya, switch terhadap sealed class tidak perlu cabang _, dan compiler akan memberi error jika ada turunan yang terlewat. Ini disebut exhaustive checking.

sealed class HasilLogin {}

class LoginBerhasil extends HasilLogin {
  final String nama;
  LoginBerhasil(this.nama);
}

class PasswordSalah extends HasilLogin {
  final int sisaPercobaan;
  PasswordSalah(this.sisaPercobaan);
}

class AkunDiblokir extends HasilLogin {}

HasilLogin login(String username, String password) {
  if (username == 'admin') return AkunDiblokir();
  if (password == 'rahasia') return LoginBerhasil(username);
  return PasswordSalah(2);
}

String pesanUntuk(HasilLogin hasil) => switch (hasil) {
      LoginBerhasil(:final nama) => 'Selamat datang, $nama!',
      PasswordSalah(:final sisaPercobaan) =>
        'Password salah. Sisa percobaan: $sisaPercobaan',
      AkunDiblokir() => 'Akun diblokir, hubungi admin.',
    };

void main() {
  print(pesanUntuk(login('ayu', 'rahasia'))); // Output: Selamat datang, ayu!
  print(pesanUntuk(login('ayu', '12345'))); // Output: Password salah. Sisa percobaan: 2
  print(pesanUntuk(login('admin', 'apa saja'))); // Output: Akun diblokir, hubungi admin.
}

Coba hapus baris AkunDiblokir() => ..., lalu jalankan dart analyze. Compiler akan menolak dengan pesan bahwa tipe HasilLogin tidak tertangani secara lengkap (not exhaustively matched).

Pola yang sama sangat cocok untuk status pemuatan data di aplikasi (Memuat, Sukses, Gagal), yang akan Anda pakai bersama Provider dan REST API:

sealed class StatusData {}

class Memuat extends StatusData {}

class Sukses extends StatusData {
  final List<String> data;
  Sukses(this.data);
}

class Gagal extends StatusData {
  final String pesan;
  Gagal(this.pesan);
}

String tampilan(StatusData status) => switch (status) {
      Memuat() => 'Menampilkan loading...',
      Sukses(data: []) => 'Belum ada data',
      Sukses(:final data) => 'Menampilkan ${data.length} item',
      Gagal(:final pesan) => 'Error: $pesan',
    };

void main() {
  print(tampilan(Memuat())); // Output: Menampilkan loading...
  print(tampilan(Sukses([]))); // Output: Belum ada data
  print(tampilan(Sukses(['Ayu', 'Bima']))); // Output: Menampilkan 2 item
  print(tampilan(Gagal('Koneksi terputus'))); // Output: Error: Koneksi terputus
}

Di Flutter, fungsi seperti tampilan() akan mengembalikan widget (misalnya CircularProgressIndicator() atau ListView), bukan String.

Class modifier (ringkas)

Dart 3 menambahkan kata kunci untuk mengatur bagaimana class boleh dipakai dari file/library lain. Di dalam file yang sama, batasan ini tidak berlaku.

Kombinasi yang paling sering dipakai di aplikasi adalah abstract interface class untuk kontrak repository, sehingga sumber data mudah diganti (misalnya data palsu untuk testing di Modul 15):

abstract interface class MahasiswaRepository {
  List<String> ambilSemuaNama();
}

final class RepositoryMemori implements MahasiswaRepository {
  final _data = ['Ayu', 'Bima', 'Citra'];

  @override
  List<String> ambilSemuaNama() => List.unmodifiable(_data);
}

void tampilkan(MahasiswaRepository repo) {
  print(repo.ambilSemuaNama().join(', '));
}

void main() {
  tampilkan(RepositoryMemori()); // Output: Ayu, Bima, Citra
}

💡 Ringkasan

  • Record: kembalikan beberapa nilai sekaligus tanpa membuat class.
  • Destructuring: var (a, b) = ..., var [x, ...sisa] = ..., for (final (i, e) in list.indexed).
  • Pattern di switch dan if-case: cocokkan rentang, tipe, dan bentuk data.
  • Sealed class: kumpulan status yang terbatas, dan compiler memastikan semuanya ditangani.
