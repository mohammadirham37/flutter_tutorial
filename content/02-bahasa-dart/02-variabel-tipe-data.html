Variabel adalah "kotak bernama" untuk menyimpan data. Dart adalah bahasa yang strongly typed (setiap nilai punya tipe yang jelas), tetapi punya type inference sehingga kita sering tidak perlu menulis tipenya secara manual.

Tipe data dasar

TipeIsiContoh
intBilangan bulatint sks = 3;
doubleBilangan desimaldouble ipk = 3.75;
numBisa int atau doublenum nilai = 80;
StringTeksString nama = 'Ayu';
booltrue atau falsebool aktif = true;
dynamicTipe bebas, pemeriksaan tipe dimatikandynamic data = 1;

Deklarasi dengan tipe eksplisit dan var

void main() {
  // Tipe ditulis eksplisit
  String nama = 'Ahmad Fikri';
  int semester = 5;
  double ipk = 3.84;
  bool aktif = true;

  // Tipe ditebak otomatis dari nilai awal (type inference)
  var jurusan = 'Informatika'; // dianggap String
  var angkatan = 2023; // dianggap int

  print(nama); // Output: Ahmad Fikri
  print(semester); // Output: 5
  print(ipk); // Output: 3.84
  print(aktif); // Output: true
  print(jurusan.runtimeType); // Output: String
  print(angkatan.runtimeType); // Output: int

  semester = 6; // variabel biasa boleh diubah nilainya
  print(semester); // Output: 6

  // jurusan = 123; // ERROR: jurusan sudah bertipe String
}

var bukan berarti "tipe bebas". Begitu diisi 'Informatika', tipe jurusan terkunci menjadi String. Properti runtimeType dipakai untuk melihat tipe sebuah nilai saat program berjalan.

Angka: int, double, dan num

void main() {
  int sks = 3;
  double nilai = 87.5;
  num apaSaja = 10; // num bisa menampung int maupun double
  apaSaja = 10.5;

  print(sks + 1); // Output: 4
  print(nilai / 2); // Output: 43.75
  print(apaSaja); // Output: 10.5

  double rata = 7; // literal int otomatis diubah menjadi double
  print(rata); // Output: 7.0
  print(1e3); // Output: 1000.0
  print(0xFF); // Output: 255
  print(1000000 == 1_000_000); // Output: true
}

Garis bawah pada 1_000_000 hanya pemisah agar angka besar mudah dibaca (fitur Dart 3.6 ke atas). Nilainya sama persis dengan 1000000.

ℹ️ Perbedaan output di DartPad

DartPad menjalankan kode sebagai JavaScript, sehingga double yang nilainya bulat dicetak tanpa .0 (misalnya 7, bukan 7.0). Output di modul ini mengikuti dart run di terminal.

String: kutip, escape, multi-baris, raw

void main() {
  String a = 'kutip satu';
  String b = "kutip dua";
  String c = "Jum'at"; // kutip satu di dalam kutip dua
  String d = 'Jum\'at'; // atau di-escape dengan backslash

  String multi = '''
Baris pertama
Baris kedua''';

  String raw = r'C:\folder\baru'; // raw string: backslash tidak diproses

  print(a); // Output: kutip satu
  print(b); // Output: kutip dua
  print(c); // Output: Jum'at
  print(d); // Output: Jum'at
  print(multi);
  // Output:
  // Baris pertama
  // Baris kedua
  print(raw); // Output: C:\folder\baru
  print('Baris 1\nBaris 2');
  // Output:
  // Baris 1
  // Baris 2
}

\n adalah karakter baris baru dan \t adalah tab. Awalan r membuat raw string sehingga backslash dicetak apa adanya, berguna untuk path Windows dan pola RegExp.

String interpolation

Untuk menyisipkan nilai ke dalam teks, gunakan $nama untuk variabel sederhana dan ${ekspresi} untuk ekspresi (perhitungan, pemanggilan method, akses properti).

void main() {
  String nama = 'Nadia';
  int sks = 21;
  double ipk = 3.756;

  print('Nama: $nama'); // Output: Nama: Nadia
  print('SKS semester depan: ${sks + 3}'); // Output: SKS semester depan: 24
  print('Panjang nama: ${nama.length} huruf'); // Output: Panjang nama: 5 huruf
  print('IPK: ${ipk.toStringAsFixed(2)}'); // Output: IPK: 3.76
  print('Huruf besar: ${nama.toUpperCase()}'); // Output: Huruf besar: NADIA

  // Menyambung dengan + juga bisa, tetapi interpolasi lebih disarankan
  print('Halo, ' + nama + '!'); // Output: Halo, Nadia!
}

⚠️ Lupa kurung kurawal

'$nama.length' akan mencetak Nadia.length, bukan 5, karena tanpa { } Dart hanya mengambil nama variabelnya. Tulis '${nama.length}'.

Method String yang sering dipakai

void main() {
  String nim = '  H1D023001  ';
  String bersih = nim.trim(); // buang spasi di awal dan akhir

  print(bersih); // Output: H1D023001
  print(bersih.length); // Output: 9
  print(bersih.toLowerCase()); // Output: h1d023001
  print(bersih.startsWith('H1D')); // Output: true
  print(bersih.contains('023')); // Output: true
  print(bersih.substring(3, 5)); // Output: 02
  print(bersih[0]); // Output: H
  print(bersih.replaceAll('0', 'o')); // Output: H1Do23oo1
  print('Flutter,Dart,Supabase'.split(',')); // Output: [Flutter, Dart, Supabase]
  print('7'.padLeft(3, '0')); // Output: 007
  print('ab' * 3); // Output: ababab
  print(''.isEmpty); // Output: true
}

substring(3, 5) mengambil karakter dari indeks 3 sampai sebelum indeks 5. Indeks String selalu dimulai dari 0.

final, const, dan late

void main() {
  final String namaKampus = 'UNSOED';
  final waktuMulai = DateTime.now(); // nilainya baru diketahui saat program berjalan
  const double nilaiMaksimal = 4.0;
  const jumlahJamSeminggu = 7 * 24; // ekspresi konstan, dihitung saat kompilasi

  // namaKampus = 'UGM'; // ERROR: final hanya bisa diisi sekali
  // nilaiMaksimal = 5.0; // ERROR: const tidak bisa diubah
  // const sekarang = DateTime.now(); // ERROR: DateTime.now() bukan nilai compile-time

  print(namaKampus); // Output: UNSOED
  print(nilaiMaksimal); // Output: 4.0
  print(jumlahJamSeminggu); // Output: 168
  print(waktuMulai.year > 2000); // Output: true
}
Kata kunciBisa diubah?Kapan nilainya ditentukan?Contoh pemakaian

finalTidak (sekali isi)Saat program berjalan (runtime)Data dari API, waktu login

final mengunci variabelnya, bukan isi objeknya. List yang final masih bisa ditambah isinya, sedangkan list const benar-benar beku:

void main() {
  final daftarFinal = ['Dart', 'Flutter'];
  daftarFinal.add('Supabase'); // boleh: isi list bisa berubah
  print(daftarFinal); // Output: [Dart, Flutter, Supabase]
  // daftarFinal = []; // ERROR: variabelnya tidak bisa diganti

  const daftarConst = ['Dart', 'Flutter'];
  print(daftarConst.length); // Output: 2
  // daftarConst.add('Hive'); // ERROR saat runtime: Unsupported operation
}

late menandai variabel yang pasti diisi nanti sebelum dibaca. late final juga bisa dipakai untuk inisialisasi malas (lazy): nilai baru dihitung saat pertama kali dipakai.

late String token; // akan diisi oleh fungsi login()

void login() {
  token = 'abc123';
}

int hitungBerat() {
  print('Menghitung...');
  return 42;
}

void main() {
  login();
  print('Token: $token'); // Output: Token: abc123

  late final int hasil = hitungBerat(); // belum dihitung di baris ini
  print('Sebelum memakai hasil');
  print(hasil); // baru dihitung di sini

  // Output:
  // Sebelum memakai hasil
  // Menghitung...
  // 42
}

var vs dynamic vs Object

void main() {
  var a = 10; // tipe terkunci: int
  dynamic b = 10; // tipe boleh berganti, tanpa pemeriksaan compiler
  Object c = 10; // menampung apa saja, tetapi tetap diperiksa compiler

  b = 'sekarang String';
  c = true;
  // a = 'teks'; // ERROR: a bertipe int

  print(a); // Output: 10
  print(b); // Output: sekarang String
  print(c); // Output: true

  // print(c.length); // ERROR compile: Object tidak punya length
  // print(b.panjangSekali); // lolos compile, tetapi CRASH saat runtime
}

Hindari dynamic kecuali benar-benar perlu (misalnya data JSON mentah). Dengan dynamic, salah ketik nama properti baru ketahuan ketika aplikasi sudah berjalan.

Konversi tipe

void main() {
  // String -> angka
  int umur = int.parse('20');
  double ipk = double.parse('3.75');
  print(umur + 1); // Output: 21
  print(ipk); // Output: 3.75

  // tryParse mengembalikan null jika gagal (tidak crash)
  int? gagal = int.tryParse('dua puluh');
  print(gagal); // Output: null

  // angka -> String
  String teks = 42.toString();
  print(teks + '!'); // Output: 42!
  print(3.14159.toStringAsFixed(2)); // Output: 3.14

  // double -> int (toInt memotong, round membulatkan)
  print(9.7.toInt()); // Output: 9
  print(9.7.round()); // Output: 10
  print(9.2.ceil()); // Output: 10
  print(9.7.floor()); // Output: 9

  // int -> double
  print(5.toDouble()); // Output: 5.0
}

Gunakan int.tryParse() untuk input dari pengguna (misalnya dari TextField di Modul 05), karena pengguna bisa saja mengetik huruf. int.parse() akan melempar FormatException jika teksnya bukan angka.

💡 Ringkasan

  • Pakai final secara default. Ganti ke var hanya jika nilainya memang perlu berubah.
  • Pakai const untuk nilai yang sudah pasti sejak kode ditulis.
  • Gunakan interpolasi '$x' / '${ekspresi}' untuk menyusun teks.
  • Selalu pakai tryParse untuk input yang belum tentu valid.
