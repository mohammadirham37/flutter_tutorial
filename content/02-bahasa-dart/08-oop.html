Flutter sepenuhnya berbasis Object-Oriented Programming (OOP): setiap widget adalah objek dari sebuah class. Section ini membahas OOP di Dart secara bertahap, mulai dari class sederhana sampai mixin, extension, dan enum.

1. Class dan objek

Class adalah cetakan, objek adalah hasil cetakannya. Class berisi field (data) dan method (perilaku).

class Mahasiswa {
  String nama;
  String nim;
  int semester;

  // Constructor singkat: langsung mengisi field
  Mahasiswa(this.nama, this.nim, this.semester);

  void perkenalan() {
    print('Halo, saya $nama ($nim), semester $semester.');
  }

  void naikSemester() {
    semester++;
  }
}

void main() {
  var ayu = Mahasiswa('Ayu', 'H1D023001', 3);
  var bima = Mahasiswa('Bima', 'H1D023002', 5);

  ayu.perkenalan();
  ayu.naikSemester();
  ayu.perkenalan();
  bima.perkenalan();
  // Output:
  // Halo, saya Ayu (H1D023001), semester 3.
  // Halo, saya Ayu (H1D023001), semester 4.
  // Halo, saya Bima (H1D023002), semester 5.
}

Kata kunci new tidak diperlukan di Dart modern. ayu dan bima adalah dua objek terpisah: mengubah semester ayu tidak memengaruhi bima.

2. Variasi constructor

class Buku {
  final String judul;
  final String penulis;
  final int tahun;
  final int stok;

  // a. Constructor utama dengan named parameter
  Buku({
    required this.judul,
    required this.penulis,
    this.tahun = 2024,
    this.stok = 0,
  });

  // b. Named constructor: cara lain membuat objek
  Buku.ebook(this.judul, this.penulis)
      : tahun = 2025,
        stok = 999;

  // c. Redirecting constructor: meneruskan ke constructor utama
  Buku.anonim(String judul) : this(judul: judul, penulis: 'Anonim');

  @override
  String toString() => '$judul oleh $penulis ($tahun), stok $stok';
}

void main() {
  print(Buku(judul: 'Dart Dasar', penulis: 'Rina', stok: 5));
  print(Buku.ebook('Flutter Cepat', 'Andi'));
  print(Buku.anonim('Catatan Kuliah'));
  // Output:
  // Dart Dasar oleh Rina (2024), stok 5
  // Flutter Cepat oleh Andi (2025), stok 999
  // Catatan Kuliah oleh Anonim (2024), stok 0
}

Method toString() di-override agar print(objek) menampilkan teks yang informatif, bukan Instance of 'Buku'. Named constructor sering ditemui di Flutter, misalnya ListView.builder dan EdgeInsets.all.

3. Initializer list dan assert

Bagian setelah tanda : pada constructor disebut initializer list. Bagian ini dijalankan sebelum body constructor dan cocok untuk mengisi field final hasil perhitungan.

class Mahasiswa {
  final String nim;
  final String nama;
  final String angkatan;

  Mahasiswa(this.nim, String nama)
      : assert(nim.length == 9, 'NIM harus 9 karakter'),
        nama = nama.trim(),
        angkatan = '20${nim.substring(4, 6)}';
}

void main() {
  final m = Mahasiswa('H1D023001', '  Ayu Lestari ');
  print('[${m.nama}]'); // Output: [Ayu Lestari]
  print(m.angkatan); // Output: 2023
}

assert hanya aktif saat mode debug (Flutter flutter run, atau dart run --enable-asserts). Jika kondisinya salah, program berhenti dengan pesan yang diberikan.

4. Const constructor

class Warna {
  final int r, g, b;
  const Warna(this.r, this.g, this.b);
}

void main() {
  const merah1 = Warna(255, 0, 0);
  const merah2 = Warna(255, 0, 0);
  print(identical(merah1, merah2)); // Output: true

  final biru1 = Warna(0, 0, 255);
  final biru2 = Warna(0, 0, 255);
  print(identical(biru1, biru2)); // Output: false
}

Objek const dengan isi yang sama hanya dibuat sekali dan dipakai bersama (identical bernilai true). Inilah alasan Flutter menyarankan const Text('Halo'): widget tidak perlu dibuat ulang setiap kali layar di-rebuild. Syaratnya, semua field harus final.

5. Factory constructor

factory adalah constructor yang boleh mengandung logika dan mengembalikan objek (baru atau yang sudah ada). Pemakaian paling umum adalah fromJson untuk mengubah data JSON menjadi objek.

class Mahasiswa {
  final String nim;
  final String nama;
  final double ipk;

  Mahasiswa({required this.nim, required this.nama, required this.ipk});

  factory Mahasiswa.fromJson(Map<String, dynamic> json) {
    return Mahasiswa(
      nim: json['nim'] as String,
      nama: json['nama'] as String,
      ipk: (json['ipk'] as num).toDouble(),
    );
  }

  Map<String, dynamic> toJson() => {'nim': nim, 'nama': nama, 'ipk': ipk};
}

void main() {
  final json = {'nim': 'H1D023007', 'nama': 'Nadia', 'ipk': 4};
  final m = Mahasiswa.fromJson(json);
  print('${m.nama} - IPK ${m.ipk}'); // Output: Nadia - IPK 4.0
  print(m.toJson()); // Output: {nim: H1D023007, nama: Nadia, ipk: 4.0}
}

Perhatikan (json['ipk'] as num).toDouble(): server bisa mengirim 4 (int) atau 3.5 (double). Membaca sebagai num lalu mengubah ke double menghindari error tipe. Pola ini akan dipakai lagi di Modul 09 (REST API).

Factory juga bisa mengembalikan objek yang sama terus-menerus (pola singleton):

class Pengaturan {
  static final Pengaturan _instance = Pengaturan._internal();
  String tema = 'terang';

  Pengaturan._internal(); // constructor private

  factory Pengaturan() => _instance;
}

void main() {
  final a = Pengaturan();
  final b = Pengaturan();
  a.tema = 'gelap';
  print(b.tema); // Output: gelap
  print(identical(a, b)); // Output: true
}

6. Getter, setter, dan private

Nama yang diawali garis bawah _ bersifat private. Akses dari luar diatur lewat getter (get) dan setter (set), sehingga data bisa divalidasi.

class Mahasiswa {
  final String nama;
  double _ipk = 0;

  Mahasiswa(this.nama);

  double get ipk => _ipk;

  set ipk(double nilai) {
    if (nilai < 0 || nilai > 4) {
      print('IPK $nilai tidak valid, diabaikan.');
      return;
    }
    _ipk = nilai;
  }

  // Getter hasil perhitungan (computed property)
  String get predikat => _ipk >= 3.51 ? 'Cumlaude' : 'Reguler';
}

void main() {
  final m = Mahasiswa('Fikri');
  m.ipk = 3.8; // memanggil setter
  print(m.ipk); // Output: 3.8
  print(m.predikat); // Output: Cumlaude
  m.ipk = 4.5; // Output: IPK 4.5 tidak valid, diabaikan.
  print(m.ipk); // Output: 3.8
}

Contoh lain yang lebih lengkap: rekening dengan saldo dan riwayat yang tidak bisa diubah sembarangan dari luar.

class RekeningBank {
  final String pemilik;
  double _saldo = 0;
  final List<String> _riwayat = [];

  RekeningBank(this.pemilik);

  double get saldo => _saldo;
  List<String> get riwayat => List.unmodifiable(_riwayat);

  void setor(double jumlah) {
    if (jumlah <= 0) return;
    _saldo += jumlah;
    _catat('Setor $jumlah');
  }

  bool tarik(double jumlah) {
    if (jumlah > _saldo) {
      _catat('Gagal tarik $jumlah');
      return false;
    }
    _saldo -= jumlah;
    _catat('Tarik $jumlah');
    return true;
  }

  void _catat(String aktivitas) => _riwayat.add(aktivitas); // method private
}

void main() {
  final rek = RekeningBank('Ayu');
  rek.setor(50000);
  rek.tarik(20000);
  rek.tarik(100000);
  print(rek.saldo); // Output: 30000.0
  print(rek.riwayat); // Output: [Setor 50000.0, Tarik 20000.0, Gagal tarik 100000.0]
}

ℹ️ Private di Dart = private per file

Dart tidak punya kata kunci private/public. Awalan _ membuat anggota hanya terlihat di file (library) yang sama. Jadi pada contoh satu file di atas, main() secara teknis masih bisa mengakses _saldo. Saat class dipindah ke file lain (misalnya lib/models/rekening.dart), barulah _saldo benar-benar tersembunyi.

7. Anggota static

class Mahasiswa {
  static int jumlahDibuat = 0; // milik class, bukan milik objek
  static const String kampus = 'UNSOED';

  final String nama;

  Mahasiswa(this.nama) {
    jumlahDibuat++;
  }

  static String formatNim(String angkatan, int urut) {
    return 'H1D$angkatan${urut.toString().padLeft(3, '0')}';
  }
}

void main() {
  final daftar = [Mahasiswa('Ayu'), Mahasiswa('Bima')];
  print(daftar.length); // Output: 2
  print(Mahasiswa.jumlahDibuat); // Output: 2
  print(Mahasiswa.kampus); // Output: UNSOED
  print(Mahasiswa.formatNim('023', 7)); // Output: H1D023007
}

Anggota static dipanggil lewat nama class, tanpa membuat objek. Contoh di Flutter: Colors.blue dan Navigator.push(...).

8. Inheritance (pewarisan) dan polymorphism

class Pengguna {
  final String nama;
  final String email;

  Pengguna(this.nama, this.email);

  String get peran => 'Pengguna';

  void tampilkanProfil() {
    print('[$peran] $nama <$email>');
  }
}

class Mahasiswa extends Pengguna {
  final String nim;

  // super parameter: diteruskan langsung ke constructor Pengguna
  Mahasiswa(super.nama, super.email, this.nim);

  @override
  String get peran => 'Mahasiswa';

  @override
  void tampilkanProfil() {
    super.tampilkanProfil(); // jalankan versi induk dulu
    print('  NIM: $nim');
  }
}

class Dosen extends Pengguna {
  final String nidn;

  // cara lama: memanggil super(...) di initializer list
  Dosen(String nama, String email, this.nidn) : super(nama, email);

  @override
  String get peran => 'Dosen';
}

void main() {
  final daftar = <Pengguna>[
    Mahasiswa('Ayu', 'ayu@mhs.unsoed.ac.id', 'H1D023001'),
    Dosen('Dr. Budi', 'budi@unsoed.ac.id', '0612345678'),
  ];

  for (final p in daftar) {
    p.tampilkanProfil();
  }
  // Output:
  // [Mahasiswa] Ayu <ayu@mhs.unsoed.ac.id>
  //   NIM: H1D023001
  // [Dosen] Dr. Budi <budi@unsoed.ac.id>
}

extends mewarisi seluruh field dan method induk. @override menandai method yang ditulis ulang. Walaupun list bertipe List<Pengguna>, setiap objek menjalankan versi method miliknya sendiri. Inilah polymorphism. Di Flutter, class HomePage extends StatelessWidget adalah contoh nyata inheritance.

9. Abstract class

Abstract class adalah class "setengah jadi" yang tidak bisa dibuat objeknya. Ia mendefinisikan method yang wajib diisi oleh class turunannya.

import 'dart:math';

abstract class BangunDatar {
  String get nama;
  double luas(); // method abstrak: tanpa isi
  double keliling();

  // method biasa boleh ada di abstract class
  void info() {
    print('$nama: luas ${luas().toStringAsFixed(2)}, '
        'keliling ${keliling().toStringAsFixed(2)}');
  }
}

class Lingkaran extends BangunDatar {
  final double r;
  Lingkaran(this.r);

  @override
  String get nama => 'Lingkaran';
  @override
  double luas() => pi * r * r;
  @override
  double keliling() => 2 * pi * r;
}

class PersegiPanjang extends BangunDatar {
  final double p, l;
  PersegiPanjang(this.p, this.l);

  @override
  String get nama => 'Persegi panjang';
  @override
  double luas() => p * l;
  @override
  double keliling() => 2 * (p + l);
}

void main() {
  // final b = BangunDatar(); // ERROR: abstract class tidak bisa diinstansiasi
  final daftar = [Lingkaran(7), PersegiPanjang(4, 3)];
  for (final b in daftar) {
    b.info();
  }
  // Output:
  // Lingkaran: luas 153.94, keliling 43.98
  // Persegi panjang: luas 12.00, keliling 14.00
}

10. Interface dengan implements

Setiap class di Dart otomatis juga merupakan interface. Dengan implements, sebuah class berjanji menyediakan semua method milik class lain, tetapi tidak mewarisi isinya. Sebuah class boleh meng-implements beberapa interface sekaligus.

abstract class BisaDicetak {
  void cetak();
}

abstract class BisaDiekspor {
  String keCsv();
}

class Transkrip implements BisaDicetak, BisaDiekspor {
  final String nama;
  final Map<String, String> nilai;

  Transkrip(this.nama, this.nilai);

  @override
  void cetak() {
    print('Transkrip $nama');
    nilai.forEach((mk, huruf) => print('  $mk: $huruf'));
  }

  @override
  String keCsv() => nilai.entries.map((e) => '${e.key},${e.value}').join(';');
}

void main() {
  final t = Transkrip('Ayu', {'Mobile': 'A', 'Basis Data': 'B'});
  t.cetak();
  print(t.keCsv());
  // Output:
  // Transkrip Ayu
  //   Mobile: A
  //   Basis Data: B
  // Mobile,A;Basis Data,B
}

11. Mixin

Mixin adalah kumpulan kemampuan yang bisa "ditempelkan" ke banyak class tanpa harus menjadi induknya. Kata kunci on membatasi mixin hanya untuk turunan class tertentu, sehingga mixin boleh memakai anggota class tersebut.

class Pengguna {
  final String nama;
  Pengguna(this.nama);
}

mixin AksesPerpustakaan {
  int batasPinjam = 3;
  final List<String> _pinjaman = [];

  void pinjamBuku(String judul) {
    if (_pinjaman.length >= batasPinjam) {
      print('Gagal: batas pinjam $batasPinjam buku');
      return;
    }
    _pinjaman.add(judul);
    print('Meminjam "$judul" (${_pinjaman.length}/$batasPinjam)');
  }
}

mixin AksesLab on Pengguna {
  void masukLab(String lab) => print('$nama masuk $lab'); // boleh pakai nama
}

class Mahasiswa extends Pengguna with AksesPerpustakaan, AksesLab {
  Mahasiswa(super.nama);
}

class Dosen extends Pengguna with AksesPerpustakaan {
  Dosen(super.nama) {
    batasPinjam = 10;
  }
}

void main() {
  final m = Mahasiswa('Ayu');
  m.pinjamBuku('Clean Code');
  m.pinjamBuku('Dart Apprentice');
  m.pinjamBuku('Flutter in Action');
  m.pinjamBuku('Refactoring');
  m.masukLab('Lab Komputasi');

  final d = Dosen('Pak Budi');
  d.pinjamBuku('Design Patterns');
  // Output:
  // Meminjam "Clean Code" (1/3)
  // Meminjam "Dart Apprentice" (2/3)
  // Meminjam "Flutter in Action" (3/3)
  // Gagal: batas pinjam 3 buku
  // Ayu masuk Lab Komputasi
  // Meminjam "Design Patterns" (1/10)
}

Anda akan menemui mixin di Flutter, misalnya class _HomeState extends State<Home> with SingleTickerProviderStateMixin untuk animasi.

12. Extension method

Extension menambahkan method baru ke class yang sudah ada (bahkan class bawaan seperti int dan String) tanpa mengubah atau mewarisinya.

extension FormatRupiah on int {
  String get rupiah {
    final s = toString();
    final buffer = StringBuffer();
    for (var i = 0; i < s.length; i++) {
      if (i > 0 && (s.length - i) % 3 == 0) buffer.write('.');
      buffer.write(s[i]);
    }
    return 'Rp$buffer';
  }
}

extension StringKampus on String {
  bool get isNimValid => RegExp(r'^H1D\d{6}$').hasMatch(this);

  String get kapital =>
      isEmpty ? this : this[0].toUpperCase() + substring(1).toLowerCase();
}

void main() {
  print(150000.rupiah); // Output: Rp150.000
  print(1250000.rupiah); // Output: Rp1.250.000
  print('H1D023001'.isNimValid); // Output: true
  print('abc'.isNimValid); // Output: false
  print('fLUTTER'.kapital); // Output: Flutter
}

13. Enum dan enhanced enum

Enum mewakili sekumpulan nilai tetap. Kombinasi enum dengan switch membuat compiler bisa memastikan semua kemungkinan sudah ditangani.

enum StatusKrs { draft, diajukan, disetujui, ditolak }

void main() {
  var status = StatusKrs.diajukan;
  print(status); // Output: StatusKrs.diajukan
  print(status.name); // Output: diajukan
  print(status.index); // Output: 1
  print(StatusKrs.values.length); // Output: 4

  final pesan = switch (status) {
    StatusKrs.draft => 'Belum diajukan',
    StatusKrs.diajukan => 'Menunggu dosen wali',
    StatusKrs.disetujui => 'KRS disetujui',
    StatusKrs.ditolak => 'Perlu revisi',
  };
  print(pesan); // Output: Menunggu dosen wali
}

Switch di atas tidak butuh _ karena semua nilai enum sudah ditulis. Jika nanti ditambahkan nilai baru, misalnya StatusKrs.dibatalkan, compiler langsung menunjukkan switch mana yang belum lengkap.

Enhanced enum (Dart 2.17+) bisa punya field, constructor, getter, dan method:

enum NilaiHuruf {
  a('A', 4.0, 85),
  ab('AB', 3.5, 80),
  b('B', 3.0, 70),
  bc('BC', 2.5, 65),
  c('C', 2.0, 60),
  d('D', 1.0, 50),
  e('E', 0.0, 0);

  const NilaiHuruf(this.label, this.bobot, this.batasBawah);

  final String label;
  final double bobot;
  final int batasBawah;

  bool get lulus => bobot >= 2.0;

  static NilaiHuruf dariAngka(num nilai) {
    return values.firstWhere((h) => nilai >= h.batasBawah);
  }
}

void main() {
  for (final n in [92, 81, 67, 45]) {
    final huruf = NilaiHuruf.dariAngka(n);
    print('$n -> ${huruf.label} (bobot ${huruf.bobot}, lulus: ${huruf.lulus})');
  }
  // Output:
  // 92 -> A (bobot 4.0, lulus: true)
  // 81 -> AB (bobot 3.5, lulus: true)
  // 67 -> BC (bobot 2.5, lulus: true)
  // 45 -> E (bobot 0.0, lulus: false)
}

values berisi semua nilai enum sesuai urutan penulisan. Karena urutannya dari batas tertinggi, firstWhere menemukan huruf pertama yang batas bawahnya terpenuhi. Skala nilai di sini hanya contoh; sesuaikan dengan pedoman akademik yang berlaku.

⚠️ Kesalahan umum OOP

  • Lupa @override. Kode tetap jalan, tetapi Anda kehilangan peringatan saat salah ketik nama method induk.
  • Field non-nullable tidak diisi di constructor: error "Non-nullable instance field must be initialized". Isi lewat this.x, initializer list, nilai default, atau gunakan late/nullable.
  • Membuat semua field publik dan bisa diubah. Biasakan field final dan sembunyikan data penting dengan _.
