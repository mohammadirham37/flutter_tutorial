Operator adalah simbol untuk mengolah nilai: menjumlah, membandingkan, menggabungkan kondisi, sampai menangani nilai null. Banyak operator Dart sama dengan bahasa C, Java, atau JavaScript, tetapi ada beberapa yang khas Dart seperti ~/, ??, dan cascade ...

Operator aritmatika

void main() {
  int a = 17;
  int b = 5;

  print(a + b); // Output: 22
  print(a - b); // Output: 12
  print(a * b); // Output: 85
  print(a / b); // Output: 3.4
  print(a ~/ b); // Output: 3
  print(a % b); // Output: 2
  print(-a); // Output: -17
}
  • / selalu menghasilkan double, walaupun kedua angkanya int.
  • ~/ adalah pembagian bulat (hasil dibulatkan ke bawah menuju nol).
  • % adalah sisa bagi (modulo), sering dipakai untuk mengecek genap/ganjil: n % 2 == 0.

Operator penugasan dan increment

void main() {
  int poin = 10;
  poin += 5; // sama dengan: poin = poin + 5
  print(poin); // Output: 15
  poin -= 3;
  print(poin); // Output: 12
  poin *= 2;
  print(poin); // Output: 24
  poin ~/= 5;
  print(poin); // Output: 4

  int x = 1;
  print(x++); // Output: 1
  print(x); // Output: 2
  print(++x); // Output: 3
  x--;
  print(x); // Output: 2
}

x++ (postfix) memberikan nilai lama lalu menambah, sedangkan ++x (prefix) menambah dulu lalu memberikan nilai baru. Itulah sebabnya print(x++) mencetak 1.

Operator perbandingan dan uji tipe

void main() {
  int nilai = 75;
  print(nilai == 75); // Output: true
  print(nilai != 80); // Output: true
  print(nilai > 80); // Output: false
  print(nilai <= 75); // Output: true

  Object data = 'Dart';
  print(data is String); // Output: true
  print(data is! int); // Output: true
  String teks = data as String; // cast: "anggap data sebagai String"
  print(teks.length); // Output: 4
}

is mengecek tipe, is! kebalikannya, dan as melakukan cast. Jika cast salah (misalnya data as int), program akan crash, jadi biasakan mengecek dengan is terlebih dahulu.

Operator logika

void main() {
  int kehadiran = 85; // persen
  double nilaiAkhir = 72.5;
  bool sudahBayarUkt = true;

  bool bolehUjian = kehadiran >= 75 && sudahBayarUkt;
  bool dapatBeasiswa = nilaiAkhir >= 85 || kehadiran == 100;

  print(bolehUjian); // Output: true
  print(dapatBeasiswa); // Output: false
  print(!sudahBayarUkt); // Output: false
}
OperatorNamaHasil true jika...
a && bANDkeduanya true
a || bORsalah satu true
!aNOTa bernilai false

Dart memakai short-circuit evaluation: pada a && b, jika a sudah false, maka b tidak dievaluasi sama sekali. Ini berguna untuk pengecekan aman seperti teks != null && teks.isNotEmpty.

Operator ternary

Bentuk singkat dari if-else yang menghasilkan nilai: kondisi ? nilaiJikaBenar : nilaiJikaSalah. Di Flutter, ternary sangat sering dipakai di dalam widget, misalnya isLoading ? CircularProgressIndicator() : Text('Data').

void main() {
  int nilai = 68;
  String status = nilai >= 60 ? 'Lulus' : 'Tidak lulus';
  print(status); // Output: Lulus

  int jumlahPesan = 1;
  print('$jumlahPesan pesan${jumlahPesan > 1 ? ' baru' : ''}'); // Output: 1 pesan
}

Operator null-aware: ??, ?., ??=

Operator ini menangani nilai yang mungkin null. Pembahasan lengkapnya ada di section Null Safety; berikut perkenalan singkatnya.

String? cariNamaPanggilan(String nama) {
  // Mengembalikan null jika nama tidak dikenal
  return nama == 'Muhammad Fikri' ? 'Fikri' : null;
}

void main() {
  String? panggilan = cariNamaPanggilan('Siti Aminah'); // null

  print(panggilan ?? 'Belum diisi'); // Output: Belum diisi
  print(panggilan?.length); // Output: null

  panggilan ??= 'Siti'; // isi hanya jika masih null
  print(panggilan); // Output: Siti

  String? lain = cariNamaPanggilan('Muhammad Fikri');
  lain ??= 'Default'; // tidak berubah karena sudah ada isinya
  print(lain); // Output: Fikri
}
  • a ?? b: pakai a, tetapi jika a null pakai b.
  • a?.b: akses b hanya jika a tidak null; jika null, hasilnya null (tidak crash).
  • a ??= b: isi a dengan b hanya jika a masih null.

Cascade ..

Cascade memungkinkan beberapa operasi berurutan pada objek yang sama tanpa menulis nama variabelnya berulang kali. Contoh ini memakai class sederhana; class dibahas detail di section OOP.

class Pesanan {
  String menu = '';
  int jumlah = 0;
  List<String> catatan = [];

  void tampilkan() => print('$jumlah x $menu, catatan: $catatan');
}

void main() {
  // Tanpa cascade
  var p1 = Pesanan();
  p1.menu = 'Mendoan';
  p1.jumlah = 5;
  p1.tampilkan(); // Output: 5 x Mendoan, catatan: []

  // Dengan cascade
  var p2 = Pesanan()
    ..menu = 'Soto Sokaraja'
    ..jumlah = 2
    ..catatan.add('pedas')
    ..tampilkan(); // Output: 2 x Soto Sokaraja, catatan: [pedas]
  print(p2.jumlah); // Output: 2

  // Cascade juga praktis untuk List
  final angka = <int>[]
    ..add(3)
    ..add(1)
    ..add(2)
    ..sort();
  print(angka); // Output: [1, 2, 3]
}

Perhatikan: ..add(3) mengembalikan objek list-nya, bukan hasil dari add. Karena itu rangkaian di atas tetap menghasilkan list. Ada juga ?.. untuk objek yang mungkin null.

⚠️ Kesalahan umum

  • Mengira 7 / 2 menghasilkan 3. Hasilnya 3.5. Gunakan 7 ~/ 2 untuk mendapatkan 3.
  • Menulis = (penugasan) padahal maksudnya == (perbandingan).
  • Membandingkan double hasil perhitungan dengan ==: 0.1 + 0.2 == 0.3 bernilai false karena keterbatasan presisi bilangan desimal.
