Platform channel adalah jalur pesan antara Dart dan kode native. Setiap plugin hardware memakai mekanisme ini di balik layar. Dengan menulis satu contoh sendiri, kamu akan paham apa yang terjadi saat memanggil Permission.camera.request() atau Geolocator.getCurrentPosition().

Tiga jenis channel

ChannelPola komunikasiContoh pemakaian
MethodChannelTanya-jawab satu kali (seperti memanggil fungsi). Dart memanggil, native mengembalikan hasil atau error.Ambil level baterai, minta izin, ambil foto
EventChannelAliran data terus-menerus dari native ke Dart, diterima sebagai Stream.Status pengisian daya, posisi GPS, data sensor
BasicMessageChannelPesan bebas dua arah dengan codec tertentu.Jarang dipakai langsung

Data yang dikirim lewat channel diubah otomatis oleh StandardMessageCodec. Tipe yang didukung antara lain null, bool, int, double, String, Uint8List, List, dan Map. Di Kotlin, int Dart menjadi Int (atau Long bila lebih dari 32 bit), List menjadi List, dan Map menjadi HashMap. Objek buatan sendiri harus diubah dulu menjadi Map.

Contoh kecil: memanggil method native

import 'package:flutter/services.dart';

// Nama channel bebas, tetapi harus unik dan SAMA PERSIS di sisi Kotlin.
// Biasakan memakai awalan domain agar tidak bentrok dengan plugin lain.
const channel = MethodChannel('id.ac.kampus/baterai');

Future<int?> ambilLevel() =>
    channel.invokeMethod<int>('ambilLevelBaterai');

invokeMethod selalu asinkron karena pesan harus menyeberang ke thread native dan kembali. Hasilnya bisa null, jadi tipe kembaliannya Future<int?>.

Contoh lengkap: level baterai (MethodChannel) dan status pengisian (EventChannel)

Contoh ini mengikuti pola contoh resmi "battery level" di dokumentasi Flutter (docs.flutter.dev → Platform integration → Platform channels), dengan nama channel dan method versi kita, ditambah sebuah EventChannel. Buat proyek baru, misalnya flutter create --org id.ac.kampus contoh_hardware.

Langkah 1: sisi Android (Kotlin). Buka android/app/src/main/kotlin/.../MainActivity.kt. Isinya bawaan hanya class MainActivity : FlutterActivity(). Ganti isinya (baris package di paling atas biarkan sesuai proyekmu):

📄 android/app/src/main/kotlin/.../MainActivity.kt

package id.ac.kampus.contoh_hardware // sesuaikan dengan proyekmu

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.content.IntentFilter
import android.os.BatteryManager
import io.flutter.embedding.android.FlutterActivity
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.plugin.common.EventChannel
import io.flutter.plugin.common.MethodChannel

class MainActivity : FlutterActivity() {
    private val channelBaterai = "id.ac.kampus/baterai"
    private val channelPengisian = "id.ac.kampus/pengisian"

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        // 1. MethodChannel: Dart bertanya, Kotlin menjawab satu kali
        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, channelBaterai)
            .setMethodCallHandler { call, result ->
                // Dijalankan di main thread Android
                if (call.method == "ambilLevelBaterai") {
                    val level = ambilLevelBaterai()
                    if (level != -1) {
                        result.success(level)
                    } else {
                        result.error("TIDAK_TERSEDIA", "Level baterai tidak tersedia.", null)
                    }
                } else {
                    result.notImplemented()
                }
            }

        // 2. EventChannel: Kotlin mengirim data terus-menerus ke Dart
        EventChannel(flutterEngine.dartExecutor.binaryMessenger, channelPengisian)
            .setStreamHandler(object : EventChannel.StreamHandler {
                private var receiver: BroadcastReceiver? = null

                override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
                    receiver = object : BroadcastReceiver() {
                        override fun onReceive(context: Context, intent: Intent) {
                            val status = intent.getIntExtra(BatteryManager.EXTRA_STATUS, -1)
                            val mengisi = status == BatteryManager.BATTERY_STATUS_CHARGING ||
                                status == BatteryManager.BATTERY_STATUS_FULL
                            events.success(mengisi)
                        }
                    }
                    registerReceiver(receiver, IntentFilter(Intent.ACTION_BATTERY_CHANGED))
                }

                override fun onCancel(arguments: Any?) {
                    receiver?.let { unregisterReceiver(it) }
                    receiver = null
                }
            })
    }

    private fun ambilLevelBaterai(): Int {
        val batteryManager = getSystemService(Context.BATTERY_SERVICE) as BatteryManager
        return batteryManager.getIntProperty(BatteryManager.BATTERY_PROPERTY_CAPACITY)
    }
}

Langkah 2: sisi Dart.

📄 lib/main.dart

// lib/main.dart
import 'dart:async';

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

void main() => runApp(const MaterialApp(home: BateraiPage()));

class BateraiPage extends StatefulWidget {
  const BateraiPage({super.key});

  @override
  State<BateraiPage> createState() => _BateraiPageState();
}

class _BateraiPageState extends State<BateraiPage> {
  // Nama channel harus sama persis dengan di MainActivity.kt
  static const _baterai = MethodChannel('id.ac.kampus/baterai');
  static const _pengisian = EventChannel('id.ac.kampus/pengisian');

  String _level = 'Belum dicek';
  bool? _sedangMengisi;
  StreamSubscription<dynamic>? _langganan;

  @override
  void initState() {
    super.initState();
    // EventChannel: dengarkan perubahan status pengisian daya
    _langganan = _pengisian.receiveBroadcastStream().listen(
      (data) => setState(() => _sedangMengisi = data as bool),
      onError: (Object e) => debugPrint('Gagal mendengar: $e'),
    );
  }

  @override
  void dispose() {
    _langganan?.cancel(); // memicu onCancel di sisi Kotlin
    super.dispose();
  }

  Future<void> _cekLevel() async {
    String teks;
    try {
      final level = await _baterai.invokeMethod<int>('ambilLevelBaterai');
      teks = 'Baterai $level%';
    } on PlatformException catch (e) {
      teks = 'Gagal: ${e.message}';
    } on MissingPluginException {
      teks = 'Channel belum dibuat di platform ini';
    }
    if (!mounted) return;
    setState(() => _level = teks);
  }

  @override
  Widget build(BuildContext context) {
    final mengisi = switch (_sedangMengisi) {
      null => 'Menunggu data...',
      true => 'Sedang mengisi daya',
      false => 'Tidak mengisi daya',
    };
    return Scaffold(
      appBar: AppBar(title: const Text('Platform Channel')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(_level, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 8),
            Text(mengisi),
            const SizedBox(height: 24),
            FilledButton.icon(
              onPressed: _cekLevel,
              icon: const Icon(Icons.battery_std),
              label: const Text('Cek Level Baterai'),
            ),
          ],
        ),
      ),
    );
  }
}

Penjelasan baris penting:

  • configureFlutterEngine adalah tempat resmi mendaftarkan channel di Android. Handler-nya dijalankan di main thread Android, jadi jangan melakukan pekerjaan berat (baca file besar, jaringan) langsung di dalamnya.
  • result.success(level) menjadi nilai kembalian invokeMethod di Dart. result.error(...) menjadi PlatformException dengan code 'TIDAK_TERSEDIA'. result.notImplemented() menjadi MissingPluginException.
  • Di sisi Kotlin, setiap pemanggilan wajib dijawab tepat satu kali (success, error, atau notImplemented). Jika lupa, await di Dart akan menunggu selamanya.
  • EventChannel bekerja dengan StreamHandler: onListen dipanggil saat Dart mulai listen, onCancel saat langganan dibatalkan. Di situlah receiver Android didaftarkan dan dilepas.
  • Di Dart, StreamSubscription disimpan lalu dibatalkan di dispose(). Tanpa itu, receiver di sisi Android tetap hidup dan memboroskan baterai.
  • Setelah await, cek mounted sebelum setState, karena halaman mungkin sudah ditutup.
  • Membaca level baterai tidak butuh izin apa pun, jadi contoh ini bisa langsung dijalankan.

ℹ️ Bagaimana dengan iOS?

Di iOS, channel yang sama didaftarkan di ios/Runner/AppDelegate.swift memakai FlutterMethodChannel dan FlutterEventChannel. Jika aplikasi dijalankan di iOS tanpa kode Swift tersebut, invokeMethod melempar MissingPluginException, sehingga contoh di atas menangkapnya agar tidak crash. Kode Swift lengkapnya ada di halaman dokumentasi Platform channels yang sama.

💡 Menguji di emulator

Buka Extended Controls → Battery di Android Emulator. Ubah Charge level lalu tekan "Cek Level Baterai", atau ubah Charger connection menjadi None/AC charger dan lihat teks status pengisian berubah sendiri lewat EventChannel. Perubahan kode Kotlin tidak ikut hot reload: hentikan aplikasi lalu jalankan ulang flutter run.

⚠️ Kesalahan umum

  • Nama channel atau nama method berbeda satu huruf antara Dart dan Kotlin. Hasilnya MissingPluginException atau notImplemented.
  • Mengubah MainActivity.kt lalu hanya menekan hot reload. Kode native baru terpakai setelah build ulang.
  • Mengirim objek Dart buatan sendiri lewat channel. Ubah dulu menjadi Map (misal toMap()).
  • Lupa membatalkan langganan EventChannel sehingga listener native terus berjalan.
