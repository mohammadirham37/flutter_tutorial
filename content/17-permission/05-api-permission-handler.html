Setelah konfigurasi beres, API permission_handler sendiri cukup ringkas. Ada lima hal yang paling sering dipakai: membaca status, request satu izin, request beberapa izin sekaligus, cek rationale, dan membuka Pengaturan. Ditambah satu lagi untuk lokasi: status layanan (GPS menyala atau tidak).

1. Membaca status tanpa dialog

Setiap izin adalah konstanta di kelas Permission, misalnya Permission.camera. Getter status membaca keadaan saat ini tanpa memunculkan dialog apa pun.

import 'package:flutter/foundation.dart';
import 'package:permission_handler/permission_handler.dart';

Future<void> contohStatus() async {
  final status = await Permission.camera.status;

  if (status.isGranted) {
    // boleh langsung memakai kamera
  } else if (status.isDenied) {
    // belum diizinkan (di Android: bisa juga sudah ditolak permanen)
  } else if (status.isPermanentlyDenied) {
    // iOS: pengguna pernah menolak, dialog tidak akan muncul lagi
  } else if (status.isLimited) {
    // akses terbatas (foto terpilih saja)
  } else if (status.isRestricted) {
    // iOS: dibatasi kontrol orang tua / kebijakan perangkat
  }

  // Versi singkat: getter langsung pada Permission
  final bolehMikrofon = await Permission.microphone.isGranted;
  debugPrint('bolehMikrofon: $bolehMikrofon');
}

Nilai PermissionStatus ada enam: granted, denied, permanentlyDenied, limited, restricted, dan provisional (notifikasi sementara di iOS).

2. Meminta izin dengan request()

import 'package:permission_handler/permission_handler.dart';

Future<void> contohRequest() async {
  // request() memunculkan dialog sistem (jika masih boleh)
  // dan mengembalikan status BARU setelah pengguna memilih.
  final hasil = await Permission.camera.request();

  if (hasil.isGranted) {
    // pengguna menekan "Izinkan" (atau memang sudah diizinkan sebelumnya)
  } else if (hasil.isPermanentlyDenied) {
    // dialog tidak muncul lagi: arahkan ke Pengaturan
    await openAppSettings();
  }
}

Jika izin sudah diberikan, request() tidak menampilkan apa pun dan langsung mengembalikan granted. Jika sudah ditolak permanen, request() juga langsung kembali (tanpa dialog) dengan hasil permanentlyDenied.

⚠️ Penting: "ditolak permanen" di Android hanya terlihat dari hasil request()

Android tidak menyediakan API untuk membedakan izin yang belum pernah diminta, yang direset ke "Tanyakan setiap kali" di Pengaturan, dan yang ditolak permanen. Karena itu, versi terbaru permission_handler tidak pernah mengembalikan permanentlyDenied dari status di Android; semuanya dilaporkan sebagai denied. Hanya hasil request() yang bisa bernilai permanentlyDenied, dan meminta izin yang sudah ditolak permanen itu murah karena tidak memunculkan dialog. Polanya: putuskan berdasarkan hasil request(), bukan berdasarkan status. Tutorial lama yang memakai await Permission.camera.isPermanentlyDenied sebelum meminta tidak lagi berlaku di Android. Di iOS, status tetap bisa bernilai permanentlyDenied.

3. Beberapa izin sekaligus, rationale, layanan lokasi, Pengaturan

import 'package:flutter/foundation.dart';
import 'package:permission_handler/permission_handler.dart';

Future<void> contohLain() async {
  // Beberapa izin sekaligus: dialog muncul berurutan
  final Map<Permission, PermissionStatus> hasil = await [
    Permission.camera,
    Permission.microphone,
  ].request();
  debugPrint('Kamera: ${hasil[Permission.camera]}');

  // Android: true jika pengguna pernah menolak sekali (dan belum permanen)
  final perluPenjelasan = await Permission.camera.shouldShowRequestRationale;
  debugPrint('perluPenjelasan: $perluPenjelasan');

  // Izin lokasi diizinkan belum tentu GPS menyala
  final gpsMenyala = await Permission.locationWhenInUse.serviceStatus.isEnabled;
  debugPrint('gpsMenyala: $gpsMenyala');

  // Membuka halaman pengaturan aplikasi ini
  final berhasilDibuka = await openAppSettings();
  debugPrint('berhasilDibuka: $berhasilDibuka');
}
  • [...].request() adalah extension pada List<Permission>. Hasilnya Map<Permission, PermissionStatus>. Pakai ini hanya untuk izin yang memang dibutuhkan bersamaan oleh satu fitur (misal rekam video: kamera + mikrofon).
  • shouldShowRequestRationale hanya bermakna di Android: bernilai true setelah pengguna menolak sekali, tanda bahwa kamu sebaiknya menjelaskan alasannya sebelum meminta lagi. Di iOS selalu false.
  • serviceStatus hanya ada pada izin yang punya "layanan" (Permission.location, locationWhenInUse, locationAlways, dan beberapa lainnya). Izin lokasi bisa granted walaupun GPS dimatikan dari panel cepat, sehingga posisi tetap tidak bisa dibaca.
  • openAppSettings() adalah fungsi top-level (bukan method Permission) yang membuka halaman info aplikasi di Pengaturan.

Gaya callback (opsional)

import 'package:flutter/foundation.dart';
import 'package:permission_handler/permission_handler.dart';

Future<void> contohCallback() async {
  await Permission.microphone
      .onGrantedCallback(() => debugPrint('Mikrofon siap'))
      .onDeniedCallback(() => debugPrint('Ditolak, coba jelaskan lagi nanti'))
      .onPermanentlyDeniedCallback(() => openAppSettings())
      .request();
}

Gaya ini ringkas untuk kasus sederhana, tetapi di kursus ini kita memakai if pada hasil request() agar alurnya mudah dibaca dan mudah dipindahkan ke controller GetX.

Contoh lengkap: panel uji izin

Halaman berikut menampilkan status kamera, nilai rationale, status GPS, serta tombol untuk meminta kamera, meminta lokasi + mikrofon sekaligus, dan membuka Pengaturan. Pakai konfigurasi manifest dan Info.plist dari section 4.

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:permission_handler/permission_handler.dart';

void main() => runApp(const MaterialApp(home: CekIzinPage()));

class CekIzinPage extends StatefulWidget {
  const CekIzinPage({super.key});

  @override
  State<CekIzinPage> createState() => _CekIzinPageState();
}

class _CekIzinPageState extends State<CekIzinPage> {
  PermissionStatus? _kamera;
  Map<Permission, PermissionStatus> _hasilBanyak = {};
  bool? _gpsAktif;
  bool? _perluPenjelasan;

  @override
  void initState() {
    super.initState();
    _cekStatus();
  }

  // 1. Membaca status TANPA memunculkan dialog
  Future<void> _cekStatus() async {
    final status = await Permission.camera.status;
    final rationale = await Permission.camera.shouldShowRequestRationale;
    final gps = await Permission.locationWhenInUse.serviceStatus.isEnabled;
    if (!mounted) return;
    setState(() {
      _kamera = status;
      _perluPenjelasan = rationale;
      _gpsAktif = gps;
    });
  }

  // 2. Meminta satu izin: dialog sistem muncul jika masih boleh
  Future<void> _mintaKamera() async {
    final status = await Permission.camera.request();
    if (!mounted) return;
    setState(() => _kamera = status);

    if (status.isPermanentlyDenied) {
      // 3. Dialog sistem tidak akan muncul lagi, arahkan ke Pengaturan
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: const Text('Izin kamera ditolak permanen.'),
          action: SnackBarAction(
            label: 'Pengaturan',
            onPressed: openAppSettings,
          ),
        ),
      );
    }
  }

  // 4. Meminta beberapa izin sekaligus
  Future<void> _mintaBanyak() async {
    final hasil = await [
      Permission.locationWhenInUse,
      Permission.microphone,
    ].request();
    if (!mounted) return;
    setState(() => _hasilBanyak = hasil);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('permission_handler'),
        actions: [
          IconButton(onPressed: _cekStatus, icon: const Icon(Icons.refresh)),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          ListTile(
            leading: const Icon(Icons.photo_camera_outlined),
            title: const Text('Status kamera'),
            subtitle: Text('${_kamera ?? 'memeriksa...'}'),
          ),
          ListTile(
            leading: const Icon(Icons.help_outline),
            title: const Text('shouldShowRequestRationale'),
            subtitle: Text('${_perluPenjelasan ?? '-'}'),
          ),
          ListTile(
            leading: const Icon(Icons.gps_fixed),
            title: const Text('Layanan lokasi (GPS) menyala?'),
            subtitle: Text('${_gpsAktif ?? '-'}'),
          ),
          for (final entri in _hasilBanyak.entries)
            ListTile(
              leading: const Icon(Icons.checklist),
              title: Text('${entri.key}'),
              subtitle: Text('${entri.value}'),
            ),
          const SizedBox(height: 16),
          FilledButton(
            onPressed: _mintaKamera,
            child: const Text('Minta Izin Kamera'),
          ),
          const SizedBox(height: 8),
          OutlinedButton(
            onPressed: _mintaBanyak,
            child: const Text('Minta Lokasi + Mikrofon Sekaligus'),
          ),
          const SizedBox(height: 8),
          TextButton(
            onPressed: openAppSettings,
            child: const Text('Buka Pengaturan Aplikasi'),
          ),
        ],
      ),
    );
  }
}

Penjelasan:

  • _cekStatus() dipanggil di initState dan lewat tombol refresh. Tidak ada dialog yang muncul di sini; aman dipanggil kapan saja.
  • _mintaKamera() memakai hasil request() untuk memutuskan apakah perlu menampilkan tombol "Pengaturan", sesuai catatan di atas.
  • Setiap await diikuti if (!mounted) return; karena dialog sistem bisa terbuka lama dan pengguna bisa saja menutup halaman.
  • '${entri.key}' menampilkan nama izin seperti Permission.microphone, cocok untuk panel uji. Untuk pengguna, tampilkan label bahasa Indonesia (section 7).

Menguji di Android Emulator

  1. Jalankan aplikasi, tekan "Minta Izin Kamera", pilih Jangan izinkan. Status menjadi denied dan rationale menjadi true.
  2. Tekan lagi dan tolak lagi. Hasil request() menjadi permanentlyDenied dan SnackBar menawarkan Pengaturan. Tekan tombol refresh: status tetap terbaca denied (perilaku Android yang dijelaskan di atas).
  3. Matikan Location dari panel cepat emulator, tekan refresh, dan lihat "Layanan lokasi" menjadi false.
  4. Izin juga bisa diatur lewat terminal. Mencabut izin akan menghentikan proses aplikasi, jadi jalankan ulang setelahnya. Untuk mengembalikan izin ke kondisi "belum pernah diminta", cara paling pasti adalah uninstall lalu pasang ulang aplikasi.
# ganti dengan applicationId proyekmu
adb shell pm grant id.ac.kampus.contoh_hardware android.permission.CAMERA
adb shell pm revoke id.ac.kampus.contoh_hardware android.permission.CAMERA
adb uninstall id.ac.kampus.contoh_hardware

ℹ️ Izin yang tidak memunculkan dialog

  • Notifikasi di Android 12 ke bawah: tidak ada izin runtime, jadi request() hanya membaca pengaturan notifikasi aplikasi tanpa dialog. Di Android 13+ dialog muncul (asalkan POST_NOTIFICATIONS ada di manifest).
  • Lokasi "always" (latar belakang) tidak bisa diminta langsung. Minta locationWhenInUse dulu, baru locationAlways. Detailnya di Modul 19.
  • Izin khusus seperti manageExternalStorage dan systemAlertWindow membuka halaman Pengaturan, bukan dialog.

⚠️ Kesalahan umum

  • Memanggil request() berkali-kali secara bersamaan (misal dari dua tombol yang ditekan cepat). Plugin melempar error karena masih ada permintaan yang berjalan. Nonaktifkan tombol saat permintaan sedang diproses.
  • Memakai Permission.storage untuk memilih foto di Android 13+. Hasilnya selalu denied; gunakan Permission.photos atau lebih baik picker sistem yang tidak butuh izin (Modul 18).
  • Menganggap isDenied berarti "belum pernah diminta". Di Android, status itu juga mencakup "ditolak permanen".
