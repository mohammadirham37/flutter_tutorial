Kita rakit semuanya menjadi Pusat Izin Aplikasi Kampus: halaman yang menampilkan status izin kamera, lokasi, notifikasi, dan mikrofon, lengkap dengan tombol untuk meminta izin atau membuka Pengaturan. Beranda aplikasi berisi fitur Presensi, Catatan Suara, dan Pengingat Jadwal yang meminta izin hanya saat fiturnya dipakai. Proyek ini menjadi kerangka untuk Modul 18 (kamera) sampai 22 (konektivitas).

Langkah 1: alur izin yang bisa dipakai ulang

Alur dari section 6 (penjelasan → dialog sistem → ajakan ke Pengaturan) kita jadikan satu fungsi pastikanIzin(). Fitur mana pun cukup memanggil await pastikanIzin(context, JenisIzin.kamera) dan melanjutkan jika hasilnya true.

📄 lib/views/alur_izin.dart

// lib/views/alur_izin.dart
// Alur izin lengkap yang dipakai ulang di modul 18-22:
// penjelasan -> dialog sistem -> (jika ditolak permanen) ajak ke Pengaturan.
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/permission_controller.dart';
import '../models/izin.dart';

/// Mengembalikan true jika fitur boleh langsung dipakai.
Future<bool> pastikanIzin(BuildContext context, JenisIzin jenis) async {
  final controller = Get.find<PermissionController>();
  final sekarang = controller.statusDari(jenis);
  if (sekarang.bolehDipakai) return true;

  // 1. Dialog penjelasan sebelum dialog sistem (dilewati jika sudah
  //    ditolak permanen, karena dialog sistem tidak akan muncul lagi).
  if (!sekarang.perluPengaturan) {
    final pernahDitolak = await controller.perluPenjelasan(jenis);
    if (!context.mounted) return false;
    final setuju = await _tampilkanPenjelasan(context, jenis, pernahDitolak);
    if (!setuju) return false;
  }

  // 2. Dialog sistem. Jika sudah ditolak permanen, hasilnya langsung kembali
  //    tanpa dialog.
  final hasil = await controller.minta(jenis);
  if (hasil.bolehDipakai) return true;
  if (!context.mounted) return false;

  // 3. Ditolak permanen atau dibatasi: hanya bisa diubah dari Pengaturan.
  if (hasil.perluPengaturan) {
    await _tampilkanAjakanPengaturan(context, jenis, controller);
  } else {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Izin ${jenis.label} belum diberikan.')),
    );
  }
  return false;
}

Future<bool> _tampilkanPenjelasan(
  BuildContext context,
  JenisIzin jenis,
  bool pernahDitolak,
) async {
  final hasil = await showDialog<bool>(
    context: context,
    builder: (context) => AlertDialog(
      icon: const Icon(Icons.privacy_tip_outlined),
      title: Text('Izinkan akses ${jenis.label}?'),
      content: Text(
        pernahDitolak
            ? '${jenis.alasan}\n\nSebelumnya kamu menolak izin ini. '
                'Tanpa izin ini, fitur tersebut tidak bisa dipakai.'
            : jenis.alasan,
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(context, false),
          child: const Text('Nanti saja'),
        ),
        FilledButton(
          onPressed: () => Navigator.pop(context, true),
          child: const Text('Lanjutkan'),
        ),
      ],
    ),
  );
  return hasil ?? false;
}

Future<void> _tampilkanAjakanPengaturan(
  BuildContext context,
  JenisIzin jenis,
  PermissionController controller,
) async {
  final buka = await showDialog<bool>(
    context: context,
    builder: (context) => AlertDialog(
      icon: const Icon(Icons.settings_outlined),
      title: Text('Izin ${jenis.label} ditolak'),
      content: Text(
        'Aplikasi tidak bisa menampilkan dialog izin lagi. '
        'Buka Pengaturan > Izin, lalu aktifkan ${jenis.label}.',
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(context, false),
          child: const Text('Batal'),
        ),
        FilledButton(
          onPressed: () => Navigator.pop(context, true),
          child: const Text('Buka Pengaturan'),
        ),
      ],
    ),
  );
  if (buka == true) await controller.bukaPengaturan();
}
  • File ini berada di folder views/ karena berisi dialog (butuh BuildContext). Logikanya tetap memanggil controller, tidak memanggil plugin langsung.
  • Dialog penjelasan dilewati jika status sudah perluPengaturan, karena dialog sistem tidak akan muncul. Jika shouldShowRequestRationale bernilai true, teks penjelasan ditambah kalimat "Sebelumnya kamu menolak izin ini".
  • Ada tiga pemeriksaan context.mounted, satu setelah setiap await yang diikuti pemakaian context.
  • Hasil "ditolak biasa" cukup diberi SnackBar, sedangkan "ditolak permanen" mendapat dialog dengan tombol "Buka Pengaturan".

Langkah 2: halaman Pusat Izin

📄 lib/views/pusat_izin_view.dart

// lib/views/pusat_izin_view.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../controllers/permission_controller.dart';
import '../models/izin.dart';
import 'alur_izin.dart';

class PusatIzinView extends GetView<PermissionController> {
  const PusatIzinView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Pusat Izin'),
        actions: [
          IconButton(
            tooltip: 'Muat ulang',
            onPressed: controller.muatUlang,
            icon: const Icon(Icons.refresh),
          ),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Obx(
            () => Text(
              '${controller.jumlahDiizinkan} dari ${JenisIzin.values.length} '
              'izin aktif',
              style: Theme.of(context).textTheme.titleMedium,
            ),
          ),
          const SizedBox(height: 4),
          const Text(
            'Izin hanya diminta saat fitur dipakai. '
            'Kamu bisa mengubahnya kapan saja di halaman ini.',
          ),
          const SizedBox(height: 12),
          Obx(
            () => controller.lokasiAktif
                ? const SizedBox.shrink()
                : const Card(
                    child: ListTile(
                      leading: Icon(Icons.location_off),
                      title: Text('Layanan lokasi (GPS) mati'),
                      subtitle: Text(
                        'Izin lokasi saja tidak cukup. Nyalakan lokasi '
                        'dari panel cepat perangkat.',
                      ),
                    ),
                  ),
          ),
          for (final jenis in JenisIzin.values) KartuIzin(jenis: jenis),
        ],
      ),
    );
  }
}

class KartuIzin extends GetView<PermissionController> {
  const KartuIzin({super.key, required this.jenis});

  final JenisIzin jenis;

  static IconData ikonUntuk(JenisIzin jenis) {
    switch (jenis) {
      case JenisIzin.kamera:
        return Icons.photo_camera_outlined;
      case JenisIzin.lokasi:
        return Icons.location_on_outlined;
      case JenisIzin.notifikasi:
        return Icons.notifications_outlined;
      case JenisIzin.mikrofon:
        return Icons.mic_none;
    }
  }

  Color _warnaStatus(StatusIzin status, ColorScheme warna) {
    if (status.bolehDipakai) return Colors.green;
    if (status.perluPengaturan) return warna.error;
    return warna.outline;
  }

  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    return Obx(() {
      final status = controller.statusDari(jenis);
      final sibuk = controller.sedangMemproses(jenis);
      return Card(
        child: Padding(
          padding: const EdgeInsets.fromLTRB(16, 12, 16, 12),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Row(
                children: [
                  Icon(ikonUntuk(jenis)),
                  const SizedBox(width: 12),
                  Expanded(
                    child: Text(
                      jenis.label,
                      style: Theme.of(context).textTheme.titleMedium,
                    ),
                  ),
                  Chip(
                    label: Text(status.label),
                    side: BorderSide(color: _warnaStatus(status, warna)),
                    backgroundColor:
                        _warnaStatus(status, warna).withValues(alpha: 0.1),
                  ),
                ],
              ),
              const SizedBox(height: 8),
              Text(jenis.alasan),
              const SizedBox(height: 8),
              Align(
                alignment: Alignment.centerRight,
                child: _tombol(context, status, sibuk),
              ),
            ],
          ),
        ),
      );
    });
  }

  Widget _tombol(BuildContext context, StatusIzin status, bool sibuk) {
    if (sibuk) {
      return const SizedBox(
        width: 24,
        height: 24,
        child: CircularProgressIndicator(strokeWidth: 2),
      );
    }
    if (status.bolehDipakai) {
      return TextButton.icon(
        onPressed: controller.bukaPengaturan,
        icon: const Icon(Icons.settings_outlined),
        label: const Text('Atur di Pengaturan'),
      );
    }
    if (status.perluPengaturan) {
      return FilledButton.tonalIcon(
        onPressed: () => pastikanIzin(context, jenis),
        icon: const Icon(Icons.open_in_new),
        label: const Text('Buka Pengaturan'),
      );
    }
    return FilledButton.icon(
      onPressed: status == StatusIzin.belumDiketahui
          ? null
          : () => pastikanIzin(context, jenis),
      icon: const Icon(Icons.lock_open),
      label: const Text('Izinkan'),
    );
  }
}
  • Setiap KartuIzin dibungkus Obx sendiri, sehingga saat status kamera berubah hanya kartu yang membaca status kamera yang dibangun ulang. Ringkasan "x dari 4 izin aktif" juga punya Obx sendiri.
  • Ikon dipetakan di view (ikonUntuk), bukan di model, karena IconData adalah urusan tampilan.
  • Tombol berubah sesuai status: "Izinkan", "Buka Pengaturan" (ditolak permanen/dibatasi), atau "Atur di Pengaturan" (sudah diizinkan, untuk mencabutnya). Saat izin sedang diminta, tombol diganti loading sehingga tidak bisa ditekan dua kali.
  • Kartu peringatan "Layanan lokasi (GPS) mati" muncul jika serviceStatus lokasi nonaktif, karena izin lokasi saja tidak cukup.
  • Tombol "Buka Pengaturan" tetap memanggil pastikanIzin. Request untuk izin yang ditolak permanen langsung kembali tanpa dialog, lalu dialog Pengaturan tampil. Jika ternyata pengguna sudah mereset izin ke "Tanyakan setiap kali", dialog sistem muncul seperti biasa.

Langkah 3: beranda yang meminta izin saat dibutuhkan

📄 lib/views/beranda_view.dart

// lib/views/beranda_view.dart
// Contoh "minta saat dibutuhkan": izin baru diminta ketika tombol ditekan.
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import '../models/izin.dart';
import 'alur_izin.dart';
import 'pusat_izin_view.dart';

class BerandaView extends StatelessWidget {
  const BerandaView({super.key});

  Future<void> _presensi(BuildContext context) async {
    final bolehKamera = await pastikanIzin(context, JenisIzin.kamera);
    if (!bolehKamera || !context.mounted) return;
    final bolehLokasi = await pastikanIzin(context, JenisIzin.lokasi);
    if (!bolehLokasi || !context.mounted) return;

    // Kamera dan lokasi siap. Modul 18 dan 19 mengisi bagian ini.
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Kamera dan lokasi siap untuk presensi.')),
    );
  }

  Future<void> _rekamCatatanSuara(BuildContext context) async {
    final boleh = await pastikanIzin(context, JenisIzin.mikrofon);
    if (!boleh || !context.mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Mikrofon siap merekam.')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Aplikasi Kampus'),
        actions: [
          IconButton(
            tooltip: 'Pusat Izin',
            onPressed: () => Get.to(() => const PusatIzinView()),
            icon: const Icon(Icons.admin_panel_settings_outlined),
          ),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Card(
            child: ListTile(
              leading: const Icon(Icons.qr_code_scanner),
              title: const Text('Presensi Kuliah'),
              subtitle: const Text('Butuh kamera dan lokasi'),
              trailing: const Icon(Icons.chevron_right),
              onTap: () => _presensi(context),
            ),
          ),
          Card(
            child: ListTile(
              leading: const Icon(Icons.keyboard_voice_outlined),
              title: const Text('Catatan Suara'),
              subtitle: const Text('Butuh mikrofon'),
              trailing: const Icon(Icons.chevron_right),
              onTap: () => _rekamCatatanSuara(context),
            ),
          ),
          Card(
            child: ListTile(
              leading: const Icon(Icons.notifications_active_outlined),
              title: const Text('Pengingat Jadwal'),
              subtitle: const Text('Butuh izin notifikasi'),
              trailing: const Icon(Icons.chevron_right),
              onTap: () => pastikanIzin(context, JenisIzin.notifikasi),
            ),
          ),
        ],
      ),
    );
  }
}

Presensi butuh dua izin. Keduanya diminta berurutan, masing-masing dengan penjelasan sendiri, dan proses berhenti di izin pertama yang ditolak. Di Modul 18 dan 19, SnackBar "siap" diganti dengan membuka kamera dan membaca lokasi.

Langkah 4: main.dart

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

import 'controllers/permission_controller.dart';
import 'services/permission_service.dart';
import 'views/beranda_view.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  // permanent: true agar controller tidak dihapus saat halaman ditutup;
  // modul 18-22 memakai controller yang sama.
  Get.put(PermissionController(PermissionService()), permanent: true);
  runApp(const AplikasiKampus());
}

class AplikasiKampus extends StatelessWidget {
  const AplikasiKampus({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'Aplikasi Kampus',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const BerandaView(),
    );
  }
}

WidgetsFlutterBinding.ensureInitialized() dipanggil sebelum Get.put karena onInit controller langsung memanggil plugin dan memasang AppLifecycleListener. permanent: true menjaga controller tetap hidup selama aplikasi berjalan.

ℹ️ Dipakai lagi di modul berikutnya

Modul 18–22 menambahkan nilai baru ke JenisIzin (misal galeri atau bluetooth), satu baris di _izinDari pada service, satu ikon di ikonUntuk, dan deklarasi platformnya. Kartu di Pusat Izin otomatis bertambah karena view melakukan perulangan pada JenisIzin.values.

⚠️ Kesalahan umum

  • Lupa menghapus test/widget_test.dart bawaan sehingga flutter analyze dan flutter test gagal.
  • Menambah JenisIzin baru tetapi lupa deklarasi manifest/Info.plist: di Android kartu selalu "Belum diizinkan" tanpa dialog, di iOS aplikasi crash.
  • Memanggil pastikanIzin tanpa memeriksa hasilnya, lalu tetap membuka kamera. Selalu if (!boleh) return;.
