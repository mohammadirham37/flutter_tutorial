Tanpa membuat adapter apa pun, Hive sudah bisa menyimpan List dan Map. Ini cara tercepat menyimpan data terstruktur, dan juga cara yang dipakai untuk cache data JSON dari API atau Supabase.

Menyimpan dan membaca List & Map

import 'package:flutter/foundation.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

Future<void> demoMapList() async {
  final box = await Hive.openBox('profil_box');

  // Menyimpan List dan Map langsung, tanpa adapter
  await box.put('matkul_favorit', ['Pemrograman Mobile', 'Basis Data', 'AI']);
  await box.put('profil', {
    'nama': 'Siti Aminah',
    'nim': 'H1D023001',
    'ipk': 3.75,
    'hobi': ['membaca', 'coding'],
  });

  final favorit = box.get('matkul_favorit') as List;
  debugPrint('Jumlah favorit: ${favorit.length}');
  debugPrint('Pertama: ${favorit.first}');

  final profil = box.get('profil') as Map;
  debugPrint('Nama: ${profil['nama']}, IPK: ${profil['ipk']}');
}

Future<void> demoMapSetelahDibukaUlang() async {
  final box = await Hive.openBox('profil_box');
  final mentah = box.get('profil');
  debugPrint('Tipe asli: ${mentah.runtimeType}');

  // final salah = mentah as Map<String, dynamic>; // TypeError!
  final profil = Map<String, dynamic>.from(mentah as Map);
  final hobi = List<String>.from(profil['hobi'] as List);
  debugPrint('${profil['nama']} punya ${hobi.length} hobi');
}

Output saat demoMapList() dijalankan, lalu aplikasi dibuka ulang dan demoMapSetelahDibukaUlang() dijalankan:

Jumlah favorit: 3
Pertama: Pemrograman Mobile
Nama: Siti Aminah, IPK: 3.75
Tipe asli: _Map<dynamic, dynamic>
Siti Aminah punya 2 hobi

⚠️ Jebakan paling sering: Map<dynamic, dynamic>

Saat disimpan, Map kamu bertipe Map<String, Object>. Namun setelah aplikasi dibuka ulang, Hive membacanya kembali dari file sebagai Map<dynamic, dynamic>. Akibatnya cast langsung akan gagal:

type '_Map<dynamic, dynamic>' is not a subtype of type 'Map<String, dynamic>' in type cast

Yang lebih menjebak, error ini tidak muncul saat kamu baru saja menyimpan data (data masih berupa objek asli di memori), tetapi baru muncul setelah aplikasi di-restart. Solusinya: selalu salin dengan Map<String, dynamic>.from(...) dan List<String>.from(...), atau terima parameter bertipe Map saja.

Pola model + toMap/fromMap

Agar tidak bekerja dengan Map mentah di seluruh aplikasi, buat kelas model yang bisa diubah ke Map dan sebaliknya. Pola ini sama dengan toJson/fromJson di Modul 09.

📄 lib/models/tugas.dart

// lib/models/tugas.dart
class Tugas {
  final String id;
  final String judul;
  final DateTime deadline;
  final bool selesai;

  const Tugas({
    required this.id,
    required this.judul,
    required this.deadline,
    this.selesai = false,
  });

  // Objek -> Map (untuk disimpan ke Hive, atau dikirim ke API)
  Map<String, dynamic> toMap() => {
        'id': id,
        'judul': judul,
        'deadline': deadline.toIso8601String(),
        'selesai': selesai,
      };

  // Map -> Objek. Parameter bertipe Map (bukan Map<String, dynamic>)
  // karena Map dari Hive bertipe Map<dynamic, dynamic>.
  factory Tugas.fromMap(Map map) => Tugas(
        id: map['id'] as String,
        judul: map['judul'] as String,
        deadline: DateTime.parse(map['deadline'] as String),
        selesai: map['selesai'] as bool? ?? false,
      );
}

📄 lib/repositories/tugas_repository.dart

// lib/repositories/tugas_repository.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import '../models/tugas.dart';

class TugasRepository {
  // Box<Map>: setiap value adalah Map
  final Box<Map> _box = Hive.box<Map>('tugas_box');

  Future<void> simpan(Tugas tugas) => _box.put(tugas.id, tugas.toMap());

  List<Tugas> ambilSemua() =>
      _box.values.map((map) => Tugas.fromMap(map)).toList();

  Future<void> hapus(String id) => _box.delete(id);
}

Jangan lupa membuka box-nya dengan tipe yang sama di main(): await Hive.openBox<Map>('tugas_box');

Kenapa DateTime diubah menjadi String ISO? Sebenarnya Hive bisa menyimpan DateTime langsung di dalam Map. Namun memakai toIso8601String() membuat Map yang sama juga bisa dikirim sebagai JSON ke server tanpa perubahan. Itu berguna ketika data lokal harus disinkronkan dengan backend.

💡 Map atau TypeAdapter?

  • Map (bagian ini): tanpa adapter, tidak ada typeId, mudah ditambah field baru (field lama yang tidak ada cukup diberi nilai default di fromMap). Cocok untuk cache data dari API dan untuk data yang strukturnya masih sering berubah.
  • TypeAdapter (bagian 5 dan 6): objek tersimpan langsung, box.get() sudah mengembalikan objek bertipe tepat, dan file lebih ringkas. Cocok untuk model yang stabil.
