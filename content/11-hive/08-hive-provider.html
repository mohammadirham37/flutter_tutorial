Di Modul 08 kamu belajar Provider untuk mengelola state. Sekarang kita gabungkan dengan Hive memakai pola yang umum dipakai di industri: Repository untuk urusan penyimpanan dan Provider (ChangeNotifier) untuk state UI.

Pembagian tugas

LapisanTugasBoleh tahu tentang
RepositoryMembaca dan menulis box HiveHive, model
ProviderLogika aplikasi, memanggil repository, lalu notifyListeners()Repository, model
WidgetMenampilkan data, meneruskan aksi pengguna ke providerProvider, model (tidak menyentuh Hive langsung)

Keuntungannya: jika suatu saat penyimpanan diganti (misalnya ke Supabase di Modul 12), yang diubah cukup repository. Widget tidak perlu disentuh, dan repository mudah diuji tanpa UI.

Contoh: pengaturan tema gelap dan nama pengguna yang tersimpan di Hive. Pasang package dulu: flutter pub add hive_ce hive_ce_flutter provider.

Langkah 1: Repository

📄 lib/repositories/pengaturan_repository.dart

// lib/repositories/pengaturan_repository.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

class PengaturanRepository {
  static const String namaBox = 'pengaturan';
  static const String _kunciTemaGelap = 'tema_gelap';
  static const String _kunciNama = 'nama_pengguna';

  final Box _box;

  PengaturanRepository(this._box);

  static Future<PengaturanRepository> buka() async {
    final box = await Hive.openBox(namaBox);
    return PengaturanRepository(box);
  }

  bool get temaGelap => _box.get(_kunciTemaGelap, defaultValue: false) as bool;
  Future<void> setTemaGelap(bool nilai) => _box.put(_kunciTemaGelap, nilai);

  String get namaPengguna =>
      _box.get(_kunciNama, defaultValue: 'Mahasiswa') as String;
  Future<void> setNamaPengguna(String nama) => _box.put(_kunciNama, nama);
}

Nama box dan nama key disimpan sebagai konstanta privat. Seluruh aplikasi tidak perlu tahu bahwa tema disimpan dengan key 'tema_gelap', sehingga salah ketik key tidak tersebar di banyak file.

Langkah 2: Provider

📄 lib/providers/pengaturan_provider.dart

// lib/providers/pengaturan_provider.dart
import 'package:flutter/foundation.dart';

import '../repositories/pengaturan_repository.dart';

class PengaturanProvider with ChangeNotifier {
  final PengaturanRepository _repo;

  PengaturanProvider(this._repo);

  // Nilai awal langsung dibaca dari Hive (sinkron, tanpa await)
  bool get temaGelap => _repo.temaGelap;
  String get namaPengguna => _repo.namaPengguna;

  Future<void> gantiTema(bool gelap) async {
    await _repo.setTemaGelap(gelap);
    notifyListeners();
  }

  Future<void> gantiNama(String nama) async {
    await _repo.setNamaPengguna(nama);
    notifyListeners();
  }
}

Langkah 3: main.dart

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';
import 'package:provider/provider.dart';

import 'providers/pengaturan_provider.dart';
import 'repositories/pengaturan_repository.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Hive.initFlutter();
  final repo = await PengaturanRepository.buka();

  runApp(
    ChangeNotifierProvider(
      create: (_) => PengaturanProvider(repo),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    final temaGelap = context.watch<PengaturanProvider>().temaGelap;
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      darkTheme: ThemeData(
        colorSchemeSeed: Colors.indigo,
        brightness: Brightness.dark,
      ),
      themeMode: temaGelap ? ThemeMode.dark : ThemeMode.light,
      home: const PengaturanScreen(),
    );
  }
}

class PengaturanScreen extends StatelessWidget {
  const PengaturanScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final pengaturan = context.watch<PengaturanProvider>();
    return Scaffold(
      appBar: AppBar(title: Text('Halo, ${pengaturan.namaPengguna}')),
      body: ListView(
        children: [
          SwitchListTile(
            title: const Text('Tema gelap'),
            subtitle: const Text('Tersimpan di Hive, tetap ada saat dibuka lagi'),
            value: pengaturan.temaGelap,
            onChanged: (nilai) =>
                context.read<PengaturanProvider>().gantiTema(nilai),
          ),
          Padding(
            padding: const EdgeInsets.all(16),
            child: TextFormField(
              initialValue: pengaturan.namaPengguna,
              decoration: const InputDecoration(
                labelText: 'Nama panggilan',
                border: OutlineInputBorder(),
              ),
              onFieldSubmitted: (nama) =>
                  context.read<PengaturanProvider>().gantiNama(nama.trim()),
            ),
          ),
        ],
      ),
    );
  }
}
Tema terang (nilai awal)
Setelah switch ditekan: tema gelap tersimpan dan tetap aktif saat aplikasi dibuka lagi

Penjelasan:

  • Repository dibuka di main() (async), lalu dikirim ke provider lewat constructor. Dengan begitu provider tidak perlu berurusan dengan await openBox.
  • Getter temaGelap di provider langsung membaca Hive. Karena membaca box itu sinkron, tidak perlu menyalin data ke variabel lain atau menunggu Future.
  • context.watch di MyApp membuat MaterialApp dibangun ulang saat tema berubah, sedangkan context.read dipakai di onChanged (aturan yang sama dengan Modul 08).

ℹ️ Bandingkan dengan Modul 10

Di SharedPreferences, membaca nilai butuh await SharedPreferences.getInstance(), sehingga tema awal harus dimuat secara async. Dengan Hive, setelah box dibuka di main(), nilai bisa langsung dibaca di build().
