Di Modul 10 kamu sudah memakai SharedPreferences untuk data kecil dan SQLite untuk data berbentuk tabel. Modul ini mengenalkan pilihan ketiga yang sangat populer di Flutter: Hive, database NoSQL yang ringan, cepat, dan ditulis murni dengan Dart.

Hive itu apa?

Hive adalah database key-value. Bayangkan sebuah Map di Dart yang isinya otomatis tersimpan ke file, sehingga tidak hilang saat aplikasi ditutup. Kamu menyimpan data dengan sebuah key (kunci) lalu mengambilnya lagi memakai key yang sama.

// Map biasa: hilang saat aplikasi ditutup
final dataSementara = <String, dynamic>{};
dataSementara['nama'] = 'Budi';

// Box Hive: cara pakainya mirip Map, tetapi tersimpan permanen ke file
// box.put('nama', 'Budi');
// box.get('nama'); // 'Budi', bahkan setelah aplikasi dibuka ulang

Istilah penting: Box

Data di Hive dikelompokkan ke dalam box. Satu box kira-kira setara dengan satu tabel di SQLite atau satu "laci" penyimpanan. Contoh pembagiannya:

  • pengaturan: tema gelap, bahasa, nama pengguna.
  • catatan_box: semua catatan kuliah.
  • cache_mahasiswa: data dari server yang disimpan sementara agar bisa dibuka saat offline.

Setiap box disimpan sebagai file sendiri (nama_box.hive) di folder dokumen aplikasi. Box yang sudah dibuka isinya dimuat ke memori, sehingga membaca data dari box tidak perlu await dan hasilnya langsung didapat.

NoSQL: tidak ada tabel dan kolom

Berbeda dengan SQLite, Hive tidak memakai CREATE TABLE, tidak ada skema kolom, dan tidak ada query SQL. Value yang disimpan bisa berupa:

  • Tipe dasar: String, int, double, bool, DateTime, null.
  • Koleksi: List dan Map (boleh bersarang).
  • Objek buatan sendiri (misalnya Catatan), asalkan kamu mendaftarkan TypeAdapter (dibahas di bagian 5).

💡 Aturan praktis

Cuma beberapa pengaturan? Pakai SharedPreferences. Butuh menyimpan daftar objek dengan cepat dan tanpa SQL? Pakai Hive. Butuh relasi antar tabel dan query kompleks? Pakai SQLite. Ketiganya boleh dipakai bersamaan dalam satu aplikasi.

Kenapa hive_ce, bukan hive?

Di pub.dev ada package hive versi 2.x yang dulu sangat populer. Sayangnya package itu sudah lama tidak dirawat lagi oleh pembuatnya. Komunitas lalu melanjutkannya sebagai Hive Community Edition: hive_ce dan hive_ce_flutter. API-nya hampir sama persis (Hive.openBox, box.put, TypeAdapter, dan seterusnya), tetapi rutin diperbarui untuk versi Dart dan Flutter terbaru, serta ada tambahan seperti @GenerateAdapters dan rentang typeId yang jauh lebih besar. Jadi tutorial lama tentang hive umumnya tetap bisa diikuti; yang berbeda hanya nama package dan baris import.
