Jika kamu mencoba box.put('a', Mahasiswa(...)) tanpa persiapan, Hive akan melempar HiveError: Cannot write, unknown type: Mahasiswa. Did you forget to register an adapter?. Hive tidak tahu cara mengubah objek buatanmu menjadi byte. Tugas itu dikerjakan oleh TypeAdapter.

Cara kerja TypeAdapter

TypeAdapter adalah kelas yang berisi tiga hal:

  1. typeId: nomor unik untuk tipe ini. Hive menulis nomor ini di depan data agar tahu adapter mana yang harus dipakai saat membaca.
  2. write(): mengubah objek menjadi urutan nilai (serialisasi).
  3. read(): membaca urutan nilai itu kembali menjadi objek (deserialisasi).

Kita menulis adapter secara manual dulu (tanpa code generator) supaya jelas apa yang sebenarnya terjadi.

Langkah 1: Model dan adapter

📄 lib/models/mahasiswa.dart

// lib/models/mahasiswa.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

class Mahasiswa {
  final String nim;
  final String nama;
  final int semester;
  final double ipk;

  const Mahasiswa({
    required this.nim,
    required this.nama,
    required this.semester,
    required this.ipk,
  });

  @override
  String toString() => 'Mahasiswa($nim, $nama, smt $semester, IPK $ipk)';
}

class MahasiswaAdapter extends TypeAdapter<Mahasiswa> {
  @override
  final int typeId = 1; // nomor unik untuk kelas Mahasiswa

  @override
  Mahasiswa read(BinaryReader reader) {
    // Urutan baca = urutan tulis
    final nim = reader.readString();
    final nama = reader.readString();
    final semester = reader.readInt();
    final ipk = reader.readDouble();
    return Mahasiswa(nim: nim, nama: nama, semester: semester, ipk: ipk);
  }

  @override
  void write(BinaryWriter writer, Mahasiswa obj) {
    writer.writeString(obj.nim);
    writer.writeString(obj.nama);
    writer.writeInt(obj.semester);
    writer.writeDouble(obj.ipk);
  }
}

Method yang tersedia di BinaryWriter dan BinaryReader berpasangan: writeString/readString, writeInt/readInt, writeDouble/readDouble, writeBool/readBool, writeByte/readByte, writeList/readList, writeMap/readMap, serta write/read yang otomatis memakai tipe yang dikenal Hive.

Langkah 2: Daftarkan adapter lalu pakai box bertipe

import 'package:flutter/foundation.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import 'models/mahasiswa.dart';

Future<void> demoMahasiswa() async {
  // Di main(): setelah Hive.initFlutter(), sebelum openBox
  Hive.registerAdapter(MahasiswaAdapter());

  final box = await Hive.openBox<Mahasiswa>('mahasiswa_box');

  await box.put(
    'H1D023001',
    const Mahasiswa(nim: 'H1D023001', nama: 'Siti', semester: 4, ipk: 3.75),
  );
  await box.put(
    'H1D023002',
    const Mahasiswa(nim: 'H1D023002', nama: 'Andi', semester: 4, ipk: 3.20),
  );

  final siti = box.get('H1D023001'); // tipe: Mahasiswa?
  debugPrint('$siti');
  debugPrint('IPK Siti: ${siti?.ipk}');

  final ipkTinggi = box.values.where((m) => m.ipk >= 3.5).toList();
  debugPrint('IPK >= 3.5: ${ipkTinggi.map((m) => m.nama).toList()}');
}

Output:

Mahasiswa(H1D023001, Siti, smt 4, IPK 3.75)
IPK Siti: 3.75
IPK >= 3.5: [Siti]

Perhatikan bahwa box.get() langsung mengembalikan Mahasiswa?, bukan Map. Filter seperti "IPK minimal 3.5" dikerjakan dengan where() biasa di Dart.

Aturan typeId

  • Unik per aplikasi. Dua adapter dengan typeId sama memicu HiveError: There is already a TypeAdapter for typeId 1.
  • Jangan pernah diganti setelah aplikasi dipakai orang. Data lama di file tetap bertanda typeId lama, sehingga tidak bisa dibaca lagi.
  • Rentang yang diizinkan hive_ce adalah 0 sampai 65439 (package hive lama hanya 0 sampai 223). Mulailah dari 0, 1, 2, dan seterusnya.
  • Hive.initFlutter() sudah mendaftarkan adapter bawaan untuk Color (typeId 200) dan TimeOfDay (typeId 201). Hindari dua nomor itu.
  • Daftarkan adapter sebelum openBox yang menyimpan tipe tersebut.

Aturan urutan field

Adapter manual membaca data secara berurutan seperti kaset: tidak ada nama field di file, hanya nilai-nilai yang berjajar. Jika di write() urutannya nim, nama, semester, ipk, maka read() wajib membaca nim, nama, semester, ipk juga. Tertukar sedikit saja (misalnya readDouble sebelum readInt) akan menghasilkan data aneh atau error RangeError.

Hati-hati saat model berubah (migrasi)

Bayangkan aplikasi sudah dipakai, lalu kamu menambah field email. Data lama di HP pengguna tidak punya email. Jika read() langsung memanggil readString() keempat, Hive membaca melewati batas data dan aplikasi crash.

Trik sederhana: tulis nomor versi format sebagai byte pertama sejak awal. Saat membaca, field baru hanya dibaca jika versinya mendukung.

// Versi 2 dari model: field baru `email`
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

class Dosen {
  final String nidn;
  final String nama;
  final String email; // FIELD BARU di versi 2

  const Dosen({required this.nidn, required this.nama, this.email = ''});
}

class DosenAdapter extends TypeAdapter<Dosen> {
  @override
  final int typeId = 2;

  static const int _versiSekarang = 2;

  @override
  Dosen read(BinaryReader reader) {
    final versi = reader.readByte(); // byte pertama = versi format
    final nidn = reader.readString();
    final nama = reader.readString();
    // Data versi 1 belum punya email, jadi hanya dibaca jika versi >= 2
    final email = versi >= 2 ? reader.readString() : '';
    return Dosen(nidn: nidn, nama: nama, email: email);
  }

  @override
  void write(BinaryWriter writer, Dosen obj) {
    writer.writeByte(_versiSekarang);
    writer.writeString(obj.nidn);
    writer.writeString(obj.nama);
    writer.writeString(obj.email); // field baru selalu DITAMBAH DI AKHIR
  }
}

⚠️ Aturan migrasi adapter manual

  • Field baru selalu ditambah di akhir, jangan disisipkan di tengah.
  • Jangan menghapus atau mengubah tipe field lama. Jika tidak dipakai lagi, tetap baca lalu abaikan nilainya.
  • Selama masih tahap belajar dan data boleh hilang, cara paling cepat adalah menghapus aplikasi dari emulator (uninstall) agar file box ikut terhapus.
  • Kode yang dibuat generator (bagian 6) menulis nomor indeks untuk setiap field, sehingga migrasi jauh lebih aman. Itu alasan utama memakai codegen di proyek nyata.
