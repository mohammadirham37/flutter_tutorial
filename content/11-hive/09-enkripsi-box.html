File box Hive tersimpan sebagai data biner biasa. Siapa pun yang bisa menyalin file aplikasi (misalnya di HP yang di-root) bisa membaca isinya. Untuk data sensitif seperti token atau catatan pribadi, Hive mendukung enkripsi AES-256 per box.

Bahan yang dibutuhkan

  • Kunci 256-bit (32 byte). Dibuat sekali dengan Hive.generateSecureKey().
  • Tempat aman untuk kunci. Kunci tidak boleh disimpan di Hive biasa atau ditulis di kode. Simpan di flutter_secure_storage, yang memakai Keystore (Android) dan Keychain (iOS).
  • HiveAesCipher(kunci) yang diberikan ke openBox lewat parameter encryptionCipher.
flutter pub add flutter_secure_storage

Versi terbaru flutter_secure_storage membutuhkan Android minimal API 23. Jika build gagal karena minSdk, ubah minSdk di android/app/build.gradle.kts menjadi minimal 23.

📄 lib/services/box_rahasia.dart

// lib/services/box_rahasia.dart
import 'dart:convert';

import 'package:flutter_secure_storage/flutter_secure_storage.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

const _storage = FlutterSecureStorage();
const _namaKunci = 'kunci_enkripsi_hive';

Future<Box<String>> bukaBoxRahasia() async {
  // 1. Coba ambil kunci yang pernah disimpan
  var kunciBase64 = await _storage.read(key: _namaKunci);

  // 2. Belum ada? Buat kunci acak 256-bit lalu simpan ke secure storage
  if (kunciBase64 == null) {
    final kunciBaru = Hive.generateSecureKey(); // List<int> 32 byte
    kunciBase64 = base64UrlEncode(kunciBaru);
    await _storage.write(key: _namaKunci, value: kunciBase64);
  }

  // 3. Buka box dengan cipher AES
  final kunci = base64Url.decode(kunciBase64);
  return Hive.openBox<String>(
    'rahasia',
    encryptionCipher: HiveAesCipher(kunci),
  );
}

Pemakaiannya sama seperti box biasa. Enkripsi dan dekripsi terjadi otomatis:

// Di main(), setelah await Hive.initFlutter();
final rahasia = await bukaBoxRahasia();
await rahasia.put('token', 'eyJhbGciOi...');
debugPrint(rahasia.get('token')); // eyJhbGciOi...

Penjelasan:

  • Kunci berupa List<int>, sedangkan secure storage hanya menyimpan String. Karena itu kunci diubah dengan base64UrlEncode saat disimpan dan base64Url.decode saat dipakai.
  • Kunci dibuat sekali saja. Membuat kunci baru setiap aplikasi dibuka berarti data lama tidak akan bisa dibaca lagi.
  • Hanya value yang dienkripsi. Key box tetap tersimpan tanpa enkripsi, jadi jangan menaruh informasi sensitif di nama key.

⚠️ Perhatian

  • Membuka box terenkripsi dengan kunci yang salah, atau membuka box biasa yang sudah berisi data dengan cipher, akan memicu error. Tentukan sejak awal box mana yang dienkripsi.
  • Jika kunci hilang (misalnya data secure storage terhapus), isi box tidak bisa dipulihkan. Untuk data yang masih ada di server, cukup hapus box lalu unduh ulang.
