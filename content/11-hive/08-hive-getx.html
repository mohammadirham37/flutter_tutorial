Di Modul 08 kamu belajar GetX dengan pola MVC untuk mengelola state. Sekarang kita gabungkan dengan Hive: service mengurus penyimpanan di box, controller (GetxController) menyimpan state reaktif, dan view cukup menampilkan data lewat Obx.

Pembagian tugas

LapisanFolderTugasBoleh tahu tentang
Modelmodels/Class data murni (bagian 5 dan 6)Tidak bergantung pada apa pun
Serviceservices/Membaca dan menulis box HiveHive, model
Controllercontrollers/Logika aplikasi dan state .obs, memanggil serviceService, model (tanpa widget, tanpa Hive langsung)
Viewviews/Menampilkan data dengan Obx, meneruskan aksi pengguna ke controllerController, model (tidak menyentuh Hive langsung)

Arah ketergantungannya satu jalur: View → Controller → Service → Hive. Keuntungannya: jika suatu saat penyimpanan diganti (misalnya ke Supabase di Modul 12), yang diubah cukup service. View tidak perlu disentuh, dan service maupun controller mudah diuji tanpa UI.

ℹ️ Service atau repository?

Di banyak tutorial, kelas yang membungkus box Hive disebut repository. Di kursus ini kita memakai nama service agar sama dengan struktur MVC Modul 08. Isinya sama saja: satu-satunya tempat yang menyentuh box. Di Modul 13–14 kamu akan melihat lagi nama repository untuk lapisan yang serupa.

Contoh: pengaturan tema gelap dan nama pengguna yang tersimpan di Hive. Pasang package dulu: flutter pub add hive_ce hive_ce_flutter get.

Langkah 1: Service

📄 lib/services/pengaturan_service.dart

// lib/services/pengaturan_service.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

class PengaturanService {
  static const String namaBox = 'pengaturan';
  static const String _kunciTemaGelap = 'tema_gelap';
  static const String _kunciNama = 'nama_pengguna';

  final Box _box;

  PengaturanService(this._box);

  static Future<PengaturanService> buka() async {
    final box = await Hive.openBox(namaBox);
    return PengaturanService(box);
  }

  bool get temaGelap => _box.get(_kunciTemaGelap, defaultValue: false) as bool;
  Future<void> setTemaGelap(bool nilai) => _box.put(_kunciTemaGelap, nilai);

  String get namaPengguna =>
      _box.get(_kunciNama, defaultValue: 'Mahasiswa') as String;
  Future<void> setNamaPengguna(String nama) => _box.put(_kunciNama, nama);
}

Nama box dan nama key disimpan sebagai konstanta privat. Seluruh aplikasi tidak perlu tahu bahwa tema disimpan dengan key 'tema_gelap', sehingga salah ketik key tidak tersebar di banyak file. Perhatikan juga bahwa service tidak mengimpor GetX sama sekali: ia hanya Dart + Hive.

Langkah 2: Controller

📄 lib/controllers/pengaturan_controller.dart

// lib/controllers/pengaturan_controller.dart
import 'package:get/get.dart';

import '../services/pengaturan_service.dart';

class PengaturanController extends GetxController {
  PengaturanController(this._service);
  final PengaturanService _service;

  // State reaktif privat
  final _temaGelap = false.obs;
  final _namaPengguna = ''.obs;

  // Getter publik read-only
  bool get temaGelap => _temaGelap.value;
  String get namaPengguna => _namaPengguna.value;

  @override
  void onInit() {
    super.onInit();
    // Nilai awal langsung dibaca dari Hive (sinkron, tanpa await)
    _temaGelap.value = _service.temaGelap;
    _namaPengguna.value = _service.namaPengguna;
  }

  Future<void> gantiTema(bool gelap) async {
    await _service.setTemaGelap(gelap); // simpan permanen dulu
    _temaGelap.value = gelap; // lalu kabari Obx
  }

  Future<void> gantiNama(String nama) async {
    await _service.setNamaPengguna(nama);
    _namaPengguna.value = nama;
  }
}
  • Service masuk lewat constructor, persis seperti pola controller di Modul 08. Controller tidak tahu cara membuka box.
  • Nilai awal diisi di onInit(). Membaca box Hive itu sinkron, jadi tidak perlu isLoading atau await.
  • Setiap method tulis menyimpan ke Hive dulu, baru mengubah nilai .obs. Mengubah .value otomatis membuat setiap Obx yang membacanya dibangun ulang.

Langkah 3: main.dart dan view

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import 'controllers/pengaturan_controller.dart';
import 'services/pengaturan_service.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Hive.initFlutter();
  final service = await PengaturanService.buka();
  Get.put(PengaturanController(service));

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    final controller = Get.find<PengaturanController>();
    // Obx membangun ulang GetMaterialApp hanya saat temaGelap berubah
    return Obx(
      () => GetMaterialApp(
        debugShowCheckedModeBanner: false,
        theme: ThemeData(colorSchemeSeed: Colors.indigo),
        darkTheme: ThemeData(
          colorSchemeSeed: Colors.indigo,
          brightness: Brightness.dark,
        ),
        themeMode: controller.temaGelap ? ThemeMode.dark : ThemeMode.light,
        home: const PengaturanView(),
      ),
    );
  }
}

class PengaturanView extends GetView<PengaturanController> {
  const PengaturanView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Obx(() => Text('Halo, ${controller.namaPengguna}')),
      ),
      body: ListView(
        children: [
          Obx(
            () => SwitchListTile(
              title: const Text('Tema gelap'),
              subtitle:
                  const Text('Tersimpan di Hive, tetap ada saat dibuka lagi'),
              value: controller.temaGelap,
              onChanged: controller.gantiTema,
            ),
          ),
          Padding(
            padding: const EdgeInsets.all(16),
            child: TextFormField(
              initialValue: controller.namaPengguna,
              decoration: const InputDecoration(
                labelText: 'Nama panggilan',
                border: OutlineInputBorder(),
              ),
              onFieldSubmitted: (nama) => controller.gantiNama(nama.trim()),
            ),
          ),
        ],
      ),
    );
  }
}
Tema terang (nilai awal)
Setelah switch ditekan: tema gelap tersimpan dan tetap aktif saat aplikasi dibuka lagi

Penjelasan:

  • Service dibuka di main() (async), lalu diberikan ke controller lewat constructor dan didaftarkan dengan Get.put. Dengan begitu controller tidak perlu berurusan dengan await openBox.
  • Obx di MyApp membaca controller.temaGelap, sehingga GetMaterialApp dibangun ulang hanya saat tema berubah.
  • PengaturanView memakai GetView<PengaturanController> sehingga getter controller langsung tersedia. Hanya judul AppBar dan switch yang dibungkus Obx, karena hanya bagian itu yang perlu berubah.
  • Di callback (onChanged, onFieldSubmitted) controller dipanggil langsung tanpa Obx, aturan yang sama dengan Modul 08.
  • TextFormField memakai initialValue yang hanya dibaca sekali, jadi tidak perlu dibungkus Obx.

ℹ️ Bandingkan dengan Modul 10

Di SharedPreferences, membaca nilai butuh await SharedPreferences.getInstance(), sehingga tema awal harus dimuat secara async. Dengan Hive, setelah box dibuka di main(), nilai bisa langsung dibaca di onInit() controller tanpa menunggu.

⚠️ Kesalahan umum

  • Memanggil Hive.box(...) langsung dari view. Biarkan hanya service yang tahu tentang box.
  • Mengubah data di box tanpa mengubah .obs di controller. Box memang berubah, tetapi Obx tidak tahu dan layar tetap menampilkan nilai lama.
  • Membungkus seluruh Scaffold dengan satu Obx besar. Bungkus hanya widget yang membaca nilai reaktif.
