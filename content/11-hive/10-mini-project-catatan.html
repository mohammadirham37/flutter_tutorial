Saatnya merangkai semua materi menjadi satu aplikasi utuh: Catatan Kuliah Offline. Aplikasi ini berjalan 100% tanpa internet dan datanya tetap ada walaupun aplikasi ditutup.

Fitur yang dibangun

  • Create: menambah catatan (judul, mata kuliah, isi) lewat form dengan validasi.
  • Read: menampilkan daftar catatan dalam ListView.
  • Update: mengetuk catatan untuk membuka form edit yang sudah terisi.
  • Delete: menghapus catatan setelah konfirmasi dialog.
  • Cari: berdasarkan judul, mata kuliah, atau isi.
  • Urutkan: terbaru, terlama, atau judul A-Z.
  • Empty state: tampilan khusus saat belum ada catatan dan saat pencarian tidak menemukan hasil.

Langkah 1: Model Catatan

Model berisi data murni tanpa kode Hive. copyWith dipakai saat edit agar kita tidak mengubah objek lama, melainkan membuat salinan dengan field yang diganti. id dan dibuatPada sengaja tidak bisa diganti.

📄 lib/models/catatan.dart

// lib/models/catatan.dart
class Catatan {
  final String id;
  final String judul;
  final String mataKuliah;
  final String isi;
  final DateTime dibuatPada;
  final DateTime diubahPada;

  const Catatan({
    required this.id,
    required this.judul,
    required this.mataKuliah,
    required this.isi,
    required this.dibuatPada,
    required this.diubahPada,
  });

  // Membuat salinan objek dengan sebagian field diganti (dipakai saat edit)
  Catatan copyWith({
    String? judul,
    String? mataKuliah,
    String? isi,
    DateTime? diubahPada,
  }) {
    return Catatan(
      id: id,
      judul: judul ?? this.judul,
      mataKuliah: mataKuliah ?? this.mataKuliah,
      isi: isi ?? this.isi,
      dibuatPada: dibuatPada,
      diubahPada: diubahPada ?? this.diubahPada,
    );
  }
}

Langkah 2: TypeAdapter manual

Adapter ini menerapkan pelajaran dari bagian 5: urutan baca sama dengan urutan tulis, DateTime disimpan sebagai angka milidetik, dan byte pertama adalah nomor versi format agar migrasi di masa depan aman.

📄 lib/models/catatan_adapter.dart

// lib/models/catatan_adapter.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import 'catatan.dart';

class CatatanAdapter extends TypeAdapter<Catatan> {
  // typeId harus unik di seluruh aplikasi dan TIDAK BOLEH diganti setelah rilis
  @override
  final int typeId = 0;

  // Versi format penyimpanan. Naikkan jika suatu saat menambah field baru.
  static const int _versi = 1;

  @override
  Catatan read(BinaryReader reader) {
    final versi = reader.readByte(); // dibaca dulu, dipakai saat migrasi nanti
    assert(versi <= _versi, 'Data dibuat oleh versi aplikasi yang lebih baru');
    // Urutan baca HARUS sama persis dengan urutan tulis di write()
    return Catatan(
      id: reader.readString(),
      judul: reader.readString(),
      mataKuliah: reader.readString(),
      isi: reader.readString(),
      dibuatPada: DateTime.fromMillisecondsSinceEpoch(reader.readInt()),
      diubahPada: DateTime.fromMillisecondsSinceEpoch(reader.readInt()),
    );
  }

  @override
  void write(BinaryWriter writer, Catatan obj) {
    writer.writeByte(_versi);
    writer.writeString(obj.id);
    writer.writeString(obj.judul);
    writer.writeString(obj.mataKuliah);
    writer.writeString(obj.isi);
    writer.writeInt(obj.dibuatPada.millisecondsSinceEpoch);
    writer.writeInt(obj.diubahPada.millisecondsSinceEpoch);
  }
}

Langkah 3: Repository

Setiap catatan disimpan dengan put(catatan.id, catatan). Karena key-nya adalah id catatan, menyimpan catatan yang sudah ada otomatis menjadi update, dan menghapus cukup dengan id. Kita tidak memakai index sama sekali.

📄 lib/repositories/catatan_repository.dart

// lib/repositories/catatan_repository.dart
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

import '../models/catatan.dart';

/// Satu-satunya kelas yang boleh menyentuh box Hive catatan.
/// Widget dan provider cukup memanggil method di sini.
class CatatanRepository {
  static const String namaBox = 'catatan_box';

  final Box<Catatan> _box;

  CatatanRepository(this._box);

  /// Membuka box lalu membungkusnya menjadi repository.
  /// Pastikan Hive sudah di-init dan CatatanAdapter sudah didaftarkan.
  static Future<CatatanRepository> buka() async {
    final box = await Hive.openBox<Catatan>(namaBox);
    return CatatanRepository(box);
  }

  /// READ: semua catatan (urutan belum diatur)
  List<Catatan> ambilSemua() => _box.values.toList();

  /// READ: satu catatan berdasarkan id (null jika tidak ada)
  Catatan? ambil(String id) => _box.get(id);

  int get jumlah => _box.length;

  /// CREATE & UPDATE: put() dengan key yang sama akan menimpa data lama
  Future<void> simpan(Catatan catatan) => _box.put(catatan.id, catatan);

  /// DELETE: hapus satu catatan
  Future<void> hapus(String id) => _box.delete(id);

  /// DELETE: kosongkan seluruh catatan
  Future<int> hapusSemua() => _box.clear();
}

Langkah 4: Provider

Provider menyimpan state UI (kata kunci pencarian dan pilihan urutan) dan menyediakan getter daftar yang sudah difilter dan diurutkan. Setiap operasi tulis memanggil repository, lalu notifyListeners().

📄 lib/providers/catatan_provider.dart

// lib/providers/catatan_provider.dart
import 'package:flutter/foundation.dart';

import '../models/catatan.dart';
import '../repositories/catatan_repository.dart';

enum UrutanCatatan { terbaru, terlama, judulAZ }

class CatatanProvider with ChangeNotifier {
  final CatatanRepository _repo;

  CatatanProvider(this._repo);

  String _kataKunci = '';
  UrutanCatatan _urutan = UrutanCatatan.terbaru;

  String get kataKunci => _kataKunci;
  UrutanCatatan get urutan => _urutan;

  /// Jumlah seluruh catatan di box (tanpa filter pencarian)
  int get totalCatatan => _repo.jumlah;

  /// Daftar yang siap ditampilkan: sudah difilter lalu diurutkan
  List<Catatan> get daftar {
    final kunci = _kataKunci.trim().toLowerCase();
    final hasil = _repo.ambilSemua().where((c) {
      if (kunci.isEmpty) return true;
      return c.judul.toLowerCase().contains(kunci) ||
          c.mataKuliah.toLowerCase().contains(kunci) ||
          c.isi.toLowerCase().contains(kunci);
    }).toList();

    switch (_urutan) {
      case UrutanCatatan.terbaru:
        hasil.sort((a, b) => b.diubahPada.compareTo(a.diubahPada));
      case UrutanCatatan.terlama:
        hasil.sort((a, b) => a.diubahPada.compareTo(b.diubahPada));
      case UrutanCatatan.judulAZ:
        hasil.sort(
            (a, b) => a.judul.toLowerCase().compareTo(b.judul.toLowerCase()));
    }
    return hasil;
  }

  void cari(String kataKunci) {
    _kataKunci = kataKunci;
    notifyListeners();
  }

  void ubahUrutan(UrutanCatatan urutan) {
    _urutan = urutan;
    notifyListeners();
  }

  Future<void> tambah({
    required String judul,
    required String mataKuliah,
    required String isi,
  }) async {
    final sekarang = DateTime.now();
    final catatan = Catatan(
      // id unik sederhana berbasis waktu (tanpa package tambahan)
      id: sekarang.microsecondsSinceEpoch.toString(),
      judul: judul,
      mataKuliah: mataKuliah,
      isi: isi,
      dibuatPada: sekarang,
      diubahPada: sekarang,
    );
    await _repo.simpan(catatan);
    notifyListeners();
  }

  Future<void> ubah(
    Catatan lama, {
    required String judul,
    required String mataKuliah,
    required String isi,
  }) async {
    final baru = lama.copyWith(
      judul: judul,
      mataKuliah: mataKuliah,
      isi: isi,
      diubahPada: DateTime.now(),
    );
    await _repo.simpan(baru); // key sama, data lama tertimpa
    notifyListeners();
  }

  Future<void> hapus(String id) async {
    await _repo.hapus(id);
    notifyListeners();
  }
}
  • switch tanpa break adalah sintaks Dart 3: setiap case otomatis berhenti.
  • totalCatatan dipisah dari daftar.length agar layar bisa membedakan "belum ada catatan sama sekali" dan "pencarian tidak menemukan apa pun".
  • Id dibuat dari microsecondsSinceEpoch sehingga cukup unik untuk satu perangkat tanpa package tambahan. Di Modul 14 kita akan memakai id dari server.

class CatatanTile extends StatelessWidget {

Langkah 6: Layar form (tambah & edit)

Satu layar dipakai untuk dua mode. Jika parameter catatan bernilai null, form berada di mode tambah; jika berisi, form di mode edit dan field langsung terisi data lama.

📄 lib/screens/form_catatan_screen.dart

// lib/screens/form_catatan_screen.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import '../models/catatan.dart';
import '../providers/catatan_provider.dart';

class FormCatatanScreen extends StatefulWidget {
  /// null = mode tambah, berisi = mode edit
  final Catatan? catatan;

  const FormCatatanScreen({super.key, this.catatan});

  @override
  State<FormCatatanScreen> createState() => _FormCatatanScreenState();
}

class _FormCatatanScreenState extends State<FormCatatanScreen> {
  final _formKey = GlobalKey<FormState>();
  late final TextEditingController _judulCtrl;
  late final TextEditingController _matkulCtrl;
  late final TextEditingController _isiCtrl;
  bool _menyimpan = false;

  bool get _modeEdit => widget.catatan != null;

  @override
  void initState() {
    super.initState();
    // Saat mode edit, isi form dengan data lama
    _judulCtrl = TextEditingController(text: widget.catatan?.judul ?? '');
    _matkulCtrl = TextEditingController(text: widget.catatan?.mataKuliah ?? '');
    _isiCtrl = TextEditingController(text: widget.catatan?.isi ?? '');
  }

  @override
  void dispose() {
    _judulCtrl.dispose();
    _matkulCtrl.dispose();
    _isiCtrl.dispose();
    super.dispose();
  }

  String? _wajibDiisi(String? nilai) {
    if (nilai == null || nilai.trim().isEmpty) return 'Wajib diisi';
    return null;
  }

  Future<void> _simpan() async {
    if (!_formKey.currentState!.validate()) return;
    setState(() => _menyimpan = true);

    final provider = context.read<CatatanProvider>();
    final judul = _judulCtrl.text.trim();
    final matkul = _matkulCtrl.text.trim();
    final isi = _isiCtrl.text.trim();

    if (_modeEdit) {
      await provider.ubah(
        widget.catatan!,
        judul: judul,
        mataKuliah: matkul,
        isi: isi,
      );
    } else {
      await provider.tambah(judul: judul, mataKuliah: matkul, isi: isi);
    }

    if (!mounted) return; // widget bisa saja sudah ditutup saat menunggu
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text(_modeEdit ? 'Catatan diperbarui' : 'Catatan disimpan'),
      ),
    );
    Navigator.pop(context);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(_modeEdit ? 'Edit Catatan' : 'Catatan Baru'),
      ),
      body: Form(
        key: _formKey,
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            TextFormField(
              controller: _judulCtrl,
              decoration: const InputDecoration(
                labelText: 'Judul',
                border: OutlineInputBorder(),
              ),
              textInputAction: TextInputAction.next,
              validator: _wajibDiisi,
            ),
            const SizedBox(height: 12),
            TextFormField(
              controller: _matkulCtrl,
              decoration: const InputDecoration(
                labelText: 'Mata Kuliah',
                hintText: 'mis. Pemrograman Mobile',
                border: OutlineInputBorder(),
              ),
              textInputAction: TextInputAction.next,
              validator: _wajibDiisi,
            ),
            const SizedBox(height: 12),
            TextFormField(
              controller: _isiCtrl,
              decoration: const InputDecoration(
                labelText: 'Isi catatan',
                alignLabelWithHint: true,
                border: OutlineInputBorder(),
              ),
              minLines: 6,
              maxLines: 12,
            ),
            const SizedBox(height: 20),
            FilledButton.icon(
              onPressed: _menyimpan ? null : _simpan,
              icon: const Icon(Icons.save),
              label: Text(_modeEdit ? 'Simpan Perubahan' : 'Simpan'),
            ),
          ],
        ),
      ),
    );
  }
}
  • context.read<CatatanProvider>() diambil sebelum await, karena memakai context setelah await perlu dicek dulu.
  • if (!mounted) return; setelah await mencegah error jika layar sudah ditutup ketika penyimpanan selesai.
  • Tombol simpan dinonaktifkan (onPressed: null) selama menyimpan agar tidak terjadi simpan ganda.

Langkah 7: Layar utama

📄 lib/screens/home_screen.dart

// lib/screens/home_screen.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

import '../models/catatan.dart';
import '../providers/catatan_provider.dart';
import '../widgets/catatan_tile.dart';
import '../widgets/empty_state.dart';
import 'form_catatan_screen.dart';

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  void _bukaForm(BuildContext context, [Catatan? catatan]) {
    Navigator.of(context).push(
      MaterialPageRoute(
        builder: (_) => FormCatatanScreen(catatan: catatan),
      ),
    );
  }

  Future<void> _konfirmasiHapus(BuildContext context, Catatan catatan) async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (dialogContext) => AlertDialog(
        title: const Text('Hapus catatan?'),
        content: Text('Catatan "${catatan.judul}" akan dihapus permanen.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(dialogContext, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(dialogContext, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );

    // showDialog mengembalikan null jika dialog ditutup dengan tap di luar
    if (yakin != true) return;
    if (!context.mounted) return;

    await context.read<CatatanProvider>().hapus(catatan.id);
    if (!context.mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('"${catatan.judul}" dihapus')),
    );
  }

  @override
  Widget build(BuildContext context) {
    final provider = context.watch<CatatanProvider>();
    final daftar = provider.daftar;

    return Scaffold(
      appBar: AppBar(
        title: const Text('Catatan Kuliah'),
        actions: [
          PopupMenuButton<UrutanCatatan>(
            icon: const Icon(Icons.sort),
            tooltip: 'Urutkan',
            initialValue: provider.urutan,
            onSelected: (u) => context.read<CatatanProvider>().ubahUrutan(u),
            itemBuilder: (_) => const [
              PopupMenuItem(
                value: UrutanCatatan.terbaru,
                child: Text('Terbaru dulu'),
              ),
              PopupMenuItem(
                value: UrutanCatatan.terlama,
                child: Text('Terlama dulu'),
              ),
              PopupMenuItem(
                value: UrutanCatatan.judulAZ,
                child: Text('Judul A-Z'),
              ),
            ],
          ),
        ],
      ),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.fromLTRB(12, 8, 12, 4),
            child: TextField(
              decoration: const InputDecoration(
                hintText: 'Cari judul, mata kuliah, atau isi...',
                prefixIcon: Icon(Icons.search),
                border: OutlineInputBorder(),
                isDense: true,
              ),
              onChanged: (teks) => context.read<CatatanProvider>().cari(teks),
            ),
          ),
          Expanded(child: _buildDaftar(context, provider, daftar)),
        ],
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: () => _bukaForm(context),
        icon: const Icon(Icons.add),
        label: const Text('Catatan'),
      ),
    );
  }

  Widget _buildDaftar(
    BuildContext context,
    CatatanProvider provider,
    List<Catatan> daftar,
  ) {
    if (provider.totalCatatan == 0) {
      return const EmptyState(
        ikon: Icons.note_alt_outlined,
        judul: 'Belum ada catatan',
        pesan: 'Tekan tombol + Catatan untuk menulis catatan kuliah pertamamu.',
      );
    }
    if (daftar.isEmpty) {
      return EmptyState(
        ikon: Icons.search_off,
        judul: 'Tidak ditemukan',
        pesan: 'Tidak ada catatan yang cocok dengan "${provider.kataKunci}".',
      );
    }
    return ListView.builder(
      padding: const EdgeInsets.only(bottom: 88), // agar tidak tertutup FAB
      itemCount: daftar.length,
      itemBuilder: (context, index) {
        final catatan = daftar[index];
        return CatatanTile(
          key: ValueKey(catatan.id),
          catatan: catatan,
          onTap: () => _bukaForm(context, catatan),
          onHapus: () => _konfirmasiHapus(context, catatan),
        );
      },
    );
  }
}
  • context.watch di build membuat layar dibangun ulang setiap provider memanggil notifyListeners(): setelah tambah, edit, hapus, cari, atau ganti urutan.
  • showDialog<bool> mengembalikan true/false dari tombol, atau null jika dialog ditutup dengan mengetuk area luar. Karena itu yang dicek adalah yakin != true.
  • context.mounted dicek setelah setiap await sebelum context dipakai lagi.
  • ValueKey(catatan.id) membantu Flutter mengenali item yang sama saat urutan list berubah.

  // 2. Siapkan folder penyimpanan Hive

  // 3. Daftarkan adapter SEBELUM membuka box yang memakainya
  Hive.registerAdapter(CatatanAdapter());

  // 4. Buka box sekali di awal, lalu bungkus dengan repository
  final repo = await CatatanRepository.buka();

  runApp(
    ChangeNotifierProvider(
      create: (_) => CatatanProvider(repo),
      child: const CatatanApp(),
    ),
  );
}

class CatatanApp extends StatelessWidget {
  const CatatanApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Catatan Kuliah Offline',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
      ),
      home: const HomeScreen(),
    );
  }
}

Bonus: unit test repository

Repository yang terpisah dari UI bisa diuji tanpa emulator. Di unit test tidak ada path_provider, sehingga kita memakai Hive.init(folder) dengan folder sementara sebagai pengganti Hive.initFlutter(). Ganti catatan_kuliah pada baris import jika nama proyekmu berbeda (lihat name: di pubspec.yaml).

📄 test/catatan_repository_test.dart

// test/catatan_repository_test.dart
import 'dart:io';

import 'package:flutter_test/flutter_test.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';
import 'package:catatan_kuliah/models/catatan.dart';
import 'package:catatan_kuliah/models/catatan_adapter.dart';
import 'package:catatan_kuliah/repositories/catatan_repository.dart';

void main() {
  late Directory tempDir;
  late CatatanRepository repo;

  setUp(() async {
    // Di unit test tidak ada path_provider, jadi pakai Hive.init + folder sementara
    tempDir = await Directory.systemTemp.createTemp('hive_test_');
    Hive.init(tempDir.path);
    if (!Hive.isAdapterRegistered(0)) {
      Hive.registerAdapter(CatatanAdapter());
    }
    repo = await CatatanRepository.buka();
  });

  tearDown(() async {
    await Hive.deleteFromDisk(); // hapus semua box
    await Hive.close();
    await tempDir.delete(recursive: true);
  });

  Catatan buatCatatan(String id, String judul) {
    final t = DateTime(2025, 1, 1, 8, 0);
    return Catatan(
      id: id,
      judul: judul,
      mataKuliah: 'Pemrograman Mobile',
      isi: 'Isi $judul',
      dibuatPada: t,
      diubahPada: t,
    );
  }

  test('create dan read', () async {
    await repo.simpan(buatCatatan('1', 'Widget'));
    expect(repo.jumlah, 1);
    expect(repo.ambil('1')?.judul, 'Widget');
  });

  test('update menimpa data dengan id yang sama', () async {
    final c = buatCatatan('1', 'Widget');
    await repo.simpan(c);
    await repo.simpan(c.copyWith(judul: 'Widget Dasar'));
    expect(repo.jumlah, 1);
    expect(repo.ambil('1')?.judul, 'Widget Dasar');
  });

  test('delete dan hapusSemua', () async {
    await repo.simpan(buatCatatan('1', 'A'));
    await repo.simpan(buatCatatan('2', 'B'));
    await repo.hapus('1');
    expect(repo.ambil('1'), isNull);
    expect(repo.jumlah, 1);
    await repo.hapusSemua();
    expect(repo.ambilSemua(), isEmpty);
  });

  test('data tetap ada setelah box ditutup dan dibuka lagi', () async {
    await repo.simpan(buatCatatan('1', 'Persisten'));
    await Hive.close(); // seperti aplikasi ditutup
    final repoBaru = await CatatanRepository.buka();
    final c = repoBaru.ambil('1');
    expect(c?.judul, 'Persisten');
    expect(c?.dibuatPada, DateTime(2025, 1, 1, 8, 0)); // adapter bekerja
  });
}
