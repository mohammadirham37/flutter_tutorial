Hot reload vs hot restart

  • Hot reload tidak menjalankan ulang main(). Jika kamu baru menambah openBox atau registerAdapter di main(), perubahannya belum terpakai, sehingga error "Box not found" bisa muncul. Lakukan hot restart (tombol ⟳ atau tekan R di terminal).
  • Hot restart menjalankan ulang main() dari awal, tetapi file box tetap ada di perangkat. Data tidak ter-reset. Untuk benar-benar mengosongkan data, uninstall aplikasi atau panggil box.clear().
  • Setelah mengubah adapter dengan cara yang tidak kompatibel (mengubah urutan field), hot restart akan mencoba membaca data lama dengan adapter baru dan bisa crash. Uninstall aplikasi saat masih tahap development.

Tips debugging

// 1. Lihat seluruh isi box di Debug Console
debugPrint(Hive.box('pengaturan').toMap().toString());

// 2. Cek apakah box sudah terbuka sebelum dipakai
if (!Hive.isBoxOpen('catatan_box')) {
  await Hive.openBox<Catatan>('catatan_box');
}

// 3. Hapus satu box beserta filenya (misalnya tombol "Reset data" saat development)
await Hive.deleteBoxFromDisk('catatan_box');

// 4. Tangkap HiveError agar aplikasi tidak langsung crash
try {
  await Hive.openBox<Catatan>('catatan_box');
} on HiveError catch (e) {
  debugPrint('Gagal membuka box: ${e.message}');
}

💡 Ringkasan modul

  • Box = kumpulan key-value yang tersimpan permanen. Buka sekali di main(), lalu baca secara sinkron.
  • put berfungsi untuk create sekaligus update. Pakai key unik (id), hindari index.
  • Map dan List bisa langsung disimpan; ingat Map.from saat membaca.
  • Objek sendiri butuh TypeAdapter dengan typeId unik yang tidak boleh berubah; tulis manual atau generate dengan @GenerateAdapters.
  • UI reaktif lewat box.listenable() atau pola Repository + Provider.
  • Data sensitif: HiveAesCipher dengan kunci di flutter_secure_storage.
