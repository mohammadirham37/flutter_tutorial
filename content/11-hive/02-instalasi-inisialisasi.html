Sebelum bisa menyimpan data, Hive perlu dipasang, diberi tahu folder penyimpanannya, lalu box yang dibutuhkan dibuka. Semua itu dilakukan sekali di main().

Langkah 1: Pasang package

Buat proyek baru (atau pakai proyek yang ada), lalu jalankan dari folder proyek:

flutter create halo_hive
cd halo_hive
flutter pub add hive_ce hive_ce_flutter
  • hive_ce: inti database (murni Dart).
  • hive_ce_flutter: tambahan khusus Flutter, misalnya Hive.initFlutter() dan box.listenable().

Hasilnya di pubspec.yaml kurang lebih seperti ini (nomor versi mengikuti yang terbaru saat kamu menjalankan perintah):

dependencies:
  flutter:
    sdk: flutter
  hive_ce: ^x.y.z
  hive_ce_flutter: ^x.y.z

Langkah 2: Import

Di file Flutter cukup satu baris ini, karena hive_ce_flutter sudah ikut meng-export seluruh isi hive_ce:

import 'package:hive_ce_flutter/hive_ce_flutter.dart';

Untuk file Dart murni yang tidak menyentuh Flutter (misalnya model), boleh juga memakai import 'package:hive_ce/hive_ce.dart';.

Langkah 3: Inisialisasi di main()

Urutannya selalu sama:

  1. WidgetsFlutterBinding.ensureInitialized(): wajib karena kita memanggil kode async yang memakai plugin (mencari folder dokumen) sebelum runApp.
  2. await Hive.initFlutter(): menentukan folder penyimpanan.
  3. Hive.registerAdapter(...): jika memakai objek sendiri (bagian 5).
  4. await Hive.openBox(...): membuka box yang akan dipakai.
  5. runApp(...).

Contoh lengkap: aplikasi yang menghitung sudah berapa kali ia dibuka. Hapus seluruh isi lib/main.dart lalu ganti dengan kode berikut.

📄 lib/main.dart

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

Future<void> main() async {
  // Wajib dipanggil sebelum await apa pun yang memakai plugin
  WidgetsFlutterBinding.ensureInitialized();

  // Menentukan folder penyimpanan Hive (folder dokumen aplikasi)
  await Hive.initFlutter();

  // Membuka box bernama 'pengaturan'. Jika belum ada, Hive membuatnya.
  final box = await Hive.openBox('pengaturan');

  // Baca hitungan lama (default 0), tambah 1, simpan lagi
  final jumlahBuka = (box.get('jumlah_buka', defaultValue: 0) as int) + 1;
  await box.put('jumlah_buka', jumlahBuka);

  runApp(MyApp(jumlahBuka: jumlahBuka));
}

class MyApp extends StatelessWidget {
  final int jumlahBuka;

  const MyApp({super.key, required this.jumlahBuka});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Halo Hive')),
        body: Center(
          child: Text(
            'Aplikasi ini sudah dibuka $jumlahBuka kali',
            style: const TextStyle(fontSize: 20),
          ),
        ),
      ),
    );
  }
}
Angka bertambah setiap aplikasi dijalankan ulang, karena tersimpan di box

Penjelasan:

  • Future<void> main() async: main boleh async agar bisa menunggu Hive siap sebelum UI tampil.
  • Hive.openBox('pengaturan') membuat file pengaturan.hive jika belum ada. Box yang tidak diberi tipe bertipe Box<dynamic>, jadi boleh diisi tipe apa saja.
  • box.get('jumlah_buka', defaultValue: 0) mengembalikan 0 saat aplikasi pertama kali dibuka.
  • Coba tutup aplikasi sepenuhnya lalu buka lagi: angkanya bertambah. Itulah bukti data tersimpan permanen.

Mengambil box yang sudah dibuka

Membuka box itu operasi async (membaca file). Setelah terbuka, di mana pun di aplikasi kamu cukup memanggil Hive.box() yang sinkron:

// Di main(): sekali saja, pakai await
await Hive.openBox('pengaturan');

// Di widget atau kelas lain: langsung ambil, tanpa await
final box = Hive.box('pengaturan');
final tema = box.get('tema_gelap', defaultValue: false);

// Box bertipe: semua value wajib bertipe String
await Hive.openBox<String>('tugas_cepat');
final tugasBox = Hive.box<String>('tugas_cepat');

⚠️ Kesalahan umum

  • Lupa WidgetsFlutterBinding.ensureInitialized() menyebabkan error "Binding has not yet been initialized".
  • Memanggil Hive.box('x') padahal openBox('x') belum dipanggil memicu HiveError: Box not found. Did you forget to call Hive.openBox()?
  • Membuka box yang sama dengan tipe berbeda (openBox<String>('a') lalu openBox('a')) juga memicu error. Pakai tipe yang sama secara konsisten.
