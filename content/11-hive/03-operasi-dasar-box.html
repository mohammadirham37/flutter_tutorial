Box punya method yang mirip Map. Di bagian ini kita coba satu per satu, lengkap dengan output yang muncul di Debug Console.

Daftar method penting

MethodFungsiAsync?
put(key, value)Simpan atau timpa value dengan key tertentuYa (Future)
get(key, defaultValue: ...)Ambil value; null atau defaultValue jika key tidak adaTidak
add(value)Simpan dengan key angka otomatis (0, 1, 2, ...), mengembalikan key baruYa
delete(key)Hapus satu data berdasarkan keyYa
containsKey(key)Cek apakah key adaTidak
keys, values, lengthSemua key, semua value, jumlah dataTidak
getAt(i), putAt(i, v), deleteAt(i)Akses berdasarkan posisi (index), bukan keygetAt tidak, lainnya ya
toMap()Salin seluruh isi box menjadi MapTidak
clear()Hapus semua data di box, mengembalikan jumlah yang terhapusYa

Pola mudahnya: menulis (put, add, delete, clear) mengembalikan Future; membaca (get, keys, values, length) langsung dapat hasilnya.

Contoh lengkap semua operasi

Fungsi berikut bisa kamu panggil dari main() setelah await Hive.initFlutter(), misalnya await demoOperasiDasar(); sebelum runApp.

import 'package:flutter/foundation.dart';
import 'package:hive_ce_flutter/hive_ce_flutter.dart';

Future<void> demoOperasiDasar() async {
  final box = await Hive.openBox('latihan');

  // ---- CREATE / UPDATE dengan key buatan sendiri ----
  await box.put('nama', 'Budi');
  await box.put('semester', 4);
  await box.put('aktif', true);
  await box.put('semester', 5); // key sama = menimpa (update)

  // ---- READ ----
  debugPrint('${box.get('nama')}'); // Budi
  debugPrint('${box.get('semester')}'); // 5
  debugPrint('${box.get('ipk')}'); // null (key belum ada)
  debugPrint('${box.get('ipk', defaultValue: 0.0)}'); // 0.0
  debugPrint('${box.containsKey('aktif')}'); // true

  // ---- add(): key berupa angka otomatis 0, 1, 2, ... ----
  final k1 = await box.add('Kalkulus');
  final k2 = await box.add('Basis Data');
  debugPrint('key baru: $k1, $k2');

  // ---- melihat isi box ----
  debugPrint('keys   : ${box.keys}');
  debugPrint('values : ${box.values}');
  debugPrint('length : ${box.length}');

  // ---- akses berdasarkan POSISI (index), bukan key ----
  debugPrint('getAt(0): ${box.getAt(0)}');
  await box.putAt(0, 'Kalkulus Lanjut');
  debugPrint('setelah putAt: ${box.get(0)}');

  // ---- DELETE ----
  await box.delete('aktif');
  await box.deleteAt(0);
  debugPrint('setelah delete: ${box.toMap()}');

  final jumlahDihapus = await box.clear();
  debugPrint('clear() menghapus $jumlahDihapus data, sisa ${box.length}');
}

Hal yang perlu diperhatikan dari output:

  • put = create sekaligus update. put('semester', 5) menimpa nilai 4 karena key-nya sama. Hive tidak membedakan insert dan update.
  • Key boleh String atau int. add() memakai key int otomatis yang terus naik.
  • Urutan key bukan urutan penyimpanan. Hive mengurutkan key: angka dulu, lalu string secara alfabet. Karena itu getAt(0) menghasilkan Kalkulus (key 0), bukan Budi yang disimpan pertama.
  • deleteAt(0) menghapus posisi pertama, yaitu key 0 (Kalkulus Lanjut), sedangkan delete('aktif') menghapus berdasarkan key.

💡 Pakai key, hindari index

Method ...At(index) mudah salah, karena index bergeser setiap ada data yang dihapus. Untuk data seperti catatan atau tugas, simpan dengan key unik milik datanya sendiri (misalnya id) memakai put(id, data), lalu ubah dan hapus memakai key yang sama. Pola ini dipakai di mini project.

Perlu await saat menulis?

Data yang di-put langsung bisa dibaca dari memori meskipun tidak di-await. Namun penulisan ke file berjalan di belakang layar. Jika aplikasi tiba-tiba dimatikan sebelum Future-nya selesai, data itu bisa hilang. Biasakan await di method async, terutama sebelum pindah halaman atau menampilkan pesan "tersimpan".

// Kurang aman: tidak menunggu sampai benar-benar tertulis ke file
box.put('draft', teks);

// Aman
await box.put('draft', teks);
