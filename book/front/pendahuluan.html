Anatomi setiap bab

Semua bab memiliki susunan yang sama agar Anda mudah menemukan apa yang dicari:

  1. Halaman pembuka. Ringkasan isi bab, prasyarat, estimasi waktu belajar, tujuan pembelajaran, dan daftar subbab.
  2. Subbab materi. Konsep, contoh kode lengkap, dan tangkapan layar hasilnya dari emulator Android.
  3. Rangkuman. Poin-poin terpenting bab dalam satu halaman, cocok untuk mengulang materi sebelum ujian.
  4. Latihan Praktikum. Tugas membangun aplikasi lengkap dengan langkah pengerjaan, hasil yang diharapkan, dan rubrik penilaian.
  5. Uji Pemahaman. Soal pilihan ganda. Kunci jawaban dan pembahasannya ada di Lampiran A.

Cara belajar yang disarankan

Pemrograman tidak bisa dikuasai hanya dengan membaca. Gunakan siklus berikut untuk setiap subbab:

  1. Baca konsepnya. Pahami dulu masalah apa yang diselesaikan oleh materi tersebut.
  2. Ketik ulang contoh kode. Hindari menyalin-tempel pada percobaan pertama. Saat mengetik, Anda akan memperhatikan setiap tanda kurung, koma, dan titik koma.
  3. Jalankan dan amati. Cocokkan hasil di layar dengan tangkapan layar di buku.
  4. Ubah sedikit. Ganti teks, warna, atau angka, atau tambahkan satu widget. Ajukan pertanyaan "apa yang terjadi jika ...?" lalu buktikan.
  5. Sengaja buat error. Hapus satu kurung atau ganti tipe data, lalu baca pesan error-nya. Ini latihan debugging yang paling berharga.
  6. Kerjakan latihan dan uji pemahaman. Simpan hasilnya di repositori Git.

Menjalankan contoh kode

Buku ini memuat dua jenis contoh kode dengan cara menjalankan yang berbeda.

1. Dart murni (terutama Bab 2). Contoh jenis ini tidak membutuhkan Flutter maupun emulator. Buka dartpad.dev, tempelkan kode, lalu klik Run. Cobalah sekarang:

void main() {
  const nama = 'Mahasiswa';
  final materi = ['Dart', 'Widget', 'Layout', 'Supabase'];

  print('Halo, $nama!');
  for (final m in materi) {
    print('Saya akan belajar $m');
  }
}

Hasilnya di panel Console:

Halo, Mahasiswa!
Saya akan belajar Dart
Saya akan belajar Widget
Saya akan belajar Layout
Saya akan belajar Supabase

2. Aplikasi Flutter (Bab 1 dan seterusnya). Contoh jenis ini membutuhkan proyek Flutter dan sebuah perangkat (emulator, ponsel fisik, atau Chrome). Buat satu proyek khusus untuk mencoba contoh:

# Cukup sekali: buat proyek latihan
flutter create latihan_flutter
cd latihan_flutter

# Setiap mencoba contoh berlabel lib/main.dart:
# 1. Ganti SELURUH isi lib/main.dart dengan kode contoh
# 2. Jalankan aplikasi
flutter run

# Jika contoh memakai package, tambahkan terlebih dahulu (misalnya http)
flutter pub add http

Kesalahan umum saat mencoba contoh

  • Menempelkan kode di bawah kode lama sehingga ada dua fungsi main(). Hapus seluruh isi berkas sebelum menempel.
  • Lupa menjalankan flutter pub add sehingga muncul error Target of URI doesn't exist.
  • Hanya menekan Hot Reload setelah mengganti seluruh main.dart. Gunakan Hot Restart (R), yang dijelaskan di Bab 1.
  • Mengabaikan garis merah di editor. Jalankan flutter analyze dan perbaiki error sebelum flutter run.
